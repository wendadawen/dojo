# 阶段 2：教学大纲

本阶段将研究范围转换为可执行的教学路径，决定内容如何组织和呈现，不重新调研论文，不改变已确认的内容范围，不写 HTML。

读者默认是完全小白。教学大纲不得依赖页面外的领域基础知识，并应使读者能够回答 `scope.md` 中的全部核心问题。

---

## 1. 输入与输入门槛

```text
content/papers/<venue>/<name>/research/
├── scope.md
└── evidence.md
```

产物缺失或研究结束条件未满足时，返回阶段 1，不得通过大纲设计绕过研究缺口。

---

## 2. 产物

```text
content/papers/<venue>/<name>/research/outline.md
```

`outline.md` 是阶段 3 写作的直接依据，使作者无需重新决定文章范围或教学结构。

---

## 3. 设计要求

### 3.1 页面开头

规划论文的一句话说明、论文解决的具体问题、学习承诺（读完能够回答的核心问题）、论文元信息（标题、作者、单位、会议、年份、论文链接、代码仓库）、首个具体场景、首次出现术语的当场解释、与第一章的过渡。只使用已确认的论文定位、核心问题和范围内容，不加入未经证实的数字、历史或性能结论。

### 3.2 核心问题覆盖

每个核心问题必须由一个正文章节负责完整回答，其他章节可以提供支持但不造成责任不清。核心问题不得只由折叠块回答。

### 3.3 教学依赖顺序

内容和基础知识必须在首次依赖前完成讲解，不得用尚未解释的术语去解释另一个新术语。两个概念互相依赖时，先寻找共同的具体场景或可观察现象，再逐步引入定义。

### 3.4 贯穿问题或例子

优先选择一个可以跨越主要章节的具体问题或最小例子：输入、变量和目标可以在第一次出现时完整说明；数字足够小，能够手算或逐步追踪；后续章节每次复用时都增加新的概念、计算步骤或结论。

单一例子无法自然覆盖全文时，使用一条贯穿问题和多个局部例子，每个局部例子说明服务哪个教学问题、为什么不能复用前一个例子。本阶段选择的例子不得引入新的外部事实或改变已确认范围。

### 3.5 章节设计

每章只承担一个主要教学任务。章节数量和标题由教学依赖与核心问题决定，不使用固定章节模板。论文"问题 → 方法 → 实验 → 评价"的叙事通常自然映射教学任务划分，但标题必须直接说明本章解决的问题或得到的结论，避免"背景""原理""深入理解"一类无法定位教学任务的抽象词。

独立评价是必有的一章，职责是给出解读者对方法的判断：优点、局限、适用场景、与相邻工作的位置。本章内容全部为解读者推断，大纲只规划评价要点，评价不得伪装成论文结论。

每章记录 7 个字段：

```markdown
## S1：<具体标题>

- 主要教学问题：本章要回答的具体问题
- 对应范围：Q1、K1、B1、M1、C1、F1 编号
- 正文要点：必须按顺序讲清的定义、机制和限制
- 讲解材料及职责：按需选择公式 / 推导 / 类比 / 数字例子 / 原图 / 图示 / 伪代码 / 可运行代码，每项说明解决哪个具体教学问题、教学简化及其边界；放折叠块的材料注明正文保留了哪些必要步骤
- 基础知识安排：本章首次讲解的基础知识及完成标准（如涉及）
- 完成检查：读者在本章结束时应能完成的解释、判断或计算
- 过渡：本章结论尚未解决什么，由下一章继续
```

### 3.6 讲解材料选择

每种材料必须关联一个具体教学问题：公式用于表达变量关系，推导用于解释关键结论的来源，数字例子用于展示计算步骤或数值变化，原图用于呈现论文原始的结构与数据，图示用于展示结构、依赖或变化过程，代码用于展示可执行机制。无法关联具体教学问题的材料不纳入大纲。材料类型没有固定套餐，不因页面出现公式就自动安排完整推导或代码。

**原图**是论文解读特有的材料：从 `evidence.md` 的原图候选清单中选择，每张注明服务的教学问题、放置位置和原文 Figure 编号；候选清单中的图都不合适时，用自绘图示替代并在大纲中说明。每张原图按"引导句 → 图片 → 解释段"组织：引导句说明看什么，解释段如实描述图中内容并说明它支撑哪个结论。

伪代码用于表达语言无关的步骤结构，可运行代码用于执行验证和观察输出，二者只有承担不同职责时才同时使用。教学构造的数字、场景和代码标记为教学示例，不写成论文的实验事实。

### 3.7 正文与折叠块分工

必须放正文：回答核心问题所需的定义、机制和结论；理解后续章节所需的基础知识；会改变结论的成立条件和限制；贯穿例子的关键推进；公式的目的、符号和各部分作用；关键实验数字及其设置。

可放折叠块：正文已保留必要步骤后的完整代数展开、更长手算过程、完整代码与输出、补充证明、已纳入范围的扩展实验、详细工程差异。

折叠块全部收起时，正文仍须回答全部核心问题、支撑章节之间的逻辑过渡。

---

## 4. 范围与证据约束

大纲只能使用 `scope.md` 中已纳入范围的内容。发现以下情况时返回阶段 1：缺少回答核心问题所必需的定义或机制；需要增加新的核心问题；需要把已排除内容纳入页面；新增事实会改变论文定位或主要结论。

只有"已确认"的核心 C/F/N 项可以进入正式讲解。存在冲突的内容按 `scope.md` 已确认的处理方式呈现。证据不足且已排除出页面范围的内容不得重新加入。

---

## 5. 完成条件

- 页面开头已规划一句话说明、具体问题、学习承诺、论文元信息、首个场景和进入第一章的过渡
- 每个核心问题都有一个负责完整回答的正文章节
- 每项基础知识都安排在首次依赖前，并有可检查的完成标准
- 每章只有一个主要教学任务，7 个字段填写完整；独立评价章节的评价要点已列出
- 贯穿问题或例子能够连接主要章节；无法贯穿时已说明局部例子的必要性
- 每项讲解材料都有具体且互不重复的教学职责，并对应已确认的范围和证据编号或明确标记为教学构造；原图均来自候选清单并标注 Figure 编号
- 折叠块全部收起时正文仍完整
- 每个常见误解和适用边界都有负责处理的章节
- 大纲未加入 `scope.md` 排除的内容
