    恒等超连接（iHC）：流间零混合、只留读写门的并行残差流

    主要依据：Hy4-preview 官方 README 与 config.json（Tencent-Hunyuan/Hy4-preview，2026-08-28 发布）；vLLM 官方实现 PR #54160（commit b2f685834a645，vllm/models/hy_v4/nvidia/hc.py，腾讯工程师提交）；checkpoint 张量实测（model.safetensors.index.json 与 shard 头，2026-09-03 本机拉取）。

    78 层、770B 参数的主干里，所有跨层传递的信息——任务目标、中间结果、异常信号——都要经过残差流。标准 Transformer 只有一条流，层数一深就成了独木桥。超连接（Hyper-Connections）把它加宽成 $n$ 条并行流，每层读入、混合、写回；mHC 又把混合矩阵约束为双随机矩阵来保住稳定性。加宽的收益换来两笔新开销：每层要做 Sinkhorn 迭代投影来满足约束，深层的混合矩阵连乘还有坍缩的倾向。这两条路线的完整机制见超连接与 mHC。

    Hy4-preview（腾讯混元 2026-08-28 发布的 770B MoE 模型）的残差通路给出第三条路：流加宽到 4 条，但流间不做任何混合——混合矩阵固定为单位阵。这就是 iHC（identity Hyper-Connections）：可学习的自由度只剩每个子块入口的读门和出口的写门，都是逐 token 动态算出的 sigmoid 门。

    这个设计的出发点可以用一个最小情形看清：入口把 embedding 复制 4 份，初始门控下 4 条流保持相等，每一步都退回标准 Pre-Norm 残差的行为——iHC 不是另起炉灶，而是从标准残差出发，把「读多少、写多少」留给训练。

    本页先在家族里定位 iHC 改了哪一刀，再走完一个子块的完整数据流，拆开门控计算与初始化，论证为什么把混合矩阵钉死在 $I$，最后落到 Hy4 的配置、权重与代价。

    核心问题

    1. iHC 相对 mHC 拿掉了什么、留下了什么？

      解答：拿掉流间混合矩阵，留下逐 token 读写门

      拿掉的是流间混合——mHC 用 Sinkhorn 投影维持的双随机混合矩阵 $\mathbf{A_r}$，iHC 直接固定为单位阵 $\mathbf{I}$，旧流原样传递。留下的是逐 token 动态的读门 $H_{pre}$ 与写门 $H_{post}$（sigmoid 参数化），它们成为残差通路的全部可学习自由度。完整论证见「1. iHC 拿掉了混合矩阵」。

    2. 一个子块在 iHC 下怎么完整走一遍？

      解答：pre 合并、RMSNorm、子层算一次、post 写回

      入口把 embedding 复制 4 份成 4 条流；每个子块四步：pre 把 4 条流按读门加权合并成一份输入（顺手算出写门）、RMSNorm、子层计算一次、post 把输出按写门加回每条流（旧值原样保留）。78 层走完后 head 门控合并，再过 final RMSNorm 进 lm_head。残差内嵌在流里，没有独立张量。完整数据流见「2. 一个子块的完整路径」。

    3. 读写门从哪来？初始时是什么行为？

      解答：展平投影加 sigmoid；初始等权读、满幅写

      pre 块把 4 条流展平成 $nd$ 维向量，经整体 RMS 与 $[2n, nd]$ 线性投影得到 8 个 logits，前 4 个过 sigmoid 加 $\epsilon_{hc}$ 得读门，后 4 个过 sigmoid 乘幅度 $m$ 加 $\epsilon_{hc}$ 得写门。初始化让读门 $\approx\sigma(-\ln 3)=0.25$（等权平均）、写门 $\approx 2\sigma(0)=1$（满幅写回），初始行为贴标准 Pre-Norm 残差，与标准残差的差别只有 $\epsilon_{hc}$ 累乘出的 $10^{-5}$ 量级。见「3. 读写门从哪来、从哪里出发」。

    4. 为什么把混合矩阵钉死在 $I$ 效果反而更好？

      解答：学出的混合本就接近单位阵，连乘会坍缩，identity 还省掉开销

      四条依据：mHC 学出的单层混合矩阵本来就接近单位阵（对角约 0.96）；双随机正矩阵连乘坍缩到均匀矩阵，深层把流混匀；identity 保持流语义一致（$I^L=I$）；Sinkhorn 近似误差与专用 kernel 负担一并消失。注意：这些是 Hy4 README 引用的社区实验结论与实现注释，iHC 本身没有正式论文。见「4. 把混合矩阵钉死在 $I$ 的理由」。

    5. Hy4 里 iHC 的配置和代价是什么？

      解答：4 流 78 层双站点；30.77M 参数，代价在激活显存

      4 条流、hidden 6144、78 层每层两个 HC 边界（注意力、MLP/MoE 各一，参数独立）、写门幅度 2.0、$\epsilon_{hc}=10^{-6}$；iHC 总参数 30,770,717（约占 770B 的 0.004%），门控权重 float32、不参与 FP8 量化；MTP 草稿层不用 iHC。代价主要在激活显存：残差状态从 1 份变 4 份，子层 FLOPs 不变。见「5. Hy4 里的 iHC：配置、权重与代价」。

    常见误解

    • 四条流等于计算量翻 4 倍——每个子层只对合并后的单份输入计算一次；变 4 倍的是残差状态的激活显存，不是子层 FLOPs。
    • 四条流各过各的注意力或 MLP——复制只发生在模型入口；每个子块把 4 条流合并成一份输入、过同一个子层、再写回。流是状态通道，不是并行计算。
    • 流间不混合等于四条流互不相干——读门把 4 条流加权合并（信息在子层计算里汇合），写门让每条流都吸收同一份子层输出；不混合的只是旧状态如何传递。
    • identity 指的就是残差连接那个恒等映射——$I$ 固定的是流间混合矩阵（mHC 记号 $\mathcal{H}^{res}$、GLM 实现称 comb）；残差通路的恒等性另由 post 里「加旧流」这一项保证。
    • iHC 被论文证明优于 mHC——iHC 没有正式论文；「Identity HC > mHC」是 Hy4 README 引用的社区实验结论（Qwen3 1.7B/8B、150B tokens、从头训练），引用时必须带实验条件。

    1. iHC 拿掉了混合矩阵

    1.1 从三映射到一刀

    标准残差的要点是恒等映射：旧状态不加修改地传向深层，梯度得以直达浅层——这是深层网络可训练的基础，见残差连接。超连接在这条通道上加宽：把单一残差流扩成 $n$ 条，每个子块入口用读映射 $\mathbf{A_m}$ 把 $n$ 条流加权合并成子层输入，出口用写映射 $\mathbf{B}$ 把子层输出分发回流上，流之间再用混合矩阵 $\mathbf{A_r}$ 线性混合。单层传播为：

    $$\hat{\mathbf{H}}=\mathbf{B}^{\intercal}\mathcal{T}\left((\mathbf{H}^{\intercal}\mathbf{A_{m}})^{\intercal}\right)+\mathbf{A_{r}}^{\intercal}\mathbf{H}$$
    • $\mathbf{H}$：$n$ 条流拼成的残差状态，每条流 $d$ 维
    • $\mathcal{T}$：子层（注意力或 MLP），对合并后的单份输入计算一次
    • $\mathbf{A_m}$、$\mathbf{B}$：读、写权重——Hy4 实现里是逐 token 的门 $H_{pre}$、$H_{post}$
    • $\mathbf{A_r}$：流间混合矩阵——每条流的旧值按它的列权重漏进其他流

    无约束的 $\mathbf{A_r}$ 连乘会让信号爆炸或消失：多层 $\mathbf{A_r}$ 乘积的最大绝对行和/列和（Amax Gain Magnitude）峰值约 3000、理想值 1（27B 模型）[N8]。mHC 把 $\mathbf{A_r}$ 约束为双随机矩阵——行和列和都是 1 的非负矩阵——恢复稳定性，用 Sinkhorn-Knopp 交替行列归一化投影实现。这两步的完整推导见超连接与 mHC，本页只用结论。

    iHC 把刀砍在混合上：$\mathbf{A_r}=\mathbf{I}$，

    $$\hat{\mathbf{H}}=\mathbf{B}^{\intercal}\mathcal{T}\left((\mathbf{H}^{\intercal}\mathbf{A_{m}})^{\intercal}\right)+\mathbf{H}$$

    流间零混合，旧状态原样传递；$\mathbf{A_m}$ 与 $\mathbf{B}$ 保留为逐 token 动态门[F6]。Hy4 官方对残差通路的表述是「residual pathway uses iHC (identity Hyper-Connections) to expand inter-layer information flow」，规格为 4 条残差流[C1]；实现注释说得更直白：「Unlike mHC there is no comb matrix, so each output channel only needs its own residual channel and the whole thing is one fused multiply-add per element」[C3]。

    命名注记：官方 README 与模型卡写 identity Hyper-Connections；vLLM 实现的 docstring 写 independent Hyper-Connections（hc.py 与 hpc_ihc.py 两处）。指同一机制——流间没有混合矩阵。本页按 README 用 identity，与 $\mathbf{A_r}=\mathbf{I}$ 的数学含义直接对应[C4]。

    这里的 identity 不是残差连接那个恒等映射。$I$ 固定的是流间混合矩阵（mHC 论文记 $\mathcal{H}^{res}$，GLM 实现称 comb）；「旧状态原样传到下一层」的恒等性由 post 块 $\hat{x}_i = H_{post,i}\cdot z + x_i$ 里的 $+x_i$ 保证。两个恒等不在同一层：一个说流怎么混合（取 $I$），一个说残差怎么保底（加旧值）。

    1.2 三条路线怎么传旧状态

    把三条路线放到「读—旧状态传递—写」三个位置上看，iHC 的改动性质一目了然。

    位置标准残差mHCiHC
    读（入口合并）无：直接用隐状态逐 token 动态读门逐 token 动态读门 $H_{pre}$
    旧状态传递恒等直传双随机矩阵线性混合（Sinkhorn 投影）恒等直传（$\mathbf{A_r}=\mathbf{I}$）
    写（出口分发）全量加回，系数 1逐 token 动态写门逐 token 写门 $H_{post}$，带幅度 $m$
    额外机制无Sinkhorn 迭代与行列和约束无：门控是唯一可学习自由度

    mHC 与 iHC 的读写门形式接近，核心分歧只在中间一档：旧状态要不要在流间重新分配。iHC 的回答是不分配——每条流的旧值只属于自己，流间的一切交互都发生在「读时合并、写时吸收」里。

    本章问题

    1. iHC 相对 mHC 改了哪一处？为什么说是最小改动？

      解答：只把混合矩阵从双随机约束改为固定单位阵

      mHC 在超连接的三映射（读 $\mathbf{A_m}$、混合 $\mathbf{A_r}$、写 $\mathbf{B}$）之上，把 $\mathbf{A_r}$ 约束为双随机矩阵，靠 Sinkhorn-Knopp 投影实现。iHC 只改这一处：$\mathbf{A_r}$ 固定为 $\mathbf{I}$，流间零混合、旧状态原样传递；读门写门保留为逐 token 的 sigmoid 门，成为全部可学习自由度。说它「最小」，是因为三条路线在读与写两端的形式是连续的（读写门从常数到动态），被改掉的只有混合这一档。命名上 README 称 identity、vLLM 注释称 independent，同一机制。

    2. 三类残差通路在「旧状态如何跨层传递」上的差别？

      解答：恒等直传、双随机混合后传递、恒等直传加门控读写

      标准残差——恒等直传，旧状态不加修改地加回；mHC——旧状态先经双随机矩阵线性混合再传递，任何一条流的旧值都会按权重漏进其他流；iHC——旧状态恒等直传，但每个子块读时按读门加权合并、写时让每条流按自己的写门吸收同一份子层输出。差别全部集中在「旧值是否在流间重新分配」这一件事上。

    2. 一个子块的完整路径

    2.1 从入口复制到末端合并

    iHC 的全部机制由三个计算块组成：pre（读门与合并）、post（写门与残差回加）、head（末端合并）[C2]。模型入口先做一次复制：embedding $[t, 6144]$ 广播成 $[t, 4, 6144]$，4 条流初值相同[C7]。之后每个子块走下面这条链：

    把一个子块自带的 pre 与 post 边界称为一个站点：Hy4 每层两个（注意力、MLP 各一），参数各自独立，第 1 层的 dense FFN 同样有[C5]。实现的前向顺序是：注意力站点 pre → input_layernorm → self_attn → post，接着 MLP 站点 pre → post_attention_layernorm → mlp → post。「Under iHC the residual is carried inside hidden_states」——残差不再有独立张量，就装在 4 条流里[C6]。

    RMSNorm 是子层自己的输入归一化，位于 pre 之后：它归一化的是合并后的单份输入，不是每条流各自归一化（机制见RMSNorm）。post 的回加对每条流用同一个 $z$、不同的系数：$\hat{x}_i = H_{post,i}\cdot z + x_i$，无参数[F2]。

    78 层走完，head 在最终输出 norm 之前把 4 条流门控合并回单一隐状态，随后过 final RMSNorm 进 lm_head[C7]。head 的门控与 pre 同构，但不产出写门——它是纯合并[F3]。

    两个容易看错的地方：复制只发生在入口，之后没有任何复制；每个子层只计算一次，输入是读门合并出的那一份。

    2.2 第一幕：初始化状态

    构造示例：一个 4 流、$d=2$ 的迷你模型，两个子块（分别放在注意力位置与 MLP 位置，子层用简单线性映射代替——子层内部不是本页主题），末端一个 head。初始参数按官方初始化取值，hc_fn 置零让门精确停在偏置值上；权重与门值为教学构造，非 Hy4 checkpoint 数值。

    入口 4 条流相等，取 $[1.0, -0.5]$。初始读门 $\sigma(-\ln 3)+\epsilon_{hc}=0.250001$（4 个）、写门 $2\sigma(0)+\epsilon_{hc}=1.000001$（4 个），合并输入：

    $$y=4\times 0.250001\times[1.0,\,-0.5]=[1.000004,\,-0.500002]$$

    读门之和是 $1+4\epsilon_{hc}=1.000004$，合并输入比原值大 $4\times 10^{-6}$ 的相对量级——随后就被 RMSNorm 归一化掉。归一化、过子层、写回后，出口 4 条流完全相等（流间最大差 $0.0$）；第二个子块同理。head 以同样的 $0.250001$ 门合并，最终输出 $[2.602972, -1.739864]$。

    让标准 Pre-Norm 残差走同样的两个子层，结果 $[2.60296, -1.739856]$——两者之差的最大分量 $1.21\times 10^{-5}$，全部来自 $\epsilon_{hc}$ 的累乘。初始状态的 iHC 就是标准 Pre-Norm 残差加上一个 $10^{-5}$ 量级的扰动；流的分化要等门被训练移动之后才出现。

    展开：第一幕两个子块的完整手算

    子块 1（注意力位置）。读门 $0.250001$（4 个），写门 $1.000001$（4 个）。

    $$y=\sum_{i=1}^{4}0.250001\,x_i=4\times 0.250001\times[1.0,\,-0.5]=[1.000004,\,-0.500002]$$

    归一化输入 $[1.264901, -0.63245]$，子层输出 $z=[1.011921, -0.12649]$。写回（4 条流相同）：

    $$\hat{x}_i=1.000001\times z+x_i=[2.011922,\,-0.62649]$$

    子块 2（MLP 位置）。门不变。合并输入 $y=[2.01193, -0.626493]$，归一化输入 $[1.350262, -0.420457]$，子层输出 $z=[0.59104, -1.113366]$，写回后 4 条流为 $[2.602962, -1.739857]$。

    head 门控合并：$4\times 0.250001\times[2.602962,\,-1.739857]=[2.602972,\,-1.739864]$。

    本章问题

    1. 4 条流怎么进子层、怎么出来？

      解答：读门合并成一份进，写门按流加回出

      入口把 embedding 复制 4 份；每个子块四步：pre 按读门加权合并成一份输入并顺手算出写门，RMSNorm，子层计算一次，post 按写门把输出加回每条流——每条流加的是同一份输出的不同倍数，旧值原样保留。78 层后 head 门控合并、final RMSNorm、lm_head。残差没有独立张量，内嵌在 4 条流里；复制只在入口发生一次，子层只算一次，激活显存是标准残差的 4 倍而子层 FLOPs 不变。

    2. 初始状态下贯穿示例走两步会发生什么？

      解答：4 条流保持相等，精确退化为标准 Pre-Norm 残差

      4 条流初始相等、读门等权 $0.25+\epsilon_{hc}$、写门 $1+\epsilon_{hc}$：合并输入约为原值（相对偏差 $4\epsilon_{hc}$，且随后被 RMSNorm 归一化掉），写回后 4 条流仍完全相等（实测流间最大差 $0.0$），第二个子块同理。head 合并后与标准 Pre-Norm 残差的差别只有 $1.21\times 10^{-5}$，全部来自 $\epsilon_{hc}$ 的累乘。流分化要等训练把门从等权移开之后才出现。

    3. 读写门从哪来、从哪里出发

    3.1 门控计算：从 4 条流到 8 个数

    pre 块要从一个 token 的 4 条流算出 8 个数：4 个读门、4 个写门。路径分四步[F1]：先展平，再算整体 RMS 尺度因子，然后线性投影出 8 个 logits 并乘上尺度因子，最后过 sigmoid 成门：

    $$x^{flat}=\mathrm{flatten}(x)\in\mathbb{R}^{nd},\qquad r=\frac{1}{\sqrt{\mathrm{mean}\left((x^{flat})^2\right)+\epsilon_{rms}}}$$ $$\mathrm{mixes}=(x^{flat}W^{\intercal})\cdot r\in\mathbb{R}^{2n}$$ $$H_{pre}=\sigma\left(\mathrm{mixes}_{[:n]}\cdot s_{0}+b_{[:n]}\right)+\epsilon_{hc},\qquad H_{post}=m\cdot\sigma\left(\mathrm{mixes}_{[n:]}\cdot s_{1}+b_{[n:]}\right)+\epsilon_{hc}$$

    合并输入是读门加权和 $y=\sum_{i=1}^{n}H_{pre,i}\cdot x_{i}$。

    • $x$：当前 token 的 4 条流，形状 $[4, d]$，Hy4 里 $d=6144$
    • $W\in\mathbb{R}^{2n\times nd}$：门控投影权重（hc_fn），门控路径里唯一的矩阵
    • $s\in\mathbb{R}^{2}$、$b\in\mathbb{R}^{2n}$：每类门的缩放与偏置（hc_scale、hc_base）
    • $m$：写门幅度（hc_magnitude，Hy4 取 2.0），写门值域约 $(\epsilon_{hc},\, m+\epsilon_{hc})$
    • $\epsilon_{rms}=10^{-5}$：RMS 分母下限；$\epsilon_{hc}=10^{-6}$：加在门上、保证严格正的小量
    • $\sigma$：sigmoid，把任意实数压进 $(0,1)$ 的光滑函数

    RMS 因子 $r$ 在这里的作用与子层前的 RMSNorm 不同：它不改变流的值，只把投影输入整体归一到单位 RMS——mixes 的量级不随流的幅度漂移，门对输入尺度不敏感。门是逐 token 的：同一 batch 里不同 token 展平出的 $x^{flat}$ 不同，门就不同；每个站点有自己的一套 $W$、$s$、$b$，互不共享[C5]。

    源码里的门控精度：门控整条路径在 float32 中计算（实现里对展平与投影显式 .float()）；hc_* 权重为 float32，在 FP8 检查点中经 modules_to_not_convert 排除在量化外[C9]。

    3.2 初始化：把起点放在标准残差上

    初始化取值[C8, F4]：$s=(0.01, 0.01)$；$b$ 的前 $n$ 个分量（读门偏置）取 $-\ln(n-1)$，后 $n$ 个（写门偏置）取 $0$；head 同构，偏置全取 $-\ln(n-1)$。$n=4$ 时读门偏置是 $-\ln 3$。

    代入读门（scale 0.01 把 mixes 压到近零，构造示例里 hc_fn 置零则精确为零）：

    $$H_{pre}\approx\sigma(-\ln 3)=\frac{1}{1+e^{\ln 3}}=\frac{1}{1+3}=\frac{1}{4}$$

    4 条流等权平均。写门：

    $$H_{post}\approx 2\,\sigma(0)=2\times\frac{1}{2}=1$$

    满幅写回。「子层输入 = 四流平均、输出 = 全额写回」正是标准 Pre-Norm 残差的行为——训练从「等价于标准残差」出发，要学的只是门的偏移[F5]。

    $\epsilon_{hc}$ 是这套初始化里唯一的偏差来源：读门之和 $1+4\epsilon_{hc}$、写门 $1+\epsilon_{hc}$。块内读门的 $4\epsilon_{hc}$ 随后就被 RMSNorm 归一化掉，真正留下来的是每步写门的 $\epsilon_{hc}$ 与 head 合并的 $4\epsilon_{hc}$——合计约 $1.2\times 10^{-5}$，正是第一幕实测到的与标准残差的差。

    补充：一般 $n$ 的初始门推导

    由 $\sigma(z)=\frac{1}{1+e^{-z}}$，取 $z=-\ln(n-1)$：

    $$\sigma\left(-\ln(n-1)\right)=\frac{1}{1+e^{\ln(n-1)}}=\frac{1}{1+(n-1)}=\frac{1}{n}$$

    即任意流数下读门的初始值都是 $\frac1n+\epsilon_{hc}$：$n$ 条流等权平均。写门初始值 $m\,\sigma(0)+\epsilon_{hc}=\frac{m}{2}+\epsilon_{hc}$，Hy4 取 $m=2$ 即 $1+\epsilon_{hc}$。head 的初始合并系数是 $n\cdot\left(\frac1n+\epsilon_{hc}\right)=1+n\epsilon_{hc}$。

    3.3 第二幕：训练后的门

    训练后的门不再等权。第二幕构造一组分化门：读门 $[0.55,\, 0.20,\, 0.10,\, 0.15]$（偏向流 1），写门 $[1.8,\, 0.6,\, 1.2,\, 0.3]$（强弱不一，都在值域 $(\epsilon_{hc},\, m+\epsilon_{hc})$ 内）；出发点是一组已轻微分化的流（第 1 维极差 0.20、第 2 维 0.10）。

    读门先起作用：合并输入 $y_2=[0.9975, -0.502]$，最接近流 1 的值 $[1.00, -0.50]$——读门偏向哪条流，子层看到的输入就更像那条流。子层输出 $z_2=[1.012247, -0.129618]$，写门把同一份 $z_2$ 按不同倍数加回：流 1 吸收 $1.8\,z_2$，流 4 只吸收 $0.3\,z_2$。

import numpy as np

n, d = 4, 2                                # 4 条流，每条 2 维
m, eps_hc, eps_rms = 2.0, 1e-6, 1e-5       # 幅度、门上的 epsilon、RMS 的 epsilon

def sigmoid(x):
    return 1.0 / (1.0 + np.exp(-x))

def rms_norm(x, eps=eps_rms):              # 逐 token、最后一维
    return x / np.sqrt(np.mean(x**2, axis=-1, keepdims=True) + eps)

def pre_block(x, W, scale, base):
    """读门合并 + 顺手算出写门。x: [n, d] -> y: [d]"""
    x_flat = x.reshape(-1)                              # [n*d]
    r = 1.0 / np.sqrt(np.mean(x_flat**2) + eps_rms)
    mixes = (W @ x_flat) * r                            # [2n]
    H_pre = sigmoid(mixes[:n] * scale[0] + base[:n]) + eps_hc
    H_post = m * sigmoid(mixes[n:] * scale[1] + base[n:]) + eps_hc
    y = np.sum(H_pre[:, None] * x, axis=0)              # [d]
    return y, H_pre, H_post

def post_block(x, z, H_post):
    """写门回加：每条流加同一份子层输出的不同倍数。"""
    return H_post[:, None] * z + x                      # [n, d]

def head_block(x, W_h, scale_h, base_h):
    """末端门控合并。"""
    x_flat = x.reshape(-1)
    r = 1.0 / np.sqrt(np.mean(x_flat**2) + eps_rms)
    mixes = (W_h @ x_flat) * r                          # [n]
    H_head = sigmoid(mixes * scale_h[0] + base_h) + eps_hc
    return np.sum(H_head[:, None] * x, axis=0), H_head

    print("  子层输出 z =", np.round(z, 6))
    print("  出口 4 条流（流间最大差 %.1e）:" % np.max(np.ptp(x, axis=0)))
    print(np.round(x, 6))

    本章问题

    1. 门怎么从 4 条流的内容算出来？

      解答：展平、整体 RMS、线性投影、sigmoid

      把 4 条流展平成 $nd$ 维向量，算整体 RMS 得尺度因子 $r$；经 $[2n, nd]$ 线性投影得 8 个 logits 并乘 $r$；前 4 个过 $\sigma$ 加 $\epsilon_{hc}$ 得读门，后 4 个过 $\sigma$ 乘幅度 $m$ 加 $\epsilon_{hc}$ 得写门；合并输入是读门加权和 $y=\sum_i H_{pre,i}x_i$。RMS 因子让门的量级不随输入幅度漂移。门逐 token 不同；每个站点一套参数，互不共享。

    2. 初始化为什么能把起点放在标准残差上？

      解答：scale 压缩投影项，偏置定在等权读与满幅写

      scale 取 0.01，把投影项对门的贡献压到近零，门近似停在偏置值上：读偏置 $-\ln(n-1)$ 使 $\sigma(-\ln 3)=\frac14$，4 条流等权读；写偏置 0 使 $2\sigma(0)=1$，满幅写回。这样初始 iHC 的行为就是标准 Pre-Norm 残差（差别仅 $\epsilon_{hc}$ 累乘的 $10^{-5}$ 量级），训练从这一点出发只学门的偏移。

    3. 训练后的门会做什么？

      解答：读门选流，写门定吸收强度，流间差距逐层放大

      读门决定子层看到哪几条流的加权组合——偏向哪条流，合并输入就更像谁；写门决定每条流吸收子层输出的强度（值域约 $(\epsilon_{hc}, m+\epsilon_{hc})$）。两者配合让流间差距逐层放大：第二幕构造门下一个子块就把第 1 维极差从 0.20 放大到 1.4684。门控权重保持 float32、不参与 FP8 量化。

    4. 把混合矩阵钉死在 $I$ 的理由

    论证的性质：iHC 没有正式论文。本章的依据是两部分——Hy4 README 官方引用的社区研究（知乎文章《你的deepseek mHC可能不需要"m"》，其链接由 README 的「iHC」指向）与 vLLM 实现注释。引用处均标注实验条件，不写成官方论文结论。

    4.1 学出的混合本来就接近单位阵

    第一条依据是「没损失什么」：该社区实验实测，mHC 训练后学出的单层混合矩阵对角约 0.96、非对角约 0.01，深度达到 10 层以上的累积乘积更是坍缩为全 0.25 的均匀混合矩阵（Qwen3 系列实验观测）[C14, N4]。也就是说，靠 Sinkhorn 代价维护的混合矩阵，学出来接近单位阵——混合本来就没学到多少，直接钉死在单位阵损失有限。

    4.2 双随机矩阵连乘的坍缩

    第二条依据是「留着反而有害」。双随机矩阵的连乘有内在的坍缩倾向：只要每层矩阵的元素有一个共同的正下界 $\delta$（一致正性；Sinkhorn 的输出通常严格正），Dobrushin 遍历系数就以不超过 $1-n\delta$ 的比率逐层几何衰减，行与行越来越像；行相同且行和为 1 的极限只有一个——均匀矩阵 $\frac{1}{n}\mathbf{1}\mathbf{1}^{\intercal}$[C15]。到那一步，4 条流在深层被完全混匀，多流失去意义。

    用构造实验复现这个现象：每个「层」生成一个随机正矩阵，经 20 步 Sinkhorn 投影到近似双随机，然后连乘 12 层，观察累积混合矩阵的第一行与它到均匀向量的距离。

def sinkhorn(A, steps):
    """交替行、列归一化，把正矩阵投影到近似双随机矩阵。"""
    for _ in range(steps):
        A = A / A.sum(axis=1, keepdims=True)   # 行和归一
        A = A / A.sum(axis=0, keepdims=True)   # 列和归一
    return A

    观察重点：第 1 层矩阵的行和列和在 4 位小数下都回到 1，最小元素 0.1019——严格正，满足一致正性；连乘后行向量迅速贴近 $[0.25, 0.25, 0.25, 0.25]$，max 距离从层 0 的 0.7500 经 0.1481、0.0319、0.0048 几何式衰减，层 6 起在 4 位小数下为 0。

    简化条件：矩阵由 rng(0) 均匀采样（元素范围 0.2 至 1.0），比训练学出的矩阵更「混」，坍缩更快；现象方向与论证一致，衰减速度不可与真实训练比。

    边界：纯置换矩阵或可约矩阵的序列不满足一致正性，连乘不坍缩（置换矩阵的乘积仍是置换矩阵）；但 Sinkhorn 的输出通常严格正，落在会坍缩的一侧[C15]。

    补充：Dobrushin 遍历系数的论证细节

    定义 $\tau(M)=\frac{1}{2}\max_{i,k}\sum_{j}|M_{ij}-M_{kj}|$——任意两行作为分布的总变差距离的上界。三条性质：

    • 次乘性：$\tau(MN)\le\tau(M)\,\tau(N)$，连乘的系数逐层相乘。
    • 元素都有正下界 $\delta$ 的双随机矩阵满足 $\tau(M)\le 1-n\delta$：任取两行，逐列差的总和被 $\delta$ 挤压。
    • $L$ 层连乘后 $\tau\le(1-n\delta)^{L}\to 0$：行间距离趋于零，所有行趋于同一分布；行和恒为 1，极限行只能是 $\frac1n\mathbf{1}^{\intercal}$。

    构造实验里 $\delta\approx 0.10$，界给出每层衰减不超过 $1-4\times 0.10=0.6$，实测衰减约 0.2 每层，在界内。论证来自上述社区文章，本页用构造实验复现现象。

    4.3 identity 还买到什么

    第三条：流语义一致性。identity 相当于所有层用同一个恒等置换——流 $i$ 永远在位置 $i$，读写门不需要追踪「流被哪一层重排到哪里」；且 $I^L=I$，无论多深都不坍缩、不混乱[C18]。

    第四条：开销消失。Sinkhorn 是迭代近似——该文实测条件下 20 步迭代后行和标准差仍有 0.12 量级，还引 mHC-lite 的实测：输入的 relative range 达 $10^{13}$（占其实测输入的 27.9%）时，列和偏差可达 100%[C17, N5]。identity 下这些近似误差不存在，混合矩阵的投影与乘法、专用 kernel 的工程负担也一并消失——「每条输出通道只需要自己的残差通道，整体是每个元素一次融合乘加」[C3]。

    综合排序（社区实验：Qwen3 1.7B 与 8B dense、150B tokens、从头训练）：Identity HC > mHC > mHC lite > mHC orthogonal[C16]。iHC 在这个序列里是损失最小、开销也最小的一端。

    本章问题

    1. 去掉流间混合，证据说损失了什么？

      解答：学出的混合本来就接近单位阵，损失有限

      社区实验实测 mHC 学出的单层混合矩阵对角约 0.96、非对角约 0.01（Qwen3 系列实验观测）——混合本来就接近单位阵；深度 10 层以上的累积乘积更是已坍缩为全 0.25 的均匀矩阵。直接把混合钉死在单位阵，丢掉的是本来就快消失的自由度。该结论为社区实验，不是官方论文结果。

    2. 如果不钉死，双随机矩阵连乘会发生什么？

      解答：行间距离几何衰减，深层坍缩到均匀矩阵

      元素有正下界 $\delta$ 的双随机矩阵（Sinkhorn 输出通常如此）连乘时，Dobrushin 遍历系数以不超过 $1-n\delta$ 的比率逐层衰减，行趋于一致，极限是均匀矩阵——$n$ 条流在深层被完全混匀。本页构造实验（随机正矩阵、20 步 Sinkhorn、连乘 12 层）中，行到均匀向量的距离从层 0 的 0.7500 经 0.1481、0.0319 几何衰减，层 6 起在 4 位小数下为 0。边界：纯置换或可约序列不满足一致正性、不坍缩。

    3. identity 还买到什么？

      解答：流语义一致、误差源与工程负担消失

      流语义一致性：流 $i$ 恒在位置 $i$，读写门无需追踪流的重排，$I^L=I$ 不坍缩。开销消失：Sinkhorn 的近似误差（该文实测条件下 20 步后行和标准差 0.12 量级）与混合矩阵投影、乘法、专用 kernel 的负担一并消失。社区实验排序 Identity HC > mHC > mHC lite > mHC orthogonal（Qwen3 1.7B/8B、150B tokens、从头训练）。

    5. Hy4 里的 iHC：配置、权重与代价

    5.1 配置与架构位置

    Hy4-preview 是腾讯混元 2026-08-28 开源的 770B MoE 模型（49B 激活、78 层、1M 上下文）[N7]。注意力用带门控的稀疏注意力（Gated DSA，见DSA）；FFN 是 256 路由专家 top-8 加 1 共享专家的 MoE（见DeepSeek MoE），第 1 层为 dense；另有一个用于投机解码的 MTP 层（见投机解码）。iHC 是这个架构里的残差通路，贯穿全部 78 层：

    config.json 里与 iHC 相关的取值[C10, N1]：

    checkpoint 实测（model.safetensors.index.json 与 shard 头）：每个站点一组 hc_pre 的三个张量，全局一个 hc_head，全部 float32[C11, N3]：

    张量形状dtype数量
    hc_pre.hc_fn$[8, 24576]$（$2n\times nd$）float32156
    hc_pre.hc_scale$[2]$float32156
    hc_pre.hc_base$[8]$float32156
    hc_head.hc_head_fn$[4, 24576]$（$n\times nd$）float321
    hc_head.hc_head_scale$[1]$float321
    hc_head.hc_head_base$[4]$float321

    共 $156\times 3+3=471$ 个张量。参数量可以从迷你例子外推：迷你站点（$n=4$、$d=2$）是 $8\times 8+2+8=74$；Hy4 站点把 $nd$ 从 8 换成 $4\times 6144=24576$，即 $8\times 24576+2+8=196{,}618$。全模型 156 个站点加 head（$4\times 24576+1+4=98{,}309$）：

    $$30{,}770{,}717=156\times 196{,}618+98{,}309$$

    占 770B 主干的约 0.004%[C12, N2]——读写门是整个残差通路唯一的可学习参数，量级不到主干的万分之一。

    MTP 草稿层不用 iHC：checkpoint 的 27 个 model.mtp_layers.* 张量里没有任何 hc 张量（结构为 eh_proj、hnorm、enorm 加单流 layer norm）[C13]。

    代价不在参数，在激活显存：残差状态从 1 份变 4 份（$[t, 4, 6144]$），每个 token 的残差激活是标准残差的 4 倍；子层 FLOPs 不变——每个子块仍只对合并后的单份输入计算一次。门控计算在 float32 中进行[C9]。

    补充：HPC 融合 kernel（工程扩展）

    eager 路径的 pre、post、head 分别发出 20、5、15 个 kernel；HPC 实现各融合为 1 个。启用条件：VLLM_ENABLE_HPC_OPS=1、sm100/sm103 架构、hc_mult=4、hidden_size 属于 {4096, 6144}[C19, N6]。跨层 post+pre 融合（HpcIHCPostPre）在参考实现中存在，vLLM 尚未移植（源码注释留有待办标记）[C20]。

    GLM-5.3-Flash 是另一个把残差流扩到 4 条的已发布模型，走 mHC 路线。逐项对照（GLM 侧事实经超连接页核对）[C21]：

    本章问题

    1. Hy4 实际用了什么配置？

      解答：4 流、6144 维、78 层双站点、幅度 2.0

      4 条流（hc_mult=4）、hidden 6144、78 层每层两个 HC 边界（注意力、MLP/MoE 各一，参数独立，第 1 层 dense FFN 同样有）、写门幅度 2.0（hc_magnitude）、门 $\epsilon_{hc}=10^{-6}$（hc_eps）、RMS $\epsilon_{rms}=10^{-5}$（rms_norm_eps，门控内的 RMS 也用它）。门控权重 float32、在 FP8 检查点中排除在量化外，门计算在 float32 中进行。

    2. iHC 在 checkpoint 里长什么样、参数和代价是多少？

      解答：471 个 float32 张量，30.77M 参数，代价在激活显存

      每站点 hc_fn $[8, 24576]$ 加 hc_scale $[2]$、hc_base $[8]$，共 196,618 参数；全局一个 head（hc_head_fn $[4, 24576]$ 加 scale、base，98,309 参数）。156 站点加 head 合计 30,770,717 参数（约占 770B 的 0.004%）、471 个张量，全部 float32。代价主要在激活显存：残差状态 4 份（$[t, 4, 6144]$）；子层 FLOPs 不变。MTP 草稿层不含 iHC（checkpoint 无对应张量）。

    3. 与 GLM-5.3-Flash 的 mHC 实现比，差异在哪？

      解答：读写门接近，核心分歧是混合矩阵

      读门同形（$\sigma+\epsilon_{hc}$）；写门 GLM 为 $2\sigma$、Hy4 为 $m\sigma+\epsilon_{hc}$（$m=2$）。GLM 的门控投影输出 24 个 logits（含混合矩阵的 16 个），Hy4 只有 8 个；GLM 用 softmax 加 Sinkhorn 20 步维护混合矩阵、末端取无权重均值，Hy4 无混合矩阵、末端门控合并。残差通路参数 35.39M 对 30.77M。两家的核心分歧集中在混合矩阵：一边维护，一边删除。

    辅助解释与类比边界

    • 「读门偏向哪条流，子层看到的输入就更像那条流」——描述读门加权平均的局部性质，只在该语义内成立，不构成对流的内容语义的主张。
    • 「标准残差 / mHC / iHC 三条路线」的对照框架——为对比组织的视角；HC 论文自身的表述是一般形式与 $n=1$ 特例，与该框架不冲突。
    • 「流是状态通道，不是并行计算」——描述 iHC 的数据流事实，不外推到其他多流架构。

    简化条件及其限制

    • 子层用线性映射代替：省略注意力与 MLP 的内部结构；不影响 pre、post、head 三块机制的验证，不能推出子层内部行为。
    • hc_fn 置零：真实初始化为非零小随机矩阵，门会在偏置值附近轻微偏移；置零得到精确的 0.25 与 1.0，突出偏置的决定作用，不能代表真实初始化的方差。
    • 第二幕的门为固定构造值：真实训练后的门逐 token 动态变化；固定值只展示门的瞬时作用，不能推出训练动态。
    • float64 代替 float32：所示数值在两种精度下一致到给出位数；不能据此推断实现里的浮点误差特性。
    • 坍缩实验用随机矩阵：比训练学出的矩阵更「混」，坍缩更快；现象方向与论证一致，衰减速度不可比。
