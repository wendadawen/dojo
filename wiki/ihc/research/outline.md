# outline.md：iHC

## 1. 页面开头

- 开头场景：78 层、770B 参数的主干里，所有信息——任务目标、中间结果、异常信号——都要跨层传递；单条残差流是唯一的通道。上一代解法（超连接/mHC，链接已有页）把通道加宽到 4 条，但给流间加了一个要 Sinkhorn 投影保稳的混合矩阵。Hy4 的残差通路走了另一条路：加宽到 4 条，但流间零混合。
- 简要解释：iHC（identity Hyper-Connections）把混合矩阵固定为单位阵，只保留每个子块入口的读门与出口的写门。
- 核心问题（学习目标，5 问）：iHC 相对 mHC 拿掉了什么、留下了什么；一个子块怎么完整走一遍；读写门从哪来、初始时是什么行为；为什么把混合矩阵钉死在 $I$；Hy4 里的配置与代价。
- 首个示例：入口复制 4 份、初始门控下 4 条流保持相等、行为退回标准残差——用最小情形显示「iHC 从标准残差出发」。
- 过渡：先把 iHC 放回家族里看清它改了哪一刀（→ 第 1 章）。

## 2. 章节设计

### 第 1 章 iHC 拿掉了混合矩阵

- 章节问题①：iHC 相对 mHC 改了哪一处？为什么说这是「最小改动」？
  - 完成答案要点：HC 三映射（读 $\mathbf{A_m}$、混合 $\mathbf{A_r}$、写 $\mathbf{B}$，链接 hyper-connections 页）；mHC 把 $\mathbf{A_r}$ 约束为双随机矩阵；iHC 把 $\mathbf{A_r}$ 固定为 $\mathbf{I}$——旧流原样传递，只保留逐 token 动态读写门。读写门从「流怎么组合」里剥离出来，变成全部可学习自由度。命名注记：README 写 identity，vLLM 注释写 independent，同一机制（范围 C1/C4；材料 F6）。
- 章节问题②：三类残差通路（标准残差 / mHC / iHC）在「旧状态如何跨层传递」上的差别？
  - 完成答案要点：标准残差——恒等直传；mHC——旧状态经双随机矩阵线性混合后传递；iHC——旧状态恒等直传，但每子块读时加权合并、写时全流吸收同一份输出。三者对照表 + 结构图（范围 C3、[已有页]结论；材料：对照表 + 家族结构图 B）。
- 正文要点：三映射回顾（压缩为一段 + 链接）、iHC 定义、对照表。
- 表达材料：家族对照结构图（HTML 结构 B 层级或三栏对比，标注读/混合/写三个位置各是什么）；对照表（标准残差 vs mHC vs iHC：读、旧状态传递、写、额外约束）。
- 前置知识：hyper-connections（链接，取三映射与双随机结论）、residual-connection（链接，取恒等映射结论）。

### 第 2 章 一个子块的完整路径

- 章节问题①：4 条流怎么进子层、怎么出来？
  - 完成答案要点：入口 embedding 复制 4 份；每子块四步：pre 读门合并（顺手算出写门）→ RMSNorm → 子层计算一次 → post 写门回加（每条流加同一份输出的不同倍数）。78 层后 head 门控合并 → final RMSNorm → lm_head。残差内嵌于流，无独立张量（范围 C2/C5/C6/C7；材料：数据流结构图 A + 贯穿示例）。
- 章节问题②：贯穿示例（初始化状态）走两步会发生什么？
  - 完成答案要点：4 条流初始相等 + 读门等权 0.25 + 写门 1.0 → 合并输出 ≈ 原值，写回后 4 条流仍相等；第二个子块同理。初始状态的 iHC 精确退化为标准 Pre-Norm 残差；分化要等门被训练后才出现（范围 C8/F4/F5；材料：手算数值）。
- 正文要点：四步数据流、结构图、示例第一轮手算（正文给关键数，完整逐步放折叠块）。
- 表达材料：子块数据流图（HTML 结构 A 顺序流程：4 流 → pre 合并 → norm → 子层 → post 写回 4 流）；迷你示例数值表。
- 前置知识：rmsnorm（链接）。

### 第 3 章 读写门从哪来、从哪里出发

- 章节问题①：门怎么从 4 条流的内容算出来？
  - 完成答案要点：展平成 $nd$ 维 → 整体 RMS → $[2n, nd]$ 线性投影出 $2n$ 个 logits → 乘 RMS 因子 → 读门 $\sigma(\cdot)+\varepsilon$、写门 $m\sigma(\cdot)+\varepsilon$。门是逐 token 的（同一个 batch 里不同 token 门不同）。RMS 归一化在这里的作用：让投影输出落在可控量级（范围 F1；材料：公式分步 + 手算）。
- 章节问题②：初始化为什么能把起点放在「标准残差」上？
  - 完成答案要点：$s=0.01$ 把 logits 压到近零 → 门 ≈ $\sigma(b)$；$b_{[:n]}=-\ln(n-1)$ 使 $\sigma(-\ln 3)=1/4$ 等权读，$b_{[n:]}=0$ 使 $2\sigma(0)=1$ 满幅写。训练从「等价于标准残差」出发，只学门的偏移（范围 C8/F4/F5；材料：推导）。
- 章节问题③：训练后的门会做什么？
  - 完成答案要点：贯穿示例第二幕（分化门）：读门偏向某几条流、写门对不同流强度不同，4 条流逐渐承担不同内容；权重 float32、不参与 FP8 量化（范围 F1/C9；材料：示例数值续）。
- 正文要点：F1 公式逐步讲解、初始化推导、示例第二幕。
- 表达材料：门控计算分步图或公式块；数值表（初始化门 vs 分化门对比）。
- 前置知识：rmsnorm（已在第 2 章链接）、sigmoid（页内一句话自包含）。

### 第 4 章 把混合矩阵钉死在 I 的理由

- 章节问题①：去掉流间混合，证据说损失了什么？
  - 完成答案要点：mHC 实测学出的单层混合矩阵对角 ≈0.96、非对角 ≈0.01——混合本来就没学到多少（标注社区实验条件）（范围 C14）。
- 章节问题②：如果不钉死，双随机矩阵连乘会发生什么？
  - 完成答案要点：正的双随机矩阵满足一致正性时，Dobrushin 遍历系数几何衰减，深层乘积趋于均匀矩阵 $\tfrac{1}{n}\mathbf{11}^{\intercal}$——4 条流在深层被完全混匀，多流失去意义；本页构造实验复现（随机 Sinkhorn 输出连乘 12 层，各行逼近均匀向量）。边界：纯置换矩阵序列不满足一致正性、不坍缩，但 Sinkhorn 输出通常严格正（范围 C15；材料：构造实验代码块 + 实跑输出）。
- 章节问题③：identity 还买到什么？
  - 完成答案要点：流语义一致性——流 $i$ 永远在位置 $i$，读写门无需追踪流被哪层重排到哪，$I^L=I$ 不坍缩；Sinkhorn 的近似误差（行和标准差 0.12 量级）与专用 kernel 负担一并消失。实验排序 Identity HC > mHC > mHC lite > mHC orthogonal（Qwen3 1.7B/8B、150B tokens、from scratch，社区实验）（范围 C16/C17/C18；材料：论证 + 折叠实验条件）。
- 正文要点：三条论证主干 + 边界（iHC 无正式论文，社区研究 + 实现注释；引用带条件）。
- 表达材料：构造实验代码块（numpy，实跑，输出展示行向量收敛到均匀）；对照表（Sinkhorn 路线 vs identity 路线：累积乘积、近似误差、额外计算、参数）。
- 前置知识：hyper-connections（Sinkhorn 结论复用）。

### 第 5 章 Hy4 里的 iHC：配置、权重与代价

- 章节问题①：Hy4 实际用了什么配置？
  - 完成答案要点：4 流、hidden 6144、78 层、每层两个边界（注意力、MLP/MoE 各一，参数独立）、幅度 2.0、$\varepsilon=10^{-6}$；门控权重 float32 不量化、门计算在 float32（范围 C9/C10；材料：配置表）。
- 章节问题②：iHC 在 checkpoint 里长什么样、参数和显存代价是多少？
  - 完成答案要点：每站点 hc_fn $[8, 24576]$ + scale $[2]$ + base $[8]$，共 196,618 参数；156 站点 + head 98,309 → 30,770,717（占 770B 约 0.004%）。代价主要是激活显存：残差状态 4 份；子层 FLOPs 不变（每子块仍算一次）。MTP 草稿层不用 iHC（范围 C11/C12/C13；材料：参数量手算 + 张量结构表）。
- 章节问题③：与 GLM-5.3-Flash 的 mHC 实现比，差异在哪？
  - 完成答案要点：逐项对照：读门 σ+ε 相同形式；写门 GLM 2σ、Hy4 $m\sigma+\varepsilon$（m=2）；混合 GLM 用 softmax+Sinkhorn、Hy4 无；末端 GLM 无权重均值、Hy4 门控合并。两家的读门写门形式接近，核心分歧就是混合矩阵（范围 [已有页] C11/F8 对照 [vLLM]；材料：对照表）。
- 正文要点：配置表、参数量手算（从迷你例子外推）、对照表、Hy4 架构定位一句话（DSA/MoE/MTP 链接）、折叠：HPC kernel（C19/C20 扩展）。
- 表达材料：张量结构表；参数量计算式；Hy4 主干示意（4 流贯穿 78 层 + 两个站点标注 + head，链接 dsa/speculative-decoding）。
- 前置知识：dsa（链接，一句话）、speculative-decoding（链接，MTP 一句话）、deepseek-moe（链接，MoE 一句话）。

## 4. 贯穿示例

一个 4 流、$d=2$ 的迷你模型，两个子块（第一个标注「注意力位置」、第二个「MLP 位置」，子层本身用简单线性映射代替——子层内部不是本页主题），末端一个 head。

- 第一幕（第 2 章，初始化状态）：入口 4 条流相等；读门 $[0.25, 0.25, 0.25, 0.25]$、写门 $[1, 1, 1, 1]$；过两个子块，4 条流始终保持相等——数值上退化为标准 Pre-Norm 残差。教学目标：初始行为 + 数据流走通。
- 第二幕（第 3 章，训练后的门）：给一组分化门（读门偏科、写门强弱不一，数值在 $m\sigma+\varepsilon$ 值域内）；从「已轻微分化的流」出发过一个子块，流间差异放大。教学目标：门的作用。
- 第三幕（第 5 章，参数量外推）：迷你站点参数 $8\times 8+2+8=74$，对照 Hy4 的 $8\times 24576+2+8=196{,}618$。教学目标：规格与量级。

所有数值在写作阶段先跑脚本生成（含 sigmoid 精确值），页面上出现的每个数都来自脚本 stdout。构造标记：示例为构造示例（权重与门值为教学构造，非 Hy4 checkpoint 数值）。
