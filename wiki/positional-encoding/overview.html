位置编码基础

给本身不含位置信息的 Transformer 自注意力补充位置信号的一类方法，使模型能区分 token 的先后顺序与相对距离。

更新于 2026-08-09

1. 为什么需要它

Transformer 的自注意力把所有位置同时拉到一起、只按内容匹配，丢掉了顺序——它对输入 token 的行重排不变（排列等变）。"我打你"和"你打我"的 token 完全相同、顺序不同，在没有位置信息时模型无法区分。RNN 靠逐步处理天然带顺序、CNN 靠局部窗口隐含位置，自注意力是唯一必须外接位置信号的架构。位置编码就是把这个外接信号注入模型的方法。自注意力的完整机制见 标准 Transformer 注意力。

2. 核心直觉

  • 四类方案按"位置信号加在哪里"区分：绝对方案加在输入嵌入上、相对方案加在注意力分数上、RoPE 乘在 query/key 上、NoPE 什么都不做。
  • 绝对正弦用多频率 sin/cos 给每个位置一个唯一"指纹"：高频维度振荡快、编码局部位置；低频维度振荡慢、编码全局位置。像二进制计数器——低位每步翻转、高位很少翻转，组合起来唯一标识每个位置。无需学习参数。
  • 可学习绝对把固定公式换成参数表：每个位置一个可学习向量，训练长度内表现与正弦相近，但超出最大长度即失败。BERT、GPT-2 采用。
  • 相对方案编码"相差几位"而非"第几位"：T5 在注意力分数上加一个与相对距离绑定的偏置，每个注意力层、每个头都直接注入位置信号，模型对位置更敏感。
  • RoPE 是"绝对构造、相对效果"：用绝对位置旋转 Q/K，但内积只依赖相对位置，无可学习参数（详见 RoPE）。

3. 关键结论与边界

  • 正弦位置编码是绝对方案，不是相对方案。它有"PE(pos+k) 是 PE(pos) 的线性函数"这一性质使模型可能学到相对位置，但向量仍与绝对位置绑定、加在嵌入上。成立条件：d_model 为偶数。
  • Vaswani 2017 的 base 和 big 模型都用正弦。可学习只是 Table 3 row (e) 的实验对比项，两者"nearly identical"，论文最终选正弦因可能允许外推。成立条件：Vaswani 2017 论文范围内。
  • 相对 bias 与 FlashAttention 不兼容。它需要物化 n×n 偏置矩阵，Flash 的分块 IO 优化失效。这是后来 RoPE 被广泛采用的原因之一。成立条件：使用 FlashAttention 加速时。
  • NoPE 依赖因果掩码，仅适用 decoder-only。不施加显式位置编码，但因果掩码让每个位置只能看到之前的 token，隐式提供位置信息。双向编码器不适用。K3 的 MLA 层选 NoPE 是因 RoPE 与矩阵吸收冲突（详见 Kimi K3、NoPE）。
