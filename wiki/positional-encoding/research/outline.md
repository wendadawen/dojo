# 位置编码基础 · 教学大纲

## 1. 页面开头

**钩子问题**：把"我打你"和"你打我"这两句话喂给一个完全没有位置编码的 Transformer——模型能分清谁打谁吗？答案是：不能。两句话的 token 完全相同，只是顺序不同；而自注意力只看内容匹配、不看顺序，交换 token 顺序后每个位置的输出值不变。要让模型分清"谁在前谁在后"，必须把位置信息注入进去。

**一句话解释**：位置编码是给不含位置信息的 Transformer 自注意力补充位置信号的一类方法。

**要解决的具体问题**：自注意力对输入行重排不变（排列等变），模型无法区分 token 顺序；位置编码通过加位置向量、加分数偏置或乘位置旋转把位置信号注入模型。

**学习承诺**：读完这一页，你应该能够——说明注意力为什么不含位置信息；写出绝对正弦位置编码公式并手算 d=4 的例子；说明可学习绝对方案与正弦方案的权衡；说明 T5 相对 bias 的机制与绝对方案的本质区别；用一张表对比四类方案与 NoPE 并解释 K3 为什么选 NoPE。

**首个具体场景**：d=4 的正弦位置编码手算——pos=1 和 pos=2 的 PE 向量，验证高频维度变化快、低频维度变化慢。

**与第一章的过渡**：先看清楚"为什么需要"，再看"怎么注入"。

**前置知识引用**：本文依赖两个已有概念页——自注意力的完整机制见 [`标准 Transformer 注意力`](../standard-attention/index.html)，排列等变性的形式化讨论见 [`NoPE`](../nope/index.html)。RoPE 与 NoPE 的深度机制分别见 [`RoPE`](../rope/index.html) 与 [`NoPE`](../nope/index.html)，本页只做对比引用。

## 2. 章节设计

### S1：为什么 Transformer 需要位置编码——注意力的排列等变性

- **主要教学问题**：注意力本身为什么不含位置信息？
- **对应范围**：Q1（C1）
- **正文要点**：
  - 自注意力做的事是"用 query 和 key 做匹配，按匹配程度对 value 加权求和"，只看内容像不像、不看位置（引用 standard-attention）。
  - 排列等变：交换输入顺序后，每个位置仍看到同样一组 token、同样内容匹配、同样权重——输出跟着挪位置但值不变（引用 nope 对排列等变的论证）。
  - 因此"我打你"和"你打我"在无位置信息时不可区分。
  - 位置编码的职责：把位置信号注入模型，让注意力具备顺序感知。
- **讲解材料及职责**：
  - 一个具体场景（我打你 vs 你打我）：展示排列等变带来的语义丢失。
  - 对照表（RNN/CNN/自注意力的位置感知来源）：说明自注意力是唯一需要外接位置信号的。
- **前置知识安排**：引用 standard-attention（注意力公式）、nope（排列等变）。
- **完成检查**：用一句话说出注意力为什么不含位置信息；说出排列等变的含义。
- **过渡**：知道了"为什么需要"，下一章看 Vaswani 2017 给出的第一种注入方式——正弦位置编码。

### S2：绝对正弦位置编码——Vaswani 2017 的 sin/cos 公式与手算

- **主要教学问题**：第一种位置编码长什么样，怎么生成？
- **对应范围**：Q2（C2, C3, C4；F1, F2, F3；N2, N3）
- **正文要点**：
  - 注入方式：位置 pos 的 PE 向量加到 token 嵌入上（F2）。
  - 公式 F1：偶数维 sin、奇数维 cos，频率 $\omega_i=1/10000^{2i/d_{model}}$ 随 i 几何递减。
  - 符号解释：pos（位置）、i（维度对索引）、d_model（嵌入维度，原文 512）、10000（base 常数）。
  - 多频率含义（C3）：i 小频率大（波长 $2\pi$，变化快，编码局部位置）；i 大频率小（波长 $10000\cdot 2\pi$，变化慢，编码全局位置）；多尺度同时编码。
  - 手算例子（教学示例）：d=4，pos=1、2、3 的 PE 向量，验证高频维（dim 0,1）变化快、低频维（dim 2,3）变化慢。
  - 线性性质（C4，F3）：$PE(pos+k)$ 是 $PE(pos)$ 的线性函数（旋转），使模型能从绝对编码读出相对位置——这是 RoPE 旋转思想的伏笔。
- **讲解材料及职责**：
  - 公式 F1、F2：表达位置向量怎么生成、怎么注入。
  - 数字例子（d=4 手算）：展示多频率在同一位置上的不同变化速率。
  - 线性性质推导（折叠块）：证明 $PE(pos+k)$ 是 $PE(pos)$ 的旋转，用和角公式。
  - 对照表（d=4 的 pos=1/2/3 PE 向量）：直观展示高频 vs 低频。
  - 教学解释（二进制计数器类比）：把多频率类比成二进制各位翻转速率不同；说明失效边界。
- **前置知识安排**：正弦余弦、几何级数（高中数学）。
- **完成检查**：写出 F1 并解释每个符号；手算 d=4、pos=1 的 PE 向量；说出 i 小 vs i 大的频率差异。
- **过渡**：正弦方案用固定公式生成位置向量。如果把固定公式换成可学习参数会怎样？下一章看可学习绝对方案。

### S3：可学习绝对位置编码——把固定向量换成可学习参数

- **主要教学问题**：可学习方案和正弦方案的差别与权衡？
- **对应范围**：Q3（C5, C6；F5；N1）
- **正文要点**：
  - 形式 F5：用 $L\times d_{model}$ 的可学习参数表代替固定 sin/cos，每个位置一个可学习向量，注入方式仍是加到嵌入上。
  - 对比结论（C5，N1）：Vaswani 2017 Table 3 row (e) 报告 learned 与 sinusoidal 训练长度内表现相近（learned base 26.74 / sinusoidal base 27.3，"nearly identical"）；base 和 big 都用正弦，可学习是实验项。
  - 外推限制（C6）：超出最大长度 L 即无对应参数、外推失败；正弦理论上可外推（公式对任意 pos 成立）但经验上也退化。
  - 采用情况：BERT、GPT-2 用可学习。
  - 权衡小结：可学习换来了"数据驱动"但失去外推能力，参数量增加 $L\cdot d_{model}$。
- **讲解材料及职责**：
  - 公式 F5：表达可学习参数表形式。
  - 对照表（正弦 vs 可学习）：参数量、外推、采用情况、训练长度内表现。
  - 数字 N1：Table 3 row (e) 的 BLEU 对比。
- **前置知识安排**：S2 的正弦方案。
- **完成检查**：说出可学习方案的参数表形式；说出 Vaswani 报告的两者关系（相近，正弦略优）；说出可学习的外推限制。
- **过渡**：绝对方案（正弦与可学习）都加在输入嵌入上、编码"第几位"。但语言理解常更依赖"相差几位"——下一章看相对方案。

### S4：相对位置编码——T5 的 bias 机制与"加在分数上"的本质区别

- **主要教学问题**：相对位置编码怎么工作，和绝对方案本质不同在哪？
- **对应范围**：Q4（C7, C8；F4）
- **正文要点**：
  - 动机：语言理解更依赖相对距离（"cat 在 sat 前面 1 位"是主谓关系）而非绝对位置（"cat 是第 2 位"）。
  - T5 bias 机制（C7，F4）：在注意力分数 softmax 之前加一个与相对距离 $i-j$ 绑定的标量偏置 $b_{\text{bucket}(i-j)}$；分桶（bucketing）把连续距离映射到有限桶（约 32 桶），每桶一个可学习标量；每个注意力头独立、各层共享一套；超出训练最大距离 clamp 到最大桶。
  - 本质区别（C8）：绝对方案编码"第几位"、加在嵌入上；相对方案编码"相差几位"、加在分数上。作用点与编码对象都不同。
  - 与绝对方案的对比：相对方案不需要为每个绝对位置建向量，参数量与桶数（非序列长度）成正比；对长度外推更友好（clamp）。
  - ALiBi 方向性提及：另一种相对方案，用与距离成正比的线性负偏置（不展开）。
- **讲解材料及职责**：
  - 公式 F4：表达 bias 加在分数上。
  - 图示（绝对 vs 相对作用点对比）：展示一个加在嵌入、一个加在分数。
  - 对照表（绝对方案 vs 相对方案）：作用点、编码对象、参数量、外推。
- **前置知识安排**：S2、S3 的绝对方案，standard-attention 的注意力分数公式。
- **完成检查**：说出 T5 bias 加在哪里、与相对距离怎么绑定；说出绝对 vs 相对的本质区别（编码对象与作用点）。
- **过渡**：四类方案（绝对正弦、可学习绝对、相对 bias、RoPE）各自机制已清楚。最后一章把它们放一张表对比，并看 K3 为什么选 NoPE。

### S5：四类方案对比与 NoPE 选择——为什么 K3 选 NoPE

- **主要教学问题**：四类方案与 NoPE 的核心权衡是什么，K3 为什么选 NoPE？
- **对应范围**：Q5（C9, C10）
- **正文要点**：
  - 四类方案 + NoPE 对比表（四维：加在哪里、是否有可学习参数、长度外推、与推理优化兼容性）：
    - 绝对正弦：加在嵌入、无参数、理论可外推经验退化、兼容。
    - 可学习绝对：加在嵌入、有参数（$L\times d$）、外推失败、兼容。
    - 相对 bias（T5）：加在分数、有参数（桶数×头）、clamp 外推、与 FlashAttention 不兼容（需物化 $n\times n$）。
    - RoPE：乘在 Q/K、无参数、需 YaRN/PI 扩展、与 MLA 矩阵吸收冲突（详见 wiki/rope、wiki/mla）。
    - NoPE：什么都不做、无参数、decoder-only 直接外推、依赖因果掩码（详见 wiki/nope）。
  - RoPE 的"绝对构造、相对效果"（C9）：用绝对位置构造旋转但内积只依赖相对位置，引用 wiki/rope。
  - K3 选 NoPE 的依据（C10）：K3 的 MLA 层保留 RoPE 接口但 mla_use_nope=true，因 RoPE 与矩阵吸收冲突；位置信息由 KDA 隐式提供，MLA 直接外推到 1M token 无需修改位置编码参数（引用 wiki/kimi-k3、wiki/nope）。
  - 选择位置方案的判断框架：看模型架构（decoder-only / encoder-decoder / 双向）、推理优化约束（FlashAttention / MLA 矩阵吸收）、外推需求。
- **讲解材料及职责**：
  - 对照表（四类 + NoPE 五行四维）：总收束对比。
  - 引用已有页面（rope、nope、kimi-k3、mla）：不内联展开。
- **前置知识安排**：S1–S4，引用 rope、nope、kimi-k3、mla。
- **完成检查**：用一张表对比四类方案与 NoPE 的四维权衡；说出 K3 选 NoPE 的依据（RoPE 与矩阵吸收冲突）。
- **过渡**：文末来源与教学说明。

## 3. 讲解顺序

先讲为什么需要（S1 排列等变），再讲第一类注入方式（S2 正弦）；从最小必要前置（sin/cos、几何级数）开始，一次只引入一个新变量（pos → i → d_model → base → 频率 → 多尺度）。S3 引入"可学习"这一个新变量。S4 把作用点从"嵌入"换到"分数"，引入"相对距离"这一个新变量。S5 收束对比，不引入新机制。
