# 位置编码基础 · 内容范围

## 1. 概念歧义处理

**状态：已裁定。**

"位置编码"在不同来源中可能指三种略有重叠的对象：

1. **注入位置信息的一般概念**：给不含位置感知的注意力补充位置信息的任何方法。本页采用此含义。
2. **绝对位置嵌入（absolute position embedding）**：特指给 token 嵌入加一个与绝对位置绑定的向量（含正弦与可学习两种）。属本页四类方案中的第一、二类。
3. **正弦位置编码**：特指 Vaswani et al. 2017 §3.5 给出的 sin/cos 公式。属本页四类方案中的第一类，常被直接称为"位置编码"。

本页讲含义 1（一般概念），含义 2、3 作为四类方案中的两类纳入讲解。RoPE（旋转位置编码）与 NoPE 各有独立概念页，本页只做对比与引用，不内联展开它们的完整机制。

## 2.1 概念含义

- **名称**：位置编码（Positional Encoding / Positional Embedding）
- **英文 / 缩写**：Positional Encoding, PE；绝对正弦位置编码 Sinusoidal Positional Encoding；可学习绝对位置编码 Learned Absolute Positional Embedding；相对位置编码 Relative Positional Encoding；旋转位置编码 Rotary Position Embedding, RoPE；无位置编码 NoPE
- **一句话定义**：位置编码是给不含位置信息的 Transformer 自注意力补充位置信号的一类方法，使模型能区分 token 的先后顺序与相对距离。
- **正式定义**（与权威来源一致）：Transformer 的自注意力对输入序列行重排不变（permutation-invariant），位置编码通过在 token 嵌入上加位置向量（绝对方案）、或在注意力分数上加位置偏置（相对方案）、或在 query/key 上乘位置旋转（RoPE 方案）将位置信息注入模型（Vaswani et al. 2017 §3.5；Raffel et al. 2019 §3.2；Su et al. 2021 §3.1）。
- **本文采用的语境**：标准 softmax 注意力下位置信号的注入方式；四类方案并列对比。

### 包括什么

- **为什么需要位置编码**：自注意力的排列等变性，交换 token 顺序后每个位置输出值不变。这是所有方案共同要解决的问题。
- **绝对正弦位置编码**：Vaswani 2017 §3.5 的 sin/cos 公式，含符号定义、多频率选择与手算例子。
- **可学习绝对位置编码**：把固定 sin/cos 向量换成可学习参数，对比权衡。
- **相对位置编码（T5 bias）**：在注意力分数上加与相对距离绑定的偏置，T5 的分桶 bias 机制。
- **RoPE 与 NoPE 的引用对比**：一句话说明机制并引用对应概念页，纳入四类对比表。
- **四类方案的核心权衡**：加在哪里、是否有参数、长度外推能力、与推理优化的兼容性。
- **K3 选 NoPE 的依据**：引用 wiki/nope 与 wiki/kimi-k3。

### 不包括什么

- **RoPE 的完整推导**：已有概念页 [`RoPE`](../rope/index.html)，本页只在对比表和动机章引用，不重复旋转矩阵推导。
- **NoPE 的完整论证**：已有概念页 [`NoPE`](../nope/index.html)，本页只引用"因果掩码隐式提供位置"的结论。
- **ALiBi 的完整机制**：属相邻相对位置编码方案，本页只在对比表列出方向，不展开线性衰减斜率推导。
- **YaRN / Position Interpolation 等长度外推扩展**：是 RoPE 之上的独立工作，本页只在外推边界一句话提及。
- **位置编码的实现细节（查表、逐元素乘法）**：工程实现，不影响机制理解。
- **训练动力学 / 消融实验**：经验分析不属本概念范围。

### 相邻概念

- **自注意力**：位置编码的注入对象。已有概念页 [`标准 Transformer 注意力`](../standard-attention/index.html)，本页引用其排列等变性结论。
- **RoPE**：四类方案之一，已有概念页 [`RoPE`](../rope/index.html)。区别：RoPE 是"乘旋转"，本页讲一般概念与其余三类。
- **NoPE**：四类方案之外的第五种选择"什么都不做"，已有概念页 [`NoPE`](../nope/index.html)。本页引用其结论。
- **ALiBi**：相对位置编码的另一种实现，不纳入本页展开，只在对比表列方向。

## 2.2 学习目标

### Q1：为什么 Transformer 需要位置编码？注意力本身的什么性质导致位置信息缺失？

- **完成答案**：读者应能说明自注意力对输入序列行重排不变——交换 token 顺序后每个位置看到同样一组 token、按同样内容匹配得到同样权重，输出只跟着挪位置而值不变（排列等变）；因此模型无法区分"甲在前、乙在后"与"乙在前、甲在后"，必须由位置编码补充位置信号。
- **为什么是核心目标**：不理解"为什么需要"就无法判断四类方案各自在解决什么、它们的共同前提是什么。
- **依赖内容**：自注意力公式、排列等变性。

### Q2：绝对正弦位置编码的公式是什么，每个符号的含义，为什么用不同频率的 sin/cos？

- **完成答案**：读者应能写出 $PE_{(pos,2i)}=\sin(pos/10000^{2i/d_{model}})$ 与 $PE_{(pos,2i+1)}=\cos(pos/10000^{2i/d_{model}})$，解释 pos、i、d_model、10000 各是什么；说明相邻维度对共用一个频率、i 小频率大（变化快、编码局部位置）、i 大频率小（变化慢、编码全局位置）；并手算 d=4、pos=1、2 的 PE 向量验证多频率。
- **为什么是核心目标**：这是 Vaswani 2017 的原始方案，是理解"位置向量怎么生成"的最直接例子，也是后续可学习方案与相对方案的对比基准。
- **依赖内容**：正弦余弦函数、几何级数、加到 embedding 的注入方式。

### Q3：可学习绝对位置编码与正弦位置编码的区别与权衡是什么？

- **完成答案**：读者应能说明可学习方案把固定 sin/cos 向量换成一个 $L\times d_{model}$ 的可学习参数表（$L$ 为最大序列长度），每个位置一个可学习向量；权衡：在训练长度内表现与正弦相近（Vaswani 2017 Table 3 row (e)），但超出 $L$ 即失败（无法外推），且增加参数量；BERT、GPT-2 采用可学习方案。
- **为什么是核心目标**：这是从"固定公式"到"可学习参数"的演进，理解它才能理解为什么后续转向相对与旋转方案。
- **依赖内容**：正弦方案、最大序列长度限制、参数量。

### Q4：相对位置编码（T5 bias）的机制是什么，与绝对位置编码的本质区别是什么？

- **完成答案**：读者应能说明 T5 不在输入嵌入上加位置向量，而是在注意力分数 softmax 之前加一个与 query-key 相对距离 $i-j$ 绑定的标量偏置 $b_{i-j}$（分桶后每桶一个可学习标量，每个头独立、各层共享）；本质区别：绝对方案编码"第几位"，相对方案编码"相差几位"，相对方案作用在注意力分数而非输入嵌入。
- **为什么是核心目标**：相对位置编码是现代 LLM 位置方案的重要一支，理解它才能理解 RoPE"绝对构造、相对效果"的设计动机。
- **依赖内容**：注意力分数公式、softmax、绝对方案的作用点。

### Q5：四类方案与 NoPE 的核心权衡是什么，K3 为什么选 NoPE？

- **完成答案**：读者应能用一张表对比四类方案（绝对正弦、可学习绝对、相对 bias、RoPE）与 NoPE 在"加在哪里、是否有可学习参数、长度外推、与推理优化兼容性"四维上的差异；并说明 K3 的 MLA 层选 NoPE 是因为 RoPE 与矩阵吸收冲突，NoPE 依赖因果掩码隐式提供位置、无需修改位置编码参数即可外推（引用 wiki/nope、wiki/kimi-k3）。
- **为什么是核心目标**：这是本页的总收束，把四类方案与一个实际工程选择联系起来，让读者能判断任何 transformer 位置方案。
- **依赖内容**：四类方案机制、NoPE 结论、K3 MLA 与矩阵吸收（引用）。

## 2.6 常见误解和适用边界

### 常见误解

| 误解 | 正确结论 | 形成原因 | 影响目标 |
|---|---|---|---|
| "Vaswani 2017 的 big 模型用了可学习位置编码" | base 和 big 模型都用正弦位置编码；可学习只是 Table 3 row (e) 的实验对比项，两者结果相近，论文最终选正弦。 | 以讹传讹，把"实验过可学习"扩大为"big 用可学习"。 | Q3 |
| "正弦位置编码是相对位置编码" | 正弦方案是绝对位置编码（向量与绝对位置 pos 绑定，加在输入嵌入上）。它具有"PE(pos+k) 是 PE(pos) 的线性函数"这一性质，使模型有可能学到相对位置，但这不改变它属于绝对方案的事实。 | 混淆"蕴含相对信息"与"是相对位置编码"。 | Q2, Q4 |
| "可学习位置编码比正弦好" | Vaswani 2017 Table 3 row (e) 报告两者训练长度内表现相近（正弦略优）；可学习超出最大长度即失败。 | BERT/GPT-2 用可学习，被推断为"更好"。 | Q3 |
| "相对位置编码加在输入嵌入上" | T5 相对 bias 加在注意力分数 softmax 之前，不是加在输入嵌入上。绝对方案才加在嵌入上。 | 混淆两类方案的作用点。 | Q4 |
| "RoPE 是相对位置编码的一种" | RoPE 用绝对位置构造旋转，但内积只依赖相对位置，叫"绝对构造、相对效果"更准确。详见 wiki/rope。 | 名字带"相对"的直觉。 | Q5 |
| "NoPE 完全没有位置信息" | NoPE 不施加显式位置编码，但 decoder-only 的因果掩码隐式提供位置信息。详见 wiki/nope。 | 字面理解"No"。 | Q5 |

### 适用边界

- **位置编码解决什么**：让排列等变的注意力获得位置感知。
- **不解决什么**：不解决位置编号的语义（如分段文档、相对时间）；不替代 token 类型嵌入（如 segment embedding）。
- **绝对方案的外推边界**：正弦理论上可外推（公式对任意 pos 成立），但经验上超出训练长度性能下降；可学习超出 $L$ 即失败。
- **相对方案的外推边界**：T5 bias 对超出训练最大距离的相对距离做截断（clamp 到最大桶），可一定程度外推但引入误差。
- **RoPE 的外推边界**：超出训练长度需 YaRN/PI 等扩展（详见 wiki/rope）。
- **NoPE 的适用边界**：依赖因果掩码，仅适用于 decoder-only 自回归模型；双向编码器不适用（详见 wiki/nope）。
