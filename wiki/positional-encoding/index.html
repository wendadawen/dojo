    位置编码基础：给不含位置信息的注意力补充位置信号的四类方案

    主要依据：Vaswani et al. 2017, "Attention Is All You Need", NeurIPS 2017, arXiv:1706.03762, §3.5 位置编码（Eq.(3)(4) 正弦公式、Table 3 row (e) learned 对比）；Raffel et al. 2019, "Exploring the Limits of Transfer Learning with a Unified Text-to-Text Transformer", JMLR, §3.2 相对位置偏置。RoPE 与 NoPE 的完整机制分别见已有概念页。

    把"我打你"和"你打我"这两句话喂给一个完全没有位置编码的 Transformer——模型能分清谁打谁吗？答案是：不能。两句话的 token 完全相同，只是顺序不同；而自注意力只看内容匹配、不看顺序，交换 token 顺序后每个位置的输出值不变。要让模型分清"谁在前谁在后"，必须把位置信息注入进去。位置编码就是干这件事的一类方法：给本身排列等变、不含位置感知的自注意力补充位置信号。按位置信号加在哪里可分成四类——加在输入嵌入上的绝对方案（正弦或可学习）、加在注意力分数上的相对偏置（T5）、乘在 query/key 上的旋转（RoPE），以及完全不施加的 NoPE。本页要回答：这四类方案各自怎么注入位置信号、有什么权衡，以及 Kimi K3 的 MLA 层为什么选 NoPE。

    为什么 Transformer 需要位置编码——注意力的排列等变性

    标准自注意力做的事情是"用 query 和 key 做匹配，按匹配程度对 value 加权求和"（见 标准 Transformer 注意力）。它只关心两个 token 的内容像不像，不关心它们各自在第几位。这引出一个问题：如果模型不知道 token 的位置，它还能区分"我打你"和"你打我"吗？

    要回答它，先看注意力本身的一个性质。如果注意力是双向的（每个位置都能看到所有位置）并且不给任何位置信息，那么交换输入顺序后，每个位置仍然看到同样的一组 token、按同样的内容匹配得到同样的权重——只是输出跟着挪了位置，而每个位置上的输出值不变。这种现象叫排列等变（permutation-equivariant）[C1]：模型对"谁先谁后"没有真正的区分能力。排列等变的更完整讨论见 NoPE 页面，本文只用这个结论。

    正因如此，"我打你"和"你打我"在无位置信息时不可区分：两个句子的 token 集合相同，注意力只按内容匹配，交换顺序后每个位置看到的内容集合不变，输出值也不变。但两句话意思完全相反——位置信息对语义至关重要。

    架构位置感知来源是否需要外接位置信号
    RNN按时间步逐步处理，隐状态天然带顺序不需要
    CNN（kernel $k$）卷积核的局部窗口隐含相对位置部分需要（远距离仍需补充）
    自注意力无——所有位置同时交互，对行重排不变需要

    RNN 靠"逐步处理"天然带顺序，CNN 靠"局部窗口"隐含相对位置，自注意力把所有位置同时拉到一起、丢掉了顺序——所以它是唯一必须外接位置信号的。这个"外接位置信号"就是位置编码（Positional Encoding）：给本身不含位置信息的注意力补充位置信号的一类方法。

    位置编码不是单一方法，而是一类方法。按"位置信号加在哪里、怎么加"可以分成四类：加在输入嵌入上的绝对位置编码（正弦或可学习）、加在注意力分数上的相对位置编码、乘在 query/key 上的旋转位置编码（RoPE），以及完全不施加的 NoPE。下面四章依次讲清前三类的机制与权衡，最后一章总收束对比并解释 NoPE 的选择。

    绝对正弦位置编码——Vaswani 2017 的 sin/cos 公式与手算

    位置编码最直接的做法是：给每个位置 $pos$ 生成一个与位置绑定的向量 $PE_{pos}$，加到那个位置的 token 嵌入上。注入方式是

    $$x'_{pos} = x_{pos} + PE_{pos},\qquad\text{Vaswani 2017 §3.5}$$

    其中 $x_{pos}$ 是位置 $pos$ 的 token 嵌入，$PE_{pos}$ 是位置 $pos$ 的位置向量，两者都是 $d_{model}$ 维。位置信息通过相加注入到嵌入里，之后被 $W^Q$、$W^K$、$W^V$ 投影到注意力使用的子空间。[F2]

    Vaswani et al. 2017 给出的位置向量生成公式是

    $$PE_{(pos,2i)}=\sin\!\left(\frac{pos}{10000^{2i/d_{model}}}\right),\qquad PE_{(pos,2i+1)}=\cos\!\left(\frac{pos}{10000^{2i/d_{model}}}\right).\qquad\text{Vaswani 2017 §3.5, Eq.(3)(4)}$$

    逐个符号解释：

    • $pos$：token 在序列中的位置索引，取 $0, 1, 2, \ldots$。
    • $i$：维度对索引，取 $0, 1, \ldots, d_{model}/2-1$。第 $i$ 对覆盖维度 $2i$（用 sin）与 $2i+1$（用 cos），两个维度共用同一个频率。
    • $d_{model}$：token 嵌入维度，也是位置向量维度；Vaswani 2017 base 模型为 512。
    • $10000$：base 常数，控制频率几何递减的速率；论文取 10000。
    • 偶数维用 sin、奇数维用 cos；同一对 $(2i, 2i+1)$ 共用频率 $\omega_i = 1/10000^{2i/d_{model}}$。

    关键在于频率 $\omega_i$ 随 $i$ 几何递减。把第 $i$ 对的角频率记为 $\omega_i = 1/10000^{2i/d_{model}}$，则 $i$ 每加 1，$\omega_i$ 乘上 $10000^{-2/d_{model}}$。这意味着不同维度对编码不同尺度的位置信息[C3]：

    • $i$ 小（如 $i=0$）：$\omega_i$ 大（$\omega_0 = 1$），波长 $\lambda_i = 2\pi/\omega_i = 2\pi$（约 6 个位置转一圈），sin/cos 随 $pos$ 变化快，编码局部/精细位置。
    • $i$ 大（如 $i=d_{model}/2-1$，$d_{model}=512$ 时 $i=255$）：$\omega_i$ 小（$\omega_{255} \approx 1/10000$），波长 $10000\cdot 2\pi$（约 62832 个位置转一圈），sin/cos 几乎不变，编码全局/粗略位置。

    波长从 $2\pi$ 到 $10000\cdot 2\pi$ 跨越四个数量级[N2]——同一个位置向量同时编码了从"邻近 6 个位置就转完一圈"到"6 万个位置才转完一圈"的多尺度位置信息。这让模型能同时处理短程和长程的位置关系。

    教学解释。 可以把多频率 sin/cos 暂时理解成一个"连续版二进制计数器"：二进制里最低位每步翻转（高频）、最高位很少翻转（低频），组合起来唯一标识每个整数；正弦位置编码里 $i$ 小的维度振荡快（像低位）、$i$ 大的维度振荡慢（像高位），组合起来给每个位置一个唯一的"指纹"。这个类比只帮助理解"为什么多频率能唯一编码位置"。它失效的边界：二进制各位是离散 0/1 跳变，sin/cos 是连续平滑函数；二进制位数固定，这里维度对数由 $d_{model}$ 决定且波长连续分布；二进制有唯一性证明，sin/cos 的唯一性依赖频率不可约。正式判断仍以正弦位置编码公式为准。

    下面用教学示例把公式落到可复算程度。

    教学示例。 取 $d_{model}=4$（让计算可手算；真实模型 $d_{model}=512$）。由 $\omega_i = 1/10000^{2i/4}$：

    $$\omega_0 = 1/10000^{0} = 1,\qquad \omega_1 = 1/10000^{2/4} = 1/10000^{0.5} = 1/100.$$

    所以维度 0,1 用频率 $\omega_0=1$（$pos$ 直接作自变量），维度 2,3 用频率 $\omega_1=0.01$（$pos/100$ 作自变量）。数字为便于手算构造，不代表真实模型配置。

    代入公式计算 $pos=0,1,2,3$ 的 PE 向量：

    $pos$dim 0: $\sin(pos\cdot\omega_0)$dim 1: $\cos(pos\cdot\omega_0)$dim 2: $\sin(pos\cdot\omega_1)$dim 3: $\cos(pos\cdot\omega_1)$
    0$\sin 0 = 0$$\cos 0 = 1$$\sin 0 = 0$$\cos 0 = 1$
    1$\sin 1 \approx 0.8415$$\cos 1 \approx 0.5403$$\sin 0.01 \approx 0.0100$$\cos 0.01 \approx 1.0000$
    2$\sin 2 \approx 0.9093$$\cos 2 \approx -0.4161$$\sin 0.02 \approx 0.0200$$\cos 0.02 \approx 0.9998$
    3$\sin 3 \approx 0.1411$$\cos 3 \approx -0.9900$$\sin 0.03 \approx 0.0300$$\cos 0.03 \approx 0.9996$

    看两个尺度怎么同时工作。维度 0,1（高频 $\omega_0=1$）：$pos$ 从 0 到 3，sin 值 $0 \to 0.8415 \to 0.9093 \to 0.1411$，cos 值 $1 \to 0.5403 \to -0.4161 \to -0.9900$——几乎转完一圈，变化剧烈。维度 2,3（低频 $\omega_1=0.01$）：sin 值 $0 \to 0.0100 \to 0.0200 \to 0.0300$，cos 值 $1 \to 1.0000 \to 0.9998 \to 0.9996$——几乎不动。高频维区分邻近位置（$pos=1$ 和 $pos=2$ 的 dim 0 差 0.07、dim 1 差 0.96），低频维区分远距离位置（$pos=1$ 和 $pos=100$ 的 dim 2 才差约 1）。这就是多尺度同时编码的最小例证。

    展开：d=4 手算例子的完整逐步代入

    已知 $d_{model}=4$、base $=10000$、$\omega_0=1$、$\omega_1=0.01$。

    $pos=1$：

    $$PE_{(1,0)}=\sin(1/10000^{0})=\sin(1)\approx 0.8415,$$

    $$PE_{(1,1)}=\cos(1/10000^{0})=\cos(1)\approx 0.5403,$$

    $$PE_{(1,2)}=\sin(1/10000^{2/4})=\sin(1/100)=\sin(0.01)\approx 0.0100,$$

    $$PE_{(1,3)}=\cos(1/10000^{2/4})=\cos(0.01)\approx 0.99995\approx 1.0000.$$

    所以 $PE_1 \approx (0.8415,\ 0.5403,\ 0.0100,\ 1.0000)$。

    $pos=2$：

    $$PE_{(2,0)}=\sin(2)\approx 0.9093,\quad PE_{(2,1)}=\cos(2)\approx -0.4161,$$

    $$PE_{(2,2)}=\sin(0.02)\approx 0.0200,\quad PE_{(2,3)}=\cos(0.02)\approx 0.9998.$$

    所以 $PE_2 \approx (0.9093,\ -0.4161,\ 0.0200,\ 0.9998)$。

    验证多尺度：dim 0 从 $pos=1$ 到 $pos=2$ 变化 $0.9093-0.8415=0.0678$（小），dim 1 变化 $-0.4161-0.5403=-0.9564$（大）——高频维在 1 步内就剧烈变化；dim 2 变化 $0.0200-0.0100=0.0100$（极小），dim 3 变化 $0.9998-1.0000=-0.0002$（几乎无）——低频维在 1 步内几乎不动。若 $pos$ 从 1 跳到 100，dim 2 才会从 $\sin(0.01)\approx 0.01$ 变到 $\sin(1)\approx 0.84$——低频维需要长距离才显出区分力。

    正弦位置编码还有一个性质，是后续旋转位置编码的思想伏笔。Vaswani 2017 §3.5 指出：对任意固定偏移 $k$，$PE_{pos+k}$ 可以表示为 $PE_{pos}$ 的线性函数。[C4]具体地，对同一频率对（维度 $2i$、$2i+1$，角频率 $\omega_i$）：

    $$PE_{(pos+k,\,2i)}=PE_{(pos,2i)}\cos(k\omega_i)+PE_{(pos,2i+1)}\sin(k\omega_i).$$

    $$PE_{(pos+k,\,2i+1)}=PE_{(pos,2i+1)}\cos(k\omega_i)-PE_{(pos,2i)}\sin(k\omega_i).$$

    这个变换是一个旋转（角度 $k\omega_i$）[F3]。它的意义是：虽然位置向量与绝对位置 $pos$ 绑定，但"位置 $pos+k$ 的向量"可以由"位置 $pos$ 的向量"经一个固定旋转得到——这意味着模型有可能从绝对编码中线性读出相对位置 $k$。这正是 Vaswani 选择 sin/cos 而非任意函数的理由（"we hypothesized it would allow the model to easily learn to attend by relative positions"）。

    补充：线性性质的和角公式推导

    目标：证明 $PE_{(pos+k,2i)} = PE_{(pos,2i)}\cos(k\omega_i) + PE_{(pos,2i+1)}\sin(k\omega_i)$。

    由正弦公式，$PE_{(pos,2i)}=\sin(pos\cdot\omega_i)$、$PE_{(pos,2i+1)}=\cos(pos\cdot\omega_i)$、$PE_{(pos+k,2i)}=\sin((pos+k)\cdot\omega_i)$。

    用正弦和角公式 $\sin(a+b)=\sin a\cos b + \cos a\sin b$，令 $a=pos\cdot\omega_i$、$b=k\omega_i$：

    $$\sin((pos+k)\omega_i)=\sin(pos\cdot\omega_i)\cos(k\omega_i)+\cos(pos\cdot\omega_i)\sin(k\omega_i)=PE_{(pos,2i)}\cos(k\omega_i)+PE_{(pos,2i+1)}\sin(k\omega_i).$$

    同理用余弦和角公式 $\cos(a+b)=\cos a\cos b - \sin a\sin b$：

    $$\cos((pos+k)\omega_i)=\cos(pos\cdot\omega_i)\cos(k\omega_i)-\sin(pos\cdot\omega_i)\sin(k\omega_i)=PE_{(pos,2i+1)}\cos(k\omega_i)-PE_{(pos,2i)}\sin(k\omega_i).$$

    用 d=4 手算例子验证：从 $pos=1$ 到 $pos=2$，$k=1$、$\omega_0=1$。$PE_{(2,0)}=\sin 2\approx 0.9093$；按线性性质：$PE_{(1,0)}\cos 1 + PE_{(1,1)}\sin 1 = \sin 1\cos 1 + \cos 1\sin 1 = 2\sin 1\cos 1 = \sin 2 \approx 0.9093$。一致。

    注意：这个"旋转"性质只在一对维度内成立，且 $k$ 是固定偏移。它说明相对位置可由线性变换读出，但正弦方案本身仍是绝对位置编码（向量与 $pos$ 绑定、加在嵌入上）——不等于"相对位置编码"。

    常见误解：把正弦位置编码叫做"相对位置编码"。这是错的。正弦方案是绝对位置编码——位置向量与绝对位置 $pos$ 绑定、加在输入嵌入上。它具有"PE(pos+k) 是 PE(pos) 的线性函数"这一性质，使模型有可能学到相对位置，但这不改变它属于绝对方案的事实。真正的相对位置编码加在注意力分数上、与相对距离绑定，下一章会讲。

    正弦方案用固定公式生成位置向量。如果把固定公式换成可学习参数会怎样？下一章看可学习绝对方案。

    可学习绝对位置编码——把固定向量换成可学习参数

    正弦方案的频率与公式都是人工设定的。一个自然的改进是：让模型自己学每个位置该用什么向量。这就是可学习绝对位置编码[F5]：用一个 $L\times d_{model}$ 的可学习参数表 $PE$ 代替固定 sin/cos，$L$ 是预设的最大序列长度，每个位置一个可学习向量。

    $$PE \in \mathbb{R}^{L\times d_{model}}\ \text{（可学习）},\qquad x'_m = x_m + PE_m.$$

    注入方式不变——仍是加到 token 嵌入上[F2]。唯一区别是 $PE$ 从"按公式算"变成"从参数表查"。位置 $m$ 超出 $L$ 时没有对应参数，模型无法处理。

    维度正弦（sinusoidal）可学习（learned）

    常见误解："Vaswani 2017 的 big 模型用了可学习位置编码。"这是错的。base 和 big 模型都用正弦位置编码；可学习只是 Table 3 row (e) 的实验对比项，论文报告两者"nearly identical"并最终选正弦。BERT、GPT-2 后来采用可学习，是因为在训练长度内表现相近且实现简单，不是因为 Vaswani 证明了可学习更好。

    可学习方案换来了"数据驱动"（模型能学到任务特定的位置模式），但失去了外推能力（超出 $L$ 即失败），并增加 $L\cdot d_{model}$ 参数。这是绝对位置编码（无论正弦还是可学习）的共同局限：它们都加在输入嵌入上、编码"第几位"，而语言理解往往更依赖"相差几位"。下一章看相对位置编码如何换一个作用点。

    绝对方案（正弦与可学习）都加在输入嵌入上、编码"第几位"。但语言理解常更依赖"相差几位"——下一章看相对方案。

    相对位置编码——T5 的 bias 机制与"加在分数上"的本质区别

    绝对位置编码给每个位置一个独立向量，编码的是"这是第几位"。但语言学里更重要的是相对距离：理解"The cat sat on the mat"中"sat"与"cat"的关系，需要知道"cat 在 sat 前面 1 位"（主谓关系），而不是"cat 是第 2 位、sat 是第 3 位"。相对位置编码直接编码"两个位置相差几位"。

    T5（Raffel et al. 2019）采用的相对方案[C7]不在输入嵌入上加位置向量，而是在注意力分数 softmax 之前加一个与 query-key 相对距离 $i-j$ 绑定的标量偏置：

    $$\text{score}(i,j)=q_i\cdot k_j + b_{\text{bucket}(i-j)}.\qquad\text{Raffel 2019 §3.2}$$

    其中 $q_i$ 是位置 $i$ 的 query、$k_j$ 是位置 $j$ 的 key、$b_{\text{bucket}(i-j)}$ 是与相对距离 $i-j$ 绑定的可学习标量。[F4]逐项说明 T5 的具体机制：

    • 分桶（bucketing）：相对距离 $i-j$ 是整数（从 $-(L-1)$ 到 $L-1$），直接每个距离一个参数会有 $2L-1$ 个。T5 用一个分桶函数把连续距离映射到有限个桶（32 个桶），桶内共享参数——邻近距离用细桶（每距离一桶）、远距离用粗桶（多距离合一桶），总共约 32 个可学习标量。
    • 每头独立、各层共享：每个注意力头有自己的一套 bias（共$32 \times h$ 个标量，$h$ 是头数），但同一套 bias 在所有注意力层之间共享——位置偏置学一次、各层复用。
    • 外推处理：对超出训练时见过的最大距离的相对距离，T5 把它 clamp（截断）到最大桶，复用最大桶的 bias。
    绝对位置编码（正弦/可学习）：位置信号加在输入嵌入上
  x_m ──► +PE_m ──► W^Q ──► q_m ┐
  x_n ──► +PE_n ──► W^K ──► k_n ┼──► q_m · k_n ──► softmax ──► 加权 V
  x_n ──► +PE_n ──► W^V ──► v_n ┘   （位置只通过嵌入进入一次，之后被投影扭曲）

相对位置编码（T5 bias）：位置信号加在注意力分数上
  x_m ──► W^Q ──► q_m ┐
  x_n ──► W^K ──► k_n ┼──► q_m · k_n + b_{bucket(m-n)} ──► softmax ──► 加权 V
  x_n ──► W^V ──► v_n ┘   （位置在每个注意力层、每个头都直接进入分数）

    本质区别在两点[C8]：

    • 编码对象不同：绝对方案编码"第几位"（向量与绝对位置 $pos$ 绑定）；相对方案编码"相差几位"（偏置与相对距离 $i-j$ 绑定）。
    • 作用点不同：绝对方案加在输入嵌入上，位置信号只在第一层之前进入一次，之后被 $W^Q$、$W^K$、$W^V$ 投影扭曲；相对方案加在注意力分数上，每个注意力层、每个头都直接把位置信号注入分数——模型对位置更敏感。
    维度绝对方案（正弦/可学习）相对方案（T5 bias）
    编码对象绝对位置 pos相对距离 i−j
    作用点输入嵌入（第一层之前）注意力分数（softmax 之前，每层每头）
    可学习参数量0（正弦）或 $L\cdot d$（可学习）约 $32 \times h$（桶数×头数，各层共享）
    长度外推正弦理论可外推、可学习失败clamp 到最大桶，可一定程度外推
    与 FlashAttention 兼容兼容（位置在嵌入上，不干扰分数计算）不兼容（需物化 $n\times n$ 偏置矩阵，Flash 的分块 IO 优化失效）
    补充：T5 分桶函数的方向性说明（不展开完整公式）

    T5 的分桶不是对称的：它对"query 在前、key 在后"（$i-j>0$）和"query 在后、key 在前"（$i-j<0$）用不同的桶。原因是语言中"看前面"和"看后面"的依赖模式不同（自回归解码时 query 只能看前面的 key）。分桶函数把 $[-(L-1), L-1]$ 范围的相对距离映射到32 个桶，邻近距离（如 $|i-j|\le 8$）每距离一桶、远距离按对数合并。完整分桶公式见 T5 源码 _relative_position_bucket，本页不展开。

    ALiBi（Press et al. 2021）是另一种相对方案：不用分桶，而是给每个头一个与距离成正比的线性负偏置 $-m_h \cdot |i-j|$（$m_h$ 是该头的固定正斜率，不学习）。它让远距离 token 的注意力分数单调下降，外推性好。本页不展开 ALiBi 的机制。

    相对方案换来了"直接编码相对距离"和"每层每头注入位置"，但也带来代价：与 FlashAttention 不兼容（需物化 $n\times n$ 偏置矩阵），限制了高效推理。这正是后来 RoPE 被广泛采用的原因之一——RoPE 用乘旋转实现相对效果，但不需要物化偏置矩阵（详见 RoPE）。

    四类方案对比与 NoPE 选择——为什么 K3 选 NoPE

    把四类方案与 NoPE 放一张表，从四个维度对比核心权衡：

    方案位置信号加在哪里可学习参数长度外推与推理优化兼容性
    绝对正弦输入嵌入（加）无理论可外推，经验也退化兼容
    可学习绝对输入嵌入（加）$L\times d_{model}$超出 $L$ 即失败兼容
    相对 bias（T5）注意力分数（加）桶数×头数（各层共享）clamp 到最大桶，有限外推与 FlashAttention 不兼容（需物化 $n\times n$）
    RoPEQ/K（乘旋转）无需 YaRN/PI 扩展与 MLA 矩阵吸收冲突
    NoPE什么都不做无decoder-only 直接外推兼容（依赖因果掩码）

    前三类都在主动"加"位置信息，区别是加在哪里、怎么加。RoPE 换成"乘"——按绝对位置 $m$ 旋转 query 和 key，使内积只依赖相对位置 $m-n$，叫"绝对构造、相对效果"（详见 RoPE）。NoPE 那一行的"什么都不做"是另一条路径：不施加任何显式位置编码，依赖 decoder-only 的因果掩码隐式提供位置信息（详见 NoPE）。

    常见误解："NoPE 完全没有位置信息。"这是错的。NoPE 不施加显式位置编码，但 decoder-only 的因果掩码让每个位置只能看到它之前的 token——这种"可见位置集合随当前位置变化"的不对称性隐式提供了位置信号。NoPE 不适用于双向编码器（那里每个位置看到同样的 token 集合，真没有位置信息）。详见 NoPE。

    K3 为什么选 NoPE

    Kimi K3 的 Gated MLA 层在结构上保留了 RoPE 接口（拆出 rot 分量），但配置中 mla_use_nope=true，所有 MLA 层不施加位置编码。这个选择有两个原因：

    第一，RoPE 与 MLA 的矩阵吸收冲突。MLA 通过压缩潜向量减少 KV cache，其推理优化依赖"矩阵吸收"——把投影矩阵 $W^{UK}$ 从 key 侧搬到 query 侧避免显式重建 K（详见 MLA）。但矩阵吸收要求 $W^{UK}$ 与位置无关；若对压缩潜变量施加 RoPE，旋转矩阵介于 query 和 $W^{UK}$ 之间且每个 token 不同，无法合并成固定矩阵——位置敏感的旋转破坏了矩阵吸收的前提。

    第二，K3 的位置信息由 KDA（递归注意力变体）隐式提供。K3 用 KDA 的递归门控与衰减机制承载时序信息，MLA 不需要额外的位置编码。这意味着扩展上下文长度时无需修改位置编码参数（如 RoPE rescaling 或 YaRN），模型直接外推到 1M token（详见 Kimi K3 §2.1.2、§3.4）。

    这是 NoPE 路线相对 RoPE 的一个实际优势：当架构需要与推理优化（如矩阵吸收）兼容、且位置信息有其他来源时，不施加位置编码反而更简单、外推更直接。K3 的选择不是"位置编码不重要"，而是"位置信息由别的机制提供，MLA 不需要显式位置编码"。

    选择位置方案的判断框架：看模型架构（decoder-only 适用 NoPE/RoPE；双向编码器需显式位置信号）、推理优化约束（FlashAttention 与相对 bias 不兼容；MLA 矩阵吸收与 RoPE 冲突）、外推需求（NoPE 直接外推；RoPE 需扩展；可学习无法外推）。没有银弹，只有权衡。

    来源与教学说明

    全文总结。回到开篇的问题：没有位置编码的 Transformer 分不清"我打你"和"你打我"，因为自注意力排列等变。位置编码通过四类方式注入位置信号：绝对正弦用多频率 sin/cos 加在嵌入上[C2]，可学习绝对把固定公式换成参数表[C6]，相对偏置加在注意力分数上编码"相差几位"[C7]，RoPE 用乘旋转实现"绝对构造、相对效果"[C9]。NoPE 不施加显式编码，靠因果掩码隐式提供位置[C9]。选择取决于架构与推理优化约束：K3 的 MLA 层因 RoPE 与矩阵吸收冲突、位置信息由 KDA 提供，选 NoPE 直接外推到更长上下文[C10]。没有银弹，只有权衡。

    d=4 正弦 PE 手算：$d_{model}=4$、base $=10000$，计算 $pos=0,1,2,3$ 的 PE 向量。构造目的：用最小手算例子展示多频率在同一位置的不同变化速率（高频维 dim 0,1 振荡快、低频维 dim 2,3 几乎不动）。数字便于手算，不代表真实模型配置（真实 $d_{model}=512$）。

    "The cat sat on the mat"相对距离：教学构造，说明语言学中相对距离比绝对位置更重要。

    教学解释与类比边界

    二进制计数器类比：服务"多频率为何能唯一编码位置"这一局部关系——$i$ 小的维度振荡快像二进制低位、$i$ 大的维度振荡慢像高位、组合起来给每个位置唯一指纹。失效边界：（1）二进制各位是离散 0/1 跳变，sin/cos 是连续平滑函数；（2）二进制位数固定，这里维度对数由 $d_{model}$ 决定且波长连续分布；（3）二进制有严格唯一性证明，sin/cos 的唯一性依赖频率不可约，非完全等价。正式判断仍以正弦位置编码公式为准。
