DFlash

块扩散并行起草 + KV 注入，让投机解码的 draft 环节不再串行；6× 无损加速、相对 EAGLE-3 高 2.5×。

arXiv:2602.06036v2 · Chen, Liang, Liu (UC San Diego) · ICML 2026 · 更新于 2026-08-19

论文定位

DFlash（Chen, Liang, Liu，UC San Diego / Z Lab，ICML 2026 accepted；arXiv:2602.06036v2）用轻量块扩散草稿模型做并行起草，把投机解码的「draft 环节仍是串行」瓶颈彻底拆掉：$L$ 个 token 不再要 $L$ 次串行草稿前向，而是 1 次并行起草整个块。

主要贡献

  • 把 DFlash 设计为块扩散草稿器：一次前向并行预测整块（块 8–16 token），起草成本对块大小不敏感。
  • 把 target 隐藏特征通过KV 注入作为 draft 每层条件（绕过 Q 投影、FFN），避免输入融合在深层被冲淡，让 $\tau$ 随 draft 层数持续提升。
  • 训练侧anchor 随机采样构块（匹配推理时「以已验证 token 为锚」的行为 + 数据增广）、早期位置加权损失（$w_k=\exp(-(k-1)/\gamma)$）、与 target 共享并冻结 embedding/LM head（draft 只更新 transformer 层）。

方法概述

推理管线：prefill 阶段从 target 第 2 层到倒数第 3 层均匀采 5 层隐藏态，按 token 拼接后过共享投影 $W_c\in\mathbb{R}^{D\times 5D}$ 融合为 $H_t$；第 $i$ 层 draft 注意力把 $H_t$ 的 K/V 投影与 draft token 的 K/V 拼接（$K_i=[W_i^K H_t;W_i^K H_d]_{\mathrm{seq}}$），存进 draft 自己的 KV cache 跨起草周期复用。draft 以块扩散单步方式（$T=1$）一次前向并行预测整块所有被遮位置；target 一次前向验证整块。详细公式与图示见 完整论文解析。

关键结论

  • Transformers 后端 Qwen3-4B/8B T=0 平均 $4.91\times$ / $4.86\times$，最高 $6.09\times$（Q3-4B Math500）；对 EAGLE-3(16) 提升 $2.4\times$。
  • SGLang B200 + FA4 + Spec-v2：Qwen3-8B Math500 并发 1 达 $5.1\times$，并发 32 仍 $2.8\times$。
  • LLaMA-3.1-8B（同 EAGLE-3 训练数据）：DFlash 在所有任务、所有并发、两种 EAGLE-3 树大小配置下都领先；EAGLE-3(60) 在并发 16/32 出现 $0.5\!\text{–}\!0.9\times$（比基线还慢）。
  • 无 KV 注入的纯块扩散草稿器仅 $2\!\text{–}\!3\times$，证明 KV 注入是 4–6× 的主要来源；MT-Bench 对话任务一致最低（$2.75\!\text{–}\!2.85\times$ T=0）。

条件：单卡 H200/B200、thinking 模式、采样温度与最大生成长度 2048、并发数——以上数字离开了这些条件不可直接对比。
