# 注意力汇聚点 术语表

| 术语 | 英文/缩写 | 首次出现 | 含义 |
|---|---|---|---|
| 注意力汇聚点 | attention sink | 页面开头 | 被分配大量注意力、语义上不重要的位置 |
| 初始位置 | initial tokens | 第 1 章 | 序列最前面的若干位置，通常指前 1–4 个 |
| sink token | — | 第 1 章 | 充当汇聚点的 token（可能是初始位置，也可能是专门的占位 token） |
| 滚动窗口 | rolling window | 第 3 章 | 只保留最近若干位置的 KV |
| 可学习 sink 参数 | learnable sink logit | 第 3 章 | 每个注意力头一个标量，加在 softmax 分母上 |
| 缓存内位置 | position within cache | 第 3 章 | 把位置重新编号为缓存内的相对位置 |
| 分母 | denominator | 第 2 章 | softmax 归一化的分母，即各可见槽位指数之和（加 sink 项） |
| 行最大值 | row max, $m$ | 第 3 章 | 在线 softmax 中用于数值稳定的每行最大值；不含 sink |
| 长程记忆 | long-term memory | 第 4 章 | 对超出上下文窗口的早期信息的利用能力 |

## 符号

| 符号 | 含义 |
|---|---|
| $q, k_t$ | query 与第 $t$ 个槽位的键 |
| $d$ | 注意力头维 |
| $\mathcal{T}$ | 可见槽位集合 |
| $m$ | 可见槽位分数的行最大值 |
| $\text{sink}$ | 每头一个的可学习汇聚点标量（作为 logit 使用） |
| $W$ | 可见槽位个数（窗口场景下即窗口大小） |
| $v_t$ | 第 $t$ 个槽位的值向量 |

## 记号约定

- "汇聚点项"指 $e^{\text{sink}-m}$ 这一项；"份额"指它在分母中的占比。
- 注意力分数默认指 $q\cdot k_t/\sqrt{d}$，与标准注意力一致。
