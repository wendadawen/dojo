# 因果掩码（Causal Mask）内容范围

## 1. 概念歧义处理

"掩码（mask）"在 Transformer 中至少指两种不同的遮挡操作：

- **因果掩码（causal mask / sequence mask / look-ahead mask / subsequent mask）**：屏蔽"未来位置"，使位置 $t$ 看不到位置 $t+1, t+2, \dots$。仅用于 decoder 自注意力。
- **填充掩码（padding mask）**：屏蔽填充 token（如 batch 中短句末尾的 `<pad>`），与位置先后无关。encoder 与 decoder 都可能使用。

两者在实现上都表现为"把注意力分数某些位置置 $-\infty$"，但屏蔽的对象和目的不同；在 PyTorch `nn.MultiheadAttention` 等接口里可以叠加为同一个 `attn_mask` 张量。

状态：**已裁定**。本文采用主流含义——"因果掩码"专指屏蔽未来位置的上三角遮挡规则。填充掩码只作为对照对象在边界处提及，不纳入讲解。

别名：causal mask、causal attention mask、look-ahead mask、subsequent mask、上三角掩码、未来掩码。

## 2. 概念含义

- 概念名称：因果掩码（Causal Mask）
- 英文：Causal Mask / Causal Attention Mask
- 一句话定义：因果掩码是 decoder-only / decoder 自注意力中施加在注意力分数矩阵上的遮挡规则——位置 $t$ 只能 attend 到位置 $1..t$，看不到未来 token；实现上把注意力分数矩阵严格上三角的元素置 $-\infty$，softmax 后这些位置的注意力权重为 $0$。
- 正式定义：与权威来源一致。Vaswani et al. 2017《Attention Is All You Need》§3.2.3 描述 decoder 的自注意力"allow each position in the decoder to attend to all positions in the decoder up to and including that position"，并通过"mask out (set to $-\infty$) all entries in the input to the softmax which correspond to illegal connections"实现。
- 本文采用的语境：以原始 Transformer 论文（Vaswani 2017）的 decoder 掩蔽自注意力为定义来源；以"位置 $t\to 1..t$、上三角 $-\infty$、softmax 后未来权重为 $0$"为机制主线。

### 包括什么

- 因果掩码的规则：位置 $t$ 只能 attend 到 $1..t$。
- 实现机制：上三角 $-\infty$ 矩阵 $M$ 加到注意力分数上，softmax 后未来位置权重为 $0$、可见位置权重重新归一化到和为 $1$。
- 核心公式：$\operatorname{Attention}(Q,K,V)=\operatorname{softmax}(QK^\top/\sqrt{d_k}+M)V$，其中 $M$ 为因果掩码。
- 一个可手算的 $3$-token 数值示例：施加掩码前后 softmax 权重与输出的变化。
- 与自回归生成的关系：为什么 decoder 需要它（防止未来信息泄漏）。
- 训练 vs 推理：训练时一次喂入整条序列并用掩码并行计算所有位置；推理时 KV-cache 逐 token 增长，掩码隐含在"cache 中只有过去的 token"这一结构里。
- 深层作用：因果掩码打破排列对称性，使不同位置可见 token 集合不同——这是 NoPE（不加显式位置编码）仍能区分词序的结构前提。
- 边界：encoder（双向，无因果掩码）vs decoder（因果，有掩码）；与填充掩码的区别。

### 不包括什么

- 标准注意力的完整教学（$Q/K/V$ 怎么来、多头拼接、$\sqrt{d_k}$ 缩放的方差推导、$O(n^2)$ 瓶颈）。理由：属于另一独立概念，已有概念页 `wiki/standard-attention/`，本文作前置概念引用其结论。
- 各类显式位置编码（绝对位置编码、相对位置编码、RoPE、ALiBi）的完整机制。理由：属于另一独立概念，本文只在讲解 NoPE 联系时点出"显式位置编码做了什么"以划清边界。
- NoPE 的完整机制与长度泛化结论。理由：已有概念页 `wiki/nope/`，本文只说明因果掩码作为其"结构前提"的那一层关系，不重复 NoPE 的论证。
- KV-cache 的工程实现细节（分页、压缩、命中率）。理由：只影响工程规模，不改变因果掩码机制；本文只用 KV-cache 的最小概念说明推理时掩码为何隐含。
- 自回归采样的解码策略（贪心、top-k、top-p、温度）。理由：属于生成策略，与掩码机制无关。

### 相邻概念

- 标准注意力（scaled dot-product attention）：因果掩码是施加在标准注意力分数上的遮挡规则，不改变 $\operatorname{softmax}(QK^\top/\sqrt{d_k})V$ 的基本结构，只在其输入加一个掩码矩阵。**已有概念页** `wiki/standard-attention/`，作前置概念引用。
- 填充掩码（padding mask）：同属"把分数置 $-\infty$"的遮挡操作，但屏蔽对象是填充 token 而非未来位置，目的不同。**不纳入本页范围**，仅在边界处作对照。
- 自回归生成（autoregressive generation）：因果掩码是其基础——逐 token 预测时只能依赖已生成的前缀。**无概念页**，正文给最小定义。
- NoPE：以因果掩码为结构前提。**已有概念页** `wiki/nope/`，正文在讲解深层作用时引用。
- 位置编码（positional encoding）：因果掩码隐式提供的位置信号是 NoPE 利用的对象；与显式位置编码正交。**无概念页**，必要时给占位说明。

## 3. 学习目标

### Q1：因果掩码是什么规则，解决什么问题？

- 完成答案：读者应能说明——因果掩码是 decoder 自注意力中"位置 $t$ 只能 attend 到 $1..t$、看不到未来 token"的遮挡规则；它解决的问题是自回归生成中 decoder 不能让位置 $t$ 的表示泄漏 $t+1,t+2,\dots$ 的信息，否则训练时模型能"抄答案"。
- 为什么是核心目标：不厘清"规则是什么"和"防什么泄漏"就无法理解机制，也分不清因果掩码与填充掩码。
- 依赖内容：标准注意力（softmax 对分数归一化）、自回归生成的最小定义。

### Q2：因果掩码如何机械地实现？

- 完成答案：读者应能说明——构造一个严格上三角为 $-\infty$、对角线及以下为 $0$ 的矩阵 $M$，把它加到注意力分数 $QK^\top/\sqrt{d_k}$ 上再 softmax；由于 $e^{-\infty}=0$，被掩位置权重为 $0$，可见位置权重重新归一化到和为 $1$。公式为 $\operatorname{softmax}(QK^\top/\sqrt{d_k}+M)V$。
- 为什么是核心目标：这是因果掩码从"规则"落到"可执行计算"的关键，不理解就无法手算或读代码。
- 依赖内容：softmax 的归一化性质、注意力分数矩阵的结构。

### Q3：用一个可手算的 $3$-token 例子验证机制

- 完成答案：读者应能手算——给定 $3\times3$ 注意力分数矩阵与因果掩码 $M$，施加 $M$ 后逐行 softmax，验证未来位置权重为 $0$、可见位置权重和为 $1$，并算出每个位置的输出。
- 为什么是核心目标：手算是验证"掩码 + softmax + 重归一化"机制最直接的方式，避免读者把结论当结论背诵。
- 依赖内容：Q2 的公式与符号。

### Q4：因果掩码在训练和推理中分别如何使用？

- 完成答案：读者应能说明——训练时一次喂入整条目标序列、用因果掩码并行计算所有位置的表示（每个位置只看前缀，但全部位置一步算完）；推理时 KV-cache 逐 token 增长，新 query 只与 cache 中已有的（过去的）key/value 交互，掩码隐含在"cache 中没有未来 token"这一结构里，无需显式构造上三角矩阵。
- 为什么是核心目标：因果掩码在训练和推理中形态不同，不理解会误以为推理时也要每步重建 $n\times n$ 掩码矩阵。
- 依赖内容：Q2 机制、自回归生成的最小概念、KV-cache 的最小概念。

### Q5：因果掩码的边界，以及它为什么是 NoPE 隐式位置的结构前提？

- 完成答案：读者应能说明——encoder 用双向注意力（无因果掩码，每个位置看到全部）；填充掩码屏蔽填充 token、因果掩码屏蔽未来位置，二者正交可叠加；因果掩码使每个位置可见的 token 集合不同，打破了"交换输入顺序得到相同输出"的排列对称性，这是 NoPE 不加显式位置编码仍能区分词序的结构原因（NoPE 完整论证见 NoPE 概念页）。
- 为什么是核心目标：不理解边界会把因果掩码误用到 encoder，或与填充掩码混淆；不理解排列对称性会无法解释"为什么 NoPE 能工作"。
- 依赖内容：Q2 机制、双向 vs 因果注意力、排列对称性的最小概念。

## 7. 常见误解和适用边界

### 常见误解

- 误解一："因果掩码和填充掩码是一回事。"
  - 正确结论：两者都把注意力分数某些位置置 $-\infty$，但因果掩码屏蔽"未来位置"（与位置先后有关），填充掩码屏蔽"填充 token"（与是否为有效 token 有关）。二者目的不同、可叠加。
  - 形成原因：实现上都是"置 $-\infty$"，初学者把实现手段当成本质。
  - 影响目标：Q1、Q5。

- 误解二："推理时也要为每步构造一个 $n\times n$ 的因果掩码矩阵。"
  - 正确结论：推理用 KV-cache 逐 token 增长，新 query 只与 cache 中已有的（过去的）key/value 交互，"看不到未来"由 cache 的内容范围天然保证，无需显式构造上三角矩阵。训练时才一次喂入整条序列、显式用 $M$。
  - 形成原因：把训练时的并行掩码形态套到推理上。
  - 影响目标：Q4。

- 误解三："encoder 也应该加因果掩码。"
  - 正确结论：encoder 是双向注意力，每个位置需要看到全部输入以构建完整上下文表示，加因果掩码会破坏这一定位。因果掩码只用于 decoder 自注意力（保留自回归性质）。
  - 形成原因：把"掩码"当成 Transformer 的通用配置。
  - 影响目标：Q5。

- 误解四："因果掩码就是 NoPE。"
  - 正确结论：因果掩码是注意力分数上的遮挡规则；NoPE 是"不施加任何显式位置编码"的选择。因果掩码是 NoPE 能工作的结构前提之一，但两者不是一回事——因果掩码在加显式位置编码的 decoder 里也照常使用。
  - 形成原因：把"因果掩码隐式提供位置信号"夸大为"因果掩码就是位置编码方案"。
  - 影响目标：Q5。

### 适用边界

- 因果掩码解决的问题：在 decoder 自注意力中防止位置 $t$ 的表示依赖 $t+1,t+2,\dots$ 的信息，从而保留自回归性质；并作为 NoPE 隐式位置信号的结构来源。
- 因果掩码不解决的问题：不提供"显式、可控、可外推"的位置标记（那是显式位置编码或 NoPE 训练学到的模式的事）；不屏蔽填充 token（那是填充掩码的事）。
- 结论成立条件：decoder 自注意力（因果注意力）。在 encoder 双向注意力中不施加因果掩码。
- 条件不满足时：若在 encoder 加因果掩码，每个位置将看不到后续输入，破坏双向上下文建模；若 decoder 不加因果掩码，训练时位置 $t$ 会"看到"未来 token，信息泄漏、模型无法学到合理的逐 token 预测。
