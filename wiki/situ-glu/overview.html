SiTU-GLU（Sigmoid Tanh Unit GLU）

一种把 SwiGLU 的门支线性因子和值支同时套上 softcap $\beta\tanh(x/\beta)$ 的 GLU 变体——让两个乘性因子都平滑饱和到 $\pm\beta$，乘积上界锁在 $\beta_1\beta_2=100$，同时保留 SwiGLU 在原点附近的近线性响应。

更新于 2026-08-09 · 依据 Kimi K3 Technical Report §2.3.2 与 §B

1. 是什么

SiTU-GLU 是 GLU 家族的下游成员，由 Kimi K3 提出。它的公式是 $[\beta_1\tanh(W_g x/\beta_1)\odot\sigma(W_g x)]\odot[\beta_2\tanh(W_u x/\beta_2)]$——把 SwiGLU 的门支线性因子 $W_g x$ 换成 softcap $\beta_1\tanh(W_g x/\beta_1)$、值支 $W_u x$ 换成 softcap $\beta_2\tanh(W_u x/\beta_2)$，同时把两个无界因子变成有界因子。K3 设定 $\beta_1=4$（门支）、$\beta_2=25$（值支），乘积上界 100。

2. 为什么需要它

  • SwiGLU 两个乘性因子都无界。门支线性因子 $W_g x$ 在大正侧近似线性、值支 $W_u x$ 本来就线性，乘积量级 $O(x^2)$。K3 在 Stable LatentMoE 路由分支近四连矩阵相乘 + 2.8T 规模下，单个坐标 pre-activation 到 100、1000，乘积到 10000、1000000（构造示例数值，说明量级关系，非 K3 实测），撑爆低精度训练。
  • GLU 的 sigmoid 门有界但值仍无界，且 GLU 不保留 Swish 近原点的正侧线性响应。直接换回 GLU 不解决爆炸问题，也丢失 SwiGLU 的局部响应形状。
  • hard clamping 饱和后梯度归零。如果只把输出 clip 到 100，饱和区里梯度严格为 0，模型进了饱和区就"死"——K3 §B 末段据此放弃 hard clamping 选 softcap。

3. 核心直觉

  • softcap = 平滑的有界化。$\beta\tanh(x/\beta)$ 把任意实数压到 $(-\beta,\beta)$，开区间不到 $\pm\beta$；近原点 $\approx x$（一阶等价），远点 $\to\pm\beta$。
  • 两支同时套才有上界。只套门支、值支仍无界，乘积仍无界。K3 §B 明确 "to the up branch ... preventing either branch from dominating the product"。
  • 上界 100 是乘积极限。$|\tanh|\le1$、$0<\sigma<1$，所以每坐标 $|\mathrm{SiTU\text{-}GLU}|\le\beta_1\beta_2=100$。对有限输入严格小于 100，但可任意接近（$x=100$ 时约 99.93）。
  • 近原点一阶等于 SwiGLU。$\beta\tanh(z/\beta)=z+O(z^3/\beta^2)$，$|W_g x|\ll 4$、$|W_u x|\ll 25$ 时 SiTU-GLU 与 SwiGLU 一阶等价；$\beta_1,\beta_2\to\infty$ 时逐点收敛到 SwiGLU——SiTU-GLU 是 SwiGLU 的"有界化版本"。
  • 饱和区梯度非零。$\tanh'(x/\beta)=1-\tanh^2(x/\beta)$ 在远点指数衰减非零（不是严格 0），让模型在饱和区仍能缓慢学——这是 K3 选 softcap 不选 clip 的核心理由。

4. 关键结论与边界

  • 负侧被 sigmoid 杀尾。$W_g x\to-\infty$ 时 $\sigma(W_g x)\to 0$ 把整个门支压到 0，输出 $\to 0$——保留了 Swish 的负尾衰减形状，不是简单对称有界。
  • $\beta_1=4,\beta_2=25$ 是 K3 工程设定，不是普适最优。报告未给选择依据与对照实验。读者不应据此推出"4 和 25 对所有模型最好"。
  • 不解决 Quantile Balancing 的负载均衡。QB 是 §2.3.3 的独立组件，与 SiTU-GLU 并列在 Stable LatentMoE 三件套里（RMSNorm + SiTU-GLU + QB），各管一件事。
  • 不保证训练损失一定下降。K3 §2.3.2 末段只承诺"preserves the local response of SwiGLU while controlling both factors in the product"——是结构有界性保证，不是性能保证；报告未给 SiTU-GLU vs SwiGLU 对照实验。
  • "better training behavior" 是经验陈述。K3 §B 末段对 softcap vs hard clamping 的对比是经验观察，不是对照实验。
