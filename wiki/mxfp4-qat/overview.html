MXFP4 量化感知训练

把 MoE 大模型的专家权重压到 4-bit 微缩浮点格式 MXFP4，并在训练前向就模拟这种量化、反向用直通估计器传梯度，使模型部署时用真正的 4-bit 权重仍保持训练精度。

更新于 2026-08-09

1. 一句话定位

MXFP4 量化感知训练（MXFP4 QAT）是一种部署导向的量化方法：把模型权重编码到 4-bit 浮点格式 MXFP4（OCP 微缩浮点，每 32 个权重共享一个 scale），训练时让前向模拟这一量化、反向用 STE 传梯度，使模型在被压到 4-bit 后仍像训练时那样准。Kimi K3 把它用在 896 个 MoE 路由专家上，覆盖 SFT 与 RL 全后训练。

2. 为什么需要它

  • MoE 专家权重主导显存。K3 有 896 个路由专家（每层 896 个，92 个 MoE 层），全部权重必须驻留显存（稀疏激活只省计算不省显存），约 2.71T 参数、BF16 下约 5.4 TB。这是部署成本的主要来源。
  • 4-bit 能省约 4 TB。压到 MXFP4 后约 1.44 TB，压缩约 3.76×。省下的量级是 TB 级，足以改变部署可行性。
  • 训练后量化（PTQ）会掉点。若训练时全精度、推理时才量化，模型从未见过量化引入的离散误差，质量下降显著。
  • RL 还多一层 mismatch。RL 的训练 target 来自 rollout（推理），若 rollout 与训练量化方案不同，target 与梯度指向不同分布，会让 RL 崩坏或收敛到错误方向。

3. 核心直觉

  • 共享 scale + 窄元素。MXFP4 把 32 个权重组成一块，共享一个 8-bit 的 power-of-two scale（承担动态范围），每个权重自己只存 4-bit 浮点元素（承担块内相对精度）。这是"4-bit 仍可用"的关键——动态范围交给 scale，元素只分辨相对差异。
  • QAT 让训练"看见"量化。前向先把权重"量化再反量化"得到近似权重，用近似权重算损失；反向用直通估计器（STE）把梯度原样传回原始权重。模型每个前向都见到量化偏差，权重会朝"量化后仍能减小损失"的方向调整。
  • STE 是"透明的窗户"。量化里的最近邻舍入不可导，STE 直接令导数为 1，让梯度穿过它。这不保证最优，但让训练能进行。
  • RL 必须 rollout 与训练同方案。K3 让 rollout 与训练共享同一 MXFP4（权重）+ MXFP8（激活）方案，target 与梯度指向同一分布，消除 train-inference mismatch。
  • 选择性量化。只量化 MoE 路由专家权重（占参数绝大部分、稀疏激活），非专家组件（attention、shared expert、router、lm_head）保持高精度——它们频繁参与每 token 计算、对精度敏感、参数占比小。

4. 关键结论与边界

  • MXFP4 不是 4-bit 整数量化。元素是 4-bit 浮点（E2M1：1 符号 + 2 指数 + 1 尾数），有独立指数位，与定点整数不同。成立条件：OCP MXFP4 规范。
  • QAT 不恢复精度，只补偿。权重仍以 4-bit 部署；QAT 让模型适应量化精度损失，补偿多少取决于训练数据与 QAT 配置。成立条件：QAT 贯穿足够长训练。
  • train-inference match 是 RL 量化的硬要求。rollout 与训练量化方案任一不一致即引入 mismatch。成立条件：同一量化方案、同一 scale 选择、同一数值路径。
  • 非专家组件不能盲目量化。attention、router 对数值精度极敏感，量化会破坏稳定性。成立条件：选择性量化策略（config.json 的 ignore 列表印证）。
