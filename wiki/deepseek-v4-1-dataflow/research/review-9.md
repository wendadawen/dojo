## 审查者 1

- 事实错误｜Attention.forward 面板「窗口 KV」｜投影与归一化的顺序反了，写成先归一化再乘 $W_{kv}$｜model.py:705 `kv = self.kv_norm(self.wkv(x))`｜改成 $k = \mathrm{RMSNorm}(W_{kv}\,x)$（RMSNorm 是 kv_norm），或直接写 kv_norm(wkv(x))

## 审查者 3
- 事实错误｜NgramHashState.forward（engram.py:160-184）的 `mod` 节点第二行｜形状写成 `→ [B, T, 2, 1]`，与同节 `hs` 的 `[B, T, 2, 24]`、以及「24 = (4 − 1) × 8」自相矛盾｜engram.py:183 `rolling.unsqueeze(-1) % self.primes[:, i - 1]`：`rolling` 是 [B,T,2]（第 180 行由 `products[..., 0]` 得到，`n_engram_layers` = 2），unsqueeze 后 [B,T,2,1]；primes 是 [层, n-gram 阶, 头] = [2,3,8]（engram.py:151 + 98 的 `primes: tuple[tuple[tuple[int, ...], ...], ...]`），`primes[:, i-1]` 是 [2,8]，广播结果为 [B,T,2,8]。三个阶各 [B,T,2,8] 拼起来才是 [B,T,2,24]｜改成 `rolling.unsqueeze(-1) % self.primes[:, i - 1]` → `[B, T, 2, 8]`，第三行补一句「8 是 engram_n_heads」。
- 事实错误｜Attention.forward 面板「YaRN」公式｜$\theta_j' = \theta_j/16\,(1-\rho_j) + \theta_j\,\rho_j$ 的斜坡方向反了，按文中 $\rho_j=\mathrm{clamp}((j-low)/(high-low),0,1)$ 代入，j 小的维会被除以 factor，与「波长本就在训练长度内的维保留频率」相反｜model.py:384-386：`ramp = ((arange(dim//2) - low)/max(high-low,1e-3)).clamp(0,1)`；`smooth = 1 - ramp`；`freqs = freqs/factor*(1-smooth) + freqs*smooth`，即 $\theta_j' = \theta_j/16\cdot \mathrm{ramp} + \theta_j\cdot(1-\mathrm{ramp})$，model.py:371-375 的注释也说明「已装进训练上下文的维保留频率、超出很远的才除以 factor」｜改成 $\rho_j = 1 - \mathrm{clamp}\big((j-low)/(high-low),0,1\big)$，公式保持 $\theta_j' = \theta_j/16\,(1-\rho_j) + \theta_j\,\rho_j$；或把 ramp 命名为 ρ 并把两个系数对调。
