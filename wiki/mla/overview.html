概念快速阅读 · 注意力机制

Multi-head Latent Attention（MLA）

把每个 token 的 K/V 压成一个低维潜向量缓存，注意力时用学习到的上投影重建——大幅减少 KV cache，同时保留全局 token-to-token 注意力。

更新于 2026-08-09

这个概念是什么

MLA 是 DeepSeek-V2（2024 年 5 月，arXiv:2405.04434）提出的注意力机制。标准多头注意力（MHA）为每个头独立产生一份 K 和 V，推理时要为每个 token 缓存 $2 n_h d_h$ 个数；MLA 把 K 和 V 压成一个 $d_c$ 维潜向量 $\mathbf{c}_t^{KV}$（$d_c \ll d_h n_h$），只缓存它，注意力计算时用学习到的上投影从 $\mathbf{c}_t^{KV}$ 重建 K/V。注意力结构本身没变——仍是 query 对所有前序 token 的 softmax 加权和。

为什么需要它

  • 自回归推理的 KV cache 瓶颈：MHA 下每 token 每层缓存 $2 n_h d_h$ 个数（K 和 V 各一份）；DeepSeek-V2 是 128 头 × 128 维 × 60 层，128K 上下文下整个 KV cache 约 480 GB（BF16）。
  • 已有方法各有代价：GQA/MQA通过共享 K/V 头减 cache，但 MQA 性能明显变弱；GQA 是 cache 与性能的折中，cache 按 $2 n_g d_h l$ 计（$n_g$ 为 KV 头分组数）。
  • 想保留全局注意力质量：稀疏注意力、滑动窗口、线性注意力族都改了注意力结构（少看 token 或换 kernel）；MLA 不改注意力连接图，只压缩存储。
  • 压缩维度可以远小于头数 × 头维：DeepSeek-V2 $d_c = 512$，而 $d_h n_h = 16384$，比值 1/32。

核心直觉

  • 压成潜向量、用时重建：用一个下投影矩阵 $W^{DKV}$ 把 $\mathbf{h}_t$ 压成 $\mathbf{c}_t^{KV} \in \mathbb{R}^{d_c}$；用两个上投影 $W^{UK}, W^{UV}$ 把 $\mathbf{c}_t^{KV}$ 还原成 $\mathbf{k}_t^C, \mathbf{v}_t^C$。缓存的是 $\mathbf{c}_t^{KV}$，不是 K/V 本身。
  • 推理时连重建都可省——矩阵吸收：注意力的 $\mathbf{q}^\top \mathbf{k}_t^C = \mathbf{q}^\top W^{UK} \mathbf{c}_t^{KV} = (W^{UK\,\top} \mathbf{q})^\top \mathbf{c}_t^{KV}$，所以推理时把 $W^{UK}$ 吸进 $W^Q$、$W^{UV}$ 吸进 $W^O$，就直接用 $\mathbf{c}_t^{KV}$ 当 key/value，$\mathbf{k}_t^C, \mathbf{v}_t^C$ 在路径上不出现。
  • RoPE 不能直接作用在压缩后的 K 上：RoPE是位置敏感的旋转矩阵 $R_t$，每个 token 不同；若作用在 $\mathbf{k}_t^C = W^{UK} \mathbf{c}_t^{KV}$ 上会变成 $R_t W^{UK} \mathbf{c}_t^{KV}$，$R_t W^{UK}$ 无法合并成固定矩阵，破坏吸收。所以 MLA 把 RoPE 单独拆出一个共享 key $\mathbf{k}_t^R$ 承载位置信息，content 部分保持可吸收。
  • 注意力公式仍是全局 softmax：MLA 的注意力对全部前序 token 求 softmax 加权和，只是 K/V 由潜向量重建（且推理时连重建都省了）。压缩的是存储，不是注意力连接图。

关键结论与边界

  • cache 公式：MHA = $2 n_h d_h l$、GQA = $2 n_g d_h l$、MQA = $2 d_h l$、MLA = $(d_c + d_h^R) l$（$d_h^R$ 来自解耦 RoPE key $\mathbf{k}_t^R$）。DeepSeek-V2 数值下 MLA/MHA $\approx 1/57$（减少约 98.2%）。成立条件：$d_c \ll d_h n_h$，且 $W^{UK}/W^{UV}$ 在推理时可被吸收。
  • 摘要 93.3% 的 baseline 是 DeepSeek 67B（GQA），不是同配置 MHA。同配置 MHA 下 MLA 的减少约 98.2%。引用 93.3% 时必须明确 baseline。
  • MLA 不解决 $O(N^2)$ 算力：注意力仍要对前序所有 token 算 q·k 内积，算力是 $O(N^2)$；MLA 只压缩存储。
  • MLA 不是 GQA 的极端形式：GQA 共享 K/V 头但每个被缓存的 K/V 仍是完整 head 维度 $d_h$；MLA 不共享头，而是把所有头的 K/V 压成一个潜向量再重建——机制完全不同。
  • K3 的两处改动：（a）对所有 MLA 层用 NoPE（不施加 RoPE），免去解耦 RoPE 与扩展上下文时的频率调整；（b）加 input-dependent full-rank output gate $\mathbf{y}_t = W^O[\mathrm{Sigmoid}(W^g \mathbf{x}_t) \odot \tilde{\mathbf{o}}_t]$，$W^g$ 满秩，让每个 token 调制从全局注意力读出的通道。对应 config.json 中 mla_use_nope=true、mla_use_output_gate=true。
