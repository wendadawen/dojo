Gated DeltaNet

把 DeltaNet 的"精准覆写单个 key-value"与 Mamba2 的"标量衰减门快速遗忘全局"统一进一个递归公式的线性注意力模型，让模型既能精确改写记忆又能快速清空过时段落。

基于 Yang, Kautz & Hatamizadeh, ICLR 2025（arXiv:2412.06464）· 2026-08-09

是什么

Gated DeltaNet（论文标题 "Gated Delta Networks"，缩写 GDN）是一种线性注意力递归模型，它的递归公式是 $S_t = S_{t-1}(\alpha_t(I - \beta_t k_t k_t^\top)) + \beta_t v_t k_t^\top$。它的前置概念是 Delta 规则与 DeltaNet（精准覆写机制）和 线性注意力（固定大小递归状态）。Mamba2 的标量衰减门 $\alpha_t$ 和 DeltaNet 的 delta 规则 $I - \beta_t k_t k_t^\top$ 在这个公式里同时出现——前者控全局遗忘，后者控单点覆写。

为什么需要它

  • DeltaNet 能精准覆写但缺全局遗忘。DeltaNet 的 delta 规则只擦除当前 key 一个方向的旧值，要清空整段过时记忆（比如上下文切换）需逐 key 串行擦除，无法一步完成。论文 §2.3 说它 "lacks the ability to rapidly clear outdated information, particularly during context switches"。
  • Mamba2 能快速遗忘但缺选择性。Mamba2 的标量 $\alpha_t$ 一步衰减整张状态，但所有 key-value 关联按同一比例缩小，不区分哪个更重要。论文 §2.2 说它 "does not account for the varying importance of different key-value associations"。
  • 两者互补，结合后比单独用任何一个都好。论文 §1 原文 "gating enables rapid memory erasure while the delta rule facilitates targeted updates"。1.3B/100B tokens 训练上 Gated DeltaNet 的 PPL 与常识推理均优于 DeltaNet 与 Mamba2；number-in-haystack 检索 S-NIAH-2 4K 上 Gated DeltaNet = 92.2，远超 DeltaNet = 18.6。

核心直觉

  • $\alpha_t$ 与 $\beta_t$ 职责不重叠。$\alpha_t$ 是数据相关标量衰减门（$\alpha_t = \sigma(W_\alpha x_t) \in (0,1)$），控整张 $S_{t-1}$ 的全局衰减；$\beta_t$ 是数据相关标量写入强度（$\beta_t = \sigma(W_\beta x_t) \in (0,1)$），控当前 $k_t$ 方向新旧值的混合比例。两者都是标量、都由 sigmoid 产出，但作用对象不同。
  • "先衰减后擦写"。因为 $\alpha_t$ 是标量可与矩阵交换，公式可读作：先把整张 $S_{t-1}$ 乘 $\alpha_t$ 衰减，再用 $I - \beta_t k_t k_t^\top$ 擦除 $k_t$ 方向，最后写入 $\beta_t v_t k_t^\top$。$\alpha_t$ 衰减所有方向，delta 规则只擦 $k_t$ 方向——两者在同一步里各司其职。
  • 退化揭示统一性。$\alpha_t \to 1$ 退化为 DeltaNet（无全局衰减）；$\beta_t \to 0$ 退化为 $\alpha_t S_{t-1}$（Mamba2 在无写入时的特殊情形）；$\alpha_t \to 0$ 一步清空整段历史。Gated DeltaNet 是 DeltaNet 与 Mamba2 的统一公式。
  • 并行训练靠 chunkwise 算法。递归形式 $S_t$ 依赖 $S_{t-1}$，串行计算无法用 GPU 并行。论文 §3.2 用扩展的 WY 表示把序列切成 chunk，chunk 内并行矩阵乘法（兼容 Tensor Core），chunk 间递归传状态。$\alpha_t$ 只做逐元素乘法，不破坏矩阵乘法结构。
  • $\alpha_t$ 是标量，KDA 把它改成 channel-wise。这是 Gated DeltaNet 与 Kimi K3 的 KDA 的关键区别——KDA 的 $\alpha_t$ 是向量（每 key 通道独立衰减率）且有 lower-bounded decay（限定 $\alpha > e^{-5}$ 以适配 BF16）。

关键结论与边界

  • Gated DeltaNet $\neq$ DeltaNet + 一个系数。$\alpha_t$ 使模型能一步衰减整段记忆（上下文切换），DeltaNet 要逐 key 擦除。S-NIAH-2 数字针检索上差距显著（92.2 vs 18.6）。
  • $\alpha_t$ 是数据相关的，不是固定常数。$\alpha_t = \sigma(W_\alpha x_t)$ 由当前输入决定本步衰减多少，这是它相对早期 data-independent decay（如 RetNet 的固定 $\gamma$）的区别。
  • $\alpha_t$ 是标量，不是 channel-wise。Gated DeltaNet 整张 $S$ 同速率衰减；KDA 才把 $\alpha_t$ 改成 channel-wise 向量。两者形式同源但设计不同，不能混为一谈。
  • Gated DeltaNet 不解决全局内容交互。任意两个远距离 token 的直接交互仍需标准注意力或混合架构（GDN + 滑动窗口注意力）。它也不解决 BF16 数值稳定性——KDA 才用 lower-bounded decay 解决。
  • 并行训练需要 chunk size 为 16 的倍数。Tensor Core 要求半精度矩阵乘法的维度为 16 的倍数，论文实现取 chunk size = 64。
