    Gated DeltaNet：把 Delta 规则的精准覆写与标量衰减门统一

    主要依据：Yang, Kautz & Hatamizadeh. "Gated Delta Networks: Improving Mamba2 with Delta Rule." ICLR 2025（arXiv:2412.06464）§3.1 Eq.8 给出 gated delta rule 公式；§3.2 给出 chunkwise 并行算法；§4 给出实验。DeltaNet 与 delta 规则的前置讲解见 Delta 规则与 DeltaNet。

    当一个语言模型在阅读一段长文档时，前面写了一段与当前问题无关的背景——模型需要"忘掉整段"重新聚焦。DeltaNet 的 delta 规则能精准覆写单个 key，但要逐 key 串行擦除整段过时记忆；线性注意力家族中的 Mamba2 标量衰减门能一步衰减整张状态，但无差别衰减所有 key-value 关联。能不能两者都要——既精准覆写单点、又快速遗忘全局？Gated DeltaNet（论文标题 "Gated Delta Networks"，缩写 GDN）的回答是：把两个机制塞进同一个递归公式。

    读完你能回答

    • DeltaNet 的 delta 规则在"快速遗忘整段记忆"上有什么缺陷？Gated DeltaNet 为什么要加 α_t？
    • 给定 $S_{t-1}$、$k_t$、$v_t$、$\alpha_t$、$\beta_t$，用 Gated DeltaNet 公式 $S_t = S_{t-1}(\alpha_t(I - \beta_t k_t k_t^\top)) + \beta_t v_t k_t^\top$ 手算一步更新，并说明 α_t、β_t 的职责分工。
    • Gated DeltaNet 在 $\alpha_t \to 1$ 与 $\beta_t \to 0$ 两种极端下分别退化为哪个模型？为什么？
    • Gated DeltaNet 的并行训练算法解决什么问题？为什么不能直接串行递归？
    • Gated DeltaNet 与 KDA 在 α_t 的设计上有什么关键区别？

    最容易误解

    • "Gated DeltaNet 的 α_t 和 KDA 的 α_t 是同一个东西"——Gated DeltaNet 的 α_t 是标量（每步一个衰减率作用于整张 S），KDA 的 α_t 是 channel-wise 向量（每 key 通道独立）且有 lower-bounded decay。
    • "α_t 和 β_t 都是遗忘门，职责重叠"——α_t 控全局衰减（整张 S 按比例缩小），β_t 控单点覆写强度（当前 k_t 方向新旧值混合比例），职责不重叠。
    • "Gated DeltaNet 只是 DeltaNet 加了个 α_t 系数，没本质区别"——α_t 使 Gated DeltaNet 能一步衰减整段记忆（上下文切换），DeltaNet 要逐 key 擦除；S-NIAH-2 数字针检索上 Gated DeltaNet 显著优于 DeltaNet。
    • "α_t 是固定常数衰减率"——α_t 是数据相关的（α_t = σ(W_α x_t)），模型根据当前输入决定本步衰减多少，这是它相对早期 data-independent decay（如 RetNet 的固定 γ）的区别。

    DeltaNet 与 Mamba2 各自缺什么——gating 与 delta 规则的互补性

    Gated DeltaNet 不是凭空设计的，它来自一个观察：DeltaNet 与 Mamba2 各自解决线性注意力"记不清"问题的一半，但都不完整。要理解 Gated DeltaNet，先看这两个"半成品"各缺什么。

    DeltaNet 的 delta 规则把线性注意力的纯加性累加替换为"先擦除后写入"：

    $$S_t = S_{t-1}(I - \beta_t k_t k_t^\top) + \beta_t v_t k_t^\top\qquad\text{（DeltaNet，F4）}$$

    它的核心机制是方向擦除——矩阵 $I - \beta_t k_t k_t^\top$ 只擦除当前 $k_t$ 一个方向的旧值，保留与 $k_t$ 正交的其他方向。这让 DeltaNet 能精准覆写单个 key-value 关联（比如"把 key=k_2 对应的 value 从 v_old 改成 v_new"）。但精准也意味着局限：如果要清空整段过时记忆（比如模型从一段背景介绍切换到新话题），需要逐个 key 串行擦除，无法一步完成。Yang 2025 ICLR §2.3 原文说 DeltaNet "lacks the ability to rapidly clear outdated information, particularly during context switches"[C1]。delta 规则与 DeltaNet 的完整讲解见 Delta 规则与 DeltaNet。

    Mamba2 走另一条路——用标量衰减门 α_t 全局衰减整张状态：

    $$S_t = \alpha_t S_{t-1} + v_t k_t^\top\qquad\text{（Mamba2，F3）}$$

    α_t 是一个标量，整张 $S_{t-1}$ 被乘以同一个 α_t。当 α_t 接近 0 时，一步就能清空整段记忆（"上下文切换"）。但 Mamba2 的衰减是无差别的——所有 key-value 关联按同一比例缩小，不区分哪个 key 更重要。Yang 2025 ICLR §2.2 原文说 "this approach does not account for the varying importance of different key-value associations"[C2]。Mamba2 无独立概念页，本页只引用此公式作对比，不展开状态空间模型理论。

    模型递归更新规则擦除机制写入机制缺什么
    DeltaNet[F4]$S_t = S_{t-1}(I - \beta_t k_t k_t^\top) + \beta_t v_t k_t^\top$方向擦除（只擦 $k_t$ 方向）新旧值凸插值无法快速清空整段
    Mamba2[F3]$S_t = \alpha_t S_{t-1} + v_t k_t^\top$标量全局衰减（整张 S）加性累加无法选择性擦除单点
    Gated DeltaNet[F1]$S_t = S_{t-1}(\alpha_t(I - \beta_t k_t k_t^\top)) + \beta_t v_t k_t^\top$标量衰减 + 方向擦除（双重）新旧值凸插值—（两者的统一）

    两者互补：gating（α_t）擅长快速遗忘全局，delta 规则（$I - \beta_t k_t k_t^\top$）擅长精准覆写单点。Yang 2025 ICLR §1 原文 "we observe that these mechanisms are complementary—gating enables rapid memory erasure while the delta rule facilitates targeted updates"[C7]。Gated DeltaNet 的工作就是把两者塞进同一个递归公式。

    Gated DeltaNet 的公式与符号——α_t 衰减与 β_t 擦写如何协同

    Gated DeltaNet 的递归更新公式（Yang 2025 ICLR §3.1 Eq.8[C3]）：

    $$\boxed{\,S_t = S_{t-1}\bigl(\alpha_t(I - \beta_t k_t k_t^\top)\bigr) + \beta_t v_t k_t^\top\,}\qquad\text{（Gated DeltaNet，F1）}$$

    公式出现前先说清它解决的问题：上一章看到 DeltaNet 缺全局遗忘、Mamba2 缺方向擦除。Gated DeltaNet 把 Mamba2 的标量 α_t 嵌进 DeltaNet 的 $I - \beta_t k_t k_t^\top$ 擦除项前面，得到 $\alpha_t(I - \beta_t k_t k_t^\top)$——先衰减整张状态、再做 delta 擦写。

    每个符号：

    • $S_t \in \mathbb{R}^{d_v \times d_k}$：第 $t$ 步的矩阵状态（记忆矩阵）。行数 $d_v$ 对应 value 维度，列数 $d_k$ 对应 key 维度。本页默认 $d_v = d_k = d$。
    • $S_{t-1}$：上一步的状态，公式右侧第一个因子。
    • $I \in \mathbb{R}^{d_k \times d_k}$：单位矩阵，与 $k_t$ 同维。
    • $k_t \in \mathbb{R}^{d_k}$：第 $t$ 步的 key 向量，由输入 $x_t$ 经投影 $k_t = W_K x_t$ 得到。
    • $v_t \in \mathbb{R}^{d_v}$：第 $t$ 步的 value 向量，由 $v_t = W_V x_t$ 得到。
    • $q_t \in \mathbb{R}^{d_k}$：第 $t$ 步的 query 向量，由 $q_t = W_Q x_t$ 得到；输出 $o_t = S_t q_t$。
    • $\alpha_t = \sigma(W_\alpha x_t) \in (0, 1)$：数据相关标量衰减门，由 sigmoid 输出。α_t 控制整张 $S_{t-1}$ 的全局衰减——模型根据当前输入 $x_t$ 决定本步衰减多少[C4]。
    • $\beta_t = \sigma(W_\beta x_t) \in (0, 1)$：数据相关标量写入强度，由 sigmoid 输出。β_t 控制当前 $k_t$ 方向新旧值的混合比例。
    • $\sigma(z) = 1/(1 + e^{-z})$：sigmoid 函数。
    • $W_Q, W_K, W_V, W_\alpha, W_\beta$：可学习参数。

    形状检查（验证维度自洽）：$k_t k_t^\top$ 是 $(d_k, 1) \times (1, d_k) = (d_k, d_k)$；$I - \beta_t k_t k_t^\top$ 是 $(d_k, d_k)$；$\alpha_t$ 是标量，$\alpha_t(I - \beta_t k_t k_t^\top)$ 仍是 $(d_k, d_k)$；$S_{t-1}(\alpha_t(I - \beta_t k_t k_t^\top))$ 是 $(d_v, d_k) \cdot (d_k, d_k) = (d_v, d_k)$；$\beta_t v_t k_t^\top$ 是标量 $\times (d_v, 1) \times (1, d_k) = (d_v, d_k)$；两项相加形状一致，结果 $(d_v, d_k)$。检查通过。

    α_t 与 β_t 的职责分工

    α_t 与 β_t 不是同一个东西，职责不重叠[C4]：

    • α_t 控全局衰减：$\alpha_t$ 是标量，作用于整张 $S_{t-1}$。无论 $S_{t-1}$ 里存了多少 key-value 关联，全部按 α_t 比例缩小。α_t → 0 时一步清空整段记忆（上下文切换），α_t → 1 时几乎不衰减。
    • β_t 控单点覆写：$\beta_t$ 只影响当前 $k_t$ 一个方向。$I - \beta_t k_t k_t^\top$ 只擦 $k_t$ 方向的旧值，$\beta_t v_t k_t^\top$ 写入新值。β_t → 1 时完全覆写 $k_t$ 方向，β_t → 0 时几乎不擦不写。这与 DeltaNet 的 β_t 完全一致（见 Delta 规则关于 β_t 职责的讲解）。

    论文 §3.1 原文："the data-dependent gating term $\alpha_t \in (0,1)$ controls state decay"；§1 原文："gating enables rapid memory erasure while the delta rule facilitates targeted updates"。

    "先衰减后擦写"的等价解读

    Gated DeltaNet 公式的乘法顺序 $\alpha_t(I - \beta_t k_t k_t^\top)$ 有明确的语义。因为 $\alpha_t$ 是标量，它可以与矩阵交换：

    $$S_{t-1}\bigl(\alpha_t(I - \beta_t k_t k_t^\top)\bigr) = \alpha_t \cdot S_{t-1}(I - \beta_t k_t k_t^\top).$$

    所以 Gated DeltaNet 的一步更新可以读作"先衰减、再擦写"[C5]：

    1. 衰减：$\alpha_t \cdot S_{t-1}$——整张状态乘 α_t，所有 key-value 关联按比例缩小。
    2. 擦除：$(\alpha_t S_{t-1})(I - \beta_t k_t k_t^\top)$——在已衰减的状态上，擦除 $k_t$ 方向的旧值。
    3. 写入：$+ \beta_t v_t k_t^\top$——写入新值。
    Gated DeltaNet 一步更新的三步语义（α_t 标量可交换）：

  S_{t-1} ──[① 衰减]──► α_t · S_{t-1} ──[② 擦除 k_t 方向]──►
                             (整张按 α_t 缩小)        (I - β_t k_t k_t^T)
                                                          │
                                                          ▼
                                          ──[③ 写入]──► S_t
                                              + β_t v_t k_t^T

  DeltaNet 只有 ②③（无 ① 全局衰减）
  Mamba2 只有 ① + 加性写入（无 ② 方向擦除）

    前提条件：α_t 是标量（可与矩阵交换）。若 α_t 是 channel-wise 向量（如 KDA 的情形），则不能这样交换——这是 Gated DeltaNet 与 KDA 的关键区别，与 KDA 的关系一章详述。

    两个快速边界检查。第一，若 $\alpha_t = 1$，则 $S_t = S_{t-1}(I - \beta_t k_t k_t^\top) + \beta_t v_t k_t^\top$——退化为 DeltaNet（无全局衰减）。第二，若 $\beta_t = 0$，则 $S_t = S_{t-1}(\alpha_t \cdot I) + 0 = \alpha_t S_{t-1}$——退化为 Mamba2 在 $v_t = 0$ 时的特殊情形（只衰减不写入）。退化关系在下一章详细讨论。

    手算 Gated DeltaNet 一步更新——三模型在同一序列上并排对比

    教学示例。 取 $d = 2$ 维，3 步序列。前两步在两个正交方向各写一个关联，第 3 步覆写 $k_1$ 方向并加 $\alpha < 1$ 全局衰减——这样能同时看到 α_t 衰减非 $k_t$ 方向、β_t 覆写 $k_t$ 方向。key 已归一化（$\|k_1\| = \|k_2\| = 1$）。

    步 $t$$k_t$$v_t$$\alpha_t$$\beta_t$意图
    1$(1, 0)^\top$$(1, 0)^\top$$1$$1$在 $k_1$ 方向写 $v_1$
    2$(0, 1)^\top$$(0, 1)^\top$$1$$1$在正交方向 $k_2$ 写 $v_2$
    3$(1, 0)^\top = k_1$$(0, 1)^\top$$0.5$$1$覆写 $k_1$ 方向（β=1），同时全局衰减（α=0.5）

    第 1 步：$S_0 = 0$，$k_1 = (1, 0)^\top$，$v_1 = (1, 0)^\top$，$\alpha_1 = 1$，$\beta_1 = 1$。

    $$k_1 k_1^\top = \begin{pmatrix}1 \\ 0\end{pmatrix}\begin{pmatrix}1 & 0\end{pmatrix} = \begin{pmatrix}1 & 0 \\ 0 & 0\end{pmatrix},\qquad I - \beta_1 k_1 k_1^\top = \begin{pmatrix}0 & 0 \\ 0 & 1\end{pmatrix}.$$

    $\alpha_1(I - \beta_1 k_1 k_1^\top) = 1 \cdot \begin{pmatrix}0 & 0 \\ 0 & 1\end{pmatrix} = \begin{pmatrix}0 & 0 \\ 0 & 1\end{pmatrix}$。$S_0$ 乘它为 0；$\beta_1 v_1 k_1^\top = \begin{pmatrix}1 & 0 \\ 0 & 0\end{pmatrix}$。所以：

    $$S_1 = 0 + \begin{pmatrix}1 & 0 \\ 0 & 0\end{pmatrix} = \begin{pmatrix}1 & 0 \\ 0 & 0\end{pmatrix}.$$

    第 2 步：$k_2 = (0, 1)^\top$（与 $k_1$ 正交），$v_2 = (0, 1)^\top$，$\alpha_2 = 1$，$\beta_2 = 1$。

    $$I - \beta_2 k_2 k_2^\top = \begin{pmatrix}1 & 0 \\ 0 & 0\end{pmatrix},\qquad S_1 \cdot \alpha_2(I - \beta_2 k_2 k_2^\top) = \begin{pmatrix}1 & 0 \\ 0 & 0\end{pmatrix}\begin{pmatrix}1 & 0 \\ 0 & 0\end{pmatrix} = \begin{pmatrix}1 & 0 \\ 0 & 0\end{pmatrix}.$$

    $\beta_2 v_2 k_2^\top = \begin{pmatrix}0 & 0 \\ 0 & 1\end{pmatrix}$。所以：

    $$S_2 = \begin{pmatrix}1 & 0 \\ 0 & 0\end{pmatrix} + \begin{pmatrix}0 & 0 \\ 0 & 1\end{pmatrix} = \begin{pmatrix}1 & 0 \\ 0 & 1\end{pmatrix}.$$

    注意 $S_2$ 在两个正交方向各存了一个关联——查询 $k_1$ 返回 $v_1 = (1, 0)^\top$，查询 $k_2$ 返回 $v_2 = (0, 1)^\top$。这一步与 DeltaNet 完全一致（因为 $\alpha_2 = 1$）。

    第 3 步（关键步）：$k_3 = (1, 0)^\top = k_1$，$v_3 = (0, 1)^\top$，$\alpha_3 = 0.5$，$\beta_3 = 1$。这一步同时做两件事——用 β=1 覆写 $k_1$ 方向（delta 规则），用 α=0.5 衰减整张 $S_2$（全局门）。

    $$I - \beta_3 k_3 k_3^\top = \begin{pmatrix}0 & 0 \\ 0 & 1\end{pmatrix},\qquad \alpha_3(I - \beta_3 k_3 k_3^\top) = 0.5 \cdot \begin{pmatrix}0 & 0 \\ 0 & 1\end{pmatrix} = \begin{pmatrix}0 & 0 \\ 0 & 0.5\end{pmatrix}.$$

    $$S_2 \cdot \alpha_3(I - \beta_3 k_3 k_3^\top) = \begin{pmatrix}1 & 0 \\ 0 & 1\end{pmatrix}\begin{pmatrix}0 & 0 \\ 0 & 0.5\end{pmatrix} = \begin{pmatrix}0 & 0 \\ 0 & 0.5\end{pmatrix}.$$

    $\beta_3 v_3 k_3^\top = \begin{pmatrix}0 \\ 1\end{pmatrix}\begin{pmatrix}1 & 0\end{pmatrix} = \begin{pmatrix}0 & 0 \\ 1 & 0\end{pmatrix}$。合起来：

    $$S_3 = \begin{pmatrix}0 & 0 \\ 0 & 0.5\end{pmatrix} + \begin{pmatrix}0 & 0 \\ 1 & 0\end{pmatrix} = \begin{pmatrix}0 & 0 \\ 1 & 0.5\end{pmatrix}.$$

    三模型在同一序列上的结果对比

    现在把 Gated DeltaNet 与 DeltaNet（$\alpha = 1$）、Mamba2（$\beta = 0$，只衰减不写入）在第 3 步的结果并排对比：

    模型第 3 步公式$S_3$$S_3 k_3$（查 $k_1$ 方向）$S_3 k_2$（查 $k_2$ 方向）
    DeltaNet[F4]$S_2(I - k_3 k_3^\top) + v_3 k_3^\top$$\begin{pmatrix}0 & 0 \\ 1 & 1\end{pmatrix}$$(0, 1)^\top = v_3$$(0, 1)^\top = v_2$（未衰减）
    Gated DeltaNet[F1]$S_2(0.5(I - k_3 k_3^\top)) + v_3 k_3^\top$$\begin{pmatrix}0 & 0 \\ 1 & 0.5\end{pmatrix}$$(0, 1)^\top = v_3$$(0, 0.5)^\top$（衰减到一半）
    Mamba2（β=0 特殊）[F3]$0.5 \cdot S_2$（$\beta = 0$，无写入）$\begin{pmatrix}0.5 & 0 \\ 0 & 0.5\end{pmatrix}$$(0.5, 0)^\top$（衰减，未覆写）$(0, 0.5)^\top$（衰减）

    三个关键观察：

    • Gated DeltaNet 与 DeltaNet 查 $k_3$ 都返回 $v_3$：因为 $\beta_3 = 1$ 完全覆写了 $k_3$ 方向，α_t 的衰减不影响"刚写入的新值"（$\beta_t v_t k_t^\top$ 这一项不被 α_t 衰减）。这是 delta 规则精准覆写的体现。
    • Gated DeltaNet 查 $k_2$ 返回 $(0, 0.5)^\top$ 而 DeltaNet 返回 $(0, 1)^\top$：$k_2$ 方向与 $k_3$ 正交，delta 规则不擦它，但 α_t = 0.5 把它衰减了一半。这正是 α_t 的作用——衰减非 $k_t$ 方向的旧关联。
    • Mamba2 查 $k_3$ 返回 $(0.5, 0)^\top \neq v_3$：Mamba2 没有 delta 规则，无法覆写 $k_3$ 方向，只能把旧的 $v_1 = (1, 0)^\top$ 衰减到 $(0.5, 0)^\top$。这是 Mamba2 缺方向擦除的体现。

    这个例子把"Gated DeltaNet = DeltaNet 的精准覆写 + Mamba2 的全局衰减"具体化了：$k_3$ 方向被精准覆写（像 DeltaNet），$k_2$ 方向被全局衰减（像 Mamba2），两者在同一步里各司其职。

    展开：Gated DeltaNet 第 3 步的"先衰减后擦写"逐步代入

    用 C5 的等价形式 $S_3 = \alpha_3 \cdot S_2(I - \beta_3 k_3 k_3^\top) + \beta_3 v_3 k_3^\top$ 分三步验证：

    ① 衰减：$\alpha_3 \cdot S_2 = 0.5 \cdot \begin{pmatrix}1 & 0 \\ 0 & 1\end{pmatrix} = \begin{pmatrix}0.5 & 0 \\ 0 & 0.5\end{pmatrix}$。整张 $S_2$ 被乘 0.5。

    ② 擦除：$(\alpha_3 S_2)(I - \beta_3 k_3 k_3^\top) = \begin{pmatrix}0.5 & 0 \\ 0 & 0.5\end{pmatrix}\begin{pmatrix}0 & 0 \\ 0 & 1\end{pmatrix} = \begin{pmatrix}0 & 0 \\ 0 & 0.5\end{pmatrix}$。擦掉 $k_3$ 方向（第一列），保留 $k_2$ 方向（衰减后的 0.5）。

    ③ 写入：$+ \beta_3 v_3 k_3^\top = \begin{pmatrix}0 & 0 \\ 1 & 0\end{pmatrix}$。写入新值 $v_3$ 到 $k_3$ 方向。

    合起来 $S_3 = \begin{pmatrix}0 & 0 \\ 0 & 0.5\end{pmatrix} + \begin{pmatrix}0 & 0 \\ 1 & 0\end{pmatrix} = \begin{pmatrix}0 & 0 \\ 1 & 0.5\end{pmatrix}$，与紧凑公式一致。这一步展示"先衰减后擦写"的语义：α_t 先把整张状态缩小，delta 规则再在缩小的状态上擦写 $k_3$ 方向。

    完成本章后，用下面几个问题检查自己是否跟上：

    本章手算验证了公式与 α_t、β_t 的协同。但公式在极端下退化为哪个模型、训练时如何并行——下一章看退化关系与并行训练算法。

    退化关系与并行训练算法——为什么训练不能直接串行递归

    Gated DeltaNet 的退化

    把 $\alpha_t$ 和 $\beta_t$ 推到极端，看 Gated DeltaNet 分别退化为哪个模型[F2]。这是验证理解的最简方式。

    • $\alpha_t \to 1$：$S_t = S_{t-1}(1 \cdot (I - \beta_t k_t k_t^\top)) + \beta_t v_t k_t^\top = S_{t-1}(I - \beta_t k_t k_t^\top) + \beta_t v_t k_t^\top$——退化为 DeltaNet（无全局衰减，只有方向擦写）。
    • $\beta_t \to 0$：$S_t = S_{t-1}(\alpha_t \cdot I) + 0 = \alpha_t S_{t-1}$——退化为 Mamba2 在 $v_t = 0$ 时的特殊情形（只衰减不写入）。注意完整 Mamba2 还有 $+ v_t k_t^\top$ 写入项，Gated DeltaNet 在 $\beta_t = 0$ 时连 delta 写入也关闭了。
    • $\alpha_t \to 0$：$S_t = S_{t-1}(0) + \beta_t v_t k_t^\top = \beta_t v_t k_t^\top$——清空所有历史，只保留当前步的写入。这是"上下文切换"的极端：一步忘掉全部过去。

    退化关系揭示 Gated DeltaNet 是 DeltaNet 与 Mamba2 的统一：DeltaNet 是 $\alpha_t = 1$ 的特例，Mamba2（无写入时）是 $\beta_t = 0$ 的特例，Gated DeltaNet 把两者统一进一个公式。

    并行训练算法——为什么不能直接串行递归

    Gated DeltaNet 的递归形式 $S_t$ 依赖 $S_{t-1}$，训练时要算整段序列的 $S_1, S_2, \ldots, S_L$，串行计算 $L$ 步无法利用 GPU 的并行能力。这在长序列上不可接受。

    Yang 2025 ICLR §3.2 给出 chunkwise 并行算法[C6]，思路是把序列切成大小为 $C$ 的 chunk（$C$ 通常取 64，且为 16 的倍数以用 Tensor Core）：

    • chunk 内：用扩展的 WY 表示（Bischof & Van Loan 1985）把递归展开为矩阵乘法，可并行计算。
    • chunk 间：递归传递 chunk 末尾的状态 $S_{[t]}$ 作为下一个 chunk 的初始状态。
    • 门控兼容性：α_t 只做逐元素乘法（标量乘矩阵），不破坏矩阵乘法结构，因此整个 chunkwise 形式仍兼容 Tensor Core GPU 优化。

    论文 §3.2 原文："the gating term only performs element-wise multiplication and does not affect the matrix multiplication structure, thus compatible with tensor core GPU optimization"。

    补充：WY 表示与 chunkwise 形式的作用（不展开推导）

    WY 表示（Bischof & Van Loan 1985）把 Householder 矩阵乘积 $\prod_i (I - \beta_i k_i k_i^\top)$ 写成紧凑形式 $I - \sum_i w_i k_i^\top$，使 chunk 内的累积擦除可表示为一次矩阵乘法。Yang 2025 ICLR §3.2 Eq.9-10 把 WY 表示扩展以纳入 α_t 衰减项，得到 $\mathbf{P}_{[t]}^r = \gamma_{[t]}^r(I - \sum_i w_i k_i^\top)$，其中 $\gamma_{[t]}^j = \prod_i \alpha_i$ 是局部累积衰减。这让 chunk 内计算全部归约为矩阵乘法，可用 Tensor Core 加速。本页不展开 UT 变换、前向替换等数值线性代数细节——它们属于独立的数值线性代数概念，Yang 2025 ICLR §3.2 与 DeltaNet 论文 §3（见 Delta 规则）已有完整论证。

    这个算法解决的核心问题是：让 Gated DeltaNet 在保持递归形式（推理时固定大小状态）的同时，训练时能像注意力一样并行计算。没有它，Gated DeltaNet 只能在短序列上用，无法扩展到 100B tokens 训练。

    代码：实现 Gated DeltaNet 递归并与 DeltaNet、Mamba2 对比 
    import numpy as np

# 教学示例：d=2 维，3 步序列，对比 Gated DeltaNet、DeltaNet、Mamba2
# 第 1-2 步在两个正交方向各写一个关联，第 3 步覆写 k_1 方向并加 alpha<1 全局衰减

d = 2
S0 = np.zeros((d, d))
I_mat = np.eye(d)

# 两个正交 key：k_1=(1,0), k_2=(0,1)
k1 = np.array([1.0, 0.0])
v1 = np.array([1.0, 0.0])
k2 = np.array([0.0, 1.0])
v2 = np.array([0.0, 1.0])
# 第 3 步用 k_3=k_1 覆写，新值 v_3=(0,1)
k3 = np.array([1.0, 0.0])
v3 = np.array([0.0, 1.0])

beta1, beta2, beta3 = 1.0, 1.0, 1.0
alpha3 = 0.5  # 第 3 步的全局衰减门

# === DeltaNet：alpha=1，纯 delta rule ===
def delta_step(S_prev, k, v, beta):
    kkT = np.outer(k, k)
    return S_prev @ (I_mat - beta * kkT) + beta * np.outer(v, k)

S_del = S0.copy()
S_del = delta_step(S_del, k1, v1, beta1)
S_del = delta_step(S_del, k2, v2, beta2)
S_del = delta_step(S_del, k3, v3, beta3)
print("DeltaNet S_3 =")
print(S_del)
print("  S_3 @ k_3 =", S_del @ k3, "(k_1 direction: rewritten to v_3)")
print("  S_3 @ k_2 =", S_del @ k2, "(k_2 direction: untouched by delta rule)")
print()

# === Gated DeltaNet：第 3 步 alpha=0.5, beta=1 ===
def gated_delta_step(S_prev, k, v, alpha, beta):
    kkT = np.outer(k, k)
    return S_prev @ (alpha * (I_mat - beta * kkT)) + beta * np.outer(v, k)

S_gdn = S0.copy()
S_gdn = gated_delta_step(S_gdn, k1, v1, alpha=1.0, beta=beta1)
S_gdn = gated_delta_step(S_gdn, k2, v2, alpha=1.0, beta=beta2)
S_gdn = gated_delta_step(S_gdn, k3, v3, alpha=alpha3, beta=beta3)
print("Gated DeltaNet S_3 (alpha_3=0.5, beta_3=1) =")
print(S_gdn)
print("  S_3 @ k_3 =", S_gdn @ k3, "(k_1 direction: rewritten to v_3 by delta rule)")
print("  S_3 @ k_2 =", S_gdn @ k2, "(k_2 direction: decayed to 0.5 by alpha gate)")
print()

# === Mamba2：第 3 步 alpha=0.5，无 delta 写入（beta=0 对照）===
def mamba2_step(S_prev, k, v, alpha):
    return alpha * S_prev + np.outer(v, k)

S_mamba = S0.copy()
S_mamba = mamba2_step(S_mamba, k1, v1, alpha=1.0)
S_mamba = mamba2_step(S_mamba, k2, v2, alpha=1.0)
S_mamba = alpha3 * S_mamba  # 第 3 步只衰减不写入（模拟 beta=0）
print("Mamba2 S_3 (alpha_3=0.5, no write) =")
print(S_mamba)
print("  S_3 @ k_3 =", S_mamba @ k3, "(k_1 direction: decayed, NOT rewritten)")
print("  S_3 @ k_2 =", S_mamba @ k2, "(k_2 direction: decayed)")
print()

# === 退化验证：alpha=1 时 Gated DeltaNet == DeltaNet ===
S_gdn_a1 = S0.copy()
for k, v, a, b in [(k1, v1, 1.0, beta1), (k2, v2, 1.0, beta2), (k3, v3, 1.0, beta3)]:
    S_gdn_a1 = gated_delta_step(S_gdn_a1, k, v, a, b)
print("Degradation alpha=1: Gated DeltaNet == DeltaNet:", np.allclose(S_gdn_a1, S_del))

# === 退化验证：beta=0 时 Gated DeltaNet == alpha * S_{t-1} ===
S_gdn_b0 = S0.copy()
S_gdn_b0 = gated_delta_step(S_gdn_b0, k1, v1, 1.0, beta1)
S_gdn_b0 = gated_delta_step(S_gdn_b0, k2, v2, 1.0, beta2)
S_prev = S_gdn_b0.copy()
S_gdn_b0 = gated_delta_step(S_gdn_b0, k3, v3, alpha3, 0.0)  # beta=0
print("Degradation beta=0: Gated DeltaNet == alpha * S_2:", np.allclose(S_gdn_b0, alpha3 * S_prev))

    与 KDA 的关系及实验效果——α_t 从标量到 channel-wise

    Gated DeltaNet 与 KDA 的 α_t 区别

    Gated DeltaNet 是 Kimi K3 的 KDA（Kimi Delta Attention） 的直接前身。KDA 基于 Gated DeltaNet 但做了三项改动[C8]，其中最关键的是 α_t 的设计（下表 KDA 列的 $g$ 为 log-decay，$\alpha_t = e^g$）：

    设计项Gated DeltaNetKDA
    α_t 形状标量（每步一个衰减率作用于整张 S）channel-wise 向量（每 key 通道一个独立衰减率）
    decay 参数化sigmoid（α_t ∈ (0,1)，无下界约束）scaled sigmoid（$g \in (g_{\min}, 0)$，lower-bounded）
    output gate（论文未特别强调 full-rank）full-rank output gate

    α_t 标量 vs channel-wise 的区别影响什么：Gated DeltaNet 的 α_t 是标量，整张 $S_{t-1}$ 按同一速率衰减——所有 key-value 关联同比例缩小，无法按通道差异化遗忘。KDA 的 α_t 是向量 $\alpha_t \in (0,1)^{d_k}$，每个 key 通道一个独立衰减率——$S_{t-1}$ 的不同行可以按不同速率衰减，模型能按通道差异化遗忘。这是 KDA 相对 Gated DeltaNet 的表达力提升。

    lower-bounded decay 的动机：Gated DeltaNet 的 α_t = σ(W_α x_t) ∈ (0,1) 可任意接近 0，累积衰减倒数可能溢出 BF16。KDA 把 decay 参数化改为 scaled sigmoid（限定 $g \in (g_{\min}, 0)$，K3 取 $g_{\min} = -5$），让 α_t 有下界 $e^{-5} \approx 0.0067$，使 chunkwise 形式的对角 tile 也能用 Tensor Core。这是工程稳定性改动，不影响递归形式本身。详见 KDA。

    公式差异：Gated DeltaNet 是 $S_t = S_{t-1}(\alpha_t(I - \beta_t k_t k_t^\top)) + \beta_t v_t k_t^\top$（α_t 标量可交换）；KDA 是 $S_t = (I - \beta_t k_t k_t^\top)\mathrm{Diag}(\alpha_t) S_{t-1} + \beta_t k_t v_t^\top$（α_t 向量不能与 $I - \beta_t k_t k_t^\top$ 交换，乘法顺序由 $\mathrm{Diag}(\alpha_t)$ 在左侧决定）。两者形式同源但 α_t 形状与参数化不同。

    现实应用

    Gated DeltaNet 已被多个实际模型采用：

    • Qwen3-Next 采用混合架构，75% 层用 Gated DeltaNet 作线性层、25% 层用 Gated Attention，以极小的全注意力预算补回精确检索能力[N4]。

    教学示例

    本页构造了一组教学数字，均非真实模型数据：

    • 手算主例子：$d = 2$ 维、$L = 3$ 步、key 归一化（$k_1 = (1,0)^\top, k_2 = (0,1)^\top$ 正交，$k_3 = k_1$）。$v_1 = (1,0)^\top, v_2 = (0,1)^\top, v_3 = (0,1)^\top$；$\beta_1 = \beta_2 = \beta_3 = 1$；$\alpha_1 = \alpha_2 = 1$，$\alpha_3 = 0.5$。构造目的：第 1-2 步在两个正交方向各写一个关联，第 3 步覆写 $k_1$ 方向（β=1）同时全局衰减（α=0.5），让 α_t 衰减非 $k_t$ 方向（$k_2$）的效果可见。沿用 Delta 规则概念页的 key/value 设定，便于读者复用已有手算经验。
    • 对照设定：DeltaNet 取 $\alpha = 1$（无衰减），Mamba2 取 $\beta = 0$（无写入，只衰减）。两者均非完整模型在真实序列上的行为，只为对照 Gated DeltaNet 的 α_t 与 β_t 各自贡献。

    教学解释与类比边界

    "先衰减后擦写"类比：把 $\alpha_t(I - \beta_t k_t k_t^\top)$ 解释为"先衰减整张、再擦写 $k_t$ 方向"是教学解释，服务于理解 C5 的等价关系。失效边界：(1) 仅当 α_t 是标量时可交换；KDA 的 channel-wise α_t 不能这样交换；(2) "先衰减"指 α_t 作用于 $S_{t-1}$，不包括 $\beta_t v_t k_t^\top$ 写入项（写入项不被 α_t 衰减）；(3) "擦写"仍受 $\beta_t$ 控制，$\beta_t < 1$ 时是部分擦除。正式判断以 F1 公式为准。

    "Gated DeltaNet = DeltaNet + Mamba2"类比：把 Gated DeltaNet 说成"DeltaNet 与 Mamba2 的统一"是教学解释，服务于理解退化关系 F2。失效边界：(1) Gated DeltaNet 不是两个模型的简单拼接，而是把 α_t 嵌进 delta 规则的擦除项前；(2) $\beta_t \to 0$ 退化为 Mamba2 在 $v_t = 0$ 的特殊情形，完整 Mamba2 还有 $+ v_t k_t^\top$ 写入项；(3) Gated DeltaNet 的训练算法与 Mamba2/DeltaNet 都不同（扩展 WY 表示）。

    教学简化及其限制

    • 手算取 $d_v = d_k = 2$。可推出：公式正确性与维度无关。不可推出：真实模型 $d = 64$ 或 $128$ 时的行为。
    • 手算取 $\alpha_t = 0.5$。可推出：α_t 衰减非 $k_t$ 方向的效果可见。不可推出：真实 $\alpha_t = \sigma(W_\alpha x_t)$ 的取值分布。
    • 不展开 WY 表示与 chunkwise 推导。可推出：chunkwise 算法存在且兼容 Tensor Core。不可推出：UT 变换、前向替换等数值线性代数细节。
    • 代码用 numpy 标量循环，只讲单头。可推出：公式正确性与单头更新规则。不可推出：训练效率与多头工程实现。
    • 不展开混合架构 H1/H2 与在线学习视角。可推出：GDN + SWA 的组成与在线学习目标存在。不可推出：混合架构设计与目标函数推导。
