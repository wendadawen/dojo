# 线性注意力教学大纲

## 0. 页面开头

### 钩子

如果你让一个标准 Transformer 写一本 50 万字的长篇小说，它在生成第 30 万个字时还要回头计算这个字与前 30 万个字的两两相似度——光是这一步注意力计算就要 9×10¹⁰ 次运算。线性注意力要解决的问题就是：让注意力不再随序列长度二次膨胀。

### 一句话解释

线性注意力把 softmax 注意力里的指数相似度 exp(q·k) 换成可分解的核函数 φ(q)·φ(k)，从而让计算量从 O(N²) 降到 O(N)，并使因果掩码下的注意力可写成与序列长度无关的固定大小递归状态。

### 学习承诺（与 scope.md 一致）

读完这一页，你应该能够：
- 指出 softmax 注意力的 O(N²) 瓶颈具体出在哪一步
- 用核函数 φ 和结合律解释线性注意力如何把 O(N²) 变成 O(N)
- 写出因果掩码下的递归形式 s_i、z_i 并说明为什么每步推理代价与序列长度无关
- 说明线性注意力相比 softmax 失去了什么、这个代价从公式哪里来

### 首个具体场景

用一个 N=3、d=2 的小例子贯穿全文：3 个 token、每个 key/value 是 2 维向量，手算 softmax 与 linear 两种注意力的差异。

### 与第一章的过渡

先看清"O(N²) 瓶颈到底卡在哪一步"，才能理解线性注意力为什么这样设计。

## 1. 章节设计

### S1：softmax 注意力的 O(N²) 瓶颈在哪一步

- 主要教学问题：标准 Transformer 的注意力为什么在长序列上慢？慢在哪一步？
- 对应范围：Q1、C1、F1
- 正文要点：
  - 给出 softmax 注意力公式 $V' = \mathrm{softmax}(QK^T/\sqrt{d})V$
  - 解释每个符号：N（序列长度）、d（每头维度）、Q/K/V（形状 N×d）
  - 用 N=3、d=2 的小例子展示 QK^T 是 3×3 矩阵——每对 token 都要算一次相似度
  - 关键观察：QK^T 这一步产生 N×N 矩阵，时间和空间都随 N 二次增长
  - 自回归推理的额外痛点：每生成一个新 token 要把历史 K、V 全留在 KV cache 中，cache 大小随 N 线性增长
- 讲解材料及职责：
  - 公式 F1：表达 Q、K、V 与注意力输出的关系
  - 数字例子（N=3、d=2）：让读者看见 3×3 矩阵的具体形状
  - ASCII 图示：展示 N×N 注意力矩阵的形状随 N 增长
- 前置知识安排：softmax 一句话提示（把任意实数分数转成和为 1 的正数概率），不展开
- 完成检查：
  - 给定 N=4、d=2，QK^T 是什么形状？这一步共需要算多少次内积？
  - 用一句话说明为什么 N 翻倍时 softmax 注意力计算量大约变成 4 倍
- 过渡：瓶颈已经定位在 QK^T 这一步。下一章要回答：能不能不构造 N×N 矩阵，直接得到 V'？

### S2：用核函数 φ 把相似度分解，再用结合律重排

- 主要教学问题：怎样在不构造 N×N 矩阵的前提下算出注意力？
- 对应范围：Q2、C2、C3、F2
- 正文要点：
  - 引入广义注意力定义 $V'_i = \frac{\sum_j \mathrm{sim}(Q_i, K_j) V_j}{\sum_j \mathrm{sim}(Q_i, K_j)}$，指出 softmax 只是 sim=exp(·) 的特例
  - 关键约束：sim 必须非负——分母作归一化用，为 0 或负就崩
  - 引入核分解假设：存在 φ 使 sim(q,k) = φ(q)·φ(k)
  - 用结合律重排：分子分母都把 φ(Q_i) 提到求和号外
  - 矩阵形式：(φ(Q)φ(K)^T)V = φ(Q)(φ(K)^T V)——先算 φ(K)^T V（与 N 无关的固定大小聚合），再与 φ(Q) 相乘
  - 复杂度从 O(N²d) 降到 O(N·d·d')，d' 为 φ 输出维度
  - 用 N=3、d=2 的小例子手算：选 φ(x)=x+1（保证非负的最简教学选择），展示 φ(K)^T V 是 2×2 矩阵而不是 3×3
- 讲解材料及职责：
  - 公式 F2：表达核分解与结合律重排
  - 数字例子（教学示例，φ(x)=x+1）：让读者看见"先聚合再查询"与"先算两两相似度"两种计算顺序的区别
  - ASCII 图示：展示两种计算顺序的依赖链差异
- 前置知识安排：矩阵乘法结合律一句话提示
- 完成检查：
  - 用一句话说明 sim 为什么必须非负
  - 写出 (φ(Q)φ(K)^T)V = ? 的重排结果
  - 解释为什么重排后时间复杂度与 N 成一次关系而不是二次
- 过渡：O(N) 的训练前向已经有了。但生成场景下还要每步重算 ∑φ(K)V^T 吗？下一章用因果掩码把递归形式挖出来。

### S3：因果掩码下变成固定大小的递归状态

- 主要教学问题：自回归生成时，线性注意力如何避免每步重算历史？
- 对应范围：Q3、C4、F3
- 正文要点：
  - 因果掩码一句话说明：第 i 个 query 只能看到前 i 个 key，用于自回归生成
  - 因果形式下第 i 个 query 的分母只对 j≤i 求和
  - 关键观察：分子 $\sum_{j \leq i} \phi(K_j) V_j^T$ 恰好是 i 的累积和，可递推
  - 定义 s_i = s_{i-1} + φ(K_i)V_i^T（attention memory，形状 d'×d），z_i = z_{i-1} + φ(K_i)（normalizer，形状 d'）
  - 输出 $V'_i = \frac{\phi(Q_i)^T s_i}{\phi(Q_i)^T z_i}$
  - 形状分析：s_i 是 d'×d 矩阵、z_i 是 d' 向量，都与 N 无关；每步推理代价 O(d·d')，与序列长度无关
  - 与 RNN 的关系：标题"Transformers are RNNs"指这种"固定状态 + 递推更新"形式，s_i、z_i 是两个隐藏状态；澄清 s_i 是 d'×d 矩阵而非向量，不等同于 LSTM 的 c_t
  - 用 N=3、d=2 的小例子手算递归：从 s_0=0 开始，逐步加上 φ(K_1)V_1^T、φ(K_2)V_2^T、φ(K_3)V_3^T，最后用 φ(Q_3)^T s_3 / (φ(Q_3)^T z_3) 算 V'_3
- 讲解材料及职责：
  - 公式 F3：表达递归更新
  - 数字例子（贯穿）：让读者手算 s_1、s_2、s_3 与 V'_3
  - ASCII 图示：展示递归状态如何随时间步更新
- 前置知识安排：因果掩码一句话说明
- 完成检查：
  - 写出 s_i 和 z_i 的递推式
  - 解释 s_i 的形状为什么与 N 无关
  - 说明生成第 100 个 token 时只需保留 s_99、z_99 两个状态，无需保留前 99 个 K、V
- 过渡：复杂度优势有了。但 softmax 为什么不能也这样重排？下一章回答代价从哪里来。

### S4：表达力代价从公式的哪里来

- 主要教学问题：线性注意力相比 softmax 失去了什么？为什么？
- 对应范围：Q4、C5、F4、F5
- 正文要点：
  - 关键事实：softmax 核 exp(q·k) 没有有限维正特征映射（特征映射是无穷维的），所以 softmax 注意力无法精确套用 F2 的重排
  - 线性注意力必须改用其它核：
    - Katharopoulos 选 φ(x)=elu(x)+1，保证 φ(x)>0，但直接定义了一个新核而非近似 softmax
    - Performer 选随机特征 φ(x) = exp(-‖x‖²/2)/√m · (exp(ω_1^T x),...,exp(ω_m^T x))，无偏近似 softmax 核但方差非零
  - 表达力损失的具体来源：softmax 的 exp 把"显著差异"指数放大、把"无关项"指数压制；线性核（如 elu+1）只是线性放大差异，没有这种"聚焦"能力
  - 用小例子对比：同一组 q、k 下，softmax 给最高相似度的权重可能是次高的 10×，而 elu+1 核只能给到 2×
  - 适用边界：N 小或表达力需求高时仍用 softmax；N ≫ d² 或需固定状态推理时用线性注意力
- 讲解材料及职责：
  - 公式 F4、F5：表达两种 φ 选择
  - 数字例子（教学示例）：让读者看见 softmax 与 elu+1 核在同一组输入下的权重分布差异
  - 对照表格：softmax 核、elu+1 核、Performer 随机特征核的关键性质对比
- 前置知识安排：无新前置
- 完成检查：
  - 用一句话说明为什么 softmax 不能精确线性化
  - 指出 elu+1 中"+1"的作用
  - 列出至少一个适用线性注意力、一个适用 softmax 的场景
- 过渡：四问已答完。最后回顾全文主线。
