# 线性注意力（Linear Attention）内容范围

## 1.1 概念含义

- 概念名称：线性注意力
- 英文名称：Linear Attention（也称 Linearized Attention）
- 常见缩写：无标准缩写；本文不引入缩写
- 一句话定义：把 softmax 注意力里的指数相似度换成"可分解为 φ(q)·φ(k) 的核函数"，从而让注意力的复杂度从 O(N²) 降到 O(N)，并使因果掩码下的注意力可写成固定大小的递归状态
- 正式定义（与权威来源一致）：对任意非负相似度函数 sim，广义注意力定义为 $V'_i = \frac{\sum_{j} \mathrm{sim}(Q_i, K_j) V_j}{\sum_{j} \mathrm{sim}(Q_i, K_j)}$；当 $\mathrm{sim}(q, k) = \phi(q)^T \phi(k)$ 可分解为某特征映射 $\phi$ 的内积时，称其为线性注意力（Katharopoulos et al. 2020, Eq.3–5）
- 本文采用的语境：以 Katharopoulos et al. 2020 的核分解 + 结合律重排 + 因果递归为主线，把 Performer（Choromanski et al. 2020）作为随机特征近似 softmax 核的另一种 φ 选择来对比，不展开 Performer 的随机特征理论细节
- 包括什么：
  - 标准 softmax 注意力的 O(N²) 瓶颈（C1）
  - 广义注意力定义与归一化分母（C2）
  - 用核函数 φ 重写并利用结合律重排计算顺序（C3）
  - 因果掩码下的递归形式 s_i, z_i 与常数时间推理（C4）
  - 表达力下降的代价与适用边界（C5）
- 不包括什么：
  - 多头机制、位置编码、训练优化器等与"线性化"无关的 Transformer 通用件（不影响线性注意力机制本身）
  - Delta rule、gated linear attention、Gated DeltaNet 等"在线性注意力递归状态上做更复杂写入"的后续工作（属于独立概念 delta-rule / gated-deltanet，由 K3 知识树单独建页）
  - FlashAttention 等对 softmax 注意力的 IO 优化（不改变复杂度阶，仍属 standard-attention 工程优化）
  - Linformer、Reformer、Sparse Transformer 等其它 O(N) 系方法（与本文方法路径不同：它们不重写注意力核，而是稀疏化或低秩近似注意力矩阵）
- 相邻概念：
  - 标准 softmax 注意力（standard-attention）：本文的对比对象，是 linear-attention 的前置概念；区别是 softmax 用 exp(q·k) 作相似度，无法分解为有限维 φ 内积
  - RNN：linear attention 在因果掩码下可重写为带两个隐藏状态的 RNN，但本文不展开 RNN 的一般理论
  - 核方法（kernel methods）：linear attention 是核方法在注意力上的应用；本文不展开核方法理论，只在需要时点明

## 1.2 学习目标

### Q1：标准 softmax 注意力为什么是 O(N²) 的？瓶颈在哪一步？

- 完成答案：读者应能指出 softmax 注意力公式中 `QK^T` 产生 N×N 矩阵，这一步的计算和存储都与序列长度 N 成二次关系；这是线性注意力要解决的原始问题
- 为什么是核心目标：不理解瓶颈在哪，就无法理解线性注意力在做什么、为什么这样设计
- 依赖内容：softmax 注意力公式、矩阵形状分析

### Q2：线性注意力如何用核函数 φ 和结合律把 O(N²) 变成 O(N)？

- 完成答案：读者应能用 φ 把 sim(q,k) 重写为 φ(q)·φ(k)，指出 (φ(Q)φ(K)^T)V 可由结合律改写为 φ(Q)(φ(K)^T V)，先算 φ(K)^T V（与 N 无关的固定大小聚合），再与 φ(Q) 相乘；并能解释为什么分母 ∑φ(K_j) 也要随之重排
- 为什么是核心目标：这是线性注意力的核心机制，回答"它到底是什么"
- 依赖内容：核函数定义、矩阵乘法结合律、归一化分母的处理

### Q3：因果掩码下，线性注意力如何变成一个固定大小的递归状态？

- 完成答案：读者应能写出 s_i = s_{i-1} + φ(K_i)V_i^T 与 z_i = z_{i-1} + φ(K_i)，并解释 V'_i = φ(Q_i)^T s_i / (φ(Q_i)^T z_i) 中 s_i、z_i 的形状与 N 无关；由此说明每生成一个新 token 的推理代价是 O(d²) 而非 O(Nd)
- 为什么是核心目标：这是 K3 知识树里 KDA 选择线性注意力家族的根本原因——它支持常数时间推理和固定大小 KV 状态
- 依赖内容：因果掩码、递归形式、形状分析

### Q4：线性注意力相比 softmax 注意力失去了什么？这个代价从公式哪里来？

- 完成答案：读者应能指出 softmax 的 exp(q·k) 没有（有限维）正特征映射，因此线性注意力必须改用近似核（如 elu+1），由此失去 softmax 的"指数放大显著差异、压制无关项"的能力；并指出这个限制来自"sim 必须非负且可分解为有限维 φ 内积"这一约束
- 为什么是核心目标：不理解代价就不能正确判断线性注意力的适用边界
- 依赖内容：核选择约束、softmax 与线性核的表达力对比

## 1.6 常见误解和适用边界

### 误解 1：线性注意力 = softmax 注意力的随机特征近似

- 错误理解：以为"线性注意力"特指 Performer 那种用随机特征近似 softmax 的方法
- 正确结论：Katharopoulos 的线性注意力是任意非负核 φ(q)·φ(k) 都成立的框架；Performer 只是其中一种 φ（随机特征近似 softmax 核）的选择。elu+1 是另一种 φ，它直接定义新核而不是近似 softmax
- 形成原因：两篇 2020 年论文同期出现，常被并列介绍
- 影响：Q2、Q4

### 误解 2：线性注意力"更快所以更好"

- 错误理解：因为复杂度从 O(N²) 降到 O(N)，所以线性注意力应全面取代 softmax 注意力
- 正确结论：在 N 较小时 softmax 仍更快（常数项更小、IO 友好），且 softmax 表达力更强；线性注意力在长序列（N ≫ d²）和自回归推理（需固定状态）场景才占优
- 形成原因：只看渐近复杂度忽略常数项与表达力代价
- 影响：Q4

### 误解 3：φ 可以任意选择

- 错误理解：以为任何函数都可作为 φ
- 正确结论：φ 必须保证 sim(q,k)=φ(q)^T φ(k) 非负，否则归一化分母可能为 0 或负，注意力不再合法。Katharopoulos 选 elu+1 正是为了保证 φ(x)>0
- 形成原因：忽略分母的作用
- 影响：Q2、Q4

### 误解 4：因果递归状态 = LSTM 的细胞状态

- 错误理解：以为 s_i、z_i 等同于 LSTM 的 c_t、h_t
- 正确结论：s_i 是 d×d 的外积累积矩阵（不是 d 维向量），形状和更新机制都不同；本文只借用 RNN 的"固定状态 + 递推更新"形式，不继承 LSTM 的门控结构
- 形成原因：标题"Transformers are RNNs"容易引起过度类比
- 影响：Q3

### 适用边界

- 概念解决什么问题：长序列注意力的 O(N²) 计算与存储瓶颈；自回归推理中 KV cache 随序列长度线性增长的问题
- 不解决什么问题：不解决表达力——线性注意力的表达力严格弱于 softmax；不解决训练稳定性；不解决位置编码
- 结论成立条件：φ 非负、序列足够长使 O(N²)→O(N) 的渐近优势显现、应用对表达力下降可容忍
- 条件不满足时：N 小或表达力需求高时仍用 softmax 注意力；φ 选不当会导致数值不稳定或训练崩溃
