Kimi Delta Attention（KDA）

Kimi K3 用的线性注意力变体——把 delta rule 的"先擦后写"加上每通道独立衰减的遗忘门，并把衰减率限定在有下界的区间，让长序列训练在 BF16 上数值稳定且能用 Tensor Core 加速。

基于 Kimi K3 Technical Report §2.1.1 与官方 config.json · 2026-08-09

1. 是什么

KDA 是 Kimi K3 在 93 层 backbone 中用于长序列混合的注意力机制，占了其中 69 层（其余 24 层是 深度教学里详述的 Gated MLA，负责全局内容交互）。它的核心是把 delta rule 的递归——"先擦除旧 key 方向、再写入新值"——叠加一个每通道独立衰减的遗忘门，并专门改了一处衰减率参数化让它在 BF16 上不溢出。它的前置概念是 delta rule（擦写机制）和 线性注意力（固定大小递归状态）。

2. 为什么需要它

  • softmax 的 KV cache 在 1M token 下装不下。标准注意力把每个历史 token 的 K、V 都存进 cache，单层单份就接近几十 GB 量级；K3 的 max_position_embeddings = 1,048,576，全 softmax 不可行。KDA 用固定大小的递归状态 $S \in \mathbb{R}^{128 \times 128}$（约 32 KB），与序列长度无关。
  • vanilla 线性注意力会"记不清"。纯加性累加 $S_t = S_{t-1} + \phi(k_t)v_t^\top$ 在序列长度超过状态维度时发生 key 碰撞，旧 token 被新写入覆盖。delta rule 的"先擦后写"解决了擦除，但没有显式的时间衰减——旧 token 只在被覆盖时才消失。
  • Kimi Linear 的 decay 参数化让 chunkwise 形式里 $1/\Gamma$ 无界。Kimi Linear 用 negative-softplus 把 log-decay 映射到 $(-\infty, 0)$，$\alpha$ 可任意接近 0，累积衰减 $\Gamma$ 可任意接近 0，倒数 $1/\Gamma$ 无界，BF16 会溢出。于是 chunkwise 形式的对角 tile 不得不走逐位置对计算，不能用 Tensor Core。

3. 核心直觉

  • 三步更新：先衰减、再擦除、再写入。每步先把旧状态 $S_{t-1}$ 按通道乘 $\alpha_t$ 衰减，再用 $I - \beta_t k_t k_t^\top$ 在 $k_t$ 方向擦除，最后加 $\beta_t k_t v_t^\top$ 写入新值。$\alpha_t$ 是每通道一个独立衰减率，$\beta_t$ 是标量写入强度，职责不同。
  • K3 的关键改动：scaled sigmoid 限定 log-decay 下界。把 decay logit $z$ 经 $g = g_{\min}\mathrm{Sigmoid}(e^A z)$ 映射到 $(g_{\min}, 0) = (-5, 0)$，于是 $\alpha = e^g \in (e^{-5}, 1) \approx (0.0067, 1)$。每个通道的最小留存率被钳在 $e^{-5}$，不会任意接近 0。代价是 KDA 无法"彻底遗忘"——最多遗忘到 $e^{-5}$。
  • 下界让对角 tile 也能用 Tensor Core。16-token tile 的累积衰减 $\Gamma > e^{-80}$，倒数 $1/\Gamma < e^{80} \approx 5.54 \times 10^{34}$ 落在 BF16 动态范围内。于是 chunkwise 形式里所有 tile（包括对角）都能用 dense matmul，消除 Kimi Linear 的 position-pair 逐对计算瓶颈。
  • full-rank output gate 与 chunkwise 并行。输出 $y = W_o[\mathrm{Sigmoid}(W_g x) \odot \mathrm{RMSNorm}(\tilde o)]$，$W_g$ 满秩（K3 把 Kimi Linear 的 low-rank 升级为 full-rank）。训练时序列切成 chunk，chunk 内并行 matmul、chunk 间递归传 $S$，把串行递归变成可并行执行。
  • K3 不全部用 KDA。93 层 = 69 KDA + 24 Gated MLA，3:1 交替，最后两层均为 Gated MLA。KDA 负责位置敏感 + 近因混合，MLA 负责全局内容交互。

4. 关键结论与边界

  • KDA $\neq$ DeltaNet。KDA 在 DeltaNet 基础上多了 channel-wise forget gate、lower-bounded decay、full-rank gate 三项。forget gate 在 delta 更新之前先衰减（由 Eq.1 的乘法顺序决定）。
  • K3 的 lower-bound 与 Kimi Linear 的 negative-softplus 不等价。前者 $g \in (-5, 0)$ 有下界、对角 tile 用 Tensor Core；后者 $g \in (-\infty, 0)$ 无下界、对角 tile 走 position-pair。这是 K3 相对 Kimi Linear 的关键改动。
  • KDA 不解决全局内容交互。任意两个远距离 token 的直接交互由 Gated MLA 负责（每 4 层一次）。KDA 也不负责跨设备状态同步（KCP）和 kernel 调度（FlashKDA），这些是 §5.1 的工程实现。
  • lower-bound 收益的前提是 $g_{\min}=-5$、tile=16、BF16 同时满足。三者同时满足时 $1/\Gamma < e^{80}$ 落在 BF16 范围内。若 $g_{\min}$ 更小或 tile 更大，$1/\Gamma$ 可能溢出，退回 Kimi Linear 的 position-pair 路径；若用 FP32 训练，negative-softplus 也能用但成本更高。
