    SigLIP

    正文 1,783 字 · 约 6 分钟阅读

    图文对比预训练用一批图像-文本对同时训练两个编码器：图像编码器把每张图映成一个向量，文本编码器把每段文字映成一个向量，训练要让配成对的图文向量互相靠近、不配对的互相远离；两个向量的相似度就是它们的点积。训练要最小化的那个目标量叫损失函数。主流做法把一批里每张图与每段文字的相似度组织成一个矩阵，在矩阵的两个方向上各做一次 softmax 归一化（把一组分数转成一组和为 $1$ 的概率），得到 softmax 对比损失。

    SigLIP 把 softmax 对比损失换成逐对的 sigmoid 损失：每一对图文各自算一个二分类代价（sigmoid 是 logistic 函数的别名，把实数压到 $0$ 到 $1$ 作为「配对」的概率），不再需要在整个批量的相似度上做归一化。损失因此不再依赖全局归一化，批量大小与损失的定义解耦，可以增大批量。

    1. 对比学习与 softmax 损失

    1.1 相似度与正负对

    两个编码器各输出一个向量，一张图一个、一段文字一个，维度相同。两个向量各自除以自身长度变成单位长度（这一步叫向量归一化），点积衡量它们有多接近，这个点积就是它们的相似度。softmax 把一组实数按指数加权归一化成一组和为 $1$ 的概率：$\mathrm{softmax}(a_k)=e^{a_k}/\sum_l e^{a_l}$。一批 $|\mathcal{B}|$ 对图文里，第 $i$ 张图和它配对的第 $i$ 段文字构成正对，和其余 $j\neq i$ 的图文组合都构成负对；做这个对比目标时假定不同图文的文本互不相关。

    1.2 softmax 对比损失与它的代价

    softmax 对比损失在两个方向上各做一次归一化：图像到文本方向，对第 $i$ 张图与所有文本的相似度做 softmax，它配对的那段文字概率越大损失越小；文本到图像方向，对第 $i$ 段文字与所有图像的相似度再做一次 softmax。两个方向取平均、取负对数就是损失。

    这个损失有全局视野的要求：数据分散在多台设备上时，要先用 all-gather（把各设备的数据汇总到每台设备）把嵌入（编码器输出的那批向量）收齐，才能算整批相似度。它还占内存：那个 $|\mathcal{B}|\times|\mathcal{B}|$ 的相似度矩阵要真的被算出来、留在内存里。它还数值不稳：直接算 softmax 的指数会溢出，通常要先减去输入的最大值再算，这又需要多过一遍整个批量。

    softmax 对比损失的公式

    $$ \mathcal{L}=-\frac{1}{2|\mathcal{B}|}\sum_{i=1}^{|\mathcal{B}|}\left(\log\frac{e^{t\,\mathbf{x}_i\cdot\mathbf{y}_i}}{\sum_{j=1}^{|\mathcal{B}|}e^{t\,\mathbf{x}_i\cdot\mathbf{y}_j}}+\log\frac{e^{t\,\mathbf{x}_i\cdot\mathbf{y}_i}}{\sum_{j=1}^{|\mathcal{B}|}e^{t\,\mathbf{x}_j\cdot\mathbf{y}_i}}\right) $$

    其中 $\mathbf{x}_i=\dfrac{f(I_i)}{\lVert f(I_i)\rVert_2}$ 是第 $i$ 张图的归一化向量，$\mathbf{y}_i=\dfrac{g(T_i)}{\lVert g(T_i)\rVert_2}$ 是它配对文本的归一化向量，$t=\exp(t')$ 是温度。

    2. 逐对的 sigmoid 损失

    2.1 损失函数与标签

    sigmoid 损失不跨对耦合，而是把学习问题变成所有图文组合上的二分类：每一对算一个打分，叫 logit——把这一对的相似度点积乘一个可学习温度、再加一个可学习偏置（两者都是随训练调整的标量）；配对的对标签为 $+1$、其余为 $-1$；把标签乘上 logit 送进 logistic 函数再取负对数，得到这一对的损失，损失越小表示这一对判定得越准；所有对的损失求和后除以批量大小，就是对这批的损失。

    logistic 函数（也叫 sigmoid）把任意实数压到 $0$ 到 $1$ 之间，$\sigma(s)=1/(1+e^{-s})$，常用来表示一个二分类判定为真的概率。对一个标签 $z\in\{+1,-1\}$ 的对，把 $z$ 乘上 logit 再取 $\sigma$，得到的正是「判定正确」的概率，取负对数就是这一对的损失，这一步和二分类的交叉熵是同一件事。

    从公式到伪代码
    1. 取一批 $|\mathcal{B}|$ 对图文，把图像、文本分别经编码器得到嵌入，再各自做 $l_2$ 归一化，得到 $\mathbf{z}^{\text{img}}$、$\mathbf{z}^{\text{txt}}$。
    2. 算相似度并缩放：$\text{logits}=\mathbf{z}^{\text{img}}\,(\mathbf{z}^{\text{txt}})^\top\cdot t+b$，其中 $t=e^{t'}$ 是温度、$b$ 是偏置。
    3. 构标签矩阵 $\text{labels}=2I-\mathbf{1}$：$I$ 是单位矩阵、$\mathbf{1}$ 是全 $1$ 矩阵，得到对角为 $+1$（配对）、其余为 $-1$。
    4. 每一对取 $-\log\sigma(\text{labels}\odot\text{logits})$（$\odot$ 是逐元素相乘），所有对求和后除以批量大小：

    $$ \mathcal{L}=-\frac{1}{|\mathcal{B}|}\sum_{i=1}^{|\mathcal{B}|}\sum_{j=1}^{|\mathcal{B}|}\log\sigma\big(z_{ij}\,(t\,\mathbf{x}_i\cdot\mathbf{y}_j+b)\big) $$

    其中 $\mathbf{x}_i$、$\mathbf{y}_j$ 是第 $i$ 张图、第 $j$ 段文字的单位长度向量 $(\mathbf{z}^{\text{img}}_i$、$\mathbf{z}^{\text{txt}}_j)$，$z_{ij}$ 是标签。

    2.2 温度与偏置项

    logit 是相似度经缩放后的打分。相似度点积乘上一个可学习的温度 $t=e^{t'}$；$t'$ 初始化为 $\log 10$，也就是 $t$ 初始为 $10$，之后的取值随训练调整。

    一批里负对的数量是正对的 $|\mathcal{B}|-1$ 倍，初始化时绝大多数对都是负对，它们的损失主导整个目标，于是最初的优化步长很大、要用来纠正这个偏差。为缓解这一点，再加一个可学习的偏置 $b$，初始化为 $-10$，把 logit 整体压到接近负值，让训练从一个接近先验的状态起步；$b$ 与 $t'$ 都随训练更新。

    去掉偏置、或把它的初始化改成 $0$，结果都变差；初始化 $-10$ 一直更好。

    2.3 一个批量手算一轮

    取四对图文，用四对 2 维小向量走一遍：三个正对的损失是 $0.6931$，第三个正对是 $0.9130$，负对的 logit 很负、损失接近 $0$；逐对求和除以批量大小就是整批的损失。

    四对图文的一次手算
    1. 图像向量取四个：$(1,0)$、$(0,1)$、$(0.6,0.8)$、$(-1,0)$；文本向量取四个：$(1,0)$、$(0,1)$、$(0.8,0.6)$、$(-1,0)$。都已是单位长度。
    2. 算相似度矩阵（图像向量与文本向量两两的点积），乘温度 $10$ 加偏置 $-10$，得到 4×4 的 logits。
    3. 对角是正对、标签 $+1$，其余是负对、标签 $-1$。
    4. 每对取 $-\log\sigma(\text{标签}\times\text{logit})$：四个正对的损失是 $0.6931$、$0.6931$、$0.9130$、$0.6931$；负对中损失最大的两个是 $0.1269$、$0.0181$，其余负对的 logit 很负、损失接近 $0$。
    5. 十六对损失求和后除以批量大小 $|\mathcal{B}|=4$，整批损失是 $0.8207$。
    import math  # 只用标准库
Zimg = [[1, 0], [0, 1], [0.6, 0.8], [-1, 0]]
Ztxt = [[1, 0], [0, 1], [0.8, 0.6], [-1, 0]]
t, b, n = 10.0, -10.0, 4
dot = lambda a, c: sum(p * q for p, q in zip(a, c))
L = [[dot(Zimg[i], Ztxt[j]) * t + b for j in range(n)] for i in range(n)]
lab = [[1 if i == j else -1 for j in range(n)] for i in range(n)]
ls = lambda x: -math.log1p(math.exp(-x))
ll = [[ls(lab[i][j] * L[i][j]) for j in range(n)] for i in range(n)]
print([["%.2f" % x for x in r] for r in L])
print([["%.4f" % -x for x in r] for r in ll])
print("loss=%.4f" % (-sum(map(sum, ll)) / n))

    3. 分块实现

    3.1 逐对独立带来的可分块性

    数据并行下，一批数据分在 $D$ 台设备上，每台 $m=|\mathcal{B}|/D$ 对。sigmoid 损失的每一项只依赖一对，是逐对独立项之和；每台设备各自算本地那一块，不必把整个批量的嵌入收集到一起，也不必算出完整的 $|\mathcal{B}|\times|\mathcal{B}|$ 相似度矩阵。

    3.2 分块的一次轮换

    三台设备、全局批量 12（每台 4 对）时，分块实现逐轮把文本嵌入换到相邻设备，任一时刻每台设备只需保留自己那一小块损失。

    三设备下逐轮轮换
    1. 起初每台设备各自持有 4 张图、4 段文本的嵌入，先算本地图像与本批文本构成的 $4\times4$ 损失，这覆盖了全部正对和一部分负对。
    2. 把各设备的文本嵌入轮换到相邻设备（例如设备 1 的图像配上设备 2 的文本），再算这批外来文本构成的负对损失，累加进损失。
    3. 重复轮换，直到每张图都与全部 12 段文本配过对。
    4. 最后做一次跨设备求和，把各轮的损失加到一起。

    4. 训练性质：批大小、负样本比与噪声

    在小批量上 sigmoid 优于 softmax，批量增大后差距收窄并很快饱和，再往上加收益很小、甚至变差。

    一批里负对数量远多于正对。实验里把负对按不同方式筛掉再看结果：随机丢掉负对来配平会让结果变差，只保留最容易的负对完全没有效果，只保留最难的负对（模型最容易弄错的、与正样本相近的负样本）则精度几乎不下降。这说明正负不平衡本身不算大问题，负样本一侧的学习信号大部分来自难负对。

    对数据噪声更鲁棒：随着图文被换成随机内容或配对被打乱的比例升高，用 sigmoid 训练的模型相对 softmax 仍保持优势。

    批大小与负对数量的数字
    1. SigLIP 在 32 k 批量处最好；softmax 要到 98 k 才好，且仍没超过 sigmoid；再加到 307 k 两者都变差。
    2. $|\mathcal{B}|$ 对图文有 $|\mathcal{B}|^2-|\mathcal{B}|$ 个负对；16 k（16384）批量下约 268 M 个负对、只有 16 k 个正对。

    5. 适用条件与边界

    成立条件是把一对图文的相似度直接当作二分类的打分，非配对的图文被一律当成负样本；它的前提是「不属于同一对的图文互不相关」，而这个假设在真实数据上并不精确。

    代价在于相似度仍只靠批量内的其他样本当负例：省下了整批归一化，但负例的数量与质量仍会影响结果，怎么更有效地引入更多负例还没有简单的答案，资料把它列为开放问题。

    常见误读是「批量越大越好」。32 k 已足够；更大的批量还需要足够长的训练方案，否则梯度更新的步数太少。
