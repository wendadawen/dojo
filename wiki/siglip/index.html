    SigLIP：用 sigmoid 替代 CLIP softmax 的逐对对比损失

    主要依据：Zhai, Mustafa, Kolesnikov, Beyer. "Sigmoid Loss for Language Image Pre-Training." ICCV 2023 Oral, arXiv:2303.15343v4（2023-09-27）, §3.1 CLIP softmax 损失公式、§3.2 SigLIP 损失公式与 bias 初始化、§3.3 chunked 实现、§4.2 batch size 影响、§4.4 SigLiT 84.5%、§4.5 SigLIP from scratch 72.1%、Table 1 / Table 2 实验数据、摘要 batch=1M 边际收益消失结论。

    用 4 个 TPUv4、2 天训练，SigLIP 达到 ImageNet zero-shot 84.5%；同等水平的 CLIP 需要约 2500 TPUv3-days。这一算力差距的核心不在模型架构——两者都是双塔 + 共享嵌入空间 + 可学习温度——而在损失函数：SigLIP 把 CLIP 的 softmax 对比损失换成逐对 sigmoid 二分类损失，每个 (image, text) 对独立判断"配不配"，不依赖 batch 内其他对。本文回答：这一替换的形式差异在哪、可学习 bias $b$ 为什么是关键、batch size 与损失如何解耦、以及 SigLIP 在小算力场景的优势与边界。前置概念为 ViT（图像塔架构）与 标准注意力（softmax 形式与数值稳定 trick）。

    最容易误解

    • 以为 SigLIP 是新模型架构——正确：SigLIP 是损失函数的更换；模型架构（双塔 + 共享嵌入空间 + 温度）与 CLIP 完全相同，图像塔常用 ViT，文本塔常用 Transformer
    • 以为 SigLIP 总是比 CLIP 好——正确：论文 §4.2 显示 sigmoid 显著优于 softmax 仅在 batch < 16k；batch 增大时优势缩小；batch > 32k 后多语言 retrieval 反而下降
    • 以为只要把 CLIP 的 softmax 换成 sigmoid 就能 work，不需要 bias——正确：可学习 bias $b$ 是 SigLIP 公式中的关键组成；论文 §3.2 明确指出没有 $b$ 时初始 logits 因"1 正 vs $|B|-1$ 负"严重失衡而使训练初期产生大量错误方向梯度
    • 以为 SigLIP 用 sigmoid 是为了避免 softmax 数值不稳定——正确：数值稳定性是次要收益；论文 §1 明确动机是"conceptually decouples the batch size from the definition of the task"——把 batch size 与损失定义解耦；softmax 数值问题早已通过 log-sum-exp trick 解决
    • 以为 MoonViT-V2 不从 SigLIP 初始化是因为 SigLIP 不好——正确：K3 选择从零训练更稳定，与 SigLIP 质量无关；MoonViT-V2 的目标是"视频 + 自定义训练目标"，与 SigLIP 的"静态图像 + 对比损失"目标不同；详见 MoonViT-V2 概念页

    CLIP softmax 损失的"全局耦合"问题——为什么需要换掉它

    用 32k batch 训 CLIP，要把每个对 (image $i$, text $j$) 的相似度 $x_i\cdot y_j$ 与整个 batch 的所有相似度聚合到一起算 softmax——分母 $\sum_j e^{t x_i\cdot y_j}$ 依赖 batch 内所有 $y_j$。能不能让每个 (image, text) 对只看自己就被评分？这是 SigLIP 要回答的问题。

    理解 SigLIP 之前要先看清 CLIP 的损失怎么算。CLIP（Radford et al. 2021）用双塔架构：图像塔 $f$ 把图像 $I_i$ 映射到嵌入 $f(I_i)$，文本塔 $g$ 把文本 $T_j$ 映射到嵌入 $g(T_j)$；嵌入经 L2 归一化得 $x_i=f(I_i)/\|f(I_i)\|_2$、$y_j=g(T_j)/\|g(T_j)\|_2$，落在共享嵌入空间；图像塔常用 ViT（已讲过 patch + Transformer 编码机制），文本塔常用 Transformer。CLIP 的训练目标是对 batch 内 $|B|$ 个 (image, text) 配对样本，让正对的相似度高于负对——这通过 softmax 损失实现（softmax 在 标准注意力 概念页已给出，这里只使用其结果）：

    $$\mathcal{L}_{\text{CLIP}}=-\frac{1}{2|B|}\sum_{i=1}^{|B|}\left(\log\frac{e^{t\,x_i\cdot y_i}}{\sum_{j=1}^{|B|}e^{t\,x_i\cdot y_j}}+\log\frac{e^{t\,x_i\cdot y_i}}{\sum_{j=1}^{|B|}e^{t\,x_j\cdot y_i}}\right).$$ [F2]

    逐项解释：

    • $x_i, y_j$：L2 归一化的图像与文本嵌入；$x_i\cdot y_j\in[-1,1]$ 是余弦相似度。
    • $t$：温度参数，可学习，参数化为 $t=\exp(t')$（$t'$ 是全局可学习 log 参数；与 CLIP 原文一致）。
    • $|B|$：batch size，即 batch 内 (image, text) 配对数。
    • 第一个 $\log$ 项：image→text 方向 softmax——第 $i$ 张图像与所有 $|B|$ 段文本的相似度作 logits，正确文本 $y_i$ 应得最高概率。
    • 第二个 $\log$ 项：text→image 方向 softmax——第 $i$ 段文本与所有 $|B|$ 张图像的相似度作 logits，正确图像 $x_i$ 应得最高概率。两个方向对称求和后取平均。
    • 分母 $\sum_{j=1}^{|B|}e^{t\,x_i\cdot y_j}$：image→text 方向的 softmax 分母，依赖整个 batch 的所有文本嵌入 $y_1,\ldots,y_{|B|}$。

    关键机制在于分母 $\sum_j$ 让每个对的损失与整个 batch 耦合。以第 $i$ 张图像为例，它对正对 $(i,i)$ 的梯度不仅取决于 $x_i\cdot y_i$，还取决于分母中所有 $e^{t\,x_i\cdot y_j}$ 项——也就是该图像与 batch 内所有其他文本的相似度。换句话说，每个对的梯度信号是"正对相似度相对 hardest negative 的优势"，而非绝对量。CLIP 论文与对比学习综述（Oord et al. 2018 InfoNCE）都把这一性质视为对比学习的核心。

    CLIP softmax 损失的耦合结构（|B|=4 示意，省略对称的 text→image 方向）：

       y_1      y_2      y_3      y_4
x_1  [ + ▓ ] [ - ▓ ] [ - ▓ ] [ - ▓ ]   ← 第 1 行 softmax：分母依赖 y_1..y_4
x_2  [ - ▓ ] [ + ▓ ] [ - ▓ ] [ - ▓ ]   ← 第 2 行 softmax：分母依赖 y_1..y_4
x_3  [ - ▓ ] [ - ▓ ] [ + ▓ ] [ - ▓ ]   ← 第 3 行 softmax：分母依赖 y_1..y_4
x_4  [ - ▓ ] [ - ▓ ] [ - ▓ ] [ + ▓ ]   ← 第 4 行 softmax：分母依赖 y_1..y_4

每行分母 = sum_j e^{t·x_i·y_j} 需要整行所有 4 个相似度
+ = 正对（z=+1），- = 负对（z=-1）

    这带来两个问题：

    • 小 batch 下梯度噪声大。每个对的梯度信号是"对 hardest negative 的相对优势"。batch 小时（如 $|B|=256$），hardest negative 往往是"运气不好没采到难样本"——梯度信号弱且噪声大。论文 §4.2 实证显示 sigmoid 损失在 batch < 16k 时显著优于 softmax，正是因为小 batch 下 softmax 的 hardest negative 池太小。
    • 分布式训练需要 expensive all-gather。当 batch 被切分到多个设备时，每个设备需要先 all-gather 全部 $|B|$ 个嵌入到本地才能算分母——这是 CLIP 训练在多设备上的核心通信瓶颈。论文 §3.3 专门讨论这一点。
    补充：softmax 数值稳定 trick——为什么不是 SigLIP 的主要动机

    softmax 直接计算 $e^{t\,x_i\cdot y_j}$ 在数值上不稳定（指数溢出）。标准 trick 是减去最大值：$\frac{e^{a_j-a_{\max}}}{\sum_k e^{a_k-a_{\max}}}$，等价于原 softmax 但避免溢出。CLIP 实现早已用此 trick，论文 §1 也明确提及（"usually stabilized by subtracting the maximum input value before applying the softmax"）。所以"避免 softmax 数值不稳定"不是 SigLIP 的主要动机——SigLIP 的核心动机是把 batch size 与损失定义解耦（§3.2 第 1 段"conceptually decouples the batch size from the definition of the task"）。

    常见误解。 SigLIP 用 sigmoid 替代 softmax 不是为了"避免 softmax 数值不稳定"。数值稳定性是次要收益——softmax 的数值问题早已通过 log-sum-exp trick 解决。SigLIP 的真正动机是把 batch size 与损失定义解耦，让每个对的梯度独立于 batch 内其他对。这个区分很重要——若以为动机是数值稳定，就会错过 SigLIP 在小 batch 下显著优于 softmax 的机制原因。

    知道了"分母依赖 batch"是问题所在。下一章看 SigLIP 怎么把它去掉——逐对独立的二分类损失。

    SigLIP 损失公式——逐对独立的二分类

    SigLIP 把 CLIP 的 softmax 损失换成 sigmoid 二分类损失。同一 batch 内 $|B|$ 个 (image, text) 配对样本，构成 $|B|\times|B|=|B|^2$ 个对；每个对独立判断"配不配"——是独立的二分类问题。损失形式是：

    $$\mathcal{L}_{\text{SigLIP}}=-\frac{1}{|B|}\sum_{i=1}^{|B|}\sum_{j=1}^{|B|}\log\frac{1}{1+e^{z_{ij}(-t\,x_i\cdot y_j-b)}}=-\frac{1}{|B|}\sum_{i,j}\log\sigma(z_{ij}(t\,x_i\cdot y_j+b)).$$ [F1]

    论文原文写作 $\log\frac{1}{1+e^{z_{ij}(-t\,x_i\cdot y_j-b)}}$；由 sigmoid 定义 $\sigma(a)=1/(1+e^{-a})$[F3]等价改写为右侧 $\log\sigma(z_{ij}(t\,x_i\cdot y_j+b))$ 形式。逐项解释：

    • $x_i, y_j$：与 CLIP 共享，L2 归一化的图像与文本嵌入[F4]：$x_i=f(I_i)/\|f(I_i)\|_2$、$y_j=g(T_j)/\|g(T_j)\|_2$。
    • $z_{ij}\in\{+1,-1\}$：配对标签。当 $i=j$（batch 内第 $i$ 张图像与第 $i$ 段文本是配对样本）时 $z_{ii}=+1$；当 $i\neq j$（不配对）时 $z_{ij}=-1$。这与 CLIP 的"对角线为正、非对角线为负"对应，只是 SigLIP 用 $\pm 1$ 显式编码。
    • $t=\exp(t')$：可学习温度，与 CLIP 共享[F5]；$t'$ 初始化为 $\log 10$ 即 $t=10$[F6]。
    • $b$：可学习 bias，SigLIP 新增项（CLIP 无此项）。初始化 $b=-10$[F6]。下一章专门讲它的作用。
    • $\sigma$：sigmoid 函数 $\sigma(a)=1/(1+e^{-a})$[F3]。
    • $-\frac{1}{|B|}\sum_{i,j}$：对 $|B|^2$ 个对求和后除以 $|B|$（注意不是除以 $|B|^2$——论文 §3.2 原文如此，与 CLIP 的 $-\frac{1}{2|B|}$ 对应；这意味着正对与负对的权重不同，下一章解释原因）。

    关键机制：每个对独立计算。$\log\sigma(z_{ij}(t\,x_i\cdot y_j+b))$ 这一项只依赖该对的 $x_i, y_j, z_{ij}, t, b$——不依赖 batch 内其他对的 $y_k$（$k\neq j$）。对比 CLIP softmax 中分母 $\sum_j e^{t\,x_i\cdot y_j}$ 把所有 $y_j$ 耦合在一起：SigLIP 把"对 hardest negative 的相对优势"换成"每个对的绝对二分类判断"。

    用 $|B|=4$ 的小例子可视化（教学示例，下一章详细手算）：

    SigLIP 损失的逐对独立结构（|B|=4 示意）：

       y_1      y_2      y_3      y_4
x_1  [ + ▓ ] [ - ▓ ] [ - ▓ ] [ - ▓ ]   每个格子独立算 log σ(z_ij·(t·x_i·y_j + b))
x_2  [ - ▓ ] [ + ▓ ] [ - ▓ ] [ - ▓ ]   无分母、无行/列耦合
x_3  [ - ▓ ] [ - ▓ ] [ + ▓ ] [ - ▓ ]   4 个正对 + 12 个负对 = 16 个独立二分类
x_4  [ - ▓ ] [ - ▓ ] [ - ▓ ] [ + ▓ ]

+ = 正对（z=+1），- = 负对（z=-1）
每个 ▓ 是一项 log σ(z_ij·(t·x_i·y_j + b))，独立求和

    与 CLIP 的 4 项形式差异：

    项CLIP softmax 损失 (F2)SigLIP sigmoid 损失 (F1)
    归一化softmax 分母 $\sum_j e^{t\,x_i\cdot y_j}$无分母，每对独立
    方向对称两次：image→text + text→image一次性对 $|B|^2$ 对求和
    损失类型cross-entropy on softmax（多分类）binary cross-entropy on sigmoid（二分类）
    bias 项无有可学习 $b$[F6]初始化 $-10$

    从语义看，CLIP 把每个图像看作"$|B|$ 选 1"多分类问题，正确文本应该胜出；SigLIP 把每个 (image, text) 对看作独立的"配不配"二分类问题，不要求"胜过其他文本"。这一形式差异是后续 batch 解耦机制的来源。

    补充：等价形式 $\log\frac{1}{1+e^{z_{ij}(-t\,x_i\cdot y_j-b)}}$ 与 $\log\sigma(z_{ij}(t\,x_i\cdot y_j+b))$ 的推导

    由 sigmoid 定义 $\sigma(a)=1/(1+e^{-a})$，令 $a=z_{ij}(t\,x_i\cdot y_j+b)$，则 $\sigma(a)=1/(1+e^{-z_{ij}(t\,x_i\cdot y_j+b)})=1/(1+e^{z_{ij}(-t\,x_i\cdot y_j-b)})$。因此 $\log\sigma(z_{ij}(t\,x_i\cdot y_j+b))=\log\frac{1}{1+e^{z_{ij}(-t\,x_i\cdot y_j-b)}}$。论文 §3.2 原文用后一形式（与 sigmoid BCE 等价），本文也使用前一形式便于直观理解 "$z$ 决定方向、$t\,x_i\cdot y_j+b$ 决定 logit"。

    形式清楚了。但 $b$ 这个新项为什么需要？为什么 CLIP 不需要它？下一章讲 $b$ 与 $t$ 的职责。

    可学习温度 $t$ 与可学习 bias $b$——为什么 $b$ 是关键

    SigLIP 公式中有两个可学习标量：温度 $t$ 与 bias $b$。温度 $t$ 与 CLIP 共享，$b$ 是 SigLIP 新增项。两者职责不同：

    温度 $t=\exp(t')$：控制相似度被放大的程度。$t$ 越大，正对与负对的 logit 差异越大、损失梯度越强；$t$ 越小，差异被压缩、梯度变弱。论文 §3.1 末段明确"$t$ 参数化为 $\exp(t')$，$t'$ 是全局可学习参数"——这与 CLIP 一致。初始化 $t'=\log 10$ 即 $t=10$[F6]。

    bias $b$：抵消初始正负样本不平衡。batch 内正对仅 $|B|$ 个（对角线）、负对 $|B|^2-|B|$ 个（非对角线）；正负比例 $1:(|B|-1)$。在 $|B|=32\text{k}$ 时比例为 $1:32767$。在 $|B|=1\text{M}$ 时比例为 $1:999999$。

    $|B|$正对数负对数正负比例
    44121:3
    32 k32 k$\approx 1.07\times 10^9$1:32767
    1 M$10^6$$\approx 10^{12}$1:999999

    若没有 $b$ 会怎样？初始模型未训练，$x_i\cdot y_j\approx 0$（嵌入未学到任何结构）。此时每个对的 logit $\approx t\cdot 0=0$，无论正负对，$\log\sigma(z_{ij}\cdot 0)=\log\sigma(0)=\log 0.5$。表面看每对损失相等，但负对数量压倒性多（32767 倍）——总损失被负对主导，梯度方向试图让所有对（包括正对）都"更负"。这与训练目标（正对应该相似）相反。

    更准确地说：sigmoid 损失对 logit $a=z_{ij}(t\,x_i\cdot y_j+b)$ 的梯度是 $\partial\log\sigma(a)/\partial a=\sigma(-a)=1-\sigma(a)$。若 $a=0$（初始无 $b$ 时），梯度 $=0.5$；正对 $z=+1$ 与负对 $z=-1$ 的梯度绝对值相同但方向相反。但因为负对数量 32767 倍于正对，总梯度被负对主导——模型整体被推向"所有对都更负"，包括正对。

    $b$ 的作用：初始 $b=-10$，使初始 logit $a=z_{ij}(t\cdot 0+b)=z_{ij}\cdot(-10)$。正对 $z=+1$ → $a=-10$ → $\sigma(-10)\approx 0.0000454$ → $\log\sigma(-10)\approx -10$；负对 $z=-1$ → $a=10$ → $\sigma(10)\approx 0.99995$ → $\log\sigma(10)\approx -0.00005$。表面上正对单对损失远大于负对单对损失（$-10$ vs $-0.00005$），但因为 $b$ 让初始模型预测偏向负类（$\sigma(b)=\sigma(-10)\approx 0.0000454$，与"负对远多于正对"的数据先验一致），少数正对的大梯度（$\sigma(10)\approx 1$）抵消多数负对的数量优势（每个负对梯度 $\approx 0$）——$b$ 起到了"先验偏置"作用，让训练从合理起点开始。

    展开：$|B|=4$、$t=10$、$b=-10$、初始 $x_i\cdot y_j=0$ 的完整损失手算

    教学示例。 设 $|B|=4$，4 张图像 + 4 段文本构成 4×4=16 个对，4 个正对（对角线 $i=j$）+ 12 个负对（非对角线 $i\neq j$）。设 $t=10$、$b=-10$，初始时 $x_i\cdot y_j=0$（嵌入未训练）。

    对正对 $(i,i)$：$z_{ii}=+1$，logit $a=z_{ii}(t\cdot 0+b)=1\times(0+(-10))=-10$，$\sigma(-10)=1/(1+e^{10})\approx 0.00004540$，损失 $\log\sigma(-10)\approx -10.0000454$。4 个正对总损失 $\approx 4\times(-10.0000454)=-40.0002$。

    对负对 $(i,j), i\neq j$：$z_{ij}=-1$，logit $a=z_{ij}(t\cdot 0+b)=(-1)\times(0+(-10))=10$，$\sigma(10)=1/(1+e^{-10})\approx 0.99995460$，损失 $\log\sigma(10)\approx -0.0000454$。12 个负对总损失 $\approx 12\times(-0.0000454)=-0.0005$。

    未归一化总损失 $=-40.0002+(-0.0005)\approx -40.0007$。按公式除以 $|B|=4$ 得 $\mathcal{L}_{\text{SigLIP}}\approx -10.0002$。

    对照：若 $b=0$（无 bias），初始时 $a=z_{ij}(t\cdot 0+0)=0$，$\sigma(0)=0.5$，$\log\sigma(0)=\log 0.5\approx -0.6931$。16 个对总损失 $=16\times(-0.6931)=-11.09$，除以 4 得 $-2.77$。表面看损失更小，但此时正对与负对的梯度绝对值相同（均为 $0.5$），方向相反——总梯度被 12 个负对主导，模型整体被推向"所有对都更负"，与训练目标相反。$b=-10$ 通过让初始正对 loss 极大、负对 loss 极小，让模型从"预测偏向负类"的起点（与数据先验一致）开始修正，避免初始方向错误。

    注意：手算数字是教学示例，使用 $t=10, b=-10$ 与初始 $x_i\cdot y_j=0$ 的简化假设；真实训练中嵌入迅速学到结构，$x_i\cdot y_j$ 不再为 0，$b$ 也会随训练调整。

    $b$ 是可学习的。训练过程中模型逐渐学到正确判别能力后，$b$ 会自动调整到合理值——论文 §4.5 图 6 显示 $b$ 最终值与负采样策略有关（不同 batch 组成下 $b$ 收敛到不同值，范围约 $-15$ 到 $+5$）。$b$ 不是固定先验，而是"先验偏置 + 可学习修正"的组合。

    CLIP 为什么不需要 $b$？softmax 的分母 $\sum_j e^{t\,x_i\cdot y_j}$ 已经隐式做了"相对优势"的归一化——每个对的损失是相对量（"正对 softmax 概率"），不存在"绝对数量失衡"问题。即使负对数量压倒性多，softmax 分母让每个对的梯度由"正对相对 hardest negative 的优势"决定，不会被负对绝对数量主导。SigLIP 把每个对独立化后，必须显式引入 $b$ 处理失衡——这是 SigLIP 公式中容易被忽视但论文 §3.2 明确强调的关键设计。

    常见误解。 SigLIP 不是"把 CLIP 的 softmax 换成 sigmoid 就完事"——可学习 bias $b$ 是公式中的关键组成。论文 §3.2 明确指出没有 $b$ 时初始 logits 因"1 正 vs $|B|-1$ 负"严重失衡而使训练初期产生大量错误方向梯度。$b=-10$ 通过让 $\sigma(b)=\sigma(-10)\approx 0.0000454$，使初始模型预测偏向负类（与数据先验一致），少数正对的大梯度抵消多数负对的数量优势。博客介绍时常省略 $b$，只写 $-\log\sigma(z_{ij}\cdot t\,x_i\cdot y_j)$——这会让人误以为"直接换 sigmoid 就能 work"。

    • 说出"若没有 $b$，初始损失被负对主导、梯度方向错误"的机制。
    • 算出 $b=-10$ 时 $\sigma(b)=\sigma(-10)\approx 0.0000454$（手算或代入）。
    • 说出 CLIP 为什么不需要 $b$（softmax 分母隐式做了相对归一化，不存在绝对数量失衡问题）。

    公式与符号全清楚了。下一章看 SigLIP 在不同 batch size 与算力条件下的实际表现，以及 K3 选择"不从 SigLIP 初始化"的衔接。

    batch size 解耦与实验边界——SigLIP 在小算力下的优势与边界

    第一章已说明 CLIP softmax 分母依赖整个 batch、小 batch 下 hardest negative 弱导致梯度噪声大。本章把这一机制主张与论文实验数字对齐——SigLIP 在小 batch 下显著优于 softmax，是因为每对的梯度由 $z_{ij}(t\,x_i\cdot y_j+b)$ 单独决定，不依赖 batch 内其他对。论文 §4.2 直接给出："the sigmoid loss performs significantly better than the softmax loss when the batch size is smaller than 16 k. As the train batch size grows, the gap closes."

    读出三点：

    • 32k 接近最优：ImageNet zero-shot 在 32k 达 73.2%，更大 batch 几乎不再提升；论文 §4.2 末段也报告 softmax 损失需要 98k 才达最优但仍不如 sigmoid。
    • 多语言 retrieval 反而下降：32k → 240k，XM avg 从 34.9 降到 32.7，中文 XM zh 从 32.5 大幅降到 23.7。论文 §4.3 报告了这一现象但未给出明确归因。
    • 1M 边际收益快速消失：摘要明确"we push the batch size to the extreme, up to one million, and find that the benefits of growing batch size quickly diminish, with a more reasonable batch size of 32k being sufficient"。论文未给出 1M 的具体精度数字，只给结论。

    核心结论（Zhai 2023 摘要 + §4.2 + §4.3）：32k batch 对 SigLIP 已足够；继续增大 batch 收益快速递减、多语言 retrieval 反而下降。这一结论是 SigLIP 在小算力场景可行的根本原因——不需要 CLIP 那种 32k+ batch + 大量 all-gather 通信。

    适用边界。SigLIP 相对 softmax 的优势不是普遍的：

    边界成立条件不成立时
    SigLIP 显著优于 softmaxbatch < 16 k（§4.2）batch ≥ 32 k 时优势缩小，但仍不差

    常见误解。 SigLIP 不是普遍比 CLIP 好。论文 §4.2 明确显示 sigmoid 显著优于 softmax 仅在 batch < 16k；batch 增大时优势缩小。脱离 batch size 谈"SigLIP 比 CLIP 好"是误读。

    K3 选择"不从 SigLIP 初始化"的衔接。SigLIP 的训练目标是"静态图像 + 对比损失"，学到的视觉表示适合图像-文本检索、zero-shot 分类等任务。MoonViT-V2 是 K3 的视觉编码器，目标是"视频 + 自定义训练目标"——K3 选择从零训练更稳定，与 SigLIP 质量无关，是设计取向不同。MoonViT-V2 已有独立概念页 MoonViT-V2。理解 SigLIP 是理解"为什么 K3 可以选择不从 SigLIP 初始化"的前置——既知道 SigLIP 学到的表示适合什么、也知道 MoonViT-V2 的目标为什么与之不同。

    补充：SigLIP 与 CLIP 的分布式 chunked 实现对比

    论文 §3.3 与图 1 给出 SigLIP 的"chunked"分布式实现：因为每个对独立计算，可以把 batch 切分到多个设备，每个设备只持有自己那部分图像与文本嵌入，逐次 swap 文本嵌入并累加损失，最后做一次 cross-device sum。这避免了 CLIP softmax 需要的 all-gather——每个时刻只有 $b\times b$（per-device batch size 平方）的小矩阵在内存中。这一实现细节是 SigLIP 在少 TPU 场景能跑大 batch 的工程原因；本页不展开完整伪代码（论文图 1），只在正文一句话提及。

    • 说出 SigLiT 84.5% 的训练条件（4 TPUv4 / 2 天 / batch 20k / ViT-g/14 frozen）。
    • 说出 SigLIP from scratch 72.1% / 32 TPUv4 / 2 天 对照 CLIP 72.6% / ~2500 TPUv3-days 的算力差距。
    • 说出 32k 最优、> 32k ImageNet zero-shot 几乎不再提升、多语言 retrieval 反而下降、1 M 边际收益消失。
    • 说出至少一个 SigLIP 不普遍最优的边界（batch < 16k 才显著优势 / 极小 batch 时 $b$ 作用减弱）。
    • 说出 K3 选择"不从 SigLIP 初始化"的原因（设计取向不同——视频 vs 静态图像；与 SigLIP 质量无关）。

    SigLIP 把对比学习的损失从"全局 softmax 耦合"换成"逐对 sigmoid 独立"，让 batch size 与损失定义解耦；理解了它，就理解了为什么 4 个 TPUv4 / 2 天能训出 84.5% zero-shot 模型，也理解了 K3 MoonViT-V2 选择"不从 SigLIP 初始化"的前提。

    教学示例

    $|B|=4$ 的 SigLIP 损失手算（"SigLIP 损失公式"章与"可学习温度与 bias"章）：构造目的——把 F1 公式落到可手算的最小 batch；展示 4 个正对 + 12 个负对的逐项求和、$b$ 抵消初始失衡的机制。设 $t=10$、$b=-10$、初始 $x_i\cdot y_j=0$；正对 $\log\sigma(-10)\approx -10.0000454$、负对 $\log\sigma(10)\approx -0.0000454$。非论文一手数据，使用论文初始化值与简化假设（嵌入未训练时 $x_i\cdot y_j=0$）。

    正负比例对照表 $|B|=4/32\text{k}/1\text{M}$（"可学习温度与 bias"章）：构造目的——把"1 正 vs $|B|-1$ 负"的不平衡量化可视化；32k 时 1:32767、1M 时 1:999999。使用论文 batch 配置。

    $b=-10$ 时 $\sigma(b)\approx 0.0000454$ 的计算（"可学习温度与 bias"章）：构造目的——把 $b$ 的"先验偏置"作用量化。$\sigma(-10)=1/(1+e^{10})\approx 0.00004540$。

    教学解释与类比边界

    "每个对的梯度信号是相对 hardest negative 的优势"类比（第一章）：服务"CLIP softmax 分母耦合全 batch"的局部关系。失效边界——它不覆盖温度 $t$ 极端值时 softmax 行为。正式判断以 F2 公式与论文 §4.2 实验为准。

    "$b=-10$ 让初始模型预测偏向负类"对应关系（"可学习温度与 bias"章）：服务"$b$ 抵消初始正负不平衡"的局部关系。失效边界——它不意味着 $b$ 是固定先验（$b$ 是可学习的，训练中会调整）；也不覆盖训练后期 $b$ 的最终值与负采样策略的关系（论文 §4.5 图 6 显示 $b$ 最终值与 batch 组成有关）。正式判断以 F1、F6 与论文 §3.2 为准。

    "SigLIP 把对比学习从多分类换成二分类"对应关系（"SigLIP 损失公式"章末段）：服务"SigLIP 形式差异"的局部关系。失效边界——它不意味着二分类一定比多分类好。正式判断以 F1、F2 与论文 §4.2 实验为准。

    教学简化及其限制

    简化一：CLIP softmax 公式直接引用，不展开 InfoNCE 推导。可推出：SigLIP 与 CLIP 的形式差异由 F1、F2 直接给出。不可推出：InfoNCE 的来历（Oord et al. 2018 CPC）、互信息估计的理论背景、softmax 的梯度推导。
