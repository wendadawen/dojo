    SwiGLU（Swish-Gated Linear Unit）：把 GLU 的 sigmoid 门换成 Swish，让门能翻号与放大

    主要依据：Shazeer 2020《GLU Variants Improve Transformer》(arXiv:2002.05202)，通过 ar5iv HTML 版逐条核对 §1–§4 与 Table 1。GLU 家族基础论断引用 Dauphin 2017《Language Modeling with Gated Convolutional Networks》，家族派生与记号差异见 GLU，不重复。

    LLaMA、PaLM、Mistral、Qwen、DeepSeek——这些主流大语言模型的 FFN 几乎都用同一种激活：SwiGLU。它由 Shazeer 2020《GLU Variants Improve Transformer》(arXiv:2002.05202) §2 Eq.(5) 提出[C1]，是 GLU 家族中把门分支的 sigmoid 换成 Swish $\mathrm{Swish}_\beta(z)=z\cdot\sigma(\beta z)$ 的变体（家族基础见 GLU；SiTU-GLU 是对 SwiGLU 加 softcap 有界化的下游改进，见 SiTU-GLU）。GLU 的 sigmoid 门恒正有界 $(0,1)$，只能压低或放行值分支；换成 Swish 后门分支可输出负值与无界正值，能翻号、能放大。问题是：这一替换让门分支多了什么能力，让它在 LLM 里成了事实标准？

    核心问题

    1. 用一句话说清 SwiGLU 在做什么，并说明它与 GLU 的关系（是什么、改了什么）。

      解答：SwiGLU 把 GLU 门分支的 sigmoid 换成 Swish，两分支结构不变

      SwiGLU 是 GLU 家族变体：一支线性投影过 Swish 当门，与另一支纯线性投影逐元素相乘，公式为 $\mathrm{Swish}_\beta(xW+b)\otimes(xV+c)$。相对 GLU 只改了一处——门分支的激活函数。见「1. 从 GLU 到 SwiGLU」。

    2. 写出 SwiGLU 公式与 Swish 定义，逐符号解释；手算一个小例子，并验证 $\mathrm{Swish}(0)=0$、$\mathrm{Swish}(1)\approx0.731$。

      解答：$\mathrm{Swish}_\beta(z)=z\cdot\sigma(\beta z)$；边界值 $0$、$0.7311$、$-0.2689$，手算例输出 $\approx[0.7311, -0.1345]$

      SwiGLU 定义见 Shazeer §2 Eq.(5)：$\mathrm{SwiGLU}(x,W,V,b,c,\beta)=\mathrm{Swish}_\beta(xW+b)\otimes(xV+c)$，其中 $W$ 用于门分支、$V$ 用于值分支（Shazeer 记法）、$\beta$ 为固定超参（实验取 $\beta=1$）。以 $x=[1.0,0.5]$、$W=\mathrm{diag}(1,-2)$、$V=I$、$b=c=0$ 手算得输出 $\approx[0.7311,-0.1345]$，第二维被 Swish 门的负值翻号。见「2. SwiGLU 的公式、Swish 定义与手算」。

    3. 解释为什么 SwiGLU 在 Transformer FFN 中要缩 $2/3$ 维度，并算出参数量等式与 LLaMA 风格 $\tfrac83 d$ 的推导。

      解答：三矩阵比双矩阵多一份权重，由 $3\cdot d\cdot d_{ff}'=2\cdot d\cdot d_{ff}$ 得 $d_{ff}'=\tfrac23 d_{ff}$，基线 $4d$ 时取 $\tfrac83 d$

      SwiGLU FFN 用 $W,V,W_2$ 三个矩阵，参数量 $3\cdot d\cdot d_{ff}'$；令其与双矩阵 FFN 的 $2\cdot d\cdot d_{ff}$ 相等，解出 $d_{ff}'=\tfrac23 d_{ff}$（如 $3072\to2048$）。标准基线取 $d_{ff}=4d$ 时，SwiGLU FFN 取 $\tfrac23\times4d=\tfrac83 d$，即 LLaMA 内部维度的来源。见「3. 把 SwiGLU 塞进 Transformer FFN」。

    4. 说明 SwiGLU 与 GLU/ReGLU/GEGLU 的派生关系，并指出 Swish 门比 sigmoid 门多了什么能力。

      解答：统一形式 $\mathrm{激活}(xW+b)\otimes(xV+c)$，只换门分支激活；Swish 门多出翻号与放大

      家族统一形式为 $\mathrm{激活}(xW+b)\otimes(xV+c)$：sigmoid 得 GLU、ReLU 得 ReGLU、GELU 得 GEGLU、Swish 得 SwiGLU，值分支始终纯线性。sigmoid 门恒正有界 $(0,1)$ 只能压低或放行；Swish 门可负、正侧无界、非单调，能压、能放、能翻。见「4. 经验结论与边界」的派生对照表。

    5. 说明 SwiGLU 的经验结论与边界——Shazeer 实验说了什么、没说什么，以及为什么社区选了 SwiGLU。

      解答：T5 上所有 GLU 变体优于基线、GEGLU 略优于 SwiGLU、原文无理论解释；社区选择是工程路径依赖

      Shazeer 在 T5 span-filling 上观察到所有 GLU 变体优于 ReLU/GELU/Swish 基线，GEGLU（$1.633$）与 SwiGLU（$1.636$）被同列为最优两变体（差距仅 $0.003$，本页推断在实验噪声内），且 §4 明确未给理论解释。社区选 SwiGLU 是 PaLM 高调采用、LLaMA 开源跟随，加上工具链惯性（本页推断）的结果。Swish 门正侧无界还可能引发激活爆炸（SiTU-GLU 加 softcap 解决）。见「4. 经验结论与边界」。

    最容易误解

    • "SwiGLU 就是 GLU 换个名字"——不对。SwiGLU 是 GLU 家族中的一个变体，把门分支的 sigmoid 换成 Swish。差别在 Swish 可负、正侧无界，sigmoid 恒正有界——这改变门对值的调制方式（输出可翻号、可放大）。
    • "Shazeer 2020 证明了 SwiGLU 最优"——不对。Table 1 中 GEGLU（$1.633$）略优于 SwiGLU（$1.636$）[C8, N1]，SwiGLU 不是实验最优；且 §4 明确"未给理论解释"（"divine benevolence"）[C9]。社区选 SwiGLU 是 PaLM/LLaMA 采用 + 工具链惯性（本页推断）的工程路径。
    • "SwiGLU 的门和 GLU 一样有界"——不对。GLU 的 sigmoid 门有界 $(0,1)$；SwiGLU 的 Swish 门正侧无界（$z\to+\infty$ 时 $\sim z$），负侧趋 $0$ 但可取负值[C2, C4]。这是 SiTU-GLU 加 softcap 想解决的。
    • "SwiGLU 的 $\beta$ 是可学习参数"——不对。Shazeer 实验中 $\mathrm{Swish}$ 门写作 $\mathrm{Swish}_1$，即取 $\beta=1$（§1 Eq.(3) 与 §2 Eq.(6)）[C3]。$\beta$ 是可调超参，不是可学习参数。
    • "LLaMA 的 $d_{ff}=\tfrac83 d$ 是新发明"——不对。$d_{ff}'=\tfrac23 d_{ff}$ 来自 Shazeer 2020 §2 末段[C6]；基线 $d_{ff}=4d$ 时 SwiGLU FFN 取 $d_{ff}'=\tfrac23\times 4d=\tfrac83 d$[C11, F5]。LLaMA 只是把 Shazeer 的 $2/3$ 规则套在 $4d$ 基线上。

    1. 从 GLU 到 SwiGLU——为什么要换门

    SwiGLU 直接建立在 GLU 的门控结构之上。GLU 把输入 $x$ 做两份线性投影，一份过 sigmoid 当"门"，再与另一份逐元素相乘。门控机制、梯度通路、家族派生规则见 GLU 页。

    GLU 的门 $\sigma(xV+c)\in(0,1)$ 这个形状本身有限制。sigmoid 把任意实数压到 $(0,1)$，这意味着门恒正（取值永远在 $0$ 到 $1$ 之间）且有界（不会超过 $1$）。把这样的门逐元素乘到值分支 $xW+b$ 上，门只能做两件事：把值"压低"（乘一个 $(0,1)$ 的小数）或"近似放行"（乘一个接近 $1$ 的数）。它不能让值翻号（变成相反符号），也不能让值放大（绝对值变大）——因为乘的系数始终是 $(0,1)$ 的正数。

    Shazeer 2020 §2 的动作很直接：把门分支的 sigmoid 换成其它激活，看会怎样。换 ReLU 得 ReGLU、换 GELU 得 GEGLU、换 Swish 得 SwiGLU，统一形式为 $\mathrm{激活}(xW+b)\otimes(xV+c)$。此处起改用 Shazeer 记法（激活在 $W$ 分支），与上一段 GLU 的 Dauphin 记法（$\sigma$ 在 $V$ 分支）标签互换，因 $\otimes$ 可交换而等价。SwiGLU 用的是 Swish。

    Swish 的定义（Shazeer §1 引用 Ramachandran et al. 2017）[F1]：

    $$\mathrm{Swish}_\beta(z)=z\cdot\sigma(\beta z),\qquad \sigma(z)=\frac{1}{1+e^{-z}}.$$

    $\beta$ 是 Swish 的超参，$\beta>0$。Shazeer §1 的 $\mathrm{FFN}_{\mathrm{Swish}}$（Eq.(3)）与 §2 的 $\mathrm{FFN}_{\mathrm{SwiGLU}}$（Eq.(6)）都写作 $\mathrm{Swish}_1$，即实验取 $\beta=1$[C3]——下文除公式外一律取 $\beta=1$，记 $\mathrm{Swish}_1=\mathrm{Swish}$。

    Swish 与 sigmoid 的形状差别是 SwiGLU 的核心：

    门分支激活取值范围能否取负正侧是否无界单调性
    sigmoid $\sigma(z)$$(0,1)$否否（上界 $1$）单调递增
    Swish $\mathrm{Swish}_1(z)$$\approx(-0.278,+\infty)$是（$z<0$ 时为负）是（$z\to+\infty$ 时 $\sim z$）非单调（先降后升）

    也就是说，换成 Swish 后，门分支不再是一个$(0,1)$ 的"压低/放行阀门"，而是一个可以翻号（输出负值乘到值上改变符号）和放大（输出大于 $1$ 的正值让值绝对值变大）的乘性调制器[C4]。sigmoid 门只能"压"，Swish 门能"压、能放、能翻"。这是机制层面的差别，具体数值表现由第 2 章的手算给出：门分支线性部分 $xW=-1$ 时，Swish 门取 $-0.2689$、sigmoid 门取 $+0.2689$，输出符号随之翻转。

    图只展示结构：GLU 与 SwiGLU 都有两分支，差别只在门分支的激活——GLU 用 sigmoid，SwiGLU 用 Swish。GLU 图按 Dauphin 记法画（$\sigma$ 在 $V$ 分支，与 GLU 一致），SwiGLU 图按 Shazeer 记法画（$\mathrm{Swish}$ 在 $W$ 分支）；两记法相差 $W\leftrightarrow V$ 标签，因 $\otimes$ 可交换而等价。每个分支的具体公式由正文给出。

    一句话定位：SwiGLU 是 GLU 家族中把门分支的 sigmoid 换成 Swish 的变体，由 Shazeer 2020 §2 Eq.(5) 定义[C1]；换门让门分支从"恒正有界"变成"可负、正侧无界"[C4]。

    本章问题

    1. 说明 GLU 与 SwiGLU 在"门分支激活"上的差别。

      解答：GLU 用 sigmoid（恒正有界 $(0,1)$），SwiGLU 用 Swish（可负、正侧无界、非单调）

      两者的两分支结构完全一致：门分支过激活、值分支纯线性、逐元素相乘。差别只在门分支的激活函数——GLU 的 sigmoid 把门压在 $(0,1)$ 内恒正有界；SwiGLU 的 Swish 可输出负值，正侧随输入无界增长，且非单调。

    2. 分别说明 sigmoid 门恒正有界与 Swish 门可负无界这两条形状差别让门多了什么能力。

      解答：恒正有界只能压低或放行；可负无界多出翻号与放大两种调制

      sigmoid 门的取值是 $(0,1)$ 的正数，乘到值分支上只能把值压低（乘小数）或近似放行（乘接近 $1$ 的数），不能改变符号也不能放大绝对值。Swish 门可取负值（翻号）与大于 $1$ 的正值（放大），即"能压、能放、能翻"，乘性调制能力更丰富。

    本章厘清了 SwiGLU 与 GLU 的差别在于门分支的激活函数：门分支换成 Swish 后能翻号与放大。这一机制由公式与手算落到具体数字。

    2. SwiGLU 的公式、Swish 定义与手算——逐符号拆解与边界值验证

    SwiGLU 的正式定义由 Shazeer 2020 §2 Eq.(5) 给出[C1, F2]：

    $$\mathrm{SwiGLU}(x,W,V,b,c,\beta)=\mathrm{Swish}_\beta(xW+b)\otimes(xV+c).$$

    逐项说明每个符号：

    • $x$：本层的输入向量，$\in\mathbb{R}^{1\times d_{in}}$。
    • $W,V$：两套独立的可学习权重，$\in\mathbb{R}^{d_{in}\times d_{out}}$。Shazeer 记法：$W$ 用于门分支（过 Swish），$V$ 用于值分支（不过激活）。这与 GLU 的 Dauphin 主记法（$\sigma$ 在 $V$ 分支）相差 $W\leftrightarrow V$ 标签，因 $\otimes$ 可交换而数学等价；读 LLaMA/PaLM 等部署代码时通常用 Shazeer 记法。
    • $b,c$：两套独立的偏置，$\in\mathbb{R}^{d_{out}}$。Shazeer §2 在 FFN 部署中省略偏置（见第 3 章），但原始 Eq.(5) 保留。
    • $\beta$：Swish 的超参，$\beta>0$。Shazeer 实验中 $\mathrm{Swish}$ 门写作 $\mathrm{Swish}_1$，即取 $\beta=1$（§1 Eq.(3) 与 §2 Eq.(6)）[C3]。$\beta$ 是可调超参，不是可学习参数。
    • $\mathrm{Swish}_\beta(xW+b)$：门分支，一份线性投影过 Swish，可输出负值与无界正值。
    • $xV+c$：值分支，一份纯线性投影，不过激活。
    • $\otimes$：逐元素乘积（Hadamard 积），两个同形向量逐位相乘。

    先用三个边界值把 Swish 的形状落到具体数字[C2]。$\sigma(0)=0.5$、$\sigma(1)\approx0.7311$、$\sigma(-1)\approx0.2689$：

    • $\mathrm{Swish}(0)=0\cdot\sigma(0)=0\cdot 0.5=0$。
    • $\mathrm{Swish}(1)=1\cdot\sigma(1)\approx1\times 0.7311=0.7311$。
    • $\mathrm{Swish}(-1)=-1\cdot\sigma(-1)\approx-1\times 0.2689=-0.2689$。

    正侧渐近：$z\to+\infty$ 时 $\sigma(z)\to1$，故 $\mathrm{Swish}(z)\sim z$（无界增长）。负侧渐近：$z\to-\infty$ 时 $\sigma(z)\to0$ 指数衰减，且衰减速度压过 $|z|$ 的线性增长，故 $\mathrm{Swish}(z)\to0$（从负侧趋近）。所以 Swish 的形状是：原点过 $0$，正侧近似线性增长，负侧先下降到一个小负值（约 $z\approx-1.278$ 处达到最小 $\approx-0.278$）再回升趋 $0$——非单调。

    构造示例。取 $x=[1.0,\,0.5]$（一行二列向量），用 $2\times2$ 对角权重让两维的门能拉开差距。$W=\mathrm{diag}(1,-2)$（门分支权重，让第二维输入翻号），$V=I$（值分支近似直通，把注意力集中到门的作用上），$b=c=0$，$\beta=1$：

    门分支内部线性部分：

    $$xW+b=[1.0\times1+0.5\times0,\;1.0\times0+0.5\times(-2)]=[1.0,\,-1.0].$$

    过 Swish（取四位小数，$\mathrm{Swish}(1.0)=1.0\cdot\sigma(1.0)\approx0.7311$，$\mathrm{Swish}(-1.0)=-1.0\cdot\sigma(-1.0)\approx-0.2689$）：

    $$\mathrm{Swish}(xW+b)\approx[0.7311,\,-0.2689].$$

    值分支：

    $$xV+c=[1.0,\,0.5]\,I+[0,0]=[1.0,\,0.5].$$

    逐元素相乘得 SwiGLU 输出：

    $$\mathrm{SwiGLU}(x)\approx[0.7311,\,-0.2689]\otimes[1.0,\,0.5]=[0.7311\times1.0,\,-0.2689\times0.5]\approx[0.7311,\,-0.1345].$$

    把数字翻译回机制：第一维 Swish 门 $\approx0.73$（正值），把值 $1.0$ 压低到约 $73\%$——和 sigmoid 门做的事差不多。第二维 Swish 门 $\approx-0.27$（负值），乘到值 $0.5$ 上得到 $\approx-0.13$——符号被翻了。这是 sigmoid 门做不到的：sigmoid 门永远在 $(0,1)$，乘到任何值上都不会改变符号。

    展开：同输入下 GLU 与 SwiGLU 的逐维对照（验证"翻号"差别）

    构造示例。同 $x=[1.0,0.5]$、$W=\mathrm{diag}(1,-2)$、$V=I$、$b=c=0$，对比 GLU 与 SwiGLU：

    • GLU 门 $\sigma(xW+b)=\sigma([1.0,-1.0])\approx[\sigma(1.0),\sigma(-1.0)]\approx[0.7311,\,0.2689]$（两维都正）。
    • GLU 输出 $=[0.7311,\,0.2689]\otimes[1.0,\,0.5]\approx[0.7311,\,0.1345]$（两维都正）。
    • SwiGLU 门 $\mathrm{Swish}(xW+b)\approx[0.7311,\,-0.2689]$（第二维负）。
    • SwiGLU 输出 $\approx[0.7311,\,-0.1345]$（第二维被翻号）。

    两份计算只差门分支的激活——sigmoid vs Swish。第二维输入 $xW=-1.0$ 是负的：sigmoid 把它压成正的 $0.27$（恒正），Swish 保留它的负号得 $-0.27$（$-1\times\sigma(-1)$）。这一差别让 SwiGLU 的门不仅能压低、还能翻号与放大。数字为教学构造，不代表真实模型参数。

    展开：Swish 边界值与渐近行为的逐步代入

    由 $\mathrm{Swish}_\beta(z)=z\cdot\sigma(\beta z)$ 与 $\sigma(z)=1/(1+e^{-z})$，取 $\beta=1$：

    • $z=0$：$\mathrm{Swish}(0)=0\cdot\sigma(0)=0\times0.5=0$。
    • $z=1$：$\sigma(1)=1/(1+e^{-1})=1/(1+0.3679)\approx0.7311$；$\mathrm{Swish}(1)=1\times0.7311\approx0.7311$。
    • $z=-1$：$\sigma(-1)=1/(1+e^{1})=1/(1+2.7183)\approx0.2689$；$\mathrm{Swish}(-1)=-1\times0.2689\approx-0.2689$。
    • $z\to+\infty$：$\sigma(z)\to1$，故 $\mathrm{Swish}(z)=z\cdot\sigma(z)\sim z$（线性增长，无界）。
    • $z\to-\infty$：$\sigma(z)\sim e^{z}$（指数衰减），$\mathrm{Swish}(z)=z\cdot e^{z}\to0$（指数衰减压过线性增长）。

    Swish 的最小值在 $z=-\sigma(z)/\sigma'(z)$ 处取得，数值约 $z\approx-1.278$，$\mathrm{Swish}(-1.278)\approx-0.278$。这个最小值是 Swish 非单调的体现：负侧先下降到一个小负值再回升趋 $0$，不像 sigmoid 单调递增。

    本章问题

    1. 写出 SwiGLU 运算的步骤（门分支线性、Swish、值分支、相乘）。

      解答：先算门分支线性 $xW+b$、过 Swish，再算值分支 $xV+c$，最后逐元素相乘

      第一步算门分支线性部分 $xW+b$；第二步过 Swish 得 $\mathrm{Swish}_\beta(xW+b)$，可负、正侧无界；第三步算值分支 $xV+c$，不过激活；第四步两者逐元素相乘（$\otimes$）得输出 $\mathrm{Swish}_\beta(xW+b)\otimes(xV+c)$。

    2. 算出 $\mathrm{Swish}(0)$、$\mathrm{Swish}(1)$、$\mathrm{Swish}(-1)$ 的近似值。

      解答：$0$、$0.7311$、$-0.2689$

      $\mathrm{Swish}(0)=0\cdot\sigma(0)=0\times0.5=0$；$\mathrm{Swish}(1)=1\times\sigma(1)\approx1\times0.7311=0.7311$；$\mathrm{Swish}(-1)=-1\times\sigma(-1)\approx-1\times0.2689=-0.2689$。注意负输入给出负门值，这是 sigmoid 没有的。

    3. 说明同输入下 SwiGLU 第二维输出为什么是负值而 GLU 是正值，以及 Shazeer 记法中 $W$ 与 $V$ 分别用于哪个分支。

      解答：第二维 $xW=-1.0$，sigmoid 压为正、Swish 保号；$W$ 用于门分支、$V$ 用于值分支

      第二维门分支线性部分 $xW=-1.0$：sigmoid 把它压成正的 $0.2689$（恒正），GLU 输出该维为 $+0.1345$；Swish 保留负号得 $-0.2689$，SwiGLU 输出该维为 $-0.1345$，符号被翻转。Shazeer 记法中 $W$ 用于门分支（过 Swish），$V$ 用于值分支（纯线性）。

    本章把 SwiGLU 的公式、Swish 的形状与手算例子落到具体数字。SwiGLU 的部署形态是把门控单元塞进 Transformer FFN，FFN 内部维度按 $\tfrac23$ 规则取 $\tfrac83 d$。

    3. 把 SwiGLU 塞进 Transformer FFN——三矩阵与 $2/3$ 缩放

    Shazeer 2020 不是把 SwiGLU 当独立单元研究的，而是把它塞进 Transformer 的 FFN（前馈网络，每层后的两层 MLP）里跟 ReLU/GELU 基线比。SwiGLU FFN 用三个权重矩阵，并按 $2/3$ 规则缩隐藏维——这是 LLaMA 内部维度 $\tfrac83 d$ 的来源。

    标准 Transformer FFN（Shazeer §1，无偏置版本，沿用 T5 代码库）只用两个权重矩阵：

    $$\mathrm{FFN}_{\mathrm{ReLU}}(x,W_1,W_2)=\max(xW_1,0)\,W_2.$$

    $W_1$ 把 $x$ 从模型维度 $d$ 升到隐藏维 $d_{ff}$，ReLU 激活，$W_2$ 再降回 $d$。SwiGLU 版（Shazeer §2 Eq.(6)）用三个[C5, F3]：

    $$\mathrm{FFN}_{\mathrm{SwiGLU}}(x,W,V,W_2)=(\mathrm{Swish}_1(xW)\otimes xV)\,W_2.$$

    $W$ 与 $V$ 各把 $x$ 从 $d$ 升到 $d_{ff}'$，逐元素相乘后再被 $W_2$ 降回 $d$。多一个矩阵，参数量就多。为保持参数量与计算量与双矩阵基线相等，Shazeer §2 末段说[C6]：

    原文："All of these layers have three weight matrices, as opposed to two for the original FFN. To keep the number of parameters and the amount of computation constant, we reduce the number of hidden units $d_{ff}$ ... by a factor of $\frac{2}{3}$ when comparing these layers to the original two-matrix version."

    参数量等式：

    • 双矩阵 FFN 参数量：$W_1$ 是 $d\times d_{ff}$，$W_2$ 是 $d_{ff}\times d$，合计 $2\cdot d\cdot d_{ff}$。
    • 三矩阵 SwiGLU FFN 参数量：$W,V$ 各 $d\times d_{ff}'$，$W_2$ 是 $d_{ff}'\times d$，合计 $3\cdot d\cdot d_{ff}'$。
    • 令相等：$3\cdot d\cdot d_{ff}'=2\cdot d\cdot d_{ff}\;\Rightarrow\;d_{ff}'=\tfrac{2}{3}\,d_{ff}$[F4]。

    Shazeer §3.1 的实验实例[C7, N2]：基线 $d_{ff}=3072$，SwiGLU 变体 $d_{ff}=2048$（$3072\times\tfrac23=2048$）。

    LLaMA 风格 $\tfrac83 d$ 的推导[C11, F5]：标准 Transformer FFN 常取 $d_{ff}=4d$（如 $d=768$ 时 $d_{ff}=3072$，正是 Shazeer §3.1 的设置）；SwiGLU FFN 取 $d_{ff}'=\tfrac23 d_{ff}=\tfrac23\times 4d=\tfrac83 d$。这是 LLaMA 及沿用 LLaMA 的 $\tfrac23\cdot4d$ 约定的模型（如 Qwen1.5-7B）FFN 内部维度取 $\tfrac83 d$ 的来源——不是 LLaMA 的新发明，是 Shazeer 2020 的 $2/3$ 规则套在 $4d$ 基线上的直接结果。

    LLaMA（Touvron et al. 2023）§2.2 明确采用 SwiGLU，并引用 PaLM（Chowdhery et al. 2022）；后续 Mistral、Qwen、DeepSeek 等开权重 LLM 跟随[C10]；Google 的 Gemma 系列则用 GEGLU[C10]。

    FFN 变体权重矩阵数$d_{ff}$（保参数量相等）典型取值（$d=4096$）
    $\mathrm{FFN}_{\mathrm{ReLU}}$2$d_{ff}$$16384=4d$
    $\mathrm{FFN}_{\mathrm{SwiGLU}}$3$\tfrac23 d_{ff}=\tfrac83 d$$\tfrac83\times4096\approx10923$
    展开：参数量等式逐步推导 + LLaMA-7B 风格 $d=4096$ 验算

    设模型维度 $d=4096$（LLaMA-7B 风格）、基线 $d_{ff}=4d=16384$。双矩阵 FFN 参数量 $=2d\cdot d_{ff}=2d\cdot 4d=8d^2=134{,}217{,}728$。三矩阵 SwiGLU FFN 若不缩维度则为 $3d\cdot d_{ff}=3d\cdot 4d=12d^2=201{,}326{,}592$，比基线多 $50\%$。缩为 $d_{ff}'=\tfrac83 d$ 后参数量 $=3d\cdot\tfrac83 d=8d^2=134{,}217{,}728$，与基线相等——关键是 $3\times\tfrac83=8=2\times4$，缩放系数 $\tfrac23$ 抵消了多一个矩阵的 $3/2$ 倍。构造示例，数字为验算用。

    注：LLaMA-7B 实际取 $d_{ff}=11008$（接近 $\tfrac83\times4096\approx10922.67$，向上取整到最近的 $256$ 倍数）。这是工程实现上的取整，不改变 $\tfrac83 d$ 的推导来源。

    本章问题

    1. 写出 $\mathrm{FFN}_{\mathrm{SwiGLU}}$ 的公式，指出三矩阵分别叫什么。

      解答：$\mathrm{FFN}_{\mathrm{SwiGLU}}(x,W,V,W_2)=(\mathrm{Swish}_1(xW)\otimes xV)\,W_2$，$W$ 门分支升维、$V$ 值分支升维、$W_2$ 降回 $d$

      $W$ 与 $V$ 各把 $x$ 从模型维度 $d$ 升到隐藏维 $d_{ff}'$：$W$ 用于门分支（过 Swish），$V$ 用于值分支；两分支逐元素相乘后由 $W_2$（$d_{ff}'\times d$）降回 $d$。偏置按 Shazeer §2 的 FFN 部署省略。

    2. 算出三矩阵 FFN 要保持参数量与双矩阵 FFN 相等时 $d_{ff}$ 应改为多少，写出等式。

      解答：由 $3\cdot d\cdot d_{ff}'=2\cdot d\cdot d_{ff}$ 得 $d_{ff}'=\tfrac23 d_{ff}$

      双矩阵 FFN 参数量 $2\cdot d\cdot d_{ff}$（$W_1$ 与 $W_2$），三矩阵 SwiGLU FFN 参数量 $3\cdot d\cdot d_{ff}'$（$W,V,W_2$）。令二者相等解出 $d_{ff}'=\tfrac23 d_{ff}$，例如基线 $3072$ 缩为 $2048$。

    3. 推出 LLaMA 风格 $d_{ff}=\tfrac83 d$ 的步骤。

      解答：标准基线 $d_{ff}=4d$，套 $2/3$ 规则得 $\tfrac23\times4d=\tfrac83 d$

      标准 Transformer FFN 常取 $d_{ff}=4d$；SwiGLU FFN 按参数量相等缩为 $d_{ff}'=\tfrac23 d_{ff}=\tfrac23\times4d=\tfrac83 d$。这不是 LLaMA 的新发明，而是 Shazeer 2020 的 $2/3$ 规则套在 $4d$ 基线上的直接结果（LLaMA-7B 实际取 $11008$，是 $\tfrac83\times4096\approx10922.67$ 向上取整到 $256$ 的倍数）。

    本章把 SwiGLU 塞进 FFN 并推出 $\tfrac83 d$ 缩放规则。能部署不等于经验上更优，Shazeer 的实验给出了 SwiGLU 的经验增益与其适用边界。

    4. 经验结论与边界——SwiGLU 为什么成为 LLM 标配

    公式与 FFN 部署已在前两章确立。Shazeer 的实验结果给出 SwiGLU 的经验增益与适用边界，社区选择 SwiGLU 而非其它变体则出于工程路径依赖。

    4.1 Shazeer Table 1 结果

    Shazeer 2020 在 T5 base（span-filling 任务，参数与计算量匹配）上对比了八个 FFN 变体。结果[C8, N1]：

    FFN 变体heldout log-perplexity（524,288 步，越低越好）
    FFN_ReLU（基线）1.677
    FFN_GELU1.679
    FFN_Swish1.683
    FFN_GLU1.663
    FFN_Bilinear1.648
    FFN_ReGLU1.645
    FFN_SwiGLU1.636
    FFN_GEGLU1.633（最优）

    关键观察：所有 GLU 变体（含退化的 Bilinear）都优于 ReLU/GELU/Swish 基线；GEGLU（$1.633$）略优于 SwiGLU（$1.636$），SwiGLU 不是 Shazeer 实验最优[C8, N1]。但 Shazeer §3.2 把 GEGLU 与 SwiGLU 同列为"产生最佳困惑度的两变体"（"The GEGLU and SwiGLU variants produce the best perplexities"）——两者差距 $0.003$。Table 1 在 $65{,}536$ 步一组给出 run 间标准差（$\mathrm{FFN}_{\mathrm{SwiGLU}}$ $1.944\ (0.010)$、$\mathrm{FFN}_{\mathrm{GEGLU}}$ $1.942\ (0.004)$），$524{,}288$ 步一组未给；据此本页推断 $0.003$ 落在实验噪声内。数字限定条件：T5 base、$d_{model}=768$、12 层编码/解码、基线 $d_{ff}=3072$（SwiGLU 变体缩为 $2048$）、span-filling 任务、524,288 步[C7]。

    4.2 Shazeer 的理论态度

    Shazeer §4 末段原文[C9]：

    原文结语："We offer no explanation as to why these architectures seem to work; we attribute their success, as all else, to divine benevolence."

    翻译：作者没有解释这些架构为什么有效，把成功归于"神恩"。这句不是谦虚的修辞，而是明确标注"无理论解释"——经验结论不等于普适保证。SwiGLU 的经验增益（相对 ReLU 基线降 $0.041$ log-perplexity）在 T5 span-filling 上成立，但不构成"在所有任务/模态/规模上都优于 ReLU 或 GEGLU"的理论保证。

    4.3 为什么社区选了 SwiGLU 而不是 GEGLU

    既然 Shazeer 实验里 GEGLU 略优，为什么 LLM 部署几乎都用 SwiGLU？这是工程路径依赖的结果：

    • PaLM（Chowdhery et al. 2022）采用 SwiGLU[C10]——Google 的高调采用让 SwiGLU 进入主流视野。
    • LLaMA（Touvron et al. 2023）跟随 PaLM 用 SwiGLU，且 LLaMA 开源、被广泛复现。
    • 工具链惯性（本页推断）：主流训练/推理栈已按 SwiGLU 形状提供实现与优化，新模型改回 ReLU 或 GEGLU 需额外适配，切换有工程成本。
    • SwiGLU 与 GEGLU 差距仅 $0.003$ log-perplexity（本页推断在实验噪声内），没有强证据让社区切换。

    所以 SwiGLU 成为事实标准是"PaLM 高调采用 + LLaMA 开源跟随 + 工具链惯性（本页推断）+ 与 GEGLU 差距在噪声内（本页推断）"的组合，不是"SwiGLU 在所有任务上都比 GEGLU 好"的保证。

    4.4 GLU 家族变体派生对照

    把从 GLU 到 SwiGLU 一章提到的派生规则完整列出（统一 Shazeer 记法 $\mathrm{激活}(xW+b)\otimes(xV+c)$）：

    变体门分支激活门值形状来源
    GLUsigmoid $\sigma$恒正、有界 $(0,1)$Dauphin 2017 §2
    Bilinear恒等（去激活）线性（可负、无界）Dauphin §5.3 / Mnih & Hinton 2007
    ReGLUReLU $\max(0,\cdot)$非负、正侧无界Shazeer 2020 §2
    GEGLUGELU可负、正侧无界Shazeer 2020 §2
    SwiGLUSwish $\mathrm{Swish}_1$可负、正侧无界、非单调Shazeer 2020 §2 Eq.(5)

    五个变体的差别只在门分支的激活，值分支始终是纯线性 $xV+c$。SwiGLU 用 Swish——可负、正侧无界、非单调——让门调制最丰富。

    4.5 SwiGLU 不解决什么

    • 不保证在所有任务/模态上最优：Shazeer 实验限定 T5 span-filling；视觉、强化学习、小数据场景未必一致。GEGLU 在 Shazeer 自己的实验里还略优[C8, N1]。
    • 不替代归一化：SwiGLU 是门控激活，与 RMSNorm/LayerNorm 正交，不能拿来"稳定训练"。
    • 不做跨位置信息聚合：门控只控制"单个位置上每个维度的带宽"，不像注意力那样把多个位置的信息聚合过来。
    • Swish 门正侧无界可能引发激活爆炸：Kimi K3 Technical Report §2.3.2 指出 SwiGLU 的门支与值支都是无界乘性因子，坐标同时偏大时会产生激活离群值、抬高溢出风险，语境是 Stable LatentMoE 的路由分支。该报告把门支与值支的线性因子同时换成 softcap $\beta\tanh(\cdot/\beta)$，让乘积有界[C12]。这是 SiTU-GLU 想解决的问题。
    • 不保证全局最优：经验增益改善的是损失曲线，不解决局部极小、鞍点、大学习率失稳等问题。

    本章问题

    1. 说出 Shazeer Table 1 中 SwiGLU 与 GEGLU 的 log-perplexity，并指出哪个更低。

      解答：SwiGLU $1.636$、GEGLU $1.633$，GEGLU 更低（更优）

      Table 1 中 GEGLU 为 $1.633$（最优），SwiGLU 为 $1.636$ 紧随其后，差距仅 $0.003$（本页推断在实验噪声内）。Shazeer 把两者同列为"产生最佳困惑度的两变体"，SwiGLU 不是实验最优。

    2. 说明 "divine benevolence" 这句在 Shazeer §4 标注的内容，以及社区选 SwiGLU 而非 GEGLU 的一个工程原因。

      解答：标注"无理论解释"；工程原因如 PaLM/LLaMA 相继采用与工具链惯性（本页推断）

      §4 末段明确表示作者不解释这些架构为何有效，把成功归于"神恩"——经验结论不构成普适保证。工程原因：PaLM 高调采用 SwiGLU、LLaMA 开源跟随（有来源，见 C10）；主流工具栈已按 SwiGLU 形状实现，切换有成本（本页推断）；加上两者差距仅 $0.003$（本页推断在实验噪声内），没有强证据让社区切换。

    3. 说出 SwiGLU 不解决的一类问题（举一个非注意力、非归一化的例子也可），并说明 SiTU-GLU 是对 SwiGLU 的什么改进。

      解答：例如 Swish 门正侧无界可能引发的激活爆炸；SiTU-GLU 用 softcap 使门支与值支乘积有界

      SwiGLU 不解决训练优化问题（全局最优、鞍点、大学习率失稳），也不解决 Swish 门正侧无界带来的激活爆炸风险——深层堆叠或 MoE 路由把多个无界因子相乘时输出可能爆炸。SiTU-GLU（Kimi K3 Technical Report §2.3.2）把 SwiGLU 门支与值支的线性因子同时换成 softcap $\beta\tanh(\cdot/\beta)$，让乘积有界。

    全文总结：SwiGLU 是 GLU 家族中把门分支的 sigmoid 换成 Swish 的变体[C1]，换门让门分支从"恒正有界"变成"可负、正侧无界"，门能压、能放、能翻[C2, C4]。Swish 定义 $\mathrm{Swish}_\beta(z)=z\cdot\sigma(\beta z)$，边界值 $\mathrm{Swish}(0)=0$、$\mathrm{Swish}(1)\approx0.731$、$\mathrm{Swish}(-1)\approx-0.269$[F1]。FFN 部署用三矩阵并按 $2/3$ 缩维度[C5, C6]，LLaMA 风格取 $d_{ff}=\tfrac83 d$[C11, F5]。Shazeer 实验中 GEGLU（$1.633$）与 SwiGLU（$1.636$）并列最优两变体但 SwiGLU 非最优[C8, N1]，且 §4 明确未给理论解释[C9]；社区选 SwiGLU 是 PaLM/LLaMA 采用[C10]与工具链惯性（本页推断）的工程路径。Swish 门正侧无界可能引发激活爆炸，这是 SiTU-GLU 加 softcap 想解决的下游问题[C12]。以上对应开篇「核心问题」的五条。

    • 参数量验算 $d=4096$、$d_{ff}=16384\to d_{ff}'\approx10923$（折叠块）：构造目的是手算验证 $\tfrac83 d$ 等式与 LLaMA-7B 实际取 $d_{ff}=11008$ 的取整关系。

    辅助解释与类比边界

    • "门能压、能放、能翻"——只解释 Swish 门（可负、正侧无界）相对 sigmoid 门（恒正有界）多出的三种乘性调制能力。失效边界：Swish 门的"翻号"与"放大"是逐元素乘法的代数结果，不是门"主动决定"翻号——门值符号取决于 $xW+b$ 的符号，模型通过学 $W$ 间接控制。类比不延伸到"门有意图"。
    • "SwiGLU 是 GLU 家族下游成员"——只解释派生关系（换门分支激活）。失效边界：家族派生不意味 SwiGLU 在所有任务上都优于 GLU；Shazeer Table 1 中两者都优于 ReLU 基线，但 GLU 与 SwiGLU 之间的差别未在所有任务上验证。
    • "社区选 SwiGLU 是路径依赖"——只解释 PaLM/LLaMA 采用[C10]与工具链惯性（本页推断）的工程路径。失效边界：路径依赖不意味 SwiGLU 一定比 GEGLU 好；Shazeer 实验里 GEGLU 略优。若未来某任务上 GEGLU 显著优于 SwiGLU，社区可能切换。

    简化条件及其限制

    • Swish 完整讲解（Ramachandran 2017 的神经搜索过程、与 GELU/ReLU 的对比、$\beta$ 调参规律）不展开。可推出：SwiGLU 所需最小判断（Swish 定义、边界值、形状差别）。不可推出：Swish 为何被神经搜索选中、$\beta\ne1$ 时形状如何变化——由 Swish 主题展开。
    • GELU/ReLU 作为激活名出现而不展开。可推出：GLU 家族派生规则。不可推出：GELU 的具体形式、ReLU 的死神经元问题——另行展开。
    • Transformer 完整架构不展开。可推出：SwiGLU 在 FFN 中的部署。不可推出：注意力、位置编码、归一化的完整架构。
    • 各 LLM 部署代码与张量并行不展开。可推出：哪些模型用 SwiGLU。不可推出：HuggingFace/llama.cpp/vLLM 的具体实现细节。
    • Sigmoid、$\otimes$、$xW+b$、链式法则作为基础记号内联一行定义；LLaMA-7B 实际取 $d_{ff}=11008$ 的取整规则不展开。可推出：SwiGLU 所需最小判断与 $d_{ff}'=\tfrac83 d$ 的来源。不可推出：这些原语的完整理论、实际取整规则——见 GLU 与 LLM 工程实现。
