# Delta 规则与 DeltaNet · 教学大纲

## 4.1 页面开头

**钩子问题**：当一个语言模型需要在 10 万 token 的对话里"记住"前面写过的某个人名，标准 Transformer 把所有历史都塞进 KV cache（线性增长的显存），线性注意力把它们压成一个固定大小的矩阵状态（省显存但记不清）。后者为什么会"记不清"？能不能既保留固定大小状态、又记得清？

**一句话解释**：Delta 规则是一种递归状态更新规则——在向记忆矩阵写入新 key-value 关联前，先沿当前 key 方向擦除旧值，再做加权写入；DeltaNet 是把线性注意力的纯加性累加替换为 delta 规则的模型。

**要解决的具体问题**：长序列下线性注意力的 retrieval error（key 碰撞），让模型分不清"该用哪个 value"。

**学习承诺**（读完能回答）：
1. 为什么线性注意力的"加性累加"在长序列上会出现"key 碰撞"，delta 规则如何解决？
2. 给定 $S_{t-1}$、$k_t$、$v_t$、$\beta_t$，用 delta 规则公式手算一步更新，说明每个符号含义与 $\beta_t \in (0,1)$ 的作用。
3. 把 delta 规则改写为"先擦除后写入"等价形式，并说明两种形式等价。
4. 说明 $\beta_t \to 1$ 与 $\beta_t \to 0$ 的退化情形与前提条件。
5. DeltaNet 与线性注意力、Mamba2、Gated DeltaNet 的机制差异；Gated DeltaNet 为什么要加 $\alpha_t$。

**首个具体场景**：从 d=2 维、L=2 步的最小记忆例子开始，对比"加性累加"与"先擦除后写入"在同一序列上的不同结果。

**与第一章的过渡**：先讲线性注意力在长序列上"记不清"的来源（第 1 章），再给出 delta 规则的形式定义与手算（第 2 章），等价形式与几何直觉（第 3 章），边界情况与几何性质（第 4 章），最后扩展到 DeltaNet 模型与相邻对比（第 5 章）。

## 4.2 章节设计

### 第 1 章：为什么线性注意力会"记不清"——key 碰撞与 retrieval error

- **主要教学问题**：线性注意力的"加性累加"为什么在长序列上检索不准？
- **对应范围**：Q1；C1, C2, F1
- **正文要点**：
  - 线性注意力用一个矩阵状态 $S \in \mathbb{R}^{d_v \times d_k}$ 压缩所有历史
  - 加性递归 $S_t = S_{t-1} + v_t k_t^\top$（最小事实，前置概念页占位）
  - retrieval：$o = S q$；当 $q = k_j$ 时理想输出是 $v_j$
  - 实际输出 $S k_j = v_j + \sum_{i \neq j} (k_i^\top k_j) v_i$（F1）
  - d 维空间最多 d 个正交向量；$L > d$ 时必然 $k_i^\top k_j \neq 0$，碰撞不可避免
- **讲解材料及职责**：
  - 公式（C1, F1）：表达 retrieval error 的代数来源
  - 数字代入（d=2, L=3 构造）：展示具体碰撞数值
  - 图示（ASCII）：S 的"外积堆叠"结构
- **前置知识安排**：引用线性注意力概念页（占位 `wiki/linear-attention/index.html`），不展开背景
- **完成检查**：
  - 用 d=2 维、3 个两两非正交的 key，手算 $S k_2$ 与理想 $v_2$ 的差异
  - 说明为什么 $L \leq d$ 且所有 key 正交时 retrieval error 为 0
- **过渡**：加性累加的问题是"只写不删"——下章给出 delta 规则的"先擦除后写入"机制。

### 第 2 章：Delta 规则的紧凑公式与手算

- **主要教学问题**：delta 规则的公式是什么？怎么用？
- **对应范围**：Q2；C3, C5
- **正文要点**：
  - 公式 $S_t = S_{t-1}(I - \beta_t k_t k_t^\top) + \beta_t v_t k_t^\top$（C3）
  - 每个符号：$S \in \mathbb{R}^{d_v \times d_k}$、$k \in \mathbb{R}^{d_k}$、$v \in \mathbb{R}^{d_v}$、$I \in \mathbb{R}^{d_k \times d_k}$、$\beta_t \in (0,1)$
  - $\beta_t = \sigma(W_\beta x_t)$（sigmoid 输出，写入强度 / 学习率）
  - 形状检查：$S_{t-1}(I - \beta k k^\top) \to (d_v, d_k) \cdot (d_k, d_k) = (d_v, d_k)$；$\beta v k^\top \to (d_v, d_k)$；左右相加形状一致
  - 与经典 Widrow-Hoff delta rule 的类比与边界（C5）：形式同构，作用对象不同
  - 来源溯源一句话：Schlag 2021 ICML 提出 delta rule 用于线性 Transformer，Yang 2024 NeurIPS 命名 DeltaNet 并并行化
- **讲解材料及职责**：
  - 公式（C3）：定义
  - 形状检查：验证维度
  - 来源时间线图（ASCII）：Schlag 2021 → Yang 2024 NeurIPS → Yang 2024 ICLR 2025
  - 手算数字例子（d=2, L=2, β=1）：演示一步更新
- **前置知识安排**：矩阵-向量乘法、外积、单位矩阵、sigmoid（基础线性代数，假设已掌握）
- **完成检查**：
  - 给定 $S_{t-1}$、$k_t$、$v_t$、$\beta_t$，手算一步 $S_t$
  - 说明 $\beta_t = 0$ 与 $\beta_t = 1$ 时的退化（不要求几何性质，留到第 4 章）
- **过渡**：紧凑公式揭示了"擦除 + 写入"的两项结构，但谁是"被擦的旧值"还不直观——下章把它改写为显式带 $v^{\text{old}}$ 的等价形式。

### 第 3 章：等价改写——"先擦除后写入"与几何直觉

- **主要教学问题**：怎么把 delta 规则写得更直观？为什么两种形式等价？
- **对应范围**：Q3；C4, C6
- **正文要点**：
  - 改写为 $S_t = S_{t-1} - v_t^{\text{old}} k_t^\top + v_t^{\text{new}} k_t^\top$，其中 $v_t^{\text{old}} = S_{t-1} k_t$，$v_t^{\text{new}} = \beta_t v_t + (1-\beta_t) v_t^{\text{old}}$
  - 等价性证明（折叠块）：代入 $v_t^{\text{new}}$ 展开后回到 C3
  - $v_t^{\text{old}}$ 的语义：当前记忆对 $k_t$ 的响应（"如果现在查询 $k_t$，记忆会给什么"）
  - $v_t^{\text{new}}$ 的语义：新旧值的凸插值（$\beta_t$ 控制新值占比）
  - 几何直觉：$I - k k^\top$ 当 $\|k\| = 1, \beta = 1$ 时是沿 $k$ 方向的正交投影（C6）；只擦除 $k$ 方向，保留 $d-1$ 维正交补
- **讲解材料及职责**：
  - 推导（折叠块）：代入展开
  - 几何图示（ASCII）：2 维下投影到 $k^\perp$ 子空间
  - 公式（C6）：投影性质
- **前置知识安排**：凸组合、正交投影（基础线性代数）
- **完成检查**：
  - 把 $v_t^{\text{new}}$ 代入展开，验证等价
  - 说明 $\|k\| = 1, \beta = 1$ 时 $I - k k^\top$ 的几何意义
- **过渡**：等价形式揭示了 $\beta_t$ 的双重作用——既是新旧值插值权重，也是擦除强度。下章专门讨论 $\beta_t$ 的边界。

### 第 4 章：边界情况与 $\beta_t$ 的退化

- **主要教学问题**：$\beta_t$ 取极端值时 delta 规则退化为什么？
- **对应范围**：Q4；F2
- **正文要点**：
  - $\beta_t = 0$：$S_t = S_{t-1}$，记忆不变
  - $\beta_t = 1$：$S_t = S_{t-1}(I - k_t k_t^\top) + v_t k_t^\top$；当 $\|k_t\| = 1$ 时完全擦除并写入
  - 中间值 $\beta_t \in (0,1)$：部分擦除（新旧值凸插值）
  - 误解排查：$I - \beta k k^\top$ 仅在 $\beta = 1, \|k\| = 1$ 时是正交投影；其他情况是秩-1 扰动（不保范数）
- **讲解材料及职责**：
  - 边界代入（F2）：直接代入公式
  - 数字例子（d=2，对比 β=0.5 与 β=1）：展示部分擦除 vs. 完全擦除
- **前置知识安排**：第 2 章紧凑公式、第 3 章几何性质
- **完成检查**：
  - 说明 $\beta_t \to 0, \beta_t \to 1$ 的退化与前提条件
  - 指出 "$I - \beta k k^\top$ 总是投影矩阵" 的错误
- **过渡**：到此 delta 规则本身已讲完。下章把它放进 DeltaNet 模型，对比相邻概念。

### 第 5 章：DeltaNet 与相邻模型对比

- **主要教学问题**：DeltaNet 是什么模型？与线性注意力、Mamba2、Gated DeltaNet 在机制上有什么差异？
- **对应范围**：Q5；C7, C8, F3
- **正文要点**：
  - DeltaNet 定义：线性注意力 + delta 规则（Yang 2024 NeurIPS §2.2）
  - 机制对比表：
    - 线性注意力：$S_t = S_{t-1} + v_t k_t^\top$（纯加法，不擦除）
    - DeltaNet：$S_t = S_{t-1}(I - \beta_t k_t k_t^\top) + \beta_t v_t k_t^\top$（选择性擦除单个 key 方向）
    - Mamba2：$S_t = \alpha_t S_{t-1} + v_t k_t^\top$（标量全局衰减，无选择性）
    - Gated DeltaNet：$S_t = S_{t-1}(\alpha_t(I - \beta_t k_t k_t^\top)) + \beta_t v_t k_t^\top$（两者结合）
  - Gated DeltaNet 的设计动机：delta 规则精细但缺全局遗忘；$\alpha_t$ 提供快速清空；$\alpha_t \to 0$ 清空，$\alpha_t \to 1$ 退化为纯 delta 规则
  - Gated DeltaNet 与 Mamba2 的关系：Mamba2 是 Gated DeltaNet 在 $\beta_t = 0$ 时的退化（F3）
  - 实验数字一句话（N1, N2）：DeltaNet 在合成检索任务显著占优；在 memorize 任务上弱于 Mamba；1.3B LM PPL 略优于 Mamba/GLA
  - 工程实现一句话：Yang 2024 NeurIPS 通过 WY 表示实现 chunkwise 并行训练（不展开）；flash-linear-attention 库提供 Triton kernel
  - Kimi K3 KDA 动机一句话：Kimi Delta Attention 基于 delta 规则递归，是本概念的现实应用（不展开 KDA 架构）
- **讲解材料及职责**：
  - 对照表（4 行）：4 种模型的递归公式对比
  - 实验数字表（N1, N2）：1.3B PPL 与 MAD benchmark 关键数字
  - 代码（折叠块）：实现 delta 规则递归并与加性累加对比
- **前置知识安排**：Mamba2 公式作为对比项给出（不展开 SSM 理论）
- **完成检查**：
  - 说明 DeltaNet 与线性注意力、Mamba2 的关键机制差异
  - 说明 Gated DeltaNet 为什么要在 delta 规则上加 $\alpha_t$
  - 指出 Gated DeltaNet 在 $\alpha_t = 1$ 时退化为 DeltaNet
- **过渡**：进入文末来源与教学说明。

## 4.3 讲解顺序

按"为什么 → 是什么 → 怎么算 → 几何含义 → 边界 → 模型定位与对比"的顺序：

1. **第 1 章**先建立动机（线性注意力为什么会"记不清"）。最小事实：加性递归 + retrieval。不引入 delta 规则。
2. **第 2 章**给出 delta 规则的紧凑公式。一次引入新变量 $\beta_t$。不引入 $v^{\text{old}}, v^{\text{new}}$（留到第 3 章）。手算用最简数字。
3. **第 3 章**改写为等价形式，引入 $v^{\text{old}}, v^{\text{new}}$ 两个新量。给出几何直觉（投影）。一次引入一个新概念。
4. **第 4 章**讨论边界，不引入新变量。
5. **第 5 章**扩展到模型对比，引入 $\alpha_t$（Gated DeltaNet），与 $\beta_t$ 形成对照。

不使用尚未解释的术语解释新术语。两个概念互相依赖时（如 $v^{\text{old}}$ 依赖 $S_{t-1} k_t$ 的语义），先给出"如果现在查询 $k_t$ 会得到什么"的具体场景再引入符号。

## 4.4 贯穿例子

**主例子**：$d = 2$ 维、$L = 2$ 步的记忆序列。

**输入与变量**（首次出现时完整说明）：
- $d_k = d_v = 2$，$S_0 = \begin{pmatrix} 0 & 0 \\ 0 & 0 \end{pmatrix}$
- 第 1 步：$k_1 = (1, 0)^\top$（已归一化），$v_1 = (1, 0)^\top$，$\beta_1 = 1$
- 第 2 步：$k_2 = (1, 0)^\top$（与 $k_1$ 同方向，模拟"覆写同一 key"），$v_2 = (0, 1)^\top$，$\beta_2 = 1$

**第 1 章复用**（线性注意力检索碰撞）：
- 改用 $d = 2$, $L = 3$ 的构造（3 个两两非正交的 key），展示 $S k_2 \neq v_2$
- $k_1 = (1, 0), k_2 = (1, 1)/\sqrt 2, k_3 = (0, 1)$，$v_1 = (1, 0), v_2 = (0, 1), v_3 = (1, 1)$
- 手算 $S k_2$ 与 $v_2$ 的差异，量化 retrieval error

**第 2 章复用**（delta 规则一步更新）：
- 使用主例子第 1 步：手算 $S_1 = S_0(I - \beta_1 k_1 k_1^\top) + \beta_1 v_1 k_1^\top = v_1 k_1^\top = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}$

**第 3 章复用**（等价形式验证）：
- 使用主例子第 2 步：手算 $v_2^{\text{old}} = S_1 k_2 = (1, 0)^\top$（旧值），$v_2^{\text{new}} = \beta_2 v_2 + (1-\beta_2) v_2^{\text{old}} = v_2 = (0, 1)^\top$；$S_2 = S_1 - v_2^{\text{old}} k_2^\top + v_2^{\text{new}} k_2^\top = \begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix}$
- 验证与紧凑公式代入结果一致

**第 4 章复用**（边界对照）：
- 改 $\beta_2 = 0.5$：手算 $v_2^{\text{new}} = 0.5 (0,1) + 0.5 (1,0) = (0.5, 0.5)$；$S_2$ 不再是单一 value 的外积，而是新旧值的混合

**第 5 章复用**（模型对比）：
- 同一序列用线性注意力（加性累加）算 $S_2$，对比 delta 规则的结果，展示"加性不擦除"导致 $S_2^{\text{linear}} = v_1 k_1^\top + v_2 k_2^\top = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}$（两个值都还在），retrieval $S_2 k_2 = (1, 1) \neq v_2$
- 引入 Gated DeltaNet $\alpha_2 = 0$ 的退化情形：$S_2 = 0$（清空）

数字足够小可手算；每章复用时增加一个新概念（碰撞、紧凑公式、等价形式、边界退化、模型对比）。
