    Delta 规则与 DeltaNet：先擦除后写入的递归记忆更新

    当一个语言模型需要在 10 万 token 的对话里"记住"前面写过的某个人名，标准 Transformer 把所有历史塞进 KV cache（显存随长度线性增长），线性注意力把它们压成一个固定大小的矩阵状态（省显存但记不清）。后者为什么会"记不清"？能不能既保留固定大小状态、又记得清？Delta 规则就是回答后一半问题的递归更新规则。

    最容易误解

    • 把 DeltaNet 的 delta 规则当成训练阶段的 Widrow-Hoff delta rule —— 形式同构但作用对象不同：经典 delta rule 修改参数权重，DeltaNet delta rule 修改前向记忆矩阵状态。
    • 认为 delta 规则"完全擦除"旧 key-value 对 —— 仅当 $\beta_t = 1$ 且 $\|k_t\| = 1$ 时完全擦除；一般 $\beta_t \in (0,1)$ 是新旧值凸插值。
    • 认为 $I - \beta k k^\top$ 总是投影矩阵 —— 仅当 $\beta = 1$ 且 $\|k\| = 1$ 时是正交投影，其他情况是秩-1 扰动。

    主要依据：Schlag, Irie & Schmidhuber, ICML 2021（arXiv:2102.11174）首次将 delta rule 引入线性 Transformer；Yang, Wang, Zhang, Shen & Kim, NeurIPS 2024（arXiv:2406.06484）正式命名 DeltaNet 并给出并行训练算法；Yang, Kautz & Hatamizadeh, ICLR 2025（arXiv:2412.06464）提出 Gated DeltaNet。

    为什么线性注意力会"记不清"——key 碰撞与 retrieval error

    线性注意力家族的模型把整段历史压缩成一个固定大小的矩阵状态 $S \in \mathbb{R}^{d_v \times d_k}$，而不是像标准 Transformer 那样把所有过去的 key、value 向量都缓存下来。这是它能做到"显存与序列长度无关"的根本原因。但压缩有代价——下面要看这个代价是怎么产生的。

    线性注意力的递归更新是纯加性的：每来一个新样本 $(k_t, v_t)$，就把外积 $v_t k_t^\top$ 累加到状态上：

    $$S_t = S_{t-1} + v_t k_t^\top,\qquad S_0 = 0.$$

    读取（retrieval）用 query 乘状态：

    $$o_t = S_t q_t.$$

    本文引用线性注意力的完整讲解见 线性注意力（占位：该页面尚未生成，本页只给出 delta 规则所需的最小事实——加性递归与 retrieval）。下面直接用这两个公式推导"记不清"的来源。

    retrieval 时到底发生了什么

    把递归展开，$S_t = \sum_{i=1}^{t} v_i k_i^\top$。当 query 恰好等于某个历史 key（设 $q = k_j$）时，理想输出是 $v_j$。实际计算：

    $$S_t k_j = \sum_{i=1}^{t} v_i (k_i^\top k_j) = v_j \cdot (k_j^\top k_j) + \sum_{i \neq j} v_i (k_i^\top k_j).$$

    右边第二项 $\sum_{i \neq j} v_i (k_i^\top k_j)$ 就是 retrieval error——其他 key 与 $k_j$ 不正交时，它们的 value 会被"误检"进来。当所有 $k_i$ 两两正交且 $\|k_j\| = 1$ 时，$k_i^\top k_j = 0$（$i \neq j$）、$k_j^\top k_j = 1$，retrieval error 为 0，输出恰好是 $v_j$。但 $d$ 维空间最多容纳 $d$ 个两两正交的向量，当序列长度 $L > d$ 时，必然存在 $k_i^\top k_j \neq 0$，retrieval error 不为零。这就是 Yang et al. 2024 NeurIPS §2.1 所说的"key 'collisions'"[C2]。

    推导：retrieval error 的代数来源（展开 $S k_j$）

    由 $S_t = S_{t-1} + v_t k_t^\top$ 递归展开得 $S_t = \sum_{i=1}^{t} v_i k_i^\top$（归纳：$S_0 = 0$，每步加一个外积）。右乘 $k_j$：

    $$S_t k_j = \left(\sum_{i=1}^{t} v_i k_i^\top\right) k_j = \sum_{i=1}^{t} v_i (k_i^\top k_j).$$

    把 $i = j$ 项单独取出：

    $$S_t k_j = v_j (k_j^\top k_j) + \sum_{i \neq j} v_i (k_i^\top k_j).$$

    当 $\|k_j\| = 1$（即 $k_j^\top k_j = 1$）时，第一项就是 $v_j$；第二项即 retrieval error。若 $k_j$ 未归一化，第一项是 $\|k_j\|^2 v_j$，量级偏移但仍包含 $v_j$ 方向。

    手算例子：d=2 维、3 个非正交 key

    教学示例。 取 $d_k = d_v = 2$，3 步序列。为便于手算，key 不做归一化：

    步 $t$$k_t$$v_t$
    1$(1, 0)^\top$$(1, 0)^\top$
    2$(1, 1)^\top$$(0, 1)^\top$
    3$(0, 1)^\top$$(1, 1)^\top$

    三步累加后：

    $$S = v_1 k_1^\top + v_2 k_2^\top + v_3 k_3^\top = \begin{pmatrix}1 & 0 \\ 0 & 0\end{pmatrix} + \begin{pmatrix}0 & 0 \\ 1 & 1\end{pmatrix} + \begin{pmatrix}0 & 1 \\ 0 & 1\end{pmatrix} = \begin{pmatrix}1 & 1 \\ 1 & 2\end{pmatrix}.$$

    现在查询 $k_2 = (1, 1)^\top$，理想输出是 $v_2 = (0, 1)^\top$：

    $$S k_2 = \begin{pmatrix}1 & 1 \\ 1 & 2\end{pmatrix}\begin{pmatrix}1 \\ 1\end{pmatrix} = \begin{pmatrix}2 \\ 3\end{pmatrix} \neq v_2 = \begin{pmatrix}0 \\ 1\end{pmatrix}.$$

    展开式核对——按 $S k_2 = \sum_i v_i (k_i^\top k_2)$ 逐项计算：

    • $v_1$ 项：$k_1^\top k_2 = 1$，贡献 $1 \cdot v_1 = (1, 0)^\top$
    • $v_2$ 项：$k_2^\top k_2 = 2$，贡献 $2 \cdot v_2 = (0, 2)^\top$
    • $v_3$ 项：$k_3^\top k_2 = 1$，贡献 $1 \cdot v_3 = (1, 1)^\top$

    三项相加 $(1, 0)^\top + (0, 2)^\top + (1, 1)^\top = (2, 3)^\top$，与矩阵乘法一致。注意 $k_2$ 未归一化时 $v_2$ 项系数是 $k_2^\top k_2 = 2$ 而不是 1，所以"理想项"是 $2 v_2 = (0, 2)^\top$（外积定义下的自然量级），与实际返回 $(2, 3)^\top$ 的差值是 $(2, 1)^\top = v_1 + v_3$——正是其他 key 不正交带来的污染。本例 $k_2$ 未归一化只是为了手算方便，结论与归一化设置一致：非零的 $k_i^\top k_j$（$i \neq j$）把别的 value 拉进了检索结果。

    这段数字是想说清一件事：线性注意力的"加性累加"不会主动擦除任何东西，所有外积都堆在 $S$ 里，互相干扰。要让模型"记清"，需要在写入新 key-value 时先擦掉旧 key 方向已存的内容。这正是 delta 规则做的事。

    本章已经看到，线性注意力的 retrieval error 来自"只写不删"。下一章给出 delta 规则的形式定义——它把"擦除"显式放进递归里。

    Delta 规则的紧凑公式与手算

    Delta 规则把线性注意力的"纯加性累加"替换为"先擦除后写入"的递归。它的紧凑形式是：

    $$\boxed{\,S_t = S_{t-1}(I - \beta_t k_t k_t^\top) + \beta_t v_t k_t^\top\,}\qquad\text{（DeltaNet 形式，C3）}$$

    公式出现前先说清它要解决的问题：上一章看到加性累加 $S_t = S_{t-1} + v_t k_t^\top$ 在 $L > d$ 时碰撞不可避免，需要一个能"擦除旧 key 方向"的更新规则。Delta 规则就是这种规则。

    每个符号：

    • $S_t \in \mathbb{R}^{d_v \times d_k}$：第 $t$ 步的矩阵状态（记忆矩阵）。行数 $d_v$ 对应 value 维度，列数 $d_k$ 对应 key 维度。本页默认 $d_v = d_k = d$。
    • $S_{t-1}$：上一步的状态，公式右侧第一个因子。
    • $I \in \mathbb{R}^{d_k \times d_k}$：单位矩阵，与 $k_t$ 同维。
    • $k_t \in \mathbb{R}^{d_k}$：第 $t$ 步的 key 向量，由输入 $x_t$ 经投影 $k_t = W_K x_t$ 得到。
    • $v_t \in \mathbb{R}^{d_v}$：第 $t$ 步的 value 向量，由 $v_t = W_V x_t$ 得到。
    • $\beta_t = \sigma(W_\beta x_t) \in (0, 1)$：写入强度（论文中也称"学习率"），由 sigmoid 输出。$\beta_t$ 是数据相关的——模型根据当前输入 $x_t$ 决定本步要"擦多狠、写多深"。
    • $\sigma(z) = 1/(1 + e^{-z})$：sigmoid 函数。
    • $W_Q, W_K, W_V, W_\beta$：可学习参数。

    形状检查（验证维度自洽）：$k_t k_t^\top$ 是 $(d_k, 1) \times (1, d_k) = (d_k, d_k)$；$I - \beta_t k_t k_t^\top$ 是 $(d_k, d_k)$；$S_{t-1}(I - \beta_t k_t k_t^\top)$ 是 $(d_v, d_k) \cdot (d_k, d_k) = (d_v, d_k)$；$\beta_t v_t k_t^\top$ 是标量 $\times (d_v, 1) \times (1, d_k) = (d_v, d_k)$；两项相加形状一致，结果 $(d_v, d_k)$。检查通过。

    两个快速边界检查。第一，若 $\beta_t = 0$，则 $S_t = S_{t-1}(I) + 0 = S_{t-1}$，记忆完全不变——这一步不写也不擦。第二，若 $\beta_t = 1$，则 $S_t = S_{t-1}(I - k_t k_t^\top) + v_t k_t^\top$，新值完全覆盖；当 $\|k_t\| = 1$ 时 $I - k_t k_t^\top$ 是沿 $k_t$ 方向的正交投影（详见第 3 章），意味着先擦除 $k_t$ 方向的旧分量、再写入新值。$\beta_t$ 介于 0 和 1 之间时是部分擦除——新旧值按 $\beta_t$ 加权插值，第 3 章给出显式形式。

    来源与命名

    Delta 规则的命名与形式类比于经典 Widrow-Hoff 1960 delta rule：

    $$\text{经典：}\;w \leftarrow w + \eta (y - \hat y) x,\qquad \text{DeltaNet：}\;S_t = S_{t-1} + \beta_t (v_t - S_{t-1} k_t) k_t^\top.$$

    两者结构同构——都是"误差 $\times$ 学习率 $\times$ 输入"。但作用对象不同：经典 delta rule 修改训练阶段的参数权重 $w$（一个固定的网络参数）；DeltaNet delta rule 修改前向推理阶段的记忆矩阵 $S$（随输入变化的短期状态）。Schlag et al. 2021 §4.2 用 "akin to the famous error-correcting delta-rule" 描述两者关系，是类比而非等同[C5]。Widrow & Hoff 1960 原文是 "Adaptive switching circuits", IRE WESCON Convention Record, pp. 96–104。

    DeltaNet 这个名字在三篇论文中的演化：

    手算一步：$\beta_t = 1$ 的最简更新

    教学示例。 取 $d = 2$ 维，初始 $S_0 = \begin{pmatrix}0 & 0 \\ 0 & 0\end{pmatrix}$，第 1 步 $k_1 = (1, 0)^\top$（已归一化，$\|k_1\| = 1$），$v_1 = (1, 0)^\top$，$\beta_1 = 1$。

    先算 $k_1 k_1^\top$：

    $$k_1 k_1^\top = \begin{pmatrix}1 \\ 0\end{pmatrix}\begin{pmatrix}1 & 0\end{pmatrix} = \begin{pmatrix}1 & 0 \\ 0 & 0\end{pmatrix}.$$

    然后 $I - \beta_1 k_1 k_1^\top$：

    $$I - k_1 k_1^\top = \begin{pmatrix}1 & 0 \\ 0 & 1\end{pmatrix} - \begin{pmatrix}1 & 0 \\ 0 & 0\end{pmatrix} = \begin{pmatrix}0 & 0 \\ 0 & 1\end{pmatrix}.$$

    $S_0(I - k_1 k_1^\top) = 0$（因 $S_0 = 0$）。再算 $\beta_1 v_1 k_1^\top = v_1 k_1^\top$：

    $$v_1 k_1^\top = \begin{pmatrix}1 \\ 0\end{pmatrix}\begin{pmatrix}1 & 0\end{pmatrix} = \begin{pmatrix}1 & 0 \\ 0 & 0\end{pmatrix}.$$

    合起来：

    $$S_1 = S_0(I - k_1 k_1^\top) + v_1 k_1^\top = 0 + \begin{pmatrix}1 & 0 \\ 0 & 0\end{pmatrix} = \begin{pmatrix}1 & 0 \\ 0 & 0\end{pmatrix}.$$

    第 2 步把同一个 key $k_2 = (1, 0)^\top = k_1$ 写入新值 $v_2 = (0, 1)^\top$，$\beta_2 = 1$。这模拟"模型改变主意——同一个 key 现在应该关联到另一个 value"的场景。$I - k_2 k_2^\top$ 还是 $\begin{pmatrix}0 & 0 \\ 0 & 1\end{pmatrix}$，于是：

    $$S_1(I - k_2 k_2^\top) = \begin{pmatrix}1 & 0 \\ 0 & 0\end{pmatrix}\begin{pmatrix}0 & 0 \\ 0 & 1\end{pmatrix} = \begin{pmatrix}0 & 0 \\ 0 & 0\end{pmatrix},$$ $$v_2 k_2^\top = \begin{pmatrix}0 \\ 1\end{pmatrix}\begin{pmatrix}1 & 0\end{pmatrix} = \begin{pmatrix}0 & 0 \\ 1 & 0\end{pmatrix},$$ $$S_2 = \begin{pmatrix}0 & 0 \\ 0 & 0\end{pmatrix} + \begin{pmatrix}0 & 0 \\ 1 & 0\end{pmatrix} = \begin{pmatrix}0 & 0 \\ 1 & 0\end{pmatrix}.$$

    现在检索 $k_2$：$S_2 k_2 = \begin{pmatrix}0 & 0 \\ 1 & 0\end{pmatrix}\begin{pmatrix}1 \\ 0\end{pmatrix} = \begin{pmatrix}0 \\ 1\end{pmatrix} = v_2$。Delta 规则成功覆盖了旧关联——查询 $k_2$ 返回新的 $v_2$ 而非旧的 $v_1$。

    对照线性注意力（加性累加）在同一序列上的结果：

    $$S_2^{\text{linear}} = v_1 k_1^\top + v_2 k_2^\top = \begin{pmatrix}1 & 0 \\ 0 & 0\end{pmatrix} + \begin{pmatrix}0 & 0 \\ 1 & 0\end{pmatrix} = \begin{pmatrix}1 & 0 \\ 1 & 0\end{pmatrix},$$ $$S_2^{\text{linear}} k_2 = \begin{pmatrix}1 & 0 \\ 1 & 0\end{pmatrix}\begin{pmatrix}1 \\ 0\end{pmatrix} = \begin{pmatrix}1 \\ 1\end{pmatrix} \neq v_2 = \begin{pmatrix}0 \\ 1\end{pmatrix}.$$

    加性累加不擦除，旧的 $v_1 = (1, 0)^\top$ 还留在 $S$ 的第一行，查询 $k_2$ 时把 $v_1$ 也拽了出来。Delta 规则因为先擦除 $k_2$ 方向的旧值，所以查询干净。这就是 delta 规则解决 key 碰撞的方式。

    紧凑公式揭示了"擦除 + 写入"的两项结构，但"被擦的旧值是谁"还不直观。下一章把它改写为显式带 $v^{\text{old}}$ 的等价形式。

    等价改写——"先擦除后写入"与几何直觉

    紧凑公式 $S_t = S_{t-1}(I - \beta_t k_t k_t^\top) + \beta_t v_t k_t^\top$ 把"擦除"藏在矩阵乘法里，看不清"擦的是什么"。把它展开成等价的"先擦除后写入"形式就清楚了。

    定义两个中间量：

    $$v_t^{\text{old}} = S_{t-1} k_t \qquad\text{（旧值：当前记忆对 } k_t \text{ 的响应）}$$ $$v_t^{\text{new}} = \beta_t v_t + (1 - \beta_t) v_t^{\text{old}} \qquad\text{（新值：新旧值的凸插值）}$$

    $v_t^{\text{old}}$ 的语义——"如果现在查询 $k_t$，记忆会返回什么"。它是 $S_{t-1}$ 右乘 $k_t$ 的结果，与 retrieval $o = S q$ 在 $q = k_t$ 时完全一致。$v_t^{\text{new}}$ 是新旧值的凸组合（$\beta_t$ 与 $1-\beta_t$ 都非负且和为 1），$\beta_t$ 越大新值占比越大。

    用这两个量把 delta 规则写成：

    $$\boxed{\,S_t = S_{t-1} - v_t^{\text{old}} k_t^\top + v_t^{\text{new}} k_t^\top\,}\qquad\text{（"先擦除后写入"形式，C4）}$$

    这一形式字面对应"先擦除后写入"——先从 $S_{t-1}$ 减去 $v_t^{\text{old}} k_t^\top$（移除当前 $k_t$ 方向已存的内容），再加上 $v_t^{\text{new}} k_t^\top$（写入插值后的新值）。

    推导：代入 $v_t^{\text{new}}$ 验证与紧凑形式（C3）等价

    已知 $v_t^{\text{new}} = \beta_t v_t + (1-\beta_t) v_t^{\text{old}}$，$v_t^{\text{old}} = S_{t-1} k_t$。代入 C4：

    $$S_t = S_{t-1} - v_t^{\text{old}} k_t^\top + (\beta_t v_t + (1-\beta_t) v_t^{\text{old}}) k_t^\top$$

    展开右端：

    $$= S_{t-1} - v_t^{\text{old}} k_t^\top + \beta_t v_t k_t^\top + (1-\beta_t) v_t^{\text{old}} k_t^\top$$

    合并 $v_t^{\text{old}} k_t^\top$ 的系数：$-1 + (1-\beta_t) = -\beta_t$，所以

    $$= S_{t-1} - \beta_t v_t^{\text{old}} k_t^\top + \beta_t v_t k_t^\top$$

    把 $v_t^{\text{old}} = S_{t-1} k_t$ 代回：

    $$= S_{t-1} - \beta_t (S_{t-1} k_t) k_t^\top + \beta_t v_t k_t^\top = S_{t-1}(I - \beta_t k_t k_t^\top) + \beta_t v_t k_t^\top$$

    最后一步用了矩阵分配律：$S_{t-1} - \beta_t S_{t-1} k_t k_t^\top = S_{t-1}(I - \beta_t k_t k_t^\top)$。这与 C3 完全一致。证毕。

    回到手算例子

    教学示例。 用第 2 章末尾的第 2 步：$S_1 = \begin{pmatrix}1 & 0 \\ 0 & 0\end{pmatrix}$，$k_2 = (1, 0)^\top$，$v_2 = (0, 1)^\top$，$\beta_2 = 1$。

    先算旧值：$v_2^{\text{old}} = S_1 k_2 = \begin{pmatrix}1 & 0 \\ 0 & 0\end{pmatrix}\begin{pmatrix}1 \\ 0\end{pmatrix} = \begin{pmatrix}1 \\ 0\end{pmatrix} = v_1$。这正是上一步写入的旧值——记忆里 $k_2$ 方向当前存的就是 $v_1$。

    新值（$\beta_2 = 1$）：$v_2^{\text{new}} = 1 \cdot v_2 + 0 \cdot v_2^{\text{old}} = v_2 = (0, 1)^\top$。完全用新值，丢弃旧值。

    套入 C4：

    $$S_2 = S_1 - v_2^{\text{old}} k_2^\top + v_2^{\text{new}} k_2^\top = \begin{pmatrix}1 & 0 \\ 0 & 0\end{pmatrix} - \begin{pmatrix}1 \\ 0\end{pmatrix}\begin{pmatrix}1 & 0\end{pmatrix} + \begin{pmatrix}0 \\ 1\end{pmatrix}\begin{pmatrix}1 & 0\end{pmatrix}$$ $$= \begin{pmatrix}1 & 0 \\ 0 & 0\end{pmatrix} - \begin{pmatrix}1 & 0 \\ 0 & 0\end{pmatrix} + \begin{pmatrix}0 & 0 \\ 1 & 0\end{pmatrix} = \begin{pmatrix}0 & 0 \\ 1 & 0\end{pmatrix}.$$

    与第 2 章紧凑公式的结果一致——两种形式确实等价。这次我们看清楚了"擦的是什么"：擦的是 $v_2^{\text{old}} k_2^\top = v_1 k_2^\top$，即上一步写入的旧关联。

    几何直觉：$I - k k^\top$ 是投影矩阵

    当 $\|k_t\| = 1$ 且 $\beta_t = 1$ 时，矩阵 $I - k_t k_t^\top$ 有特殊几何含义——它是沿 $k_t$ 方向的正交投影。设 $P = I - k k^\top$，验证两条性质：

    • 幂等性：$P^2 = (I - k k^\top)(I - k k^\top) = I - 2 k k^\top + k (k^\top k) k^\top = I - 2 k k^\top + k \cdot 1 \cdot k^\top = I - k k^\top = P$（用 $\|k\| = 1$ 即 $k^\top k = 1$）。
    • 对称性：$P^\top = (I - k k^\top)^\top = I - k k^\top = P$。

    幂等 + 对称 = 正交投影。它把任何向量 $x$ 投影到与 $k$ 正交的子空间 $k^\perp$：$Px = x - k(k^\top x) = x - (k^\top x) k$，即"去掉 $x$ 在 $k$ 方向的分量"。Yang et al. 2024 NeurIPS §3.3 明确说"only erases information in one subspace while keeping the other $d-1$ subspace intact"[C6]。工程实现中通过 L2 归一化 key 向量获得此投影性质。

    2 维直觉：$k = (1, 0)^\top$，$I - k k^\top = \begin{pmatrix}0 & 0 \\ 0 & 1\end{pmatrix}$。任意 $x = (a, b)^\top$ 被 $P$ 乘后得 $(0, b)^\top$——$x$ 方向分量被擦掉，$y$ 方向分量保留。这就是"只擦 $k$ 方向、保正交补"的几何含义。

    2 维投影示意（k = (1,0)ᵀ, β = 1, P = I - k kᵀ）

       y
       ↑
       │
   b   ●     ← (a, b) 投影前
       │
       │   P 把 x 分量擦掉（k 方向）
       │   保留 y 分量（k⊥方向）
       ↓
       ●     ← (0, b) 投影后 = P·(a,b)ᵀ
       │
       └───────────────→ x
               a

    当 $\beta_t < 1$ 或 $\|k_t\| \neq 1$ 时，$I - \beta_t k_t k_t^\top$ 退化为秩-1 扰动（不再是正交投影），不保范数也不幂等。这是常见误解——投影性质需要两个前提同时满足，下一章详细讨论边界。

    完成本章后，用下面几个问题检查自己是否跟上：

    • 把 $v_t^{\text{new}} = \beta_t v_t + (1-\beta_t) v_t^{\text{old}}$ 代入 C4 展开到 C3，每一步说明用了什么代数规则。
    • $v_t^{\text{old}} = S_{t-1} k_t$ 的语义是什么？为什么说它就是"如果现在查询 $k_t$ 会返回什么"。
    • $\|k\| = 1, \beta = 1$ 时 $I - k k^\top$ 为什么是正交投影？幂等性和对称性各验证一次。

    到此 delta 规则本身已经讲完——紧凑公式、等价形式、几何直觉都有了。下一章专门讨论 $\beta_t$ 在极端值下的退化情形，澄清常见误解。

    边界情况与 $\beta_t$ 的退化

    把 $\beta_t$ 推到两个极端，看 delta 规则分别退化为哪种更新规则。这是验证理解的最简方式，也是误解多发点。

    $\beta_t = 0$：记忆完全不变

    代入 $S_t = S_{t-1}(I - 0 \cdot k_t k_t^\top) + 0 \cdot v_t k_t^\top = S_{t-1} \cdot I + 0 = S_{t-1}$。这一步既不擦也不写，记忆保持上一步状态。语义上——模型根据当前输入 $x_t$ 判定"本步不需要更新"，把 $\beta_t$ 推到 0 即可。

    $\beta_t = 1$：完全覆盖（当 $\|k\| = 1$ 时）

    代入 $S_t = S_{t-1}(I - k_t k_t^\top) + v_t k_t^\top$。当 $\|k_t\| = 1$ 时，$I - k_t k_t^\top$ 是沿 $k_t$ 方向的正交投影（C6），意味着把 $S_{t-1}$ 中所有"沿 $k_t$ 方向"的分量擦干净，再写入新值 $v_t k_t^\top$。旧 key-value 关联被完全替换。

    前提条件：$\|k_t\| = 1$。如果 $k_t$ 未归一化，$\beta_t = 1$ 时 $I - k_t k_t^\top$ 不是投影——它仍是秩-1 扰动，但擦除强度由 $\|k_t\|^2$ 决定：把任意 $x$ 投影为 $x - k_t(k_t^\top x)$，$k_t$ 越长擦得越狠，可能"擦过头"。Yang 2024 NeurIPS §3.3 说工程实现中对 key 做 L2 归一化以避免这个问题。

    中间值 $\beta_t \in (0, 1)$：部分擦除

    这是最常见的情形。用 C4 形式看最清楚：

    $$S_t = S_{t-1} - v_t^{\text{old}} k_t^\top + \underbrace{(\beta_t v_t + (1-\beta_t) v_t^{\text{old}})}_{v_t^{\text{new}}} k_t^\top.$$

    $v_t^{\text{new}}$ 是新旧值的凸插值——$\beta_t$ 越大新值占比越大。把 $v_t^{\text{new}} k_t^\top$ 写回时，新关联不是"完全替换"而是"按 $\beta_t$ 加权混合"。

    教学示例。 把第 2 章末尾的例子改 $\beta_2 = 0.5$，其他不变：$S_1 = \begin{pmatrix}1 & 0 \\ 0 & 0\end{pmatrix}$，$k_2 = (1, 0)^\top$，$v_2 = (0, 1)^\top$。先算 $v_2^{\text{old}} = S_1 k_2 = (1, 0)^\top$，再算 $v_2^{\text{new}} = 0.5 \cdot (0, 1)^\top + 0.5 \cdot (1, 0)^\top = (0.5, 0.5)^\top$。

    代入 C4：

    $$S_2 = \begin{pmatrix}1 & 0 \\ 0 & 0\end{pmatrix} - \begin{pmatrix}1 \\ 0\end{pmatrix}\begin{pmatrix}1 & 0\end{pmatrix} + \begin{pmatrix}0.5 \\ 0.5\end{pmatrix}\begin{pmatrix}1 & 0\end{pmatrix}$$ $$= \begin{pmatrix}1 & 0 \\ 0 & 0\end{pmatrix} - \begin{pmatrix}1 & 0 \\ 0 & 0\end{pmatrix} + \begin{pmatrix}0.5 & 0 \\ 0.5 & 0\end{pmatrix} = \begin{pmatrix}0.5 & 0 \\ 0.5 & 0\end{pmatrix}.$$

    检索 $k_2$：$S_2 k_2 = (0.5, 0.5)^\top = v_2^{\text{new}}$。返回的是新旧值各半的插值——既不是旧的 $v_1 = (1, 0)^\top$，也不是新的 $v_2 = (0, 1)^\top$，而是 $(0.5, 0.5)^\top$。这就是"部分擦除"的语义：记忆里的旧关联被部分替换为新关联。

    误解排查：$I - \beta k k^\top$ 不是"总是投影"

    把投影性质的前提条件列清楚：

    条件$I - \beta k k^\top$ 是什么擦除行为
    $\beta = 1$ 且 $\|k\| = 1$正交投影（幂等 + 对称）完全擦除 $k$ 方向，保留正交补
    $\beta = 1$ 但 $\|k\| \neq 1$秩-1 扰动，非投影擦除强度由 $\|k\|^2$ 决定，可能擦过头
    $\beta \in (0, 1)$秩-1 扰动，非投影部分擦除（新旧值凸插值）
    $\beta = 0$单位矩阵 $I$不擦除（记忆不变）

    把 "$I - \beta k k^\top$ 是投影矩阵" 当成无前提结论是常见误解——它只在 $\beta = 1$ 且 $\|k\| = 1$ 时成立。

    完成本章后，用下面几个问题检查自己是否跟上：

    • $\beta_t = 0$ 时 delta 规则退化为？$\beta_t = 1$ 且 $\|k_t\| = 1$ 时退化为？
    • 用一句话说明 $\beta_t \in (0, 1)$ 时为什么是"部分擦除"而非"完全擦除"。
    • 指出错误："$I - \beta k k^\top$ 在任何 $\beta$ 下都是投影矩阵"。

    到此 delta 规则本身已经讲完。下一章把它放进 DeltaNet 模型，并对比相邻概念——线性注意力、Mamba2、Gated DeltaNet。

    DeltaNet 与相邻模型对比

    DeltaNet 是什么

    DeltaNet 就是把线性注意力的加性累加替换为 delta 规则的模型。Yang et al. 2024 NeurIPS §2.2 的原话——"DeltaNet: Linear Transformers with the Delta Update Rule"。一句话定义：

    DeltaNet = 线性注意力的递归骨架 + delta 规则替换加性累加 + （工程上）L2 归一化 key/query + chunkwise 并行训练算法

    本页讲的是"递归骨架 + delta 规则"这两部分。L2 归一化与并行训练算法属于工程实现，本页不展开（详见 Yang 2024 NeurIPS §3）。

    4 种记忆更新规则对比

    把 DeltaNet 放进"矩阵状态 + 结构化递归"家族，与线性注意力、Mamba2、Gated DeltaNet 并排对比：

    模型递归更新规则擦除机制写入机制
    线性注意力[C1]$S_t = S_{t-1} + v_t k_t^\top$无加性累加
    DeltaNet[C3]$S_t = S_{t-1}(I - \beta_t k_t k_t^\top) + \beta_t v_t k_t^\top$沿 $k_t$ 方向选择性擦除新旧值凸插值写入
    Mamba2[C7]$S_t = \alpha_t S_{t-1} + v_t k_t^\top$整体标量衰减（$\alpha_t \in (0,1)$）加性累加
    Gated DeltaNet[C7]$S_t = S_{t-1}(\alpha_t(I - \beta_t k_t k_t^\top)) + \beta_t v_t k_t^\top$整体衰减 + 方向擦除（双重）新旧值凸插值写入

    三组对比：

    • 线性注意力 vs. DeltaNet：两者都是矩阵状态 + 加性写入，但线性注意力不擦除，DeltaNet 用 $I - \beta k k^\top$ 选择性擦除当前 key 方向。第 1 章已展示线性注意力在 $L > d$ 时的碰撞问题。
    • DeltaNet vs. Mamba2：DeltaNet 的擦除是"方向性"的（只擦 $k_t$ 方向，保留正交补）；Mamba2 的擦除是"标量全局"的（$\alpha_t$ 乘到整个 $S_{t-1}$ 上，所有方向均匀衰减）。DeltaNet 精细但缺少全局遗忘，Mamba2 全局但无选择性。
    • Gated DeltaNet = Mamba2 + DeltaNet：把 $\alpha_t$ 的标量衰减嵌进 delta 规则的 $I - \beta k k^\top$ 前面，得到 $\alpha_t(I - \beta_t k_t k_t^\top)$。这是 Gated DeltaNet 的核心设计——同时具备方向擦除（delta 规则）与全局衰减（Mamba2 风格遗忘门）[C7]。

    Gated DeltaNet 的退化

    Gated DeltaNet 公式 $S_t = S_{t-1}(\alpha_t(I - \beta_t k_t k_t^\top)) + \beta_t v_t k_t^\top$ 在两个极端下退化为已知模型[F3]：

    • $\alpha_t \to 1$：$S_t = S_{t-1}(I - \beta_t k_t k_t^\top) + \beta_t v_t k_t^\top$——退化为 DeltaNet。
    • $\beta_t \to 0$ 且 $\alpha_t$ 任意：$S_t = S_{t-1}(\alpha_t \cdot I) + 0 = \alpha_t S_{t-1}$——退化为 Mamba2 在 $v_t = 0$ 时的特殊情形（无新值写入）。
    • $\alpha_t \to 0$：$S_t = 0 + \beta_t v_t k_t^\top$——清空所有历史，只保留当前步的写入。

    这是 Yang 2024 ICLR 2025 §3.1 设计动机的代数体现——"gating enables rapid memory erasure while the delta rule facilitates targeted updates"，$\alpha_t$ 与 $\beta_t$ 各管一摊。

    DeltaNet 在 3 类 recall / copy 任务上满分（In-Context Recall、Noisy Recall、Selective Copy 得 100），仅 Fuzzy Recall 较弱（35.7）[N2]——这正是 delta 规则"先擦除后写入"擅长的场景（key-value 关联需要被精确覆写）。但在 Memorize 任务上反而最弱（52.8 vs. Mamba 89.5）——Mamba 的标量衰减更擅长"渐进式记住全部历史"，DeltaNet 的方向擦除对"全部保留"反而不利。这说明 delta 规则不是万能方案，而是针对"key-value 检索"场景的设计选择。

    1.3B / 100B tokens 语言建模上[N1]：DeltaNet (w. conv) Wiki PPL = 16.87, LMB PPL = 12.21；Mamba (w. conv) = 17.06 / 13.89；GLA = 17.25 / 14.92；Transformer++ = 16.85 / 13.44。DeltaNet 略优于 Mamba 和 GLA，与 Transformer++ 接近。

    工程实现与现实应用

    Yang 2024 NeurIPS §3 给出 delta 规则的 chunkwise 并行训练算法，基于 Bischof & Van Loan 1985 的 WY 表示（Householder 矩阵乘积的紧凑形式），使得训练时不需逐步串行递归。这部分属于数值线性代数与工程，本页不展开。开源实现在 flash-linear-attention 库（fla-org/flash-linear-attention，Triton kernel）。

    本概念的现实应用——Kimi K3 模型的 KDA（Kimi Delta Attention）即基于 delta 规则递归。KDA 自身是独立架构概念，超出本页范围。

    代码：实现 delta 规则递归并与加性累加对比 
    import numpy as np

# 教学示例：d=2 维，2 步序列，对比 delta 规则与线性注意力加性累加
# 用以验证正文手算结果

d = 2
S0 = np.zeros((d, d))

# 同一序列：第 1 步写 (k_1, v_1)，第 2 步用相同 key 写新值 v_2
k1 = np.array([1.0, 0.0])
v1 = np.array([1.0, 0.0])
k2 = np.array([1.0, 0.0])  # 与 k1 同方向，模拟"覆写同一 key"
v2 = np.array([0.0, 1.0])
beta1 = 1.0
beta2 = 1.0

# === 线性注意力：加性累加 ===
S_lin = S0.copy()
S_lin = S_lin + np.outer(v1, k1)  # step 1
S_lin = S_lin + np.outer(v2, k2)  # step 2
print("Linear S_2 =\n", S_lin)
print("Linear S_2 @ k_2 =", S_lin @ k2, " (expected mismatch with v_2 =", v2, ")")
print()

# === Delta 规则：紧凑公式 S_t = S_{t-1}(I - beta k k^T) + beta v k^T ===
I_mat = np.eye(d)

def delta_step(S_prev, k, v, beta):
    kkT = np.outer(k, k)
    return S_prev @ (I_mat - beta * kkT) + beta * np.outer(v, k)

S_del = S0.copy()
S_del = delta_step(S_del, k1, v1, beta1)  # step 1
print("Delta S_1 =\n", S_del)
S_del = delta_step(S_del, k2, v2, beta2)  # step 2
print("Delta S_2 =\n", S_del)
print("Delta S_2 @ k_2 =", S_del @ k2, " (expected = v_2 =", v2, ")")
print()

# === 等价形式验证：v_old, v_new ===
S_del2 = S0.copy()
S_del2 = delta_step(S_del2, k1, v1, beta1)  # 重建 S_1
v_old = S_del2 @ k2
v_new = beta2 * v2 + (1 - beta2) * v_old
S_del2 = S_del2 - np.outer(v_old, k2) + np.outer(v_new, k2)
print("Equivalent form S_2 =\n", S_del2)
print("Matches compact form:", np.allclose(S_del2, S_del))

    验证的机制：代码实现 C3 紧凑公式与 C4 等价形式，逐行对应正文 §2 的紧凑公式与 §3 的代入推导。同序列下线性注意力返回 $(1, 1)^\top$（受 $v_1$ 污染），delta 规则返回 $(0, 1)^\top = v_2$（旧值被擦除）。

    观察重点：$\beta_t = 1$ 时 $S_2$ 的第一行被完全擦成 0（因 $k_2 = (1, 0)^\top$ 只擦第一行方向），第二行写入 $v_2$。这正是第 3 章投影性质的数值体现。

    教学简化：教学实现使用 numpy 标量循环逐手算 step；真实工程用 Triton chunkwise kernel（Yang 2024 NeurIPS §3）批量并行计算，并融合 L2 归一化与 kernel。本代码不实现 batch、不处理多头、不归一化 key。

    C7（Gated DeltaNet 与 Mamba2 公式）：Yang 2024 ICLR 2025 arXiv:2412.06464 §3.1 Eq. 8（gated delta rule 公式）与 §2.2（Mamba2 公式 $S_t = \alpha_t S_{t-1} + v_t k_t^\top$）。

    C8（实验对比）：Yang 2024 NeurIPS arXiv:2406.06484 §4.1 Table 2（MAD benchmark）与 §4.2 Table 3（1.3B LM PPL）。

    核心公式与来源

    F1（retrieval 展开 $S k_j = v_j + \sum_{i \neq j} (k_i^\top k_j) v_i$）：代数恒等式，由 C1 $S = \sum_i v_i k_i^\top$ 直接展开得到。Yang 2024 NeurIPS §2.1 引用为 retrieval error 的来源。

    F2（$\beta_t = 0$ 与 $\beta_t = 1$ 边界）：由 C3 直接代入得到；$\beta_t = 1, \|k\| = 1$ 时的投影性质见 C6。

    F3（Gated DeltaNet 退化）：由 C7 直接代入得到；Mamba2 形式见 Yang 2024 ICLR 2025 §2.2。

    教学示例

    本页构造了两组教学数字，均非真实模型数据：

    • 第 1 章碰撞例子：$d = 2$ 维、$L = 3$ 步、key 未归一化（$k_1 = (1,0)^\top, k_2 = (1,1)^\top, k_3 = (0,1)^\top$，$v_1 = (1,0)^\top, v_2 = (0,1)^\top, v_3 = (1,1)^\top$）。构造目的：用最小维度手算展示 retrieval error 的代数来源。
    • 第 2-4 章主例子：$d = 2$ 维、$L = 2$ 步、key 归一化（$k_1 = k_2 = (1,0)^\top$，$v_1 = (1,0)^\top, v_2 = (0,1)^\top$，$\beta \in \{0.5, 1\}$）。构造目的：用最小维度手算展示 delta 规则的紧凑公式、等价形式、边界退化，并对比加性累加。第 2 步故意让 $k_2 = k_1$，模拟"模型改变主意、覆写同一 key 的关联"。

    教学解释与类比边界

    "先擦除后写入"类比：把 $I - k k^\top$ 解释为"沿 $k$ 方向的投影"、把 $- v^{\text{old}} k^\top + v^{\text{new}} k^\top$ 解释为"擦旧值写新值"是教学解释，服务于理解 C3 与 C4 的等价关系。失效边界：(1) 当 $\beta \neq 1$ 时是部分擦除（凸插值），不是完全替换；(2) 当 $\|k\| \neq 1$ 时 $I - \beta k k^\top$ 不是投影，是秩-1 扰动；(3) 投影只擦一个方向，不擦整个矩阵——Mamba2 的标量衰减才擦整个矩阵。正式判断仍以 C3 公式为准。

    "DeltaNet vs. Mamba2 方向擦除 vs. 标量衰减"类比：把 DeltaNet 比作"用橡皮擦掉一个字"、把 Mamba2 比作"把整页纸都晒褪色"是教学解释，服务于理解方向擦除与标量衰减的差异。失效边界：(1) DeltaNet 的擦除强度由 $\beta_t$ 控制，不一定是完全擦除；(2) Mamba2 的 $\alpha_t$ 也可以接近 1（几乎不擦），与"晒褪色"的强语义不完全对应；(3) 两者都能配合 $v_t k_t^\top$ 写入，不是纯擦除操作。

    教学简化及其限制

    • key 未归一化（第 1 章碰撞例子）：为便于手算，第 1 章使用未归一化的 $k$（如 $k_2 = (1,1)^\top$）。真实 DeltaNet 工程实现中 key 经 L2 归一化（Yang 2024 NeurIPS §3.3），保证 $I - k k^\top$ 是正交投影。本页第 2-4 章主例子使用已归一化的 $k$，与工程一致。简化不影响 retrieval error 的代数来源结论。
    • $d_v = d_k = 2$ 极小维度：为便于手算选 $d = 2$。真实模型 $d$ 通常为 64 或 128。$d$ 越大可容纳的正交 key 越多，但 $L > d$ 时碰撞仍不可避免。本页结论不依赖具体 $d$ 值。
    • 未展开 WY 表示与并行训练算法：Yang 2024 NeurIPS §3 用 Bischof & Van Loan 1985 的 WY 表示把 delta 规则的递归改写为 chunkwise 并行形式，使训练时可在 chunk 内并行计算。本页只提及存在、不展开推导，因为它属于数值线性代数与工程实现，不影响 delta 规则本身的概念理解。
    • 未展开多头实现：真实 DeltaNet 与 Gated DeltaNet 是多头模型，每个 head 维护独立的 $S$。本页只讲单头递归，多头属于工程。
    • 代码使用 numpy 标量循环：教学代码逐 step 循环；真实工程用 Triton chunkwise kernel 批量并行。教学代码只验证公式正确性，不验证训练效率。
