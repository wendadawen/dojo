# Sherry 稀疏三值量化：术语表

| 术语/符号 | 首次出现 | 含义 |
|---|---|---|
| 三值量化（ternary quantization） | 开头 | 权重量化到 {-1,0,+1} 三值（乘缩放系数后 {-d,0,+d}）的方法族 |
| 权重量化 | 开头 | 把浮点权重近似为低比特离散值加共享缩放系数；反量化 $x\approx d\cdot q$ |
| bpw（bits per weight） | 开头 | 平均每权重占用 bit 数，含缩放系数等摊销时另注明 |
| Sherry | 开头 | arXiv:2601.07892 提出的 1.25-bit 三值量化框架 |
| STQ1_0 | 开头 | llama.cpp 中实现 Sherry 格式的量化类型与推理内核（PR #22836） |
| 3:4 稀疏 | 第 1 章末/第 2 章 | 每 4 个权重中恰好一个为零的结构约束 |
| $d$（缩放系数，scale） | 开头 | 一组三值权重共享的正实数因子，反量化 $x\approx d\cdot q$；论文训练侧记 $\alpha$，本页统一写 $d$，论文引用处注明 |
| 码本（codebook） | 第 2 章 | 16 项查找表，4 bit 索引查到「零位位置+三个非零 lane 相对符号」模式 |
| 符号位 | 第 2 章 | 5 bit 中的 1 bit，控制整组三个非零值整体符号翻转 |
| SIMD | 开头 | 单指令多数据：一条指令对 2 的幂个通道并行执行同一操作 |
| LUT / 查表指令 | 第 2 章 | SIMD 查表指令（x86 vpshufb、ARM tbl 系），单指令索引上限 4 bit（16 项） |
| stride-16 分组 | 第 3 章 | STQ1_0 内核在 64 权重块内按 (w0,w16,w32,w48) 分组而非连续 4 个 |
| amax | 第 4 章 | 取组内绝对值最大者作为缩放系数的朴素选法 |
| Sparse-AbsMean | 第 4 章 | 论文训练侧缩放：置零绝对值最小者，d 取留存权重平均绝对值（论文附录 D 证 L2 最优） |
| 加权最小二乘（WLS）缩放 | 第 4 章 | $d=\sum w_i x_i q_i/\sum w_i q_i^2$，AngelSlim 编码器采用 |
| imatrix（重要性矩阵） | 第 4 章 | 用校准数据统计的每权重重要性，llama.cpp 生态的校准产物 |
| 加权 SSD | 第 4 章 | 按 imatrix 加权的量化平方误差和 |
| PTQ / QAT | 第 4 章 | 训练后量化 / 量化感知训练 |
| TQ1_0 / TQ2_0 | 第 1 章 | llama.cpp 已有三值格式：1.6875 bpw（3 权重/5 bit）与 2.0625 bpw |
| Q1_0 | 第 5 章 | llama.cpp 1-bit 二值格式，作速度对照 |
| IQ1_S / IQ1_M / IQ2_XXS | 第 5 章 | llama.cpp 社区低比特格式，约 1.56/1.75/2.06 bpw，作对照 |
| weight trapping | 第 6 章 | 硬性 3:4 约束下梯度同质化导致的表征坍缩（论文训练侧问题） |
| Arenas | 第 6 章 | 论文的退火残差通路机制 $Y=XT\alpha+\lambda_t XW$，仅训练侧 |
| MoE 路由专家 | 开头场景 | 混合专家模型中按路由激活的专家权重，Hy4 中占参数大头 |
| MIX-STQ1_0 | 开头场景 | 逐层混合精度策略，本页不展开，见 mixed-precision-quant 页 |
