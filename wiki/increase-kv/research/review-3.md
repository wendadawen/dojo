### 公式与数字复算

- $m = 2\times32\times8\times128\times2 = 131{,}072$ B $= 128$ KB ✓
- $B_{total} = 8192/16 = 512$ 块；$n_{skip} = 4096/16 = 256$ 块 ✓
- 每块 $16\times128\ \text{KB} = 2$ MiB ✓；$T_{old} = 512\times2\ \text{MiB} = 1$ GiB ✓；$T_{new} = 256\times2\ \text{MiB} = 512$ MiB ✓；节省 $256/512 = 50\%$ ✓
- 代数：$(T_{old}-T_{new})/T_{old} = n_{skip}\cdot m\cdot s_{blk} / (B_{total}\cdot m\cdot s_{blk}) = n_{skip}/B_{total}$ ✓
- 扫描表：128→384 块→768 MiB→25%；384→128 块→256 MiB→75%；512→0→0→100% ✓（均复算通过）
- 引言数字：8192 token×128 KB = 1 GiB、256 块×2 MiB = 512 MiB ✓；图一、图二标注数字与正文一致 ✓
