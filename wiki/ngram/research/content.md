# N-gram

- 描述：语言模型是给每个可能的下一个词赋概率的模型；N-gram 语言模型是其中最简单的一类，它把「下一个词取决于整段历史」近似成「只取决于前面 N-1 个词」，从训练语料（用来统计的文本集合）里数出 n-gram 出现次数、归一化得到条件概率。
- 摘要：用最近 $N-1$ 个词近似整段历史，条件概率 $P(w_t\mid w_{1:t-1})\approx P(w_t\mid w_{t-N+1:t-1})$。概率直接从语料计数估计，没见过的组合靠平滑分出一点概率质量。
- 主题：数学基础
- 标签：数学与数值

## 资料

- Daniel Jurafsky, James H. Martin. Speech and Language Processing（第 3 版草稿），第 3 章 N-gram Language Models，Draft of August 19, 2026. [https://web.stanford.edu/~jurafsky/slp3/3.pdf](https://web.stanford.edu/~jurafsky/slp3/3.pdf)

## 短页

### 只看前面几个词

N-gram 是一段连续 $N$ 个词（$N=2$ 叫 bigram（二元），$N=3$ 叫 trigram（三元））；它也是一种模型：给一个词序列，估计下一个词出现的概率，估计时只把它前面最近的几个词当作条件。bigram 模型只看前一个词，trigram 模型只看前两个词；一般的 N-gram 模型（$N$ 是 n-gram 的长度）只看前面 $N-1$ 个词。
依据：paper/slp3-ch3.txt L54-L59；paper/slp3-ch3.txt L67-L101

### 为什么不数整段历史

一个词序列出现的概率，按条件概率的定义可以写成每个词在它全部历史条件下的概率连乘。要估计其中一项，就得统计「这个长串后面接某个词」出现过多少次。可是语言是有创造性的，一个较长的词串几乎不会在语料里重复出现，这个次数在语料里统计不到，公式无法使用。N-gram 的做法是把条件从整段历史缩到最近的几个词：近处几个词在语料里反复出现，可以统计到；代价是丢掉了更远的上下文。
依据：paper/slp3-ch3.txt L102-L128；paper/slp3-ch3.txt L130-L155

### 计数、归一与平滑

要估计「前 $N-1$ 个词是某个片段时，下一个词是某词」的概率，就在训练语料里数出完整 n-gram 出现了多少次，再数它的前缀（前 $N-1$ 个词）出现了多少次，两者相除。语料里没一起出现过的组合，计数为零，整句概率会因为这一个零变成零；平滑的做法是从高频组合分出一点概率质量，分给没见过的组合。
依据：paper/slp3-ch3.txt L173-L234；paper/slp3-ch3.txt L738-L756

## 长页

一个语言模型给每个可能的下一个词一个概率。比如前面是「今天天气真」，下一个词更可能是「好」而不是「桌子」。要算的是条件概率 $P(w\mid h)$：$w$ 是候选的下一个词，$h$ 是它前面的全部词（历史）。估计它最直接的办法是数频率：看 $h$ 在语料（用来统计词频的文本集合）里出现过多少次，其中后面接 $w$ 的有多少次，两者相除。n-gram 是最简单的一类语言模型，它绕开「整段历史无法计数」这个困难，只把最近几个词当成条件；「n-gram」这个词既指连续 $N$ 个词的片段，也指这样估概率的模型。
依据：paper/slp3-ch3.txt L17-L37；paper/slp3-ch3.txt L51-L59；paper/slp3-ch3.txt L67-L101

### 把整段历史截到最近几个词

整句的概率可以按条件概率的定义拆成一串条件概率连乘。设一句话共 6 个词 $w_1,w_2,\dots,w_6$，记作 $w_{1:6}$，那么 $P(w_{1:6})$ 等于「第一个词的概率」乘「第二个词在第一个词条件下的概率」，一直乘到最后一个词 $w_6$ 在它前面全部词条件下的概率。这一步没有近似，是概率的乘法法则。
依据：paper/slp3-ch3.txt L102-L128

问题出在每一项都以上面全部的词为条件。条件里词越多，这个条件在语料里出现的次数越少，到整段历史时几乎从不重现，条件概率就估不出来。n-gram 的做法是做一个马尔可夫假设：某个词出现的概率，只需要看它前面的有限几个词，更远的历史略去。
依据：paper/slp3-ch3.txt L124-L155

按「看几个词」分阶：只看前一个词的叫 bigram，只看前两个词的叫 trigram，一般地，只看前面 $N-1$ 个词的叫 N-gram，$N$ 叫阶。把「看前一个词」代进连乘，就得到 bigram 模型对整句概率的估计。
依据：paper/slp3-ch3.txt L156-L171

::: 从乘法法则到 N 元近似

1. 按乘法法则，整句概率拆成逐词条件概率的连乘（设句子共 $T$ 个词）：

$$P(w_{1:T}) = P(w_1)\,P(w_2\mid w_1)\,P(w_3\mid w_{1:2})\cdots P(w_T\mid w_{1:T-1}) = \prod_{k=1}^{T} P(w_k\mid w_{1:k-1})$$

依据：paper/slp3-ch3.txt L102-L117

2. 每一项 $P(w_k\mid w_{1:k-1})$ 以 $w_k$ 前面的全部词为条件。马尔可夫假设把它缩到最近的少数几个词；bigram 只留前一个词：

$$P(w_k\mid w_{1:k-1}) \approx P(w_k\mid w_{k-1}),\qquad P(w_{1:T}) \approx \prod_{k=1}^{T} P(w_k\mid w_{k-1})$$

第一个词前面没有词，约定它以前面的 `<s>`（句首记号）为条件。
依据：paper/slp3-ch3.txt L134-L155；paper/slp3-ch3.txt L165-L171；paper/slp3-ch3.txt L196-L199

3. 同样的代入用在一般的 N 元（留前 $N-1$ 个词）上：

$$P(w_k\mid w_{1:k-1}) \approx P(w_k\mid w_{k-N+1:k-1})$$

这里 $w_{k-N+1:k-1}$ 是「从第 $k-N+1$ 个词到第 $k-1$ 个词」这一段，共 $N-1$ 个词。
依据：paper/slp3-ch3.txt L157-L163

:::

### 用计数估计概率

有了连乘式，只要每个 $N$ 元条件概率能从语料估出来就能算整句。估计的办法叫最大似然估计：数出整串 n-gram 在语料里出现的次数 $C(w_{k-N+1:k})$，再数它的前缀（去掉最后一个词的那 $N-1$ 个词）出现的次数 $C(w_{k-N+1:k-1})$，两者相除。
依据：paper/slp3-ch3.txt L206-L210

这样得到的比值是相对频率：把它看成「前 $N-1$ 个词取定后，下一个词的概率分布」，它对所有下一个词求和为 1，也就是归一化的条件概率。
依据：paper/slp3-ch3.txt L179-L181；paper/slp3-ch3.txt L219-L224

句子的首尾要各加一个记号：句首记号 `<s>` 给第一个词提供「前一个词」这个条件，句尾记号 `</s>` 让所有句子的概率加起来等于 1。
依据：paper/slp3-ch3.txt L196-L199；paper/slp3-ch3.txt L211-L214

「我 爱 猫」「我 爱 狗」「你 爱 猫」，每句前后加首尾记号，数出各 bigram 的次数，再除以它前面的词出现的次数，就得到条件概率；把一句里各步的条件概率相乘，就是这句的概率。
依据：自行构造

```python
from collections import Counter
from fractions import Fraction

sents = [["我", "爱", "猫"], ["我", "爱", "狗"], ["你", "爱", "猫"]]
corpus = [["<s>"] + s + ["</s>"] for s in sents]

uni, bi = Counter(), Counter()
for s in corpus:
    for w in s:
        uni[w] += 1
    for a, b in zip(s, s[1:]):
        bi[(a, b)] += 1

print("条件概率：")
for (a, b), c in sorted(bi.items()):
    print(f"  P({b}|{a}) = {c}/{uni[a]} = {Fraction(c, uni[a])}")

w = ["<s>", "我", "爱", "猫", "</s>"]
p = Fraction(1)
src = []
for a, b in zip(w, w[1:]):
    p *= Fraction(bi[(a, b)], uni[a])
    src.append(f"P({b}|{a})")
print("整句 P(<s> 我 爱 猫 </s>) = " + " * ".join(src) + " = " + str(p))
```

```text
条件概率：
  P(你|<s>) = 1/3 = 1/3
  P(我|<s>) = 2/3 = 2/3
  P(爱|你) = 1/1 = 1
  P(爱|我) = 2/2 = 1
  P(狗|爱) = 1/3 = 1/3
  P(猫|爱) = 2/3 = 2/3
  P(</s>|狗) = 1/1 = 1
  P(</s>|猫) = 2/2 = 1
整句 P(<s> 我 爱 猫 </s>) = P(我|<s>) * P(爱|我) * P(猫|爱) * P(</s>|猫) = 4/9
```

依据：自行构造

::: 把 bigram 概率写成计数之比（推一遍）

1. 「前一个词是 $w_{k-1}$，下一个词是 $w_k$」的条件概率，等于两者共同出现的次数除以前一个词自己做前缀时的后继总数：

$$P(w_k\mid w_{k-1}) = \frac{C(w_{k-1}w_k)}{\sum_{w} C(w_{k-1}w)}$$

依据：paper/slp3-ch3.txt L182-L195

2. 分母上这个和正好等于 $w_{k-1}$ 自己的计数：除句尾记号外，每个 $w_{k-1}$ 的出现都恰好带一个后继。分母写成这个计数，就得到一般 N 元形式：

$$P(w_k\mid w_{k-N+1:k-1}) = \frac{C(w_{k-N+1:k})}{C(w_{k-N+1:k-1})}$$

依据：paper/slp3-ch3.txt L189-L210

3. 以「爱」为前缀检查：语料里「爱」出现 3 次，后继是「猫」2 次、「狗」1 次；$2/3 + 1/3 = 1$，两个后继的概率对固定前缀求和为 1。
依据：自行构造

:::

### 稀疏与平滑

可能出现的 n-gram 总数是词表大小 $V$ 的 $N$ 次方，阶数每加一，这个数就乘一个 $V$。而语料只有有限个词，所以无论语料多大，总有一些完全合法的组合一次也没出现。
依据：paper/slp3-ch3.txt L644-L649；paper/slp3-ch3.txt L739-L741

没出现的组合计数为零，估计出的概率也是零。整句概率是各步相乘，只要中间有一步的概率为零，整句概率就变成零。
依据：paper/slp3-ch3.txt L739-L751

平滑就是处理这件事：从高频组合分出一点概率质量，分给没见过的组合，让它们得到一个很小的正概率。加一平滑是最简单的一种：把每个 n-gram 的计数都加 1，再归一。
依据：paper/slp3-ch3.txt L752-L766

::: 加一平滑的最小算例

1. 设词表有 4 个词。某前缀 $A$ 出现 3 次，后继是 $B$ 两次、$C$ 一次，另外两个词没出现过。未平滑时 $P(B\mid A) = 2/3$，$P(C\mid A) = 1/3$。
2. 加一平滑把每个计数加 1，再在分母上加上词表大小 4：$P_{\text{加一}}(B\mid A) = 3/(3+4) = 3/7$，$P_{\text{加一}}(C\mid A) = 2/7$。
3. 没出现过的两个词各得 $1/7$，不再是零。四项相加 $3/7 + 2/7 + 1/7 + 1/7 = 1$，对固定前缀仍归一。
依据：自行构造

:::

### 用困惑度比较不同阶

阶越高，用的上下文越长，同一个词串被赋的概率通常越大；但概率会随句子变长而整体变小，不便于跨长度比较。困惑度把这一点除掉：取句子里每个词条件概率倒数的几何平均。困惑度越小，模型对这段文字越不意外，也就越好。
依据：paper/slp3-ch3.txt L445-L478；paper/slp3-ch3.txt L516-L519

比较不同阶要用同一段测试文字、同一个词表。
依据：paper/slp3-ch3.txt L506-L525

::: 困惑度公式、三阶数字与交叉熵

1. 困惑度是测试文字概率的倒数再开 $T$ 次方（$T$ 是测试文字的词数）：

$$\mathrm{perplexity}(W) = P(w_1 w_2 \cdots w_T)^{-1/T} = \sqrt[T]{\prod_{i=1}^{T} \frac{1}{P(w_i\mid w_1\cdots w_{i-1})}}$$

依据：paper/slp3-ch3.txt L452-L469

2. 在一套英语新闻语料上，unigram（一元，$N=1$）、bigram、trigram 的困惑度依次是 962、170、109，阶越高越低。
依据：paper/slp3-ch3.txt L509-L522

3. 把每个词条件概率取以 2 为底的对数、对整句求平均、再取负，得到每词[交叉熵](wiki/cross-entropy)；困惑度等于 2 的每词交叉熵次方，所以每词交叉熵越小、困惑度越小。
依据：paper/slp3-ch3.txt L958-L1131

:::

### 适用条件与边界

n-gram 的概率来自训练语料的计数，所以训练语料要和实际用的场景同域：给法律文本建模就得用法律文本训练；换一个体裁，统计到的高频搭配不再成立。
依据：paper/slp3-ch3.txt L629-L633；paper/slp3-ch3.txt L701-L709

阶越高越贴合训练语料，但参数个数随阶数指数增长，能覆盖到的组合比例随阶数下降，越高阶越容易碰到没数过的组合。
依据：paper/slp3-ch3.txt L630-L649；paper/slp3-ch3.txt L1202-L1205

容易混的是它和神经网络语言模型：后者把词映射到连续向量，让上下文相近的词共享统计，不需要见过完全相同的词串。
依据：paper/slp3-ch3.txt L1202-L1210
