# glossary：n-gram

| 术语/符号 | 首现 | 含义 |
|---|---|---|
| n-gram / n 元语法 | 开头 | 长度为 $n$ 的 token 序列；也指用最近 $n-1$ 个 token 近似历史的语言模型 |
| bigram / 二元语法 | 第 1 章 | $n=2$ 的 n-gram |
| trigram / 三元语法 | 第 1 章 | $n=3$ 的 n-gram |
| unigram | 第 3 章 | $n=1$，退化为词频 |
| 语言模型 | 开头 | 给每个可能的下一个 token 赋概率的模型（引 pretraining 页） |
| 链式法则 | 第 1 章 | 联合概率分解为条件概率连乘（F1） |
| 马尔可夫假设 | 第 1 章 | 预测只依赖最近有限历史（C2） |
| 历史 $h$ | 第 1 章 | 当前词之前的全部 token 序列 |
| $\langle s\rangle$ / $\langle/s\rangle$ | 第 2 章 | 句首/句尾特殊符号，使所有句子概率可归一 |
| MLE / 最大似然估计 | 第 2 章 | 计数归一化得到的概率估计（F3） |
| $C(\cdot)$ | 第 2 章 | 语料中某序列的出现次数 |
| 稀疏 | 第 3 章 | 组合数远超语料覆盖能力、大量计数为零的状态 |
| 平滑 | 第 3 章 | 从高频事件匀概率质量给未见事件的修正 |
| 困惑度 | 第 3 章 | 每词交叉熵损失的指数；越小预测越好 |
| 词表 $V$ / $|V|$ | 第 3 章 | 语料的不重复 token 集合及其大小 |
| 哈希查表 | 第 4 章 | 把 (n-1) 元组经整数哈希映射到固定大小表的行 |
| 乘子 $c_p$ | 第 4 章 | 各位置 token 的整数乘法系数，splitmix64 派生的奇数 |
| 质数词表 $P_h$ | 第 4 章 | 第 $h$ 个哈希头的模数（2000 万附近的质数） |
| PLE | 第 4 章 | Qwen3.8-Flash-Next 的逐层嵌入模块，n-gram 表的使用者（引数据流页） |
