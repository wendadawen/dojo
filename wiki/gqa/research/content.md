# GQA

- 描述：GQA 是一种注意力机制，把查询头分成若干组、每组共用一套键和值，组数在 MQA 与多头之间取值。
- 摘要：生成每个新 token 都要重读全部键、值张量，这一步受显存带宽限制。GQA 让每组查询头共用一套键值，组数取 $1$ 是 MQA、取头数就是多头，换来质量与速度的折中。
- 主题：注意力机制, 内存与缓存
- 标签：注意力

## 短页

### 把查询头分成组，每组一套键值

多头注意力（见[标准注意力](wiki/standard-attention)）里每个头各有一套键和值。GQA（grouped-query attention，分组查询注意力）把查询头分成若干组，每组只算一份键和一份值，这一份叫这组的键头和值头；查询头数量不变。组数取 $1$ 时只有一组，就是 MQA（见 [MQA](wiki/mqa)）；组数取查询头数时每个头各成一组，就是原来的多头。
依据：paper/src-gqa/main.tex L132-L134

### 生成慢在反复读取键值

生成文本是一个 token 一个 token 往下走的（token 是模型读写文本的最小单位）。写一个新 token 时，要用这一位置的查询和这个位置及前面所有位置的键各比一次，再按比较结果取这些位置的值。前面位置的键和值在各自算出的那一步之后就不再改变，把它们留下来供后面各步复用，就是 KV cache（见 [KV cache](wiki/kv-cache)）。序列越长、键值头越多，每步要重读的这份数据越大；当序列长度接近向量维度、或同时处理的序列很少时，读写这份数据相对算术运算量就大，瓶颈落在显存（存放这些键值的内存）的带宽（读写显存的速度）上。键值头数从多头的查询头数降到组数 $G$，每步要读的数据量随之缩小；组数越多，缩得越少，质量越接近多头。
依据：paper/src-gqa/main.tex L111；paper/src-gqa/main.tex L134；paper/src-gqa/main.tex L136；paper/src-mqa/main.tex L101；paper/src-mqa/main.tex L207-L209；paper/src-mqa/main.tex L253

### 按组共用一套键值

做法是把键头、值头的数量设成组数 $G$：查询头数量不变，键和值的投影（一组可学的参数，输入乘它得到这一头的键或值）只做 $G$ 套，第 $i$ 个查询头取用它所属那一组的键和值。得到这样的模型，可以把已有的多头模型（它训练好的参数叫检查点）改造过来：把每组内各头的键投影、值投影分别逐元素取平均合成一组，再继续训练一小段（叫续训），让它适应新结构。
依据：paper/src-gqa/main.tex L126；paper/src-gqa/main.tex L130；paper/src-gqa/main.tex L134

## 长页

多头注意力（见[标准注意力](wiki/standard-attention)）给每个位置算出多组查询、键和值，每组叫一个头。生成文本时模型一个 token 一个 token 往下写（token 是模型读写文本的最小单位），写每个新 token 都要把前面所有位置已经算出的键和值重读一遍（见 [KV cache](wiki/kv-cache)），读取它耗掉的显存（存放这些键值的内存）带宽（每秒能读写的数据量）成了生成的瓶颈。GQA 把查询头分成若干组、每组共用一套键和值，在只存一套键值的 MQA 与每个头各存一套的多头之间取位置。
依据：paper/src-gqa/main.tex L111；paper/src-gqa/main.tex L117；paper/src-gqa/main.tex L132-L134

### 生成慢在反复读取键值

生成是自回归的：模型每次只推进一个位置，因为第 $t$ 个位置的输出决定了这一步生成哪个 token，而这个 token 又成为下一个位置的输入，前后有依赖，没法把多个位置放到一起并行算。但注意力层每一步要做的事没有变：它把当前位置的查询和这个位置及前面所有位置的键各做一次比较，再按比较结果取这些位置的值。这些键和值在前面的步骤里已经算好、也不会再变，但每一步仍要把它们从显存再读进来一次。而显存的读写速度比运算慢得多，这份数据越大，这一步就越受它的限制。

每步真正要新算的只有当前位置这一份查询、键和值，读进来的却是整段历史的键和值。当序列长度与向量维度接近、或者批大小（一次同时处理的序列条数）为 $1$ 时，访存与计算之比（这一步要读写的数据量除以算术运算量的比值）接近 $1$；硬件的运算能力比带宽高出约两个数量级，这个比值接近 $1$ 时，时间几乎都花在读写数据上，受的是显存带宽的限制，不是运算速度。序列越长，或者同时处理的序列越少，要读写的量相对算术量越大，带宽就越紧张。
依据：paper/src-mqa/main.tex L205；paper/src-mqa/main.tex L207；paper/src-mqa/main.tex L209；paper/src-mqa/main.tex L251；paper/src-mqa/main.tex L253；paper/src-mqa/main.tex L255

::: 访存与计算之比
1. 训练时目标序列是已知的，所有位置的注意力可以并行算，计算能顺着矩阵乘法展开。
依据：paper/src-mqa/main.tex L209

2. 分析时取几条约定的规模：待比较的位置数与查询位置数相同，都记作序列长度 $n$；每个键、值向量的维度 $k$、$v$ 都取模型维度 $d$ 除以头数 $h$；$n$ 不超过 $d$。
依据：paper/src-mqa/main.tex L194-L199

3. 这 $n$ 步合起来的算术量是 $\Theta(bnd^2)$，其中 $b$ 是批大小：各步的注意力计算都要和 $d$ 维的投影矩阵相乘，每步约 $bd^2$ 次乘加，$n$ 步合起来是这个量级。
依据：paper/src-mqa/main.tex L249

4. 这 $n$ 步合起来的访存量是 $\Theta(bn^2d + nd^2)$：第一项来自反复读入的键、值（每个位置约 $d$ 个数，共 $n$ 个位置、$b$ 条序列，$n$ 步各读一遍），第二项来自各投影矩阵。
依据：paper/src-mqa/main.tex L251

5. 两者相除，访存与计算之比是 $\Theta(\frac{n}{d} + \frac{1}{b})$。
依据：paper/src-mqa/main.tex L205；paper/src-mqa/main.tex L253
:::

### 把查询头分组，每组一套键值

GQA 把查询头分成 $G$ 组，每组只算一份键和一份值，这一份叫这组的键头和值头，于是键头、值头各有 $G$ 个。第 $i$ 个查询头用它所属那一组的键和值。用 $G$ 记组数：$G$ 等于 $1$ 时只有一组，就是 MQA（见 [MQA](wiki/mqa)）；$G$ 等于查询头数时每个头各成一组，就是原来的多头。生成时每步要读的键、值数据量随 $G$ 增大而增大：从 MQA 的一套，增到多头那样的查询头数套。
依据：paper/src-gqa/main.tex L132-L134；paper/src-gqa/main.tex L136；paper/src-gqa/main.tex L188-L190

::: 4 个查询头分 2 组算一遍
设序列有两个位置，查询头数 $h=4$，每个头里查询、键、值向量的维度都是 $2$，组数 $G=2$：第 0、1 个查询头为第 0 组，第 2、3 个为第 1 组。多头要有 4 套键和 4 套值，MQA 只要 1 套，GQA 这里要 2 套。
依据：自行构造

- 第 0 组的键头：位置 0 的键 $(1,0)$、位置 1 的键 $(0,2)$；值头：位置 0 的值 $(2,0)$、位置 1 的值 $(0,1)$。
- 第 1 组的键头：位置 0 的键 $(0,1)$、位置 1 的键 $(1,0)$；值头：位置 0 的值 $(1,1)$、位置 1 的值 $(1,0)$。
依据：自行构造

分数由当前位置的查询与该位置的键做点积得到，再经 SoftMax 归一成一组和为 $1$ 的权重（两者的算法见[标准注意力](wiki/standard-attention)），用权重对该位置的值加权求和就得到输出。
依据：自行构造

1. 第 0 组的两个查询头都只用第 0 组的键和值。设位置 1 处这两个查询头是 $q_a=(1,0)$、$q_b=(0,1)$。
依据：自行构造

2. $q_a$ 的分数是 $(1,0)\cdot(1,0)=1$、$(1,0)\cdot(0,2)=0$；SoftMax 后是 $(0.731,0.269)$，输出约 $0.731\times(2,0)+0.269\times(0,1)=(1.462,0.269)$。
依据：自行构造

3. $q_b$ 的分数是 $(0,1)\cdot(1,0)=0$、$(0,1)\cdot(0,2)=2$；SoftMax 后是 $(0.119,0.881)$，输出约 $0.119\times(2,0)+0.881\times(0,1)=(0.238,0.881)$。
依据：自行构造

4. 两个头共用同一套键和值，查询不同，算出的输出就不同，这正是同组共享键值、各头仍各自算注意力的样子。
依据：自行构造

5. 第 1 组的查询头用第 1 组自己的键和值。设位置 1 处 $q_c=(1,1)$：两个分数是 $(1,1)\cdot(0,1)=1$、$(1,1)\cdot(1,0)=1$，权重为 $(0.5,0.5)$，输出 $0.5\times(1,1)+0.5\times(1,0)=(1,0.5)$。
依据：自行构造
:::

### 从现有多头检查点改造

已有一个训练好的多头模型，它的参数叫检查点。放弃它、按新结构重新训练代价大。GQA 的做法是把这个检查点改造成 GQA 结构，再补一小段训练。改结构要动键和值的投影（投影就是一组可学的参数，输入乘它得到这一头的键或值）：把每一组内各头的键投影逐元素取平均，得到这一组的键头；值投影同样处理，得到这一组的值头。
依据：paper/src-gqa/main.tex L113；paper/src-gqa/main.tex L126；paper/src-gqa/main.tex L134

改好的模型要用原来的训练配方、按原预训练步数的一小部分继续训练（这一步叫续训），让模型适应新结构。预训练是模型在大批数据上先训练一段、得到通用参数的过程，续训就在这段训练的基础上接着做。
依据：paper/src-gqa/main.tex L126；paper/src-gqa/main.tex L130

::: 续训到不同比例的分数
在同一族模型上，把改好的模型（组数取 $8$）续训到原预训练步数的 $0$、$5\%$、$10\%$，平均分是：
- $0$：56.713
- $5\%$：57.4
- $10\%$：57.56
依据：paper/src-gqa/figures/uptraining_steps.tex L30-L44
:::

### 质量与速度的取舍

把 GQA 跟同一规模的多头相比：GQA-8（组数取 8 的 GQA）以接近 MQA 的生成时间，取得接近多头的平均分。
依据：paper/src-gqa/main.tex L168；paper/src-gqa/tables/main_results.tex L10-L13

::: 各做法的生成时间与平均分
实验在同一族模型的两个规模上做；从大那个规模的多头改造成 MQA 和 GQA-8，两者各续训原预训练步数的 $5\%$。每样本生成时间（跑一遍模型逐 token 生成所需的时间，秒）与平均分：
- 多头 Large：0.37 秒，46.0
- 多头 XXL：1.51 秒，47.2
- MQA-XXL：0.24 秒，46.6
- GQA-8-XXL：0.28 秒，47.1
依据：paper/src-gqa/tables/main_results.tex L10-L13；paper/src-gqa/tables/main_results.tex L17

GQA-XXL 取不同组数时的生成时间（输入长度 2048、输出长度 512）：1 组 0.489 秒、4 组 0.476 秒、8 组 0.514 秒、16 组 0.594 秒、32 组 0.800 秒、64 组 2.531 秒；多头是 2.531 秒，MQA 是 0.489 秒。从 1 组到 8 组耗时变化很小，之后逐档增大，到 64 组回到多头水平。
依据：paper/src-gqa/main.tex L190；paper/src-gqa/figures/time_vs_groups.tex L28-L44；paper/src-gqa/figures/time_vs_groups.tex L48
:::

### 适用条件与边界

注意力用在三个地方：编码器自注意力处理输入序列，解码器自注意力处理已经生成的部分，编码器-解码器注意力让解码器读取编码器的输出；编码器、解码器是模型里处理输入、输出的两部分，自注意力指同一段序列内部各位置互相看，只用编码器那一处时各位置可以并行算。GQA 不用在编码器自注意力层，因为这里并行算，带宽一般不是瓶颈。
依据：paper/src-gqa/main.tex L140；paper/src-gqa/main.tex L148

GQA 也只改键和值这一侧：每组只算一份键和值，查询头数不变。
依据：paper/src-gqa/main.tex L134

组数可以取 $1$ 到查询头数之间的值，中间取值在质量与速度之间取位置；头数越多的模型，可压的键值头越多，预期收益越大。
依据：paper/src-gqa/main.tex L134；paper/src-gqa/main.tex L136；paper/src-gqa/main.tex L138

MQA 是 GQA 在 $G=1$ 时的特例，只共用一套键值，质量更低、速度更快（见 [MQA](wiki/mqa)）。
依据：paper/src-gqa/main.tex L134；paper/src-gqa/main.tex L136
