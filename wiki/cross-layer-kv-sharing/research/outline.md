# 跨层 KV 复用 文章大纲

## 4.1 页面开头

**具体问题**：标准 Transformer 的每一层都要为整段上下文各存一份 KV，层数越多缓存越大。如果让多层共用同一份全局 KV，能省下什么、代价是什么？本文回答：复用的是哪一层的 KV、省下多少、它与"复用索引"有什么区别、以及复用的前提与边界。

**组件**：`blockquote.meta`、`callout-blue`、`learning-goals`（4 条）、`misconceptions`（4 条）。

## 4.2 章节设计

### 第 1 章 复用的是哪一层的 KV

- **章节问题**：多层共用的那份 KV 从哪里来？
- **完成答案要点**：把层分成下段（自解码器）与上段（交叉解码器）；下段末层隐状态 $X^{L/2}$ 经投影得到唯一的全局 KV，上段各层通过交叉注意力复用它，不再从本层隐状态生成全局 KV。因此"全局 KV 的份数"从每层一份变成每段一份。
- **对应范围**：Q1；C1；F1
- **正文要点**：一般形式与符号；与"每层各算一份"的对照；上段各层仍保有自己的 query 与局部 KV
- **材料**：公式 F1；结构图（下段生产、上段复用）
- **前置知识**：标准注意力、KV cache
- **本章问题**：2 条

### 第 2 章 省下多少：层维度被消掉

- **章节问题**：复用能省多少缓存与计算？
- **完成答案要点**：全局 KV 的份数与层数无关，缓存复杂度从 $\mathcal{O}(LND)$ 降到 $\mathcal{O}((N+L)D)$；prefill 阶段上段不必为每个位置算全局 KV，可提前退出，复杂度从 $\mathcal{O}(LN^2D)$ 降到 $\mathcal{O}(LND)$。注意"只缓存一次"严格指全局 KV，局部窗口 KV 仍按层存在。
- **对应范围**：Q2；C2、C3、C7；F2、F3；N1、N4
- **正文要点**：复杂度对照；"once"的准确含义；与压缩注意力的分工（一个消层维度、一个消 token 维度）
- **材料**：对照表格（标准 vs 复用）；`details` 补充 MLA 的分工对照
- **前置知识**：KV cache、MLA
- **本章问题**：2 条

### 第 3 章 两级复用：共享 KV 与复用索引

- **章节问题**："共享 KV"与"复用索引"有什么区别？
- **完成答案要点**：共享 KV 是让多层读同一份条目；复用索引是让多层沿用同一份 Top-K 选择。CSA2 把两者解耦为三种模式：Full 自算两者、Reindex 复用 KV 自算索引、Reuse 两者都复用。复用索引不等于看到一样的东西——各层的 query 与窗口 KV 仍不同。
- **对应范围**：Q3；C4；N3
- **正文要点**：两级复用的对象与节省；三模式的判定条件；为什么索引必须与它评分的 KV 配套
- **材料**：对照表格（三模式各自计算/复用哪些量）；结构图（两级复用）
- **前置知识**：稀疏注意力的 Top-K 选择
- **本章问题**：2 条

### 第 4 章 前提与边界：同组才能共用

- **章节问题**：复用的前提是什么？不能随便复用的原因是什么？
- **完成答案要点**：前提是同组层的压缩比一致，跨组的 KV 不能互用（条目覆盖的 token 数不同）；运行期实测显示共享分组为层 2–7、8–13、14–19、20–39，source 层是 2、8、14、20，每个压缩层读到的 cache 都来自组内 source；代价是上段各层不再有各自的全局 KV，质量由训练补偿。
- **对应范围**：Q4；C5、C6；N2、N3
- **正文要点**：分组前提；运行期证据（cache 归属）；表达能力代价；短序列下收益有限
- **材料**：分组表格；`details` 补充运行期实测方法
- **前置知识**：第 1、3 章结论
- **本章问题**：2 条

## 4.3 讲解顺序

第 1 章定复用对象，第 2 章算收益（依赖第 1 章的"份数变化"），第 3 章区分两级复用（依赖第 1 章的 KV 共享），第 4 章给前提与边界（依赖前三章）。第 3 章开头用一句说明"共享"与"复用索引"是两件事。

## 4.4 贯穿示例

**场景**：$L=40$ 层、$N=1\,048\,576$ 个 token 的请求。

1. 第 1 章：全局 KV 不再是 40 份，而是由下段末层隐状态投影出的若干份
2. 第 2 章：缓存复杂度从 $\mathcal{O}(LND)$ 降到 $\mathcal{O}((N+L)D)$，prefill 可提前退出
3. 第 3 章：其中某些层只复用 KV、索引仍自算（Reindex），另一些两层都复用（Reuse）
4. 第 4 章：实际份数 = 4 份主 KV（层 2/8/14/20 各一份），分组 2–7 / 8–13 / 14–19 / 20–39
