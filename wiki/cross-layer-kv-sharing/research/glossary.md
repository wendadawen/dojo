# 跨层 KV 复用 术语表

| 术语 | 英文/缩写 | 首次出现 | 含义 |
|---|---|---|---|
| 跨层 KV 复用 | cross-layer KV sharing | 页面开头 | 让多个层共用同一份全局 KV，而不是每层各算一份 |
| 全局 KV | global KV | 第 1 章 | 覆盖整段上下文的 KV 条目（与每层的局部窗口 KV 相对） |
| 局部 KV | local / window KV | 第 1 章 | 每层自己的滑动窗口 KV，仍按层保存 |
| 自解码器 | self-decoder | 第 1 章 | 下段 $L/2$ 层，逐层计算并产出供上段复用的全局 KV |
| 交叉解码器 | cross-decoder | 第 1 章 | 上段 $L/2$ 层，复用下段产出的全局 KV |
| 生产层 / source 层 | source layer | 第 3 章 | 负责计算 KV 并发布给同组其他层的那一层 |
| 复用层 | consumer layer | 第 3 章 | 读取同组 source 层发布的 KV 的层 |
| 索引复用 | index reuse | 第 3 章 | 多层沿用同一份 Top-K 选择结果 |
| 压缩比 | compress ratio, $r$ | 第 4 章 | 一个压缩条目覆盖的 token 数；同组必须一致 |
| 提前退出 | early exit | 第 2 章 | prefill 阶段在进入上段前结束计算 |

## 符号

| 符号 | 含义 |
|---|---|
| $L$ | 层数 |
| $N$ | 序列长度 |
| $D$ | 隐藏维（复杂度式中的维度） |
| $X^{l}$ | 第 $l$ 层的隐状态 |
| $X^{L/2}$ | 下段末层隐状态，全局 KV 的投影来源 |
| $\hat K, \hat V$ | 被复用的全局键与值 |
| $W_K, W_V$ | 全局 KV 的投影权重 |
| $C$ | 局部缓存的常数规模（如窗口大小） |

## 记号约定

- "份数"指独立保存的 KV cache 副本数；"组"指共用同一份主 KV 的层区间。
- 复杂度式沿用论文记号：$\mathcal{O}(LND)$ 中的 $D$ 为隐藏维，$N$ 为序列长度，$L$ 为层数。
