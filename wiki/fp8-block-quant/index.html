    FP8 Block Quantization

    正文 1,323 字 · 约 4 分钟阅读

    模型把权重（模型的可学参数）和激活（前向计算中逐层流动的数值，前向计算指从输入开始按层逐层算出输出的过程）保存成张量，张量是多维数组。把每个数用 8 位浮点 E4M3 存下，比用 16 位格式存省空间，也降低读写这些数时的访存带宽压力。但 8 位能表示的数范围很窄。FP8 块量化把张量切成固定大小的块，每块各自算一个缩放因子 $s$，块内元素除以 $s$ 后存成 E4M3，用的时候再乘回 $s$。每块用自己的缩放因子，8 位的窄范围因此能逐块贴合本块的数据。

    1. E4M3：可表示范围与特殊值取舍

    E4M3 是 8 位浮点：1 个符号位 $S$、4 个指数位 $E$、3 个尾数位 $M$，把 8 位写成 $S.EEEE.MMM$ 三段。它的指数带偏置 $7$，正规数的值写成

    $$F = (-1)^S \times 1.M \times 2^{E-7},$$

    其中 $1.M$ 表示把三位尾数看成小数点后的三位二进制小数、前面补一个隐含的 1。指数域 $E$ 从 $1$ 到 $15$，对应指数 $-6$ 到 $8$。最大正规数写作 $S.1111.110$，值为 $1.75 \times 2^8 = 448$；最小正规数是 $2^{-6}$，次正规数最小到 $2^{-9}$。

    E4M3 不表示无穷，只保留一种尾数位型给 NaN（正负各一个）。按 IEEE 754 的惯例，指数域全为 $1$ 的一段位型留给无穷和 NaN；E4M3 把这一段里除 $S.1111.111$ 之外的位型都让给正规数，于是多出七个更大的数，最大正规数从按惯例会得到的 $240$ 提到 $448$，动态范围（能表示的数值跨度）多出一个 2 的幂。这样取舍，是因为多出来的取值范围比多支持几个特殊值有用；正负号与零的对称性仍然保留。

    解出 448，以及 240 与 480 的来历
    1. 指数带偏置 $7$，$E=15$ 时指数为 $15-7=8$。
    2. 取位型 $0.1111.110$：$S=0$，$E=1111_2=15$，尾数位 $110_2$ 表示小数 $0.75$，故 $1.M=1.75$。代入 $F=1.75\times 2^{8}=1.75\times 256=448$。
    3. 若沿用 IEEE 惯例、把指数域 $1111$ 整段留给无穷和 NaN，最大正规数的指数只到 $14$，此时 $1.875\times 2^{14-7}=1.875\times 128=240$。
    4. 回收这段位型后就多出 $256、288、320、352、384、416、448$ 七个数，最大从 $240$ 变成 $448$。
    5. 若零只留一个编码、NaN 也只留一个编码（放弃正负对称），省下的位型可以再让给正规数，最大可达 $1.875\times 2^8=480$；但会破坏 IEEE 格式里可用整数比较正负浮点数的性质，代价不值得，故不取。

    2. 缩放：把张量对准可表示区间

    把精度更高的数直接按 E4M3 存下，会有一部分数超出 E4M3 能表示的范围。通用做法是先把张量整体缩放，让它的最大绝对值落到 E4M3 能表示的最大值附近，再转换；溢出的值饱和到该格式能表示的最大值，转换完再把缩放的倍数乘回去。

    一个张量共用一个缩放因子时，缩放因子由张量的最大绝对值定出。这种做法对离群值高度敏感：少数远大于其余元素的值会主导这个缩放因子，量化精度下降。

    一个离群值把最小的元素舍入为 0

    取一个张量，元素是 $6.5$、$0.5$、$0.00001$，整个张量共用一个缩放因子。

    1. 缩放因子 $s=6.5/448=0.0145089286$。
    2. $6.5$ 除以 $s$ 得 $448$，正好落在 E4M3 的最大正规数上，精确还原为 $6.5$。
    3. $0.5$ 除以 $s$ 得 $34.46$，最近的 E4M3 值是 $36$，还原 $36\times s=0.5223$，相对误差约 $4.5\%$。
    4. $0.00001$ 除以 $s$ 得 $0.000689$，低于最小次正规数 $2^{-9}\approx 0.001953$ 的一半，舍入为 $0$，这个元素被整个丢掉。
    5. 把 $0.00001$ 单独放一块，块内最大值就是它，除以 $s$ 得 $448$，精确还原；同一元素从被丢弃变为零误差。可见误差取决于块内元素的范围，而不只取决于元素自己。

    3. 分块：权重 128×128、激活 1×128

    缩小粒度能缓解这个问题：不让整个张量共用一个缩放因子，而是把张量切成小块，每块各自一个。矩阵乘法 $C=A\times B$ 里，$A$ 的形状是 $M\times K$、$B$ 是 $K\times N$，$K$ 是两个矩阵共享的内维，$C$ 的形状是 $M\times N$。权重和激活各自按内维 $K$ 的方向分组：一个权重矩阵 $B$ 按 $128$ 个输入通道乘 $128$ 个输出通道切一块，激活按每个 token 的 $128$ 个通道切一片。token 是文本被分词后的一小段，前向计算时一个 token 对应激活矩阵的一行；通道是激活向量里的一个位置。

    缩放因子在运行时对该块在线求出：取这一块里绝对值最大的元素 $a$，令 $s=a/448$。块内元素 $x$ 存成把 $x/s$ 舍入到最近的 E4M3 值的结果；反量化时把存下的值乘回 $s$。放大到整块：形状为 $K\times N$ 的权重按 $128\times128$ 切，缩放因子的形状是 $(K/128)\times(N/128)$，每个块一个。

    一个块内 6.0、0.5 与 0.05 的往返

    取一个块，块内绝对值最大的是 $6.0$，另有元素 $0.5$ 和 $0.05$。

    1. 块内最大值 $6.0$ 定出缩放因子 $s=6.0/448=0.0133928571$。
    2. 最大值除以 $s$ 得 $448$，正好落在 E4M3 的最大正规数上，精确还原为 $6.0$。
    3. $0.5$ 除以 $s$ 得 $37.33$，最近的 E4M3 值是 $36$，还原 $36\times s=0.4821$，相对误差约 $3.6\%$。
    4. $0.05$ 除以 $s$ 得 $3.733$，最近的 E4M3 值是 $3.75$，还原 $3.75\times s=0.05022$，相对误差约 $0.45\%$。
    5. 把 $0.05$ 单独放一块时，它自己就是块内最大值，除以 $s$ 得 $448$，精确还原。同一元素的相对误差从 $0.45\%$ 降到 $0$。

    4. 配套：E4M3 全用与累加精度

    惯例是让反向传播里的梯度用 E5M2、只给前向的权重和激活用 E4M3，这也是这两种编码的推荐用法；E5M2 有 5 个指数位、2 个尾数位。这里连反向传播（从输出端往回逐层计算、据此更新权重的那一趟）的梯度也用 E4M3，所有权重、激活、梯度一律 E4M3。这么做的理由是分组缩小后，块内元素共用一个缩放因子，取值范围有限的限制被限制在块内。

    反量化嵌在累加里完成。FP8 矩阵乘法在 GPU（做并行数值计算的处理器）的 Tensor Core（做矩阵乘加的专用单元）上逐段累加，累加保留的有效位数有限：在 H800（一款 GPU）上只有约 14 位。为此每累计一段元素，就把部分和搬到 CUDA Core（GPU 的通用计算单元）上的 FP32（32 位浮点）寄存器里做全精度累加，块缩放因子也在那里乘进去。

    14 位累加与 K=4096 的误差
    1. Tensor Core 上 FP8 矩阵乘法的累加只保留约 14 位，低于 FP32 的累加精度；内维 $K$ 越大问题越突出。
    2. 取两个随机矩阵、内维 $K=4096$，有限累加精度带来的最大相对误差接近 $2\%$。
    3. 每累计 $128$ 个元素就提升到 FP32 做全精度累加，是能改善精度、又不带来大开销的最小间隔。

    5. 适用条件与边界

    块量化成立的前提是块内元素能被一个缩放因子合理表示。分组越小，缩放因子越能贴近组内元素，越能容纳离群值。

    代价是每个块都要多存一个缩放因子，随权重或激活一起保存；反量化是一步额外算术。

    一个常见误解是把块量化当成逐张量缩放。逐张量缩放是整个张量共用一个缩放因子，正是块量化要取代的做法；块量化按块给出多个缩放因子。

    一个反例：激活梯度按权重式 128×128 分块量化会发散
    1. 激活按 $1\times128$ 分片，反向传播时需要换成 $128\times1$ 的分组。若改用更直接的做法——把激活梯度也照权重的 $128\times128$ 分块量化、反向只需转置——训练会发散。
    2. 对象是一个约 16B（B 指十亿）总参数的 MoE 模型（MoE 指混合专家，一种每层有多个专家子网络、每个 token 只激活其中几个的模型），训练约 300B 个 token。
    3. 一种解释是激活梯度在不同 token 之间高度不平衡，产生与 token 相关的离群值，块量化难以处理这种离群值。
