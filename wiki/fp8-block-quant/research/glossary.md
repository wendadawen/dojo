# glossary.md：FP8 块量化

| 术语/符号 | 首次出现 | 含义 |
|---|---|---|
| E4M3 | 第 1 章 | 1 符号+4 指数+3 尾数的 8 位浮点格式，偏置 7，最大正规数 448 |
| E5M2 | 第 2 章 | 1+5+2 的 8 位浮点格式，偏置 15，动态范围更宽（32 binade） |
| 指数偏置（bias） | 第 1 章 | 指数域减去的常数（E4M3 为 7），决定范围的中心位置 |
| 规格化数（normal） | 第 1 章 | 指数域非全 0 的浮点数，尾数隐含前导 1 |
| 非规格化数（subnormal） | 第 1 章 | 指数域全 0 的数，无隐含 1，用于渐进下溢 |
| binade | 第 2 章 | 相邻两个 2 的幂之间的区间；衡量动态范围的单位 |
| 饱和（saturation） | 第 2 章 | 溢出值截断到最大可表示值（E4M3 无 inf，故饱和） |
| max 对齐 | 第 3 章 | 缩放使张量最大绝对值对准格式最大可表示值的实践 |
| 离群值（outlier） | 第 3 章 | 幅度远大于典型值的元素；逐张量缩放的精度杀手 |
| 块量化（block-wise） | 第 4 章 | 按块（权重 128×128、激活 1×128）分别计算 scale 的粒度方案 |
| tile（片） | 第 4 章 | 激活的分组单位（1×128，逐 token 逐 128 通道） |
| scale / weight_scale_inv | 第 4 章 | 量化因子 $s=448/\max$ 与其倒数（checkpoint 存倒数，反量化乘回） |
| promotion（提升累加） | 第 5 章 | 每 128 个内积元素把部分和搬到 FP32 寄存器累加的策略 |
| GEMM | 第 5 章 | 通用矩阵乘（General Matrix Multiply） |
