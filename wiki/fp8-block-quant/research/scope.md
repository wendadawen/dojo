# scope.md：FP8 块量化

## 1. 概念含义

- 名称：FP8 块量化（E4M3 block-wise quantization）
- 简要定义：把权重（与激活）压成 8 位浮点 E4M3 存储/计算，用 128×128（权重）与 1×128（激活）的分块缩放因子对准可表示区间，兼顾显存减半与精度保持
- 正式定义：E4M3 位布局 1+4+3、偏置 7、最大正规数 448（FP8 论文 Table 1）；块内缩放对齐最大绝对值（FP8 论文 §2 的 max 对齐实践 + DSV3 §3.3.2 的分块粒度）
- 语境：讲解「格式 → 缩放 → 分块 → 实证」完整链条，落点是 GLM-5.3-Flash checkpoint 的量化布局实证
- 包括：E4M3 位布局与范围、E5M2 对照与分工、特殊值取舍、逐张量缩放的离群值问题、DeepSeek-V3 分块方案、GLM checkpoint 实证
- 不包括：FP8 训练的完整框架（通信/优化器状态压缩）、microscaling 格式标准化细节（链接 mxfp4-qat 页）、推理框架 kernel 实现
- 相邻概念：量化基础（有页 quantization-basics，前置）；MXFP4（有页 mxfp4-qat，对照：块缩放思想的标准化路线）

## 2. 学习目标

### Q1：E4M3 用 8 位怎么表示浮点？范围与精度各是多少？

- 答案：1 符号+4 指数+3 尾数、偏置 7；值 $=(-1)^S 2^{E-7}(1+\frac{M}{8})$；最大正规数 448、最小正正规数 $2^{-6}$、最小正非规格化数 $2^{-9}$；相对精度由 3 位尾数决定（相邻值间隔 ~1/8 相对量级）
- 核心理由：格式是一切的地基，448 与偏置 7 是后续缩放公式的常数
- 依赖：浮点记数法（自包含：先讲 S.E.M 拆位）

### Q2：E4M3 与 E5M2 怎么分工？E4M3 为什么不表示无穷？

- 答案：E5M2 有 5 指数位（偏置 15）动态范围宽 32 binade、按 IEEE 惯例含无穷/多 NaN，用于梯度；E4M3 回收无穷与多余 NaN 的位模式，最大值从 240 提到 448（多 7 个幅值、17→18 binade），用于权重与激活；溢出饱和而非置无穷
- 核心理由：「为什么训练框架默认混用、推理权重量化只取 E4M3」的解释基础
- 依赖：Q1

### Q3：为什么逐张量缩放不够？分块怎么解决？

- 答案：max 对齐的逐张量缩放下，离群值把整体 scale 拉大、普通元素精度被压垮（FP8 论文 §4.3：量化残差时无单一指数偏置可用）；DSV3 把粒度切到 1×128（激活，逐 token 逐 128 通道）与 128×128（权重），离群值只影响自己所在的块
- 核心理由：分块是「块量化」名字的来源，也是精度收益的机制
- 依赖：Q1；量化的 scale 概念（链接 quantization-basics）

### Q4：块量化的 scale 怎么算、checkpoint 里怎么存？GLM-5.3-Flash 的布局是什么？

- 答案：$s=448/\max|W_{\text{block}}|$（max 对齐+E4M3 上限，transformers quantizer L124-142 实现），存 scale 的倒数（weight_scale_inv，反量化乘回）；GLM：37,338 个 scale 全部符合 $\lceil N/128\rceil\times\lceil K/128\rceil$、F32 存储、平均 1.022 B/参数、只有大矩阵乘权重走 FP8（KDA 层零量化）
- 核心理由：从公式到真实 checkpoint 的证据闭环
- 依赖：Q3；ceil 记号（自包含）

### Q5：训练时为什么还要配 FP32 累加与 E4M3 全用？

- 答案：H800 上 FP8 GEMM 累加精度仅约 14 位、K=4096 时最大相对误差近 2%；DSV3 每 128 个内积元素把部分和提升到 CUDA Core 的 FP32 寄存器累加（promotion）；因分块缩放「共享指数」的效果，DSV3 在所有张量上只用 E4M3（对比先前 Fprop E4M3/Dgrad E5M2 的混用）；实测相对 loss 误差 <0.25%
- 核心理由：块量化不只是存储格式，配套的数值策略是它成立的前提
- 依赖：Q3

## 6. 误解与边界

误解：
1. 「FP8=INT8 的浮点版，精度差不多」——FP8 有指数位，动态范围远大于 INT8（E4M3 18 binade vs INT8 无指数），但相对精度粗（3 位尾数≈2~3 位十进制有效数字）
2. 「块越小精度越好，无脑切小」——B.2：激活梯度切成 128×128 块反而发散（token 相关离群值）；粒度选择有边界
3. 「E4M3 溢出报 inf」——E4M3 无穷位模式被回收，溢出饱和到 ±448
4. 「scale_inv 是量化用的 scale」——存的是倒数（反量化因子），量化时乘 448/max、反量化时乘回 max/448

边界：
- 448/max 的 max 对齐公式出自 FP8 论文的通用实践+transformers quantizer 实现；DSV3 正文以文字+图描述（无显式公式），组合陈述时标明各部分来源
- <0.25% 是 DSV3 两个规模、~1T token 的实验结论，不能外推到任意模型
- GLM 实证的 scale 形状/数量是本机读张量头的结果，反量化语义来自 transformers quantizer 源码（加载器行为）
