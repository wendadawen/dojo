# scope.md：CLIP 内容范围

## 1. 概念含义

- 概念名称：CLIP（对比语言-图像预训练）
- 英文名称：Contrastive Language-Image Pre-Training
- 简要定义：用一个对比目标在 4 亿网络图文对上联合训练图像编码器与文本编码器，把两种模态映射进同一嵌入空间的预训练方法
- 正式定义：CLIP 联合训练图像编码器与文本编码器，在 batch 内预测哪些 (image, text) 配对真实出现——最大化 N 个真实配对的余弦相似度、最小化 N²−N 个错误配对的相似度，优化对称交叉熵损失（Radford et al. 2021, §2.1–2.3）
- 本文采用的语境：视觉-语言预训练方法；zero-shot 分类作为其代表性使用方式
- 包括什么：双塔架构与共享嵌入空间、对称 softmax 对比损失、可学习温度、zero-shot 分类机制（prompt + 文本编码器合成线性分类器）、训练配置关键数字、batch 耦合边界（衔接 SigLIP）
- 不包括什么：
  - prompt 逐数据集的完整工程细节（§3.1.4 仅取代表性结论，展开属于提示工程独立主题）
  - CLIP 各下游评测基准的完整结果（30+ 数据集逐项数字，不影响核心机制理解）
  - 对比学习谱系完整梳理（SimCLR/MoCo/InfoNCE 家族史，只在来源说明中定位 CLIP 损失的出处）
  - CLIP 后续全部变体（只衔接 SigLIP 与 MoonViT-V2 两个已存在页面的工作）
- 相邻概念：
  - SigLIP（更换损失为逐对 sigmoid）：关键区别在损失形式，SigLIP 页展开，本页只指出 softmax 损失的 batch 耦合这一动机来源
  - ViT（图像编码器选项之一）：已有页面，本页引用不重复
  - 对比学习（方法族）：CLIP 是其在视觉-语言模态的应用，本文不展开方法族

## 2. 学习目标

### Q1：CLIP 在做什么、解决什么问题？

- 完成答案：CLIP 用"预测哪段文本配哪张图"这一预训练任务，在 4 亿网络图文对上联合训练图像编码器与文本编码器，学到共享嵌入空间；训练后可用自然语言指称视觉概念，使模型无需下游训练样本即可迁移（zero-shot）到新任务。解决的问题是：传统视觉模型依赖固定类别标注数据训练，类别集合在训练时锁定，迁移到新任务需要重新收集标注
- 为什么是核心目标：不理解"语言监督 + 对比目标"这一动机，后续损失与 zero-shot 机制都没有着力点
- 依赖内容：预训练/迁移的基本含义、对比目标的定义

### Q2：对称 softmax 对比损失怎么算？

- 完成答案：batch 内 N 个配对构成 N×N 相似度矩阵；image→text 与 text→image 两个方向各做一次以相似度（乘温度缩放）为 logits 的 softmax 交叉熵，正对是对角线元素，两方向平均。分母对整个 batch 求和，每个对的损失与 batch 内其他样本耦合。能写出公式、说明每个符号、手算 |B|=2 例子
- 为什么是核心目标：这是 CLIP 的训练机制本体，也是 SigLIP 更换损失的对象
- 依赖内容：softmax、交叉熵、余弦相似度

### Q3：zero-shot 分类如何不训练就完成新任务？

- 完成答案：把每个类别名套进 prompt 模板（默认 "A photo of a {label}."）输入文本编码器得到各类别文本嵌入，与图像嵌入算余弦相似度，softmax 后取最大——文本编码器起到"根据类别描述合成线性分类器权重"的作用（论文称 hypernetwork）。prompt 提供消歧上下文；80 个 prompt 的 ensemble 在 ImageNet 上额外提升。代表数字：ViT-L/14@336px zero-shot ImageNet top-1 76.2%，与原始 ResNet-50 持平且不用其 128 万训练样本
- 为什么是核心目标：zero-shot 迁移是 CLIP 影响力的直接来源
- 依赖内容：共享嵌入空间、softmax 概率比较

### Q4：CLIP 的训练配置与边界是什么？

- 完成答案：可学习温度 τ 以对数参数化（初始化 0.07，截断防止 logits 放大超过 100）；batch 32,768；图像编码器有 ResNet 与 ViT 两个系列、文本编码器为 Transformer。边界：softmax 分母依赖整个 batch（小 batch 下难负样本池不足、多设备需 all-gather），这是 SigLIP 换逐对 sigmoid 损失的动机；zero-shot 并非"零设计"，prompt 工程与 ensemble 在 ImageNet 合计提升近 5%
- 为什么是核心目标：明确结论成立条件与后续工作的衔接点
- 依赖内容：损失公式、温度作用

## 6. 常见误解和适用边界

- 误解 1："CLIP 是一个图像分类模型"——错误。CLIP 是双塔预训练模型；分类是使用方式：文本编码器按类别描述合成线性分类器。影响 Q1/Q3
- 误解 2："对比损失只把配对样本拉近"——错误。同时最大化 N 个正对相似度并最小化 N²−N 个负对相似度（§2.3 原文双向表述）。影响 Q2
- 误解 3："zero-shot 等于不需要任何输入设计"——错误。prompt 模板消歧（如 crane 的吊车/鹤两义）与 ensemble 在 ImageNet 合计提升近 5 个百分点（§3.1.4）。影响 Q3
- 误解 4："CLIP 的 softmax 损失在大 batch 下没有代价"——错误。分母对整个 batch 求和，多设备训练需 all-gather、小 batch 下难负样本不足；这是 SigLIP 更换损失的直接动机。影响 Q4
- 适用边界：76.2% 是 ViT-L/14@336px 在 ImageNet 的 zero-shot top-1（含 prompt ensemble），不适用于其他模型/数据集直接搬用；"16/27 胜过 ResNet-50 特征线性分类器"是 27 个数据集的统计而非逐数据集保证（CLIP 在部分细粒度任务上不如监督基线，§3.1.5 报告了胜负各半的整体图景）
