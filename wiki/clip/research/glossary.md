# glossary.md：CLIP 术语表

| 术语/符号 | 首次出现 | 含义 |
|---|---|---|
| CLIP | 第 1 章标题前导语 | Contrastive Language-Image Pre-Training，对比语言-图像预训练 |
| 预训练 | 第 1 章 | 在大规模无下游标注数据上先训练通用表示，再迁移到具体任务 |
| zero-shot 迁移 | 第 1 章 | 不使用目标任务的任何训练样本直接推理 |
| WIT | 第 1 章 | WebImageText，CLIP 的 4 亿网络图文对训练数据集 |
| 自然语言监督 | 第 1 章 | 用配对文本（而非人工类别标注）作为训练信号 |
| 图像编码器 $f$ | 第 2 章 | 把图像映射为向量表示的网络；CLIP 用 ResNet 或 ViT 系列 |
| 文本编码器 $g$ | 第 2 章 | 把文本映射为向量表示的 Transformer |
| 双塔 | 第 2 章 | 图像与文本各用一个独立编码器、只在嵌入空间相互比较的结构 |
| 线性投影 | 第 2 章 | 单个矩阵乘法把编码器输出映射到共享嵌入空间（无非线性层） |
| L2 归一化 | 第 2 章 | 向量除以自身模长，落到单位球面 |
| 余弦相似度 | 第 2 章 | 归一化向量内积 $x_i\cdot y_j\in[-1,1]$，衡量方向一致程度 |
| $x_i$ | 第 3 章 | 第 $i$ 张图像 L2 归一化后的嵌入 |
| $y_j$ | 第 3 章 | 第 $j$ 段文本 L2 归一化后的嵌入 |
| $N$ / $|B|$ | 第 3 章 | batch 内 (image, text) 配对数；本页统一用 $N$ |
| 正对 / 负对 | 第 3 章 | batch 内真实配对 $(i,i)$ / 错误配对 $(i,j),i\neq j$ |
| 对称交叉熵 | 第 3 章 | image→text 与 text→image 两个方向 softmax 交叉熵的平均 |
| 温度 $\tau$ | 第 3 章 | 控制相似度进入 softmax 前缩放的可学习参数；缩放因子 $t=1/\tau$ |
| logit | 第 3 章 | softmax 输入的未归一化分数（本页为 $t\,x_i\cdot y_j$） |
| InfoNCE | 第 3 章来源说明 | 对比学习目标族名称，CLIP 损失属于该形式 |
| prompt 模板 | 第 4 章 | 把类别名嵌入的句式，默认 "A photo of a {label}." |
| prompt ensemble | 第 4 章 | 多个模板的文本嵌入取平均作为类别表示 |
| hypernetwork | 第 4 章 | 生成另一个网络（这里是线性分类器）权重的网络 |
| [EOS] | 第 2 章 | 文本序列结束符，其最高层激活作为整句表示 |
| all-gather | 第 5 章 | 分布式训练中把各设备分片聚合成全量的通信原语 |
| SigLIP | 第 5 章 | 把 CLIP 的 softmax 损失换成逐对 sigmoid 损失的后续工作 |
