# outline.md：CLIP 文章大纲

## 页面开头

具体问题引入：给视觉模型换一批类别就要重新收集标注训练——ImageNet 128 万张标注只覆盖 1000 类。有没有办法让模型"看图配文字"就学到可迁移的视觉表示？随后给出 CLIP 一句话定位（在 4 亿网络图文对上用对比目标联合训练双塔编码器）、核心问题列表、首段过渡到第一章。只用 scope 已确认事实，数字用 N1/N3。

## 章节设计

### 第 1 章 为什么用自然语言监督训练视觉模型——标注瓶颈与 zero-shot 需求

- 章节问题：
  1. 传统监督视觉训练的类别锁定问题是什么，自然语言监督怎么绕开它？
  2. CLIP 的预训练数据 WIT 是什么规模、怎么来的？
- 完成答案要点：标注数据集类别在训练时固定、迁移需重新标注；自然语言监督用网络图文对（无需人工类别标注）覆盖开放概念；WIT 400M 对、500k 查询、每查询至多 20k 对类平衡（N1）；预训练后可用自然语言指称概念实现 zero-shot 迁移（C1）
- 正文要点：标注成本与类别锁定 → 语言监督的开放性 → 对比目标一句话预告（下一章展开）
- 表达材料：对照表格（固定类别标注 vs 自然语言监督）
- 前置知识：无新增（预训练/迁移在文中两句话说明）

### 第 2 章 双塔架构与共享嵌入空间——两个编码器怎么被拉到一起

- 章节问题：
  1. CLIP 的图像塔和文本塔分别是什么，输出怎么进入共享空间？
  2. 为什么用余弦相似度度量两个模态的"配对程度"？
- 完成答案要点：图像塔为修改版 ResNet 或 ViT（ViT 见已有页），文本塔为 Transformer（63M/12 层，[EOS] 激活代表整句）；两侧各经线性投影（无非线性投影头）进共享空间，L2 归一化后用余弦相似度比较，取值 [-1,1]（C6/C7/F3）；双塔结构使推理时文本嵌入可预计算
- 正文要点：双塔（两个独立编码器）+ 线性投影 + L2 归一化；余弦相似度一行定义；[EOS] 机制两句话
- 表达材料：HTML 结构图（结构 A：图像/文本两路 → 投影 → 共享空间相似度）；对照表格（ResNet 系 vs ViT 系）
- 前置知识：ViT 链接（图像塔）

### 第 3 章 对称 softmax 对比损失——batch 就是分类题的选项

- 章节问题：
  1. 写出对称 softmax 对比损失公式并逐项解释符号。
  2. 手算 |B|=2 的损失，验证公式在每个方向做什么。
  3. 温度 τ 起什么作用、为什么对数参数化并截断？
- 完成答案要点：N 个配对构成 N×N 相似度矩阵；image→text 方向每张图是一道"N 选 1"分类题、logits 为缩放相似度、正答案是对角线；text→image 对称一次；两方向平均（F1/C2）；分母对整个 batch 求和 → 每个对与 batch 耦合；温度 τ 控制 logits 范围，对数参数化直接优化、初始化 0.07、截断防放大超过 100（F2/C8）；batch 32768（N2）；损失谱系定位一句话（N-pair → InfoNCE → 图文适配，C9）
- 正文要点：从"N 选 1"直觉进公式；符号逐项；|B|=2 手算（正文保留关键步骤、完整中间数值入折叠块）；温度机制；batch 耦合预告第 5 章
- 表达材料：贯穿数值示例（|B|=2，相似度矩阵 → 两个方向 softmax → 平均）；相似度矩阵表格（正对在对角线）
- 前置知识：标准注意力（softmax）、交叉熵（softmax 交叉熵 = 分类损失）链接

### 第 4 章 zero-shot 分类——文本编码器是生成分类器的网络

- 章节问题：
  1. 给一个新数据集的类别列表，CLIP 怎么不训练就分类？
  2. prompt 模板解决什么问题、带来多少提升？
  3. zero-shot CLIP 的代表结果是多少、条件是什么？
- 完成答案要点：类别名套 prompt 模板 → 文本编码器得各类别嵌入（可预计算缓存）→ 图像嵌入与全部类别嵌入比余弦相似度 → softmax 取最大（C3）；文本编码器是 hypernetwork（C4）；prompt 消歧（crane 吊车/鹤；训练文本多为完整句子），默认模板 "A photo of a {label}."，ImageNet 上单模板 +1.3%、80 prompt ensemble +3.5%、合计近 5%（C5/N5）；ViT-L/14@336px zero-shot ImageNet top-1 76.2%/top-5 95%、不用 128 万训练样本与 ResNet-50 持平（N3）；27 数据集 16 胜（N4，非逐数据集保证）
- 正文要点：合成线性分类器机制 → prompt 必要性（一词多义）→ ensemble → 数字与条件
- 表达材料：HTML 结构图（结构 A：类别名 → prompt → 文本编码器 → 类别嵌入矩阵；图像 → 图像编码器 → 嵌入；相似度比较）；手算延续（用第 3 章的 2×2 相似度矩阵演示一次 zero-shot：两张候选类别文本、一张图、判对）
- 前置知识：无新增（复用第 2、3 章结论）

### 第 5 章 训练配置与边界——softmax 损失的 batch 耦合及其他

- 章节问题：
  1. CLIP 的关键训练配置有哪些（温度、batch、模型家族、算力）？
  2. softmax 损失的 batch 耦合带来什么限制，SigLIP 为什么换掉它？
- 完成答案要点：温度初始化与截断（C8）；batch 32768（N2）；5 ResNet + 3 ViT、默认报告模型 ViT-L/14@336px；算力 RN50x64 592 V100×18 天、最大 ViT 256 V100×12 天（N6）；边界一：分母依赖整个 batch——小 batch 难负样本不足、多设备需聚合全部嵌入，是 SigLIP 换逐对 sigmoid 的动机（C10，链接 SigLIP 页）；边界二：zero-shot 非零设计（prompt 合计近 5%）；边界三：16/27 是统计非逐项保证（N4）
- 正文要点：配置一览表 → 三条边界逐条（每条给条件与来源）→ SigLIP/MoonViT-V2 链接收尾
- 表达材料：对照表格（CLIP softmax vs SigLIP sigmoid 一行式对比，详细机制链接 SigLIP 页）
- 前置知识：SigLIP 链接（后续工作）
