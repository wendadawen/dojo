EAGLE-3

EAGLE-3 是投机解码里的一种草稿模型，它只有一层 decoder，输入是 target 模型前向已经算出的低、中、高三层隐藏状态融合成的向量，直接输出下一个 token 的分布，并在训练时把自己多步的输出喂回去对齐推理。

只读 target 特征的草稿模型

大模型逐 token 生成文本，每生成一个 token 都要把全部参数过一遍，一个接一个，解码慢。投机解码用一个草稿模型先猜出几个 token，再让大模型一次并行核对，猜对的直接接下，猜错的退回重来。这套框架是投机解码，要加速的那个大模型叫 target。token 是模型处理文本的最小单位，文本先被切成 token 序列；隐藏状态是模型每一层对每个位置算出的向量，逐层往后传，已经聚了该位置之前的上下文；decoder 是把向量按上下文一层层算下去的模块。EAGLE-3 是一种草稿模型，它只有一层 decoder，输入是 target 算出的低、中、高三层隐藏状态融合成的向量（再拼上刚采样出的那个 token 的嵌入，嵌入是 token 对应的向量），输出下一个 token 的分布。

另训小模型当草稿的难处

通常的草稿模型是一个独立于 target 的小模型，容量有限，很难精确逼近大模型，猜出的分布偏离大模型较多，被接下的比例就低。EAGLE-3 改用另一条路：target 一次前向（从输入一路算到输出的一遍完整计算）本来就会算出每个位置的隐藏状态，把这些已经算好的表示直接喂给草稿，比只看 token 更容易对齐。

融合三层特征，一层 decoder 出草稿

低、中、高三层隐藏状态在同一位置各出一个 k 维向量，k 是隐藏维度。把这 3 个向量首尾接成一个 3k 维向量，过一个全连接层压回 k 维，得到融合特征 g；全连接层是每个输出由各输入各乘一个权重再相加的一层。把 g 与刚采样出的那个 token 的嵌入（token 对应的向量）拼接，过一层 decoder，再由 LM head（把向量映成下一个 token 分布的那一层）得到分布，从中采样就是一条草稿。
