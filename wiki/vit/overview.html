Vision Transformer（ViT）

Dosovitskiy 2021 提出的图像分类架构：把图像切成 patch 当 token 喂给标准 Transformer，主动去除 CNN 的空间归纳偏置，让模型从大数据中自己学空间关系。

更新于 2026-08-09

是什么

ViT 是一个把图像分类从 CNN 范式迁移到标准 Transformer 范式的架构。它把一张 $224\times 224$ 图像切成 $14\times 14=196$ 个 $16\times 16$ patch，每个 patch 展平后线性投影成 $D$ 维 token，prepend 一个可学习 class token、加上可学习 1D 位置编码，最后送入 $L$ 层标准 Transformer 编码块。class token 的最终隐状态经 LayerNorm 后接分类头输出类别。除输入端的 tokenization 外，编码块结构与 [标准注意力](../../wiki/standard-attention/index.html) 概念页给出的多头自注意力完全一致。

为什么需要它

  • CNN 的 locality（局部卷积）与 translation invariance（平移不变权重共享）在小数据下有效，但限制了模型在大数据下可学到的关系种类——远距离像素要堆很多层才能交互。
  • NLP 已经验证标准 Transformer 的可扩展性（BERT → GPT-3 趋势）。Dosovitskiy 2021 §1 假设这种可扩展性来自"无空间归纳偏置"，可移植到视觉。
  • 把图像变成与文本 token 同构的 patch 序列后，Transformer 不需要任何架构改动——这是 ViT 能直接复用 NLP 已验证可扩展性的关键。
  • 实验证明大数据下"无归纳偏置"反而成为优势：JFT-300M 预训练后 ViT-H/14 在 ImageNet 上达 88.55%，超过 BiT-L（ResNet152x4）的 87.54%，且用更少 TPUv3-core-days（2.5k vs 9.9k）。

核心直觉

  • Patch 是图像预处理产物，token 是投影后的 $D$ 维向量。把 $16\times 16\times 3$ patch 展平为 $768$ 维、再用矩阵 $E$ 投影到 $D$ 维才完成 tokenization。
  • Class token 借鉴 BERT 的 [CLS]。它 prepend 在序列最前，承载全局信息用于分类；与所有 patch token 一起经过 $L$ 层 Transformer，最后接分类头。这是论文主线选择，GAP 是替代方案。
  • 位置编码弥补注意力位置无关性。注意力本身不知道"哪个 patch 在图像的哪个位置"，需要外接位置信息。ViT 选可学习 1D 绝对位置编码——简单、不引入额外空间先验。
  • 编码块与标准 Transformer 几乎完全一致。每层是 pre-LN + 多头自注意力 + 残差 + MLP + 残差，Q/K/V 内部计算与 [标准注意力](../../wiki/standard-attention/index.html) 完全一致。ViT 的"新"只在输入端，不在编码块本身。
  • $224\times 224$ patch 16 → 196 token，加 class token → 197 序列长度。ViT-B/16 配置下 $D=768$，输入张量 $z_0\in\mathbb{R}^{197\times 768}$。

关键结论与边界

  • 大数据下 ViT 超越 CNN：ViT-L/16 (JFT-300M) 在 ImageNet 上 87.76%、ViT-H/14 88.55%，超过 BiT-L 的 87.54%，且训练计算更少（2.5k vs 9.9k TPUv3-core-days）。成立条件——JFT-300M 量级预训练 + ImageNet 微调。
  • 小数据从零训练 ViT 不如 CNN：在 ImageNet-1k（1.3M 图）上从零训练 ViT 不如 ResNet，缺乏局部先验、欠拟合。这是 DeiT 等后续工作要解决的问题（更强 augmentation + 蒸馏）。
  • 原始 ViT 不解决检测/分割/视频/多模态对齐：检测下游需加 task-specific head（DETR、Mask2Former）；视频时序需扩展（MoonViT-V2 等变体）；多模态对齐需对比损失目标（CLIP、SigLIP）。ViT 本身只做编码。
  • "large scale training trumps inductive bias"（Dosovitskiy 2021 §1 原文）：大规模训练胜过归纳偏置。这是后续 ViT 家族（DeiT、Swin、BEiT、MAE、DINOv2、MoonViT-V2）的共同前提。
