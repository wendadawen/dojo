    Vision Transformer（ViT）：把图像切成 patch 当 token 喂给标准 Transformer

    主要依据：Dosovitskiy et al. 2021, "An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale", ICLR 2021, arXiv:2010.11929v2, §3.1 模型概述 Eq.(1)–Eq.(4)、Table 1 模型配置、§4.2 Table 2 实验结果、§4.4 Scaling Study。

    把一张 $224\times 224$ 的猫图给 ResNet，它会用 $3\times 3$ 卷积核逐层扫描局部像素、堆几十层才让远距离像素交互；把同一张图给 ViT，它先把图切成 $14\times 14=196$ 个 $16\times 16$ 的方块，每个方块当一个 token 喂给标准 Transformer，让多层自注意力自己决定"猫耳朵的 patch 该看哪些 patch"——结果是后者在大数据下精度更高、训练计算更少。ViT 是 DeiT、Swin、BEiT、MAE、DINOv2、MoonViT-V2 等 ViT 家族变体的共同基础，后文用到 标准注意力、残差连接、位置编码 三个概念。ViT 究竟怎么把图像变成 token、编码块与标准 Transformer 有何异同、什么时候比 CNN 强？

    核心问题

    1. ViT 要解决什么问题——为什么把图像切成 patch 当 token 喂给标准 Transformer，而不是继续用 CNN？

      解答：为什么要用 patch 序列替代 CNN

      CNN 的局部性与平移等变归纳偏置在小数据下是优势，在大数据下限制了模型可学关系的种类——远距离像素要堆很多层才能交互。ViT 主动去除几乎全部 vision-specific 归纳偏置（仅 patch 切分保留少量 2D 邻域结构），把图像变成与文本 token 同构的 patch 序列直接喂给标准 Transformer，让空间关系从数据中学，依据是 NLP 已验证的标准 Transformer 可扩展性。完整论证见"ViT 要解决什么问题"一章。

    2. 写出 $z_0=[x_{\text{class}};\,x_p^1 E;\,\ldots;\,x_p^N E]+E_{\text{pos}}$，逐项解释符号，手算 $224\times 224$ patch 16 → 196 token、197 序列长度。

      解答：$z_0$ 公式与手算

      $x$ 是 $H\times W\times C$ 输入图像，切成 $N=HW/P^2$ 个 $P\times P\times C$ patch；每个 patch 展平为 $x_p^i\in\mathbb{R}^{P^2 C}$，经线性投影 $E\in\mathbb{R}^{P^2 C\times D}$ 得 patch token；$x_{\text{class}}\in\mathbb{R}^{D}$ 是 prepend 的可学习 class token；$E_{\text{pos}}\in\mathbb{R}^{(N+1)\times D}$ 是可学习 1D 位置编码。$224\times 224$、$P=16$ 时 $N=50176/256=196$，加 class token 后序列长度 $N+1=197$；ViT-B/16 下 $z_0\in\mathbb{R}^{197\times 768}$。逐符号推导与形状对照见"图像如何变成 token 序列"一章。

    3. 写出编码块 $z_\ell'=\text{MSA}(\text{LN}(z_{\ell-1}))+z_{\ell-1}$、$z_\ell=\text{MLP}(\text{LN}(z_\ell'))+z_\ell'$、分类头 $y=\text{LN}(z_L^0)$，并说明与标准 Transformer 的三处差异（pre-LN、encoder-only、Q/K/V 来源）。

      解答：编码块公式与三处差异

      每层先做 $\text{MSA}(\text{LN}(z_{\ell-1}))+z_{\ell-1}$，再做 $\text{MLP}(\text{LN}(z_\ell'))+z_\ell'$（pre-LN + 残差）；$L$ 层后取 class token 位置 $z_L^0$ 经 LayerNorm 得 $y$。与标准 Transformer 的三处差异：LN 在子层前（pre-LN 而非 post-LN）、encoder-only（无 decoder 与交叉注意力）、$Q,K,V$ 来自 patch 嵌入 $z_{\ell-1}$ 的线性投影。其余部件均为标准件。见"Transformer 编码块"一章。

    4. 指出 ViT 的数据规模边界——小数据从零训练 ViT 不如 ResNet；JFT-300M 预训练后 ViT-L/16 达 87.76%、ViT-H/14 达 88.55% 超越 BiT-L 的 87.54% 且用更少 TPUv3-core-days。

      解答：数据规模边界

      ImageNet-1k（1.3M 图）量级从零训练时 ViT 缺乏局部先验、不如 ResNet；JFT-300M 预训练 + ImageNet 微调后 ViT-L/16 达 87.76%、ViT-H/14 达 88.55%，超过 BiT-L 的 87.54%，且 ViT-H/14 只用 2.5k TPUv3-core-days（BiT-L 为 9.9k）。结论"大规模训练胜过归纳偏置"的成立条件是大数据预训练。见"数据规模边界"一章。

    最容易误解

    • 以为 ViT 是"用 attention 替换卷积"——正确：ViT 是"把图像变成 token 序列后整体喂给标准 Transformer"；attention 只是 Transformer 内部的一个子操作，ViT 的真正创新在 tokenization（patch embedding + class token + 位置编码）
    • 以为 patch 就是 token——正确：patch 是图像预处理产物（切成方块的展平向量），token 化的真正机制是后面的线性投影 $E$；任何序列输入都可以是 token，ViT 的特殊之处是用"patch + 线性投影"作 tokenization
    • 以为 class token 是分类才需要的辅助向量、去掉做 GAP 一样好——正确：附录 D.3 消融显示 GAP 与 class token 整体性能相当（需不同学习率），但论文主线用 class token，因为它沿用文本 Transformer / BERT 的 [class] token 设计；GAP 是替代方案而非默认
    • 以为 ViT 在 ImageNet 上 88.55% 超过 ResNet 就意味着"ViT 普遍比 CNN 强"——正确：88.55% 是 ViT-H/14 在 JFT-300M 预训练后的微调结果；脱离预训练数据规模谈架构优劣是误读
    • 以为 ViT 是新架构、与标准 Transformer 是两种东西——正确：ViT 的 MSA、MLP、残差、LayerNorm 都是 Transformer 标准件；"新"只在输入端（patch + class token + 1D 位置编码）与输出端（用 class token 而非 pooled 输出做分类），Q/K/V 内部计算与 标准注意力 完全一致

    1. ViT 要解决什么问题——CNN 的归纳偏置与大数据下的局限

    理解 ViT 之前要先看清 CNN 的两个归纳偏置——架构对数据做的先验假设。CNN 用局部卷积核扫描图像——卷积即局部加权求和：

    • Locality（局部性）：卷积核只看 $3\times 3$ 或 $5\times 5$ 的局部邻域，假设"相邻像素的关系强于远距离像素"。
    • Translation equivariance（平移等变性）：同一个卷积核在图像上共享权重，输入平移时输出特征同等平移；要得到"平移不变"还需池化等聚合操作。

    这两个偏置在小数据下是优势：参数共享减少过拟合、平移鲁棒符合视觉先验、不需要从头学空间结构。但它们在大数据下成为限制——比如"猫坐在沙发上"这种长程关系，CNN 要堆很多层才能让远距离像素交互；模型也无法学到与平移等变先验相冲突的关系（如"目标在图像左上角"这一类位置敏感任务）。

    辅助解释。 可以把"归纳偏置"理解为"架构给数据预先设定的规则"：CNN 预先设定"局部像素重要 + 平移等变"；标准 Transformer 几乎不预设 vision-specific 空间规则，空间关系都从数据学。这个类比只帮助理解"为什么大数据下几乎没有 vision-specific 归纳偏置反而成为优势"。它不意味着"归纳偏置越少总是越好"——小数据下无先验会让模型更容易过拟合、泛化更差（见"数据规模边界"一章）。

    标准 Transformer 已成 NLP 的模型首选；Dosovitskiy 2021 §1 指出，得益于 Transformer 的计算效率与可扩展性，NLP 中已能训练参数量超过 100B 的模型，并由此得出"large scale training trumps inductive bias"（大规模训练胜过归纳偏置）的结论[C1]——ViT 据此让模型从数据中自己学出空间关系，而不是预设局部性。ViT 的设计取向因此是：把图像变成与文本 token 同构的 patch 序列，直接喂给标准 Transformer，不做任何 vision-specific 的架构改动。Attention 在 Transformer 内部按"内容相关加权"自动学出该看哪些 patch，不预设局部性。

    架构空间先验远距离交互路径大数据下可学关系
    CNNlocality + translation equivariance$O(\log_k n)$ 层（$k$ 为核大小）受先验限制
    ViT几乎没有 vision-specific 归纳偏置（patch 切分保留少量 2D 邻域结构）$O(1)$ 层（自注意力直接交互）从数据学，先验限制很少

    $n$ 为把图像视作一维序列时的位置数（这里取边长像素数 224）。CNN 路径 $O(\log_k n)$ 指要让相距 $n$ 的两位置交互需要的层数（等同于 Vaswani 2017 §4 Table 1 的 CNN 最大路径长度）；ViT 路径 $O(1)$ 指一层自注意力就让任意两 patch 直接交互（已在 标准注意力 §1 说明）。

    常见误解。 ViT 不是"用 attention 替换卷积"，而是"用纯 Transformer 替代 CNN"。Attention 只是 Transformer 内部的一个子操作；ViT 的真正创新在下一章的 tokenization（patch embedding + class token + 位置编码）。把 ViT 简单概括为"用 attention 看图"会错过它"几乎没有 vision-specific 归纳偏置"的核心设计取向。

    与 NLP Transformer 的对应：文本 token 是词向量；图像 token 是 patch 投影。Transformer 内部完全相同——这是 ViT 能直接复用 NLP 已验证可扩展性的关键。

    本章问题

    1. 用一句话说出 CNN 的两个归纳偏置（locality + translation equivariance）。

      解答：CNN 的两个归纳偏置

      局部性——卷积核只看 $3\times 3$ 或 $5\times 5$ 的邻域，假设相邻像素的关系强于远距离像素；平移等变性——同一卷积核在整幅图像上共享权重，输入平移时输出特征同等平移（"平移不变"还需池化等聚合操作才出现）。二者都是架构对数据预先设定的先验假设，不是从数据学到的性质。

    2. 这些偏置在小数据下为什么是优势、在大数据下为什么成为限制？

      解答：偏置优势与限制的转换条件

      小数据下：参数共享减少过拟合，平移鲁棒符合视觉先验，不需要从头学空间结构。大数据下：数据足以覆盖更广的关系时，先验反而排除了一类可学关系——远距离像素交互需要堆很多层才能建立，与平移等变先验冲突的位置敏感任务（如"目标在图像左上角"）学不出来。转换条件是预训练数据规模。

    3. 说出 ViT 的设计取向。

      解答：ViT 的设计取向

      几乎没有 vision-specific 归纳偏置（仅 patch 切分保留少量 2D 邻域结构）——把图像切成与文本 token 同构的 patch 序列，直接喂给标准 Transformer，不做任何 vision-specific 架构改动，让所有空间关系从数据中学。依据是 NLP 已验证的标准 Transformer 可扩展性，以及 Dosovitskiy 2021 §1 的结论"large scale training trumps inductive bias"（大规模训练胜过归纳偏置）。

    标准 Transformer 的输入是 token 序列，图像要进入它必须先被转换成这种序列——patch embedding、class token、位置编码负责完成这三步转换。

    2. 图像如何变成 token 序列——patch embedding、class token、位置编码

    标准 Transformer 接收一个 $D$ 维 token 序列 $z_0\in\mathbb{R}^{(N+1)\times D}$ 作为输入。ViT 用三步把一张图像变成这个序列。

    第一步 Patch 切分。输入图像 $x\in\mathbb{R}^{H\times W\times C}$，其中 $H$ 是高度、$W$ 是宽度、$C$ 是通道数（RGB 图像 $C=3$）。把它切成 $N=HW/P^2$ 个不重叠的 $P\times P\times C$ patch，$P$ 是 patch 大小（论文主线 $P=16$）。每个 patch 形状为 $P\times P\times C$。

    第二步 展平 + 线性投影。每个 patch 展平为 $P^2 C$ 维向量 $x_p^i\in\mathbb{R}^{P^2 C}$，再用线性投影矩阵 $E\in\mathbb{R}^{P^2 C\times D}$ 投影到 $D$ 维（$xE$ 即矩阵乘法、输出 $D$ 维）。投影后的 $x_p^i E\in\mathbb{R}^{D}$ 是一个 patch token。[C2]

    第三步 Class token prepend + 位置编码。在 patch 序列最前 prepend 一个可学习向量 $x_{\text{class}}\in\mathbb{R}^{D}$（借鉴 BERT 的 [CLS] token——见下方折叠块）；序列长度从 $N$ 变为 $N+1$。[C3]然后加上可学习 1D 绝对位置编码 $E_{\text{pos}}\in\mathbb{R}^{(N+1)\times D}$——注意力本身位置无关（见 位置编码），需要外接位置信息让模型知道"哪个 patch 在图像的哪个位置"。[C4]

    三步合成公式：

    $$z_0=[x_{\text{class}};\,x_p^1 E;\,x_p^2 E;\,\ldots;\,x_p^N E]+E_{\text{pos}},\qquad E\in\mathbb{R}^{P^2 C\times D},\;E_{\text{pos}}\in\mathbb{R}^{(N+1)\times D}.$$ [F1]

    其中 $[;\,]$ 表示沿序列维拼接。$z_0\in\mathbb{R}^{(N+1)\times D}$ 是 Transformer 的输入。

    补充：BERT [CLS] token 的来源与 ViT 的借鉴

    BERT（Devlin et al. 2019）在 NLP 中用 [CLS] token 做句子分类：在句子最前加一个特殊 token，让它经过 Transformer 后承载"整句语义"，最后接分类头。Dosovitskiy 2021 §3.1 直接沿用此设计：$x_{\text{class}}$ 就是 ViT 的 [CLS] token，$z_L^0$（第 $L$ 层输出的第 0 行）是它的最终隐状态。这个借鉴让 ViT 不需要为分类任务设计特殊输出结构——直接复用 BERT 的"class token 做分类"模式。

    补充：为什么选可学习 1D 而非 sin/cos 或 2D 位置编码

    论文 §3.1 选择"learned 1D position embeddings"（可学习 1D 绝对位置编码）。附录 D.4 消融对比 1D vs 2D（保留行/列结构）位置编码，差异不显著；§3.1 给出的选择理由是未观察到更高级的 2D-aware 位置编码带来显著性能增益。这与 Vaswani 2017 原始 Transformer 的 sin/cos 编码不同——sin/cos 是固定的、不可学习；ViT 让位置编码与 patch 嵌入一起从数据学。家族完整对比见 位置编码。

    补充：class token vs GAP（全局平均池化）的消融

    附录 D.3 给出消融：用 GAP（对所有 patch token 的输出取平均做分类头输入）与 class token 整体性能相当（需不同学习率）。论文主线使用 class token 是沿用文本 Transformer / BERT 的 [class] token 设计（论文自述为尽量贴近原始 Transformer 模型）。GAP 是替代方案而非默认方案。

    三步合成流程如下。

    输入图像$x\in\mathbb{R}^{H\times W\times C}$
    ↓ 切成 $N=HW/P^2$ 个 $P\times P\times C$ patch
    patch 序列$\text{patch}_1,\ \text{patch}_2,\ \ldots,\ \text{patch}_N$（每个展平为 $P^2 C$ 维向量 $x_p^i$）
    ↓ 线性投影 $x_p^i E$（$E\in\mathbb{R}^{P^2 C\times D}$）
    token 序列$\text{token}_1,\ \text{token}_2,\ \ldots,\ \text{token}_N$（每个为 $D$ 维 patch token）
    ↓ prepend class token $x_{\text{class}}\in\mathbb{R}^{D}$
    拼接序列$[x_{\text{class}};\ \text{token}_1;\ \ldots;\ \text{token}_N]$（序列长度 $N+1$）
    ↓ 加位置编码 $E_{\text{pos}}\in\mathbb{R}^{(N+1)\times D}$
    Transformer 输入$z_0\in\mathbb{R}^{(N+1)\times D}$

    构造示例。$H=W=224$、$P=16$、$C=3$（标准 ImageNet RGB 图像 + ViT 主线 patch 大小，教学构造，不代表真实模型参数）[N2]：

    • $N=HW/P^2=224\times 224/16^2=50176/256=196$ 个 patch；
    • 加 class token 得 $N+1=197$ 个 token；
    • ViT-B/16 配置下 $D=768$，故 $z_0\in\mathbb{R}^{197\times 768}$。

    各形状对照：

    量形状含义
    $x$$\mathbb{R}^{224\times 224\times 3}$输入 RGB 图像
    单个 patch$\mathbb{R}^{16\times 16\times 3}$$P\times P\times C$ 图像块
    $x_p^i$$\mathbb{R}^{768}$第 $i$ 个 patch 展平后向量（$P^2 C=16\times 16\times 3=768$）
    $E$$\mathbb{R}^{768\times 768}$线性投影矩阵（$P^2 C\times D=768\times 768$；此处 $P^2 C=768$ 恰好等于 $D=768$ 是 ViT-B/16 的巧合，不是必须）
    $x_p^i E$$\mathbb{R}^{768}$第 $i$ 个 patch token（$D$ 维）
    $x_{\text{class}}$$\mathbb{R}^{768}$可学习 class token
    $E_{\text{pos}}$$\mathbb{R}^{197\times 768}$可学习 1D 位置编码（$N+1=197$）
    $z_0$$\mathbb{R}^{197\times 768}$Transformer 输入序列

    Patch 大小 $P$ 的影响。$P$ 越小 token 越多、计算量越大：$P=32$ 时 $N=49$；$P=14$ 时 $N=256$。ViT-H/14 的命名（Huge 配置 + patch 14）见于论文 §4.2；论文未说明 Huge 选用 patch 14 的理由。

    常见误解。 Patch 不是 token——patch 是图像预处理产物（切成方块的展平向量），token 化的真正机制是后面的线性投影 $E$。把 "patch" 与 "token" 混用会让人误以为"patch = token"是 ViT 特有的概念；实际上任何序列输入（文本词向量、音频片段）都可以是 token，ViT 的特殊之处是用"patch + 线性投影"作 tokenization 让 Transformer 不需要任何架构改动。

    本章问题

    1. 写出 $z_0$ 公式并说出每个符号（$x, P, N, E, x_{\text{class}}, E_{\text{pos}}, D, z_0$）。

      解答：$z_0$ 公式逐项解释

      $z_0=[x_{\text{class}};\,x_p^1 E;\,\ldots;\,x_p^N E]+E_{\text{pos}}$。$x\in\mathbb{R}^{H\times W\times C}$ 是输入图像；$P$ 是 patch 边长（主线 $P=16$）；$N=HW/P^2$ 是 patch 数；$x_p^i\in\mathbb{R}^{P^2 C}$ 是第 $i$ 个展平 patch；$E\in\mathbb{R}^{P^2 C\times D}$ 是线性投影矩阵；$x_{\text{class}}\in\mathbb{R}^{D}$ 是可学习 class token；$E_{\text{pos}}\in\mathbb{R}^{(N+1)\times D}$ 是可学习 1D 位置编码；$D$ 是隐藏维；$z_0\in\mathbb{R}^{(N+1)\times D}$ 是 Transformer 输入序列。

    2. 算出 $224\times 224$ patch 16 的 patch 数与含 class token 的序列长度。

      解答：196 个 patch、197 序列长度

      $N=HW/P^2=224\times 224/16^2=50176/256=196$；prepend class token 后序列长度 $N+1=197$。ViT-B/16 配置下 $D=768$，故 $z_0\in\mathbb{R}^{197\times 768}$。

    3. 说出 class token 与位置编码各自的作用。

      解答：class token 与位置编码的分工

      class token 是 prepend 在序列最前的可学习向量，经 $L$ 层编码后承载全局信息、供分类头使用（借鉴 BERT [CLS]）；位置编码弥补注意力本身位置无关的缺陷，让模型知道"哪个 patch 在图像的哪个位置"。前者服务输出端分类，后者服务输入端空间定位。附录 D 消融显示 GAP 可替代 class token、1D 与 2D 位置编码差异不显著，二者都是论文主线选择而非唯一可行方案。

    第 2 章构造的 $z_0$ 送入编码块：$L$ 层编码块逐层在序列上做自注意力与前馈变换，每层输出 $z_\ell'$、$z_\ell$，最后一层的 class token 位置经 LayerNorm 得到分类输出 $y$。

    3. Transformer 编码块——与标准 Transformer 几乎完全一致

    ViT 把 $z_0$ 喂给 $L$ 层编码块，每层接收 $z_{\ell-1}\in\mathbb{R}^{(N+1)\times D}$ 输出 $z_\ell\in\mathbb{R}^{(N+1)\times D}$。每层内部含两个子层——多头自注意力（MSA）+ 前馈网络（MLP），每个子层前用 LayerNorm、后用残差连接（$y=F(x)+x$，见 残差连接）。[C5]

    $$z_\ell'=\text{MSA}(\text{LN}(z_{\ell-1}))+z_{\ell-1},\qquad \ell=1\ldots L.$$ [F2]

    $$z_\ell=\text{MLP}(\text{LN}(z_\ell'))+z_\ell',\qquad \ell=1\ldots L.$$ [F3]

    $L$ 层后取 class token 对应位置 $z_L^0$，经 LayerNorm 得到图像表示 $y$：[C6]

    $$y=\text{LN}(z_L^0).$$ [F4]

    逐项解释：

    • $\text{LN}$（LayerNorm）：把每行特征归一化到均值 0、方差 1（沿特征维归一化）。ViT 用 pre-LN——LN 在子层前应用，与 Vaswani 2017 原始 Transformer 的 post-LN（LN 在子层后）不同（见下方折叠块）。
    • $\text{MSA}$（多头自注意力）：内部公式 $\text{softmax}(QK^\top/\sqrt{d_k})V$ 与 标准注意力 完全一致；多头拼接机制也与其 §4 一致。区别只在 $Q,K,V$ 的来源——NLP 是词嵌入的线性投影，ViT 是 patch 嵌入 $z_{\ell-1}$ 的线性投影。
    • $\text{MLP}$（前馈网络）：两层 + GELU 非线性（GELU 是平滑的 ReLU 变体）。中间层维度由配置表的 MLP size 给出（ViT-B 为 3072）。
    • 残差连接：两个子层后都加上输入（$+z_{\ell-1}$ 与 $+z_\ell'$），让深网络训练稳定——见 残差连接。
    • $z_L^0$：第 $L$ 层输出 $z_L\in\mathbb{R}^{(N+1)\times D}$ 的第 0 行（class token 对应位置）。预训练时分类头接在 $z_L^0$ 后是一个 MLP（含一个隐藏层 + tanh 非线性），微调时简化为单线性层。
    补充：pre-LN 与 post-LN 的训练稳定性差异

    Vaswani 2017 原始 Transformer 用 post-LN（LN 在子层后，残差在 LN 前）；ViT 用 pre-LN（LN 在子层前，残差在 LN 后）。Xiong et al. 2020（arXiv:2002.04745）指出 pre-LN 让残差路径上没有 LN 阻塞，梯度沿残差路径更顺畅，深网络训练更稳定——这一结论常被用来解释 ViT 选 pre-LN 的工程动机（ViT 论文本身未展开论证）。MoonViT-V2 等后续变体用 RMSNorm 进一步替换 LN，但整体 pre-LN 结构不变。

    与标准 Transformer 的三处差异。除 pre-LN 外，ViT 还有两处可核对差异：

    项Vaswani 2017 原始 TransformerViT
    归一化位置post-LN（LN 在子层后）pre-LN（LN 在子层前）
    编码-解码结构encoder + decoder（含交叉注意力子层）encoder-only（无 decoder、无交叉注意力）
    $Q,K,V$ 来源编码块输入序列（词向量）的线性投影编码块输入序列（patch 嵌入 $z_{\ell-1}$）的线性投影

    表中"$Q,K,V$ 来源"指编码块输入端 token 类型；每层的 $Q,K,V$ 都由该层输入序列线性投影得到，内部计算与标准注意力完全一致。除这三处外，MSA、MLP、残差、LayerNorm 都是 Transformer 的标准件——ViT 不是新架构，而是输入端改造。

    关键结论。 ViT 的真正贡献在上一章的 tokenization（patch embedding + class token + 1D 位置编码），不在编码块本身。理解了 标准注意力 的多头公式，就理解了 ViT 编码块的 MSA；理解了 残差连接，就理解了 ViT 的 $+z_{\ell-1}$ 与 $+z_\ell'$。这是 MoonViT-V2 能用 RMSNorm 替换 LN、去 bias 仍保持整体结构的前提。

    本章问题

    1. 写出 $z_\ell', z_\ell, y$ 三条公式并解释每个符号（$L, \ell, \text{LN}, \text{MSA}, \text{MLP}, z_L^0$）。

      解答：编码块三条公式

      $z_\ell'=\text{MSA}(\text{LN}(z_{\ell-1}))+z_{\ell-1}$，$z_\ell=\text{MLP}(\text{LN}(z_\ell'))+z_\ell'$（$\ell=1\ldots L$），$y=\text{LN}(z_L^0)$。$L$ 是编码块总数，$\ell$ 是层下标，LN 是 LayerNorm（pre-LN 位置），MSA 是多头自注意力，MLP 是两层 + GELU 前馈网络，$z_L^0$ 是第 $L$ 层输出中 class token 对应的第 0 行。

    2. 说出 pre-LN 与 post-LN 的差异，以及 ViT 为什么选择 pre-LN。

      解答：pre-LN 与 post-LN

      post-LN（Vaswani 2017）把 LN 放在子层之后、残差在 LN 前；pre-LN（ViT）把 LN 放在子层之前、残差路径上没有 LN 阻塞。Xiong et al. 2020 指出 pre-LN 让梯度沿残差路径更顺畅、深网络训练更稳定，这常被用来解释 ViT 选择 pre-LN 的工程动机（ViT 论文本身未展开论证）。

    3. 说出 ViT 与标准 Transformer 的三处差异（pre-LN、encoder-only、$Q,K,V$ 来源）。

      解答：三处差异

      归一化位置：post-LN 改为 pre-LN；结构：encoder + decoder（含交叉注意力子层）改为 encoder-only；$Q,K,V$ 来源：词嵌入的线性投影改为 patch 嵌入 $z_{\ell-1}$ 的线性投影。三处之外，MSA、MLP、残差、LayerNorm 都是标准件——ViT 不是新架构，而是输入端改造。

    编码块与标准 Transformer 一致，ViT 与 CNN 的精度差异因此主要来自训练数据规模——论文报告的 88.55% 就是在 JFT-300M 量级预训练下取得的。

    4. 数据规模边界——什么时候 ViT 比 CNN 强、什么时候反而更弱

    ViT 的精度高度依赖预训练数据规模。Dosovitskiy 2021 §4.1 用三个数据集做预训练：

    数据集图像数类别数可用性
    ImageNet-1k（ILSVRC-2012）1.3M1k公开
    ImageNet-21k14M21k公开

    小数据从零训练的边界。§4.3 报告：在 ImageNet-1k（1.3M 图）上从零训练 ViT 不如 ResNet——缺乏 CNN 的局部先验，在同算力下比 ResNet 过拟合更严重、泛化更差。[C7]这是后续 DeiT 等工作（更强 augmentation + 蒸馏）要解决的问题。

    大数据预训练 + 微调的优势。§4.2 Table 2 给出 ImageNet top-1 微调精度与预训练计算量（TPUv3-core-days）[N3]：

    读出两点：

    • 精度：ViT-L/16 (JFT) 87.76% 与 ViT-H/14 88.55% 都超过 BiT-L（ResNet152x4 + JFT 预训练）的 87.54%；ViT-H/14 与 Noisy Student（88.4–88.5%）相当。
    • 计算量：ViT-H/14 用 2.5k TPUv3-core-days，是 BiT-L 的 9.9k 的约 1/4、Noisy Student 的 12.3k 的约 1/5。用更少计算达到更高精度——这是大数据下"无归纳偏置"反而成为优势的实证。

    核心结论（Dosovitskiy 2021 §1 原文）："large scale training trumps inductive bias"——大规模训练胜过归纳偏置。[C1, C7]在 JFT-300M 量级数据下，ViT 主动去除几乎全部 vision-specific 归纳偏置、让模型从数据学，反而比 CNN 的局部卷积 + 平移等变先验达到更高精度，且训练计算更少。这是后续 ViT 家族（DeiT、Swin、BEiT、MAE、DINOv2、MoonViT-V2）的共同前提。

    适用边界。该结论的成立条件与不成立情形：

    情形ViT 相对 CNN 表现原因
    小数据从零训练（ImageNet-1k 量级）不如 CNN缺乏局部先验、过拟合更严重
    大数据预训练 + 微调（JFT-300M 量级）超过 CNN无归纳偏置限制、从数据学长程关系
    检测/分割下游任务需 task-specific headViT 本身只做编码，DETR/Mask2Former 等需加专用头[N4]
    视频时序建模原始 ViT 不支持原始 ViT 只处理单帧；MoonViT-V2 等变体才扩展到视频[N4]
    多模态对齐需对比损失目标CLIP、SigLIP 用对比损失对齐图文嵌入，ViT 仅作视觉 backbone[N4]

    前两行来自 Dosovitskiy 2021 §4.2–§4.4；后三行是 ViT 之后的延伸工作，不在该论文范围内，出处见 [N4]。

    常见误解。 ViT 在 ImageNet 上 88.55% 超过 ResNet 不等于"ViT 普遍比 CNN 强"。88.55% 是 ViT-H/14 在 JFT-300M（303M 图）预训练后的微调结果；脱离预训练数据规模谈架构优劣是误读。论文 §4.3 明确报告小数据下 ViT 不如 ResNet——这是 DeiT 等后续工作要解决的问题。

    ViT 家族变体一句话提及。后续工作在 ViT 基础上改动训练目标、注意力模式或归一化方式，但 patch 化 + Transformer 编码的整体框架不变：

    • DeiT：蒸馏 + 数据增强，解决小数据训练问题；
    • Swin Transformer：层级窗口注意力，重新引入 CNN 风格的局部归纳偏置；
    • BEiT / MAE：掩码图像建模自监督预训练，不再依赖标签数据；
    • DINOv2：自监督训练 + 大数据，无需微调即可迁移；
    • MoonViT-V2：K3 的视觉编码器（27 层、从零训练、RMSNorm、去 bias、视频分解注意力），见 MoonViT-V2。

    本章问题

    1. 说出 ViT 在 ImageNet 上 88.55% 对应的预训练数据集与模型。

      解答：88.55% 的成立条件

      ViT-H/14（Huge 配置 + patch 14）在 JFT-300M（303M 图、Google 私有）预训练后于 ImageNet 微调达到 88.55%（Dosovitskiy 2021 Table 2）。脱离该预训练数据规模不能复现该精度——ImageNet-1k 量级从零训练时 ViT 不如 ResNet。

    2. 说出大数据下 ViT 相对 CNN 的两个优势。

      解答：精度更高、计算更少

      精度：ViT-L/16 (JFT) 87.76%、ViT-H/14 88.55%，均超过 BiT-L（ResNet152x4 + JFT）的 87.54%。计算：ViT-H/14 用 2.5k TPUv3-core-days，约为 BiT-L（9.9k）的 1/4、Noisy Student（12.3k）的 1/5。二者共同构成"大规模训练胜过归纳偏置"的实证。

    3. 说出该结论的成立条件与至少一个不成立情形。

      解答：成立条件与边界

      成立条件：大数据预训练（JFT-300M 量级）+ 下游微调。不成立情形：ImageNet-1k 量级从零训练（缺乏局部先验、过拟合更严重，不如 ResNet）；检测/分割需 task-specific head（DETR、Mask2Former）；视频时序（原始 ViT 只处理单帧）；多模态对齐需对比损失目标（CLIP/SigLIP）。后三类为论文之后的延伸工作，出处见 [N4]。

    辅助解释与类比边界

    "归纳偏置 = 架构给数据预先设定的规则"类比（「ViT 要解决什么问题」辅助解释）：服务"为什么大数据下几乎没有 vision-specific 归纳偏置反而成为优势"的局部关系。失效边界——它不意味着"归纳偏置越少总是越好"（小数据下无先验会让模型过拟合更严重、泛化更差）；也不覆盖"不同任务下不同归纳偏置的相对优势"。正式判断以「数据规模边界」一章为准。

    "ViT 把图像变成与文本 token 同构的 patch 序列"对应关系（「ViT 要解决什么问题」末段）：服务"ViT 能直接复用 NLP 已验证可扩展性"的局部关系。失效边界——文本 token 是离散词向量、图像 token 是连续 patch 投影，二者统计性质不同；ViT 的可扩展性在论文 §4.2 实证支持，但不保证所有视觉任务下都比 CNN 好。

    简化条件及其限制

    简化一：CNN 归纳偏置只取 locality + translation equivariance 两个。简化做法：省略更细的归纳偏置（如层级结构、池化等操作带来的平移不变性）。可推出：小数据下有效、大数据下成为限制的对照。不可推出：不同归纳偏置在各任务下的相对优势。

    简化二：MSA 内部公式直接引用 标准注意力。简化做法：省略缩放因子 $\sqrt{d_k}$ 的方差推导与多头拼接的参数量等价证明（已在 标准注意力 给出）。可推出：ViT 编码块的 MSA 机制。不可推出：缩放因子的方差推导细节。

    简化三：只引用 ImageNet top-1 精度与 TPUv3-core-days。简化做法：省略 ImageNet ReaL、CIFAR-10/100、Oxford-IIIT Pets、Oxford Flowers-102、VTAB 等多数据集结果。可推出：大数据下 ViT 超越 CNN 的核心结论。不可推出：所有视觉任务下 ViT 都比 CNN 好。

    简化四：变体家族（DeiT/Swin/BEiT/MAE/DINOv2/MoonViT-V2）只一句话提及。简化做法：省略各变体机制。可推出：ViT 是后续变体的共同前置概念。不可推出：各变体的具体改动细节。

    ViT 从 CNN 归纳偏置的问题出发，用 patch embedding + class token + 1D 位置编码把图像变成 token 序列、用标准 Transformer 编码，并在 JFT-300M 量级预训练后超越 CNN。tokenization 三步、$z_0$ 与编码块公式、数据规模边界构成它的完整机制。这些是理解 DeiT、Swin、MoonViT-V2 等变体的共同前提。
