    Vision Transformer（ViT）：把图像切成 patch 当 token 喂给标准 Transformer

    主要依据：Dosovitskiy et al. 2021, "An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale", ICLR 2021, arXiv:2010.11929v2, §3.1 模型概述 Eq.(1)–Eq.(4)、Table 1 模型配置、§4.2 Table 2 实验结果、§4.4 结论。

    最容易误解

    • 以为 ViT 是"用 attention 替换卷积"——正确：ViT 是"把图像变成 token 序列后整体丢给标准 Transformer"；attention 只是 Transformer 内部的一个子操作，ViT 的真正创新在 tokenization（patch embedding + class token + 位置编码）
    • 以为 patch 就是 token——正确：patch 是图像预处理产物（切成方块的展平向量），token 化的真正机制是后面的线性投影 $E$；任何序列输入都可以是 token，ViT 的特殊之处是用"patch + 线性投影"作 tokenization
    • 以为 class token 是分类才需要的辅助向量、去掉做 GAP 一样好——正确：附录 D 消融显示在 JFT-300M 下 GAP 与 class token 性能相近，但论文主线用 class token，因为它继承 BERT 且让 Transformer 把"全局信息"显式聚合到一个位置；GAP 是替代方案而非默认
    • 以为 ViT 在 ImageNet 上 88.55% 超过 ResNet 就意味着"ViT 普遍比 CNN 强"——正确：88.55% 是 ViT-H/14 在 JFT-300M 预训练后的微调结果；脱离预训练数据规模谈架构优劣是误读
    • 以为 ViT 是新架构、与标准 Transformer 是两种东西——正确：ViT 的 MSA、MLP、残差、LayerNorm 都是 Transformer 标准件；"新"只在输入端（patch + class token + 1D 位置编码）与输出端（用 class token 而非 pooled 输出做分类），Q/K/V 内部计算与 [标准注意力](../../wiki/standard-attention/index.html) 完全一致

    是什么
    Dosovitskiy 2021 提出的图像分类架构：图像 → patch 切分 → 线性投影 → 加 class token + 1D 位置编码 → 标准 Transformer 编码 → class token 输出做分类
    为什么需要
    CNN 的 locality 与 translation invariance 在小数据下有效但限制大数据下可学关系；ViT 主动去除空间归纳偏置，让模型从数据学
    本文是哪些概念的前置
    DeiT、Swin、BEiT、MAE、DINOv2、MoonViT-V2 等 ViT 家族变体
    前置概念
    [标准注意力](../../wiki/standard-attention/index.html)、[残差连接](../../wiki/residual-connection/index.html)、[位置编码](../../wiki/positional-encoding/index.html)
    不展开
    DeiT/Swin/BEiT/MAE/DINOv2 各自机制；MoonViT-V2 视频分解注意力；检测/分割下游；CLIP/SigLIP 对比对齐

    ViT 要解决什么问题——CNN 的归纳偏置与大数据下的局限

    把一张 $224\times 224$ 的猫图给 ResNet，它会用 $3\times 3$ 卷积核逐层扫描局部像素、堆几十层才让远距离像素交互；把同一张图给 ViT，它先把图切成 $14\times 14=196$ 个 $16\times 16$ 的方块，每个方块当一个 token 喂给标准 Transformer，让 12 层自注意力自己决定"猫耳朵的 patch 该看哪些 patch"——结果是后者在大数据下精度更高、训练计算更少。

    理解 ViT 之前要先看清 CNN 的两个归纳偏置——架构对数据做的先验假设。CNN 用局部卷积核扫描图像（概念页 CNN 待生成，这里只需"卷积 = 局部加权求和"的最小概念）：

    • Locality（局部性）：卷积核只看 $3\times 3$ 或 $5\times 5$ 的局部邻域，假设"相邻像素的关系强于远距离像素"。
    • Translation invariance（平移不变性）：同一个卷积核在图像上共享权重，假设"目标平移后特征不变"。

    这两个偏置在小数据下是优势：参数共享减少过拟合、平移鲁棒符合视觉先验、不需要从头学空间结构。但它们在大数据下成为限制——比如"猫坐在沙发上"这种长程关系，CNN 要堆很多层才能让远距离像素交互；模型也无法学到与平移不变先验相冲突的关系（如"目标在图像左上角"这一类位置敏感任务）。

    教学解释。 可以把"归纳偏置"理解为"架构给数据预先设定的规则"：CNN 预先设定"局部像素重要 + 平移不变"；标准 Transformer 不预设任何空间规则，所有关系都从数据学。这个类比只帮助理解"为什么大数据下无归纳偏置反而成为优势"。它不意味着"无归纳偏置总是更好"——小数据下无先验会让模型欠拟合（见 §4 的边界）。

    NLP 已经验证标准 Transformer 的可扩展性：BERT → GPT-3 趋势显示数据越多、模型越大、性能持续上升。Dosovitskiy 2021 §1 假设这种可扩展性来自"无空间归纳偏置"——让模型从数据中自己学出空间关系，而不是预设局部性。ViT 的设计取向因此是：把图像变成与文本 token 同构的 patch 序列，直接喂给标准 Transformer，不做任何 vision-specific 的架构改动。Attention 在 Transformer 内部按"内容相关加权"自动学出该看哪些 patch，不预设局部性。

    架构空间先验远距离交互路径大数据下可学关系
    CNNlocality + translation invariance$O(n/k)$ 层（$k$ 为核大小）受先验限制
    ViT无（patch + 标准 Transformer）$O(1)$ 层（自注意力直接交互）从数据学，无先验限制

    $n$ 为图像线性化后的 token 数。CNN 路径 $O(n/k)$ 指要让相距 $n$ 的两位置交互需要的层数；ViT 路径 $O(1)$ 指一层自注意力就让任意两 patch 直接交互（已在 [标准注意力](../../wiki/standard-attention/index.html) §1 说明）。

    常见误解。 ViT 不是"用 attention 替换卷积"，而是"用纯 Transformer 替代 CNN"。Attention 只是 Transformer 内部的一个子操作；ViT 的真正创新在下一章的 tokenization（patch embedding + class token + 位置编码）。把 ViT 简单概括为"用 attention 看图"会错过它"无空间先验"的核心设计取向。

    与 NLP Transformer 的对应：文本 token 是词向量；图像 token 是 patch 投影。Transformer 内部完全相同——这是 ViT 能直接复用 NLP 已验证可扩展性的关键。

    现在知道"为什么试纯 Transformer"。但 Transformer 的输入是 token 序列——图像怎么变成 token？下一章看 patch embedding + class token + 位置编码三步。

    图像如何变成 token 序列——patch embedding、class token、位置编码

    标准 Transformer 接收一个 $D$ 维 token 序列 $z_0\in\mathbb{R}^{(N+1)\times D}$ 作为输入。ViT 用三步把一张图像变成这个序列。

    第一步 Patch 切分。输入图像 $x\in\mathbb{R}^{H\times W\times C}$，其中 $H$ 是高度、$W$ 是宽度、$C$ 是通道数（RGB 图像 $C=3$）。把它切成 $N=HW/P^2$ 个不重叠的 $P\times P\times C$ patch，$P$ 是 patch 大小（论文主线 $P=16$）。每个 patch 形状为 $P\times P\times C$。

    第二步 展平 + 线性投影。每个 patch 展平为 $P^2 C$ 维向量 $x_p^i\in\mathbb{R}^{P^2 C}$，再用线性投影矩阵 $E\in\mathbb{R}^{P^2 C\times D}$ 投影到 $D$ 维（概念页 矩阵乘法 待生成，这里只需"$xE$ 是矩阵乘法、输出 $D$ 维"的最小概念）。投影后的 $x_p^i E\in\mathbb{R}^{D}$ 是一个 patch token。

    第三步 Class token prepend + 位置编码。在 patch 序列最前 prepend 一个可学习向量 $x_{\text{class}}\in\mathbb{R}^{D}$（借鉴 BERT 的 [CLS] token——见下方折叠块）；序列长度从 $N$ 变为 $N+1$。然后加上可学习 1D 绝对位置编码 $E_{\text{pos}}\in\mathbb{R}^{(N+1)\times D}$——注意力本身位置无关（已在 [位置编码](../../wiki/positional-encoding/index.html) 概念页说明），需要外接位置信息让模型知道"哪个 patch 在图像的哪个位置"。

    三步合成公式：

    $$z_0=[x_{\text{class}};\,x_p^1 E;\,x_p^2 E;\,\ldots;\,x_p^N E]+E_{\text{pos}},\qquad E\in\mathbb{R}^{P^2 C\times D},\;E_{\text{pos}}\in\mathbb{R}^{(N+1)\times D}.\quad\text{F1, Dosovitskiy 2021 §3.1 Eq.(1)}$$

    其中 $[;\,]$ 表示沿序列维拼接。$z_0\in\mathbb{R}^{(N+1)\times D}$ 是 Transformer 的输入。

    补充：BERT [CLS] token 的来源与 ViT 的借鉴

    BERT（Devlin et al. 2019）在 NLP 中用 [CLS] token 做句子分类：在句子最前加一个特殊 token，让它经过 Transformer 后承载"整句语义"，最后接分类头。Dosovitskiy 2021 §3.1 直接沿用此设计：$x_{\text{class}}$ 就是 ViT 的 [CLS] token，$z_L^0$（第 $L$ 层输出的第 0 行）是它的最终隐状态。这个借鉴让 ViT 不需要为分类任务设计特殊输出结构——直接复用 BERT 的"class token 做分类"模式。

    补充：为什么选可学习 1D 而非 sin/cos 或 2D 位置编码

    论文 §3.1 选择"learned 1D position embeddings"（可学习 1D 绝对位置编码）。附录 D.4 消融对比 1D vs 2D（保留行/列结构）位置编码，差异不显著；论文选 1D 是因为它最简单、不引入额外空间先验（与 ViT 整体"无归纳偏置"取向一致）。这与 Vaswani 2017 原始 Transformer 的 sin/cos 编码不同——sin/cos 是固定的、不可学习；ViT 让位置编码与 patch 嵌入一起从数据学。家族完整对比见 [位置编码](../../wiki/positional-encoding/index.html) 概念页。

    补充：class token vs GAP（全局平均池化）的消融

    附录 D.3 给出消融：在 JFT-300M 预训练下，用 GAP（对所有 patch token 的输出取平均做分类头输入）与 class token 性能相近。论文主线使用 class token 是因为：(1) 继承 BERT 的设计模式；(2) 让 Transformer 内部把"全局信息"显式聚合到一个位置（class token 通过注意力与所有 patch 交互）。GAP 是替代方案而非默认方案；后续一些模型（如 DeiT 部分变体）改用 GAP。

    把流程画出来：

    图像 x ∈ R^(H×W×C)
   │
   ▼ 切成 N=HW/P² 个 P×P×C patch
patch_1, patch_2, ..., patch_N    （每个展平为 P²·C 维向量 x_p^i）
   │
   ▼ 线性投影 x_p^i · E   (E ∈ R^(P²C × D))
token_1, token_2, ..., token_N    （每个 D 维 patch token）
   │
   ▼ prepend class token x_class ∈ R^D
[x_class; token_1; ...; token_N]   （序列长度 N+1）
   │
   ▼ + E_pos   (E_pos ∈ R^((N+1) × D))
z_0 ∈ R^((N+1) × D)                ← Transformer 输入

    手算例子（教学示例）。$H=W=224$、$P=16$、$C=3$（标准 ImageNet RGB 图像 + ViT 主线 patch 大小）：

    • $N=HW/P^2=224\times 224/16^2=50176/256=196$ 个 patch；
    • 加 class token 得 $N+1=197$ 个 token；
    • ViT-B/16 配置下 $D=768$，故 $z_0\in\mathbb{R}^{197\times 768}$。

    Patch 大小 $P$ 的影响。$P$ 越小 token 越多、计算越大、精度上限越高：$P=32$ 时 $N=49$；$P=14$ 时 $N=256$。论文 Table 1 同时给出 ViT-H/14 配置（patch 14），主要因为 Huge 模型用更细粒度 patch 配合更大模型容量。

    常见误解。 Patch 不是 token——patch 是图像预处理产物（切成方块的展平向量），token 化的真正机制是后面的线性投影 $E$。把 "patch" 与 "token" 混用会让人误以为"patch = token"是 ViT 特有的概念；实际上任何序列输入（文本词向量、音频片段）都可以是 token，ViT 的特殊之处是用"patch + 线性投影"作 tokenization 让 Transformer 不需要任何架构改动。

    $z_0$ 全有了，下一步该 Transformer 编码了。下一章看编码块 $z_\ell', z_\ell$ 与分类头 $y$。

    Transformer 编码块——与标准 Transformer 几乎完全一致

    ViT 把 $z_0$ 喂给 $L$ 层编码块，每层接收 $z_{\ell-1}\in\mathbb{R}^{(N+1)\times D}$ 输出 $z_\ell\in\mathbb{R}^{(N+1)\times D}$。每层内部含两个子层——多头自注意力（MSA）+ 前馈网络（MLP），每个子层前用 LayerNorm、后用残差连接（已在 [残差连接](../../wiki/residual-connection/index.html) 概念页给出 $y=F(x)+x$ 的机制）。

    $$z_\ell'=\text{MSA}(\text{LN}(z_{\ell-1}))+z_{\ell-1},\qquad \ell=1\ldots L.\quad\text{F2, Dosovitskiy 2021 §3.1 Eq.(2)}$$

    $$z_\ell=\text{MLP}(\text{LN}(z_\ell'))+z_\ell',\qquad \ell=1\ldots L.\quad\text{F3, Dosovitskiy 2021 §3.1 Eq.(3)}$$

    $L$ 层后取 class token 对应位置 $z_L^0$，经 LayerNorm 得到图像表示 $y$：

    $$y=\text{LN}(z_L^0).\quad\text{F4, Dosovitskiy 2021 §3.1 Eq.(4)}$$

    逐项解释：

    • $\text{LN}$（LayerNorm）：把每行特征归一化到均值 0、方差 1（概念页 LayerNorm 待生成，这里只需"沿特征维归一化"的最小概念）。ViT 用 pre-LN——LN 在子层前应用，与 Vaswani 2017 原始 Transformer 的 post-LN（LN 在子层后）不同（见下方折叠块）。
    • $\text{MSA}$（多头自注意力）：内部公式 $\text{softmax}(QK^\top/\sqrt{d_k})V$ 与 [标准注意力](../../wiki/standard-attention/index.html) 概念页完全一致；多头拼接机制也与该页 §4 一致。区别只在 $Q,K,V$ 的来源——NLP 是词嵌入的线性投影，ViT 是 patch 嵌入 $z_{\ell-1}$ 的线性投影。
    • $\text{MLP}$（前馈网络）：两层 + GELU 非线性（概念页 GELU 待生成，这里只需"GELU 是平滑的 ReLU 变体"的最小概念）。中间层维度由配置表的 MLP size 给出（ViT-B 为 3072）。
    • 残差连接：两个子层后都加上输入（$+z_{\ell-1}$ 与 $+z_\ell'$），让深网络训练稳定——已在 [残差连接](../../wiki/residual-connection/index.html) 概念页说明。
    • $z_L^0$：第 $L$ 层输出 $z_L\in\mathbb{R}^{(N+1)\times D}$ 的第 0 行（class token 对应位置）。预训练时分类头接在 $z_L^0$ 后是一个 MLP（含一个隐藏层 + GELU），微调时简化为单线性层。
    补充：pre-LN 与 post-LN 的训练稳定性差异

    Vaswani 2017 原始 Transformer 用 post-LN（LN 在子层后，残差在 LN 前）；ViT 用 pre-LN（LN 在子层前，残差在 LN 后）。Xiong et al. 2020（arXiv:2002.04745）指出 pre-LN 让残差路径上没有 LN 阻塞，梯度沿残差路径更顺畅，深网络训练更稳定——这是 ViT 选 pre-LN 的工程动机。本页只一句话提及，不展开稳定性推导。MoonViT-V2 等后续变体用 RMSNorm 进一步替换 LN，但整体 pre-LN 结构不变。

    与标准 Transformer 的三处差异。除 pre-LN 外，ViT 还有两处可核对差异：

    项Vaswani 2017 原始 TransformerViT
    归一化位置post-LN（LN 在子层后）pre-LN（LN 在子层前）
    编码-解码结构encoder + decoder（含交叉注意力子层）encoder-only（无 decoder、无交叉注意力）
    $Q,K,V$ 来源词嵌入的线性投影patch 嵌入 $z_{\ell-1}$ 的线性投影

    除这三处外，MSA、MLP、残差、LayerNorm 都是 Transformer 的标准件——ViT 不是新架构，而是输入端改造。

    关键结论。 ViT 的真正贡献在 S2 的 tokenization（patch embedding + class token + 1D 位置编码），不在编码块本身。理解了 [标准注意力](../../wiki/standard-attention/index.html) 的多头公式，就理解了 ViT 编码块的 MSA；理解了 [残差连接](../../wiki/residual-connection/index.html)，就理解了 ViT 的 $+z_{\ell-1}$ 与 $+z_\ell'$。这是 MoonViT-V2 能用 RMSNorm 替换 LN、去 bias 仍保持整体结构的前提。

    数据规模边界——什么时候 ViT 比 CNN 强、什么时候反而更弱

    ViT 的精度高度依赖预训练数据规模。Dosovitskiy 2021 §4.1 用三个数据集做预训练：

    数据集图像数类别数可用性
    ImageNet-1k（ILSVRC-2012）1.3M1k公开
    ImageNet-21k14M21k公开
    JFT-300M300M18kGoogle 私有

    来源：Dosovitskiy 2021 §4.1。JFT-300M 是论文大数据预训练来源；ImageNet-21k 是公开可用的中等规模替代。

    小数据从零训练的边界。§4.3 报告：在 ImageNet-1k（1.3M 图）上从零训练 ViT 不如 ResNet——缺乏 CNN 的局部先验、欠拟合。这是后续 DeiT 等工作（更强 augmentation + 蒸馏）要解决的问题，本页只一句话提及。

    大数据预训练 + 微调的优势。§4.2 Table 2 给出 ImageNet top-1 微调精度与预训练计算量（TPUv3-core-days）：

    模型预训练数据ImageNet top-1 (%)TPUv3-core-days
    ViT-L/16ImageNet-21k85.30 ± 0.020.23k
    ViT-L/16JFT-300M87.76 ± 0.030.68k
    ViT-H/14JFT-300M88.55 ± 0.042.5k
    BiT-L（ResNet152x4）JFT-300M87.54 ± 0.029.9k
    Noisy Student（EfficientNet-L2）ImageNet + JFT88.4–88.512.3k

    来源：Dosovitskiy 2021 Table 2（§4.2）。TPUv3-core-days = 1 个 TPUv3 核训练 1 天的计算量。± 数字为多次运行的标准差。

    读出两点：

    • 精度：ViT-L/16 (JFT) 87.76% 与 ViT-H/14 88.55% 都超过 BiT-L（ResNet152x4 + JFT 预训练）的 87.54%；ViT-H/14 与 Noisy Student（88.4–88.5%）相当。
    • 计算量：ViT-H/14 用 2.5k TPUv3-core-days，是 BiT-L 的 9.9k 的约 1/4、Noisy Student 的 12.3k 的约 1/5。用更少计算达到更高精度——这是大数据下"无归纳偏置"反而成为优势的实证。

    核心结论（Dosovitskiy 2021 §1 原文）："large scale training trumps inductive bias"——大规模训练胜过归纳偏置。在 JFT-300M 量级数据下，ViT 主动去除空间先验让模型从数据学，反而比 CNN 的局部卷积 + 平移不变先验达到更高精度，且训练计算更少。这是后续 ViT 家族（DeiT、Swin、BEiT、MAE、DINOv2、MoonViT-V2）的共同前提。

    适用边界。该结论的成立条件与不成立场景：

    场景ViT 相对 CNN 表现原因
    小数据从零训练（ImageNet-1k 量级）不如 CNN缺乏局部先验、欠拟合
    大数据预训练 + 微调（JFT-300M 量级）超过 CNN无归纳偏置限制、从数据学长程关系
    检测/分割下游任务需 task-specific headViT 本身只做编码，DETR/Mask2Former 等需加专用头
    视频时序建模原始 ViT 不支持原始 ViT 只处理单帧；MoonViT-V2 等变体才扩展到视频
    多模态对齐需对比损失目标CLIP/SigLIP 用对比损失对齐图文嵌入，ViT 仅作视觉 backbone

    常见误解。 ViT 在 ImageNet 上 88.55% 超过 ResNet 不等于"ViT 普遍比 CNN 强"。88.55% 是 ViT-H/14 在 JFT-300M（300M 图）预训练后的微调结果；脱离预训练数据规模谈架构优劣是误读。论文 §4.3 明确报告小数据下 ViT 不如 ResNet——这是 DeiT 等后续工作要解决的问题。

    ViT 家族变体一句话提及。后续工作在 ViT 基础上改动训练目标、注意力模式或归一化方式，但 patch 化 + Transformer 编码的整体框架不变：

    • DeiT：蒸馏 + 数据增强，解决小数据训练问题；
    • Swin Transformer：层级窗口注意力，重新引入 CNN 风格的局部归纳偏置；
    • BEiT / MAE：掩码图像建模自监督预训练，不再依赖标签数据；
    • DINOv2：自监督训练 + 大数据，无需微调即可迁移；
    • MoonViT-V2：K3 的视觉编码器（27 层、从零训练、RMSNorm、去 bias、视频分解注意力），已有概念页 [MoonViT-V2](../../wiki/moonvit-v2/index.html)。

    224×224 + patch 16 → 196 token / 197 序列长度手算：构造目的——把 $N=HW/P^2$ 落到论文主线配置的可复算数字；非论文一手数据，但使用论文标准配置（$H=W=224$、$P=16$、$C=3$、ViT-B $D=768$）。

    ViT-B/12/16 每头维度 $d_k=64$ 手算：构造目的——把 $d_k=D/h$ 落到论文 Table 1 的 ViT-B 数字（$D=768$、$h=12$）；与 [标准注意力](../../wiki/standard-attention/index.html) 概念页的 $d_k=64$ 一致。

    形状对照表：构造目的——把 $x, x_p^i, E, x_p^i E, x_{\text{class}}, E_{\text{pos}}, z_0$ 的形状在 224×224 patch 16 ViT-B 配置下可视化；其中 $P^2 C=768$ 恰好等于 $D=768$ 是 ViT-B/16 的巧合（不是必须），其他配置（如 ViT-L/16 $D=1024$）不满足这一巧合。

    教学解释与类比边界

    "归纳偏置 = 架构给数据预先设定的规则"类比（S1 callout）：服务"为什么大数据下无归纳偏置反而成为优势"的局部关系。失效边界——它不意味着"无归纳偏置总是更好"（小数据下无先验会让模型欠拟合）；也不覆盖"不同任务下不同归纳偏置的相对优势"。正式判断以 §4 数据规模边界为准。

    "ViT 把图像变成与文本 token 同构的 patch 序列"对应关系（S1 末段）：服务"ViT 能直接复用 NLP 已验证可扩展性"的局部关系。失效边界——文本 token 是离散词向量、图像 token 是连续 patch 投影，二者统计性质不同；ViT 的可扩展性在论文 §4.2 实证支持，但不保证所有视觉任务下都比 CNN 好。

    教学简化及其限制

    简化一：CNN 归纳偏置只取 locality + translation invariance 两个。省略了更细的归纳偏置（如层级结构、池化等变性）。成立条件——本文只需要"小数据下有效、大数据下成为限制"这一对照；不影响的结论——ViT 数据规模边界的核心判断仍以 §4 实验为准。

    简化二：MSA 内部公式直接引用 standard-attention 概念页。省略了缩放因子 $\sqrt{d_k}$ 的方差推导与多头拼接的参数量等价证明（已在 [标准注意力](../../wiki/standard-attention/index.html) 给出）。成立条件——读者已读或可读该概念页；不影响的结论——ViT 编码块机制本身无需重新推导 MSA。

    简化三：只引用 ImageNet top-1 精度与 TPUv3-core-days。省略了 ImageNet ReaL、CIFAR-10/100、Oxford-IIIT Pets、Oxford Flowers-102、VTAB 等多数据集结果。成立条件——ImageNet top-1 是论文核心结论的代表数字；不影响的结论——"大数据下 ViT 超越 CNN"在所有大数据集结果上一致，本页结论不依赖单一数据集。

    简化四：变体家族（DeiT/Swin/BEiT/MAE/DINOv2/MoonViT-V2）只一句话提及。省略各变体机制。成立条件——本文是这些变体的前置概念，不展开变体机制；不影响的结论——本文核心论断不依赖变体细节，MoonViT-V2 已有独立概念页可链接。
