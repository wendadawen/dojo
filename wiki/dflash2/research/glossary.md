# DFlash 2 术语表

| 术语/符号 | 首次出现 | 含义 |
|---|---|---|
| DFlash | 开头 | 第一代块扩散草稿器框架（Z Lab 论文，ICML 2026），本页的基础 |
| DFlash 2 | 开头 | Inco AI 2026-08-18 发布的第二代草稿器（本页主题） |
| 草稿器（drafter） | 开头 | 投机解码中负责并行猜 token 的小模型 |
| 目标模型（target） | 开头 | 验证草稿的大模型 |
| 路径选择器（path selector） | 第 1 章 | 从每位置 top 候选中串出一条连贯路径的轻量模块 |
| 候选（candidate） | 第 1 章 | 每个位置保留下来的多个可能 token（top-16） |
| Recall@1 / Recall@16 | 第 1 章 | top-1 命中率 / 正确 token 出现在 top-16 内的比率（条件于前文全对） |
| oracle | 第 1 章 | 假想的完美选择器：总能从 top-16 里选对 |
| 接受长度（acceptance length） | 第 1 章 | 每轮验证平均接受的 token 数（含 bonus token），per-request 口径 |
| 后缀衰减（suffix decay） | 第 1 章 | 块内越靠后的位置预测准确率越低的现象 |
| 骨干（backbone） | 第 1 章 | 草稿模型的 transformer 主体（区别于外挂模块） |
| $S_t(a,b)$ | 第 2 章 | 相邻候选对的路径分数 |
| $U_t(b)$ | 第 2 章 | DFlash 自身对候选 $b$ 的 logit（单项分） |
| $A(\cdot),B(\cdot)$ | 第 2 章 | 每个 token 的 256 维紧凑嵌入（前驱侧/当前侧） |
| $H(h_t)$ | 第 2 章 | 上下文门：决定嵌入匹配的哪些维度计入分数 |
| 低秩双线性注意力 | 第 2 章 | 对 $S_t$ 第二项的形式描述（嵌入维 256 远小于隐状态维） |
| 贪心走路径 | 第 2 章 | 从最后已验证 token 出发、每步取最高分后继的遍历 |
| 拒绝采样 | 第 2 章 | 修正草稿分布使采样输出与 target 分布一致的机制 |
| DSpark 修正头 | 第 2 章 | 相邻路线：串行改写各位置全词表分布的模块（对比项，+77.8M 参数） |
| Domino | 第 2 章 | 与 DSpark 同路线的串行修正方法（提及） |
| 两抽头动态深度卷积 | 第 3 章 | 只含「当前位+前一位」两个抽头、系数随内容变化的逐通道卷积 |
| $\operatorname{Conv}_k(x)_t$ | 第 3 章 | 卷积输出：$k_{t,0}\odot x_t+k_{t,1}\odot x_{t-1}$ |
| $k_{t,0},k_{t,1}$ | 第 3 章 | 动态卷积系数：学习基核 + 隐状态小修正（每 16 通道共享一个修正） |
| 块内注意力份额 | 第 3 章 | attention 分给块内 token 的注意力比例 |
| attention/FFN 子层 | 第 3 章 | transformer 层内的两个子模块（卷积插在其前后） |
| MTP | 第 4 章 | 目标模型原生的 multi-token prediction 路径（对比基准） |
| thinking 模式 | 第 4 章 | 模型输出长推理链的模式（Qwen3.5-4B 实验条件之一） |
| 无损（lossless） | 第 1 章 | greedy 输出与 target 逐字节一致、采样保分布 |
| 循环延迟（cycle latency） | 第 2 章 | 一个 draft-verify 周期的耗时（开销百分比的分母） |
| PR 分支 | 第 5 章 | 尚未合入稳定版本的引擎集成分支 |
