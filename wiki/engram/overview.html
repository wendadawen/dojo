Engram

Engram 是给大语言模型加的条件记忆模块：用最近几个 token 的哈希去查一张大嵌入表，取回静态向量，经门控后加回隐藏状态。

一张按 N-gram 查的大表

Engram 是一种条件记忆模块。它给大语言模型外挂一张嵌入表，表里每一行是一个可训练的向量，地址由位置 $t$ 前面几个 token 的 ID 算哈希得到：$N$-gram 指连续 $N$ 个 token 组成的片段，以 $t$ 结尾的那一段就叫后缀 $N$-gram。叫「条件」是因为哪几行被取用由当前位置的局部 token 决定，而不是每行都参与计算。取回的向量不随上下文变化，经一个门控后加回这一层的隐藏状态。它不替换主干里任何一层，只是在一部分层上多接一条支路。

模型在用计算模拟查表

大语言模型的主干是一叠 Transformer 层，每层传给下一层的是隐藏状态。一层里主要有两部分：注意力在位置之间传信息，让每个位置能看到前面位置的内容；前馈层逐个位置各算各的。前馈部分常换成混合专家（MoE）：前馈层变成多个并行的专家子网络，每个 token 只激活其中几个，参数总量因此可以远大于每个 token 用到的计算量。这种结构扩展的是条件计算，模型里只有按单个 token 取行的嵌入表，没有按 $N$-gram 取行的查表操作。于是文本里的实体和固定搭配只能靠计算一点点拼出来：认出「Diana, Princess of Wales」这样一个多 token 实体，要用掉靠前的若干层注意力和前馈网络，逐层把国名、「Princess of Wales」这样的片段拼成一个整体。这些模式本身是静态的，本来可以一次查表取回。

压缩、哈希、门控、预取

  1. 压缩词表：把拼写等价、只是大小写或重音不同的 token 合成同一个 ID。
  2. 多头哈希查表：取以当前位置结尾的后缀 $N$-gram（$N$ 叫阶），每个阶用多个哈希头各算一个地址，每个头是一张独立的表，查到的向量拼成一个记忆向量。
  3. 上下文门控：静态向量会碰撞，也会一词多义，所以按当前隐藏状态算一个 0 到 1 之间的门，乘到记忆向量上，再以残差加回隐藏状态。
  4. 提前预取：地址只由 token 决定，可以在算到这一层之前就把向量取来，与计算重叠，表因此可以放在显存之外。
