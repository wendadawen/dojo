# 量化基础 outline：教学大纲

## 1. 页面开头

钩子：训练一个 7B 模型用 FP16 要 14 GB 显存放权重；若部署到消费级显卡（24 GB 还要装 KV cache、激活），几乎装不下。能不能在精度损失可控的前提下，把每个参数从 16 bit 压到 4 bit？这正是量化要解决的问题。

一句话解释：量化把高精度浮点权重或激活按一组 scale（和可选 zero-point）映射到低精度整数或浮点网格上，让显存和计算按位宽比例下降。

要解决的具体问题：在大模型部署中减小显存占用与计算量，同时把精度损失控制在可用范围内。

学习承诺（读完你能回答）：
1. 量化要解决什么问题、为什么会引入精度损失（Q1）
2. 给定一组浮点权重和位宽，如何用对称均匀量化把它编码成整数并反量化（Q2）
3. 对称与非对称、per-tensor 与 per-channel 与 per-block 的精度-开销差别（Q3）
4. 量化误差的三个来源，离群值为什么会让误差爆炸（Q4）
5. PTQ 与 QAT 的关键差别，MXFP4 这类 block-wise 浮点量化相对定点量化的优势（Q5）

首个具体场景：手算 $[1.2, 3.4, 5.6]$ 的 INT4 对称量化（S2 出现）。

与第一章的过渡：先看清"量化为什么值得做"，再看"它到底怎么把浮点变成整数"。

开头组件：callout（蓝色，量化定义+核心权衡一句话）；context-box（"量化决策四要素"——位宽、对称/非对称、粒度、PTQ/QAT）；learning-goals（5 条）；blockquote.meta（主要依据）。

## 2. 章节设计

### S1：量化要解决什么问题（对应 Q1）

- 主要教学问题：为什么大模型部署需要把权重压到低精度？
- 对应范围：Q1；C1、C4（动机）；N1 压缩比
- 正文要点：
  - 大模型权重以 FP16/BF16 存储，每参数 2 字节；7B 模型约 14 GB（N1）
  - INT8（1 字节）压一半到约 7 GB；INT4（0.5 字节）压到约 3.5 GB；按位宽比例下降（N1）
  - 计算上 INT8/INT4 在专用硬件上吞吐量更高、能耗更低
  - 量化的基本权衡：位宽低则压缩比大但精度损失大；压缩比与精度损失成正比
  - 引出"量化到底怎么把浮点变成整数"——下一章
- 讲解材料及职责：数字例子 N1（压缩比，展示代入）；callout（核心权衡一句话）
- 前置知识安排：浮点数位宽与字节数（一句话提示"每参数字节 = 位宽/8"，不展开）
- 完成检查：
  - 说出 FP16 → INT8 与 FP16 → INT4 的理论压缩比
  - 说明为什么压缩比与精度损失成正比
- 过渡：本章已得"量化值得做"，但没说它具体怎么把一个浮点数变成一个低精度整数。下一章给出最基础的均匀仿射量化公式并手算。

### S2：均匀量化怎么把浮点变成整数（对应 Q2）

- 主要教学问题：给定一组浮点数和位宽，怎么用对称均匀量化编码并反量化？
- 对应范围：Q2；C1、C2；F1、F2；E1 手算
- 正文要点：
  - 先讲仿射量化公式 F1：$x_q = \mathrm{clip}(\mathrm{round}(x/s) + z,\, q_{\min},\, q_{\max})$，$\hat{x} = s\,(x_q - z)$
  - 解释符号 $x, s, z, x_q, q_{\min}, q_{\max}, \hat{x}$；说明 $s$ 决定网格步长、$z$ 使实数 0 精确对应某整数（保留 zero-padding）
  - 对称特例 F2：$z=0$，整数范围 $[-2^{b-1}+1, 2^{b-1}-1]$（INT8 取 $[-127,127]$、INT4 取 $[-7,7]$）；$s = \max(|x|)/(2^{b-1}-1)$；反量化 $\hat{x} = s\,x_q$
  - 用边界验证公式：若 $x=\max(|x|)$ 则 $x/s = 2^{b-1}-1$、$x_q$ 取最大正等级；若 $x=0$ 则 $x_q=0$、$\hat{x}=0$
  - 贯穿手算 E1：$[1.2, 3.4, 5.6]$ 的 INT4 对称量化
  - $s = 5.6/7 = 0.8$；$x/s = [1.5, 4.25, 7.0]$；$\mathrm{round} = [2, 4, 7]$（1.5 按四舍五入取 2）；$\hat{x} = s\cdot x_q = [1.6, 3.2, 5.6]$；误差 $= \hat{x} - x = [0.4, -0.2, 0]$
  - 把数字结果翻译成机制结论：每个真实值被舍到最近的 4-bit 等级，误差不超过 $s/2 = 0.4$
- 讲解材料及职责：公式 F1、F2（变量关系）；数字例子 E1（手算代入、中间结果、最终结果）；callout（"对称的反量化只需乘法"）
- 前置知识安排：线性层 $y=Wx+b$ 一句话提示"权重是 $W$ 的元素"
- 完成检查：
  - 说出对称量化为何取 $[-127,127]$ 而非 $[-128,127]$
  - 手算 $[2.0, 4.0, 6.0]$ 的 INT4 对称量化（$s=6/7$，$x_q=[2,5,7]$，$\hat{x}\approx[1.71,4.29,6]$）
  - 说出单值最大舍入误差上界
- 过渡：手算看到误差 $[0.4, -0.2, 0]$——误差从哪来、能不能压下去？下一章分解误差来源。

### S3：量化误差从哪来（对应 Q4）

- 主要教学问题：量化误差的三个来源是什么？离群值为什么会让误差爆炸？
- 对应范围：Q4；C5、C6；E2 离群值手算
- 正文要点：
  - 三来源：
    1. 离散级粗：位宽低则等级少；INT4 对称只有 15 个非零等级（$\pm 1$ 到 $\pm 7$）；相邻可表示值间距为 $s$
    2. 舍入：$\mathrm{round}(x/s)$ 把连续值映射到最近整数，单值最大误差 $\le s/2$
    3. 裁剪：超出 $[\alpha,\beta]$ 的值被 clip 到端点，误差等于超出量
  - 离群值放大：per-tensor 下把 $[1.2, 3.4, 5.6]$ 换成 $[1.2, 3.4, 5.6, 50.0]$
    - $\max(|x|)=50$，$s=50/7\approx7.143$
    - $x/s = [0.168, 0.476, 0.784, 7.0]$
    - $\mathrm{round} = [0, 0, 1, 7]$
    - $\hat{x} = s\cdot x_q = [0, 0, 7.143, 50]$
    - 误差 $= [-1.2, -3.4, +1.543, 0]$；正常值几乎全被舍到 0 或 1
  - 这是 per-channel / per-block 出现的直接动机——把离群值的影响局限在它所在的通道或块内
- 讲解材料及职责：数字例子 E2（控制变量：只加入一个离群值，看其他值的误差如何爆炸）；callout（"per-tensor 的单点故障：一个离群值毒化整张张量"）
- 前置知识安排：无
- 完成检查：
  - 说出三来源各自的名字与一句话定义
  - 解释为什么 $[1.2, 3.4, 5.6, 50.0]$ 的 1.2 被舍到 0
  - 说出单值最大舍入误差上界 $s/2$ 与离群值如何影响 $s$
- 过渡：本章指出"粒度选择直接影响误差"，下一章正式对照不同粒度与对称/非对称。

### S4：对称/非对称 与 量化粒度（对应 Q3）

- 主要教学问题：对称与非对称、per-tensor 与 per-channel 与 per-block 在精度和开销上的差别是什么？
- 对应范围：Q3；C2、C3、C4；F3 非对称公式；C1 对照表
- 正文要点：
  - 对称 vs 非对称：
    - 对称（F2）：$z=0$，反量化 $\hat{x}=s\,x_q$，只需乘法；适合零中心分布（典型为权重）
    - 非对称（F3）：$z\ne0$，反量化 $\hat{x}=s(x_q-z)$，多一次减法；适合偏斜分布（典型为 ReLU 后激活、取值 $[0,\text{max}]$，对称会浪费一半整数等级）
    - 公式给出非对称的 scale 与 zero-point：$s=(\beta-\alpha)/(q_{\max}-q_{\min})$，$z=\mathrm{round}(q_{\min}-\alpha/s)$
  - 量化粒度：
    - per-tensor：一组 $(s,z)$，元数据最少、kernel 最简，单离群值毒化全张量
    - per-channel：每输出通道一组 $(s,z)$，精度更好、元数据量增为通道数，kernel 需按通道处理
    - per-block（per-group）：通道再切固定大小块（如 32、128），每块一组；INT4 主流粒度
    - 有效位宽算法：INT4 + per-block（块 32） + 8-bit scale ≈ $4 + 8/32 = 4.25$ bit/元素
  - 选择规则：权重常取对称 + per-channel 或 per-block；激活常取非对称 + per-tensor 或 per-token
- 讲解材料及职责：公式 F3（非对称 scale/zero-point）；对照表 C1（对称/非对称 + per-tensor/channel/block 双维度）；callout（"粒度必须与位宽一起声明"）
- 前置知识安排：ReLU 激活函数一句话提示"ReLU 把负值置零，所以输出非负"，不展开
- 完成检查：
  - 说出对称量化的反量化只需乘法、非对称多一次减法
  - 说出 per-tensor 在哪种数据分布下精度最差
  - 说出 INT4 + per-block(32) 的有效位宽
  - 说出权重和激活通常各选哪种对称性
- 过渡：本章给出"如何选 scale/粒度"以减小误差。但还有一类误差无法靠 scale 选择消除——训练时模型从未见过量化误差。下一章讲 PTQ 与 QAT 的差别。

### S5：PTQ vs QAT 与 浮点 block-wise 量化（对应 Q5）

- 主要教学问题：PTQ 与 QAT 的关键差别？MXFP4 这类 block-wise 浮点量化相对定点量化的优势？
- 对应范围：Q5；C7、C8、C9；F4 STE；C2 对照表；对 `mxfp4-qat` 的引用
- 正文要点：
  - PTQ（C7）：训练全程用高精度权重；训练结束用少量校准数据（128–512 样本，N3）统计激活范围、确定 $(s,z)$；权重量化后部署；无需重训、分钟到小时级；低位宽精度下降显著
  - QAT（C8）：
    - 前向伪量化：先把权重 $w$ 量化再反量化得 $\hat{w}$，用 $\hat{w}$ 算前向与损失；模型每个前向都见到量化偏差
    - 反向 STE（F4）：令 $\partial\hat{w}/\partial w \equiv 1$，让梯度绕过不可导的 round/clip 直传到 $w$；梯度更新发生在原始高精度权重上
    - 模型权重朝"在低精度下仍能减小损失"的方向调整，补偿（部分）精度损失
    - 代价是要重训
  - PTQ vs QAT 对照表 C2：训练成本、精度、适用位宽、典型场景
  - block-wise 浮点量化（MXFP4，C9）：
    - 把每 32 个连续值组成一块，块共享一个 8-bit E8M0 power-of-two scale（$s_b=2^{e_b}$），每个元素存 4-bit E2M1 浮点
    - 反量化 $\hat{x}_i = s_b \cdot \mathrm{FP4}(q_i)$
    - 相对定点 INT4 的优势：元素有独立指数位（块内动态范围更宽），per-block scale 抑制离群值污染（与 S3 的离群值问题闭环）
    - 完整 QAT 细节见 [MXFP4 量化感知训练](../mxfp4-qat/index.html)
  - 教学解释：把 STE 比作"透明的窗户"——梯度穿过它看见的就是高精度 $w$；类比只解释 STE 的"导数当作 1"这一点，不覆盖 STE 的其它变体（如 LSQ）
- 讲解材料及职责：对照表 C2（PTQ vs QAT 双维度）；公式 F4（STE 约束）；伪代码（伪量化前向 + STE 反向的最小流程）；callout（"QAT 不恢复精度，只补偿"）
- 前置知识安排：反向传播与梯度下降一句话提示"训练按梯度更新参数"
- 完成检查：
  - 说出 PTQ 与 QAT 各自的训练成本与精度特点
  - 说出 STE 在反向做了什么、为什么需要它
  - 说出 MXFP4 的块大小、scale 类型、元素格式
  - 说出 MXFP4 元素相对定点整数的两点优势
- 过渡：本章是收束——把前四章的 scale、粒度、误差、训练方式四组选择汇成一张"量化决策表"。文末给出完整来源与教学说明。

## 4. 贯穿例子

主线：$[1.2, 3.4, 5.6]$ 的 INT4 对称量化。
- S2 首次出现：完整手算（$s=0.8$，$x_q=[2,4,7]$，$\hat{x}=[1.6,3.2,5.6]$，误差 $[0.4,-0.2,0]$）
- S3 复用并加入离群值：$[1.2, 3.4, 5.6, 50.0]$，看正常值误差爆炸（$s\approx7.143$，$x_q=[0,0,1,7]$，$\hat{x}\approx[0,0,7.14,50]$，误差 $[-1.2,-3.4,+1.54,0]$）
- S4 复用对照：per-tensor 单 scale（已被离群值主导）vs 把 $[1.2,3.4,5.6]$ 与 $[50.0]$ 分两块各算 scale，正常块的 $s$ 不被毒化
- S5 复用：单权重 $w=0.8$ 在 QAT 前向被伪量化为 $\hat{w}=0.75$（INT4 对称 $s=0.25$ 时 E2M1 取 0.75 这个等级）——这是教学简化，不深入 MXFP4，因为完整 QAT 在 `mxfp4-qat` 页

固定输入：$[1.2, 3.4, 5.6]$、INT4 对称、$s=0.8$。每次复用增加一个新层次（误差 / 离群值 / 粒度 / 训练方式）。

## 5. 讲解材料职责

- 公式 F1、F2、F3、F4：表达变量关系；首次出现处定义每个符号、范围与运算
- 数字例子 E1（$[1.2,3.4,5.6]$ INT4 对称）：展示代入、中间结果、最终结果，验证公式
- 数字例子 E2（$[1.2,3.4,5.6,50.0]$ per-tensor）：控制变量，看离群值如何放大误差
- 对照表 C1（对称/非对称 × 粒度）：并排对照选择维度
- 对照表 C2（PTQ vs QAT）：并排对照训练方式
- 伪代码（QAT 前向 + STE 反向）：展示输入、状态、核心步骤、输出
- 可运行代码（per-tensor 对称 INT4 量化 $[1.2,3.4,5.6]$ 与离群值版本对比）：验证机制可执行
- ASCII 图示（仿射量化的"浮点网格 → 整数网格"映射）：展示网格结构与 clip/round 位置
- callout（核心权衡、对称反量化只需乘法、离群值毒化、QAT 不恢复精度）：突出关键结论
- 教学解释（STE 类比"透明窗户"、量化网格类比"刻度尺"）：标明职责与边界
