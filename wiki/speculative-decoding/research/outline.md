# 投机解码 · 教学大纲

## 1. 页面开头

- 钩子问题：让 70B 模型生成 100 个 token，为什么必须串行调用 100 次大模型？每次调用要把全部 140GB 权重从显存读一遍、却只用它算 1 个 token 的概率——剩下的算力白白空转。能不能把这些空转的算力用来「猜」未来几个 token、再让大模型一次核对？
- 一句话解释：投机解码用小 draft 模型快速猜若干个候选 token，大 target 模型一次性并行验证，按修改版拒绝采样规则接受匹配的、修正不匹配的，从而在不改变输出分布的前提下减少大模型的串行调用次数。
- 解决的具体问题：自回归解码串行慢；内存带宽受限使「算 1 个」和「算 $\gamma+1$ 个」墙钟时间几乎相同，但缺少「值得算的 $\gamma$ 个 token」。
- 学习承诺：读完能回答 Q1-Q5（见 learning-goals）。
- 首个具体场景：贯穿例子——3 个 token 的 draft，覆盖接受、拒绝、残差重采样、bonus 四种情况。
- 过渡：先讲为什么「猜-核」可行（硬件前提），再讲怎么猜、怎么核（机制），最后讲为什么这样核能保分布（数学）。

## 2. 章节设计

### S1：为什么串行解码慢——内存带宽留下的「免费午餐」

- 主要教学问题：自回归解码慢在哪里，为什么「并行验证多个 token」几乎不增加成本？
- 对应范围：Q1、C2。
- 正文要点：
  - 自回归解码：每次用一个 token 喂回模型得到下一个 token 的分布，KV cache 让历史 token 不必重复计算，但权重仍需每步重新读取。
  - 单 token 前向传播的瓶颈是 HBM→SM 的权重读取（如 70B 模型约 140GB 权重，HBM 带宽 3.35 TB/s，理论下限约 42ms/token）；算术运算量相对很低，计算单元大量空闲。
  - 关键观察（C2）：同一个前向传播，只要把输入序列延长 $\gamma$ 个位置，就在几乎相同的墙钟时间内得到 $\gamma+1$ 个位置上的分布——额外的算术落在空闲计算单元上，几乎不增加时间。
  - 由此引出「猜-核」框架的硬件前提：单流低负载下，「生成 1 个」与「验证 $\gamma+1$ 个」成本相近。
- 讲解材料：
  - 数字例子（N3 衍生）：70B 模型权重 140GB、HBM 3.35 TB/s、单步理论下限（教学计算，非实测）。
  - ASCII 图示（材料 13）：单 token 解码 vs $\gamma+1$ token 验证的墙钟时间对照。
- 前置知识：[gpu-execution-model](../../wiki/gpu-execution-model/index.html)（HBM 带宽、SM 计算单元），[standard-attention](../../wiki/standard-attention/index.html)（因果注意力一次前向可出每位置分布）。自回归解码与 KV cache 用最小衔接句内联（前置无概念页）。
- 完成检查：
  - 用一句话说出为什么单 token 解码是带宽受限而非计算受限。
  - 说出「验证 $\gamma$ 个 token」与「生成 1 个 token」墙钟时间为何相近的硬件原因。
  - 说出本结论在什么负载条件下不成立。
- 过渡：硬件允许我们「免费」核 $\gamma$ 个 token——但核什么？哪里来值得核的 $\gamma$ 个 token？下一章讲 draft 模型如何提供候选。

### S2：Draft-then-Verify——一轮做了什么

- 主要教学问题：Draft-then-Verify 一轮做了什么，每个 token 在什么条件下被接受或拒绝？
- 对应范围：Q2、C3、C4、C5、C6、F1、F2。
- 正文要点：
  - 一轮的输入：当前前缀、draft 模型 $q$、target 模型 $p$、草稿长度 $\gamma$。
  - 步骤 1（Draft）：draft 自回归采样 $\gamma$ 个 token $x_1,\dots,x_\gamma$，保留每步分布 $q_1,\dots,q_\gamma$。
  - 步骤 2（Verify）：target 对前缀 + $\gamma$ 个 draft token 做单次前向，得到 $p_1,\dots,p_{\gamma+1}$。
  - 步骤 3（接受/拒绝）：对 $i=1,\dots,\gamma$ 逐位计算 $a_i = \min(1, p_i(x_i)/q_i(x_i))$，以概率 $a_i$ 接受。
    - 边界：$p\geq q$ 必接受（$a=1$）；$p<q$ 以比值 $p/q$ 概率接受；$p=0$ 必拒绝（$a=0$）。
  - 步骤 4（首个拒绝处）：从残差 $p'_i = \mathrm{norm}(\max(0, p_i - q_i))$ 重采样一个 token，丢弃其后所有 draft token，结束本轮。
  - 步骤 5（Bonus）：若 $\gamma$ 个全接受，从 $p_{\gamma+1}$ 免费采样一个 bonus token。
  - 一轮产出：1 到 $\gamma+1$ 个 token；最差情况（首轮即拒）仍产出 1 个（重采样 token），不劣于纯解码。
- 讲解材料：
  - ASCII 图示（材料 13）：一轮的五个步骤与时序。
  - 伪代码折叠块（材料 11）：把五步形式化，便于后续对照公式与代码。
  - 对照表格（材料 14）：接受/拒绝/bonus 四种位置结果的输入、动作、产出对照。
- 前置知识：standard-attention（因果注意力使各位置分布独立）。
- 完成检查：
  - 说出 $\gamma$ 个 draft token 是怎么来的、为什么 target 只需要一次前向传播。
  - 给定 $p(x)=0.4, q(x)=0.5$，算出 $a(x)$ 并说出是必接受还是概率接受。
  - 说出残差分布在什么条件下才会被触发。
  - 说出 bonus token 在什么条件下产生、为什么是「免费」的。
- 过渡：机制讲完了——但为什么接受概率要写成 $\min(1, p/q)$？为什么拒绝后要从 $\max(0, p-q)$ 重采样而不是直接从 $p$？这些选择不是任意调参，下一章证明它们组合起来恰好让输出分布回到 $p$。

### S3：为什么这条规则能保分布——单位置证明

- 主要教学问题：为什么这个接受/拒绝规则能保证输出分布与纯 target 采样完全相同？
- 对应范围：Q3、F3、F4、C7（贪心退化铺垫）。
- 正文要点：
  - 把单位置上「最终被采出 $x$」拆成两条互斥路径：
    - 路径 A：draft 采样到 $x$ 且被接受。
    - 路径 B：某个 token 被拒（不一定是 $x$），从残差重采样到 $x$。
  - 路径 A 概率：$q(x)\cdot\min(1, p(x)/q(x)) = \min(q(x), p(x))$。
  - 路径 B 概率：拒绝概率 $\beta = 1 - \sum_{x'}\min(q(x'),p(x'))$，乘以残差条件概率 $p'(x) = \max(0, p(x)-q(x))/\beta$，得 $\max(0, p(x)-q(x))$。
    - 关键恒等式：$\sum_{x'}\max(0, p(x')-q(x')) = 1 - \sum_{x'}\min(p(x'),q(x')) = \beta$，故残差归一化常数恰好等于拒绝概率。
  - 总和：$\min(q(x),p(x)) + \max(0, p(x)-q(x)) = p(x)$（恒等式 $\min(a,b)+\max(0,b-a)=b$）。
  - 接受率与 TV 距离（F4）：$\alpha = \sum_x \min(p,q) = 1 - \mathrm{TV}(p,q)$，说明 $\alpha$ 是分布相似度的度量——draft 越像 target、$\alpha$ 越高。
  - 贪心退化（C7，铺垫 Q5）：若 $p,q$ 退化为点质量（argmax），$\min(1, p/q)$ 退化为 argmax 是否相同的二元判断。
- 讲解材料：
  - 公式（材料 A2）：F1、F2、F3、F4 各配一次「公式 + 符号定义 + 边界检查」。
  - 推导折叠块（材料 09）：F3 的完整五步推导（路径 A、拒绝概率、归一化常数、路径 B、总和），正文只给结论与恒等式提示。
  - 对照表格（材料 14）：单位置上「路径 A vs 路径 B」的概率贡献分解（教学示例数字）。
- 前置知识：拒绝采样用最小衔接句内联（约 2 句：「从 $q$ 采样、以 $\min(1,p/q)$ 接受是经典拒绝采样；残差重采样是投机解码的修改——经典拒绝采样重采样时直接从 $p$ 来，但这里因为接受步骤已经偏置了分布，必须用残差修正。」）。
- 完成检查：
  - 写出单位置 $\Pr[\text{emit }x]$ 的两项分解。
  - 说出残差分布归一化常数为什么恰好等于拒绝概率。
  - 说出 $\alpha$ 与 $\mathrm{TV}(p,q)$ 的关系，并据此判断「draft 越像 target」时 $\alpha$ 如何变化。
  - 说出贪心情形下规则如何退化。
- 过渡：现在我们相信规则保分布——那么实际跑起来能快多少？这取决于接受率和草稿长度，下一章用期望 token 数和加速比公式量化。

### S4：能快多少——期望 token 数与加速比

- 主要教学问题：接受率 $\alpha$ 和草稿长度 $\gamma$ 如何决定加速比，什么时候反而更慢？
- 对应范围：Q4、F5、F6、N1、N2、N3、N4、M2、M4。
- 正文要点：
  - 接受率 $\alpha$：单位置平均接受概率，$\alpha = \sum_x\min(p,q)$（F4）。
  - 期望 token 数（F5）：$\mathbb{E}[L] = (1 - \alpha^{\gamma+1})/(1 - \alpha)$，截断几何级数；边界 $\alpha=1\Rightarrow\gamma+1$、$\alpha=0\Rightarrow 1$。
  - 加速比（F6）：$S = (1-\alpha^{\gamma+1})/[(1-\alpha)(1+\gamma c)]$，$c = T_{\text{draft}}/T_{\text{target}}$。
  - 复算 Leviathan 数字（N1、N3）：$\alpha=0.8, \gamma=5, c=0.05 \Rightarrow \mathbb{E}[L]\approx 3.69, S\approx 2.95\times$，与原文「2-3×」一致。
  - 复算 Chen 数字（N2）：Chinchilla 70B 分布式部署 2-2.5×，不展开拓扑。
  - 退化条件：
    - $\alpha$ 太低（如 $\alpha=0.2, \gamma=5, c=0.05 \Rightarrow S\approx 1.04$，几乎不加速）。
    - $c$ 太大（draft 接近 target 规模，$c\to 1$）。
    - 高负载批处理（M4，N4）：vLLM 高查询率下 1.4-1.8× 减速，因为「空闲算力」消失、验证位置挤占他人算力。
  - $\gamma$ 的最优值：$\alpha^k$ 衰减 vs $\gamma c$ 线性增长，存在最优 $\gamma$（如 $\alpha=0.8, c=0.05$ 时最优 $\gamma\approx 8$）。
- 讲解材料：
  - 数字例子折叠块（材料 10）：$\alpha=0.8, \gamma=5, c=0.05$ 完整手算 $\mathbb{E}[L]$ 与 $S$；$\alpha=0.2$ 的反例手算。
  - 对照表格（材料 14）：不同 $\alpha$ 与 $\gamma$ 下的 $\mathbb{E}[L]$ 与 $S$（教学示例，固定 $c=0.05$）。
- 前置知识：无新前置。
- 完成检查：
  - 写出 $\mathbb{E}[L]$ 与 $S$ 的公式，并解释每个符号。
  - 给定 $\alpha=0.7, \gamma=4, c=0.1$，手算 $S$。
  - 说出三种使 $S<1$ 或减速的条件。
  - 说出 $\gamma$ 是否越大越好、为什么。
- 过渡：现在我们知道何时加速、何时不加速——但所有这些数字都假设「接受率 $\alpha$ 是个已知量」。最后一章用贯穿例子把整条机制跑一遍，让抽象的 $\alpha$、$p$、$q$ 落到具体数字上。

### S5：把机制跑一遍——3 个 token 的手算例子

- 主要教学问题：给定具体的 $p$、$q$ 与 3 个 draft token，把接受/拒绝/残差/bonus 全流程手算一遍，验证 $\mathbb{E}[L]$ 与 $S$ 的数字落地。
- 对应范围：Q2、Q3、Q4 的综合验证，贯穿例子。
- 正文要点：
  - 贯穿例子的设定：词表 $V=\{A, B, C\}$（3 个 token，便于手算）；$\gamma=3$；前缀固定，省略条件记号。
  - 给定 3 步 draft 分布与采样结果：
    - $q_1=(0.5,0.3,0.2)$，采样 $x_1=A$
    - $q_2=(0.4,0.4,0.2)$，采样 $x_2=B$
    - $q_3=(0.2,0.3,0.5)$，采样 $x_3=C$
  - 给定 target 单次前向得到的 4 个位置分布：
    - $p_1=(0.4,0.4,0.2)$
    - $p_2=(0.3,0.5,0.2)$
    - $p_3=(0.4,0.4,0.2)$
    - $p_4=(0.5,0.3,0.2)$（bonus 位置）
  - 逐位验证：
    - pos 1：$x_1=A$，$p_1(A)/q_1(A)=0.4/0.5=0.8<1$，接受概率 $0.8$。假设接受（说明：本例展示一条具体采样路径，非期望）。
    - pos 2：$x_2=B$，$p_2(B)/q_2(B)=0.5/0.4=1.25\geq 1$，必接受。
    - pos 3：$x_3=C$，$p_3(C)/q_3(C)=0.2/0.5=0.4<1$，接受概率 $0.4$。假设拒绝。
  - 残差重采样（pos 3）：$\max(0, p_3-q_3) = (0.2, 0.1, 0)$，和 $0.3$，残差 $= (2/3, 1/3, 0)$；假设重采样到 $A$。
  - 本轮产出：$[A, B, A]$ 共 3 个 token（无 bonus，因为 pos 3 被拒）。
  - 对照单位置证明（S3）：在 pos 1 上验证 $\Pr[\text{emit }A] = \min(0.5,0.4) + \max(0, 0.4-0.5) = 0.4 + 0 = 0.4 = p_1(A)$ ✓。
  - 期望产出对照（S4）：用 $\alpha = \sum_x\min(p,q)$ 在三个位置求平均，代入 $\mathbb{E}[L]$ 公式，与「具体路径产出 3 个」对比说明「期望 vs 单次采样」。
- 讲解材料：
  - 数字例子折叠块（材料 10）：完整逐位代入、残差归一化、重采样概率计算。
  - 对照表格（材料 14）：三个位置的 $q_i, p_i, x_i, p_i(x_i)/q_i(x_i), a_i$、结果一表汇总。
- 完成检查：
  - 给定上面 3 个 $p$ 与 $q$，逐位算出 $a_i$。
  - 在 pos 3 上手算残差分布的归一化。
  - 在 pos 1 上验证单位置输出分布等于 $p_1$。
  - 说出本例若 pos 3 也接受、产出会是几个 token（4 个，含 bonus）。
- 过渡：贯穿例子把机制、证明、加速比公式串通——最后一章把工程实例（K3 与 EAGLE-3）和论文实测做个交代，并说明本页的边界。
