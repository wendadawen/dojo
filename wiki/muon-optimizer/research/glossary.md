# Muon 优化器术语表

登记全文首次出现的术语、缩写和符号。后续阶段写作和审查以此为准，保证全文含义一致。

## 概念与缩写

| 术语 | 首现位置 | 定义或含义 |
|---|---|---|
| Muon | S1 钩子 | MomentUm Orthogonalized by Newton-Schulz 的缩写，本文所述的矩阵参数优化器。大写 U 来自 momentUm。 |
| Newton-Schulz 迭代 | S1 过渡 | 用矩阵多项式迭代逼近矩阵正交化的方法，只依赖矩阵乘法。本文的前置概念（占位页）。 |
| 正交化 | S1 | 把矩阵的奇异值拉平到接近 1、保留奇异向量方向的操作，目标为最近的半正交矩阵。 |
| 半正交矩阵 semi-orthogonal matrix | S1 | 满足 OᵀO=I（列正交）或 OOᵀ=I（行正交）的矩阵。 |
| SVD（奇异值分解） | S1 | 把矩阵 G 分解为 G=USVᵀ，U、V 为正交矩阵，S 为对角奇异值矩阵。 |
| 奇异值 | S1 | SVD 中 S 的对角元素，衡量矩阵在各奇异值方向上的"幅度"。 |
| 条件数 | S1 | 最大奇异值与最小奇异值之比，衡量矩阵接近低秩的程度。 |
| 动量 momentum | S1 | SGD-momentum 中累积历史梯度的缓冲区，记为 M_t。 |
| Nesterov momentum | S3 | 先构造前瞻动量 M̃_t=G_t+β·M_{t-1} 再决定更新方向的动量变体。Muon 默认使用。 |
| 动量系数 | S1 | 动量累积中的衰减因子 β，控制历史梯度的保留比例。 |
| 谱范数归一化 | S2 | NS 迭代前对矩阵做 X=G/(‖G‖_F+ε)，保证初始奇异值落在 [0,1]。 |
| Frobenius 范数 ‖·‖_F | S2 | 矩阵所有元素平方和的平方根。 |
| 矩阵多项式 φ(x) | S2 | NS 迭代对奇异值施加的五次多项式 φ(x)=ax+bx³+cx⁵。 |
| 基线系数 | S2 | (a,b,c)=(2,-1.5,0.5)，经典五阶 NS 格式。 |

| bfloat16 | S2 | 16 位浮点格式，现代 GPU 有专用张量核心加速。NS 迭代可在此精度下稳定运行。 |
| Shampoo | S3 | 二阶预条件优化器，其无累积版本更新等价于正交化梯度。Muon 的前身概念。 |
| 逆四次根 | S3 | Shampoo 计算中需要的 (GGᵀ)^(-1/4) 运算，Muon 用 NS 迭代替代以提效。 |
| AdamW | S3 | 逐坐标自适应学习率加权重衰减的优化器，与 Muon 混合使用。 |
| SGD-momentum | S1 | 带动量的随机梯度下降，Muon 的动量来源。 |
| embedding 层 | S4 | 将 token 映射为向量的输入层，二维但用 AdamW 优化。 |
| lm_head / 分类头 | S4 | 网络输出层，二维但用 AdamW 优化。 |
| LayerNorm | S4 | 层归一化，其 scale/shift 为一维参数，用 AdamW。 |

## 术语漂移检查

- "正交化"全文统一指把奇异值拉平到接近 1 的操作，不与"归一化"（normalize）混用。谱范数归一化是 NS 迭代前的预处理步骤，单独称"谱范数归一化"。
- "动量"指 SGD-momentum 的动量缓冲区 M_t，不与其他动量概念混用。Nesterov momentum 是其变体，首次出现时明确标注。
- "奇异值方向"指 SVD 后某个奇异值对应的更新方向，不简称"方向"。
- "更新矩阵"指用于更新参数的矩阵（动量矩阵或其正交化结果），不与"梯度矩阵"混用；梯度矩阵 G_t 是当前步梯度，动量矩阵 M_t 是累积结果。
- "调优系数"专指 (3.4445, -4.7750, 2.0315)，"基线系数"专指 (2, -1.5, 0.5)，不互换。
