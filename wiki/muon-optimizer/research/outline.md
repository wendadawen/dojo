# Muon 优化器教学大纲

## 1. 页面开头

### 钩子问题

训练一个 transformer 时，某个隐藏层权重矩阵的动量更新经 SVD 分解后发现：最大的几个奇异值方向拿走了更新的绝大部分"能量"，而很多奇异值很小的方向几乎不被更新。这样的更新矩阵条件数很高、近似低秩。直接用它更新参数，等于只优化了少数方向。Muon 要解决的就是这个问题：让每一个奇异值方向都获得均等的更新尺度。

### 一句话解释

Muon 是一种用于神经网络隐藏层二维权重矩阵的优化器，它对动量更新矩阵做 Newton-Schulz 迭代近似正交化（把奇异值拉平到接近 1）后，再作为更新方向。

### 学习承诺

读完这一页，你应该能够：说明 Muon 每一步对动量矩阵做了什么、为什么这样能改善更新；写出 Newton-Schulz 单步迭代公式并解释它如何把正交化变成只靠矩阵乘法可算的步骤；对比 Muon 与 SGD-momentum、AdamW 在更新方向几何结构上的区别；说明 Muon 适用哪些参数、为什么 embedding 和输出层仍用 AdamW。

### 首个场景

一个 2×2 的对角更新矩阵 diag(0.9, 0.1)：两个奇异值方向上更新幅度相差 9 倍，少数方向主导。这个最小例子将贯穿后续章节，展示正交化如何把它拉平。

### 过渡

先看这种"少数方向主导"的更新矩阵究竟带来了什么问题，再进入 Muon 的机制。

## 2. 章节设计

### S1：动量更新矩阵为什么需要正交化

- 主要教学问题：直接用动量矩阵更新二维权重参数时，更新方向有什么问题？
- 对应范围：Q1（动机部分）、C4、C5。
- 正文要点：
  - 回顾 SGD-momentum：用动量缓冲区累积历史梯度，得到更新矩阵 M_t。正文给出更新式 M_t = β·M_{t-1} + G_t，W_{t+1} = W_t - η·M_t，说明 β 为动量系数、G_t 为当前梯度、M_0=0。一句话回顾即可，不展开 SGD 细节。
  - 引入 SVD 视角：二维矩阵 M_t 可做 SVD 分解 M_t = U S Vᵀ，奇异值矩阵 S 的对角元素衡量各奇异值方向的"更新幅度"。前置概念为 [Newton-Schulz 正交化](../newton-schulz/index.html)（占位页，待生成），此处用最小衔接说明 SVD 与奇异值的含义，不内联完整讲解。
  - 经验观察（C4）：SGD-momentum 产生的更新矩阵条件数很高，近似低秩，少数方向主导。
  - 用贯穿例子展示：diag(0.9, 0.1) 条件数 9，大奇异值方向拿走绝大部分更新能量。
  - 正交化的直觉（C5）：把奇异值拉平到接近 1，放大"稀有方向"，抑制主导方向，使各方向均等更新。给出正交化目标 Ortho(G) = argmin_O {‖O−G‖_F : OᵀO=I 或 OOᵀ=I}，等价于 SVD 后取 UVᵀ（F4）。
- 讲解材料及职责：
  - 公式 M_t = β·M_{t-1} + G_t：表达动量累积。
  - 公式 Ortho(G) 目标与 UVᵀ 等价：表达正交化的数学目标。
  - 数字例子 diag(0.9, 0.1)：展示条件数高的具体表现。
- 前置知识安排：SGD-momentum 一句话回顾；SVD/奇异值最小衔接并指向 NS 占位页。
- 完成检查：
  - 用自己的话说动量更新矩阵条件数高意味着什么。
  - 说明正交化目标为什么等价于把奇异值全置 1。
  - 计算 diag(0.9, 0.1) 的条件数。
- 过渡：正交化目标明确了，但直接做 SVD 取 UVᵀ 太慢。下一章看 Newton-Schulz 迭代如何用矩阵乘法逼近这个目标。

### S2：Newton-Schulz 迭代如何近似正交化

- 主要教学问题：如何把"正交化一个矩阵"变成只靠矩阵乘法就能逐步逼近的计算？
- 对应范围：Q2、F1、F2、F3、F5、C8、N1、N2、N3、N4、N5。
- 正文要点：
  - 单步迭代公式（F1）：G' = (aI + b(GGᵀ) + c(GGᵀ)²) G = aG + b(GGᵀ)G + c(GGᵀ)²G。说明它只用到矩阵乘法与线性组合，无 SVD、无求逆。
  - SVD 下的多项式映射（F2）：设 G = USVᵀ，则 G' = U(aS + bS³ + cS⁵)Vᵀ，即对每个奇异值 s 施加多项式 φ(s) = as + bs³ + cs⁵。这是理解 NS 的关键：矩阵迭代在 SVD 下退化为对奇异值的标量迭代。
  - N 步复合（F3）：N 步迭代输出 U φᴺ(S) Vᵀ，φᴺ 表示重复施加 φ。只要 φ 把 [0,1] 上的点都映射到接近 1，多次迭代后奇异值就都被拉平。
  - 谱范数归一化预处理（F5）：迭代前做 X = G/(‖G‖_F + ε)，ε=1e-7，保证初始奇异值落在 [0,1]。说明 Ortho(cG)=Ortho(G)，所以缩放是良性的。补充：若 m>n 则先转置，使迭代在 m≤n 的矩阵上运行。
  - 系数（N1、N2）：基线系数 (2, -1.5, 0.5)，调优系数 (3.4445, -4.7750, 2.0315)。说明调优原则：a 尽量大（φ'(0)=a 控制小奇异值收敛速率），且 φᴺ(x)∈[0.7,1.3] 即可（N5）。
  - 迭代步数（N3）：默认 5 步。
  - bfloat16 稳定性（C8）：NS 迭代只用矩阵乘法，可在 bfloat16 下稳定运行，这是它优于 SVD 与 coupled Newton iteration 的工程优势。
  - 贯穿例子手算：用基线系数对 diag(0.9, 0.1) 做 NS 迭代。先谱归一化得 diag(0.9939, 0.1104)，逐步施加 φ，展示 5 步后两个奇异值都逼近 1。正文中给出前两步的关键计算，完整 5 步放折叠块。
- 讲解材料及职责：
  - 公式 G'=(aI+b(GGᵀ)+c(GGᵀ)²)G：表达单步迭代的矩阵乘法结构。
  - 推导 SVD 下 G'=Uφ(S)Vᵀ：解释矩阵迭代等价于奇异值标量迭代。
  - 数字例子 diag(0.9,0.1) 经 5 步 NS：展示拉平过程，可手算复算。
  - 对照表格：基线系数 vs 调优系数下小奇异值第 1 步的映射结果，展示调优加速。
- 前置知识安排：Newton-Schulz 正交化（占位页）作为概念来源，本文给出迭代公式本身。
- 完成检查：
  - 写出 NS 单步迭代公式，说明它只用矩阵乘法。
  - 解释为什么 SVD 下矩阵迭代等价于对奇异值施加多项式。
  - 说明谱范数归一化的作用与为什么缩放是良性的。
  - 用基线系数计算 φ(0.1104) 第 1 步的值。
- 过渡：NS 迭代能把动量矩阵正交化，但 Muon 还要决定动量与正交化的组合顺序、更新尺度。下一章把所有步骤组装成完整算法，并与其他优化器对比。

### S3：Muon 的完整更新流程与几何含义

- 主要教学问题：Muon 如何把动量与正交化组合成完整更新？它与其他优化器在更新方向几何上有什么区别？
- 对应范围：Q1（完整）、Q3、C1、C3、C6、F6。
- 正文要点：
  - 完整算法步骤（C1、C3）：
    1. 计算当前梯度 G_t。
    2. Nesterov momentum 累积（C3）：先构造前瞻动量 M̃_t = G_t + β·M_{t-1}，更新 M_t = β·M_{t-1} + G_t。说明 Muon 默认用 Nesterov，且动量在正交化之前加入。
    3. 谱范数归一化预处理。
    4. 5 步 NS 迭代正交化，得到 O_t ≈ U Vᵀ（奇异值接近 1）。
    5. 参数更新 W_{t+1} = W_t - η·O_t。
    - 用伪代码（折叠块）呈现完整流程。
  - 与 SGD-momentum 的几何区别：SGD-momentum 直接用 M_t 更新，各奇异值方向步长正比于奇异值大小（大方向更新猛、小方向更新不足）；Muon 用正交化后的 O_t 更新，各奇异值方向步长趋于均等。
  - 与 AdamW 的几何区别：AdamW 逐坐标归一化（按元素二阶矩缩放），不考虑矩阵整体方向结构；Muon 对整个矩阵做正交化，改变的是方向间的相对尺度。一句话回顾 AdamW 即可。
  - 与 Shampoo 的关系（C6、F6）：无累积 Shampoo 更新 (GGᵀ)^(-1/4)G(GᵀG)^(-1/4) 经 SVD 展开等价于 UVᵀ，即正交化梯度。Muon 可视为"无累积 Shampoo + momentum"，用 NS 迭代替代 Shampoo 的逆四次根计算。正文给出展开的关键步骤，完整推导放折叠块。
  - 工程开销（N8）：典型 LM 训练 FLOP 开销 < 1%，可在 bfloat16 下运行。
  - NanoGPT 证据（N6、N7、N9、N10）：作为外部事实引用，说明 Muon 在竞争性任务中的表现，明确标记为外部数字而非机制结论。
- 讲解材料及职责：
  - 伪代码：表达完整算法的输入、状态、步骤、输出。
  - 公式 W_{t+1}=W_t-η·O_t：表达最终更新。
  - 推导 Shampoo 无累积 = UVᵀ：表达 Muon 与 Shampoo 的定位关系。
  - 对照表格：SGD-momentum / AdamW / Muon 三者在"更新方向几何结构"上的对比。
- 前置知识安排：SGD-momentum（已回顾）、AdamW（一句话回顾）、Shampoo（首次出现给一句话定位）。
- 完成检查：
  - 按顺序说出 Muon 一步更新的五个步骤。
  - 说明动量在正交化之前加入的原因。
  - 对比 SGD-momentum 与 Muon 在大/小奇异值方向上步长的差异。
  - 说明 AdamW 逐坐标归一化与 Muon 矩阵级正交化的区别。
- 过渡：Muon 的机制已完整。但并非所有参数都该用 Muon——下一章明确它的适用边界。

### S4：Muon 的适用边界

- 主要教学问题：Muon 适用哪些参数、不适用哪些参数，为什么 embedding 和输出层仍用 AdamW？
- 对应范围：Q4、C2、C7、F7、N11。
- 正文要点：
  - 参数分类（C2）：
    - 隐藏层二维权重矩阵（线性层权重、卷积核展平后）：Muon。
    - 标量/向量参数（bias、LayerNorm 的 scale/shift）：AdamW。说明一维参数无法定义"奇异值方向"，正交化无意义。
    - embedding 层：AdamW。理论依据为 modular norm theory（Large et al. 2024），本文只引用结论不推导。
    - 输出层（lm_head/分类头）：AdamW。经验结论，无理论解释。
    - 用对照表格呈现参数类型与优化器选择。
  - QKV 分开（C7）：训练 transformer 时 Muon 应分别应用于 Q、K、V，而非合并为单一 QKV 矩阵。经验结果，由 Vlado Boza 首先展示。
  - RMS 对齐缩放因子（F7）：正交化后矩阵 Φ=UVᵀ 的 RMS 为 √(1/max(m,n))，乘以 0.2·√max(m,n) 可使 update RMS 对齐到 0.2（与 AdamW 一致）。说明此为 Moonshot 改进（非 Keller 原始博客），PyTorch 2.12 官方采用，目的是复用 AdamW 调好的学习率与权重衰减。正文给出 RMS 推导的关键步骤，完整推导放折叠块。
  - PyTorch 官方默认超参（N11）：lr=1e-3, weight_decay=0.1, momentum=0.95, nesterov=True, ns_steps=5。作为工程参考，明确标记为外部数字。
  - 常见误解回顾：Muon 不是"更好的 Adam 平替"；NS 迭代是近似而非精确；Muon 不适用于所有二维参数。
- 讲解材料及职责：
  - 对照表格：参数类型 → 优化器 → 原因。
  - 公式 γ=0.2·√max(m,n)：表达 RMS 对齐缩放。
  - 推导 RMS(UVᵀ)=√(1/max(m,n))：解释缩放因子来源。
- 前置知识安排：embedding、lm_head、LayerNorm 等术语首次出现给最小说明。
- 完成检查：
  - 列出哪些参数用 Muon、哪些用 AdamW，并各给一个原因。
  - 说明 embedding 用 AdamW 的理论依据与输出层用 AdamW 的依据性质区别。
  - 说明 QKV 分开应用的原因。
  - 解释 0.2·√max(m,n) 缩放因子解决什么问题。
- 过渡：（文末来源与教学说明承接）

## 4. 贯穿例子

### 例子设定

一个 2×2 对角矩阵 G = diag(0.9, 0.1)，代表某隐藏层权重矩阵的动量更新在两个奇异值方向上的幅度。数字为教学示例，便于手算，不代表真实训练数据。

### 跨章推进

- S1：首次出现。说明条件数 = 0.9/0.1 = 9，大奇异值方向拿走绝大部分更新能量，正交化目标是把 (0.9, 0.1) 拉平到接近 (1, 1)（等价于取 UVᵀ）。
- S2：对 G 做谱归一化得 X = diag(0.9939, 0.1104)，用基线系数 (2, -1.5, 0.5) 逐步施加 φ。正文给出前两步关键计算：第 1 步后 (1.0001, 0.2189)，第 2 步后 (1.0000, 0.4222)。完整 5 步（最终逼近 (1, 1)）放折叠块。同时用调优系数对比第 1 步小奇异值映射（0.3739 vs 0.2189），展示调优加速。
- S3：在完整算法伪代码中复用该例子作为输入，说明最终更新 W_{t+1} = W_t - η·O_t 中 O_t 的奇异值已拉平。
- S4：用该例子说明 RMS 对齐——正交化后 O_t≈UVᵀ 的 RMS≈√(1/2)≈0.707，乘以 0.2·√2≈0.283 后 RMS≈0.2，与 AdamW 对齐。
