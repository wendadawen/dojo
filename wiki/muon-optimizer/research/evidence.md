# Muon 优化器核心论断与证据

来源优先级：主源为 Keller Jordan 2024 博客《Muon: An optimizer for hidden layers in neural networks》（https://kellerjordan.github.io/posts/muon/）。Moonshot AI 的《Muon is Scalable for LLM Training》（2025）作为 RMS 对齐缩放因子的来源。PyTorch 2.12 官方文档 `torch.optim.Muon` 作为默认超参的来源。

## C 论断（机制与定义）

### C1：Muon 的定义
- 论断：Muon 是对神经网络隐藏层二维参数的优化器，取 SGD-momentum 生成的更新，对其应用 Newton-Schulz 迭代作为后处理正交化步骤，再应用到参数。
- 来源定位：Keller Jordan 2024 博客标题及正文"Muon is an optimizer for 2D parameters of neural network hidden layers"、"taking the updates generated by SGD-momentum, and then applying a Newton-Schulz iteration as a post-processing step"。
- 适用条件：参数为二维矩阵。
- 置信状态：已确认。

### C2：Muon 仅用于隐藏层二维参数，embedding 与输出层用 AdamW
- 论断：标量与向量参数、输入层（embedding）、输出层（分类头/lm_head）应使用 AdamW 等标准方法，即使它们是二维的。
- 来源定位：博客正文"When training a neural network with Muon, scalar and vector parameters of the network, as well as the input and output layers, should be optimized by a standard method such as AdamW"、"we find that it is also important to optimize input and output parameters using AdamW, even though these are typically 2D"。
- 适用条件：训练 transformer 等含 embedding 与输出头的网络。
- 置信状态：已确认。embedding 用 AdamW 由 modular norm theory（Large et al. 2024）支持；输出层用 AdamW 是经验结论，无理论解释。

### C3：动量在正交化之前加入
- 论断：Muon 在正交化之前加入 momentum，且使用 Nesterov-style momentum 作为默认。
- 来源定位：博客正文"add momentum before the orthogonalization"、"using Nesterov-style momentum for Muon works a bit better than normal SGD-momentum in every case we have tested. We have therefore made this the default in the public Muon implementation"。
- 适用条件：Muon 公开实现。
- 置信状态：已确认。

### C4：动量更新矩阵条件数高、近似低秩
- 论断：SGD-momentum 和 Adam 产生的二维参数更新矩阵通常条件数很高，近似低秩，所有神经元的更新被少数几个方向主导。
- 来源定位：博客正文"the updates produced by both SGD-momentum and Adam for the 2D parameters in transformer-based neural networks typically have very high condition number. That is, they are almost low-rank matrices, with the updates for all neurons being dominated by just a few directions"。
- 适用条件：transformer 等网络的二维参数更新。
- 置信状态：已确认（经验观察，非理论证明）。

### C5：正交化放大稀有方向
- 论断：正交化有效放大那些在更新中幅度很小但对学习重要的"稀有方向"，抑制过度主导的少数方向。
- 来源定位：博客正文"We speculate that orthogonalization effectively increases the scale of other 'rare directions' which have small magnitude in the update but are nevertheless important for learning"。
- 适用条件：二维更新矩阵。
- 置信状态：已确认（作者推测，speculate）。

### C6：与 Shampoo 的关系
- 论断：去除 preconditioner accumulation 的 Shampoo 更新等价于正交化梯度 UV^T；Muon 可视为"无累积 Shampoo"，区别在于 Muon 在正交化前加 momentum、用 Newton-Schulz 迭代替代逆四次根。
- 来源定位：博客正文推导 Shampoo 更新 (G_t G_tᵀ)^(-1/4) G_t (G_tᵀ G_t)^(-1/4) = UV^T，并称"Muon can be viewed as an instantaneous or non-accumulating Shampoo (Anil 2024b)"。
- 适用条件：Shampoo 去除累积。
- 置信状态：已确认。

### C7：QKV 应分开应用 Muon
- 论断：训练 transformer 时，Muon 应分别应用于 Q、K、V 参数，而非合并为单一 QKV 矩阵后统一应用。
- 来源定位：博客正文"Muon works better for optimizing transformers if it is applied to their Q, K, V parameters separately, rather than together as would be the default for transformer implementations that parametrize QKV as a single linear layer whose outputs are split"。该结果由 Vlado Boza 首先展示。
- 适用条件：transformer 训练。
- 置信状态：已确认（经验结果）。

### C8：Newton-Schulz 迭代可在 bfloat16 下稳定运行
- 论断：NS 迭代用矩阵乘法多项式逼近正交化，可在 bfloat16 精度下稳定运行，而 Shampoo 使用的 coupled Newton iteration 需 float32。
- 来源定位：博客正文对比 SVD（太慢）、coupled Newton iteration（需 float32，较慢）、Newton-Schulz iteration（可 bfloat16）。
- 适用条件：现代 GPU（Ampere 及以后）。
- 置信状态：已确认。

## F 论断（公式）

### F1：Newton-Schulz 单步迭代公式
- 论断：单步 NS 迭代表示为 G' = (aI + b(GGᵀ) + c(GGᵀ)²) G，等价于 G' = aG + b(GGᵀ)G + c(GGᵀ)²G。
- 来源定位：博客正文 NS 迭代定义及 PyTorch 实现 `newtonschulz5`。
- 适用条件：G 为二维矩阵，系数 (a,b,c) 给定。
- 置信状态：已确认。

### F2：SVD 下的多项式映射
- 论断：设 G = USVᵀ，则单步迭代输出 G' = U(aS + bS³ + cS⁵)Vᵀ，即对每个奇异值施加多项式 φ(x) = ax + bx³ + cx⁵。
- 来源定位：博客正文"X' = U(aS + bS³ + cS⁵)Vᵀ"及"the polynomial φ(x) = ax + bx³ + cx⁵"。
- 适用条件：G 可做 SVD。
- 置信状态：已确认。

### F3：N 步复合
- 论断：应用 N 步 NS 迭代的输出为 U φᴺ(S) Vᵀ，其中 φᴺ 表示对 S 的对角元素重复施加 φ 共 N 次。
- 来源定位：博客正文"applying N steps of NS iteration outputs U φᴺ(S) Vᵀ"。
- 适用条件：初始奇异值落在收敛域。
- 置信状态：已确认。

### F4：正交化目标等价于 UVᵀ
- 论断：正交化目标 Ortho(G) = argmin_O {‖O−G‖_F : OᵀO=I 或 OOᵀ=I}，等价于 SVD 后取 UVᵀ（奇异值全置 1）。
- 来源定位：博客正文"Ortho(G) = argmin_O {‖O − G‖_F : OᵀO = I or OOᵀ = I}"及"equivalent to replacing the update by UVᵀ"。
- 适用条件：G 可做 SVD。
- 置信状态：已确认。

### F5：谱范数归一化预处理
- 论断：NS 迭代前对 G 做 X = G/(‖G‖_F + ε) 归一化，保证初始奇异值落在 [0,1]；该缩放是良性的，因为 Ortho(cG) = Ortho(G)。
- 来源定位：博客正文"X = G / (‖G‖_F + ε)"及"orthogonalization satisfies Ortho(cG) = Ortho(G), so this scaling is benign"。
- 适用条件：G 非零。
- 置信状态：已确认。

### F6：Shampoo 无累积版本等价于正交化
- 论断：(G_t G_tᵀ)^(-1/4) G_t (G_tᵀ G_t)^(-1/4) = UVᵀ。
- 来源定位：博客正文展开 SVD 推导：(US²Uᵀ)^(-1/4)(USVᵀ)(VS²Vᵀ)^(-1/4) = (US^(-1/2)Uᵀ)(USVᵀ)(VS^(-1/2)Vᵀ) = UVᵀ。
- 适用条件：G 可做 SVD。
- 置信状态：已确认。

### F7：Moonshot RMS 对齐缩放因子
- 论断：正交化后的矩阵 Φ=UVᵀ 的 RMS 为 √(1/max(m,n))（假设满秩 r=min(m,n)），乘以 0.2·√max(m,n) 可使 update RMS 对齐到 0.2，与 AdamW 一致。
- 来源定位：Moonshot AI《Muon is Scalable for LLM Training》（2025）；苏剑林博客推导 RMS(UVᵀ)=√(r/nm)，r=min(m,n) 时为 √(1/max(n,m))。
- 适用条件：满秩或近似满秩矩阵。
- 置信状态：已确认。此为 Moonshot 改进，非 Keller 原始博客内容；PyTorch 2.12 官方实现采用。

## N 论断（数字）

### N1：调优后系数
- 论断：NS 迭代调优后系数 (a, b, c) = (3.4445, -4.7750, 2.0315)。
- 来源定位：博客正文及 PyTorch 实现 `newtonschulz5` 中 `a, b, c = (3.4445, -4.7750, 2.0315)`。
- 适用条件：Muon 公开实现默认。
- 置信状态：已确认。

### N2：基线系数
- 论断：基线五次 NS 系数 (a, b, c) = (2, -1.5, 0.5)。
- 来源定位：博客正文"baseline coefficients (2, -1.5, 0.5)"。
- 适用条件：经典五阶 NS 格式。
- 置信状态：已确认。

### N3：迭代步数
- 论断：默认 NS 迭代步数 T = 5。
- 来源定位：博客正文"5 steps of NS iteration is sufficient"及 PyTorch 默认 `steps=5`。
- 适用条件：transformer 语言模型与小型卷积网络训练。
- 置信状态：已确认。

### N4：归一化 epsilon
- 论断：谱范数归一化的 ε = 1e-7。
- 来源定位：PyTorch 实现 `eps=1e-7`。
- 适用条件：数值稳定。
- 置信状态：已确认。

### N5：允许误差范围
- 论断：调优系数时要求对所有 x∈[0,1]，lim_{N→∞} φᴺ(x) ∈ [0.7, 1.3]，即 ε 可高达约 0.3 而不影响损失曲线。
- 来源定位：博客正文"requiring that lim_{N→∞} φᴺ(x) ∈ [0.7, 1.3] for all x ∈ [0,1]"。
- 适用条件：训练损失曲线容忍度。
- 置信状态：已确认。

### N6：NanoGPT speedrun 首次提速
- 论断：Muon 于 2024-10-15 首次创造 NanoGPT 训练速度记录，相对 AdamW 提速 35%。
- 来源定位：博客正文"switching from AdamW to Muon set a new NanoGPT training speed record on 10/15/24, where Muon improved the training speed by 35%"。
- 适用条件：NanoGPT speedrun 任务（FineWeb 数据集，val loss 3.28 目标）。
- 置信状态：已确认。

### N7：记录持续数
- 论断：自 Muon 创纪录以来，NanoGPT speedrun 产生 12 个新记录，由 7 位不同研究者创造，Muon 在所有记录中保持为优化器选择。
- 来源定位：博客正文"Muon has persisted as the optimizer of choice through all 12 of the new NanoGPT speedrunning records since then, which have been set by 7 different researchers"。
- 适用条件：截至博客发布。
- 置信状态：已确认。

### N8：FLOP 开销
- 论断：典型 LM 训练场景下 Muon 的 FLOP 开销低于 1%。NanoGPT speedrun（m=768, B=524288）开销 0.7%；Llama 405B（m=16384, B=16M）开销 0.5%。
- 来源定位：博客正文 FLOP 开销分析"FLOP overhead ≤ T·m/B"及两个场景数字。
- 适用条件：T=5，典型 batch size。
- 置信状态：已确认。

### N9：1.5B transformer 训练时间
- 论断：用 8 张 H100 训练 1.5B 参数 transformer 达到 GPT-2 XL 级 HellaSwag 性能，Muon 需 10 小时，AdamW 需 13.3 小时。
- 来源定位：博客正文引用的扩展验证。
- 适用条件：8xH100，1.5B 参数。
- 置信状态：已确认。

### N10：CIFAR-10 速度记录
- 论断：CIFAR-10 训练至 94% 准确率的速度记录从 3.3 A100-seconds 提升到 2.6 A100-seconds。
- 来源定位：博客正文。
- 适用条件：CIFAR-10，94% 准确率目标。
- 置信状态：已确认。

### N11：PyTorch 官方默认超参
- 论断：PyTorch 2.12 `torch.optim.Muon` 默认超参为 lr=1e-3, weight_decay=0.1, momentum=0.95, nesterov=True, ns_coefficients=(3.4445, -4.775, 2.0315), eps=1e-7, ns_steps=5。
- 来源定位：PyTorch 2.12 文档 `torch.optim.Muon`。
- 适用条件：PyTorch 2.12 官方实现。
- 置信状态：已确认。

### N12：贡献者
- 论断：Muon 由 Keller Jordan、Yuchen Jin、Vlado Boza、Jiacheng You、Franz Cesista、Laker Newhouse、Jeremy Bernstein 合作完成。Bernstein 与 Newhouse 提出 NS 迭代作为 Shampoo 计算策略；Boza 发现 QKV 分开优化；Jin 扩展实验；Bernstein、You、Cesista 将 NS 效率从 6nm² 优化到 4nm²+2m³ FLOPs。
- 来源定位：博客 Citation 及正文致谢。
- 适用条件：—
- 置信状态：已确认。
