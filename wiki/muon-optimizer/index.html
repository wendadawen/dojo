    Muon 优化器：对动量矩阵做正交化后再更新参数

    主要依据：Keller Jordan 等《Muon: An optimizer for hidden layers in neural networks》（2024，博客）；Moonshot AI《Muon is Scalable for LLM Training》（2025，RMS 对齐缩放因子）；PyTorch torch.optim.Muon 官方实现（2.9 起内置，adjust_lr_fn='match_rms_adamw' 提供 RMS 对齐选项）。

    训练 transformer 时，某个隐藏层权重矩阵的动量更新经 SVD 分解后发现：最大的几个奇异值方向拿走了更新的绝大部分"能量"，而很多奇异值很小的方向几乎不被更新。Muon（MomentUm Orthogonalized by Newton-Schulz）由 Keller Jordan 等于 2024 年提出，专门针对隐藏层二维权重矩阵，对动量更新做 Newton-Schulz 正交化后再作为更新方向，让每一个奇异值方向获得均等的更新尺度；标量/向量参数、embedding 层、输出层仍用 AdamW。本文回答四个问题：正交化为什么能改善更新、Newton-Schulz 迭代如何只用矩阵乘法逼近正交化、Muon 与 SGD-momentum 和 AdamW 的几何区别、Muon 的适用边界在哪里。[C1]

    最容易误解

    • Muon 不是"更好的 Adam 平替"——它改变的是更新方向的几何结构，仅适用于隐藏层二维权重矩阵，收益与模型结构和参数类型相关。
    • Newton-Schulz 迭代是近似正交化而非精确——调优系数允许奇异值在 $[0.7,\ 1.3]$ 区间内波动，关键是"拉平"而非"精确求解"。
    • Muon 不适用于所有二维参数——embedding 和输出层虽是二维矩阵，但仍应用 AdamW。

    动量更新矩阵为什么需要正交化——条件数高与稀有方向被忽略

    先回顾带动的随机梯度下降（SGD-momentum）。它维护一个动量缓冲矩阵 $M_t$，每步把当前梯度 $G_t$ 累积进去：

    $$M_t = \beta\, M_{t-1} + G_t,\qquad M_0 = 0,$$

    其中 $\beta$ 是动量系数（控制历史梯度保留比例），$G_t = \nabla_W \mathcal{L}(W_t)$ 是当前步对权重矩阵 $W_t$ 计算的梯度。参数更新为 $W_{t+1} = W_t - \eta\, M_t$，$\eta$ 为学习率。这里的"动量"指的就是这个累积历史梯度的缓冲区 $M_t$。

    对二维矩阵 $M_t$ 做奇异值分解 $M_t = U S V^\top$：$U$、$V$ 是正交矩阵，$S$ 是对角矩阵，对角元素 $s_i$ 称为奇异值，衡量更新在各个奇异值方向上的"幅度"。（矩阵的 SVD 与奇异值是理解本文的前置知识，完整讲解见 Newton-Schulz 正交化；SVD 基础见 奇异值分解。）

    Keller Jordan 在主源博客中报告了一项经验观察：SGD-momentum 和 Adam 产生的二维参数更新矩阵通常条件数很高，近似低秩——所有神经元的更新被少数几个方向主导。[C4] 条件数定义为最大奇异值与最小奇异值之比；条件数高意味着各方向更新幅度悬殊。

    教学示例。 假设某个隐藏层权重矩阵的动量更新 $M_t$ 经 SVD 后奇异值为 $(0.9,\ 0.1)$，即 $M_t$ 在两个奇异值方向上的更新幅度相差 9 倍（条件数 $0.9/0.1 = 9$）。大奇异值方向拿走了绝大部分更新能量，小奇异值方向几乎不被更新。这里的数字是为便于手算构造的教学数字，不代表真实训练数据。

    直接用这样的 $M_t$ 更新参数，等于只优化了少数方向。作者推测，正交化能有效放大那些在更新中幅度很小但对学习重要的"稀有方向"，抑制过度主导的少数方向。[C5]

    正交化的数学目标是找到与 $M_t$ 最近的半正交矩阵：[F4]

    $$\operatorname{Ortho}(G) = \arg\min_O \{\|O - G\|_F : O^\top O = I \text{ 或 } OO^\top = I\}.$$

    设 $G = USV^\top$，则这个最近半正交矩阵就是 $UV^\top$——把所有奇异值全置 1、保留奇异向量方向。对上面的 $(0.9,\ 0.1)$，正交化目标是把奇异值拉平到接近 $(1,\ 1)$，使两个方向获得均等的更新尺度。$O^\top O = I$ 表示列正交（用于行数 $\ge$ 列数的矩阵），$OO^\top = I$ 表示行正交。

    但直接做 SVD 取 $UV^\top$ 太慢。下一章看 Newton-Schulz 迭代如何只用矩阵乘法逼近这个目标。

    Newton-Schulz 迭代如何近似正交化——只用矩阵乘法把奇异值推向 1

    Newton-Schulz（NS）迭代用矩阵乘法的多项式逼近正交化，单步公式为：[F1]

    $$G' = \left(aI + b(GG^\top) + c(GG^\top)^2\right) G = aG + b(GG^\top)G + c(GG^\top)^2 G.$$

    其中 $a,b,c$ 是给定系数。这一步只用到矩阵乘法（$GG^\top$、$(GG^\top)G$ 等）和线性组合，没有 SVD、没有求逆。这是它能在 GPU 上高效运行的关键。

    要理解它为什么能正交化，看 SVD 下的等价形式。设 $G = USV^\top$，代入单步公式：[F2]

    $$G' = U\left(aS + bS^3 + cS^5\right)V^\top = U\,\phi(S)\,V^\top,$$

    其中 $\phi(x) = ax + bx^3 + cx^5$ 是一个五次多项式。也就是说，对矩阵施加一步 NS 迭代，等价于对它的每个奇异值施加一次多项式 $\phi$。矩阵迭代在 SVD 下退化为对奇异值的标量迭代。

    补充：从 G'=(aI+b(GG^T)+c(GG^T)^2)G 到 U·φ(S)·V^T

    已知 $G = USV^\top$，则 $G^\top = VS^\top U^\top$（$S$ 对角故 $S^\top = S$）。计算：

    $$GG^\top = (USV^\top)(VSU^\top) = US^2U^\top,$$

    $(GG^\top)^2 = (US^2U^\top)(US^2U^\top) = US^4U^\top$。代入单步公式：

    $$G' = (aI + b\,US^2U^\top + c\,US^4U^\top)(USV^\top) = U(aI + bS^2 + cS^4)SV^\top = U(aS + bS^3 + cS^5)V^\top.$$

    最后一步用了 $S$ 对角因此与 $I$ 可交换、$S^2 \cdot S = S^3$ 等。结果就是对角矩阵 $aS + bS^3 + cS^5 = \phi(S)$，每个对角元素为 $\phi(s_i)$。

    应用 $N$ 步 NS 迭代的输出为 $U\,\phi^N(S)\,V^\top$，其中 $\phi^N$ 表示对 $S$ 的对角元素重复施加 $\phi$ 共 $N$ 次。[F3] 只要 $\phi$ 把区间 $[0,1]$ 上的点都映射到接近 1，多次迭代后所有奇异值就都被拉平。

    这里有一个前提：初始奇异值必须落在 $\phi$ 的收敛域内。NS 迭代前先做谱范数归一化预处理：[F5]

    $$X = \frac{G}{\|G\|_F + \varepsilon},\qquad \varepsilon = 10^{-7}.$$

    其中 $\|G\|_F$ 是 Frobenius 范数（矩阵所有元素平方和的平方根）。归一化后所有奇异值落在 $[0,1]$，因为最大奇异值不超过 $\|G\|_F$。这个缩放是良性的：正交化满足 $\operatorname{Ortho}(cG) = \operatorname{Ortho}(G)$（对任意非零常数 $c$），所以缩放不改变正交化结果。[N4] 此外，若 $G$ 的行数大于列数（$m > n$），先对 $G$ 做转置再迭代，迭代完成后再转回来，使迭代始终在 $m \le n$ 的矩阵上运行以减少计算量。

    系数 $(a,b,c)$ 有两组常用取值。[N1, N2, N3, N5] 基线系数 $(a,b,c) = (2,\ -1.5,\ 0.5)$ 来自经典五阶 NS 格式，多次迭代后奇异值收敛到 1。调优系数 $(a,b,c) = (3.4445,\ -4.7750,\ 2.0315)$ 是 Muon 公开实现的默认值，调优原则有两条：让 $a$ 尽量大，因为 $\phi'(0) = a$ 控制小奇异值的初始增长速率；以及对所有 $x \in [0,1]$，允许 $\lim_{N\to\infty}\phi^N(x) \in [0.7,\ 1.3]$，即奇异值不必精确收敛到 1，误差约 0.3 即可不影响训练损失曲线。默认迭代步数 $T = 5$。

    调优系数的目标是"快速进入容忍区间"，不是"精确收敛到 1"。调优系数的 $\phi'(0)=3.4445$ 大于基线的 $2$，使小奇异值第一步增长更快；但大系数也让接近 1 的奇异值产生振荡，最终在 $[0.7,\ 1.3]$ 区间内波动而非收敛到 1。这种"不精确"是设计选择——正交化的关键是把奇异值谱拉平，不是精确求解。

    NS 迭代的另一个工程优势是可在 bfloat16 精度下稳定运行。[C8] 对比之下，SVD 太慢，Shampoo 使用的 coupled Newton iteration 需要至少 float32 精度才能避免数值不稳定。NS 迭代只用矩阵乘法，而现代 GPU 有 bfloat16 专用张量核心，这使得它在工程上可行。

    手算例子：把 diag(0.9, 0.1) 拉平

    用教学示例 $G = \operatorname{diag}(0.9,\ 0.1)$ 展示 NS 迭代。先做谱范数归一化：$\|G\|_F = \sqrt{0.9^2 + 0.1^2} = \sqrt{0.82} \approx 0.9055$，所以归一化后奇异值为 $(0.9939,\ 0.1104)$。

    用基线系数 $\phi(x) = 2x - 1.5x^3 + 0.5x^5$ 做第一步。对大奇异值 $s_1 = 0.9939$：

    $$\phi(0.9939) = 2(0.9939) - 1.5(0.9939)^3 + 0.5(0.9939)^5 \approx 1.0001.$$

    对小奇异值 $s_2 = 0.1104$：

    $$\phi(0.1104) = 2(0.1104) - 1.5(0.1104)^3 + 0.5(0.1104)^5 \approx 0.2189.$$

    第一步后奇异值从 $(0.9939,\ 0.1104)$ 变为 $(1.0001,\ 0.2189)$：大奇异值已逼近 1，小奇异值从 0.11 提升到 0.22。第二步对小奇异值再施加 $\phi$：$\phi(0.2189) \approx 0.4222$。完整 5 步后两个奇异值都逼近 1。

    代码：用 numpy 复现 diag(0.9, 0.1) 的 5 步 NS 迭代 
    import math
import numpy as np

def newtonschulz5(G, a, b, c, steps=5, eps=1e-7):
    """对 2D 矩阵 G 做 steps 步 Newton-Schulz 迭代。"""
    X = G.astype(np.float64) / (np.linalg.norm(G) + eps)
    if G.shape[0] > G.shape[1]:
        X = X.T
    for _ in range(steps):
        A = X @ X.T
        B = b * A + c * (A @ A)
        X = a * X + B @ X
    if G.shape[0] > G.shape[1]:
        X = X.T
    return X

# 教学示例
G = np.diag(np.array([0.9, 0.1]))
fro = np.linalg.norm(G)
print(f"||G||_F = {fro:.6f}")
X = G / (fro + 1e-7)
print(f"谱归一化后奇异值 = {np.round(np.linalg.svd(X, compute_uv=False), 4)}")

# 基线系数
O_base = newtonschulz5(G, 2.0, -1.5, 0.5)
sv_base = np.linalg.svd(O_base, compute_uv=False)
print(f"基线系数 5 步后奇异值 = {np.round(sv_base, 4)}")

# 调优系数
O_tuned = newtonschulz5(G, 3.4445, -4.7750, 2.0315)
sv_tuned = np.linalg.svd(O_tuned, compute_uv=False)
print(f"调优系数 5 步后奇异值 = {np.round(sv_tuned, 4)}")

# 验证基线系数下 O 接近正交矩阵
print(f"基线 O^T O =\n{np.round(O_base.T @ O_base, 4)} (应接近 I)")

    Muon 的完整更新流程与几何含义——动量、正交化与参数更新

    把动量与正交化组合起来，Muon 一步更新的完整流程为：

    1. 计算当前梯度 $G_t = \nabla_W \mathcal{L}(W_t)$。
    2. 用 Nesterov momentum 累积动量。先构造前瞻动量 $\tilde{M}_t = G_t + \beta\, M_{t-1}$，再更新 $M_t = \beta\, M_{t-1} + G_t$（$M_0 = 0$）。Muon 默认用 Nesterov 版本，因为作者报告它在他们测试过的所有情况中都略优于普通 SGD-momentum。[C3] 动量在正交化之前加入。
    3. 对动量矩阵做谱范数归一化预处理 $X = \tilde{M}_t / (\|\tilde{M}_t\|_F + \varepsilon)$。
    4. 做 5 步 NS 迭代正交化，得到 $O_t \approx U V^\top$（奇异值接近 1）。
    5. 参数更新 $W_{t+1} = W_t - \eta\, O_t$。
    代码：Muon 一步完整更新（伪代码）

    以下是伪代码，不是 Python。它展示 Muon 对单个二维权重矩阵的一步更新。

    输入：权重矩阵 W_t，当前梯度 G_t，上一步动量 M_{t-1}，
      动量系数 β，学习率 η，NS 系数 (a,b,c)，NS 步数 T=5，ε=1e-7
状态：动量缓冲 M（初始为 0）

# 第 1 步：Nesterov 前瞻动量
M̃_t ← G_t + β · M_{t-1}        # 前瞻动量（用于正交化）
M_t ← β · M_{t-1} + G_t        # 更新动量缓冲（供下一步使用）

# 第 2 步：谱范数归一化
X ← M̃_t / (‖M̃_t‖_F + ε)
若 rows(X) > cols(X)：X ← Xᵀ   # 保证 m ≤ n

# 第 3 步：T 步 Newton-Schulz 迭代
重复 T 次：
    A ← X · Xᵀ
    B ← b·A + c·(A·A)
    X ← a·X + B·X
若之前做过转置：X ← Xᵀ         # 转回原形状
O_t ← X                        # 正交化后的更新矩阵

# 第 4 步：参数更新
W_{t+1} ← W_t - η · O_t

输出：更新后的 W_{t+1} 与动量 M_t

    关键在于第 2 步与第 4 步的组合：动量在正交化之前加入。这不是任意选择——作者报告使用动量对最佳经验性能是必要的，且 Nesterov 版本略优。前瞻动量 $\tilde{M}_t$ 是被正交化的对象，最终的更新方向是 $O_t \approx UV^\top$ 而非原始动量 $M_t$。

    与 SGD-momentum、AdamW 的几何区别

    三者改变的是更新方向的几何结构，而非简单的学习率缩放：

    优化器更新方向各奇异值方向步长几何结构
    SGD-momentum$M_t$（动量矩阵）正比于奇异值大小大奇异值方向更新猛、小方向更新不足
    AdamW逐坐标归一化的动量按元素二阶矩缩放不考虑矩阵整体方向结构
    Muon$O_t \approx UV^\top$（正交化后）各方向趋于均等（奇异值接近 1）矩阵级正交化，方向间相对尺度被重整

    SGD-momentum 直接用 $M_t$ 更新，各奇异值方向步长正比于奇异值大小——大方向更新过猛、小方向更新不足（回到动量更新矩阵条件数高的问题）。AdamW 逐坐标归一化（按元素二阶矩缩放每个参数），它不看矩阵整体的方向结构。（AdamW 是逐坐标自适应学习率加权重衰减的优化器，本文只用其作为对照。）Muon 对整个矩阵做正交化，改变的是方向间的相对尺度：把各奇异值拉平到接近 1，使各方向步长均等。

    与 Shampoo 的关系

    Muon 可视为"无累积 Shampoo"。Shampoo 是二阶预条件优化器，去除其 preconditioner accumulation 后，更新经 SVD 展开等价于正交化梯度：[C6]

    $$(G_t G_t^\top)^{-1/4} G_t (G_t^\top G_t)^{-1/4} = UV^\top.$$

    补充：Shampoo 无累积版本等价于 UV^T

    设 $G = USV^\top$，则 $G G^\top = US^2U^\top$，$G^\top G = VS^2V^\top$。展开：

    $$(G G^\top)^{-1/4} = (US^2U^\top)^{-1/4} = US^{-1/2}U^\top,$$

    $$(G^\top G)^{-1/4} = (VS^2V^\top)^{-1/4} = VS^{-1/2}V^\top.$$

    代入完整更新：

    $$(US^{-1/2}U^\top)(USV^\top)(VS^{-1/2}V^\top) = U \cdot S^{-1/2} \cdot S \cdot S^{-1/2} \cdot V^\top = U \cdot I \cdot V^\top = UV^\top.$$

    中间用了 $U^\top U = I$、$V^\top V = I$（正交矩阵性质）以及 $S^{-1/2} \cdot S \cdot S^{-1/2} = I$（对角矩阵可交换）。结果就是奇异值全置 1 的 $UV^\top$，与正交化目标一致。

    所以 Muon 与无累积 Shampoo 的更新方向在数学上等价。[F6] 区别在于：Muon 在正交化之前加入 momentum（Shampoo 不加）；Muon 用 Newton-Schulz 迭代替代 Shampoo 的逆四次根 $(GG^\top)^{-1/4}$ 计算，从而更高效、可在 bfloat16 下运行。

    工程开销与外部证据

    NS 迭代的 FLOP 开销很低。对 $n \times m$ 矩阵（$m \le n$），每步 NS 迭代约需 $2(2nm^2 + m^3)$ matmul FLOPs，总开销上界为 $T \cdot m / B$（$T=5$ 为迭代步数，$B$ 为 batch size）。在典型 LM 训练场景下 FLOP 开销低于 1%：[N8] NanoGPT speedrun（$m=768$，$B=524288$）约 0.7%，Llama 405B（$m=16384$，$B=16\text{M}$）约 0.5%。

    Muon 的主要外部证据来自竞争性训练任务 NanoGPT speedrun（以 FineWeb 数据集训练 NanoGPT 达到 val loss 3.28 为目标）：[N6, N7] 2024-10-15 从 AdamW 切换到 Muon 首次创造训练速度记录，提速 35%；此后产生的 12 个新记录由 7 位不同研究者创造，Muon 在所有记录中保持为优化器选择。扩展验证中，用 8 张 H100 训练 1.5B 参数 transformer 达到 GPT-2 XL 级 HellaSwag 性能，Muon 需 10 小时而 AdamW 需 13.3 小时；[N9] CIFAR-10 训练至 94% 准确率的速度记录从 3.3 A100-seconds 提升到 2.6 A100-seconds。[N10] 这些是外部事实数字，说明 Muon 在竞争性任务中的表现，不直接构成机制结论。

    Muon 的适用边界——哪些参数用 Muon，哪些仍用 AdamW

    Muon 并非全量替换 AdamW 的"更好版本"。它改变的是更新方向的几何结构，仅适用于特定参数类型。[C2] 训练一个含 Muon 的网络时，参数按以下方式分组：

    参数类型典型形状优化器原因
    隐藏层线性层权重$[\text{dim}, \text{dim}]$Muon二维矩阵，正交化使其各方向均等更新
    卷积核（展平后三维）$[\text{out}, \text{in}\cdot k^2]$Muon展平为二维后适用
    bias、LayerNorm scale/shift$[\text{dim}]$ 或标量AdamW一维参数无法定义"奇异值方向"，正交化无意义
    embedding 层$[\text{vocab}, \text{dim}]$AdamWmodular norm theory 理论支持不同优化动力学
    输出层（lm_head/分类头）$[\text{dim}, \text{vocab}]$AdamW经验结论，无理论解释

    embedding 层用 AdamW 有理论支持：modular norm theory（Large et al. 2024）表明 embedding 层的优化动力学应当与其他层不同。输出层用 AdamW 则是纯经验结论——作者明确指出这"似乎不遵循理论，而是由经验驱动"。[C2] 本文只引用 modular norm theory 的结论，不展开其推导。

    QKV 应分开应用

    训练 transformer 时，Muon 应分别应用于 Q、K、V 三个投影矩阵，而非合并为单一 QKV 矩阵后统一应用。[C7] 这是 Vlado Boza 首先展示的经验结果：transformer 实现常把 QKV 参数化为一个输出再分割的单一线性层，但对其统一应用 Muon 效果不如分开应用。

    RMS 对齐缩放因子

    正交化后的更新 $O_t \approx UV^\top$ 的各奇异值接近 1，但不同形状矩阵的"每元素平均更新幅度"（update RMS）不同。为了让 Muon 的 update RMS 与 AdamW 一致（便于复用 AdamW 调好的学习率与权重衰减），Moonshot AI 提出了 RMS 对齐缩放因子：[F7]

    $$\gamma = 0.2 \cdot \sqrt{\max(m, n)}.$$

    更新式变为 $W_{t+1} = W_t - \eta\, \gamma\, O_t$。这个缩放因子的来源是正交化矩阵的 RMS 性质。矩阵 $W \in \mathbb{R}^{n \times m}$ 的 RMS 定义为 $\|W\|_F / \sqrt{nm}$。对满秩矩阵 $UV^\top$（秩 $r = \min(m,n)$）：

    $$\operatorname{RMS}(UV^\top) = \frac{\|UV^\top\|_F}{\sqrt{nm}} = \sqrt{\frac{r}{nm}} = \sqrt{\frac{1}{\max(m,n)}}.$$

    补充：RMS(UVᵀ) = √(1/max(m,n))

    设 $U \in \mathbb{R}^{n \times r}$，$V \in \mathbb{R}^{m \times r}$，$U^\top U = I$，$V^\top V = I$（列正交），$r = \min(m,n)$。则 $UV^\top \in \mathbb{R}^{n \times m}$，其 Frobenius 范数平方为：

    $$\|UV^\top\|_F^2 = \sum_{i=1}^{n}\sum_{j=1}^{m} (UV^\top)_{ij}^2 = \sum_{i,j} \left(\sum_{k=1}^{r} U_{ik} V_{jk}\right)^2.$$

    展开平方并交换求和顺序：

    $$= \sum_{k=1}^{r} \sum_{l=1}^{r} \left(\sum_{i=1}^{n} U_{ik} U_{il}\right) \left(\sum_{j=1}^{m} V_{jk} V_{jl}\right).$$

    由 $U^\top U = I$ 知 $\sum_i U_{ik} U_{il} = \delta_{kl}$（克罗内克 δ），同理 $\sum_j V_{jk} V_{jl} = \delta_{kl}$。所以：

    $$= \sum_{k=1}^{r} \delta_{kk} \cdot \delta_{kk} = \sum_{k=1}^{r} 1 = r.$$

    因此 $\|UV^\top\|_F = \sqrt{r}$，$\operatorname{RMS}(UV^\top) = \sqrt{r}/\sqrt{nm} = \sqrt{r/(nm)}$。满秩时 $r = \min(m,n)$，化简得 $\sqrt{1/\max(m,n)}$。

    所以 $0.2 \cdot \sqrt{\max(m,n)} \cdot O_t$ 的 RMS 为 $0.2 \cdot \sqrt{\max(m,n)} \cdot \sqrt{1/\max(m,n)} = 0.2$，与 AdamW 的典型 update RMS（约 0.2–0.4）对齐。此缩放因子是 Moonshot 改进，非 Keller Jordan 原始博客内容；PyTorch torch.optim.Muon（2.9 起内置）提供该选项（adjust_lr_fn='match_rms_adamw'），默认仍为 Keller 原始缩放（adjust_lr_fn='original'）。[F7] 对前面的 2×2 例子，$\gamma = 0.2 \cdot \sqrt{2} \approx 0.283$，基线系数收敛后 $O_t \approx I$ 的 RMS 约 0.707，缩放后约 0.2。

    最后回顾全文要点，回扣开篇的四个学习目标。第一，Muon 每一步对动量更新矩阵做 Newton-Schulz 正交化，把奇异值拉平到接近 1，使各奇异值方向获得均等更新尺度，改善二维权重矩阵的条件数过高问题。第二，Newton-Schulz 迭代用五次多项式 $\phi(x)=ax+bx^3+cx^5$ 对奇异值施加变换，在 SVD 下矩阵迭代退化为标量迭代，只用矩阵乘法、可在 bfloat16 下运行。第三，Muon 与 SGD-momentum、AdamW 的关键区别在更新方向的几何结构：SGD-momentum 步长正比于奇异值大小，AdamW 逐坐标归一化不看矩阵整体方向，Muon 对整个矩阵做正交化重整方向间相对尺度。第四，Muon 仅适用于隐藏层二维权重矩阵（线性层权重、卷积核展平），embedding 层用 AdamW 有 modular norm theory 理论支持，输出层用 AdamW 是纯经验结论；QKV 应分开应用；Moonshot 的 RMS 对齐缩放因子使 Muon 可复用 AdamW 调好的超参。

    教学解释与类比边界

    "正交化把奇异值拉平到接近 1"只解释 SVD 下奇异值被多项式映射这一局部关系，不保证正交化对任意矩阵都收敛——收敛要求初始奇异值落在 $\phi$ 的收敛域（由谱范数归一化保证）。"放大稀有方向、抑制主导方向"是作者推测（speculate），不作为已证结论。"无累积 Shampoo"的定位只解释 Muon 与去除累积的 Shampoo 在更新方向上的等价性，不覆盖 Shampoo 的完整 preconditioner accumulation 机制。

    教学简化及其限制

    简化做法是用 numpy 的 float64 计算。可推出：NS 迭代的奇异值拉平机制与计算精度无关。不可推出：bfloat16 下的精确数值行为与 float64 完全一致（真实工程用 bfloat16 在 GPU 上运行，精度行为有差异但机制一致）。

    简化做法是只展示 2×2 对角矩阵。可推出：NS 迭代机制对任意大小矩阵相同。不可推出：大矩阵的收敛速度与 2×2 一致（真实训练中矩阵远大于此，如 $768 \times 768$ 或更大）。

    简化做法是伪代码与代码只展示单步更新与正交化。可推出：Muon 的核心更新机制。不可推出：完整训练流程（未展示学习率调度、权重衰减除 RMS 对齐外、梯度裁剪等工程细节，不能直接作为生产训练代码）。
