Quantile Balancing

Quantile Balancing 是一种混合专家的负载均衡方法：从一次前向传播的路由分数分位数直接算出每个专家的偏置，让每个专家收到目标数量的 token，替代固定步长的偏置更新。

用分位数一次算准偏置

Quantile Balancing（QB）是一种混合专家模型里调负载均衡的方法。混合专家（MoE）的每一层有若干个并列的专家子网络，一个 token（模型处理的一段文本的单位）不是走全部专家，而是由一个路由层给它算出一组分数，只送给分数最高的几个专家。QB 给每个专家配一个偏置，加在路由分数上参与选专家，让每个专家收到的 token 数量大致相等。给定一个 batch（一次一起处理的一批 token）的 $m$ 个 token、$n$ 个专家、每个 token 选 $k$ 个，均衡时每个专家应收到这个 batch 的 $k/n$ 比例，约 $mk/n$ 个 token。QB 的偏置不是一步步试出来的，而是用一次前向（把输入算成输出的那一遍）得到的这批路由分数一次算出：先给每个 token 定一个阈值（它那一行带偏置的分数里第 $k+1$ 高的值），把每个专家的分数减去对应阈值后取分位数（一组数里指定比例以下的阈值）、取负，再减掉全体偏置的均值。

固定步长在大规模更难均衡

偏置能调负载，因为把一个专家的偏置调高，它就更可能被选上、收到更多 token。旧的做法按每个专家实际负载与目标负载的差，每步给它加减一个固定的小步长 $\gamma$：少了就加、多了就减。这样只走了固定一小步，步长也不好取：太大来回震荡，太小时每步能纠正的量太小、收敛慢。专家池规模变大时，把负载维持均衡就更难，不均衡的路由会拖慢专家并行训练（把不同专家放到不同设备上的训练方式）。

四步得到新偏置

记 token $i$ 对专家 $j$ 的分数为 $s_{i,j}$，当前偏置为 $b$，$\alpha_i$ 是 token $i$ 的第 $k+1$ 高分。QB 从一次前向传播（把输入算成输出的那一遍）算出下一组偏置：先对带偏置的分数 $s_{i,j}+b_j$ 取第 $k+1$ 大的值，作为 token $i$ 的阈值 $\alpha_i$；再算每对 $(i,j)$ 的差值 $s_{i,j}-\alpha_i$，记作 margin；然后对每个专家 $j$，把它那一列的 margin 按从大到小排，取第 $\lfloor mk/n\rfloor+1$ 个，取负得到 $\tilde b_j$；最后减去全体 $\tilde b_j$ 的均值，得到新偏置。整个更新只用一次前向得到的这批分数，不需要另设学习率（优化时每步走多远的那类系数）。
