# DeepSeek-V4.1-Flash 术语表

## 模型与结构

| 术语 | 英文/缩写 | 首次出现 | 含义 |
|---|---|---|---|
| 主干 | backbone | 第 1 章 | 40 层语言 Transformer；不含 Engram 表、视觉编码器与 DSpark |
| 因果编码器 | causal encoder | 第 2 章 | 主干前 20 层（层 0–19）；产出 $H_{L/2}$ 供解码器构造全局 KV |
| 解码器 | decoder | 第 2 章 | 主干后 20 层（层 20–39）；全局 KV 由 $H_{L/2}$ 投影而来 |
| CED | Causal Encoder–Decoder | 第 2 章 | 让解码器全局 KV 前移到编码器末层隐状态的结构设计（报告 §2.2） |
| CSA2 | Compressed Sparse Attention 2 | 第 1 章 | 管理全局 KV 的注意力方案：压缩 + 跨层共享 + Top-K 复用 |
| 滑动窗口注意力 | SWA, sliding window attention | 第 2 章 | 每个 query 只看最近 $n_{\text{win}}$ 个位置的原始 KV；$n_{\text{win}} = 128$ |
| 窗口 | window | 第 2 章 | 上述 $n_{\text{win}}$ 个位置构成的环形缓冲 |
| 主 KV | main KV | 第 1 章 | 压缩后的全局 KV 条目；与"窗口 KV"相对 |
| 窗口 KV | SWA KV | 第 1 章 | 未压缩的原始 KV，保持 FP8 |
| 压缩比 | compress ratio, $r$ | 第 1 章 | 一个压缩条目覆盖的 token 数；本文取 1 或 2 |
| 压缩条目 | compressed entry | 第 1 章 | 一组 $r$ 个 token 池化出的一个 KV 条目 |
| 组 | group | 第 1 章 | 编号 $j$ 的压缩条目所覆盖的 token 区间 $[jr,(j+1)r)$ |
| 索引器 | indexer | 第 3 章 | 给压缩条目打分的旁路注意力，产出 Top-K 位置 |
| 索引器 K | indexer K | 第 1 章 | 由压缩条目投影来的键，供索引器打分；FP4 存储 |
| 索引分 | index score, $I_{q,j}$ | 第 3 章 | query $q$ 对压缩条目 $j$ 的打分 |
| Top-K | Top-K indices | 第 3 章 | 每个 query 保留的压缩条目下标集合；$K = 512$ |
| 候选池 | candidate pool | 第 3 章 | 建池层选出的块所覆盖的位置集合；$2048 \times 8 = 16384$ 个位置 |
| 块 | block | 第 3 章 | 候选选择的单位；块分取块内最大索引分；块大小 8 |
| Full / Reindex / Reuse | — | 第 3 章 | CSA2 的三种静态层模式（见第 3 章） |
| 稀疏注意力 | sparse attention | 第 3 章 | 只在选中槽位集合上做注意力；窗口槽位与压缩槽位拼进同一次调用 |
| 注意力汇聚点 | attention sink | 第 3 章 | 每个头一个可学习标量，只加在注意力分母上 |
| 超连接 | HC / mHC | 第 4 章 | 残差流按 4 份并行携带、用三套系数读写；mHC 让混合矩阵近似双随机 |
| Sinkhorn 迭代 | Sinkhorn–Knopp | 第 4 章 | 行列交替归一化，把矩阵逼近双随机；本文 20 轮，末步列方向 |
| 路由专家 | routed expert | 第 4 章 | 384 个专家中按打分选出的 6 个 |
| 共享专家 | shared expert | 第 4 章 | 每层 1 个、每 token 必过的专家 |
| 激活参数 | activated parameters | 第 4 章 | 处理一个 token 时实际参与计算的参数量 |
| Engram | — | 第 5 章 | n-gram 哈希查表的条件记忆模块，插在层 1、14 |
| DSpark | — | 第 5 章 | 块式推测解码的 draft 头；3 个 MTP 块、每块 5 个草稿位置 |
| MTP | multi-token prediction | 第 5 章 | 一次前向预测多个后续 token 的训练/推理结构 |

## 配置与量化

| 术语 | 英文/缩写 | 首次出现 | 含义 |
|---|---|---|---|
| FP4 / E2M1 | — | 第 1 章 | 4 位浮点，1 位符号 + 2 位指数 + 1 位尾数；可表示 $\{0,0.5,1,1.5,2,3,4,6\}$ 及其相反数 |
| MXFP4 | — | 第 1 章 | 微缩放格式：每 16 个通道共享一个 E4M3 scale |
| E4M3 scale | — | 第 1 章 | 8 位浮点 scale，最大值 448 |
| FP8 / E4M3 | — | 第 1 章 | 8 位浮点，最大值 448；窗口 KV 与索引器激活用 |
| 每 16 通道一个 scale | block-16 scaling | 第 1 章 | 主 KV 的缩放粒度；决定每条目 32 个 scale |
| ue8m0 | — | 第 1 章 | 2 的幂次 scale 格式（FP8 块量化用） |

## 符号

| 符号 | 含义 | 首次出现 |
|---|---|---|
| $L$ | 主干层数，$L=40$ | 第 2 章 |
| $H_{l}$ | 第 $l$ 层的隐状态 | 第 2 章 |
| $H_{L/2}$ | 编码器末层隐状态（参考实现中即层 20 的注意力输入） | 第 2 章 |
| $r$ | 压缩比 | 第 1 章 |
| $j$ | 压缩条目（组）编号 | 第 1 章 |
| $i$ | query 的序列位置（prefill，0 起） | 第 3 章 |
| $s$ | 解码步编号 | 第 3 章 |
| $q_h, k_j$ | 索引器第 $h$ 头的 query、条目 $j$ 的键 | 第 3 章 |
| $w_{q,h}$ | 索引器第 $h$ 头的权重 | 第 3 章 |
| $K$ | 每 query 保留的压缩条目数，$K=512$ | 第 3 章 |
| $n_{\text{win}}$ | 窗口大小，$n_{\text{win}}=128$ | 第 2 章 |
| $d$ | 注意力头维（本文指 latent 维 512 或索引头维 128，按上下文说明） | 第 3 章 |
| $m$ | 稀疏注意力在线 softmax 的行最大值 | 第 3 章 |
| $\sigma$ | sigmoid 函数 | 第 4 章 |
| $\epsilon$ | 数值稳定小量（mHC 用 $10^{-6}$，路由归一化用 $10^{-20}$） | 第 4 章 |

## 记号约定

- 层号从 0 开始（层 0 是主干第一层）；报告用 1 起的 $L/2$ 表述时按上下文换算。
- 压缩条目与组的编号从 0 开始；"位置"一律指 token 在序列中的下标。
- 字节一律用 B（byte）；参数量用 B（billion）时写全"十亿"以免与字节混淆。
