    语言模型预训练（Pretraining）：在大语料上最小化下一 token 交叉熵

    主要依据：Radford et al., Language Models are Unsupervised Multitask Learners（OpenAI 2019）§2 式 (1)、§3.1；Touvron et al., "LLaMA"（arXiv:2302.13971）§7；Ouyang et al., "InstructGPT"（arXiv:2203.02155）§3.1；Zhang et al., "Instruction Tuning for Large Language Models: A Survey"（arXiv:2308.10792）§1；Goodfellow et al., Deep Learning §5.5。

    手机输入法在打了「今天天气真」之后给出「好」的概率远高于「量子」——它内部就是一个微型语言模型。把这件事做到极致：给任何前文都输出下一个 token 在整个词表上的概率分布，并在大规模语料上练成这个能力——这就是语言模型预训练。本文说明语言模型是什么、一条文本的概率如何逐 token 分解、预训练的训练目标为什么是「最小化下一 token 交叉熵」，以及预训练产出的基座模型为什么还需要后训练。

    核心问题

    1. 语言模型输出的是什么？

      解答：token 序列上的概率分布，实际接口是「前文到下一 token 分布」

      语言模型是词、token 或字符序列上的概率分布；实际使用形式是 next token prediction：给定任意前文，输出下一个 token 在整个词表上的概率分布。「生成一句话」不是一次完成的——模型每次只给一个分布，整句由逐 token 预测与采样合成。完整论证见「1. 语言模型是什么」。

    2. 一条序列的概率如何分解成逐 token 预测？

      解答：链式分解 $p(s_1,\dots,s_n)=\prod_i p(s_i\mid s_{<i})$

      由概率乘法公式，联合概率等于各步条件概率连乘：$p(s_1,\dots,s_n)=\prod_{i=1}^{n}p(s_i\mid s_1,\dots,s_{i-1})$。序列里每个位置对应一次「给定前文预测下一 token」，整个序列的概率是这些条件概率的乘积；训练损失因此也逐 token 可分。手算见「2. 一条文本的概率如何逐 token 分解」。

    3. 预训练的训练目标是什么，为什么它同时是「最小化交叉熵」和「最大化似然」？

      解答：语料上最小化下一 token 平均交叉熵；取负对数后两种说法是同一件事

      预训练在无标注语料上最小化每个位置「下一 token 的交叉熵」的平均值。监督信号来自文本本身：前文是输入、下一 token 是标签（自监督）。序列似然是条件概率连乘，取负对数后恰好是逐 token 损失之和——所以「最大化似然」与「最小化交叉熵」是同一个目标的两种表述。完整论证见「3. 预训练的目标」。

    4. 预训练产出什么，为什么还需要后训练？

      解答：产出基座模型；其默认行为是续写而非按指令回答

      预训练结束得到基座模型：具备广泛的续写与语言能力，但训练目标（词预测误差）与用户目标（有帮助且安全地遵循指令）存在错位，基座对指令输入的自然反应是按语料风格续写。后训练从 SFT 开始：在人类示范数据上继续微调预训练模型。完整论证见「4. 预训练产出基座模型」。

    1. 语言模型是什么

    语言模型的正式定义是 token 序列上的概率分布[C1]：给每个可能的序列一个概率，常见序列概率高、罕见组合概率低。token 是文本的最小处理单元（词、子词或字符，由分词器决定），词表是全部 token 的集合——实际系统的词表规模以万计（GPT-2 的词表为 $50{,}257$ 个 token[C7]）。

    「一个所有序列上的分布」没法直接使用，语言模型的实际接口是条件形式：给定任意前文，输出下一个 token 在词表上的概率分布。这个任务常被表述为 next token prediction[C1]。一个训练好的模型面对前文「今天天气真」时，会给「好」「不错」「冷」等 token 较高概率、给「量子」极低概率——每个 token 各得一个概率，全体加起来等于 $1$。

    需要立即澄清一个常见错觉：模型不是「一次生成一句话」。它每次只输出一个分布；生成时从中取出一个 token，拼进前文，再对新的前文输出下一个分布，如此重复。「整句」的概率与生成都由这个逐步过程承担——这正是下一章链式分解的内容。

    构造示例。设一个五 token 的玩具词表 {天, 气, 真, 好, 冷}（每个汉字视为一个 token）。面对前文「天」，模型输出的下一 token 分布可以是：

    下一 token概率
    气$0.80$
    真$0.10$
    好$0.05$
    冷$0.04$
    天$0.01$

    概率合计为 $1$。这就是语言模型的全部输出形态：一个前文，一张词表上的分布表。

    本章问题

    1. 语言模型输出的是什么？「生成一句话」和「每次只预测下一个 token」是什么关系？

      解答：输出是词表上的概率分布；整句由逐 token 过程合成

      语言模型是 token 序列上的概率分布，实际接口是 next token prediction：给定前文，输出下一个 token 在整个词表上的概率分布（合计为 $1$）。生成一句话是重复执行「输出分布、取一个 token、拼进前文」的过程，不是一次性输出；整句的概率由下一章的链式分解逐 token 计算。

    2. 词表和 token 分别是什么？

      解答：token 是最小处理单元，词表是全部 token 的集合

      token 是文本被切分后的最小处理单元，可以是词、子词或字符，由分词器决定；词表是模型认识的全部 token 的集合。模型在每个位置输出的分布定义在词表上——词表有多大，分布就覆盖多少个取值。本文的构造示例用五个汉字的词表，真实系统以万计（GPT-2 为 $50{,}257$）。

    2. 一条文本的概率如何逐 token 分解

    现在回答核心问题：只知道「每次预测下一个 token」，怎么得到「一整条文本的概率」？答案是概率的乘法公式：联合概率等于条件概率的逐步连乘。GPT-2 论文把这个分解写成 §2 的式 (1)[C2]：

    $$p(s_1, \dots, s_n) = \prod_{i=1}^{n} p(s_i \mid s_1, \dots, s_{i-1}),$$
    • $s_1, \dots, s_n$：一条 $n$ 个 token 的文本；
    • $p(s_i \mid s_1, \dots, s_{i-1})$：给定前文时，下一个 token 是 $s_i$ 的条件概率——正是语言模型每个位置的输出；
    • 整条文本的概率 = $n$ 次逐 token 预测的概率连乘。

    论文同时指出，这个分解「使 $p(x)$ 的采样与估计可行」[C2]：序列级的量全部化归到逐 token 的条件概率上，模型只需要（也只能够）表达每个位置的条件分布。

    构造示例（沿用五 token 词表）。三个 token 的文本「天气真」，各步条件概率人为设定（选取便于手算）：

    位置 $i$前文预测的 token $s_i$条件概率 $p(s_i\mid s_{<i})$该 token 的损失 $-\ln p$
    $1$（句首）天$0.25$$1.3863$
    $2$天气$0.80$$0.2231$
    $3$天气真$0.60$$0.5108$

    三个条件概率连乘得到序列概率：

    $$p(\text{天气真}) = 0.25 \times 0.80 \times 0.60 = 0.12.$$

    每个 token 的损失 $-\ln p(s_i\mid s_{<i})$ 是交叉熵在单个位置上的取值，其定义与计算见 交叉熵。三个位置的损失之和为 $1.3863+0.2231+0.5108\approx 2.1203$，除以 $3$ 得平均 $0.7068$。可以验证：对连乘取负对数，乘法变加法，恰好等于逐 token 损失之和：

    $$-\ln p(\text{天气真}) = -\ln 0.12 \approx 2.1203.$$

    这个「乘变加」正是下一章训练目标的来源。

    展开：为什么联合概率能写成条件概率连乘

    这是概率乘法公式 $p(A,B)=p(A)\,p(B\mid A)$ 的重复使用：$p(s_1,s_2)=p(s_1)\,p(s_2\mid s_1)$；再乘一步 $p(s_1,s_2,s_3)=p(s_1,s_2)\,p(s_3\mid s_1,s_2)=p(s_1)\,p(s_2\mid s_1)\,p(s_3\mid s_1,s_2)$；一般地推广到 $n$ 步。每一步都只是「前文的联合概率 $\times$ 给定前文的下一 token 条件概率」，不需要任何额外假设。

    本章问题

    1. 为什么联合概率能写成条件概率连乘？

      解答：概率乘法公式的重复使用

      由 $p(A,B)=p(A)\,p(B\mid A)$ 逐步代入：先拆出第一个 token，再拆第二个，依此类推，得 $p(s_1,\dots,s_n)=\prod_i p(s_i\mid s_1,\dots,s_{i-1})$（GPT-2 式 (1)）。分解不依赖任何模型假设；语言模型的工作只是把其中每个条件概率参数化。

    2. 给定各步条件概率，一条 3 token 文本的概率和逐 token 损失怎么算？

      解答：概率连乘、损失求和，两者差一次负对数

      构造示例「天气真」：条件概率 $0.25, 0.80, 0.60$ 连乘得序列概率 $0.12$；逐 token 损失为 $-\ln 0.25=1.3863$、$-\ln 0.80=0.2231$、$-\ln 0.60=0.5108$，总和 $2.1203$（平均 $0.7068$）。负对数把乘法变加法：$-\ln 0.12\approx 2.1203$，与逐 token 损失之和一致。

    3. 预训练的目标——在大语料上最小化下一 token 交叉熵

    上一章把「一条文本的似然」化成了「逐 token 条件概率的连乘」。预训练直接利用这一点：在语料（大规模文本集合）上训练模型参数 $\theta$，使语料中实际出现的文本获得尽可能高的概率。形式化地，训练目标是最小化语料上下一个 token 的平均交叉熵：

    $$\mathcal{L}(\theta) = -\,\mathbb{E}_{\text{语料}}\big[\log p_\theta(s_i \mid s_{
  • $\theta$：模型参数；
  • $s_{<i}$：位置 $i$ 的前文；
  • 期望按语料中的位置取平均——语言建模的结果通常以「每个预测单元的平均负对数概率」的缩放或指数化形式报告（预测单元通常是字符、字节或词）[C3]。

    • 这个目标有两种等价的说法。「最小化交叉熵」来自逐 token 损失的视角（每个位置是一次以词表为类别集的预测，见 交叉熵）。「最大化似然」来自序列视角：语料似然是所有序列概率的连乘，最大化它等价于最大化 $\log$ 似然，也就是最小化逐 token 负对数概率之和。教材的等价链把两种说法焊接在一起：最大似然在实现上即最小化负对数似然，而任何负对数似然损失都是交叉熵[C6]。

    「预训练是无监督的」经常被误解为没有学习信号。恰恰相反：监督信号来自文本本身——把每个位置的前文当输入、真实的下一个 token 当标签，数据不用任何人工标注。这种范式称为自监督。语料的规模因此可以远超任何人工标注数据集。

    把构造示例放进语料视角：「天气真」若出现在语料里，它贡献三个训练位置——模型看到「（句首）」学预测「天」，看到「天」学预测「气」，看到「天气」学预测「真」。整个语料有多少个 token，就有多少个这样的位置，每个位置都产生一次交叉熵与一次梯度。预训练就是在海量位置上重复「下一 token 预测」。

    本章问题

    1. 预训练的损失是什么？「无标注」从哪来？

      解答：语料上下一 token 的平均交叉熵；监督信号由文本自身提供

      损失为 $\mathcal{L}(\theta)=-\mathbb{E}_{\text{语料}}[\log p_\theta(s_i\mid s_{<i})]$：每个位置上前文是输入、真实下一 token 是标签，损失是该 token 概率的负对数按语料位置平均。「无标注」指不需要人工标签——监督信号（下一 token）由文本自身携带（自监督），因此语料可以是无标注的海量文本。

    2. 为什么这个目标既是「最小化交叉熵」又是「最大化似然」？

      解答：序列似然连乘取负对数后恰是逐 token 损失之和

      语料似然是各序列概率的连乘，序列概率又按链式分解为条件概率连乘。取 $\log$ 后连乘变连加，最大化似然等价于最大化 $\sum\log p_\theta(s_i\mid s_{<i})$，即最小化其相反数——逐 token 负对数概率之和，也就是交叉熵之和（按预测单元平均后即训练损失）。教材表述：最小化 NLL 等价于最小化交叉熵。两种说法指向同一个最优化问题。

    4. 预训练产出基座模型，行为对齐交给后训练

    预训练结束时得到的是基座模型（base model）：它有广泛的续写能力、事实知识和语言技能，但它的默认行为是续写——按训练语料的风格接着写下去。给基座模型一句「请把这句话翻译成法语」，它很可能接着生成另一条类似的请求或更多文本，而不是给出译文：在它的训练分布里，这句请求后面跟着的通常是更多网页内容。

    问题不在能力，而在目标错位。综述的表述是：语言模型通常被训练为在大语料上最小化上下文词预测误差，而用户想要的是模型「遵循指令、有帮助且安全」[C5]。预测下一 token 与按指令回答之间没有自动的桥梁。

    架桥的工作属于后训练，从 SFT（Supervised Fine-Tuning，监督微调）开始。InstructGPT 的流程描述是：标注者在输入分布上提供期望行为的示范，然后「用监督学习在这个数据上微调预训练 GPT-3 模型」[C4]。基座模型因此是整个后训练流程的起点：SFT 在它之上塑造「按指令回答」的行为，其细节见 SFT 监督微调。

    本章问题

    1. 预训练结束时得到什么？它默认会做什么？

      解答：基座模型；默认行为是按语料风格续写

      得到基座模型：具备广泛续写能力、事实知识与语言技能的通用模型。它的默认行为是续写——对指令输入的自然反应是接着生成语料风格的后续文本，而非按指令回答。这不是能力缺陷，而是训练目标（下一词预测）的直接产物：模型学到的是「前文之后通常跟着什么」。

    2. 为什么从预训练模型到「能用」的产品模型还需要后训练？

      解答：训练目标与用户目标错位，后训练负责行为对齐

      预训练目标是「在大语料上最小化上下文词预测误差」，用户目标是「模型遵循指令、有帮助且安全」——两者错位，基座模型不会自动按指令回答。后训练从 SFT 开始弥合：在人类示范数据上微调预训练模型（InstructGPT：标注者提供示范，「用监督学习在这个数据上微调预训练 GPT-3」），后续再用偏好优化继续调整。SFT 的机制见专门页面。

    构造示例

    • 五 token 词表 {天, 气, 真, 好, 冷}、前文「天」的分布、文本「天气真」的各步条件概率（$0.25/0.80/0.60$）均为构造数据，便于手算复算，不代表任何真实模型输出。序列概率 $0.12$、逐 token 损失 $1.3863/0.2231/0.5108$、总和 $2.1203$、平均 $0.7068$、$-\ln 0.12\approx 2.1203$ 均由 Python 计算后写入。

    辅助解释与类比边界

    • 「输入法联想下一个词」只用于给出「前文到下一 token 分布」的直观形态，帮助理解接口；它不涉及预训练的规模、语料构成与训练动态，正式定义以「token 序列上的概率分布」为准。
    • 「基座模型对翻译指令的续写反应」是由 C5 错位论断推演的解释性场景（训练分布中指令文本后常为普通网页文本），不是任何论文报告的实验观察；它只说明「续写默认行为与指令要求不匹配」这一局部关系。
    • 「海量位置各产生一次梯度」描述逐位置可分性与位置规模，不涉及实际的样本打包、梯度累积等工程机制。

    简化条件及其限制

    • 本页只讨论自回归（decoder-only）语言模型的预训练；掩码语言模型（BERT 式，完形填空式预训练）是另一范式，本页结论不适用。术语对照：本文「预训练」均指 next-token 预训练。
    • 模型内部结构（Transformer、注意力）全部作为黑盒处理：$p_\theta$ 只被当作「输出词表分布的参数化机器」。本页结论不依赖任何具体架构。
    • 构造示例直接给定条件概率，跳过「参数 $\to$ 分布」的计算；因此示例能验证分解与损失计算，不能验证训练本身的动态。
