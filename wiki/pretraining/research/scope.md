# 语言模型预训练 内容范围

## 1. 概念含义

- 概念名称：语言模型预训练
- 英文名称：language model pretraining
- 简要定义：在大规模无标注文本语料上，用「预测下一个 token」的交叉熵目标训练语言模型，得到的通用模型（基座模型）。
- 正式定义：语言模型是 token 序列上的概率分布，由链式分解 $p(s_1,\dots,s_n)=\prod_i p(s_i \mid s_1,\dots,s_{i-1})$ 参数化（GPT-2 §2.1 式 (1)）；预训练在语料上最小化下一 token 的平均负对数似然（交叉熵）。
- 本文采用的语境：decoder-only 自回归语言模型的预训练；这是 SFT 页的直接前置。

### 概念歧义处理

状态：已裁定。「预训练」在 NLP 历史上曾指 ELMo/BERT 式的编码器预训练（掩码语言模型），本页采用当前主流 LLM 语境的 next-token 预训练；两种范式的对比在术语对照处一句话说明，不展开（BERT 式属另一独立概念）。

### 包括什么

- 语言模型的定义：序列上的概率分布、next token prediction 表述
- 链式分解（自回归分解）：联合概率 = 条件概率连乘（GPT-2 式 (1)）
- 预训练目标：最小化下一 token 交叉熵 = 最大化语料似然（Goodfellow MLE 等价 + 实践表述）
- 手算：小词表上对两三个 token 的序列逐步分解与损失计算
- 预训练产出（基座模型）与后训练的关系定位：预训练给通用语言能力，行为对齐交给后训练（InstructGPT 三步法的起点表述；为 SFT 页服务）

### 不包括什么

- Transformer 架构与注意力机制：独立概念（wiki 已有相关页面亦不强制链接，因本页不依赖架构细节）；排除理由：不影响理解预训练目标
- 数据工程（语料清洗、去重、配比）：数据工程主题
- 缩放定律（scaling laws）：独立研究主题
- 掩码语言模型（BERT 式预训练）：另一预训练范式，只在术语对照提及
- 分词器（BPE 等）：工程细节，本页用「小词表」示例绕开

### 相邻概念

- SFT：预训练之后的监督微调；本页只在结尾定位，由 SFT 页展开
- 交叉熵：预训练的损失函数，前置概念页（`wiki/cross-entropy/`，本流程同批生成）
- 掩码语言模型/编码器预训练：术语对照一句话

## 2. 学习目标

### Q1：语言模型是什么？

- 完成答案：语言模型是 token 序列上的概率分布（LLaMA §7："Language models are probability distributions over sequences of words, tokens or characters"）；实际使用形式是「给定前文，输出下一个 token 在词表上的分布」，即 next token prediction。
- 为什么是核心目标：不懂语言模型的形态，预训练目标无从谈起。
- 依赖内容：概率分布、条件概率（常识级，页内最小说明）。

### Q2：一条序列的概率如何分解成逐 token 预测？

- 完成答案：链式分解 $p(s_1,\dots,s_n) = \prod_i p(s_i \mid s_{<i})$（GPT-2 式 (1) 原文引据）；每一步只预测下一个 token；手算一个 3 token 小例子（给定每步条件概率，算序列概率与逐 token 损失）。
- 为什么是核心目标：这是「预训练 = 下一 token 交叉熵」的数学基础。
- 依赖内容：条件概率、乘法公式（常识级）。

### Q3：预训练的训练目标是什么，为什么它同时是「最小化交叉熵」和「最大化似然」？

- 完成答案：在语料上最小化下一 token 的平均交叉熵 $-\mathbb{E}[\log p_\theta(s_i \mid s_{<i})]$；由 Goodfellow §5.5 的等价（MLE = 最小化 NLL = 最小化交叉熵）说明两种说法是同一件事；「无标注」指不需要人工标签——文本本身就是监督信号（下一 token 即标签）。
- 为什么是核心目标：这是预训练的定义性机制。
- 依赖内容：交叉熵概念页（链接）。

### Q4：预训练产出的模型是什么样的，为什么还需要后训练？

- 完成答案：产出基座模型：具备流畅续写与广泛语言能力，但行为是「续写语料」而非「按指令回答」；后训练（从 SFT 开始）在基座上继续训练以对齐行为（InstructGPT §3.1 Step 1："We then fine-tune a pretrained GPT-3 model on this data using supervised learning"；综述 §1 的错位表述）。
- 为什么是核心目标：给 SFT 页提供入口；不给这个定位，「预训练模型」只是一个孤立概念。
- 依赖内容：Q1–Q3。

## 6. 常见误解和适用边界

### 常见误解

1. 错误理解：预训练的「无监督」意味着没有学习信号。正确结论：监督信号来自文本本身——前文是输入、下一 token 是标签（自监督）；「无标注」指不需要人工标注。影响：Q3。
2. 错误理解：语言模型一次生成整句。正确结论：模型每次只输出下一 token 的分布，整句由逐 token 采样/分解合成（Q2 的链式分解正是这一点）。形成原因：产品级对话模型「一次给整段回答」的观感。影响：Q1、Q2。
3. 错误理解：预训练模型的参数里存着「检索到的语料」。正确结论：参数是分布的参数化，学到的是给前文条件下的预测规律，不是逐条存储文本。影响：Q4（此点只作定位性说明，不展开记忆机制研究）。
4. 错误理解：预训练后模型已经「会回答问题」。正确结论：基座模型的默认行为是续写；「按指令回答」是后训练（SFT 起）塑造的（InstructGPT 三步法定位）。影响：Q4。

### 适用边界

- 本页结论限于自回归（decoder-only）语言模型；掩码式预训练的结论不适用（术语对照处说明）。
- 「预训练 → 后训练」的分工是当前主流实践（InstructGPT 以来的范式），不是数学必然；正文以实践定位的措辞呈现。
