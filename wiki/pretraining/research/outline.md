# 语言模型预训练 文章大纲

## 1. 页面开头

开头场景：手机输入法的「联想下一个词」：打了「今天天气真」，输入法给出「好 60%、不错 25%、差 5%……」。把这个能力放大：模型对任何前文都能给出整个词表上的下一个 token 分布，并在几乎全网文本上练成——这就是语言模型预训练。

随后：简要定义、核心问题（4 条学习目标）、首个示例预告（贯穿：一个 8 token 小词表 + 一句 3 token 文本）、过渡到第 1 章。

## 2. 章节设计

### 第 1 章：语言模型是什么（回答 Q1）

- 章节问题：
  - 问题 1：语言模型输出的是什么？
  - 问题 2：「生成一句话」和「每次只预测下一个 token」是什么关系？
- 完成答案要点：
  - 问题 1：token 序列上的概率分布（C1 原文）；实际接口：给定前文，输出词表上的分布；词表概念。
  - 问题 2：模型每次只输出下一 token 分布；整句的概率由分解承担，生成由逐 token 进行（误解 2 的定位，采样一词不展开）。
- 对应范围：Q1 / C1。
- 正文要点：输入法联想类比 → 形式化：前文 → 分布 → 词表。
- 表达材料及职责：小词表 + 一个前文对应分布的示意（HTML 表格）。
- 前置知识安排：条件概率最小说明。

### 第 2 章：一条文本的概率如何逐 token 分解（回答 Q2）

- 章节问题：
  - 问题 1：为什么联合概率能写成连乘？
  - 问题 2：给定每步条件概率，一句 3 token 文本的概率和逐 token 损失怎么手算？
- 完成答案要点：
  - 问题 1：概率乘法公式逐次展开（$p(s_1,s_2,s_3)=p(s_1)p(s_2|s_1)p(s_3|s_1,s_2)$）；GPT-2 式 (1) 原文引据（F1，C2）；该分解使采样与估计可行（C2 后半句）。
  - 问题 2：3 token 小例子：序列概率 = 三步连乘；逐 token 损失 $-\log p(\cdot)$（链接交叉熵页）；全程 Python 实算后写入。
- 对应范围：Q2 / C2 / F1。
- 正文要点：乘法公式 → 一般式 → 手算表。
- 表达材料及职责：手算表（3 行：每步的条件、概率值、损失值）。
- 前置知识安排：首次链接交叉熵概念页（token 损失的计算方法引用该页，不重推）。

### 第 3 章：预训练的目标——在大语料上最小化下一 token 交叉熵（回答 Q3）

- 章节问题：
  - 问题 1：预训练的损失是什么，「无标注」从哪来？
  - 问题 2：为什么这个目标既是「最小化交叉熵」又是「最大化似然」？
- 完成答案要点：
  - 问题 1：语料平均的下一 token 交叉熵（F2）；监督信号来自文本本身：前文是输入、下一 token 是标签（自监督；误解 1）；「无标注」= 不需人工标签。
  - 问题 2：似然 = 序列概率连乘（第 2 章）；取负对数后正是逐 token 损失求和（C6 等价原文）；平均按 token/预测单元（C3 原文）。
- 对应范围：Q3 / C3 / C6 / F2。
- 正文要点：目标公式 → 自监督解释 → 两种说法的等价 → 「语料上平均」的报告惯例。
- 表达材料及职责：F2 公式；无图。
- 前置知识安排：复用交叉熵页结论。

### 第 4 章：预训练产出基座模型，行为对齐交给后训练（回答 Q4）

- 章节问题：
  - 问题 1：预训练结束时得到什么，它默认会做什么？
  - 问题 2：为什么从预训练模型到「能用」的产品模型还需要后训练？
- 完成答案要点：
  - 问题 1：基座模型：通用语言能力（续写流畅、知识广泛），默认行为是续写语料风格文本（误解 3 的定位说明）。
  - 问题 2：训练目标（词预测误差）与用户目标（有帮助且安全）的错位（C5 原文）；后训练从 SFT 开始：在人类示范上微调预训练模型（C4 原文）；一句话预告 SFT 页。
- 对应范围：Q4 / C4 / C5。
- 正文要点：错位表述 → InstructGPT 起点的表述 → 指向 SFT 页。
- 表达材料及职责：无图（一句话定位，流程图留给 SFT 页）。

## 4. 贯穿示例

设定：8 token 玩具词表、一句 3 token 文本（如「天气真好」按 3 个 token 分）。每步条件概率人为构造（标注构造示例），Python 实算。

- 第 1 章进场：给前文「天气真」的下一 token 分布表。
- 第 2 章推进：整句概率连乘 + 逐 token 损失表。
- 第 3 章推进：把单句损失放进「语料平均」的形式（同一例子从单句变语料视角）。
- 第 4 章推进：说明基座模型对该前文只会「按分布续写」，引出指令场景。
