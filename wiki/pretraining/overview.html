语言模型预训练

在大规模无标注语料上，用「预测下一个 token」的交叉熵目标训练语言模型，产出通用的基座模型。

更新于 2026-08-25

它是什么

语言模型是 token 序列上的概率分布，实际接口是 next token prediction：给定任意前文，输出下一个 token 在整个词表上的概率分布。预训练就是训练这个分布的过程——在大规模无标注文本上，反复让模型预测下一个 token，并按交叉熵调整参数。

为什么需要它

「预测下一个 token」不需要任何人工标注：前文是输入、语料里真实出现的下一个 token 是标签（自监督）。监督信号由文本自身携带，训练数据因此可以扩展到远超人工标注的量级。在这个量级上练出的模型获得广泛的续写、知识与语言能力，成为后续一切后训练的基座。

核心机制

  • 链式分解：一条文本的概率等于各步条件概率连乘 $p(s_1,\dots,s_n)=\prod_i p(s_i\mid s_{<i})$，序列级的量全部化归到逐 token 预测。
  • 训练目标：最小化语料上下一 token 的平均交叉熵。序列似然是条件概率连乘，取负对数后恰是逐 token 损失之和——「最大化似然」与「最小化交叉熵」是同一目标。
  • 逐 token 可分：每个位置的损失只依赖该位置的前文与真实 token，训练与诊断都可以逐位置进行。

关键结论与边界

  • 预训练产出基座模型：能流畅续写，但默认行为是「按语料风格续写」而非「按指令回答」——训练目标（词预测误差）与用户目标（遵循指令、有帮助且安全）存在错位。
  • 行为对齐交给后训练：从 SFT（在人类示范上微调预训练模型）开始。此为当前主流实践，不是数学必然。
  • 本页结论限于自回归（decoder-only）语言模型；掩码语言模型（BERT 式）是另一范式，结论不适用。
