    MOPD（Multi-Teacher On-Policy Distillation）：把多个专项专家合并进一个统一学生模型

    主要依据：Kimi K3 技术报告 §4.1.3 "Multi-Teacher On-Policy Distillation"（Eq.15）及 §4.1.2 中九个专家的训练与轨迹收集流程。

    K3 通过强化学习训练了九个各有专长的专家模型：3 个领域（通用任务、通用 agent、编码 agent）× 3 个努力程度（{low, high, max}），共 9 个。能不能不部署九份、只部署一份就把它们的能力都装进去？直接把九组权重平均行不通——参数空间没有对应关系，平均后互相抵消。MOPD（Multi-Teacher On-Policy Distillation，多教师在线策略蒸馏）就是 K3 给出的答案：让一个统一的学生模型自己生成 token，由对应领域和努力程度的专家教师逐 token 给出对数概率比作为稠密奖励，在已有 RL 框架里完成合并。本文讲清楚它的奖励公式、稳定化算子、多教师路由机制和能力边界。

    核心问题

    1. 为什么要把九个专家合成一个统一模型，而不是直接部署九个专家？简单平均权重为什么不可行？

      解答：部署成本与能力共享要求合并，参数平均无对应关系

      分别部署要九份权重显存、九套推理实例，还需要领域路由，且九种能力互不共享；而九个专家在不同数据分布与奖励信号下训练，参数空间没有对应关系，直接平均会互相抵消。MOPD 训练一个以努力程度 $e$ 为条件输入的统一学生，靠"学生自己生成 token、对应教师逐 token 打分"把能力转移进同一组参数。见"1. 合并动机"一章。

    2. 学生自己生成的 token 如何变成一个奖励信号？Eq.15 里每个符号在做什么？

      解答：教师与学生的概率之比取对数，即 per-token 奖励

      学生在已生成前缀 $y_{<t}$ 后采样 $y_t$，教师不重写答案，只给出 $\pi_{\text{teacher}}^{(d,e)}(y_t\mid x,y_{<t})$ 与学生概率 $\pi_\theta(y_t\mid e,x,y_{<t})$ 之比的对数；$\text{sg}$ 把整个比值当常数，$\text{clip}$ 把值限制在 $[-R_{\max},R_{\max}]$，得到稠密的 per-token 奖励。逐符号说明见"2. Per-token 奖励"一章。

    3. 裁剪阈值 $R_{\max}$ 和停梯度 $\text{sg}$ 各自解决什么问题，去掉会怎样？

      解答：sg 保证梯度只走策略梯度项，clip 截断极端信号

      $\text{sg}$ 保证梯度只走 $\nabla\log\pi_\theta(y_t)$ 这一条路径，去掉会让梯度额外从奖励本身含有的 $\log\pi_\theta$ 流过、破坏策略梯度形式；$\text{clip}$ 截断极端对数比值，去掉会让学生几乎不采样但教师高概率的 token 给出过大梯度、单步更新失稳。见"3. 稳定性"一章。

    4. 九个教师如何按领域和努力程度轮流指导同一个学生？这个稠密奖励如何接入已有 RL 框架？

      解答：按样本标签选教师，稠密奖励是 RL 框架的标准输入

      每条训练样本携带领域 $d$ 和努力程度 $e$ 标签，训练时按 $(d,e)$ 选出对应教师给奖励；学生条件化于 $e$ 而不条件化于 $d$。per-token 稠密奖励是 RL 框架标准的 advantage 输入，partial rollout 与 per-token 正则化等已有组件原样复用，无需另造训练栈。见"4. 多教师路由"一章。

    5. MOPD 不能做什么？（教师上限、top-k 无优势、需要先有专家）

      解答：只转移已有能力，不发明新能力

      九个专家必须先由 RL 训练好，MOPD 是其后的合并阶段，教师缺位就没有奖励来源；学生质量以教师为上限，奖励信号只推动学生向教师靠拢；K3 实验中更精细的 top-k 蒸馏目标无额外优势；$R_{\max}$ 在稳定性与信号完整性之间折中。见"5. 能力边界"一章。

    1. 合并动机——为什么要把九个专家合成一个统一模型

    K3 的 RL 阶段把训练拆成三个领域，每个领域在三个努力程度上各训练一个专家，共九个[C1, N1, N2]。三领域是通用任务、通用 agent、编码 agent；三努力程度是 {low, high, max}。

    九个专家各自很强，但分别部署有三层成本。第一，服务九份模型意味着九倍的权重显存与九套推理实例。第二，用户请求到来时需要先判断该路由到哪个专家，领域边界模糊时路由本身就是一个难题。第三，九个专家各自为政，通用任务专家学到的推理能力没法帮到编码 agent 专家，能力之间不共享。

    那直接把九组权重做平均呢？不行。九个专家是在不同数据分布、不同奖励信号下训练出来的，它们的参数空间没有对应关系——通用任务专家的第 $i$ 个权重和编码 agent 专家的第 $i$ 个权重并不代表同一个"语义旋钮"，平均后会互相抵消，不会得到一个同时具备九种能力的模型。

    MOPD 走的合并路线是：训练一个统一学生模型 $\pi_\theta$，把努力程度 $e$ 作为模型的条件输入[C2]。同一组参数 $\theta$ 在 $e=\text{low}$ 时产出低努力程度的响应，在 $e=\text{max}$ 时产出高努力程度的响应。九个专家的能力不是靠平均权重塞进来，而是靠"学生自己生成 token、对应教师逐个打分"的训练过程转移过来。这就把九份要部署的模型缩成了一份，同时让九种能力在同一组参数里共存。

    方案部署成本能力是否共享能力来源
    分别部署九个专家九份权重、九套实例、需路由不共享各自 RL 训练
    简单平均九组权重一份——不可行：参数空间无对应，平均后互相抵消
    MOPD 合并为条件化学生一份共享（同一组参数）学生自己生成 token，教师逐 token 打分

    澄清一个常见误解：MOPD 并不训练这九个专家。九个专家是上游 RL 阶段（§4.1.2，含努力程度预算控制）已经训练好的产物[C3]；它们的生成轨迹被联合收集起来，同时用于监督微调和 MOPD（K3 报告原文为 "jointly collected for supervised fine-tuning and multi-teacher on-policy distillation"，未说明是否分区）。MOPD 是这个两阶段流程的第二阶段——合并，不是第一阶段——训练专家。教师参数在 MOPD 阶段不再更新——这是由 Eq.15 中 $\text{sg}$ 算子推出的：$\text{sg}$ 把整个对数比值当常数，教师梯度不会回传到自身参数；K3 报告未明文使用"冻结"一词，本文依此推断。

    本章问题

    1. 九个专家的两个构成维度分别是什么，各自取几个值。

      解答：3 领域 × 3 努力程度

      领域取通用任务、通用 agent、编码 agent 三个值；努力程度取 low、high、max 三个值；$3 \times 3 = 9$ 个专家。

    2. 用一句话说明为什么简单平均九组权重不可行。

      解答：参数空间无对应关系

      九个专家在不同数据分布、不同奖励信号下训练，第 $i$ 个权重并不代表同一个"语义旋钮"，平均后会互相抵消，得不到同时具备九种能力的模型。

    3. 统一学生如何用同一组参数表达多个努力程度。

      解答：努力程度作为条件输入

      努力程度 $e$ 是模型的条件输入：同一组参数 $\theta$ 在 $e=\text{low}$ 时产出低努力程度的响应、在 $e=\text{max}$ 时产出高努力程度的响应；九种能力靠"学生生成、教师打分"的训练过程转移进同一组参数，而不是靠平均权重。

    知道了"为什么要合并"，下一章看"怎么合并"——学生自己走，教师逐 token 打分。

    2. Per-token 奖励——学生自己生成 token、教师逐个打分

    MOPD 的奖励信号建立在"学生自己生成 token"这一事实上。给定输入 $x$、领域 $d$、努力程度 $e$，学生 $\pi_\theta$ 在已生成前缀 $y_{

    MOPD 的奖励公式建立在两个概念上：

    • 知识蒸馏：教师模型把高概率分给它偏好的 token，学生模仿教师的概率分布。标准做法是教师先生成完整答案、学生在固定教师序列上拟合（off-policy）；MOPD 用的是其在线变体。
    • 策略梯度 / RLHF：策略梯度按 $\nabla\log\pi_\theta(y_t)\cdot A$ 更新参数，其中奖励或优势 $A$ 作为常数乘子，$y_t$ 是学生采样的动作；$A$ 为正时推动 $\log\pi_\theta(y_t)$ 上升，为负时下降。

    对每个 token $y_t$，教师给出的是它在这个上下文下分配给 $y_t$ 的概率 $\pi_{\text{teacher}}^{(d,e)}(y_t\mid x,y_{

    • $x$：输入 query。

    • $y_t$：第 $t$ 个 token，由学生 $\pi_\theta$ 采样得到（on-policy）。
    • $e$：努力程度，取值 {low, high, max}；学生把它作为条件输入。
    • $d$：领域索引，用于选定 9 个教师中的哪一个。
    • $\pi_{\text{teacher}}^{(d,e)}$：对应 $(d,e)$ 的专家教师，已训练；MOPD 阶段不更新（由 $\text{sg}$ 推出，非报告明文）。
    • $\pi_\theta$：学生模型，参数 $\theta$ 在训练中更新，条件化于 $e$。
    • $\log$：自然对数。
    • $\text{sg}(\cdot)$：停梯度算子，把括号内整体当常数，不对其求导（下一章展开）。

    • $R_{\max}>0$：裁剪阈值。

    $$\log\frac{\pi_{\text{teacher}}^{(d,e)}(y_t\mid x,y_{这一步把"概率之比"翻译成了"教师对数概率减去学生对数概率"[F2]。它的含义很直接：当教师比学生更认可这个 token 时（教师分给 $y_t$ 的概率更高），差为正；当教师比学生更不认可时，差为负；两者相等时为零。把这个带符号的标量作为策略梯度里的优势 $A$，就能驱动学生调整：正奖励让学生增加该 token 的对数概率，负奖励让学生减小它。

    构造示例。 设词表只有三个 token {A, B, C}。学生当前概率分布 $\pi_\theta=(0.5,0.3,0.2)$，教师概率分布 $\pi_{\text{teacher}}=(0.7,0.2,0.1)$，取 $R_{\max}=5$（足够大，本例不触发裁剪）。学生按自己的分布采样一个 token：

    • 若学生采样到 A：$r=\text{clip}(\log(0.7/0.5),-5,5)=\text{clip}(0.336,-5,5)=+0.336$。教师比学生更认可 A，奖励为正，策略梯度推动 $\log\pi_\theta(A)$ 上升。
    • 若学生采样到 B：$r=\text{clip}(\log(0.2/0.3),-5,5)=\text{clip}(-0.405,-5,5)=-0.405$。教师比学生更不认可 B，奖励为负，推动 $\log\pi_\theta(B)$ 下降。
    • 若学生采样到 C：$r=\text{clip}(\log(0.1/0.2),-5,5)=\text{clip}(-0.693,-5,5)=-0.693$。教师比学生更不认可 C，奖励为负，推动 $\log\pi_\theta(C)$ 下降。

    对照三种情况可以看到机制：教师概率高于学生的 token 得正奖励被鼓励，教师概率低于学生的 token 得负奖励被抑制。在这个例子里教师相对学生更偏好 A、更不偏好 B 和 C，所以训练会把学生分布从 $(0.5,0.3,0.2)$ 推向教师的 $(0.7,0.2,0.1)$。这就是 MOPD 转移能力的基本方式：学生不用读教师的完整答案，只在自己走过的轨迹上接收逐 token 的方向信号。

    构造示例。 学生 $\pi_\theta=(0.5,0.3,0.2)$，教师 $\pi_{\text{teacher}}=(0.7,0.2,0.1)$，$R_{\max}=5$。三种 token 的对数比值分别用 $\log\pi_{\text{teacher}}-\log\pi_\theta$ 计算：

    • A：$\log(0.7)-\log(0.5)=(-0.356675)-(-0.693147)=+0.336472$，落在 $[-5,5]$ 内，$r=+0.336472$。
    • B：$\log(0.2)-\log(0.3)=(-1.609438)-(-1.203973)=-0.405465$，落在区间内，$r=-0.405465$。
    • C：$\log(0.1)-\log(0.2)=(-2.302585)-(-1.609438)=-0.693147$，落在区间内，$r=-0.693147$。

    三个奖励的符号分别与"教师概率是否高于学生"一致：A 高（正），B 和 C 低（负）。由于 $R_{\max}=5$ 大于所有比值的绝对值，本例未触发裁剪；裁剪的作用在下一章用极端概率比展示。

    本章问题

    1. 用一句话说出 on-policy 在这里指什么，谁的策略生成 token。

      解答：训练轨迹来自学生当前策略

      token 由学生 $\pi_\theta$ 在已生成前缀后自己采样，教师只读前缀打分、不重写答案；训练分布在学生真实会进入的状态上，而不是教师预先生成的固定序列。

    2. 说明为什么对数比值能表达"教师比学生更认可这个 token"。

      解答：对数除法性质把比值拆成带符号的差

      $\log(\pi_{\text{teacher}}/\pi_\theta) = \log\pi_{\text{teacher}} - \log\pi_\theta$：教师概率高于学生时差为正、低于时为负、相等时为零。这个带符号标量直接作为策略梯度的优势 $A$，正奖励增加该 token 概率、负奖励减小它。

    3. 手算：若学生概率 $(0.6,0.4)$、教师概率 $(0.3,0.7)$，$R_{\max}=5$，学生采样到第一个 token 时 $r$ 的符号是什么。

      解答：负号

      $r = \text{clip}(\log(0.3/0.6), -5, 5) = \log 0.5 \approx -0.693$，落在 $[-5,5]$ 内未被裁剪，符号为负——教师比学生更不认可该 token，训练会压低它的概率。

    奖励公式有了，但里面有两个工程选择（裁剪、停梯度）还没解释——下一章看它们各自解决什么问题。

    3. 稳定性——裁剪和停梯度让奖励信号可控

    Eq.15 里有两个看起来多余的算子：$\text{sg}$ 和 $\text{clip}$[C5]。它们不是装饰，而是分别解决一类会破坏训练稳定性的问题。

    先看 $\text{sg}$。在策略梯度里，奖励 $r$ 应当被当作常数乘子，梯度只通过 $\nabla\log\pi_\theta(y_t)$ 这一项流动。但 Eq.15 的对数比值里同时含有 $\pi_\theta$——如果不加约束，对 $r$ 直接求导会让梯度既从"策略梯度项"走，又从"奖励本身含有的 $\log\pi_\theta$"走，破坏策略梯度的标准形式。$\text{sg}$ 把整个对数比值当作常数，等价于声明"这部分不参与求导"，让梯度只走 $\nabla\log\pi_\theta(y_t)$ 这一条路径。教师 $\pi_{\text{teacher}}^{(d,e)}$ 在 MOPD 阶段不更新参数——由 $\text{sg}$ 把对数比值当常数推出（K3 报告未明文使用"冻结"一词）；因此梯度只走 $\nabla\log\pi_\theta(y_t)$。

    澄清一个常见误解：有人说"教师的梯度回传到学生"。这是错的。$\text{sg}$ 阻断了这条路——教师参数在 MOPD 阶段不更新（由 $\text{sg}$ 推出，非 K3 报告明文），对数比值当常数，梯度不会从教师流回学生。学生参数的更新只来自策略梯度项 $\nabla\log\pi_\theta(y_t)\cdot r_{\text{opd}}$，其中 $r_{\text{opd}}$ 是一个标量乘子。教师起的是"奖励来源"的角色，不是"梯度来源"。

    再看 $\text{clip}$。当学生几乎不采样某个 token 但教师却高概率分配给它时，对数比值会非常大。例如学生 $\pi_\theta(A)=0.01$、教师 $\pi_{\text{teacher}}(A)=0.9$ 时，$\log(0.9/0.01)=\log 90\approx 4.50$；如果学生概率低到 $0.001$，比值会到 $\log 900\approx 6.80$。这种极端奖励会在单步更新里给出过大的梯度，把参数推向一个不稳定的方向。$\text{clip}$ 把奖励限制在 $[-R_{\max},R_{\max}]$，超出就截断，防止单步更新被极端信号主导——这是 K3 报告里说的"约束极端 advantage 信号以稳定 RL 训练"。

    澄清另一个常见误解：有人把 $\text{clip}$ 理解成"把实际概率比 $\pi_{\text{teacher}}/\pi_\theta$ 限制在 $[-R_{\max},R_{\max}]$"。这是错的。$\text{clip}$ 裁剪的是作为奖励信号的对数比值（也就是策略梯度里那个 advantage 副本），不直接限制实际概率比本身。学生参数更新之后，真实的 $\pi_{\text{teacher}}/\pi_\theta$ 完全可以超过 $R_{\max}$——只是用于计算梯度的那个奖励标量被截断了。两者的区别：一个是数值上送给优化器的 advantage，一个是模型前向算出的真实概率之比。

    下面用同一组极端概率比对照两个 $R_{\max}$ 取值，看裁剪在什么时候触发。数字仍为构造示例。

    构造示例。 固定学生 $\pi_\theta(A)=0.01$、教师 $\pi_{\text{teacher}}(A)=0.9$，对数比值 $\log(0.9/0.01)\approx 4.50$。比较两个 $R_{\max}$：

    • $R_{\max}=5$：$r=\text{clip}(4.50,-5,5)=4.50$，未触发裁剪，奖励信号完整保留。
    • $R_{\max}=3$：$r=\text{clip}(4.50,-3,3)=3$，触发裁剪，压掉了 $4.50-3=1.50$ 的偏差信号。

    这个对照说明裁剪的阈值行为：对数比值落在 $[-R_{\max},R_{\max}]$ 内时信号原样通过，超出时被截到边界。$R_{\max}$ 越小，被截掉的极端信号越多，训练越平稳但信息损失也越大；$R_{\max}$ 越大，信号越完整但单步更新可能越剧烈。K3 报告没有给出 $R_{\max}$ 的具体取值，这里不引用任何具体数字。

    1. 说明 $\text{sg}$ 阻断了哪条梯度路径，梯度最终只从哪一项走。

      解答：阻断奖励自身的求导路径，梯度只走策略梯度项

      $\text{sg}$ 把整个对数比值当常数，阻断了从"奖励本身含有的 $\log\pi_\theta$"（以及教师侧参数）出发的求导路径；梯度只走 $\nabla\log\pi_\theta(y_t)$ 这一项，$r_{\text{opd}}$ 作为标量乘子参与更新。

    2. 说明 $\text{clip}$ 裁剪的是奖励信号还是实际概率比，并说出两者的区别。

      解答：裁剪的是作为奖励信号的对数比值

      被截断的是送给优化器的 advantage 数值；学生参数更新之后，模型前向算出的真实概率之比 $\pi_{\text{teacher}}/\pi_\theta$ 完全可以超过 $R_{\max}$。前者是数值上送入优化的信号，后者是前向的真实分布量。

      解答：例如学生 0.01、教师 0.9、$R_{\max}=3$

      取 $\pi_\theta(A)=0.01$、$\pi_{\text{teacher}}(A)=0.9$，对数比值 $\log 90 \approx 4.50$；若 $R_{\max}=3$，则 $r=\text{clip}(4.50,-3,3)=3$，截掉了 1.50 的偏差信号；若 $R_{\max}=5$ 则不裁剪，$r=4.50$。

    1. 训练样本如何选定教师，说出 $(d,e)$ 的作用。

      解答：按样本标签从九个教师中选一个

      解答：部署不需要领域路由器

      从公式形式 $\pi_\theta(y_t\mid e,x,y_{<t})$ 不含 $d$ 可以推断：部署时只需用户指定努力程度 $e$，不需要判断该路由到哪个领域；九个领域专家的能力已吸收进同一组参数，学生自己会在不同输入上表现出对应的领域能力（这是由公式形式推出的推断，K3 报告未明文陈述）。

      解答：per-token advantage 是 RL 框架的标准输入

      RL 框架本来就消费 per-token advantage：partial rollout 的轨迹生成与暂停逻辑不需要为蒸馏改造，K2.5 的 per-token 正则化可以原样消费 MOPD 的奖励。MOPD 只是把教师当作一个稠密奖励源插进已有流水线。

    机制和集成都清楚了——最后一章看 MOPD 的能力边界。

    5. 能力边界——MOPD 能做什么、不能做什么

    MOPD 的机制决定了它的能力边界。最重要的一条：它不能凭空产生新能力。九个专家必须先由 RL 训练好（§4.1.2），MOPD 是其后的合并阶段。如果某个领域没有训练好的教师，MOPD 在那个领域就没有奖励来源，无能为力。这是两阶段流程的必然结果——MOPD 把教师已有的能力搬进学生，不发明新能力。

    第二条边界直接由奖励公式推出：学生质量以教师为上限。Eq.15 的奖励信号是"教师比学生更认可这个 token 吗"，它推动学生向教师靠拢，但学生不会显著超越教师。如果教师在某类问题上本来就弱，学生通过 MOPD 学到的也只是教师的弱表现。要超越教师，需要带任务奖励的真正 RL 探索，不是蒸馏——这是从奖励公式结构推出的方向性结论，K3 报告未明文陈述。

    第三条边界来自 K3 的实验结论：他们还试过更精细的 top-k 蒸馏目标（在 token 级信号上对教师分布的 top-k 概率施加额外约束，具体形式报告未详述），但在收敛速度和最终性能上都没有观察到明显优势[C7]。这说明对 K3 的设置而言，per-token 对数比值已经抓住了关键信号，更精细的约束没有带来额外收益。这个结论只针对 K3 的实验设置——报告没有给出具体数值，因此本文不引用任何 top-k 对比的具体数字，也不把它推广成"top-k 永远没用"。

    澄清一个常见误解：有人凭直觉认为"top-k 蒸馏更精细所以应该更好"。K3 的实验说并非如此——至少在他们的设置里，额外的 top-k 约束既没加快收敛，也没提升最终性能。更精细不等于更好，per-token 对数比值已经够用。

    第四条边界来自上一章的裁剪：$R_{\max}$ 在限制极端信号的同时也压掉了部分高信息量的偏差。学生几乎不采样但教师高概率的 token，恰恰是学生最该改正的地方，但裁剪会把这些最强烈的纠正信号截断。$R_{\max}$ 是"稳定性"和"信号完整性"之间的折中——它让训练不会因为一个极端 token 而失稳，代价是丢掉一部分本可以学到的东西。

    维度MOPD 能做MOPD 不能做
    能力来源把已有教师的能力合并进学生凭空产生教师没有的能力
    质量上限让学生逼近教师显著超越教师
    基础设施复用 partial rollout、per-token 正则化等已有 RL 组件替代真正的 RL 探索（带任务奖励）
    训练流程把多教师稠密奖励插进单一 RL 流水线训练那九个专家本身（那是上游 RL 阶段的事）

    综合这些边界，MOPD 的适用条件可以总结成三条：第一，存在已训练好的 $(d,e)$ 专家教师；第二，训练样本可按 $(d,e)$ 路由到对应教师；第三，学生架构能以 $e$ 为条件输入。三条都满足时，MOPD 是一个低成本、复用已有基础设施的多专家合并方案；任何一条不满足，它就退化为不可用或需要补齐前置条件。

    本章问题

    1. MOPD 是两阶段流程的哪一阶段，另一阶段是什么。

      解答：第二阶段是合并，第一阶段是上游 RL 训练专家

      第一阶段是 §4.1.2 的 RL：训练九个专家并联合收集轨迹；MOPD 是其后的第二阶段，只把已有教师的能力搬进学生，不训练专家，教师在 MOPD 阶段不更新参数（由 $\text{sg}$ 推出）。

    2. 用奖励公式说明学生质量为什么以教师为上限。

      解答：奖励信号的方向始终指向教师分布

      Eq.15 的奖励是"教师比学生更认可这个 token 吗"：正奖励推动学生向教师靠拢，比值为零时不再推动，信号方向不会越过教师分布。教师在某类问题上弱，学生通过 MOPD 学到的也是教师的弱表现；要超越教师需要带任务奖励的真正 RL 探索（此为公式结构的方向性结论，K3 报告未明文陈述）。

    3. 说出 $R_{\max}$ 的两面性：它同时限制了什么、压掉了什么。

      解答：稳定性与信号完整性之间的折中

      一方面把奖励限制在 $[-R_{\max},R_{\max}]$，防止单步更新被极端 token 主导，保证训练平稳；另一方面把学生几乎不采样但教师高概率的 token 的最强纠正信号截断，丢掉部分高信息量偏差。K3 报告未披露具体取值。

    回到开头的核心问题：本文讲清了为什么要把九个专家合成一个统一模型（合并动机）、学生自己生成的 token 如何变成 Eq.15 的稠密奖励（per-token 奖励）、裁剪与停梯度各自解决的稳定性问题（稳定性）、九个教师如何按 $(d,e)$ 轮流指导并接入已有 RL 框架（多教师路由），以及 MOPD 的能力边界——不能凭空产生新能力、学生以教师为上限、top-k 在 K3 设置下无优势、$R_{\max}$ 在稳定性与信号完整性之间折中。MOPD 的价值在于把多专家合并这一步插进已有的 RL 流水线，不需要为蒸馏另造训练栈；它的边界也由机制本身决定——它转移已有能力，不发明新能力。
