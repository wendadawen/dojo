    MOPD

    正文 2,946 字 · 约 9 分钟阅读

    后训练指模型预训练完成之后再做的那一段训练，预训练指模型先在大规模文本上做的那段训练，MOPD 就是一段后训练流程。强化学习是一类训练方法：模型对一个问题生成回答，按回答得到的反馈调整自己生成内容的概率。模型生成内容时给出的概率分布叫策略；模型一次完整生成的内容叫轨迹，轨迹由 token 组成，token 是模型逐次输出的最小单位。

    MOPD 按领域把能力合进一个学生模型：先对每个领域各跑一遍强化学习，得到一批各管一个领域的模型，叫领域教师；再让学生在自生成的轨迹上接受对应领域教师的逐 token 监督，把这批教师的能力合进一个模型。名字里的 on-policy 指训练用的轨迹由学生当前策略自己生成，而不是用教师或固定数据集写出来的文本。

    1. 后训练里的能力集成问题

    强化学习能逐个领域推高模型的能力：数学靠可验证答案的奖励，软件工程靠在可执行沙箱里做任务的奖励，奖励是训练给出的一个分数，表示这次回答有多好；各领域的训练流程互不相同，每个流程都能可靠地改进它所在的领域。想要的是一个在所有领域都好的模型，而把这样的模型建出来仍是后训练里的开放问题。

    混数据联合 RL 把各领域的提示混进一份数据一起训练，提示是交给模型回答的输入，RL 就是强化学习；跨领域的训练信号互相干扰，出现此消彼长，合出来的模型低于各领域专家。按域顺序训练把领域一个接一个地练，先练好的能力可能随后面阶段推进而衰减。在教师轨迹上离线微调先用各领域 RL 训出教师，再让学生在这些教师的轨迹上继续训练（监督微调）；这种离线监督带来训练与推理（推理指模型训练完成后被使用、对输入做前向计算）的分布失配。在权重空间合并把教师的参数平均、或把各教师的改动方向相减相加，合出来的模型往往不稳定，达不到每个教师的全部能力。

    这四类做法的取舍落在学习效率、能达到的上限和训练稳定性三者之间，没有留下满意的中间点。MOPD 换成在策略空间里做集成。

    2. 三段流水线：SFT、按领域 RL、蒸馏

    MOPD 把后训练排成三段。第一段做通用 SFT（监督微调）：在一个覆盖所有目标领域的语料上微调基座模型（基座模型指预训练好、还没做后训练的模型），得到一个 SFT 检查点（检查点是训练中途保存下来的模型参数）。这个检查点既是第二段各领域训练的起点，也是第三段学生的初始化。

    第二段做领域专精的 RL 训练：对每个领域，从 SFT 检查点出发训出一个领域教师 $\pi_{\phi_d}$，$\phi_d$ 是这个教师的参数。每个教师用它那个领域最自然的强化学习配方。各领域的训练互相独立，可以完全并行。

    第三段用蒸馏把教师合进学生，蒸馏指让学生去学教师给出的概率分布。学生从 SFT 检查点初始化，第二段的领域教师全部冻结，组成教师集合；在一个多领域数据集上训练学生。训完之后，第三段给出一个统一模型。

    3. 用逐 token 反向 KL 合成学生

    第三段的每个优化步重复四步。第一步，从多领域数据集里采一批提示。第二步，学生为每个提示生成一条轨迹，并记下自己在这条轨迹每个位置给出的概率分布。第三步，每条轨迹按提示所属的领域交给对应领域的教师，教师在这条轨迹上回填（把轨迹过一遍教师，取回逐位置的对数概率），得到它在同样每个位置的概率分布。第四步，学生按逐 token 反向 KL 朝这个教师更新。其中第三步与第四步是 MOPD 与普通强化学习的差别所在：普通强化学习在轨迹生成后要算一个奖励再更新，MOPD 不做这一步，它直接用每个位置上教师与学生的分布差异当监督。

    反向 KL 是衡量两个概率分布差距的一种散度（散度是衡量两个分布差距的一类量），写成 $D_{\mathrm{KL}}(\pi_\theta\|\pi_{\phi_d})=\sum_v \pi_\theta(v)\log\frac{\pi_\theta(v)}{\pi_{\phi_d}(v)}$，$v$ 取遍词表里的 token，词表是模型能输出的全部 token 的集合，$\pi_\theta(v)$ 是学生在当前位置给 token $v$ 的概率。正向 KL 的写法是 $D_{\mathrm{KL}}(\pi_{\phi_d}\|\pi_\theta)$，它把教师放在前面、由教师的概率加权；反向指的是把两者对调，把学生 $\pi_\theta$ 放在分子、由学生的概率加权，学生只在自己给概率的地方被教师纠正。

    第三段最小化的目标对每条轨迹先做 token 平均、再对轨迹取期望：$\mathcal{L}_{\mathrm{rev\text{-}KL}}=\mathbb{E}_{x,y\sim\pi_\theta}\big[\frac{1}{|y|}\sum_t D_{\mathrm{KL}}\big(\pi_\theta(\cdot\mid x,y_{<t})\,\big\|\,\pi_{\phi_d}(\cdot\mid x,y_{<t})\big)\big]$，$|y|$ 是轨迹长度，$x$ 是这条轨迹对应的提示，$y_{<t}$ 是轨迹在位置 $t$ 之前的部分，$\pi_{\phi_d}$ 是这条提示被路由到的那个教师。

    3.1 折成策略梯度：教师与学生之差当 advantage

    把目标整理一步就能写成策略梯度的形式，教师与学生的对数概率之差落在策略梯度里「回报」的位置：$\nabla_\theta\mathcal{L}=-\mathbb{E}_{x,y}\big[\frac{1}{|y|}\sum_t \hat{A}_{t}\nabla_\theta\log\pi_\theta(y_t)\big]$，其中 $\hat{A}_{t}=\log\pi_{\phi_d}(y_t)-\log\pi_\theta(y_t)$ 是逐 token 对数概率差，叫 advantage。策略梯度是一类更新规则，把一次生成的回报乘上「生成这条轨迹的概率对参数的梯度」，回报是给这次回答的一个数值评价，高的路线被抬高、低的被压低；在这里，$\hat{A}_{t}$ 就是位置 $t$ 的回报。

    advantage 是两个对数概率之差：为正表示教师认为这个 token 该更常出现，为负表示该更少出现；它没有减去基线（同类做法里用来对照的一个参考值）。为了稳定，对每个 token 的 advantage 做两侧截断，$\hat{A}^{\mathrm{clip}}_{t}=\mathrm{clip}(\hat{A}_{t},-A_{\max},+A_{\max})$，$A_{\max}$ 是上限，截断限制单个 token 贡献的更新幅度。

    整理后的最终损失是一个加权策略梯度：$\mathcal{L}^{\mathrm{PG}}_{\mathrm{MOPD}}(\theta)=-\mathbb{E}_{x,y}\big[\frac{1}{|y|}\sum_t \hat{A}^{\mathrm{clip}}_{t}\log\pi_\theta(y_t)\big]$。它可以直接放进现成的策略梯度训练框架，改动只在 advantage 的计算。

    从反向 KL 的梯度到策略梯度

    用「对数概率求导」把反向 KL 目标的梯度整理成上面的策略梯度形式。

    1. 先看单个 $v$：$\pi_\theta(v)\log\frac{\pi_\theta(v)}{\pi_{\phi_d}(v)}=\pi_\theta(v)(\log\pi_\theta(v)-\log\pi_{\phi_d}(v))$。
    2. 记 $l=\log\pi_\theta(v)$，对 $l$ 求导得 $\frac{d}{dl}\big[\pi_\theta(v)(l-\log\pi_{\phi_d}(v))\big]=\pi_\theta(v)+\pi_\theta(v)(l-\log\pi_{\phi_d}(v))$，再乘上 $\nabla_\theta l=\nabla_\theta\log\pi_\theta(v)$，就是这一项对 $\theta$ 的梯度。
    3. 把 $v$ 求和，第一块 $\sum_v \pi_\theta(v)\nabla_\theta\log\pi_\theta(v)$ 在 $y\sim\pi_\theta$ 下期望为 $0$，因为 $\sum_v\pi_\theta(v)$ 恒为 $1$、其梯度为零。
    4. 剩下的第二块是 $\sum_v \pi_\theta(v)\big(\log\frac{\pi_\theta(v)}{\pi_{\phi_d}(v)}\big)\nabla_\theta\log\pi_\theta(v)$，取期望时只有一个采样到的 token $y_t$ 留下，得到 $-\mathbb{E}\big[\hat{A}_{t}\nabla_\theta\log\pi_\theta(y_t)\big]$；这里的 $\hat{A}_{t}=\log\pi_{\phi_d}(y_t)-\log\pi_\theta(y_t)$ 是正号的对数概率差，前面的负号与策略梯度式里的整体符号一致。
    5. 对 $\hat{A}_{t}$ 加两侧截断再代回，就是最终的加权策略梯度损失。

    3.2 只取教师 top-k 的实现

    策略梯度形式每个位置只用采样到的那一个 token，用它估计梯度方差较大。另一种在教师的 top-k token 上蒸馏的做法用到更多 token：top-k 指取概率最大的 $k$ 个 token，记教师在位置 $t$ 下这些 token 的集合为 $\mathcal{T}_{t,d}=\mathrm{TopK}_k(\pi_{\phi_d}(\cdot\mid x,y_{<t}))$，损失在集合内求和：$\mathcal{L}^{\mathrm{TopK}}_{\mathrm{MOPD}}(\theta)=\mathbb{E}_{x,y}\big[\frac{1}{|y|}\sum_t\sum_{v\in\mathcal{T}_{t,d}}\big(\pi_\theta(v)\log\frac{\pi_\theta(v)}{\pi_{\phi_d}(v)}-\pi_\theta(v)+\pi_{\phi_d}(v)\big)\big]$。

    这里比标准反向 KL 多一项 $\pi_{\phi_d}(v)-\pi_\theta(v)$，它修正只取 $k$ 个 token 带来的截断偏差，使损失在学生等于教师时取到最小；不加这一项，被截断的反向 KL 没有这个性质。

    top-k 形式还有一个实现上的好处：教师只要回传这 $k$ 个 token 的概率，数据量小到可以像一条奖励信号那样传输；全词表蒸馏则要每个位置都传输整个词表的分布。

    4. 教师回填不增加训练时间

    第三段新增的操作是教师回填：学生的每条轨迹都要过一遍对应的教师，取回逐 token 的对数概率。把教师回填并入强化学习的训练循环会增加基础设施的复杂度，还增加串行的等待时间。做法是把每个领域的教师部署成独立的回填服务，放在训练器之外。

    学生的采样器持续生成轨迹，一条轨迹一结束，训练器就向对应领域的教师服务发一个异步的回填请求；教师算出并返回逐 token 的对数概率。因为教师回填和别的轨迹的采样在时间上重叠，MOPD 的墙钟开销（实际流逝的时间）由采样主导，教师的开销被学生采样掩盖。

    5. 一个手算的逐步打分

    取一个只有三个 token 的微型词表 $\{A,B,C\}$，看一个位置上学生与教师的分布怎么变成一个 advantage、又怎么进入策略梯度的权重。学生是那个正在被训练、要在自生成轨迹上更新概率的模型；教师是这条提示被路由到的那个冻结的领域教师。

    分布与打分走一遍

    取一个位置的分布：学生 $\pi_\theta=(0.5,0.3,0.2)$，教师在同一个位置、同一个上下文（同一个提示 $x$、同样的 $y_{<t}$）下给 $\pi_{\phi_d}=(0.2,0.6,0.2)$。先按 $\hat{A}_{t}=\log\pi_{\phi_d}(y_t)-\log\pi_\theta(y_t)$ 逐个 token 算对数概率差。

    1. 学生在这个位置采样，采到 token $A$。
    2. 逐 token 的对数概率差就是 advantage $\hat{A}_{t}$：$A$ 是 $\log 0.2-\log 0.5=-0.9163$，$B$ 是 $\log 0.6-\log 0.3=0.6931$，$C$ 是 $\log 0.2-\log 0.2=0$。
    3. 判断：教师给 $B$ 的概率比学生大得多，$B$ 的 advantage 为正，采样到 $B$ 就被抬高；$A$ 反过来，advantage 为负，采样到 $A$ 就被压低。
    4. 这个 advantage 在策略梯度损失里的权重是 $-\hat{A}_{t}\log\pi_\theta(y_t)$，其中 $\log\pi_\theta(A)=\log 0.5=-0.6931$；抬高还是压低由 $\hat{A}_{t}$ 的符号决定，损失里带一个负系数 $-\hat{A}_{t}$。
    5. 把 advantage 按学生的概率加权求期望：$\sum_v\pi_\theta(v)\hat{A}_{v}=0.5\times(-0.9163)+0.3\times 0.6931+0.2\times 0=-0.2502$。
    6. 对照反向 KL：$D_{\mathrm{KL}}(\pi_\theta\|\pi_{\phi_d})=0.5\log\frac{0.5}{0.2}+0.3\log\frac{0.3}{0.6}+0.2\log\frac{0.2}{0.2}=0.5\times0.9163+0.3\times(-0.6931)=0.2502$，取负正好等于第 5 步的期望 advantage。

print("逐 token advantage")

print("负的反向 KL", round(-kl, 4))

    6. MOPD 的结构优势与同源教师

    第一，训练信号是逐 token 的稠密监督：教师在轨迹的每个位置都给出一整套概率分布，比标准强化学习只用轨迹级奖励稠密得多，方差更低、样本效率更高（样本效率指达到同等效果所需的样本多少）。第二，训练完全在学生自己的轨迹分布上，训练与推理的状态分布按构造一致，消除了分布失配。第三，能力在策略空间按提示路由合成，不靠权重的平均或改动方向的算术，避开了权重空间合并常见的不稳定。

    三项里第三项，策略空间集成的稳定，由教师与学生的分布接近支撑。领域教师是从同一个 SFT 检查点、也就是学生的初始化出发，经该领域 RL 得到的，教师与学生的策略分布天然接近，学生起点处的 KL 低，优化从头到尾平滑。第二项消除分布失配则是学生自采样按构造带来的，与教师是否同源无关。

    在同源教师下，两个实现形式的效果相当：在同样的教师、数据量和超参数（训练前设定、训练中不更新的配置量）下，策略梯度形式与 top-k 形式的总体能力接近。两者都稳定，数学准确率平滑上升，逐 token 反向 KL 从一个本来就很低的初始值单调下降，策略熵——策略分布的随机程度，越集中越小——稳定在 0.30 附近。

    同源教师与外部分布不同的教师

    把数学教师从同源 RL 教师换成更大、数学更强、但分布不同的外部模型，其余设置不变。归一化分统一以 SFT 学生为 0、以每个领域的教师为 1，衡量一个方法在某个领域补上了学生与教师之间多少差距。

    1. 同源 RL 教师下，策略梯度形式的归一化分是 0.9373，top-k 形式是 0.9093。
    2. 换成外部分布不同的教师，策略梯度形式掉到 0.6003，top-k 形式掉到 $-1.1898$。

    逐 token 反向 KL 的初始值，同源约 0.04，外部分布不同的教师约 0.19，高约 5 倍，这个差是外部教师更难收敛的原因之一。

    7. 适用条件与边界

    教师要与学生同源（由同一个 SFT 检查点各自的领域 RL 得到），学生初始的 KL 才会低；初始 KL 高时，策略梯度形式会让策略熵收缩、把学生压向单一模式，top-k 形式会直接失稳。此外，教师回填这一步还要求教师能给出对数概率。

    合入之后每个领域仍有缺口，剩下的要再走一轮来补。参数合并是另一条路，它不必训练，但跨领域看并不稳定，效果同时取决于合并系数（权重合并时各教师贡献的比例）和所选的基准（用来评测的那套测试集）。

    合入缺口与两处回退

    各基准上的每域归一化分落在 0.91 到 0.95 之间。

    把同一套流水线用到规模大得多的另一个基座上，多数基准追平或超过对应教师，两处小幅回退，指令遵循（按用户指令完成任务的能力）低 2.2、软件工程低 0.8。

    两条常见的说法并不成立：用更强的外部教师并不会得到更好的学生——把数学教师换成更大、数学更强的外部模型，学生的数学反而退化；教师 top-k 蒸馏也不会带来额外的稳定性或降方差。
