Block AttnRes

把深度方向的"等权累加残差"替换为"块级 softmax 加权检索"——每层用可学习 pseudo-query 对此前块级表征做 attention，让深网络每层都能按内容回看历史块。

更新于 2026-08-09 · 来源：Kimi K3 Technical Report §2.2 + HuggingFace 官方 config.json

这个概念是什么

Block AttnRes（块注意力残差）是 Kimi K3 的跨层信息流机制。标准残差把所有前层输出以系数 1 累加进同一个残差流，深网络中早期信息会被层层稀释；Block AttnRes 把主干按 12 层分块，每层用 attention 主动检索此前块级表征，而不是被动接收累加好的过去。它是 残差连接在深度方向的扩展——把"沿深度做累加"换成"沿深度做 attention"。

为什么需要它

  • 标准残差在深度上是瓶颈：93 层的 K3 主干里，第 1 层 embedding 在第 93 层的残差流中只占 1/93 的份额，且无法被后续层按内容找回。K3 报告把这一点类比为 RNN 在时间维度的瓶颈——所有历史被压进单一流。
  • Transformer 已用 attention 解决了 token 维度的同类问题：序列方向用 self-attention 替代 RNN 累加，让每个位置选择性访问前序位置。AttnRes 把同样的思路用到深度维度。
  • Full AttnRes 太贵：每层对所有前序层做 attention 需 $O(Ld)$ 内存保留所有层输出，93 层的 K3 用不起。Block AttnRes 把层分组、块内求和成单表征，内存降到 $O(Nd)$。

核心直觉

  • 每层自带 pseudo-query：每层有一个可学习参数向量 $q_l=w_l$（不依赖输入），与候选来源的内积决定权重。这与标准 attention 中 $Q=W_Q x$ 不同——pseudo-query 是层参数，不是输入函数。
  • 候选来源 = embedding + 此前块快照 + 当前块 partial sum：K3 把 93 层分 8 块（最后一块 partial），加上 embedding 共 9 个 block 级表征。对最后一个块内的层，候选 = 8 个块快照 + 当前 partial sum = 9 个。
  • 块内求和把 $L$ 个层输出压成 $N$ 个块表征：block $n$ 内所有层输出求和成 $b_n$，attention 只作用在块级表征上。这是内存从 $O(Ld)$ 降到 $O(Nd)$ 的来源。
  • softmax kernel 用 RMSNorm 防大值主导：$\phi(q,k)=\exp(q^\top\mathrm{RMSNorm}(k))$，RMSNorm 把 key 缩放到单位均方根，让 pseudo-query 按方向而非幅值选择来源。否则幅值大的层会主导 softmax，屏蔽其他来源。
  • K3 加权三次：每层 attention 子层前一次、MLP 子层前一次（两套独立参数）、模型末尾 final norm 前一次（output AttnRes 聚合所有块表征）。

关键结论与边界

  • Block AttnRes 不取消标准残差：K3 仍逐层累加 attention 与 MLP 输出（保留梯度流动性质）；AttnRes 替代的是"送入归一化的输入"，从"当前残差流"换成"attention 检索块级历史表征得到的结果"。这是最常见的误解。
  • 9 个候选是最大值，不是固定值：候选数随 block index 增长——block 1 的层只有 2 个候选（embedding + 当前 partial sum），最后一个 block 的 $i\ge 2$ 层才有 9 个。K3 实现预分配 9 个槽位适配最大值。
  • $N\approx 8$ 是经验结论：K3 报告 §2.2 转述原 AttnRes preprint [57] 的实验结论，在多数模型尺度下恢复 Full AttnRes 的大部分收益。本页未核对原 preprint 数据。
  • 不解决 token 维度与 channel 维度问题：AttnRes 只管深度方向；token 维度由 KDA / Gated MLA 负责，channel 维度由 Stable LatentMoE 负责。三者构成 K3 的三维信息流。
  • 加权三次的位置需区分证据层级：K3 报告原文确认"each module 各加权一次 + 末尾聚合"；具体"attention 前 / MLP 前 / final norm 前"三次位置来自 K3 前向数据流 note 对官方源码的核对（间接证据）。
