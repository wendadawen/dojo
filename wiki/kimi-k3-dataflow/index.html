    Kimi K3 前向数据流

    Kimi K3 是一个 2.78T 参数的 MoE 模型：93 层主干中，第 0 层为 KDA + Dense FFN，第 1–90 层按 KDA $\times$ 3 : Gated MLA $\times$ 1 循环混合，末尾第 91、92 层连续 MLA；FFN 全部是 Stable Latent MoE（896 路由专家 top-16 + 2 共享专家），并用 Block AttnRes 做跨块加权残差、SiTU-GLU 有界激活保证稳定；全模型无位置编码（NoPE），上下文 1M，每 token 激活 104.2B 参数。

    更新于 2026-08-05（2026-08-07 按官方源码修订 Block AttnRes 数据流）· 来源：官方 config.json 与官方实现代码 · 数值与公式逐项核对

    1. 关键规格

    规模总参数 2.78T；每 token 激活 104.2B；上下文 1,048,576
    主干93 层 = 69 层 KDA + 24 层 Gated MLA；hidden=7168；96 头；KDA head_dim=128
    层分布第 0 层（KDA + Dense FFN，first_k_dense_replace=1）；第 1–90 层 KDA $\times$ 3 : MLA $\times$ 1 循环（MLA 在 3,7,…,87）；第 91、92 层连续 MLA
    MoE896 路由专家，每 token 激活 16 个（稀疏度 $56\times$）；另有 2 个共享专家
    Latent MoErouted_expert_hidden_size=3584（隐空间）；moe_intermediate_size=3072；latent_moe_use_norm=true
    MLAq_lora_rank=1536；kv_lora_rank=512；qk_nope_head_dim=128；qk_rope_head_dim=64；v_head_dim=128；mla_use_output_gate=true
    KDAshort_conv_kernel_size=4；gate_lower_bound=$-5$（safe_gate）；use_full_rank_gate=true
    AttnResattn_res_block_size=12；8 个历史块快照（第 1 个即 embedding）+ 当前残差流 = 9 个候选；每层 attention 前与 MLP 前各加权一次，模型末尾再加权一次
    激活SiTU-GLU：activation_situ_beta=4.0，activation_situ_linear_beta=25.0，输出坐标上界 100
    词表vocab_size=163840；tie_word_embeddings=false（lm_head 独立权重）
    位置编码全模型 NoPE（MLA 不施加 RoPE，rotary_emb=None）
    视觉MoonViT-V2，401M 参数，27 层（vt_hidden=1024、patch=14，原生多模态）
    其他RMSNorm eps=1e-5；routed_scaling_factor=1.0；moe_renormalize=true；MXFP4 权重量化（QAT；范围=路由专家权重+embedding，attn/共享专家/lm_head/视觉塔豁免）

    3. 要点

    整体结构：三条信息流

    • 沿序列：69 层 KDA 做低成本、固定状态的长序列混合，每 3 层插入 1 层 Gated MLA 保留全局注意力，共 24 层 MLA；末两层（91、92）连续 MLA 收尾。
    • 沿深度：Block AttnRes 在等权累加的残差流上叠加块级加权：每层在 attention 前、MLP 前各加权一次（两套独立可学习参数），模型末尾 final norm 前再加权一次，让每层可按内容选择此前块级快照的信息。
    • 沿宽度：Stable LatentMoE 把路由专家放进 3584 维隐空间，扩到 896 个专家而通信/显存不随专家数线性增长。
    • KDA 与 MLA 均无显式位置编码（NoPE）：位置感由 KDA 的循环状态、衰减与短卷积隐式提供，扩展上下文无需 RoPE 插值。

    KDA（Kimi Delta Attention，69 层）

    • q/k/v 各自投影到 12288（$96 \times 128$）后过核长 4 的深度可分离因果短卷积 + silu；q/k 再 L2 归一。
    • 衰减信号 g 由 f_a_proj（7168→128）与 f_b_proj（128→12288）低秩生成，每 token/头/维一个；dt_bias 每头每维偏置；A_log 每头一个尺度。
    • 衰减率（K3 用 safe_gate）：$\log\alpha = -5\,\sigma\!\left(e^{A_{\log}}\cdot(g + \mathrm{dt\_bias})\right)$，即 lower-bound sigmoid，值域 $(-5, 0)$，每步衰减 $\exp(-5)\approx 0.0067$ 下限——不是非安全版本的 softplus 形式。
    • delta 规则：$S_t = (I - \beta_w\hat k\hat k^\top)\,\mathrm{diag}(\alpha)\,S_{t-1} + \beta_w\,\hat k\,v^\top$，写强度 $\beta_w$ 由 b_proj（7168→96，每头一标量）sigmoid 得到；输出 $o = S^\top\hat q$。
    • 输出门为全秩（use_full_rank_gate=true）：g_proj 7168→12288，FusedRMSNormGated 先 RMSNorm(o) 再与 $\sigma(g)$ 逐元素相乘。

    Gated MLA（24 层）

    • Q 路：q_a_proj 压缩到 1536 → RMSNorm → q_b_proj 升到 18432（$96\times192$）；每头 192 拆为 nope 128 + rot 64。
    • KV 路：kv_a_proj_with_mqa 压缩到 576（512 + 64），拆出压缩潜向量 ckv 与共享的 rot 键；ckv 过 RMSNorm 后 kv_b_proj 展开 96 头 $\times 256$，再拆 k_nope 128 与 v 128。
    • rot 分量仅做结构拆分，不施加旋转（rotary_emb=None）；q/k 拼回 192 维做标准因果注意力，scaling = $192^{-1/2}$。
    • 输出经 g_proj（7168→12288）sigmoid 门控（mla_use_output_gate=true）后 o_proj 投影回 7168。

    Stable Latent MoE（除第 0 层外全部 FFN）

    • 门控（KimiMoEGate）：sigmoid 打分 → top-16(s + bias) 选专家；bias 只影响排序、不进权重；选中专家权重按原始分数 renormalize 后乘 routed_scaling_factor=1.0。
    • 负载均衡：偏置在代码里沿用 DeepSeek-V3 的 e_score_correction_bias（结构相同、名字照搬）；训练时按技术报告用 Quantile Balancing 更新（取 margin 的 $1-k/n$ 分位数一步到位，无 sign-update 学习率），推理时冻结。开源推理代码不含该更新逻辑（训练路径未开源），Quantile Balancing 细节以技术报告为准。
    • 路由专家（KimiBlockSparseMLP）：w1=gate、w3=up、w2=down，在隐空间 3584→3072→3584，SiTU-GLU 有界激活。
    • 聚合后先 RMSNorm（latent_moe_use_norm=true）再上投影回 7168；共享专家为全宽 KimiMLP（intermediate $=3072\times2=6144$），对所有 token 恒激活。

    Block AttnRes（跨块注意力式残差）

    • 93 层按 12 层分块；块边界（layer_idx % 12 == 0，即 0,12,…,84）在 attention 前把进入该层时的输入快照存入 block_residual，共 8 个块快照（第 1 个即 embedding），加上当前残差流共 9 个候选。
    • 每层在 attention 前、MLP 前各做一次：把"当前残差流 + 全部历史块快照"做 RMSNorm，用层自带可学习打分权重（norm.weight $\times$ proj.weight）逐维相乘求和得标量分数，softmax 后加权求和作为送入 norm 的输入；模型末尾 final norm 前再做第三次（output_attn_res）。
    • 效果：深层能自适应地多信任近期块或回溯早期块，缓解 93 层深度下的信息稀释；开销从逐层的 $O(L\cdot d)$ 降到逐块的 $O(N\cdot d)$。

    Dense FFN（仅第 0 层）

    • first_k_dense_replace=1：只有第 0 层用稠密 KimiMLP，gate_proj/up_proj 7168→33792，SiTU-GLU 后 down_proj 33792→7168。
    • SiTU-GLU：门支 $\mathrm{SiTU}(g)=\beta\tanh(g/\beta)\,\sigma(g)$（$\beta=4$），值支 $\tilde u=\beta_l\tanh(u/\beta_l)$（$\beta_l=25$），两因子均平滑饱和，输出坐标上界 $\beta\cdot\beta_l=100$，从根源抑制激活爆炸。
