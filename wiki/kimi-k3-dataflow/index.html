    Kimi K3 前向数据流

    Kimi K3 是一个 2.78T 参数的 MoE 模型：93 层主干中，第 0 层为 KDA + Dense FFN，第 1–90 层按 KDA $\times$ 3 : Gated MLA $\times$ 1 循环混合，末尾第 91、92 层连续 MLA；FFN 全部是 Stable Latent MoE（896 路由专家 top-16 + 2 共享专家），并用 Block AttnRes 做跨块加权残差、SiTU-GLU 有界激活保证稳定；全模型无位置编码（NoPE），上下文 1M，每 token 激活 104.2B 参数。多模态输入时，27 层 MoonViT-V2 视觉塔把像素变成 7168 宽 token（个数与帧数无关），经占位符扩展融入同一序列，此后与文本共享全部 93 层。

    3. 要点

    整体结构：三条信息流

    • 沿序列：69 层 KDA 做低成本、固定状态的长序列混合，每 3 层插入 1 层 Gated MLA 保留全局注意力，共 24 层 MLA；末两层（91、92）连续 MLA 收尾。
    • 沿深度：Block AttnRes 在等权累加的残差流上叠加块级加权：每层在 attention 前、MLP 前各加权一次（两套独立可学习参数），模型末尾 final norm 前再加权一次，让每层可按内容选择此前块级快照的信息。
    • 沿宽度：Stable LatentMoE 把路由专家放进 3584 维隐空间，扩到 896 个专家而通信/显存不随专家数线性增长。
    • KDA 与 MLA 均无显式位置编码（NoPE）：位置感由 KDA 的循环状态、衰减与短卷积隐式提供，扩展上下文无需 RoPE 插值。

    KDA（Kimi Delta Attention，69 层）

    • q/k/v 各自投影到 12288（$96 \times 128$）后过核长 4 的深度可分离因果短卷积 + silu；q/k 再 L2 归一。
    • 衰减信号 g 由 f_a_proj（7168→128）与 f_b_proj（128→12288）低秩生成，每 token/头/维一个；dt_bias 每头每维偏置；A_log 每头一个尺度。
    • 衰减率（K3 用 safe_gate）：$\log\alpha = -5\,\sigma\!\left(e^{A_{\log}}\cdot(g + \mathrm{dt\_bias})\right)$，即 lower-bound sigmoid，值域 $(-5, 0)$，每步衰减 $\exp(-5)\approx 0.0067$ 下限——不是非安全版本的 softplus 形式。
    • delta 规则：$S_t = (I - \beta_w\hat k\hat k^\top)\,\mathrm{diag}(\alpha)\,S_{t-1} + \beta_w\,\hat k\,v^\top$，写强度 $\beta_w$ 由 b_proj（7168→96，每头一标量）sigmoid 得到；输出 $o = S^\top\hat q$。
    • 输出门为全秩（use_full_rank_gate=true）：g_proj 7168→12288，FusedRMSNormGated 先 RMSNorm(o) 再与 $\sigma(g)$ 逐元素相乘。

    Gated MLA（24 层）

    • Q 路：q_a_proj 压缩到 1536 → RMSNorm → q_b_proj 升到 18432（$96\times192$）；每头 192 拆为 nope 128 + rot 64。
    • KV 路：kv_a_proj_with_mqa 压缩到 576（512 + 64），拆出压缩潜向量 ckv 与共享的 rot 键；ckv 过 RMSNorm 后 kv_b_proj 展开 96 头 $\times 256$，再拆 k_nope 128 与 v 128。
    • rot 分量仅做结构拆分，不施加旋转（rotary_emb=None）；q/k 拼回 192 维做标准因果注意力，scaling = $192^{-1/2}$。
    • 输出经 g_proj（7168→12288）sigmoid 门控（mla_use_output_gate=true）后 o_proj 投影回 7168。

    Stable Latent MoE（除第 0 层外全部 FFN）

    • 门控（KimiMoEGate）：sigmoid 打分 → top-16(s + bias) 选专家；bias 只影响排序、不进权重；选中专家权重按原始分数 renormalize 后乘 routed_scaling_factor=1.0。
    • 负载均衡：偏置在代码里沿用 DeepSeek-V3 的 e_score_correction_bias（结构相同、名字照搬）；训练时按技术报告用 Quantile Balancing 更新（取 margin 的 $1-k/n$ 分位数一步到位，无 sign-update 学习率），推理时冻结。开源推理代码不含该更新逻辑（训练路径未开源），Quantile Balancing 细节以技术报告为准。
    • 路由专家（KimiBlockSparseMLP）：w1=gate、w3=up、w2=down，在隐空间 3584→3072→3584，SiTU-GLU 有界激活。
    • 聚合后先 RMSNorm（latent_moe_use_norm=true）再上投影回 7168；共享专家为全宽 KimiMLP（intermediate $=3072\times2=6144$），对所有 token 恒激活。

    Block AttnRes（跨块注意力式残差）

    • 93 层按 12 层分块；块边界（layer_idx % 12 == 0，即 0,12,…,84）在 attention 前把进入该层时的输入快照存入 block_residual，共 8 个块快照（第 1 个即 embedding），加上当前残差流共 9 个候选。
    • 每层在 attention 前、MLP 前各做一次：把"当前残差流 + 全部历史块快照"做 RMSNorm，用层自带可学习打分权重（norm.weight $\times$ proj.weight）逐维相乘求和得标量分数，softmax 后加权求和作为送入 norm 的输入；模型末尾 final norm 前再做第三次（output_attn_res）。
    • 效果：深层能自适应地多信任近期块或回溯早期块，缓解 93 层深度下的信息稀释；开销从逐层的 $O(L\cdot d)$ 降到逐块的 $O(N\cdot d)$。

    Dense FFN（仅第 0 层）

    • first_k_dense_replace=1：只有第 0 层用稠密 KimiMLP，gate_proj/up_proj 7168→33792，SiTU-GLU 后 down_proj 33792→7168。
    • SiTU-GLU：门支 $\mathrm{SiTU}(g)=\beta\tanh(g/\beta)\,\sigma(g)$（$\beta=4$），值支 $\tilde u=\beta_l\tanh(u/\beta_l)$（$\beta_l=25$），两因子均平滑饱和，输出坐标上界 $\beta\cdot\beta_l=100$，从根源抑制激活爆炸。

    4. 视觉编码器与多模态融合

    视觉侧是一个 27 层的独立 MoonViT-V2：参数 401,214,464（技术报告称 MoonViT-V2 401M），加 merger 的 46,144,512 共 447.4M，占全模型约 0.16%。它的职责是把像素变成 7168 宽 token；融合之后视觉与文本在同一序列里共享全部 93 层，不存在贯穿深度的独立视觉分支。「视觉编码器」与「多模态融合」两个视图给出完整路径。

    4.1 patch 投影：一次 Conv2d

    patch_embed 是 Conv2d，kernel 与 stride 都等于 patch_size=14，因此每个 patch 独立映射、互不重叠，等价于对展平后的 $3\times14\times14=588$ 维向量做一次 $588\to1024$ 的线性变换；无 bias（patch_embed_proj_bias=false）。权重形状 $[1024,3,14,14]$，共 602,112 参数。像素边长非 14 整数倍时由 processor 先 resize；视频沿时间维分组，每组 t 帧，$t\le 4$（位置嵌入时间表仅 4 帧，源码 assert）。patch 数 $=t\cdot h\cdot w$。

    4.2 位置信息：可学习方格插值 + 2D RoPE 双轨

    视觉侧两套位置机制职责不同。

    • divided_fixed 位置嵌入：一张可学习的 $64\times64$ 方格表（4,194,304 参数），对每张图按其实际 $(h,w)$ 双线性插值后与 patch 特征相加——位置信息跟随图像真实长宽比，无需 resize 成固定尺寸。$t>1$ 时 2D 嵌入重复 t 份，再加一份冻结的 1D sincos 时间嵌入（非持久 buffer，仅 4 帧）。本机实测 $t=3$ 时输出恰为「2D 嵌入重复 3 份 + time_weight[0:3] 逐元素相加」。
    • 2D RoPE（Rope2DPosEmbRepeated）：作用于注意力头维 128，相邻频率槽交错编码宽（偶数槽，$x\_pos=\mathrm{flat}\%W$）与高（奇数槽，$y\_pos=\mathrm{flat}//W$），$\theta$ 基 10000，网格硬上限 $512\times512$。源码 docstring 把 h/w 标注写反，此处按代码实测行为记录；本机实测旋转严格保范数（33.935440 → 33.935440）。

    与语言塔形成对照：语言主干全模型 NoPE（rotary_emb=None），视觉塔反而用满 2D RoPE——位置感在视觉侧由显式编码提供，在语言侧由 KDA 的循环状态隐式提供。

    4.3 27 层 block：与语言主干的差别

    视觉 block 是标准 pre-norm 结构，相对语言主干有五处明显差别。

    项目视觉塔语言主干
    注意力双向、变长打包（cu_seqlens）、12 头 × 128（头维 $=$ qkv_hidden/heads $\ne$ hidden/heads $=85.3$）KDA 96×128 因果 / MLA 96 头 NoPE 因果
    FFN稠密 MLP2：1024→4096→1024，GELU(tanh)Stable Latent MoE / 第 0 层 Dense，SiTU-GLU
    位置编码2D RoPE + 可学习方格NoPE
    量化vision_tower 与 mm_projector 均豁免 MXFP4路由专家权重 + embedding 量化

    归一化两侧一致（RMSNorm、无 bias）。多图输入时同一图像内所有 patch 互相可见、跨图不互注意——本机实测两图拼接跑与分开跑输出逐元素一致（max diff < 1e-5），印证 cu_seqlens 块对角掩码。

    4.4 merger：时间全池化 + 2×2 空间合并

    merge_type=sd2_tpool（spatial downsampling 2× with temporal pooling all）在一个函数里完成两件事：先把 t 帧沿时间维全部平均（本机实测第 1/2/3 帧分别填 1/2/3，合并后处处为 2.0），再把空间上 2×2 相邻的 4 个 patch 捆成一个 token 的 4 份特征（不相加，留给投影层混合）。随后 PatchMergerMLPV2 做两层无 bias 线性（4096→4096→7168，GELU）加 RMSNorm(7168)；V1 版本的 pre_norm（LayerNorm@1024）在 V2 中已移除。

    时间全池化的直接后果：视觉 token 数与帧数无关，$n_{vis}=(h/2)(w/2)$。一张 448×448 图无论 1 帧还是 4 帧都是 256 个 token——视频的帧间信息在进入语言主干前已被压缩进单帧特征。这与 Qwen3.8-Flash-Next（视觉 token 数 $\propto t$）是两种取舍：K3 用帧信息换上下文预算，qwen 保留全部帧。

    4.5 融合：占位符扩展，序列变长

    融合发生在 embedding 之后、第 0 层之前，核心是 _merge_input_ids_with_image_features 的三步：① 全 1 的 occupation 表把每个占位符位置（media_placeholder_token_id=163605）改写为该图的 $n_i$；② cumsum − 1 得到所有 token 的新位置，占位符之后的文本整体后移；③ 文本 embedding 与视觉特征交错写入长度为 $T'=T-\#\mathrm{PH}+\textstyle\sum_i n_i$ 的新序列。

    本机实测（官方方法原样调用）：6 位序列含 1 个占位符加 5 个视觉 token，输出 10 位，文本落在 0–2 与 8–9、视觉特征按序落在 3–7，position_ids 连续 0..9；两占位符两图（3+2 token）输出 8 位，交错序列 [文本, 图1×3, 文本, 图2×2, 文本] 逐元素正确；视觉段 labels 填 ignore_index=-100。

    三个边界行为：占位符数必须等于输入图数（段多于占位符在 occupation 表 broadcast 处即报错，占位符多于段在填充校验处抛 ValueError）；纯文本输入不进融合函数（官方 forward 有 pixel_values 非空守卫）；decode 单步（len(ids)==1 且带 KV cache）不重跑融合，只按 cache 痕迹修补 attention_mask。

    这是 LLaVA 式扩展融合，与 Qwen3.8-Flash-Next 的 masked_scatter 原地替换（processor 预先填充等量占位符、序列长度不变）是两种方案。扩展式让 tokenizer 层面的序列长度与实际进入主干的长度解耦；替换式把对齐责任前移到 processor。

    5. 长上下文开销的来源

    推理时的缓存/状态开销由层型比例决定：69 层 KDA 的递归状态与短卷积状态固定不变，24 层 MLA 的 KV cache 随长度线性增长。按官方 config 精确计算（bf16）：

    上下文MLA KV × 24 层（参考实现）MLA KV × 24 层（潜压缩）KDA 状态 × 69 层合计（参考口径）
    4K5.625 GiB0.105 GiB0.216 GiB5.841 GiB
    32K45.000 GiB0.844 GiB0.216 GiB45.216 GiB
    128K180.000 GiB3.375 GiB0.216 GiB180.216 GiB
    256K360.000 GiB6.750 GiB0.216 GiB360.216 GiB
    1M1440.000 GiB27.000 GiB0.216 GiB1440.216 GiB

    两个口径分开陈述。参考实现口径：官方 HF 参考实现缓存的是 kv_b_proj 展开后的 96 头 K(192)+V(128)，即 60 KiB/token/层——不利用 MLA 的潜空间压缩。若 93 层全为这种 MLA，1M 上下文需 5.45 TiB；层型 24/93 使其降到 25.8%。潜压缩口径：每 token 只存压缩潜向量 ckv(512)+k_rot(64)=576（1.125 KiB/token/层，kv_b_proj 权重可吸收进查询投影），1M 上下文 24 层共 27 GiB——生产部署按此理解 1M 上下文的可行性，参考口径只用来读出层型比例的结构意义。KDA 侧每层固定递归状态 3.0 MiB（96×128×128）加短卷积状态 216 KiB（q/k/v 三个 12288×3 滑窗），69 层合计 0.216 GiB，与序列长度完全无关。

    多模态输入对开销的影响集中在 MLA 层：一张 448×448 图贡献 256 个视觉 token，24 层 MLA 参考口径新增 KV 360 MiB（prefill 一次性）；视觉塔本身的 447.4M 参数对所有输入恒定加载。

    6. 核对方式

    结构与维度以官方 config.json 与 modeling_kimi_k3.py、modeling_kimi_linear.py 源码为准，两个文件与 config 的快照存于 research/。视觉与融合机制直接加载官方源码组件实测：probe1_vision.py 覆盖 patch 投影、位置嵌入（含 t=3 展开与 t>4 报错）、2D RoPE（槽位归属、保范数、512 上限）、27 层 block（含两图拼接与分开跑的等价性）、时间池化均值、PatchMergerMLPV2 形状链与参数量，共 40 项断言；probe2_fusion.py 以 unbound 方式调用官方 _merge_input_ids_with_image_features，覆盖单/双占位符扩展落位、position_ids、报错边界与 decode 守卫，共 16 项断言；probe3_memcost.py 按官方 config 精确计算第 5 节开销表。原始输出见 research/measured-output.txt。

    关键实测结论：视觉塔参数 401,214,464 与技术报告的 401M 吻合（27 层每层 14,682,112 + patch 602,112 + 位置表 4,194,304 + final norm 1,024）；两图拼接跑与分开跑输出逐元素一致（max diff < 1e-5）；时间池化恰为均值；RoPE 偶数槽编码宽、奇数槽编码高（源码 docstring 与实现相反，以代码为准）；融合扩展 6 位→10 位、交错落位逐元素正确；KDA 69 层固定状态 0.216 GiB、MLA 参考口径 1M 上下文 1440 GiB / 潜压缩口径 27 GiB。
