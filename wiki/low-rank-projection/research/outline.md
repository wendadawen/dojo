# 教学大纲：低秩分解

## 1. 页面开头

**钩子问题**：训练一个 1750 亿参数的 GPT-3，微调时如果每个任务都要存一份完整权重，存储成本高到无法部署多任务。但如果"权重更新量"其实只需要极少的数字就能表达呢？推理时，注意力要为每个 token 缓存 K 和 V，长上下文下 KV cache 占满显存。但如果这些 K/V 其实可以用一个很小的向量重建呢？

**一句话解释**：低秩分解把一个大矩阵 $W$ 拆成两个小矩阵 $A, B$ 的乘积（$W \approx AB$），用 $r(m+n)$ 个参数代替 $mn$ 个参数，在 $r \ll \min(m,n)$ 时大幅减少参数与存储。

**学习承诺**（learning-goals 组件，3-5 条，与 scope.md Q1-Q5 一致）。

**首个具体场景**：LoRA 微调——冻结 1750 亿参数的 $W_0$，只训练 $A, B$ 两个小矩阵。

**与第一章的过渡**：要理解"为什么两个小矩阵能近似一个大矩阵"，先要看清大矩阵到底贵在哪里、以及什么决定了它"能被压缩多少"。

## 2. 章节设计

### S1：大矩阵为什么贵——参数与存储的成本

- 主要教学问题：一个大矩阵在参数和存储上带来什么成本？为什么我们需要压缩它？
- 对应范围：Q1 的动机部分；F5（参数计数）。
- 正文要点：
  - 神经网络的一层线性变换 $h = Wx$，$W \in \mathbb{R}^{m \times n}$ 需要 $mn$ 个参数
  - 代入 LLM 规模：$d = 12288$ 时一个方阵权重 $d^2 \approx 1.5$ 亿参数
  - 推理时注意力要为每个 token 缓存 K 和 V，各 $n_h d_h$ 维
  - 成本公式：存一个 $m \times n$ 矩阵要 $mn$ 个数；缓存一个 $d$ 维向量要 $d$ 个数
- 讲解材料及职责：
  - context-box：给出"成本场景"键值（参数场景、缓存场景、共性）
  - 公式 F5 的来源：维度算术
- 前置知识安排：矩阵乘法 $h=Wx$ 一句话说明（无概念页，占位提示）
- 完成检查：
  - 一个 $d=12288$ 的方阵权重有多少参数？
  - MHA 每 token 每层缓存多少个数（用 $n_h, d_h$ 表示）？
- 过渡：成本来自"矩阵的每个元素都要存"。但如果矩阵内部有冗余——很多元素可以由少数几个数推出——就能压缩。什么衡量这种冗余？答案是"秩"。

### S2：矩阵的秩——能被压缩多少由什么决定

- 主要教学问题：什么是矩阵的秩？为什么"低秩"意味着可以用更少的数表达？
- 对应范围：Q1；C1 的直觉铺垫。
- 正文要点：
  - 秩的直觉定义：矩阵的列（或行）张成的空间维度 = 独立方向数
  - 若 $W = AB$，$A \in \mathbb{R}^{m \times r}$、$B \in \mathbb{R}^{r \times n}$，则 $\mathrm{rank}(W) \le r$（因为 $W$ 的每一列都是 $A$ 的列的线性组合）
  - 反过来：若 $\mathrm{rank}(W) = r$，则存在分解 $W = AB$ 使 $A \in \mathbb{R}^{m \times r}, B \in \mathbb{R}^{r \times n}$
  - 参数对比：$mn$（原矩阵）vs $r(m+n)$（分解）；当 $r \ll \min(m,n)$ 时 $r(m+n) \ll mn$
  - 数值代入：$m=n=12288, r=2$ → $mn \approx 1.5 \times 10^8$，$r(m+n) = 49152$，比例 $\approx 0.033\%$
  - 关键限制：只有当矩阵真的低秩时才能无损分解；现实中矩阵往往满秩，所以需要"近似"
- 讲解材料及职责：
  - ASCII 图示：$m \times n$ 大矩阵 = $m \times r$ 瘦矩阵 × $r \times n$ 矮矩阵
  - 公式：$W = AB \Rightarrow \mathrm{rank}(W) \le r$；参数 $mn \to r(m+n)$
  - 数字例子：$12288 \times 12288$ 的参数对比
- 前置知识安排：矩阵乘法的列视角（$Wx$ 的第 $i$ 个元素是 $A$ 第 $i$ 行与 $Bx$ 的内积）——一句话带过
- 完成检查：
  - 若 $W \in \mathbb{R}^{1000 \times 1000}$ 且 $\mathrm{rank}(W)=5$，用 $W=AB$ 分解后需要多少参数？比原矩阵少多少倍？
  - 为什么"满秩矩阵无法无损压缩"？
- 过渡：现实中大矩阵几乎满秩，无法无损分解。但很多矩阵"接近低秩"——它们的大部分信息集中在前几个方向。如何找到"最好的 $r$ 维近似"？SVD 给出答案。

### S3：SVD 与最优低秩近似——误差由奇异值决定

- 主要教学问题：如何找到对 $W$ 最好的秩-$k$ 近似？这个"最好"的误差是多少？
- 对应范围：Q2；C2；F2, F3。
- 正文要点：
  - SVD：$W = U\Sigma V^\top$，$\Sigma$ 对角线是奇异值 $\sigma_1 \ge \sigma_2 \ge \cdots \ge 0$，按从大到小排序
  - 奇异值的含义：第 $i$ 个奇异值衡量矩阵在第 $i$ 个主方向上的"强度"或"能量"
  - 截断 SVD：$W_k = \sum_{i=1}^{k}\sigma_i u_i v_i^\top$，保留前 $k$ 大方向
  - Eckart-Young-Mirsky 定理：$W_k$ 是所有秩 $\le k$ 矩阵中对 $W$ 的最优近似
  - 误差公式：$\|W - W_k\|_F = \sqrt{\sum_{i>k}\sigma_i^2}$（Frobenius），$\|W - W_k\|_2 = \sigma_{k+1}$（谱）
  - 关键直觉：奇异值衰减越快，截断丢的越少；若 $\sigma_{k+1}$ 及以后都很小，低秩近似就好
  - $W_k$ 本身就是一次低秩分解：$W_k = U_k \Sigma_k V_k^\top = (U_k \Sigma_k^{1/2})(\Sigma_k^{1/2} V_k^\top) = AB$，所以 SVD 给出的最优近似天然是 $AB$ 形式
- 讲解材料及职责：
  - 公式 F2, F3：SVD 与误差
  - 数字例子折叠块：3×3 对角矩阵 $W = \mathrm{diag}(3,1,0.5)$ 的秩-1、秩-2 近似与误差手算（教学示例 N5）
  - 补充折叠块：Eckart-Young 最优性的直觉说明（为何截前 $k$ 大奇异值是最优的）
- 前置知识安排：无新前置；SVD 的存在性直接使用
- 完成检查：
  - 对 $W = \mathrm{diag}(5, 2, 0.1)$，秩-1 近似的 Frobenius 误差是多少？谱范数误差是多少？
  - 什么形状的奇异值分布适合低秩近似？什么形状不适合？
- 过渡：SVD 告诉我们"最优低秩近似存在且误差可控"。现在看两个 LLM 中的实际应用：LoRA 把它用在"权重更新"上，MLA 把它用在"KV 压缩"上。

### S4：LoRA——把权重更新参数化为低秩

- 主要教学问题：LoRA 如何用低秩分解把微调参数减到原模型的极小比例？
- 对应范围：Q3；C1；F1；N1, N2。
- 正文要点：
  - 微调的本质：$W_{\text{新}} = W_0 + \Delta W$，全量微调要训练整个 $\Delta W \in \mathbb{R}^{d \times d}$（$d^2$ 参数）
  - LoRA 假设（C1）：权重更新 $\Delta W$ 有低"内在秩"，所以令 $\Delta W = BA$，$B \in \mathbb{R}^{d \times r}, A \in \mathbb{R}^{r \times d}$
  - 前向：$h = W_0 x + BAx$（F1），$W_0$ 冻结，只训练 $A, B$
  - 参数：$d^2 \to 2dr$；$d=12288, r=2$ → $1.5 \times 10^8 \to 49152$，约 $0.033\%$（N2）
  - 论文报告 GPT-3 175B 可低至 $0.01\%$（N1）
  - 初始化：$A$ 随机高斯、$B = 0$，使训练开始时 $\Delta W = BA = 0$（从预训练权重出发）
  - 注意区分：LoRA 不是对 $W_0$ 做低秩近似，而是把"要学的更新量"参数化为低秩——学到什么就是什么
- 讲解材料及职责：
  - 公式 F1：$h = W_0 x + BAx$
  - ASCII 图示：$W_0$（冻结，大）+ $B, A$（训练，小）的拼接结构
  - 数字例子：$d=12288, r=2$ 的参数对比
  - 对照表格：全量微调 vs LoRA 的参数、存储、切换成本
- 前置知识安排：无
- 完成检查：
  - LoRA 中 $B$ 初始化为零的作用是什么？
  - $d=4096, r=8$ 时 LoRA 的训练参数是全量微调的多少比例？
  - 为什么说 LoRA "不是在近似 $W_0$"？
- 过渡：LoRA 用低秩分解减少"要训练的参数"。MLA 换了个角度——它用低秩投影减少"推理时要缓存的向量"。

### S5：MLA——把 KV 压进低维潜向量

- 主要教学问题：MLA 如何用低秩压缩减少 KV cache？缓存的具体是什么？
- 对应范围：Q4；C3；F4, F6；N3, N4。
- 正文要点：
  - MHA 的 KV cache：每 token 每层缓存 K 和 V，各 $n_h d_h$ 维，共 $2 n_h d_h$ 个数（F6）
  - MLA 的低秩压缩（F4）：先下投影 $c_t^{KV} = W^{DKV} h_t$ 把 $d$ 维隐藏状态压成 $d_c$ 维潜向量；K/V 由上投影重建 $k_t^C = W^{UK} c_t^{KV}, v_t^C = W^{UV} c_t^{KV}$
  - 只缓存 $c_t^{KV}$（$d_c$ 维），不缓存 K/V 本身
  - 维度：$W^{DKV} \in \mathbb{R}^{d_c \times d}$，$W^{UK}, W^{UV} \in \mathbb{R}^{d_h n_h \times d_c}$
  - 这就是一次低秩分解：$k_t^C = W^{UK} W^{DKV} h_t$，等价于用一个秩 $\le d_c$ 的矩阵 $W^{UK}W^{DKV}$ 代替满秩的 $W^K$
  - DeepSeek-V2 配置（N3）：$n_h=128, d_h=128, d_c=512$；$2n_h d_h = 32768$ vs $d_c = 512$
  - 论文报告 KV cache 减少 93.3%（N4，含解耦 RoPE 项的整体降幅）
  - 有损性：重建的 K/V 与 MHA 直接投影的不等价（C3 的适用条件）
  - 完整 MLA 机制（RoPE 解耦、矩阵吸收）见 MLA 概念页
- 讲解材料及职责：
  - 公式 F4：下投影 + 上投影
  - ASCII 图示：MHA 缓存 K,V vs MLA 只缓存 $c_{KV}$ 的对比
  - 数字例子：$d_c=512$ vs $2n_h d_h = 32768$ 的对比
  - 对照表格：MHA vs MLA 的缓存维度
- 前置知识安排：标准注意力的 K/V 与 KV cache（链接 standard-attention 概念页）
- 完成检查：
  - MLA 缓存的是 K 和 V 本身，还是别的东西？维度是多少？
  - 为什么说 $k_t^C = W^{UK} W^{DKV} h_t$ 是一次低秩分解？
  - 重建的 K/V 与 MHA 的 K/V 等价吗？
- 过渡：LoRA 和 MLA 都依赖"目标矩阵低秩"这一假设。但这个假设不是总是成立——最后一章看它的边界。

### S6：适用边界——低秩不是万能的

- 主要教学问题：低秩近似在什么条件下失效？有哪些实际教训？
- 对应范围：Q5；C4。
- 正文要点：
  - 失效条件：奇异值平坦时，截断丢的信息多（由 F3 误差公式直接推出）
  - LoRA 的假设边界：若任务需要高秩更新（权重变化跨很多方向），小 $r$ 的 LoRA 效果受限
  - MLA 的有损性：低秩压缩重建的 K/V 与 MHA 不等价；$d_c$ 太小会丢信息
  - KDA 的教训（C4）：Kimi Linear 用 low-rank 门控，K3 改为 full-rank（`use_full_rank_gate = true`），因为低秩门控表达力不足——这是"低秩不够用就回到满秩"的真实案例
  - 选择低秩的依据：看奇异值是否快速衰减；工程上靠实验验证
- 讲解材料及职责：
  - 对照表格：奇异值快速衰减 vs 平坦两种情况的近似效果
  - callout：核心边界提示
- 前置知识安排：无
- 完成检查：
  - 什么样的奇异值分布不适合低秩近似？
  - K3 为什么把门控从 low-rank 改成 full-rank？
  - MLA 的低秩压缩是有损还是无损？
- 过渡：（文末来源与教学说明）

## 3. 讲解顺序

S1（成本动机）→ S2（秩 = 可压缩量）→ S3（SVD = 最优近似 + 误差）→ S4（LoRA 应用）→ S5（MLA 应用）→ S6（边界）。

先讲"为什么贵"再讲"什么决定能压多少"，再讲"最优怎么压"，最后两次落地应用和边界。每个新概念在首次依赖前完成讲解：秩在 S2 讲清后 S3/S4/S5 才用；SVD 在 S3 讲清后 S4/S5 引用"低秩分解"时不再重讲；LoRA/MLA 的具体机制分别在 S4/S5 首次出现。

## 4. 贯穿例子

**主线例子**：参数/缓存的维度算术。从 S1 的 $mn$ 成本，到 S2 的 $r(m+n)$ 分解，到 S3 的 $W_k$ 误差，到 S4 的 $d^2 \to 2dr$（LoRA），到 S5 的 $2n_h d_h \to d_c$（MLA）。每次复用都增加一层（成本 → 秩 → 误差 → 训练参数 → 推理缓存），数字可手算。

**局部例子**：S3 的 $3 \times 3$ 对角矩阵 $W = \mathrm{diag}(3, 1, 0.5)$ 用于手算 SVD 误差公式，服务"误差由奇异值决定"这一具体问题。
