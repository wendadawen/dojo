    低秩分解：用两个小矩阵的乘积近似大矩阵

    主要依据：LoRA 论文（Hu et al., arXiv:2106.09685v2, §1/§4）；DeepSeek-V2 论文（arXiv:2405.04434v2, §2.1.2）；Wikipedia "Singular value decomposition" 与 "Low-rank approximation"（Eckart-Young-Mirsky 定理与误差公式）。

    GPT-3 的隐藏维度 $d = 12288$，单个 $d \times d$ 权重矩阵约 1.5 亿参数，全量微调每个任务都要存一份完整权重；标准注意力推理时每个 token 要缓存 K 和 V，长上下文下 KV cache 占满显存。但如果"权重更新量"只需要极少的数字就能表达，缓存的 K/V 可以用一个小向量重建呢？这两个问题的答案都指向同一个工具——低秩分解：把一个大矩阵 $W$ 拆成两个小矩阵 $A, B$ 的乘积 $W \approx AB$，用 $r(m+n)$ 个参数代替 $mn$ 个参数。本文从"大矩阵为什么贵"出发，讲清秩与可压缩性、SVD 给出的最优低秩近似及其误差公式，再落到 LoRA 微调和 MLA 的 KV 压缩两个 LLM 实际应用，最后说明适用边界。

    大矩阵为什么贵——参数与存储的成本

    神经网络的一层线性变换写成 $h = Wx$：输入向量 $x$ 乘以权重矩阵 $W$ 得到输出 $h$。这里"$Wx$"表示用矩阵 $W$ 对向量 $x$ 做一次线性变换——$W$ 的每一行与 $x$ 做内积，得到 $h$ 的一个分量。一个 $W \in \mathbb{R}^{m \times n}$ 的矩阵有 $m \times n$ 个元素，每个元素都是一个要存储和训练的参数[F5]。

    代入 LLM 的规模感受一下。GPT-3 的隐藏维度 $d = 12288$，一个 $d \times d$ 的方阵权重有

    $$d^2 = 12288^2 = 150{,}994{,}944 \approx 1.5 \times 10^8$$

    个参数——单个权重矩阵就一亿五千万。全量微调时要为每个参数计算梯度、维护优化器状态，部署多任务时每个任务存一份完整权重。

    推理时的注意力有另一类成本。标准多头注意力（MHA）为序列里的每个 token 计算并缓存 K 和 V 两个向量，各 $n_h d_h$ 维（$n_h$ 个头、每头 $d_h$ 维），所以每 token 每层缓存 $2 n_h d_h$ 个数[F6]。序列一长，这个缓存随 token 数线性增长，很快占满显存。关于 K/V 和 KV cache 的完整说明见标准注意力概念页。

    成本的根本来源是：矩阵的每个元素都要存。但如果矩阵内部有冗余——很多元素可以由少数几个数推出——就能压缩。什么衡量这种冗余？答案是矩阵的秩。

    • 一个 $d = 12288$ 的方阵权重有多少个参数。
    • MHA 每 token 每层缓存多少个数（用 $n_h, d_h$ 表示）。
    • 说明成本根源"每个元素都要存"与"冗余可以压缩"为何不矛盾。

    本章说明大矩阵的成本来自"每个元素都要存"。但元素是否有冗余、能压缩多少——下一章讲矩阵的秩如何决定可压缩量。

    矩阵的秩——能被压缩多少由什么决定

    矩阵的秩（rank）是它的列（或行）张成空间的维度，直观地说就是矩阵里"独立方向"的个数。如果 $W$ 的所有列都可以由少数几个列向量线性组合出来，那 $W$ 的秩就低——它携带的独立信息少。

    关键联系：如果 $W = AB$，其中 $A \in \mathbb{R}^{m \times r}$、$B \in \mathbb{R}^{r \times n}$，那么 $W$ 的每一列都是 $A$ 的列向量的线性组合（组合系数由 $B$ 的对应列给出），因此 $W$ 最多有 $r$ 个独立的列方向：

    $$W = AB \quad \Longrightarrow \quad \mathrm{rank}(W) \le r.$$

    反过来也成立：如果 $\mathrm{rank}(W) = r$，那么存在分解 $W = AB$ 使 $A \in \mathbb{R}^{m \times r}$、$B \in \mathbb{R}^{r \times n}$。这就是说，秩 $r$ 的矩阵可以无损地写成两个"瘦"矩阵的乘积。

      W (m×n)              A (m×r)         B (r×n)
┌─────────────┐      ┌───┐           ┌─────────────┐
│             │      │   │           │             │
│             │  =   │   │     ×     │             │
│             │      │   │           │             │
│             │      │   │           │             │
└─────────────┘      └───┘           └─────────────┘
   mn 个数            mr 个数          rn 个数
                     合计 r(m+n) 个数

当 r ≪ min(m,n) 时，r(m+n) ≪ mn

    现在算参数。原矩阵 $W \in \mathbb{R}^{m \times n}$ 有 $mn$ 个参数；分解成 $AB$ 后有 $mr + rn = r(m+n)$ 个参数[F5]。当 $r \ll \min(m, n)$ 时，$r(m+n)$ 远小于 $mn$。

    代入 LLM 规模：$m = n = 12288$、$r = 2$（LoRA 论文指出 rank 可以低至 1 或 2 就足够[N2]）：

    $$mn = 12288^2 \approx 1.5 \times 10^8, \qquad r(m+n) = 2 \times 24576 = 49152.$$

    比例 $49152 / 150994944 \approx 0.033\%$——从一亿五千万降到不到五万。这就是低秩分解的威力。

    但这里有个根本限制：只有当矩阵真的低秩时，$W = AB$ 才是精确的。现实中 LLM 的权重矩阵几乎都是满秩的（$d \times d$ 矩阵秩为 $d$），无法无损分解。所以实际用的不是"精确分解"，而是"近似"——找一个秩 $\le r$ 的矩阵 $\hat{W}$ 使它尽量接近 $W$。如何找到这个最好的 $\hat{W}$？SVD 给出答案。

    本章建立了"秩 = 可压缩量"。但现实中矩阵满秩，无法无损分解——下一章讲 SVD 如何在"近似"意义下给出最优的低秩压缩与误差公式。

    SVD 与最优低秩近似——误差由奇异值决定

    奇异值分解（SVD）把任意矩阵 $W \in \mathbb{R}^{m \times n}$ 分解为三个矩阵的乘积：

    $$W = U \Sigma V^\top,$$

    其中 $U$ 是 $m \times m$ 正交矩阵，$V$ 是 $n \times n$ 正交矩阵，$\Sigma$ 是 $m \times n$ 对角矩阵，对角线上的非负实数 $\sigma_1 \ge \sigma_2 \ge \cdots \ge \sigma_{\min(m,n)} \ge 0$ 按从大到小排序，称为奇异值[F2]。用 $u_i, v_i$ 分别记 $U, V$ 的第 $i$ 列，SVD 也可以写成：

    $$W = \sum_{i=1}^{\min(m,n)} \sigma_i \, u_i v_i^\top.$$

    奇异值的含义是：第 $i$ 个奇异值衡量矩阵在第 $i$ 个"主方向"上的强度。$\sigma_1$ 最大，说明矩阵在 $u_1 v_1^\top$ 这个方向上最强；后面的奇异值依次递减，对应越来越弱的方向。

    截断 SVD只保留前 $k$ 大的奇异值，得到秩-$k$ 近似：

    $$W_k = \sum_{i=1}^{k} \sigma_i \, u_i v_i^\top.$$

    $W_k$ 本身就是一次低秩分解：令 $A = U_k \Sigma_k^{1/2}$（$m \times k$）、$B = \Sigma_k^{1/2} V_k^\top$（$k \times n$），则 $W_k = AB$，内维为 $k$。所以 SVD 给出的最优近似天然就是 $AB$ 形式。

    为什么说 $W_k$ 是"最优"的？Eckart-Young-Mirsky 定理保证：在所有秩不超过 $k$ 的矩阵中，$W_k$ 是对 $W$ 最接近的近似，无论用 Frobenius 范数还是谱范数衡量[C2]。这里的"最接近"有精确含义——任何其他秩 $\le k$ 的矩阵 $\hat{W}$，都有 $\|W - W_k\| \le \|W - \hat{W}\|$。

    近似误差由被截掉的奇异值决定[F3]：

    $$\|W - W_k\|_F = \sqrt{\sigma_{k+1}^2 + \sigma_{k+2}^2 + \cdots}, \qquad \|W - W_k\|_2 = \sigma_{k+1}.$$

    其中 $\|\cdot\|_F$ 是 Frobenius 范数（所有元素平方和的平方根），$\|\cdot\|_2$ 是谱范数（最大奇异值）。两个公式都说明同一件事：截断丢掉的奇异值越小，近似越好。如果 $\sigma_{k+1}$ 及以后都很小（奇异值快速衰减），低秩近似就好；如果奇异值平坦（每个都差不多大），截断会丢掉大量信息。

    补充：为什么截前 k 大奇异值就是最优的（直觉说明）

    奇异值 $\sigma_i$ 衡量矩阵在第 $i$ 个主方向上的"能量"。Frobenius 范数 $\|W\|_F^2 = \sum \sigma_i^2$ 就是总能量。要把矩阵压到秩 $k$，必须丢弃 $\min(m,n) - k$ 个方向。因为奇异值从大到小排序，丢弃最小的那些丢掉的能量最少——$\sum_{i>k} \sigma_i^2$ 是所有可能选择中最小的。这就是 Eckart-Young 定理的直觉：保留能量最大的方向，丢弃能量最小的。严格证明用到了正交矩阵不改变 Frobenius 范数这一性质，见 Wikipedia "Low-rank approximation" 的证明小节。

    展开：3×3 对角矩阵的秩-1、秩-2 近似与误差

    教学示例。取对角矩阵 $W = \mathrm{diag}(3, 1, 0.5)$，即对角线为 $3, 1, 0.5$、其余为 $0$ 的 $3 \times 3$ 矩阵。选对角矩阵是为了让 SVD 平凡：$U = V = I$，$\Sigma = W$，奇异值 $\sigma_1 = 3, \sigma_2 = 1, \sigma_3 = 0.5$，这样本页可以直接套误差公式而不用先算 SVD。

    秩-1 近似：保留 $\sigma_1 = 3$，$W_1 = \mathrm{diag}(3, 0, 0)$。

    Frobenius 误差：$\|W - W_1\|_F = \sqrt{\sigma_2^2 + \sigma_3^2} = \sqrt{1^2 + 0.5^2} = \sqrt{1.25} \approx 1.118$。

    谱范数误差：$\|W - W_1\|_2 = \sigma_2 = 1$。

    秩-2 近似：保留 $\sigma_1, \sigma_2$，$W_2 = \mathrm{diag}(3, 1, 0)$。

    Frobenius 误差：$\|W - W_2\|_F = \sqrt{\sigma_3^2} = 0.5$。

    谱范数误差：$\|W - W_2\|_2 = \sigma_3 = 0.5$。

    从秩-1 到秩-2，Frobenius 误差从 $1.118$ 降到 $0.5$——多保留一个奇异值，误差减小。这个矩阵的奇异值 $3 \gg 1 \gg 0.5$ 衰减明显，所以秩-2 近似已经很好（只丢掉 $0.5$）。若奇异值是 $3, 2.9, 2.8$ 这样平坦分布，秩-1 近似会丢掉 $\sqrt{2.9^2 + 2.8^2} \approx 4.04$，误差大得多。

    本章说明 SVD 给出最优低秩近似且误差由奇异值决定。但理论如何落到 LLM 实践——下一章讲 LoRA 把低秩分解用在权重更新上。

    LoRA——把权重更新参数化为低秩

    微调的本质是调整权重：$W_{\text{新}} = W_0 + \Delta W$，其中 $W_0$ 是预训练权重、$\Delta W$ 是更新量。全量微调要训练整个 $\Delta W \in \mathbb{R}^{d \times d}$，参数量 $d^2$。GPT-3 175B 的 $d = 12288$，一个权重矩阵的更新量就是 1.5 亿参数——为每个下游任务都存一份这样的更新量，成本无法承受。

    LoRA（Low-Rank Adaptation）的核心假设是[C1]：预训练的过参数化模型实际上处在低内在维度上，因此微调时的权重更新量 $\Delta W$ 也有低"内在秩"。于是把更新量参数化为两个小矩阵的乘积：

    $$\Delta W = BA, \qquad B \in \mathbb{R}^{d \times r}, \quad A \in \mathbb{R}^{r \times d}, \quad r \ll d.$$

    前向传播变成[F1]：

    $$h = W_0 x + \Delta W x = W_0 x + BAx.$$

    预训练权重 $W_0$ 冻结不训练，只训练 $A$ 和 $B$。参数量从 $d^2$ 降为 $2dr$（$B$ 有 $dr$ 个、$A$ 有 $rd$ 个）。

      冻结（不训练）         只训练这两个
┌─────────────┐      ┌───┐  ┌─────────────┐
│             │      │   │  │             │
│     W₀      │      │ B │  │      A      │
│   (d × d)   │      │d×r│  │    (r × d)  │
│             │      │   │  │             │
└─────────────┘      └───┘  └─────────────┘
  d² 个参数          2dr 个参数（r ≪ d）

h = W₀ x + B A x

    代入 GPT-3 的规模：$d = 12288$、$r = 2$[N2]：

    $$d^2 = 150{,}994{,}944, \qquad 2dr = 2 \times 12288 \times 2 = 49{,}152.$$

    比例 $49152 / 150994944 \approx 0.033\%$。论文报告在 GPT-3 175B 上，可训练参数可低至原模型的 $0.01\%$（约一万倍减少[N1]）。

    初始化有一个关键设计[F1]：$A$ 用随机高斯初始化、$B$ 初始化为零，所以训练开始时 $\Delta W = BA = B \cdot A = 0$——模型从预训练权重 $W_0$ 出发，更新量从零开始逐渐学到。这保证了 LoRA 微调的起点和原模型一致。

    对比项全量微调LoRA
    训练参数$d^2$（全部 $W_0$）$2dr$（只 $A, B$）
    $d=12288, r=2$ 时1.5 亿49152（$\approx 0.033\%$）
    推理时用 $W_0 + \Delta W$可合并为 $W_0 + BA$，无额外延迟
    多任务切换每个任务存一份完整权重每个任务只存小矩阵 $A, B$

    这里要区分一个容易混淆的点：LoRA 不是在对 $W_0$ 做低秩近似。$W_0$ 是冻结的预训练权重，完整保留。LoRA 做的是把"要学的更新量 $\Delta W$"用低秩形式 $BA$ 参数化——$A, B$ 学到什么就是什么，没有"近似 $W_0$"这一步。低秩约束限制了 $\Delta W$ 能表达的方向数（最多 $r$ 个），这是基于"权重更新的内在秩低"这一假设[C1]。

    本章说明 LoRA 用低秩分解减少要训练的参数。但低秩还能减少推理缓存——下一章讲 MLA 如何把 KV 压进低维潜向量。

    MLA——把 KV 压进低维潜向量

    标准注意力（MHA）为每个 token 计算并缓存 K 和 V 两个向量，各 $n_h d_h$ 维，共 $2 n_h d_h$ 个数[F6]。DeepSeek-V2 的 MLA（Multi-Head Latent Attention）用低秩压缩减少这个缓存[C3]。

    MLA 不直接生成并缓存 K/V，而是先用一个下投影把隐藏状态 $h_t$ 压成低维潜向量[F4]：

    $$c_t^{KV} = W^{DKV} h_t, \qquad W^{DKV} \in \mathbb{R}^{d_c \times d}.$$

    这里 $c_t^{KV} \in \mathbb{R}^{d_c}$ 是压缩后的潜向量，$d_c \ll d$。推理时只缓存 $c_t^{KV}$，不缓存 K/V 本身。注意力计算时，K 和 V 由上投影从潜向量重建：

    $$k_t^C = W^{UK} c_t^{KV}, \qquad v_t^C = W^{UV} c_t^{KV}, \qquad W^{UK}, W^{UV} \in \mathbb{R}^{d_h n_h \times d_c}.$$

    把两个式子合起来看：$k_t^C = W^{UK} W^{DKV} h_t$。这等价于用一个 $d_h n_h \times d$ 的矩阵 $W^{UK} W^{DKV}$ 代替原本直接投影 K 的矩阵 $W^K$。而 $W^{UK} W^{DKV}$ 的秩不超过 $d_c$（因为中间经过 $d_c$ 维瓶颈），所以这是一次低秩分解——把满秩的 $W^K$ 换成秩 $\le d_c$ 的 $W^{UK} W^{DKV}$[C3]。

      MHA：每个 token 缓存 K 和 V 本身
  token t ──► [K_t (n_h·d_h)] [V_t (n_h·d_h)]  缓存 2·n_h·d_h 个数

  MLA：每个 token 只缓存潜向量 c_kv
  token t ──► h_t ──W_DKV──► [c_kv (d_c)]  只缓存这个
                                   │
                          W_UK / W_UV（推理时重建）
                                   │
                          ┌────────┴────────┐
                          ▼                  ▼
                       k_t^C              v_t^C
                    (需要时才算)        (需要时才算)

    代入 DeepSeek-V2 的配置[N3]：$n_h = 128$、$d_h = 128$、$d_c = 512$。

    $$\text{MHA 缓存} = 2 n_h d_h = 2 \times 128 \times 128 = 32768, \qquad \text{MLA 潜向量} = d_c = 512.$$

    潜向量维度只有 MHA 缓存的 $512 / 32768 = 1/64$。注意上面的 1/64 是 DeepSeek-V2 同配置下单层、忽略解耦 RoPE 项 $d_h^R$ 的理论比例。论文报告的 Table 7 是不同层级的整体对比：110.6K→15.6K（Small MoE，减少 85.9%）、860.2K→34.6K（Large MoE，减少 96.0%）是 DeepSeek-V2 MoE 与不同 MHA 基线（含 DeepSeek 67B 等）的整体对照，基线的 $n_h, d_h, d_c$、层数与模型规模均不同，因此这些减少比例不能直接与同配置单层的 1/64 对照（1/64 对应 98.4% 减少，残留约 1.56%，而 15.6/110.6 残留约 14.1%）；整体相比 DeepSeek 67B 减少 93.3%[N4]。

    K/V 怎么来直接由 $W^K h_t, W^V h_t$ 生成由 $W^{UK} c_t^{KV}, W^{UV} c_t^{KV}$ 重建
    等价权重秩满秩（$d_h n_h$）秩 $\le d_c$（经过 $d_c$ 维瓶颈）

    这里要强调一点：MLA 的低秩压缩是有损的。重建出的 $k_t^C, v_t^C$ 与 MHA 直接投影的 $k_t, v_t$ 在形状上一致但数值不等价——它们是从 $d_c$ 维子空间投影回来的，丢掉了 $d_h n_h - d_c$ 个方向的信息[C3]。$d_c$ 越小压缩越大，但丢的信息也越多；$d_c$ 的选择是压缩率与表达力的权衡。MLA 的完整机制（解耦 RoPE、矩阵吸收等进一步优化）见MLA概念页，本页只讲它的低秩压缩部分。

    完成本章后，用下面几个问题检查自己是否跟上：

    • MLA 缓存的是 K 和 V 本身还是别的向量，维度是多少。
    • 说明为什么 $k_t^C = W^{UK} W^{DKV} h_t$ 是一次低秩分解，秩不超过多少。
    • 重建的 K/V 与 MHA 的 K/V 是否等价，为什么。

    本章说明 MLA 用低秩压缩减少推理缓存。但 LoRA 与 MLA 都依赖"目标矩阵低秩"这一假设——下一章讲它的适用边界与失效条件。

    适用边界——低秩不是万能的

    低秩近似有效有一个前提：目标矩阵的奇异值快速衰减，即信息集中在前几个主方向上[C4]。从误差公式 $\|W - W_k\|_F = \sqrt{\sum_{i>k}\sigma_i^2}$ 直接可以看出：如果 $\sigma_{k+1}$ 及以后都很小，截断丢得少；如果奇异值平坦（每个都差不多大），截断会丢掉大量信息。

    奇异值分布秩-k 近似效果典型场景
    快速衰减（如 $3, 1, 0.5$）好——前几个方向集中大部分能量低秩矩阵、有结构的权重
    平坦（如 $3, 2.9, 2.8$）差——每个方向都重要，截断丢得多满秩随机矩阵、白噪声

    LoRA 的假设是"权重更新的内在秩低"[C1]。如果某个任务需要高秩更新——权重变化跨很多方向——那么小的 $r$ 就不够，LoRA 效果会受限。论文的实验显示 rank 可以低至 1 或 2[N2]，但这针对的是自然语言微调任务；对需要大幅改变模型行为的任务，更小的 $r$ 是否足够尚需按任务验证——这是低秩假设边界的直接推论，论文未给出 $r$ 上限的一般建议。

    MLA 的低秩压缩是有损的[C3]。$d_c$ 太小会丢掉 K/V 的信息，影响注意力质量。DeepSeek-V2 选 $d_c = 512$ 是在压缩率和表达力之间权衡的结果。

    一个来自 K3 的真实教训[C4]：Kimi Linear 的注意力门控用 low-rank 形式（$W_g$ 低秩分解），K3 把它改为 full-rank（配置项 use_full_rank_gate = true），正是因为低秩门控的表达力不足——每个输出通道没有独立的门控信号。这是"低秩不够用就回到满秩"的实例。完整机制见KDA概念页。

    核心边界：低秩分解不是无损压缩。它有效的条件是目标矩阵奇异值快速衰减（或权重更新内在秩低）。条件不满足时，近似误差大、表达力受损。选择低秩前要看奇异值分布或靠实验验证；$r$（或 $d_c$）是误差与成本的权衡，不是越小越好也不是越大越好。

    完成本章后，用下面几个问题检查自己是否跟上：

    • 什么样的奇异值分布不适合低秩近似。
    • K3 为什么把注意力门控从 low-rank 改成 full-rank。
    • MLA 的低秩压缩是有损还是无损，损失从哪里来。

    回顾全文学习目标：大矩阵之所以贵是因为每个元素都要存（$d=12288$ 时单矩阵 1.5 亿参数）；秩衡量可压缩量，秩 $r$ 的矩阵可无损写成 $AB$ 用 $r(m+n)$ 个参数；SVD 的截断近似由 Eckart-Young 定理保证最优，误差等于被截掉的奇异值；LoRA 把权重更新量 $\Delta W = BA$ 参数化为低秩，参数从 $d^2$ 降到 $2dr$（GPT-3 175B 下可低至原模型 $0.01\%$）；MLA 把 KV 压成 $d_c$ 维潜向量缓存，DeepSeek-V2 下约为 MHA 同配置的 1/64；但低秩有效的前提是奇异值快速衰减或权重更新内在秩低，条件不满足时近似误差大、表达力受损（K3 把 low-rank 门控改回 full-rank 即是实例）。

    来源与教学说明

    核心论断与来源

    [C1] LoRA 核心假设——权重更新有低内在秩。来源：Hu et al., "LoRA: Low-Rank Adaptation of Large Language Models", arXiv:2106.09685v2, §1 Introduction："the learned over-parametrized models in fact reside on a low intrinsic dimension. We hypothesize that the change in weights during model adaptation also has a low 'intrinsic rank'"。

    [C2] Eckart-Young-Mirsky 定理——截断 SVD 是最优低秩近似。来源：Wikipedia "Low-rank approximation"（定理最初由 Schmidt 在函数空间提出，Eckart 和 Young 1936 年重新发现，Mirsky 1960 年推广到酉不变范数）+ Wikipedia "Singular value decomposition"（"$\tilde{M}$ is the best approximation of $M$ by any matrix of rank less than or equal to $t$, under the Frobenius norm ... This is known as the Eckart–Young theorem"）。

    [C3] MLA 低秩 K-V 联合压缩。来源：DeepSeek-AI, "DeepSeek-V2: A Strong, Economical, and Efficient Mixture-of-Experts Language Model", arXiv:2405.04434v2, §2.1.2 "Low-Rank Key-Value Joint Compression"："The core of MLA is the low-rank joint compression for keys and values to reduce KV cache"。

    [C4] 低秩近似失效条件 + K3 的 full-rank 转变。来源：Eckart-Young 误差公式（C2 推论）；KDA 概念页已核对的 Kimi K3 config.json use_full_rank_gate = true（Kimi K3 技术报告）。

    核心公式与来源

    [F1] LoRA 前向 $h = W_0 x + BAx$。来源：arXiv:2106.09685v2, §4 Eq.(3)。Figure 1 标注 "We only train $A$ and $B$"。初始化 $A$ 随机高斯、$B$ 为零使 $\Delta W = 0$。

    [F2] SVD $W = U\Sigma V^\top$ 与截断 SVD $W_k = \sum_{i=1}^{k}\sigma_i u_i v_i^\top$。来源：Wikipedia "Singular value decomposition"（定义）+ "Low-rank approximation"（$A_k$ 形式）。

    [F3] 误差公式 $\|W - W_k\|_F = \sqrt{\sum_{i>k}\sigma_i^2}$、$\|W - W_k\|_2 = \sigma_{k+1}$。来源：Eckart-Young-Mirsky 定理，Wikipedia "Low-rank approximation" 的谱范数与 Frobenius 范数证明小节。

    [F4] MLA 压缩公式 $c_t^{KV} = W^{DKV} h_t$（Eq.9）、$k_t^C = W^{UK} c_t^{KV}$（Eq.10）、$v_t^C = W^{UV} c_t^{KV}$（Eq.11）。来源：arXiv:2405.04434v2, §2.1.2 Eq.(9)(10)(11)。$W^{DKV} \in \mathbb{R}^{d_c \times d}$，$W^{UK}, W^{UV} \in \mathbb{R}^{d_h n_h \times d_c}$。

    [F5] 参数计数 $mn \to r(m+n)$。由矩阵乘法维度直接推出；LoRA 论文 §4 隐含使用（$d^2 \to 2dr$）。

    [F6] KV cache 计数 MHA = $2 n_h d_h$、MLA = $d_c$。来源：arXiv:2405.04434v2, §2.1.4 Table 1：MHA = $2 n_h d_h l$、MLA = $(d_c + d_h^R) l$（本页取 $l=1$ 比较单层，略去较小的解耦 RoPE 项 $d_h^R$）。

    外部数字与实验条件

    [N1] LoRA 在 GPT-3 175B 上可训练参数低至原模型 $0.01\%$、约一万倍减少。来源：arXiv:2106.09685v2, §2（$0.01\%$）与 §1（10,000 times）。实验条件：GPT-3 175B 特定 rank 配置。

    [N2] rank $r$ 可低至 1 或 2，满秩 $d$ 高达 12288。来源：arXiv:2106.09685v2, §1："a very low rank (i.e., $r$ in Figure 1 can be one or two) suffices even when the full rank (i.e., $d$) is as high as 12,288"。实验条件：GPT-3 175B。

    [N3] DeepSeek-V2 配置 $n_h=128, d_h=128, d_c=512$。来源：arXiv:2405.04434v2, §3.1.2："we set the number of attention heads $n_h$ to 128 and the per-head dimension $d_h$ to 128. The KV compression dimension $d_c$ is set to 512"。

    [N4] MLA 减少 KV cache 93.3%；Table 7 对照 Small MoE 110.6K→15.6K、Large MoE 860.2K→34.6K。来源：arXiv:2405.04434v2 摘要（93.3%）与 §2.1.4 Table 7。93.3% 为相比 DeepSeek 67B 的整体降幅（含解耦 RoPE 项与多层）。

    教学示例

    [N5] 教学示例矩阵 $W = \mathrm{diag}(3, 1, 0.5)$。人为构造，目的是让 SVD 平凡（$U = V = I$）以便手算误差公式。奇异值 $\sigma_1=3, \sigma_2=1, \sigma_3=0.5$；秩-1 近似 Frobenius 误差 $\sqrt{1.25} \approx 1.118$、谱误差 $1$；秩-2 近似 Frobenius 误差 $0.5$、谱误差 $0.5$。不代表真实权重数据。

    完成检查中的 $W = \mathrm{diag}(5, 2, 0.1)$：秩-1 Frobenius 误差 $\sqrt{2^2 + 0.1^2} = \sqrt{4.01} \approx 2.002$、谱误差 $2$。$d=4096, r=8$ 的 LoRA 参数比例 $2 \times 4096 \times 8 / 4096^2 = 16/4096 \approx 0.39\%$。

    教学解释与类比边界

    "奇异值衡量矩阵在第 $i$ 个主方向上的强度/能量"这一解释只帮助理解"为什么截前 $k$ 大奇异值是最优的"这一局部关系。它不覆盖非方阵、复数矩阵或加权低秩近似的情形；正式判断以 Eckart-Young 定理和误差公式为准。

    "$W = AB$ 时 $W$ 的每一列都是 $A$ 的列向量的线性组合"这一解释只说明 $\mathrm{rank}(W) \le r$ 的代数原因，不涉及 $A, B$ 的最优选择；最优选择由 SVD 给出。

    教学简化及其限制

    - (1) SVD 计算算法：简化做法：只用 SVD 的存在性与最优性结论，不展开数值迭代算法（如 Jacobi 方法）。可推出：低秩近似的存在性与误差公式。不可推出：实际计算 SVD 的数值方法。
    - (2) LoRA α/r 缩放：简化做法：略去 $\alpha/r$ 缩放因子。可推出：低秩分解如何减少参数的机制。不可推出：训练稳定性与缩放对梯度的影响。
    - (3) MLA 完整机制：简化做法：只讲低秩压缩部分，略去解耦 RoPE 与矩阵吸收。可推出：MLA 用低秩投影减少 KV cache 的机制。不可推出：MLA 的完整前向数据流（见MLA概念页）。
    - (4) 教学示例维度：简化做法：用对角矩阵使 SVD 平凡。可推出：误差公式的数值验证。不可推出：真实矩阵 SVD 的计算过程。
    - (5) 参数计数范围：简化做法：只算矩阵元素本身，未计入偏置、优化器状态等工程开销。可推出：低秩分解的参数压缩比。不可推出：实际训练显存占用。
