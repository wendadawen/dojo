# FusedMoE

- 描述：FusedMoE 是 vLLM 里的 MoE 层实现，把每个 token 与其 top-k 专家的计算合并起来，用两次分组 GEMM 加一次加权求和批量算完。
- 摘要：把 $M$ 个 token 的各路专家计算按专家重排对齐，收进两次分组 GEMM 和一次求和，用少数几个 kernel 批量算完。
- 主题：模型结构, 推理系统
- 标签：MoE
