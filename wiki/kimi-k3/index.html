Kimi K3 前向数据流

Kimi K3 是一个 2.78T 参数的 MoE 模型：93 层主干中，第 0 层为 KDA + Dense FFN，第 1–90 层按 KDA×3 : Gated MLA×1 循环混合，末尾第 91、92 层连续 MLA；FFN 全部是 Stable Latent MoE（896 路由专家 top-16 + 2 共享专家），并用 Block AttnRes 替代逐层残差、SiTU-GLU 有界激活保证稳定；全模型无位置编码（NoPE），上下文 1M，每 token 激活 104.2B 参数。

更新于 2026-08-05 · 来源：官方 config.json 与官方实现代码 · 所有数字与公式已逐项核对

要点

整体结构：三条信息流

  • 沿序列：69 层 KDA 做低成本、固定状态的长序列混合，每 3 层插入 1 层 Gated MLA 保留全局注意力，共 24 层 MLA；末两层（91、92）连续 MLA 收尾。
  • 沿深度：Block AttnRes 取代"所有历史层输出等权相加"的普通残差，让当前层可按输入内容选择此前哪个深度块的信息。
  • 沿宽度：Stable LatentMoE 把路由专家放进 3584 维隐空间，扩到 896 个专家而通信/显存不随专家数线性增长。
  • KDA 与 MLA 均无显式位置编码（NoPE）：位置感由 KDA 的循环状态、衰减与短卷积隐式提供，扩展上下文无需 RoPE 插值。

KDA（Kimi Delta Attention，69 层）

  • q/k/v 各自投影到 12288（96 头 × 128 维）后过核长 4 的深度可分离因果短卷积 + silu；q/k 再 L2 归一。
  • 衰减信号 g 由 f_a_proj（7168→128）与 f_b_proj（128→12288）低秩生成，每 token/头/维一个；dt_bias 每头每维偏置；A_log 每头一个尺度。
  • 衰减率（K3 用 safe_gate）：log α = −5·σ(e^{A_log}·(g + dt_bias))，即 lower-bound sigmoid，值域 (−5, 0)，每步衰减 exp(−5)≈0.0067 下限——不是非安全版本的 softplus 形式。
  • delta 规则：S_t = (I − βk̂k̂ᵀ)·diag(α)·S_{t−1} + β·k̂·vᵀ，写强度 β 由 b_proj（7168→96，每头一标量）sigmoid 得到；输出 o = Sᵀ·q̂。
  • 输出门为全秩（use_full_rank_gate=true）：g_proj 7168→12288，FusedRMSNormGated 先 RMSNorm(o) 再与 σ(g) 逐元素相乘。

Gated MLA（24 层）

  • Q 路：q_a_proj 压缩到 1536 → RMSNorm → q_b_proj 升到 18432（96×192）；每头 192 拆为 nope 128 + rot 64。
  • KV 路：kv_a_proj_with_mqa 压缩到 576（512 + 64），拆出压缩潜向量 ckv 与共享的 rot 键；ckv 过 RMSNorm 后 kv_b_proj 展开 96 头 × 256，再拆 k_nope 128 与 v 128。
  • rot 分量仅做结构拆分，不施加旋转（rotary_emb=None）；q/k 拼回 192 维做标准因果注意力，scaling = 192^(−1/2)。
  • 输出经 g_proj（7168→12288）sigmoid 门控（mla_use_output_gate=true）后 o_proj 投影回 7168。

Stable Latent MoE（除第 0 层外全部 FFN）

  • 门控（KimiMoEGate）：sigmoid 打分 → top-16(s + bias) 选专家；bias 只影响排序、不进权重；选中专家权重按原始分数 renormalize 后乘 routed_scaling_factor=1.0。
  • 负载均衡：bias 用 Quantile Balancing 更新（取 margin 的 1−k/n 分位数一步到位，无 sign-update 学习率；推理时冻结），替代 DeepSeek 式 e_score_correction_bias 的逐步更新。
  • 路由专家（KimiBlockSparseMLP）：w1=gate、w3=up、w2=down，在隐空间 3584→3072→3584，SiTU-GLU 有界激活。
  • 聚合后先 RMSNorm（latent_moe_use_norm=true）再上投影回 7168；共享专家为全宽 KimiMLP（intermediate=3072×2=6144），对所有 token 恒激活。

Block AttnRes（跨块注意力式残差）

  • 93 层按 12 层分块；块边界（layer_idx % 12 == 0，即 0,12,…,84）把当时累计的 prefix_sum 快照存入 block_residual，共 8 个块源，加上首层输入（embedding）共 9 个深度来源。
  • 每层把"当前 prefix_sum + 全部历史块源"做 RMSNorm，用层自带的可学习打分权重（norm.weight × proj.weight）逐维相乘求和得标量分数，softmax 后加权求和作为本层残差。
  • 效果：深层能自适应地多信任近期块或回溯早期块，缓解 93 层深度下的信息稀释；开销从逐层的 O(L·d) 降到逐块的 O(N·d)。

Dense FFN（仅第 0 层）

  • first_k_dense_replace=1：只有第 0 层用稠密 KimiMLP，gate_proj/up_proj 7168→33792，SiTU-GLU 后 down_proj 33792→7168。
  • SiTU-GLU：门支 β·tanh(g/β)·σ(g)（β=4），值支 β_l·tanh(u/β_l)（β_l=25），两因子均平滑饱和，输出坐标上界 β·β_l=100，从根源抑制激活爆炸。
