Kimi K3: Open Frontier Intelligence

Kimi Team 用 KDA+AttnRes+Stable LatentMoE 三维度扩展信息流，在 2.8T 参数下实现约 2.5× scaling 效率提升，是首个开放权重的 3T 级模型。

arXiv:2607.24653v2 · Kimi Team (Moonshot AI) · 2026-08-07

1. 做了什么

K3 是一个 2.8 万亿参数的 MoE 多模态模型，104B 激活参数，1M token 上下文。它在序列、深度、宽度三个维度重新设计了信息流机制，配合训练和基础设施创新，在 OOD 验证 loss 上实现较前代 K2 约 2.5× 的 scaling 效率。性能落后最强闭源模型 Claude Fable 5 和 GPT-5.6 Sol，但总体优于其他开放和闭源模型（研究级推理 CritPt、HLE-Full 为例外）。完整权重已开放。

2. 创新点

  • 三维度信息流：不是简单增大模型，而是系统性重新设计 token 间、层间、通道间的信息流动——KDA+MLA 混合注意力管序列，Block AttnRes 管深度，Stable LatentMoE 管宽度。三维度互相支撑：KDA 让长序列可负担才敢加深到 93 层，AttnRes 让深网络可行才敢扩到 896 专家。
  • Stable LatentMoE 三件稳定化：896 专家 top-16（稀疏度 56×）在 2.8T 规模会激活爆炸和负载失衡。RMSNorm + SiTU-GLU（有界激活）+ Quantile Balancing（分位数负载均衡）分别解决这两个失效模式，使极端稀疏训练成为可能。
  • 开源 3T 级里程碑：首个开放权重的 3T 级模型。WebDev Arena #1/99（首个开源模型登顶），ProgramBench、SWE-Marathon、BrowseComp 多项第一。
  • 训练-部署协同：MXFP4 QAT 从 SFT 贯穿 RL，EAGLE draft 复用 MTP 层——部署效率从训练阶段就考虑，而非事后优化。

3. 大致怎么做

  • 序列维度：每 4 层中 3 层 KDA（线性注意力，固定递归状态）+ 1 层 MLA（全局注意力，低秩 KV 压缩）。KDA 高效处理长序列，MLA 周期性提供全局交互。MLA 用 NoPE（无位置编码），KDA 隐式编码位置，扩展到 1M 无需外推。93 层 = 69 KDA + 24 MLA。
  • 深度维度：93 层分为 8 个 block（每 12 层），每层用可学习伪查询对 embedding、此前各 block 的汇总表示与当前 block 的 partial sum 做选择性检索（块内每层仍跨 block 检索，各层输出按求和汇总为块级表征）。把跨层检索的内存开销从 O(Ld) 降到 O(Nd)。
  • 宽度维度：路由专家在 3584 维潜在空间操作（非全宽 7168），2 个共享专家保持全宽。每 token 选 16 个路由专家，RMSNorm 归一化后升回全宽，与共享专家相加。
  • 训练：四类文本域 + 视觉语料；cosine decay（独立搜索后优于 WSD）；Per-Head Muon 按头正交化；四阶段渐进上下文扩展（8K→64K→256K→1M）。
  • 后训练：SFT→RL→MOPD 三阶段，3 域 × 3 努力级别 = 9 个专家蒸馏为统一模型。

4. 关键结论

  • 约 2.5× scaling efficiency：在 OOD 验证 loss 上达到 K2 相同水平所需 FLOPs 减半多（§3.2, Fig.7）。这是架构+数据+训练配方的联合效果，非单一组件——论文未分解各因素贡献。
  • 2.78T 总参，104.2B 激活，1M 上下文（Table 1；config.json 确认）。较 K2：总参 +167%，激活 +220%，上下文 8×。
  • 整体落后 Fable 5 和 GPT-5.6 Sol，总体优于 Opus 4.8/GPT-5.5/GLM-5.2（研究级推理 CritPt、HLE-Full 例外）（§6.1.4, Table 2）。亮点：ProgramBench 77.8（第一）、SWE-Marathon 42.0（第一）、BrowseComp 91.2（第一）。短板：CritPt 23.4、HLE-Full 43.5/56.0（研究级推理落后）。
  • benchmark 条件：编程用不同 harness（Kimi Code/Claude Code/Codex），Terminal-Bench 2.1 官方 88.3 是三 harness 取最优（§6.1.3）；Fable 5 含 fallback，GPT-5.6 Sol 含 cyberguard。直接比分数需谨慎。
