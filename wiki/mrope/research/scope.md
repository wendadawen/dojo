# scope：MRoPE

## 概念含义

- 名称：MRoPE（Multimodal Rotary Position Embedding，多模态旋转位置编码）。
- 简要定义：把 RoPE 的单一一维位置 id 拆成时间/高/宽三个分量，文本、图像、视频 token 各按自身结构分配三个分量，再共享同一组旋转频率。
- 正式定义（与来源一致）：Qwen2-VL 论文 §2.1"This is achieved by deconstructing the original rotary embedding into three components: temporal, height, and width."
- 本文语境：以 Qwen2-VL 论文为定义出处，以 transformers 的两代实现（qwen2_vl 的分段排布、qwen4_exp 的交错排布）讲清「三个分量怎么共用头维」，以 Qwen3.8-Flash-Next 的实测数字落实行为。
- 包括：一维位置编码在多模态下的问题；三分量定义与三种模态的分配规则；跨模态位置衔接；头维槽位的分段与交错两种排布；位置 id 推进量与长序列外推的关系。
- 不包括：RoPE 本身的旋转机制与内积相对性证明（rope 页范围）；视觉编码器结构（vit 页）；YaRN 等长度外推方法（另一独立主题）。
- 相邻概念：3D-RoPE（视频理解的早先做法，MRoPE 的相关前驱，仅提一句不展开）；绝对位置嵌入/可学习位置编码（positional-encoding 页范围）。

## 学习目标

### Q1：一维位置编码在多模态输入下遇到什么问题？

- 完成答案：文本 token 天然有序，图像 token 却排成二维网格（视频再加时间维）；把网格拉平塞进一维位置轴会丢失「同行相邻/同列相邻」的区分，且真实世界是三维的、一维嵌入限制对空间与时间的建模。
- 为什么核心：这是 MRoPE 的动机，决定后面每个设计。
- 依赖：RoPE 的基本机制（rope 页）。

### Q2：三个分量怎么定义，文本/图像/视频各自怎么分配？

- 完成答案：位置 id 从一个数变成 $(t,h,w)$ 三元组；文本三者相同（等价退化回 1D-RoPE）；图像 $t$ 恒定、$h/w$ 按网格坐标；视频 $t$ 逐帧递增、$h/w$ 同图像。
- 为什么核心：这是 MRoPE 的定义本体。
- 依赖：Q1；二维网格坐标（vit 页的 patch 网格）。

### Q3：三个分量怎么共用同一组旋转频率？（分段与交错两种排布）

- 完成答案：头维的旋转维切成三段配额（mrope_section），分段排布让每个分量独占一段频率、交错排布让三个分量以 3 为步长交替占用频率槽位；交错使每个分量都覆盖低频到高频的完整范围。
- 为什么核心：这是「一个头维装三个位置轴」的实现核心，也是读 transformers 源码必备。
- 依赖：RoPE 频率分层（rope 页讲过低频/高频）。

### Q4：为什么 MRoPE 有助于长序列外推？

- 完成答案：图像块结束后位置轴只推进该块的最大网格边长而非 token 数，同样长的多模态序列占用的位置 id 范围小得多，推理长度可显著超过训练长度。
- 为什么核心：这是 MRoPE 的主要实际收益，也是与 KV cache 预算并列的「位置轴预算」视角。
- 依赖：Q2 的分配规则。

## 内容分级

- 核心：Q1–Q4 对应内容。
- 辅助：跨模态衔接（新模态从前一模态最大位置 id + 1 开始，与推进量是同一件事）；qwen4_exp 里 partial rotary（64/256 维）与 MRoPE 的组合。
- 扩展（排除）：Qwen2.5-VL 的 position alignment 细节、视频时间间隔加权（后续版本变化，不影响 Q1–Q4）；3D-RoPE 前驱对比。

## 常见误解与适用边界

- 误解一：「MRoPE 是新的旋转公式」。纠正：旋转公式与 RoPE 完全相同，变的只是位置 id 从一维变三维与频率槽位的分配。
- 误解二：「三个分量各占 1/3 的头维」。纠正：配额由 mrope_section 决定（如 [11,11,10]），且分段/交错两种排布都存在；交错下三个分量共享全部频率范围。
- 误解三：「视觉 token 占多少序列位置，位置 id 就前进多少」。纠正：推进量是 $\max(h,w)/\text{merge}$；一张 1764 token 的图只推进 42。
- 边界：MRoPE 的低碰撞/外推收益依赖「图像网格远大于 merge 尺度」与「推理序列的多模态占比」；纯文本序列上 MRoPE 严格退化为 1D-RoPE，无额外收益。
- 版本边界：分段排布是 qwen2_vl/qwen2.5 系实现，交错排布见于 qwen4_exp（mrope_interleaved=true）；两者的分配规则同源但槽位布局不同。
