# outline：MRoPE

## 页面开头

场景引入：一句「请描述这张图」的 prompt 里，文本 token 一字排开，图像 token 却来自 28×28 的网格——它们该排进哪条位置轴？给出简要定义（三分量）、学习目标（Q1–Q4）、前置引用（rope 页、positional-encoding 页）、过渡到第 1 章。

## 章节

### 第 1 章 文本有序、图像有格——一维位置轴装不下多模态（回答 Q1）

- 章节问题：①把网格拉平进一维轴丢失了什么？②论文给出的动机原句是什么？
- 答案要点：同行相邻与同列相邻在一维轴上距离相同，方向信息丢失（C5 动机）；真实环境三维、文本一维的矛盾。
- 材料：HTML 结构图（结构 B：一维轴 vs 二维网格两种排布对照，展示拉平后「同行/同列距离都变 1」）；无公式。
- 前置：RoPE 一维机制引 rope 页。

### 第 2 章 位置 id 变三元组——三种模态的分配规则（回答 Q2）

- 章节问题：①$(t,h,w)$ 各自怎么取值？②纯文本时退化成什么？
- 答案要点：F1 生成式；文本三值相同（C2）、图像 $t$ 恒定（C3）、视频 $t$ 逐帧（C4）；跨模态衔接 = 前一模态最大位置 id + 1（C7）。
- 材料：三维分配对照表格（文本/图像/视频 × 三个分量）；可运行代码折叠块（mrope_demo.py：文本+图像+文本序列的三维位置 id 逐 token 打印，实际运行）。
- 贯穿示例启动：8 个文本 token + 一张 (1,28,28) 图 + 5 个文本 token 的构造序列。

### 第 3 章 一个头维装三条轴——分段与交错两种槽位排布（回答 Q3）

- 章节问题：①mrope_section 的配额怎么落到频率槽位？②分段与交错各自的布局和代价？
- 答案要点：rotary_dim=64 → 32 槽位；分段（qwen2_vl，C8）独占连续段；交错（qwen4_exp，C9）以 3 为步长交替，每分量覆盖完整频率范围、W 少一槽因 32 不被 3 整除；F2。
- 材料：两种排布的槽位对照图（HTML 表格直接呈现 32 槽位归属，T/H/W 字母行——非 ASCII 框线图）；可运行代码折叠块第二段（槽位归属计算）。
- 前置：频率分层含义引 rope 页。

### 第 4 章 位置轴上的省账——推进量与长序列外推（回答 Q4）

- 章节问题：①图像块让位置轴前进多少？②为什么这带来外推能力？
- 答案要点：推进量 $\max(h,w)/\text{merge}$（C10）而非 token 数；本机实测对照表（N3/N4）；论文外推证据（C6、N2 16K→80K；N1 消融数字最小引用）；「位置轴预算 vs 序列长度预算」两种预算并存的视角。
- 材料：推进量对照表格；跨模态衔接与推进量等价性的说明（C7=C10）。
- 贯穿示例收束：构造序列的后续文本从位置 22 开始（而非 204），把 Q2 的例子算完。

## 贯穿示例

8 文本 + (1,28,28) 图 + 5 文本：第 2 章生成三维 id → 第 4 章算推进量与后续文本起点。数字小、可手算、两次复用各加一层。

## 正文与折叠块分工

- 正文：全部定义、分配规则表、槽位归属表、推进量结论与实测数字。
- 折叠块：可运行代码与完整逐 token 输出、分段排布的完整槽位推导（从 mrope_section*2 切段到 i%3 选取）。

## 前置知识引用位置

- rope 页：第 1 章开头（RoPE 一维机制）与第 3 章（频率分层）。
- positional-encoding 页：第 1 章动机处（位置编码家族）。
- vit 页：第 2 章（patch 网格概念）。
- 数据流页（qwen3-8-flash-next-dataflow）：第 4 章结尾（完整实测与上下文占比）。

## 章间过渡

1→2：问题定了「需要三个轴」，下一章回答三个轴上的 id 怎么取值。
2→3：id 有了，但 RoPE 的旋转频率只有一组，下一章回答怎么分给三个分量。
3→4：槽位分配不改变「位置 id 走多快」，最后一章回答多模态让位置轴走得慢多少、换来什么。
