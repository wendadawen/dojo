位置编码 · 概览

MRoPE

MRoPE（多模态旋转位置编码）把旋转位置编码（给每个位置一个编号、按编号旋转向量的位置编码）的一个位置编号拆成时间、高、宽三份，让文本、图像、视频各按自己的排布取这三份编号。

位置编号分成三份

旋转位置编码给每个位置一个编号，按编号把查询和键（自注意力里做点积的两个向量）各转一个角（见旋转位置编码）。模型逐单元处理输入，处理的最小单元叫 token——文本、图像、视频都由 token 组成。多模态指输入里的数据不止文本，还含图像、视频等多种。MRoPE（多模态旋转位置编码）把一个位置编号拆成时间、高、宽三份，分别驱动向量的一段维度去旋转。文本 token 三份取同一个编号，退化成普通的一维编号；图像 token 的时间编号不随时间变化、保持固定，高、宽编号按它所在的行、列取；视频再让时间编号逐帧加一。

一维编号表达不了图和视频

文本是一维的，一个 token 接一个 token，一个编号就够用：靠前的编号小、靠后的编号大。图像 token 排在高×宽两维的网格上，视频按帧展开、每个 token 还落在一帧上。用一维编号，只能把网格按某种顺序拉平排成一条线，编号也就只反映这条线上的先后：行、列这些方向区分不出来。一维位置编码限制了对三维空间（行、列、帧三个方向）和时间动态的建模，就要按行、列、帧这些方向分别给编号。

按网格取三份编号再旋转

视觉 token 按它的帧、行、列取时间、高、宽三个编号，转法和旋转位置编码一样；一段输入里多张图或多段视频时，后一段的编号从前一段用过的最大编号加一开始。
