概念概览 · 注意力机制

MRoPE

把位置编号从一个数变成 $(t,h,w)$ 三元组：文本退化、图像按网格、视频逐帧，位置轴因此走得比 token 数慢得多。

更新于 2026-08-27

定义

MRoPE（多模态旋转位置编码）把 RoPE 的单一位置 id 拆成时间、高、宽三个分量，旋转公式本身不变；文本、图像、视频 token 各按自身结构给三个分量赋值。

问题背景

文本 token 天然一维有序，图像 token 却来自二维网格、视频再加时间维；拉平进一维位置轴后方向信息丢失，而文本与视觉要进同一个注意力，位置编码必须同构。

核心机制

  • 三元组分配：文本三值相同（退化回 1D-RoPE）；图像时间分量恒定、高宽按网格；视频时间分量逐帧递增。
  • 槽位配额：mrope_section 给三个分量分配频率槽位；分段排布各自独占连续段，交错排布以 3 为步长循环占用，后者让每个分量覆盖完整频率范围。
  • 跨模态衔接：新模态从前一模态最大位置 id 加一开始。
  • 推进量：图像块结束后位置轴只推进网格最大边长除以合并因子，而非视觉 token 数。

关键结论与边界

  • 一张 $1344\times 1344$ 的图（patch 16、合并 2）占 1764 个序列位置，但位置轴只前进 42——序列长度预算与位置轴预算是两笔账。
  • 论文证据：训练每视频最多 16K token、推理 80K 仍稳健（Qwen2-VL-72B，Video-MME 中等时长）；消融显示 M-RoPE 在多数基准优于 1D-RoPE、视频基准提升最明显（Qwen2-1.5B + ViT-L 骨干）。
  • 纯文本序列上 MRoPE 严格退化为 1D-RoPE，无额外收益；多模态占比越高，位置轴的压缩越显著（由推进量公式直接可得）。
