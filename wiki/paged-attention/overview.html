PagedAttention

PagedAttention 是一种注意力算法，把每个序列的键、值切成固定 token 数的块存在不连续显存里，按块计算注意力，使 KV cache 能按需分配、跨序列共享，减少显存浪费。

切成块

token 是模型处理文本的最小单位；大语言模型一次处理一条序列，也就是一串陆续出现的 token，生成时一次只输出一个 token。每个新 token 都要用到它前面所有位置的键和值（键、值由注意力产出，注意力让序列里各位置互相取信息，见标准注意力），这些留下来的键、值就是 KV cache。PagedAttention 把每个序列的 KV cache 切成固定 token 数的块，每块装固定数量 token 的键和值；块与块之间不必相邻，可以散在显存各处。注意力也不再假定键、值是连续的一整段，而是按块逐块取、逐块算。

按最长预留，留下大片空闲

现有系统把每个请求的 KV cache 放在连续的一段显存里，并按这个请求可能的最大长度一次预留好，因为实际要生成多长事先并不知道。预留出来还没用到的位置、请求比上限短而多留出来的部分、分配器切出的再也拼不起来的空隙，这三类浪费让真正存 token 状态的显存只剩很小一部分，实测可以低到 20.4%。而且每个序列各占一段连续的显存，多个序列没法指向同一份键、值，也就没法共享。这些浪费占住了显存，能同时处理的请求数因此受限，吞吐也随之受限。

切成块，用块表按需取用

每块配一块物理显存，再用一张块表把逻辑块映射到物理块、并记下这块已经填了几个位置。新 token 的键、值先填进最后一个没填满的逻辑块，填满了才分配新的逻辑块和物理块。一个序列没填满的只剩最后一块，显存不必按最大长度预留，按实际用量分配。不同序列之间还能共用块：让多个序列的逻辑块指向同一批物理块，用引用计数记着有几处指向它；要改一块被多个序列共用的块时，先复制出一份再改，这一步叫写时复制。
