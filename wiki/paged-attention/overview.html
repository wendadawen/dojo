概念概览 · PagedAttention

PagedAttention（分页注意力）：把 KV cache 切成页，消掉显存浪费

vLLM 借操作系统分页思想管理 KV cache：固定大小页 + 页表映射 + 按需分配，把显存有效利用率从两三成提到接近全量——代价是小页让跨内存层搬运退化为碎片化小传输。

更新于 2026-08-19

这是什么

PagedAttention 是 vLLM 提出的 KV cache 分页管理机制：把每个请求的 KV cache 切成固定 token 数的页，页在显存中不必连续，用页表维护逻辑顺序。注意力的数学计算不变，变的只是存储布局与 kernel 取数方式。

解决什么问题

此前的系统按请求的最大可能长度预分配连续显存，产生三类浪费：为未来 token 的预留槽、实际长度小于最大长度的内部碎片、大小不一的预留块之间的外部碎片。vLLM 实测既有系统只有 20.4%–38.2% 的 KV cache 显存真正存了 token 状态——浪费直接压低可并发的批大小。

核心机制

  • 固定大小页 + 页表：序列的逻辑页号映射到任意空闲物理页，注意力 kernel 沿页表逐页取数，对上层透明。
  • 按需分配：token 写满当前页才申请新页——预留槽清零；所有页同大小，任何空闲页可用——外部碎片清零；内部碎片只剩每请求最后一页（至多一页）。
  • 页级共享：共享前缀的序列可让页表指向同一物理页，是跨请求 KV cache 复用的实现基础。

关键结论与边界

  • 分页解决的是显存利用率，不是容量：装不下的缓存仍要逐出或分层。
  • 页很小（TensorRT-LLM 32 / vLLM 16 / SGLang 1 token），序列散布在互不相邻的页中；跨内存层搬运只能逐页小传输，实测 8192 token 加载仅约 22% PCIe 5.0 带宽——这是分层缓存传输瓶颈的来源。
  • 页大小是显存效率、缓存命中粒度、管理开销、传输单元四向权衡的旋钮，没有普适最优；Strata 的 GPU-assisted I/O 让传输效率退出这个权衡。
