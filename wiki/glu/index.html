    GLU（Gated Linear Unit）：用一个 sigmoid 门逐元素缩放线性投影

    主要依据：Dauphin et al. 2017《Language Modeling with Gated Convolutional Networks》(arXiv:1612.08083)；Shazeer 2020《GLU Variants Improve Transformer》(arXiv:2002.05202)。公式编号与章节均按原文核对。

    把一个向量送进神经网络的一层时，能不能让"每个维度自己决定放多少出去"——而不是用一个固定的激活函数对每个维度套同一条规则？GLU（Gated Linear Unit，门控线性单元）就是回答这个问题的一类单元：它算两份线性投影，一份过 sigmoid 压到 $(0,1)$ 当"门"，再与另一份逐元素相乘，让门控制每个维度放多少信息过去。本文说明 GLU 的定义、梯度通路、家族派生与经验边界。

    核心问题

    1. 用一句话说清 GLU 在做什么，并说明它解决什么问题。

      解答：算两份线性投影，一份过 sigmoid 当门，与另一份逐元素相乘，实现按维度调节且不杀梯度

      GLU 用 sigmoid 门逐元素缩放线性投影：$h=(xW+b)\otimes\sigma(xV+c)$。它同时回应"线性+固定激活"的两个缺口——不能按输入内容逐维度调节放行量，以及用 sigmoid/tanh 当门会顺带压掉梯度。完整动机见「1. 为什么需要"门"」。

    2. 从公式解释为什么 GLU 既有非线性又给梯度留了线性通路（与 GTU 对比）。

      解答：非线性来自乘性门控；梯度第一项被门值而非门导数缩放，开门时近似直通

      GLU 梯度的第一项 $\nabla\mathbf{X}\otimes\sigma(\mathbf{X})$ 的缩放因子是门值本身，开门单元上近似为 $\nabla\mathbf{X}$，即"乘性跳连"；非线性来自值与门的乘性交互，而非把 sigmoid 套在输出上。GTU 的对应项带 $\tanh'$，随输入增大趋零。完整推导见「3. 为什么 GLU 给梯度留了一条线性通路」。

    3. 给定小输入与权重，手算 GLU 的输出，并把数字翻译成"哪个维度被门放行/压低"。

      解答：$h\approx[0.73, 0.19]$——第一维放行约 73%，第二维仅约 38%

      以 $x=[1.0,0.5]$、$W=I$、$V=\mathrm{diag}(1,-1)$、$b=c=0$ 为例：门 $\sigma(xV)\approx[0.73,0.38]$，输出 $h\approx[0.73,0.19]$。两维都有值，门给出不同放行比例，即"按维度调节"。手算全过程见「2. GLU 的公式与手算」。

    4. 说明 GLU 家族怎么派生（Bilinear、SwiGLU/GeGLU/ReGLU），并指出 Dauphin 与 Shazeer 的记号差异。

      解答：去激活得 Bilinear，换激活得 ReGLU/GEGLU/SwiGLU；两篇记法只是 $W\leftrightarrow V$ 互换

      把门分支的激活去掉得 Bilinear；换成 ReLU/GELU/Swish 得 ReGLU/GEGLU/SwiGLU（Shazeer 2020）。Dauphin 把 $\sigma$ 放在 $V$ 分支、Shazeer 放在 $W$ 分支，因 $\otimes$ 可交换而数学等价。见「4. GLU 家族」。

    5. 说明在 Transformer FFN 用 GLU 时为什么要缩 $2/3$ 维度，以及 GLU 不保证什么。

      解答：三矩阵比双矩阵多一份权重，缩 $d_{ff}$ 至 $2/3$ 保参数量相等；GLU 不保证普适更优

      GLU FFN 用三个权重矩阵，令 $3\cdot d\cdot d_{ff}'=2\cdot d\cdot d_{ff}$ 得 $d_{ff}'=\tfrac{2}{3}d_{ff}$。"变体更优"只是 T5 上的经验结论（原文明确无理论解释），GLU 也不替代归一化、不做跨位置聚合、门全关时输出为零。见「4. GLU 家族」与「5. 经验结论与边界」。

    最容易误解

    • "GLU 就是 sigmoid 激活函数"——不对。GLU 的 sigmoid 只作用于门分支，值分支是纯线性的；非线性来自乘性门控，不是把 sigmoid 当激活套在整条输出上。
    • "GLU 一定比 ReLU 好"——不对。Shazeer 只在 T5 上经验观察到 GLU 变体优于 ReLU 基线，原文未给理论解释，不构成普适保证。
    • "门必须用 sigmoid"——不对。原始 GLU 用 sigmoid，但 Shazeer 的"GLU 变体"框架把 sigmoid 替换为任意激活（ReLU/GELU/Swish）甚至去掉（Bilinear），统称 GLU 家族。
    • "Dauphin 和 Shazeer 的 $W,V$ 是同一个东西"——不对。两篇把 $\sigma$ 放在不同分支，是 $W\leftrightarrow V$ 标签互换，不是矛盾；读 SwiGLU 时用 Shazeer 记法。

    1. 为什么需要"门"——一层线性+激活缺了什么

    一个最常见的神经网络层长这样：先做线性变换 $xW+b$，再套一个固定的激活函数，例如 $\mathrm{ReLU}(xW+b)$ 或 $\tanh(xW+b)$。这里 $x$ 是输入向量，$W$ 是权重矩阵，$b$ 是偏置，$W$ 与 $b$ 在训练中学习；激活函数 $\mathrm{ReLU}(z)=\max(0,z)$、$\tanh(z)$ 之类是预先选定的、对所有维度套同一条规则的非线性。

    这种"线性 + 固定激活"缺了两样东西。

    第一，缺一种按输入内容、逐维度决定放多少的能力。$\mathrm{ReLU}$ 只能"大于 0 全放、小于 0 全砍"，规则是固定的；$\tanh$ 只能整体压到 $[-1,1]$，也固定。模型没法说"这一维今天该放 70%、那一维该放 10%"——除非它专门再算一个量来当"阀门"。

    第二，缺一种不杀梯度的非线性。如果用 sigmoid 或 $\tanh$ 当门来获得"按维度调节"，会顺带把梯度也压下去：sigmoid 的导数 $\sigma'(z)=\sigma(z)(1-\sigma(z))$[F2] 在输入绝对值大时趋于 0，$\tanh$ 的导数 $\tanh'(z)=1-\tanh^2(z)$ 同样如此。深层网络里这种"门控激活的导数"逐层相乘，梯度就消失了。这一现象出现在门控单元 GTU（Gated Tanh Unit）中——这里写作 $\tanh(\mathbf{X})\otimes\sigma(\mathbf{X})$ 是梯度分析用的两分支共享输入简写，其一般形式两支各带仿射项 $\tanh(\mathbf{X}*\mathbf{W}+\mathbf{b})$、$\sigma(\mathbf{X}*\mathbf{V}+\mathbf{c})$，本身含可学习权重；其梯度结构见「3. 为什么 GLU 给梯度留了一条线性通路——门值缩放而非导数缩放」。[C4, F3]

    门控的想法正是同时回应这两个缺口：再算一份线性投影、过 sigmoid 压到 $(0,1)$ 当"门"，逐元素乘到"值"上。sigmoid $\sigma(z)=1/(1+e^{-z})$ 把任意实数压到 $(0,1)$（基础记号，下同）；$\otimes$ 是逐元素乘积，两个同形向量逐位相乘。开门（门 $\approx 1$）即放行原值，关门（门 $\approx 0$）即屏蔽。这一步把"按维度调节"和"是否杀梯度"分了开来：GLU 的梯度里有一条不被门导数压没的通路。

    图只展示结构：上面是常规"线性+激活"单分支；下面是 GLU 的两分支——值分支 $xW+b$ 与门分支 $\sigma(xV+c)$，在 $\otimes$ 处逐元素相乘。每个分支的具体公式由正文给出。

    一句话定位：GLU 是一种用 sigmoid 门逐元素缩放线性投影的神经网络单元。它在 2017 年由 Dauphin 等人为门控卷积语言模型提出，后被 Shazeer 2020 推广为整个"GLU 变体"家族。

    本章问题

    1. 常规层与 GLU 层在"激活来自哪里"上的差别是什么。

      解答：常规层的激活预先选定、对所有维度套同一条规则；GLU 的门由输入内容算出、逐维度调节

      常规层只有一份线性投影 $xW+b$，其激活函数（$\mathrm{ReLU}$、$\tanh$ 等）是预先选定的，对所有维度套同一条固定规则。GLU 额外再算一份线性投影 $xV+c$ 并过 sigmoid 得到门，逐元素乘到值分支上——"放多少"由输入内容经学习到的 $V,c$ 决定，不同维度可以有不同的放行量。

    2. 为什么门用 sigmoid（压到 $(0,1)$）而不是直接用原始线性值当门。

      解答：门需要的是 0 到 1 之间的放行比例，原始线性值无界且可负，起不到这个作用

      门的语义是"该维度放行多少"：$0$ 表示完全屏蔽、$1$ 表示完全放行。原始线性值 $xV+c$ 无界且可正可负，直接乘上去会任意放大或翻转符号，无法当作放行比例使用；sigmoid 把任意实数压到 $(0,1)$，门的取值范围与语义固定，且其导数性质已知，便于分析梯度通路。

    GLU 的正式定义与一个手算例子见「2. GLU 的公式与手算」。

    2. GLU 的公式与手算——定义、边界与逐维度缩放

    GLU 的正式定义由 Dauphin et al. 2017（§2, Eq.(1)）给出[C1, F1]：

    $$h(\mathbf{X})=(\mathbf{X}*\mathbf{W}+\mathbf{b})\otimes\sigma(\mathbf{X}*\mathbf{V}+\mathbf{c})$$

    逐项说明每个符号：

    • $\mathbf{X}$：本层的输入。Dauphin 原文中是 $\mathbb{R}^{N\times m}$ 的矩阵（$N$ 为序列长度、$m$ 为输入通道数）。
    • $*$：Dauphin 原文是卷积算子；$*$ 不是矩阵乘。在 Transformer/前馈语境里它退化为普通矩阵乘，本文后续统一记作 $xW$ 以简化。这是教学简化，不改变 GLU 的机制。
    • $\mathbf{W},\mathbf{V}$：两套独立的可学习权重（卷积核 / 权重矩阵）。Dauphin 原文 $\mathbf{W},\mathbf{V}\in\mathbb{R}^{k\times m\times n}$；前馈语境里 $\in\mathbb{R}^{d_{in}\times d_{out}}$。
    • $\mathbf{b},\mathbf{c}$：两套独立的偏置，$\in\mathbb{R}^{n}$。
    • $\mathbf{X}*\mathbf{W}+\mathbf{b}$：值分支，一份普通的线性投影，不经过任何激活。
    • $\sigma(\mathbf{X}*\mathbf{V}+\mathbf{c})$：门分支，另一份线性投影过 sigmoid，被压到 $(0,1)$，逐维度作为"放行量"。
    • $\otimes$：逐元素乘积（Hadamard 积），两个同形张量逐位相乘。

    用三个边界检查验证公式确实在做"门控缩放"：

    • 门全为 1：$\sigma(\mathbf{X}*\mathbf{V}+\mathbf{c})=\mathbf{1}$ 时，$h=\mathbf{X}*\mathbf{W}+\mathbf{b}$，输出就是值分支本身——线性直通。
    • 门全为 0：$\sigma(\mathbf{X}*\mathbf{V}+\mathbf{c})=\mathbf{0}$ 时，$h=\mathbf{0}$——输出被完全屏蔽。
    • 门在 $(0,1)$：输出是值分支逐维度乘上一个 $(0,1)$ 的系数——逐维度缩放。

    所以 GLU 的非线性来自乘性门控，不是把 sigmoid 当激活套在整条输出上——这是它和"线性 + sigmoid 激活"的关键区别。

    构造示例。取 $x=[1.0,\,0.5]$（一行二列向量），用最简单的 $2\times2$ 权重让两维的门能拉开差距。取 $W=I$（单位阵）让值分支近似直通，便于把注意力集中到门的作用上：

    $$W=\begin{pmatrix}1&0\\0&1\end{pmatrix}=I,\quad V=\begin{pmatrix}1&0\\0&-1\end{pmatrix},\quad b=c=[0,0].$$

    值分支（用 $xW+b$ 简化记法，$*$ 退化为矩阵乘）：

    $$xW+b=[1.0,\,0.5]\,I+[0,0]=[1.0,\,0.5].$$

    门分支的内部线性部分：

    $$xV+c=[1.0\times1+0.5\times0,\;1.0\times0+0.5\times(-1)]=[1.0,\,-0.5].$$

    过 sigmoid（取四位小数，$\sigma(1.0)=1/(1+e^{-1})\approx0.7311$，$\sigma(-0.5)=1/(1+e^{0.5})\approx0.3775$）：

    $$\sigma(xV+c)=\sigma([1.0,\,-0.5])\approx[0.7311,\,0.3775].$$

    逐元素相乘得 GLU 输出：

    $$h(x)=[1.0,\,0.5]\otimes[0.7311,\,0.3775]\approx[0.7311,\,0.1888].$$

    把数字翻译回机制：第一维的门 $\approx0.73$，放行了值 $1.0$ 的约 $73\%$；第二维的门 $\approx0.38$，只放行了值 $0.5$ 的约 $38\%$。两个维度同样有值，门却给出了不同的放行比例——这就是"按维度调节"。数字是便于手算的教学构造，不代表真实模型参数。

    展开：门 → 1 与门 → 0 的退化（同一输入，换一套 $V$）

    构造示例。把 $V$ 换成 $\mathrm{diag}(10,-10)$，其余不变。门分支内部线性部分变为 $xV=[10,\,-5]$，$\sigma([10,-5])\approx[\sigma(10),\sigma(-5)]\approx[0.99995,\,0.00669]$，近似为 $[1,0]$。于是 $h\approx[1.0,\,0.5]\otimes[1,0]=[1.0,\,0]$：第一维门近似全开，值分支直通；第二维门近似全关，输出归零。这验证了"开门直通、关门屏蔽"——GLU 在两个极端分别退化为"线性"和"零"。

    本章问题

    1. 给定 $x,W,V,b,c$，写出 GLU 运算的三个步骤（值分支、门分支、相乘）。

      解答：值分支 $xW+b$、门分支 $\sigma(xV+c)$、两者逐元素相乘

      第一步算值分支 $xW+b$，不经过任何激活；第二步算门分支，先做线性投影 $xV+c$ 再过 sigmoid 压到 $(0,1)$；第三步把两个同形向量逐元素相乘（$\otimes$），得输出 $h=(xW+b)\otimes\sigma(xV+c)$。

    2. 门为全 $1$ 与全 $0$ 时，GLU 输出分别退化为什么。

      解答：全 $1$ 退化为值分支本身（线性直通），全 $0$ 退化为零输出（完全屏蔽）

      门全为 $1$ 时 $h=xW+b$，输出就是值分支，等价于一层纯线性变换；门全为 $0$ 时 $h=\mathbf{0}$，输出被完全屏蔽。门在 $(0,1)$ 之间时，输出是值分支逐维度乘一个放行系数，即逐维度缩放。

    3. GLU 的非线性来自哪里？为什么不能把它等价于"线性 + sigmoid 激活"。

      解答：非线性来自乘性门控，即两个输入相关的量逐元素相乘

      GLU 的非线性来自值分支与门分支的乘性交互：门本身是输入的非线性函数（含 sigmoid），再逐元素乘到值上，整体不再是单一线性变换的逐元素单变量函数。"线性 + sigmoid 激活"只是对一份线性投影逐元素套 sigmoid，输出仍是逐维度的单变量非线性，没有乘性交互，二者机制不同。

    本章给出了 GLU 的公式并手算验证了"门控缩放"。但公式只说明前向；GLU 为什么给梯度留了一条不被导数压没的线性通路，见「3. 为什么 GLU 给梯度留了一条线性通路」。

    3. 为什么 GLU 给梯度留了一条线性通路——门值缩放而非导数缩放

    GLU 被提出的核心理由不是输出计算，而是不杀梯度；这一点取决于它梯度的结构。

    为隔离梯度结构，Dauphin 把分析简化到两分支共享输入的形式 $Y=\mathbf{X}\otimes\sigma(\mathbf{X})$（这是教学简化，不改变结论；一般 GLU 只是把两个 $\mathbf{X}$ 换成 $\mathbf{X}*\mathbf{W}+\mathbf{b}$ 与 $\mathbf{X}*\mathbf{V}+\mathbf{c}$，梯度结构相同）。用乘积求导法则（链式法则）对 $\mathbf{X}$ 求梯度，得 GLU 的梯度（Dauphin §3, Eq.(3)）[C3, F4]。其中 $\nabla\mathbf{X}$ 表示上游梯度——损失对 GLU 输出的梯度，由下游回传过来：

    $$\nabla[\mathbf{X}\otimes\sigma(\mathbf{X})]=\nabla\mathbf{X}\otimes\sigma(\mathbf{X})\;+\;\mathbf{X}\otimes\sigma'(\mathbf{X})\,\nabla\mathbf{X}.$$

    两项的职责不同：

    • 第一项 $\nabla\mathbf{X}\otimes\sigma(\mathbf{X})$：被缩放的因子是门值 $\sigma(\mathbf{X})$ 本身，不是 $\sigma'(\mathbf{X})$。对"开门"单元（$\sigma(\mathbf{X})\approx1$）这一项近似为 $\nabla\mathbf{X}$——梯度几乎不衰减地直通。Dauphin 原文称之为"乘性跳连"（multiplicative skip connection）[C3]。
    • 第二项 $\mathbf{X}\otimes\sigma'(\mathbf{X})\nabla\mathbf{X}$：含 $\sigma'(\mathbf{X})=\sigma(\mathbf{X})(1-\sigma(\mathbf{X}))$，门饱和（无论趋于 0 还是 1）时趋于 0。这是"正常的 sigmoid 路径"，会衰减。

    关键在第一项：它的缩放因子是门值而不是门导数。门值由模型学习、可控；门导数是否趋零只取决于输入大小。所以 GLU 把"梯度是否被压没"从"激活导数是否趋零"改成"门值是否开门"——门开则梯度通，门关则梯度断（这是有意的屏蔽，不是副作用）[C2]。

    对照 GTU（Gated Tanh Unit，Dauphin §3, Eq.(2)）$Y=\tanh(\mathbf{X})\otimes\sigma(\mathbf{X})$ 的梯度[C4, F3]：

    $$\nabla[\tanh(\mathbf{X})\otimes\sigma(\mathbf{X})]=\tanh'(\mathbf{X})\nabla\mathbf{X}\otimes\sigma(\mathbf{X})\;+\;\sigma'(\mathbf{X})\nabla\mathbf{X}\otimes\tanh(\mathbf{X}).$$

    两项分别带 $\tanh'(\mathbf{X})$ 和 $\sigma'(\mathbf{X})$。第一项也带了 $\tanh'(\mathbf{X})$——而 $\tanh'(\mathbf{X})=1-\tanh^2(\mathbf{X})$ 随 $|\mathbf{X}|$ 增大趋于 0。也就是说，GTU 的"值分支"梯度也会被 $\tanh$ 的导数压没，且这个压没取决于输入大小、不是门可控的。GLU 的对应项没有这个 $\tanh'$ 因子。这正是 Dauphin 的论点：GLU "在开门单元上不额外缩放梯度"。

    单元前向梯度第一项（值路径）的缩放因子该因子是否随输入增大趋零
    GLU$\mathbf{X}\otimes\sigma(\mathbf{X})$$\sigma(\mathbf{X})$（门值，非导数）否（仅在门主动关闭时趋零）
    GTU$\tanh(\mathbf{X})\otimes\sigma(\mathbf{X})$$\tanh'(\mathbf{X})$（导数）是（$|\mathbf{X}|$ 大即趋零）
    补充：GLU 梯度 $\nabla[\mathbf{X}\otimes\sigma(\mathbf{X})]$ 的链式法则步骤

    目标：对 $Y=\mathbf{X}\otimes\sigma(\mathbf{X})$ 求 $\mathbf{X}$ 的梯度，已知上游梯度 $\nabla\mathbf{X}$（损失对 $Y$ 的梯度）。设 $A=\mathbf{X}$、$B=\sigma(\mathbf{X})$，则 $Y=A\otimes B$。逐元素看，$Y_i=A_i B_i$，故 $\frac{\partial Y_i}{\partial X_i}=\frac{\partial A_i}{\partial X_i}B_i + A_i\frac{\partial B_i}{\partial X_i}=1\cdot\sigma(X_i)+X_i\cdot\sigma'(X_i)$。乘以上游梯度得回传：$\nabla_{X_i}=\nabla_{Y_i}\cdot\sigma(X_i)+\nabla_{Y_i}\cdot X_i\cdot\sigma'(X_i)$。整理为向量形式：$\nabla=\nabla\mathbf{X}\otimes\sigma(\mathbf{X})+\mathbf{X}\otimes\sigma'(\mathbf{X})\nabla\mathbf{X}$，与 Dauphin Eq.(3) 一致。其中用到 $\sigma'(z)=\sigma(z)(1-\sigma(z))$。

    边界：GLU 不是"永不消失"。若门 $\sigma(\mathbf{X})$ 饱和到 0，第一项也趋于 0——通路被门主动关掉。区别在于这是门控选择而非输入幅值副作用。Dauphin 原文的限定语是"对激活的门单元不额外缩放"（for the activated gating units）。

    本章问题

    1. GLU 梯度的两项中，哪一项不含 $\sigma'$？它的缩放因子是什么。

      解答：第一项 $\nabla\mathbf{X}\otimes\sigma(\mathbf{X})$，缩放因子是门值 $\sigma(\mathbf{X})$ 本身

      第一项 $\nabla\mathbf{X}\otimes\sigma(\mathbf{X})$ 不含 $\sigma'$。它用门值缩放上游梯度：门开的单元上 $\sigma(\mathbf{X})\approx1$，梯度近似直通，Dauphin 称之为"乘性跳连"。门值由模型学习并可控，与输入幅值无直接关系。

    2. GTU 梯度的第一项含什么导数？它为什么会让深层梯度消失。

      解答：含 $\tanh'(\mathbf{X})=1-\tanh^2(\mathbf{X})$，随 $|\mathbf{X}|$ 增大趋零且不可由门控制

      GTU 梯度第一项为 $\tanh'(\mathbf{X})\nabla\mathbf{X}\otimes\sigma(\mathbf{X})$，值路径也被 $\tanh$ 的导数缩放。$\tanh'(\mathbf{X})$ 随 $|\mathbf{X}|$ 增大趋于 $0$，深层网络里逐层相乘导致梯度消失，且这一压低取决于输入幅值，门无法干预。GLU 的对应项没有 $\tanh'$ 因子。

    3. 门 $\sigma(\mathbf{X})$ 饱和到 0 时，GLU 的梯度通路会发生什么？这是"副作用"还是"门控选择"。

      解答：通路被门主动关断，属于门控选择而非输入幅值副作用

      门饱和到 $0$ 时第一项 $\nabla\mathbf{X}\otimes\sigma(\mathbf{X})$ 也趋于 $0$，梯度通路被切断。但这与 GTU 的消失不同：GTU 的压低由输入幅值决定、不可控，而 GLU 的关断是门控本身的选择——模型学习到"该维度此刻不需要传信息"，是有意的屏蔽。

    GLU 的 sigmoid 不是唯一选择：把门分支的激活替换或去掉，得到整个 GLU 家族，其派生规则与塞进 Transformer 前馈层的形式见「4. GLU 家族」。

    4. GLU 家族——换激活、去门控、塞进 FFN

    GLU 的 sigmoid 不是唯一选择。Shazeer 2020（§2, Eq.(4)(5)）把"门分支的激活"替换成其它函数，得到一族变体；Dauphin 原文本身也定义了一个去掉门控激活的退化形式。

    4.1 派生规则

    去激活（退化为 Bilinear）：把 GLU 的 $\sigma$ 去掉，让门分支也是纯线性，得 Bilinear 层（Dauphin §5.3，归因 Mnih & Hinton 2007）[C5, F5]：

    $$h(\mathbf{X})=(\mathbf{X}*\mathbf{W}+\mathbf{b})\otimes(\mathbf{X}*\mathbf{V}+\mathbf{c}).$$

    虽无线性门控激活，逐元素乘本身仍是"两个线性投影的乘性交互"，比单一"线性+激活"多一种数据相关的乘性调制。

    换激活（变体）：保留"值分支线性 × 门分支过激活"的结构，把 sigmoid 换成别的激活。Shazeer §2 Eq.(5) 给出[C6, F6]：

    $$\mathrm{ReGLU}(x,W,V,b,c)=\max(0,\,xW+b)\otimes(xV+c),$$

    $$\mathrm{GEGLU}(x,W,V,b,c)=\mathrm{GELU}(xW+b)\otimes(xV+c),$$

    $$\mathrm{SwiGLU}(x,W,V,b,c,\beta)=\mathrm{Swish}_\beta(xW+b)\otimes(xV+c).$$

    其中 $\mathrm{Swish}_\beta(z)=z\cdot\sigma(\beta z)$（也写作 SiLU，$\beta=1$ 时为 $z\cdot\sigma(z)$），$\mathrm{GELU}$、$\mathrm{ReLU}=\max(0,z)$ 是激活名，这里只作为门控激活出现，不展开各自机制。

    4.2 记号差异：Dauphin vs Shazeer

    两篇论文把 $\sigma$/激活放在不同分支上：

    记法GLU 形式$\sigma$/激活在哪值分支
    Dauphin（本文主记法）$(xW+b)\otimes\sigma(xV+c)$$V$ 分支$xW+b$
    Shazeer$\sigma(xW+b)\otimes(xV+c)$$W$ 分支$xV+c$

    因 $\otimes$ 可交换，$(xW+b)\otimes\sigma(xV+c)=\sigma(xV+c)\otimes(xW+b)$，两者只是 $W\leftrightarrow V$ 标签互换、数学等价，不是矛盾[C9]。但读 SwiGLU、GeGLU 这类 Shazeer 系变体时，要按 Shazeer 记法——激活在 $W$ 分支。SiTU-GLU、SwiGLU 均沿用 Shazeer 记法，本文的变体公式也按 Shazeer 记法给出。

    4.3 塞进 Transformer FFN：三矩阵与 $2/3$ 缩放

    标准 Transformer FFN（Shazeer §1，无偏置版本）只用两个权重矩阵：

    $$\mathrm{FFN}_{\mathrm{ReLU}}(x,W_1,W_2)=\max(xW_1,0)\,W_2.$$

    GLU 变体版（Shazeer §2, Eq.(6)）用三个[C7, F7]：

    $$\mathrm{FFN}_{\mathrm{GLU}}(x,W,V,W_2)=(\sigma(xW)\otimes xV)\,W_2.$$

    多一个矩阵，参数量就多。为保持参数量与计算量与双矩阵基线相等，Shazeer 把 FFN 的隐藏维 $d_{ff}$ 缩为原来的 $2/3$[C7, F8]。推导：

    • 双矩阵 FFN 参数量：$W_1$ 是 $d\times d_{ff}$，$W_2$ 是 $d_{ff}\times d$，合计 $2\cdot d\cdot d_{ff}$。
    • 三矩阵 GLU FFN 参数量：$W,V$ 各 $d\times d_{ff}'$，$W_2$ 是 $d_{ff}'\times d$，合计 $3\cdot d\cdot d_{ff}'$。
    • 令相等：$3\cdot d\cdot d_{ff}'=2\cdot d\cdot d_{ff}\;\Rightarrow\;d_{ff}'=\tfrac{2}{3}\,d_{ff}$。

    实例（Shazeer §3.1）[N2]：基线 $d_{ff}=3072$，GLU 变体缩为 $d_{ff}'=2048$（$3072\times\tfrac{2}{3}=2048$）。由于基线常取 $d_{ff}=4d$，缩放后变体取 $d_{ff}'=\tfrac{2}{3}\times4d=\tfrac{8}{3}d$。

    展开：参数量等式的逐步推导与一个小数字验证

    设模型维度 $d=768$、基线 $d_{ff}=3072$。双矩阵 FFN 参数量 $=2\times768\times3072=4{,}718{,}592$。三矩阵 GLU FFN 若不缩维度则为 $3\times768\times3072=7{,}077{,}888$，比基线多 $50\%$。缩为 $d_{ff}'=2048$ 后参数量 $=3\times768\times2048=4{,}718{,}592$，与基线相等。构造示例，数字为验算用。

    本章问题

    1. 把 GLU 变成 SwiGLU，改的是哪一处？变成 Bilinear 又改了哪一处。

      解答：SwiGLU 把激活换成 Swish，Bilinear 把激活去掉

      SwiGLU（Shazeer 记法）把作用在 $xW+b$ 上的激活由 sigmoid 换成 $\mathrm{Swish}_\beta(z)=z\cdot\sigma(\beta z)$，结构仍是"一支过激活、一支线性、逐元素相乘"。Bilinear 则把激活完全去掉，两分支都是纯线性投影，乘性交互仍在但没有饱和门。

    2. Dauphin 记法与 Shazeer 记法的 $\sigma$ 分别在哪个分支？为什么数学等价。

      解答：Dauphin 在 $V$ 分支、Shazeer 在 $W$ 分支；$\otimes$ 可交换故等价

      Dauphin 写作 $(xW+b)\otimes\sigma(xV+c)$，$\sigma$ 在 $V$ 分支；Shazeer 写作 $\sigma(xW+b)\otimes(xV+c)$，激活在 $W$ 分支。由于逐元素乘积 $\otimes$ 满足交换律，两个式子只是 $W\leftrightarrow V$ 标签互换，数学上等价，不是矛盾。读 SwiGLU、GeGLU 等 Shazeer 系变体时按 Shazeer 记法理解。

    3. 三矩阵 GLU FFN 要保持参数量与双矩阵 FFN 相等，$d_{ff}$ 应改为多少？写出等式。

      解答：缩为原来的 $2/3$，由 $3\cdot d\cdot d_{ff}'=2\cdot d\cdot d_{ff}$ 解出

      双矩阵 FFN 参数量为 $2\cdot d\cdot d_{ff}$，三矩阵 GLU FFN 为 $3\cdot d\cdot d_{ff}'$。令二者相等得 $d_{ff}'=\tfrac{2}{3}d_{ff}$。例如基线 $d_{ff}=3072$ 时缩为 $2048$；若基线取 $d_{ff}=4d$，则变体取 $\tfrac{8}{3}d$。

    "家族变体更优"是经验结论还是理论保证，取决于 Shazeer 的实验数据与原文给出的边界，见「5. 经验结论与边界」。

    5. 经验结论与边界——GLU 不保证什么

    Shazeer 2020 在 T5 base（segment-filling 任务，参数与计算量匹配）上对比了各变体[C8]。结果是经验性的：

    FFN 变体heldout log-perplexity（524,288 步，越低越好）
    FFN_ReLU（基线）1.677
    FFN_GELU1.679
    FFN_Swish1.683
    FFN_GLU1.663
    FFN_Bilinear1.648
    FFN_ReGLU1.645
    FFN_SwiGLU1.636
    FFN_GEGLU1.633（最优）

    观察：所有 GLU 变体（含退化的 Bilinear）都优于 ReLU/GELU/Swish 基线；GEGLU 与 SwiGLU 最优（Shazeer §2/§3 原文 "The GEGLU and SwiGLU variants produce the best perplexities"）。数字来自 Shazeer 2020 Table 1[N1]，限定条件：T5 base 架构、$d_{model}=768$、12 头、基线 $d_{ff}=3072$（GLU 变体缩为 2048）、segment-filling 任务。

    但 Shazeer 在论文末尾（§4）明确给出了对这一经验结论的态度：

    原文结语："We offer no explanation as to why these architectures seem to work; we attribute their success, as all else, to divine benevolence."

    翻译：作者没有解释这些架构为什么有效，把成功归于"神恩"。这句不是谦虚的修辞，而是明确标注"无理论解释"——经验结论不等于普适保证。

    5.1 GLU 不解决什么

    • 不保证在所有任务/模态上更好：Shazeer 的结论限定在 T5 语言建模。视觉、强化学习、小数据场景未必一致。
    • 不替代归一化：GLU 是门控激活，与 LayerNorm/RMSNorm 正交，不能拿来"稳定训练"。
    • 不做跨位置信息聚合：门控只控制"单个位置上每个维度的带宽"，不像注意力那样把多个位置的信息聚合过来。把门控和注意力混同是常见误解。
    • 不保证全局最优：梯度通路改善的是可训练性，不保证收敛到全局最优，也不解决局部极小、鞍点、大学习率失稳等问题。
    • 门全关时退化为零输出：若所有门饱和到 0，GLU 输出近似零、梯度也近零——"门控决定何时通"的另一面是"门关了就不通"。

    本章问题

    1. 说出 Shazeer 实验的一个限定条件，并指出它不能推广到什么场景。

      解答：限定在 T5 base 语言建模、参数与计算量匹配；不能推广到其它任务与模态

      例如限定条件"T5 base 架构、segment-filling 任务、参数量与计算量与基线匹配"。该结论不能推广到视觉、强化学习、小数据等场景——原文只在 T5 语言建模上做了对比，且明确未给理论解释。

    2. GLU 不解决的一类问题是什么。（举一个非注意力、非归一化的例子也可。）

      解答：例如训练优化问题——收敛到全局最优、避开鞍点与大学习率失稳

      GLU 改善的是可训练性（梯度通路），不解决优化层面的困难：不保证收敛到全局最优，也不处理局部极小、鞍点或大学习率失稳。此外它不做跨位置信息聚合（那是注意力的职责）、不替代归一化（LayerNorm/RMSNorm 的职责）。

    3. "divine benevolence"这句在论文里标注的是什么。

      解答：标注"无理论解释"——经验结论不构成普适保证

      这句自谦的结语明确表示作者不解释这些架构为何有效，把成功归于"神恩"。它的作用是标注该结论的经验性质：GLU 变体更优是 T5 上的实验观察，不是理论保证。

    辅助解释与类比边界

    • "门控制每个维度放多少信息过去"——只解释 $\sigma(\cdot)\in(0,1)$ 作为逐维度系数的乘性缩放关系。失效边界：门 $\sigma$ 不是真正的物理阀门，没有离散开关；"放行"是连续乘法、不是选择。
    • "乘性跳连"——Dauphin 原词，只解释 GLU 梯度第一项 $\nabla\mathbf{X}\otimes\sigma(\mathbf{X})$ 被门值缩放、不含导数这一局部关系。失效边界：门饱和到 0 时该通路也趋零；它不等同于 ResNet 的加性跳连（结构不同），只是借"跳连"一词描述"梯度不被激活导数压没"。
    • "门控决定何时通 vs 输入幅值副作用"——只解释 GLU 与 GTU 的梯度差别来源。失效边界：不意味着 GLU 永不梯度消失（门全关仍消失），也不意味着 GTU 在浅层就一定坏。

    简化条件及其限制

    • 把 Dauphin 的 $*$（卷积）在 Transformer 语境统一记为矩阵乘 $xW$。可推出：GLU 在卷积与前馈两种语境的机制结论一致；不可推出：卷积的具体维度/平移不变性质——那需要回到 $*$ 的卷积定义。
    • 梯度分析用简化形式 $Y=\mathbf{X}\otimes\sigma(\mathbf{X})$（两分支共享 $\mathbf{X}$）。可推出：GLU 梯度的通路结构与门值/导数的关系；不可推出：一般 GLU 两分支用不同 $W,V$ 时的精确系数——一般形式只是把两个 $\mathbf{X}$ 换成 $xW+b$ 与 $xV+c$，链式结构相同。
    • Swish/GELU/ReLU 作为激活名出现而不展开。可推出：家族派生规则；不可推出：SwiGLU 为何选 Swish、GELU 的具体形式。
    • Sigmoid、$\otimes$、$xW+b$、链式法则作为基础记号给出定义。可推出：GLU 所需定义；不可推出：这些原语的完整理论。

    全文总结：GLU 用 sigmoid 门逐元素缩放线性投影，把"按维度调节"与"是否杀梯度"拆开——值分支给梯度留了一条被门值（而非门导数）缩放的线性通路，这是它相对 GTU 的关键差别。手算验证了门控缩放的极端退化。把 sigmoid 替换或去掉得到 Bilinear、ReGLU/GEGLU/SwiGLU 家族，Dauphin 与 Shazeer 仅是 $W\leftrightarrow V$ 标签互换。塞进 Transformer FFN 要缩 $2/3$ 维度保参数量，而"变体更优"是 T5 上的经验结论、原文未给理论解释。以上对应开篇「核心问题」的五条。
