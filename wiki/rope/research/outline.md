# RoPE 旋转位置编码 · 教学大纲

## 1. 页面开头

### 钩子问题

> 给一个 Transformer 三个内容完全相同的 token "the the the"，每个位置的输出会一样吗？答案是：在没有位置信息时，三个位置的输出完全一样——注意力只看内容，不看顺序。要让模型分清"第一个 the"和"第三个 the"，必须把位置信息注入到注意力里。

### 一句话解释

RoPE 是一种按 token 绝对位置旋转 query 和 key 向量的位置编码，使注意力内积自然只依赖两个 token 的相对位置 `m−n`，不引入任何可学习参数。

### 要解决的具体问题

让 softmax 注意力具备位置感知，且同时满足：绝对位置可定位、相对位置决定注意力分数、无额外参数、支持长度外推（含扩展方法）。

### 学习承诺（与 scope.md 的 Q1–Q5 一致）

读完这一页，你应该能够：
- 用一句话说清 RoPE 在做什么，并说明它和绝对位置编码、相对位置编码、NoPE 的本质区别；
- 给定 2 维 q、k 和位置 m、n，手算 RoPE 旋转后的内积，并验证只依赖 m−n；
- 说明 d 维 RoPE 怎么从 2 维推广，以及 θ_i 几何级数起什么作用；
- 解释远程衰减性质来源，以及"只在 QK 不在 V"的机制原因；
- 说清 RoPE 的适用边界、长度外推为何需要 YaRN/PI，以及 K3 MLA 不施旋转的设计选择。

### 首个具体场景

钩子问题中"三个 the"的场景，会在 S1 用对照表说明四类位置编码方案各自怎么处理这个问题。

## 2. 章节设计

### S1：为什么需要位置编码——RoPE 与四类方案的差异

- **主要教学问题**：注意力本身没有位置感知；已有的几类位置编码各自做了什么，RoPE 与它们的差异在哪。
- **对应范围**：Q1；C1, C2, C3；scope §2.1 "包括什么" 的应用位置、§2.6 误解"RoPE 是相对位置编码"和"RoPE 引入了额外参数"。
- **正文要点**：
  - 自注意力是排列等变的（引用 [`NoPE`](../nope/index.html)），交换输入顺序后每个位置输出值不变。
  - 位置编码的目的是给注意力加位置感知。
  - 四类方案对照表：APE / 相对 PE（T5、ALiBi）/ RoPE / NoPE——"位置信息加在哪里、怎么加、有无额外参数"。
  - RoPE 的特征：在注意力层内部、softmax 之前对 Q/K 旋转；不引入参数；不改 V；不改输入嵌入；"绝对构造、相对效果"。
  - 澄清两个误解：RoPE 不引入参数、不叫"相对位置编码"（叫"绝对构造、相对效果"更准确）。
- **讲解材料及职责**：
  - 对照表格组件：四类方案的"做了什么 / 加在哪里 / 是否有参数 / 长度外推"对比。
  - callout（yellow）：澄清"绝对构造、相对效果"。
- **前置知识安排**：自注意力最小定义 + 排列等变（引用 NoPE 页）。
- **完成检查**：
  - APE、相对 PE、RoPE、NoPE 各把位置信息加在哪里？分别是否有可学习参数？
  - RoPE 论文摘要里"absolute position"与"relative position dependency"同时出现，这两件事是怎么统一的？
- **过渡**："上面看到 RoPE 用旋转处理位置问题。下一章用最小的 2 维例子看旋转到底是怎么做的。"

### S2：2 维 RoPE 是怎么旋转的——最小可手算机制

- **主要教学问题**：2 维情况下 RoPE 的旋转矩阵长什么样，怎么对 q 和 k 旋转，旋转后内积长什么样。
- **对应范围**：Q2；F1, F2；N3；scope §2.1 "包括 2 维 RoPE"、§2.6 误解"内积只是 cos"。
- **正文要点**：
  - 把单个 2 维 (q₀, q₁) 对看作平面上的一个点。
  - 位置 m 的旋转矩阵 `R_m`：2×2 矩阵形式 + 逐元素公式。
  - θ 是该对的频率（每位置旋转多少弧度）。
  - 旋转 q 得 `R_m q`、旋转 k 得 `R_n k`。
  - 内积 `(R_m q) · (R_n k)` 的展开：给出 F2 完整公式，强调不只是 cos 项。
  - 手算数字例子（教学示例）：q=(1,0)、k=(1,0)、θ=π/4、m=1、n=2；逐步代入得内积 √2/2。
  - 澄清误解："内积只是 cos((m−n)θ)" 是 q=k 的特例，一般情况还有 sin 项。
- **讲解材料及职责**：
  - ASCII 图示组件：2 维平面上的旋转可视化（q 点位置 m=1 旋转到 R_m q，k 点位置 n=2 旋转到 R_n k，箭头表示旋转方向）。
  - 数字例子折叠块：完整代入过程。
- **前置知识安排**：2×2 矩阵乘法、三角函数 cos/sin（假设已知）。
- **完成检查**：
  - 写出 m=0 时的 `R_m`，说明为什么位置 0 的旋转矩阵是单位矩阵。
  - 给定 q=(1, 1)、k=(0, 1)、θ=π/6、m=0、n=1，手算内积。
- **过渡**："上面看到 m=1、n=2 的内积出现了 (n−m)=1 的 cos 与 sin。但旋转矩阵明明用了绝对位置 m 和 n，为什么内积只剩 m−n？下一章证明这件事。"

### S3：内积为何只依赖 m−n——旋转矩阵群的性质

- **主要教学问题**：从代数上证明 `(R_m q) · (R_n k) = q · R_{n−m} k`，即旋转矩阵乘积只依赖相对位置。
- **对应范围**：Q2；F3；C2；scope §2.1 "相对位置保持性质"、§2.6 误解"RoPE 是相对位置编码"。
- **正文要点**：
  - 关键等式 `R_m^T R_n = R_{n−m}`：用三角恒等式 cos(a+b)、sin(a+b) 展开。
  - 推出 `(R_m q)^T (R_n k) = q^T (R_m^T R_n) k = q^T R_{n−m} k`。
  - 含义：旋转矩阵构成 Abel 群，乘积只看角度差；绝对位置 m、n 在内积中"抵消"，只留 m−n。
  - 验证：用 S2 的手算例子，检查 F2 公式右侧确实只含 (n−m)θ，不含单独的 m 或 n。
  - 澄清误解：RoPE 用绝对位置 m、n 构造旋转，但产生的效果是相对位置——"绝对构造、相对效果"。
- **讲解材料及职责**：
  - 推导折叠块：从 `R_m^T R_n` 展开到 `R_{n−m}` 的完整代数（cos(mθ+nθ)=cos(mθ)cos(nθ)−sin(mθ)sin(nθ) 等）。
  - 对照：S2 手算例子的代入验证（说明 F2 右侧确实只含 (n−m)θ）。
- **前置知识安排**：三角恒等式 cos(a±b)、sin(a±b)（假设已知）。
- **完成检查**：
  - 用三角恒等式展开 `R_m^T R_n`，证明等于 `R_{n−m}`。
  - S2 手算例子中，m=1、n=2 与 m=5、n=6（同样 m−n=1）的内积是否相同？为什么？
- **过渡**："2 维情况下相对位置性质已经成立。但真实模型 d=64 或 128，怎么把这个机制推广到更高维度？"

### S4：d 维推广——分块对角旋转矩阵与 θ_i 几何级数

- **主要教学问题**：d 维 RoPE 如何从 2 维推广，θ_i 几何级数为什么让 RoPE 同时编码多尺度位置信息。
- **对应范围**：Q3；F4, F5, F6；C4, C3；scope §2.1 "d 维 RoPE"、"频率 θ_i 选择"。
- **正文要点**：
  - d 维向量拆为 d/2 个 2 维对：(q₀,q₁)、(q₂,q₃)、……
  - 每对独立旋转，用各自的频率 θ_i。
  - 分块对角矩阵 `R_m^d`：d/2 个 2×2 块。
  - 每块上 F3 成立，整体 `R_m^d^T R_n^d = R_{n−m}^d`，相对位置保持。
  - 频率公式 `θ_i = base^{-2i/d}`、`base = 10000`。
  - 几何级数多尺度：i 小 θ 大（旋转快、捕获短程）；i 大 θ 小（旋转慢、捕获长程）；N2 数字（d=128 时 θ₀=1、θ₆₃≈0.0001）。
  - 实现等价性一句话：实际实现用前后两半的逐元素乘法（GPT-NeoX 风格），与分块对角等价。
  - 手算 d=4 最小多频率例子：两个频率 θ₀=1、θ₁=0.5；q=(1,0,1,0)、k=(1,0,1,0)、m=1、n=2；每对独立验证。
- **讲解材料及职责**：
  - ASCII 图示组件：d=8 时分块对角矩阵的结构示意。
  - 对照表格组件：θ_i 几何级数前几项与对应的"旋转周期"（多少位置完成一周）。
  - 数字例子折叠块：d=4 多频率手算。
- **前置知识安排**：分块对角矩阵概念（用一句话说明）；几何级数（假设已知）。
- **完成检查**：
  - 给定 d=4、base=10000，计算 θ₀、θ₁（答案：θ₀=1、θ₁=10000^{-1/2}≈0.01，但教学用 base=4 给 θ₁=0.5 便于手算——澄清这是教学数字）。
  - i 小 vs i 大的频率对哪个负责短程依赖、哪个负责长程依赖？为什么？
- **过渡**："d 维 RoPE 已经能编码多尺度位置信息。但有个隐含问题：当两个 token 距离 |m−n| 越来越大，注意力内积会怎样变化？下一章回答这个问题，同时说明为什么 RoPE 只动 Q/K 不动 V。"

### S5：远程衰减与"只在 QK 不在 V"

- **主要教学问题**：RoPE 内积随 |m−n| 增大怎样变化？为什么 RoPE 只旋转 Q/K，不旋转 V？
- **对应范围**：Q4；F7, F8；C5, C1；scope §2.1 "远程衰减性质"、"应用位置"、§2.6 误解"RoPE 是给 V 也加旋转"。
- **正文要点**：
  - 假设 q、k 分量 i.i.d.、均值 0、方差 1，`E[q^T R_{n−m}^d k] = Σ cos((n−m)θ_i)`（F7）。
  - 由 Riemann-Lebesgue 引理，当 |m−n|→∞，归一化和 `(1/(d/2)) Σ cos((n−m)θ_i)` 趋于 0（F8）。
  - 含义：期望意义上，远距离 token 间注意力衰减——隐式 locality bias。
  - 教学解释：钟表指针类比（每个 2 维对是一只指针，i 小指针转得快、i 大指针转得慢；远距离时各指针相位散乱、cos 平均后抵消）。失效边界：分量非 i.i.d. 时不一定成立。
  - 为什么只动 Q/K：注意力分数只来自 `QK^T`，V 决定"取什么信息"而非"看哪里"，旋转 V 不改变注意力分布。
  - 澄清误解："RoPE 给 V 也加旋转"是错的；标准 RoPE 实现只在 Q/K 上。
- **讲解材料及职责**：
  - 推导折叠块：从 F5 出发，在 i.i.d. 假设下取期望得到 F7。
  - 教学解释（callout purple）：钟表指针类比，列失效边界。
  - 对照表格组件：i.i.d. 假设下不同 |m−n| 的归一化内积值（教学数字 d=8、几个 |m−n|）。
- **前置知识安排**：期望的线性性（假设已知）；Riemann-Lebesgue 引理（仅作陈述，不证明）。
- **完成检查**：
  - 用一句话说明为什么 RoPE 不动 V。
  - i.i.d. 假设为什么是远程衰减结论的关键？真实模型中这个假设严格成立吗？
- **过渡**："期望意义上远距离 token 注意力衰减——这是 RoPE 经验上对长程依赖有隐式 locality bias 的来源。但 RoPE 不是银弹：超出训练长度时它的频率会进入未学区间，下一章讲这个边界。"

### S6：适用边界——长度外推、K3 MLA 的 NoPE 选择

- **主要教学问题**：RoPE 的适用边界在哪里？长度外推为何需要 YaRN/PI？K3 MLA 为何拆出 rot 分量但不施旋转？
- **对应范围**：Q5；C7, C8；scope §2.5 不展开项、§2.6 边界、误解"RoPE 可任意外推"、"K3 的 MLA 用了 RoPE"。
- **正文要点**：
  - 适用条件：softmax 注意力、d 偶数、位置可用整数 m 表示。
  - 不适用 / 不解决：不替代 token 类型嵌入；不解决位置编号语义；纯双向编码器若需显式绝对位置信号，APE 可能更直接。
  - 长度外推边界：训练长度内 mθ_i 取值有限；超出时高频分量进入未学角度区间，简单外推性能下降。
  - YaRN/PI 简述（不展开推导）：PI 缩放 m、YaRN 按频率分组缩放，是常见扩展；细节属相邻概念。
  - 与矩阵吸收的冲突：MLA 等架构若对压缩潜变量施加 RoPE 会破坏矩阵吸收（引用 [`MLA`](../mla/index.html) S3）。
  - K3 MLA 的 NoPE 选择：K3 的 MLA 层结构上保留 rot 分量接口，但 `mla_use_nope=true`，实际不施旋转（引用 [`NoPE`](../nope/index.html) 与 [`Kimi K3`](../kimi-k3/index.html) §2.1.2）；位置信息由 KDA 隐式提供。
  - 澄清误解："K3 的 MLA 用了 RoPE"是错的；"RoPE 可任意外推到更长序列"也是错的。
- **讲解材料及职责**：
  - callout（red）：长度外推失败原因的一句话提示。
  - 对照表格组件：原始 RoPE vs PI vs YaRN 在"如何调整"上的差异（只列方向，不展开公式）。
- **前置知识安排**：因果掩码（概念页待生成，给最小定义：上三角 mask）；MLA 矩阵吸收（引用 [`MLA`](../mla/index.html) S2/S3，不重复推导）。
- **完成检查**：
  - RoPE 在长度外推时为什么失效？PI 与 YaRN 各自的解决思路是什么？
  - K3 的 MLA 层为什么用 NoPE 而不是 RoPE？这与矩阵吸收有什么关系？
- **过渡**（无下一章，给收束）："RoPE 是 softmax 注意力的事实标准位置编码；理解它的机制与边界，是判断任何 transformer 位置方案的前提。"
