# RoPE 旋转位置编码 · 内容范围

## 1. 概念歧义处理

**状态：已裁定。**

"RoPE"在不同来源中可能指三种略有重叠的对象：

1. **原始论文方案**（Su et al. 2021, arXiv:2104.09864）：在 Q、K 上施加位置相关的旋转矩阵，使 `q_m · k_n` 只依赖 `m−n`。本页采用此含义。
2. **工程实现变体**：GPT-NeoX/LLaMA 风格将 d 维向量拆成"前半 / 后半"做逐元素旋转，与论文原始"相邻对"形式等价。
3. **扩展方法**：YaRN、Position Interpolation、LongRoPE 等在原始 RoPE 之上调整角度缩放以延长上下文。

本页讲原始 RoPE（含义 1），实现等价性只在 d 维推广章节点出（含义 2），扩展方法（含义 3）放"相邻概念"边界，不在本页展开。

## 2.1 概念含义

- **名称**：旋转位置编码（Rotary Position Embedding）
- **英文 / 缩写**：Rotary Position Embedding，RoPE
- **一句话定义**：RoPE 是一种按 token 绝对位置旋转 query/key 向量的位置编码，使注意力内积自然只依赖两个 token 的相对位置。
- **正式定义**（与权威来源一致）：对位置 `m` 的 query 向量 `q` 与位置 `n` 的 key 向量 `k`，分别左乘旋转矩阵 `R_m`、`R_n`，使 `(R_m q) · (R_n k) = q · R_{n−m} k`，其中 `R_m` 是分块对角的二维旋转矩阵堆叠，每块按位置 `m` 旋转角度 `m θ_i`（Su et al. 2021, Eq.5–12）。
- **本文采用的语境**：标准 softmax 注意力下的位置编码方案；输入向量维度 `d` 默认为偶数。

### 包括什么

- **2 维 RoPE**：在单个 (q₀, q₁) 对上的旋转，是机制的最小可手算单元。
- **d 维 RoPE**：将 d 维向量拆为 d/2 个 2 维对，每对独立旋转。
- **频率 θ_i 选择**：`θ_i = base^{-2i/d}`，`base = 10000`。
- **相对位置保持性质**：`R_m^T R_n = R_{n−m}`，内积只依赖 `m−n`。
- **远程衰减性质**：随 |m−n| 增大，期望内积衰减。
- **应用位置**：仅作用于 Q、K，不作用于 V；发生在每个注意力层内部、softmax 之前。
- **使用范围事实**：LLaMA / Mistral / Qwen / Falcon / PaLM / Gemma / GPT-NeoX 等主流开源 LLM 采用。

### 不包括什么

- **YaRN / Position Interpolation / LongRoPE 等长度扩展方法**：是 RoPE 之上的独立工作，本页只在边界章节点出存在与原理方向，不展开推导。
- **ALiBi、T5 相对偏置、绝对位置编码（含 learned/sinusoidal）的完整对比**：这些是相邻概念，本页只在动机章用对照表说明"位置注入方式"的差异。
- **KV cache 实现细节**：旋转可预算并 cache，但 cache 实现属于工程话题，不影响 RoPE 机制理解。
- **旋转矩阵稀疏性与硬件优化**：实际实现用逐元素乘法代替稀疏矩阵乘法，只在 d 维推广章节一句话提及，不展开。
- **训练动力学 / 学到的东西**：经验分析不属本概念范围。

### 相邻概念

- **绝对位置编码（APE）**：把位置向量加到 token 嵌入上。区别：APE 改变输入嵌入，RoPE 在注意力内旋转 Q/K。不纳入本页范围。
- **相对位置编码（T5 相对偏置、ALiBi）**：在注意力分数上加一个与相对距离绑定的偏置。区别：相对 PE 是"加偏置"，RoPE 是"乘旋转"。不纳入本页范围。
- **NoPE**：完全不施加位置编码，依赖因果掩码。区别：NoPE 是"什么都不做"的选项。已有概念页 [`NoPE`](../nope/index.html)，本页在边界章节引用。
- **长度外推扩展（YaRN 等）**：在 RoPE 之上调整频率。不纳入本页范围。

## 2.2 学习目标

### Q1：RoPE 在做什么，与绝对/相对位置编码的本质区别是什么？

- **完成答案**：读者应能说明 RoPE 是在注意力层内部对 Q 和 K 施加位置相关的旋转，使两点之间的内积只依赖相对位置 `m−n`；区别于 APE（加在嵌入上）和相对 PE（在分数上加偏置），RoPE 不引入额外参数、不改 V、不改输入嵌入，是"乘"而非"加"。
- **为什么是核心目标**：不理解 RoPE 的"做什么"与"和已有方案的区别"就无法判断它适用于哪种场景、为什么被广泛采用。
- **依赖内容**：位置编码动机、自注意力排列等变、APE/相对 PE 对照。

### Q2：给定 2 维 q、k 和位置 m、n，手算 RoPE 后内积为何只依赖 m−n？

- **完成答案**：读者应能写出 2 维旋转矩阵 `R_m`，对 q=(q₀,q₁) 在位置 m、k=(k₀,k₁) 在位置 n 执行旋转，展开 `(R_m q)·(R_n k)` 得到只含 `cos((n−m)θ)` 与 `sin((n−m)θ)` 的表达式，并代入具体数字验证。
- **为什么是核心目标**：这是 RoPE 数学核心，是 d 维推广和远程衰减的基石；不能手算 2 维就无法判断 d 维结论是否正确。
- **依赖内容**：2 维旋转矩阵、复数与旋转的等价（可选）、三角恒等式。

### Q3：d 维 RoPE 如何从 2 维推广，θ_i 的几何级数起什么作用？

- **完成答案**：读者应能说明 d 维 RoPE 把向量拆为 d/2 个 2 维对，每对独立旋转；分块对角矩阵 `R_m^d` 由 d/2 个 2×2 块构成；每块的频率 `θ_i = base^{-2i/d}` 形成几何级数，i 小则 θ 大（旋转快、捕获短程），i 大则 θ 小（旋转慢、捕获长程）。
- **为什么是核心目标**：实际模型 d=64/128，2 维只是教学最小单元；不理解 d 维推广无法解释 RoPE 在真实模型中如何同时编码多尺度位置信息。
- **依赖内容**：2 维 RoPE、分块对角矩阵、几何级数。

### Q4：远程衰减性质是怎么来的，它和"只在 QK 不在 V"的关系是什么？

- **完成答案**：读者应能说明在 q、k 分量独立同分布假设下，`q^T R_{n−m}^d k` 的期望为 `Σ cos((n−m)θ_i)`，由 Riemann-Lebesgue 引理当 |m−n| 大时趋于 0；并说明 RoPE 只作用在 Q、K（注意力分数只来自 QK^T），V 不被旋转因为 V 决定"取什么信息"而非"看哪里"。
- **为什么是核心目标**：远程衰减解释了 RoPE 经验上对长程依赖的隐式 locality bias；只在 QK 不在 V 是常见疑问且影响理解。
- **依赖内容**：d 维 RoPE、期望与求和的可交换、Riemann-Lebesgue 引理（仅作陈述）。

### Q5：RoPE 的适用边界在哪里，长度外推时为什么需要 YaRN/PI 等扩展？

- **完成答案**：读者应能说明 RoPE 适用条件是 softmax 注意力、Q/K 维度偶数；超出训练长度时高频分量 `mθ_i` 进入未训练的角度区间，简单外推性能下降，需要 Position Interpolation（缩放 m）或 YaRN（按频率分组缩放）等扩展；并说明 K3 MLA 层虽拆出 rot 分量但不施加旋转（NoPE）的设计选择与 RoPE 边界的关系。
- **为什么是核心目标**：不理解 RoPE 的边界会把"加 RoPE"当成银弹，也无法解释为何主流长上下文模型需要扩展方法。
- **依赖内容**：θ_i 频率选择、训练分布外的角度未学、YaRN/PI 存在性。

## 2.6 常见误解和适用边界

### 常见误解

| 误解 | 正确结论 | 形成原因 | 影响目标 |
|---|---|---|---|
| "RoPE 是给 V 也加旋转" | RoPE 只旋转 Q 和 K，V 保持不变。注意力分数只来自 `QK^T`，V 决定"取什么"而非"看哪里"，旋转 V 不改变注意力分布。 | 实现里 Q/K/V 一起出现，读者推断"三个一起旋转"。 | Q4 |
| "RoPE 是相对位置编码" | RoPE 用绝对位置 `m`、`n` 构造旋转，但产生的内积只依赖相对位置 `m−n`。叫"绝对构造、相对效果"更准确。论文摘要原文："encodes the absolute position with a rotation matrix and meanwhile incorporates the explicit relative position dependency"。 | 名字带"相对"的直觉。 | Q1 |
| "RoPE 引入了额外参数" | RoPE 没有任何可学习参数。`θ_i` 与 `base=10000` 是固定常数，旋转矩阵预算即用。 | 与 learned APE 混淆。 | Q1 |
| "2 维旋转后内积只是 `cos((m−n)θ)`" | 完整内积是 `(q₀k₀+q₁k₁)cos((n−m)θ) + (q₀k₁−q₁k₀)sin((n−m)θ)`。`cos` 项只是当 q=k 时的特例。 | 简化记号被当成全部。 | Q2 |
| "RoPE 可任意外推到更长序列" | 训练长度外，`mθ_i` 超出训练见过的角度范围，简单外推性能下降；YaRN/PI 等扩展方法专门处理此事。 | 论文摘要提到"flexibility of sequence length"，被扩大为"无限外推"。 | Q5 |
| "K3 的 MLA 用了 RoPE" | K3 的 MLA 层虽在结构上保留了 rot 分量的接口，但 `mla_use_nope=true`，实际不施加旋转。 | DeepSeek-V2 原始 MLA 用解耦 RoPE，读者假设 K3 也用。 | Q5 |

### 适用边界

- **适用条件**：softmax 注意力、Q/K 维度偶数、token 位置可用整数 `m` 表示。
- **不解决**：不解决"位置编号本身的语义"（如分段文档、相对时间）；不替代 token 类型嵌入（如 segment embedding）。
- **长度外推边界**：`m θ_i` 在训练长度内取值有限；超出时高频分量进入未学区间，需要 YaRN/PI 等扩展。
- **与矩阵吸收的冲突**：MLA 等架构中若对压缩潜变量施加 RoPE 会破坏矩阵吸收的前提（[`MLA`](../mla/index.html) S3 已论证）；K3 通过 NoPE 化解此冲突。
- **不适用场景**：纯双向编码器中若需要显式绝对位置信号，APE 或可学习位置嵌入可能更直接；RoPE 的优势在自回归与长上下文外推。
