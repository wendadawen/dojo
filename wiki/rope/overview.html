RoPE 旋转位置编码

按 token 绝对位置旋转 query 和 key 向量，使注意力内积自然只依赖两个 token 的相对位置，且不引入任何可学习参数。

更新于 2026-08-09

这个概念是什么

RoPE（Rotary Position Embedding，旋转位置编码）是 Su et al. 2021 在 RoFormer 论文（arXiv:2104.09864）中提出的位置编码方案。它在每个注意力层内部、softmax 之前，对 query 和 key 向量施加位置相关的旋转矩阵 $R_m$——位置 $m$ 的旋转角度是 $m\theta_i$，每个 2 维对用各自的频率 $\theta_i$。结果：两个 token 之间的注意力内积只依赖相对位置 $m-n$，不依赖各自的绝对位置。详细机制见 深度教学。

为什么需要它

  • 注意力本身没有位置感知。自注意力只看内容匹配，不关心 token 在第几位；不加位置信息时"甲在前、乙在后"和"乙在前、甲在后"产生同样的输出（排列等变，详见 NoPE）。
  • 已有的两类做法各有代价。绝对位置编码（APE）超出训练长度即失败；相对位置编码中 T5 需要额外的偏置参数（bucket 表），ALiBi 无需参数、外推性好于 learned APE 但仍有限。需要一种既无额外参数、又能让注意力自然编码相对位置的方案。
  • 长度外推需求。自回归 LLM 在推理时可能遇到比训练时更长的上下文；RoPE 的旋转结构让位置可以连续延伸，配合扩展方法（PI、YaRN、LongRoPE 等）支持 128K 到百万级上下文。

核心直觉

  • 绝对构造、相对效果。RoPE 用绝对位置 $m$ 构造旋转矩阵 $R_m$，但数学上 $(R_m q)\cdot(R_n k) = q \cdot R_{n-m} k$——绝对位置在内积中抵消，只剩相对位置 $m-n$。叫"绝对构造、相对效果"比叫"相对位置编码"更准确。
  • 每个 2 维对是一只指针。d 维向量被拆成 $d/2$ 个 2 维对，每对独立旋转；$i$ 小的对转得快（捕获短程），$i$ 大的对转得慢（捕获长程）。$\theta_i = 10000^{-2i/d}$ 形成的几何级数让 RoPE 同时编码多尺度位置信息。
  • 只在 Q 和 K 上旋转。注意力分数只来自 $QK^T$，V 决定"取什么"而非"看哪里"——所以 RoPE 不动 V。
  • 远程衰减是相位抵消性质。$|m-n|$ 大时各频率分量相位散乱、$\cos$ 平均后抵消，归一化内积趋于 0；这给 RoPE 隐式的 locality bias。但这是特定情形的确定性计算与定性趋势，不是每个具体 token 对的逐点保证。

关键结论与边界

  • RoPE 没有可学习参数。$\theta_i$ 与 $\mathrm{base}=10000$ 都是固定常数，旋转矩阵可预先计算、直接使用。这是它与 learned APE 的本质区别。成立条件：原始 RoPE 定义；扩展方法（如 YaRN）可能引入可学习缩放。
  • 简单外推会失效，需要扩展方法。超出训练长度时 $m\theta_i$ 进入未学角度区间；Position Interpolation 缩放 $m$、YaRN 按频率分组缩放，是常见扩展。RoPE 不是"无限外推"，而是"结构上可扩展"。
  • RoPE 与 MLA 矩阵吸收冲突。MLA 推理优化依赖 $W^{UK}$ 与位置无关；对压缩潜变量施加 RoPE 会破坏这一前提。DeepSeek-V2 用解耦 RoPE 化解（详见 MLA 的"为什么 RoPE 要解耦"一章），Kimi K3 直接用 NoPE 关闭位置编码（详见 Kimi K3 的"K3 的 Gated MLA"与"长上下文扩展"一章）。
  • 主流开源 LLM 的事实标准。LLaMA（所有版本）、Mistral、Falcon、Qwen、PaLM、Gemma、GPT-NeoX 等采用 RoPE。但不是银弹：纯双向编码器若需显式绝对位置信号，APE 可能更直接。
