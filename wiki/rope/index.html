    RoPE 旋转位置编码：用旋转矩阵让注意力内积只依赖相对位置

    主要依据：Su, Lu, Pan, Murtadha, Wen, Liu. "RoFormer: Enhanced Transformer with Rotary Position Embedding." arXiv:2104.09864v5, 2023（首版 2021）。论文公式编号：Eq.(1)–(10) 在 §2 背景与相关工作；Eq.(11) 相对位置编码目标，Eq.(12)–(13) 2 维复数解与旋转矩阵，Eq.(14)–(16) d 维形式与块对角矩阵；Eq.(20)–(33) §3.4.1 的 2 维严格推导，Eq.(34) §3.4.2 高效实现，Eq.(35)–(37) §3.4.3 远程衰减。

    给一个 Transformer 喂三个内容完全相同的 token "the the the"，每个位置的输出会一样吗？答案是：在没有任何位置信息时，三个位置的输出完全一样——注意力只看内容匹配，不看顺序。要让模型分清"第一个 the"和"第三个 the"，必须把位置信息注入到注意力里。RoPE（Rotary Position Embedding，旋转位置编码）的做法是：按 token 的绝对位置旋转它的 query 和 key 向量，使两个 token 之间的注意力内积自然只依赖它们的相对位置 $m-n$，且不引入任何可学习参数。RoPE 是当前自回归 LLM 的默认位置编码，被 LLaMA、Mistral、Qwen、Falcon、PaLM、Gemma、GPT-NeoX 等采用[C6]。本文回答：RoPE 的旋转矩阵长什么样？为什么内积只依赖 $m-n$？远程衰减从何而来？为什么只动 Q/K 不动 V？长度外推为何需要扩展方法？

    核心问题

    1. RoPE 在做什么？它与绝对位置编码、相对位置编码、NoPE 的本质区别是什么。

      解答：RoPE 用旋转承载位置，且是乘不是加

      RoPE 把 token 的绝对位置 $m$ 编码成一个旋转矩阵 $R_m$，左乘到该位置的 query 和 key 上，使注意力分数自动只依赖两个 token 的位置差。

      本质区别在于位置信息的注入方式与注入位置：

      • 绝对位置编码把位置向量加在第一层之前的 token 嵌入上，learned 版本有可学习参数、超出表长即失效。
      • 相对位置编码（T5 相对偏置、ALiBi）把距离相关的偏置加在 softmax 之前的注意力分数上，T5 有约 32 个 bucket 每头的参数，ALiBi 无参数。
      • RoPE 是乘：在每个注意力层内、softmax 之前旋转 Q 和 K，不修改 V、不修改输入嵌入，且没有可学习参数（$\theta_i$ 与 base 都是固定常数）。
      • NoPE 不注入任何位置信息，依赖因果掩码隐式提供位置区分。

      常被称作"相对位置编码"容易引起误解。准确表述是"绝对构造、相对效果"：构造阶段用绝对位置 $m$、$n$ 各自算旋转，效果阶段绝对位置在内积中抵消、只留下 $n-m$。完整论证见「为什么 Transformer 需要位置编码」与「内积为何只依赖 m−n」两章。

    2. 给定 2 维 q、k 与位置 m、n，如何手算旋转后的内积？为什么结果只依赖 $m-n$。

      解答：代入 F2 公式，并由 $R_m^T R_n=R_{n-m}$ 保证

      手算用 F2 公式，只需两个系数与一个相对角：

      $$\langle R_m q, R_n k \rangle = (q_0 k_0 + q_1 k_1)\cos((n-m)\theta) - (q_0 k_1 - q_1 k_0)\sin((n-m)\theta).$$

      以 $q=k=(1,0)$、$\theta=\pi/4$、$m=1$、$n=2$ 为例：对称项 $1\cdot1+0\cdot0=1$，反对称项 $1\cdot0-0\cdot1=0$，相对角 $(n-m)\theta=\pi/4$，因此内积为 $1\cdot\cos(\pi/4)-0=\sqrt{2}/2\approx0.7071$。把位置换成 $m=5$、$n=6$（位置差不变）结果仍是 $0.7071$。

      只依赖 $m-n$ 的原因是旋转矩阵构成群：$R_m^T=R_m^{-1}=R_{-m}$，于是 $R_m^T R_n=R_{n-m}$，代入 $\langle R_m q, R_n k\rangle=q^T R_m^T R_n k=q^T R_{n-m} k$，绝对位置完全抵消。

      需要注意 $\sin$ 项不总为零：它的系数是 $q$ 与 $k$ 的二维叉积，只有 $q$ 与 $k$ 共线（含 $q=k$）时才消失。完整推导与更多手算例子见「2 维 RoPE 是怎么旋转的」与「内积为何只依赖 m−n」两章。

    3. d 维 RoPE 如何从 2 维推广？$\theta_i$ 的几何级数起什么作用。

      解答：分块对角旋转 + 频率跨数量级

      推广方式是把 $d$ 维向量拆成 $d/2$ 个坐标对 $(q_0,q_1),(q_2,q_3),\dots$，第 $i$ 对用自己的频率 $\theta_i$ 独立旋转，整体旋转矩阵为分块对角：

      $$R_m^d = \mathrm{diag}\big(R_m^{(0)}, R_m^{(1)}, \ldots, R_m^{(d/2-1)}\big).$$

      每个 $2\times2$ 块都满足 $R_m^T R_n=R_{n-m}$，块外元素为零、各块互不干扰，所以 d 维内积等于 $d/2$ 个二维内积之和，相对位置保持性质在 d 维依然成立。

      频率取 $\theta_i=\mathrm{base}^{-2i/d}$，构成几何级数，作用是让不同坐标对负责不同尺度的位置分辨：以 $d=128$、$\mathrm{base}=10000$ 为例，$i=0$ 时 $\theta_0=1$，约 6.3 个位置就转满一圈，能分辨邻近 token 的细微位置差；$i=63$ 时 $\theta_{63}\approx1.15\times10^{-4}$，需约 54410 个位置才转一圈，在极大跨度上仍保留可区分的相位差。高频负责短程、低频负责长程，多尺度覆盖由此而来。详见「d 维推广」一章。

    4. 远程衰减性质从何而来？为什么 RoPE 只旋转 Q 和 K 而不动 V。

      解答：相位抵消带来衰减；分数只来自 $QK^T$

      远程衰减来自确定性求和的相位抵消，不需要概率假设。d 维内积是 $d/2$ 个 $\cos((n-m)\theta_i)$ 的加权和，而 $\theta_i$ 跨越多个数量级；$|m-n|$ 增大时各项相位分散到不同象限、正负贡献互相抵消，归一化和的幅度总体趋小。以 $q=k$ 且每对分量恒定的构造情形（$d=128$、$\mathrm{base}=10000$）实测：$|m-n|=1$ 时归一化和 $0.9702$，$=10$ 时 $0.6691$，$=1000$ 时 $0.1590$，$=5000$ 时 $-0.0070$。

      两点需要注意：一是"衰减"指幅度趋小而非严格单调递减，本质是几乎周期的振荡，因此远处出现负值不构成矛盾；二是该曲线来自上述构造情形，论文 §3.4.3 用 Abel 变换给出的是求和上界，真实模型中具体 token 对可能偏离曲线，成立的是定性趋势。

      不动 V 的原因是注意力分数只由 $QK^T$ 决定：旋转 Q 和 K 已经让"看哪里"带上位置感知，而 V 决定"取到之后拿什么内容"，旋转 V 不改变 softmax 的输入，不属于位置编码要解决的问题。详见「远程衰减」一章。

    5. RoPE 的适用边界是什么？长度外推为何需要 PI/YaRN，Kimi K3 的 MLA 层为何不施加旋转。

      解答：三条适用条件、外推越界、与矩阵吸收冲突

      适用条件有三条：使用 softmax 注意力（分数来自 $QK^T$）；query/key 维度 $d$ 为偶数（可拆成 $d/2$ 个二维对）；token 位置可用整数 $m$ 表示。RoPE 不替代 token 类型嵌入，也不提供绝对位置查询能力；纯双向编码器若需要显式绝对位置信号，APE 更直接。

      长度外推需要扩展方法，因为训练时 $m$ 只在 $[0, L_{\text{train}})$ 取值，模型只见过 $m\theta_i$ 落在 $[0, L_{\text{train}}\cdot\theta_i)$ 的角度组合；超出训练长度后角度进入训练分布外区间，$i$ 小的高频分量最先越界。PI 把位置整体缩放回训练范围（$m'=m\cdot L_{\text{train}}/L_{\text{target}}$）；YaRN 按频率分组施加不同缩放，高频基本保持以保留局部分辨力、低频缩放以覆盖更长距离；LongRoPE 按维度非均匀搜索缩放因子。"RoPE 可任意外推"是常见误解，论文所说的长度灵活性指结构上可扩展，不代表简单外推效果不变。

      K3 的 MLA 层不施加旋转，是因为 RoPE 与矩阵吸收冲突：吸收要求 $W^{UK}$ 与位置无关，而施加 RoPE 后注意力项变成 $\tilde q^T(R_n W^{UK} c^{KV})$，位置相关且逐 token 不同的 $R_n$ 夹在中间，无法合并为固定矩阵。DeepSeek-V2 的应对是解耦 RoPE、用额外一组共享 key 承载位置；Kimi K3 的 Gated MLA 在结构上保留 rot 分量接口，但 mla_use_nope=true，位置信息交由 KDA 通过递归门控与衰减隐式提供，因此扩展上下文时无需调整位置编码参数。详见「适用边界」一章。

    先看一个贯穿全文的问题：把同一组 2 维 query 和 key 放在不同位置 $m$、$n$ 上，旋转后它们的内积会是什么样？这个问题会在 2 维 RoPE 一章手算回答，并在内积证明一章验证它只依赖 $m-n$。

    为什么 Transformer 需要位置编码——RoPE 与四类方案的差异

    标准自注意力做的事情是"用 query 和 key 做匹配，按匹配程度对 value 加权求和"。它只关心两个 token 的内容像不像，不关心它们各自在第几位。这引出一个问题：如果模型不知道 token 的位置，它还能区分"甲在前、乙在后"和"乙在前、甲在后"吗？

    要回答它，先看注意力本身的一个性质。如果注意力是双向的（每个位置都能看到所有位置）并且不给任何位置信息，那么交换输入顺序后，每个位置仍然看到同样的一组 token、按同样的内容匹配得到同样的权重——只是输出跟着挪了位置，而每个位置上的输出值不变。这种现象叫排列等变：模型对"谁先谁后"没有真正的区分能力。排列等变的更完整讨论见 NoPE 页面，本文只用这个结论。

    正因如此，主流做法是主动注入位置信息——这就是位置编码。常见的显式位置编码分四类，各自"做了什么"不同：

    方案做了什么（位置注入方式）加在哪里可学习参数长度外推
    绝对位置编码（APE）给输入嵌入加一个与绝对位置绑定的向量第一层之前的 token 嵌入有（learned）或无（sinusoidal）差（learned 超出表长即失败；sinusoidal 中等）
    相对位置编码（T5 相对偏置、ALiBi）在注意力分数上加一个与两个位置距离绑定的偏置注意力分数（softmax 之前）T5 有（~32 bucket/头）；ALiBi 无ALiBi 较好；T5 中等
    旋转位置编码（RoPE）按绝对位置 $m$ 旋转 Q 和 K（乘法）每个注意力层内、softmax 之前无需配合扩展（YaRN、PI）
    NoPE什么都不做——无decoder-only 直接外推

    前三类都在"加"位置信息，区别只是加在哪里、怎么加。RoPE 那一行的特征是：它乘而不是加——把位置 $m$ 编码成一个旋转矩阵 $R_m$，左乘到 query 和 key 上；它不修改 value，也不修改输入嵌入[C1]；它没有可学习参数，$\theta_i$ 和 base 都是固定常数[C3]。NoPE 那一行的"什么都不做"是另一条路径，依赖因果掩码隐式提供位置信息，详见 NoPE 页面。

    RoPE 经常被叫做"相对位置编码"，但这个名字容易让人误以为它直接用 $m-n$ 构造旋转。准确的说法是"绝对构造、相对效果"：构造旋转用的是绝对位置 $m$ 和 $n$，但产生的内积 $(R_m q)\cdot(R_n k)$ 只依赖 $m-n$[C2]。论文摘要原文："encodes the absolute position with a rotation matrix and meanwhile incorporates the explicit relative position dependency"——同时编码绝对位置并引入相对位置依赖。

    本章问题

    1. APE、相对 PE、RoPE、NoPE 各把位置信息加在哪里？分别是否有可学习参数。

      解答：四类方案的注入位置与参数

      APE 把位置向量加在第一层之前的 token 嵌入上；learned 版本有可学习参数，sinusoidal 版本没有。相对位置编码（T5 相对偏置、ALiBi）把距离相关的偏置加在 softmax 之前的注意力分数上；T5 有约 32 个 bucket 每头的可学习参数，ALiBi 没有。RoPE 在每个注意力层内、softmax 之前把绝对位置编码成旋转矩阵左乘到 Q 和 K 上，没有可学习参数（$\theta_i$ 与 base 都是固定常数）。NoPE 不注入任何位置信息，也没有参数，依赖因果掩码隐式提供位置区分。

    2. RoPE 论文摘要里“absolute position”与“relative position dependency”同时出现，这两件事是怎么统一的。

      解答：绝对构造与相对效果的统一

      两者描述的是同一机制的不同层面：构造阶段用的是绝对位置，位置 $m$ 决定旋转矩阵 $R_m$、位置 $n$ 决定 $R_n$，二者独立计算；效果阶段体现为相对位置，因为内积 $\langle R_m q, R_n k\rangle = q^T R_m^T R_n k = q^T R_{n-m} k$ 中绝对位置相互抵消，只留下 $n-m$。因此准确说法是“绝对构造、相对效果”，RoPE 并不直接用 $m-n$ 去构造旋转。

    3. RoPE 修改了 value 吗？修改了输入嵌入吗。

      解答：RoPE 的作用范围

      都没有。RoPE 只把旋转矩阵左乘到 Q 和 K 上，不修改 V，也不修改输入嵌入。原因是注意力分数只来自 $QK^T$：旋转 Q 和 K 就足以让“看哪里”带上位置感知，而 V 决定“取什么信息”，旋转 V 不改变 softmax 的输入，不属于位置编码要解决的问题。

    本章把 RoPE 的"做什么"与已有方案的差异说清了：相对位置是效果不是构造，参数为零，作用点在每个注意力层内。但旋转矩阵长什么样、内积为何只剩 $m-n$ 尚未回答——下一章用最小 2 维例子讲旋转矩阵的形式。

    2 维 RoPE 是怎么旋转的——最小可手算机制

    先把问题缩到最小：假设 query 和 key 都只有 2 维，记 $q=(q_0, q_1)$、$k=(k_0, k_1)$；位置分别是 $m$ 和 $n$；这两个维度共用一个频率 $\theta$（表示每位置旋转多少弧度）。RoPE 要做的事是：在 $q$ 和 $k$ 上分别施加一个位置相关的旋转矩阵。

    位置 $m$ 的旋转矩阵定义为

    $$R_m = \begin{pmatrix} \cos m\theta & -\sin m\theta \\ \sin m\theta & \cos m\theta \end{pmatrix}$$

    这是标准的 2 维旋转矩阵，角度为 $m\theta$[F1]。位置 $n$ 的旋转矩阵 $R_n$ 把 $m$ 换成 $n$ 即可。RoPE 对 $q$ 和 $k$ 的变换是

    $$\tilde{q}_m = R_m q, \qquad \tilde{k}_n = R_n k.$$

    逐元素写开，旋转后的 $q$ 是

    $$\tilde{q}_m = \begin{pmatrix} q_0 \cos m\theta - q_1 \sin m\theta \\ q_0 \sin m\theta + q_1 \cos m\theta \end{pmatrix}.$$

    关键问题：旋转后的内积 $\tilde{q}_m \cdot \tilde{k}_n$ 长什么样？把两个 2 维向量的内积展开（直接套用上面的逐元素公式，再用 $\cos(a-b)=\cos a\cos b + \sin a\sin b$ 与 $\sin(a-b)=\sin a\cos b - \cos a\sin b$），结果是

    $$\langle R_m q, R_n k \rangle = (q_0 k_0 + q_1 k_1)\cos((n-m)\theta) - (q_0 k_1 - q_1 k_0)\sin((n-m)\theta).$$

    这个结果只含 $(n-m)\theta$，不含单独的 $m\theta$ 或 $n\theta$——这就是 RoPE 的核心性质在 2 维情况下的体现[F2]。但要强调一点：内积不是只有 $\cos$ 项。当 $q=k$ 时 $q_0 k_1 - q_1 k_0 = 0$，$\sin$ 项消失，只剩 $\cos$；但一般情况下两项都在。论文给出的完整公式是上面这个形式（Eq.(4)）。

    上面这个例子是教学示例，便于手算验证。它的输入是 $q=(1,0)$、$k=(1,0)$、$\theta=\pi/4$、$m=1$、$n=2$。$\theta=\pi/4$ 是教学数字，不是真实模型的频率——真实模型 d=64/128 且 base=10000，下一章会看到具体数值。

    展开：2 维手算例子的完整代入过程

    已知 $q=(1,0)$、$k=(1,0)$、$\theta=\pi/4$、$m=1$、$n=2$。

    第一步，旋转 $q$：位置 $m=1$，角度 $m\theta=\pi/4$，

    $$\tilde{q}_m = (\cos(\pi/4)\cdot 1 - \sin(\pi/4)\cdot 0,\ \sin(\pi/4)\cdot 1 + \cos(\pi/4)\cdot 0) = (\sqrt{2}/2,\ \sqrt{2}/2) \approx (0.7071,\ 0.7071).$$

    第二步，旋转 $k$：位置 $n=2$，角度 $n\theta=\pi/2$，

    $$\tilde{k}_n = (\cos(\pi/2)\cdot 1 - \sin(\pi/2)\cdot 0,\ \sin(\pi/2)\cdot 1 + \cos(\pi/2)\cdot 0) = (0,\ 1).$$

    第三步，内积：

    $$\tilde{q}_m \cdot \tilde{k}_n = (\sqrt{2}/2)\cdot 0 + (\sqrt{2}/2)\cdot 1 = \sqrt{2}/2 \approx 0.7071.$$

    第四步，用内积公式验证：$q_0 k_0 + q_1 k_1 = 1\cdot 1 + 0\cdot 0 = 1$，$q_0 k_1 - q_1 k_0 = 1\cdot 0 - 0\cdot 1 = 0$，$(n-m)\theta = (2-1)\pi/4 = \pi/4$，

    $$\langle R_m q, R_n k \rangle = 1\cdot \cos(\pi/4) - 0\cdot \sin(\pi/4) = \sqrt{2}/2 \approx 0.7071.$$

    两种方法结果一致——这是 F2 公式正确性的证据。$\sin$ 项系数为零是因为 $q=k$，不是公式退化的结果。

    常见误解：把"2 维旋转后内积"简化成 $\cos((m-n)\theta)$。这只在 $q=k$ 的特殊情况下成立（这时 $q_0 k_1 - q_1 k_0 = 0$，$\sin$ 项系数为零）。一般情况下内积还有 $\sin$ 项，正确形式是 $(q_0 k_0 + q_1 k_1)\cos((n-m)\theta) - (q_0 k_1 - q_1 k_0)\sin((n-m)\theta)$。"$\cos$ 形式"是 $q=k$ 的特例。

    本章问题

    1. 写出 $m=0$ 时的 $R_m$，说明为什么位置 0 的旋转矩阵是单位矩阵。

      解答：$R_0$ 为单位矩阵

      代入 $m=0$ 得 $0\cdot\theta=0$，而 $\cos 0=1$、$\sin 0=0$，因此

      $$R_0=\begin{pmatrix}1 & 0\\ 0 & 1\end{pmatrix}.$$

      几何含义是旋转角为零，向量保持原样。这与 RoPE 的定义一致：位置 0 是旋转的起点，不施加任何偏转，位置信息完全由后续位置相对它的旋转量体现。

    2. 给定 $q=(1,1)$、$k=(0,1)$、$\theta=\pi/6$、$m=0$、$n=1$，手算内积（提示：用 F2 公式）。

      解答：内积等于 $\sqrt{3}/2-1/2\approx0.3660$

      先算两个系数：对称项 $q_0k_0+q_1k_1=1\cdot0+1\cdot1=1$，反对称项 $q_0k_1-q_1k_0=1\cdot1-1\cdot0=1$。相对角 $(n-m)\theta=\pi/6$，其中 $\cos(\pi/6)=\sqrt{3}/2\approx0.8660$、$\sin(\pi/6)=1/2$。代入 F2：

      $$\langle R_0 q, R_1 k\rangle = 1\cdot\frac{\sqrt{3}}{2} - 1\cdot\frac{1}{2} = \frac{\sqrt{3}-1}{2} \approx 0.3660.$$

      直接旋转可以验证：$m=0$ 时 $\tilde q=(1,1)$ 不变；$k$ 旋转 $\pi/6$ 得 $(-1/2,\ \sqrt{3}/2)\approx(-0.5000,\ 0.8660)$，内积为 $1\cdot(-0.5)+1\cdot0.8660=0.3660$，两种算法一致。此例中 $q\neq k$，反对称项不为零，因此 $\sin$ 项必须计入。

    3. F2 内积公式里 $\sin$ 项什么时候为零？这对应什么几何条件。

      解答：反对称项为零的条件

      $\sin$ 项的系数是 $q_0k_1-q_1k_0$，它为零当且仅当 $q_0k_1=q_1k_0$，即 $q$ 与 $k$ 共线（含 $q=k$、$q=ck$ 以及任一为零向量的情形）。几何上这个量是 $q$ 与 $k$ 张成的平行四边形的有向面积（二维叉积），共线时面积为零。此时内积退化为 $(q_0k_0+q_1k_1)\cos((n-m)\theta)$，也就是常见的“只剩 $\cos$”形式；一般情况下两项都存在。

    本章给出了 2 维旋转矩阵和内积公式，并用 $q=(1,0)$ 验证了内积只含 $(n-m)\theta$。但旋转矩阵用了绝对位置 $m$、$n$，内积为何只剩 $m-n$——下一章用三角恒等式证明这是旋转矩阵群的性质。

    内积为何只依赖 m−n——旋转矩阵群的性质

    上一章用具体数字看到内积只剩 $(n-m)\theta$，但没证明为什么。这一章用代数证明：对任意 2 维 $q$、$k$，$(R_m q)\cdot(R_n k) = q \cdot R_{n-m} k$——绝对位置 $m$、$n$ 在内积中完全抵消。

    关键观察：内积 $(R_m q)\cdot(R_n k) = q^T R_m^T R_n k$。要证的就是

    $$R_m^T R_n = R_{n-m}.$$

    这是旋转矩阵群的性质：两个旋转矩阵的乘积还是旋转矩阵，且角度是两个角度之差。下面用三角恒等式直接验证。

    补充：R_m^T R_n = R_{n-m} 的三角恒等式推导

    把 $R_m$、$R_n$ 写出来并计算 $R_m^T R_n$。注意 $R_m^T$ 是把 $R_m$ 的非对角元符号翻转（$\sin$ 项变 $-\sin$）：

    $$R_m^T = \begin{pmatrix} \cos m\theta & \sin m\theta \\ -\sin m\theta & \cos m\theta \end{pmatrix}, \qquad R_n = \begin{pmatrix} \cos n\theta & -\sin n\theta \\ \sin n\theta & \cos n\theta \end{pmatrix}.$$

    矩阵乘法：

    $$R_m^T R_n = \begin{pmatrix} \cos m\theta \cos n\theta + \sin m\theta \sin n\theta & -\cos m\theta \sin n\theta + \sin m\theta \cos n\theta \\ -\sin m\theta \cos n\theta + \cos m\theta \sin n\theta & \sin m\theta \sin n\theta + \cos m\theta \cos n\theta \end{pmatrix}.$$

    用三角恒等式 $\cos(a-b) = \cos a \cos b + \sin a \sin b$ 与 $\sin(a-b) = \sin a \cos b - \cos a \sin b$：

    $$R_m^T R_n = \begin{pmatrix} \cos((n-m)\theta) & -\sin((n-m)\theta) \\ \sin((n-m)\theta) & \cos((n-m)\theta) \end{pmatrix} = R_{n-m}.$$

    证毕。$R_m^T R_n = R_{n-m}$ 只依赖角度差 $n-m$，与单独的 $m$ 或 $n$ 无关。

    有了 $R_m^T R_n = R_{n-m}$[F3]，内积的相对位置保持直接得出：

    $$\langle R_m q, R_n k \rangle = q^T R_m^T R_n k = q^T R_{n-m} k.$$

    右侧只含 $R_{n-m}$，绝对位置 $m$、$n$ 完全抵消。这就是上一章手算例子中"$(n-m)\theta = \pi/4$ 出现、单独的 $m=1$ 或 $n=2$ 不出现"的代数来源。

    再用上一章的手算例子做一次验证：上一章里 $m=1$、$n=2$、$q=k=(1,0)$、$\theta=\pi/4$，内积是 $\sqrt{2}/2$。如果把 $m$ 改成 5、$n$ 改成 6（保持 $m-n=1$），手算结果应当一致。代入 F2：$(q_0 k_0 + q_1 k_1)\cos((6-5)\pi/4) - (q_0 k_1 - q_1 k_0)\sin((6-5)\pi/4) = 1\cdot\cos(\pi/4) - 0\cdot\sin(\pi/4) = \sqrt{2}/2$。结果确实一致——这是 $R_m^T R_n = R_{n-m}$ 在具体数字上的验证。

    注意 $R_{n-m}$ 与 $R_{m-n}$ 的区别：$R_{n-m}$ 角度是 $(n-m)\theta$，$R_{m-n}$ 角度是 $(m-n)\theta = -(n-m)\theta$。由于 $R_{-t} = R_t^T$，两者方向相反但内积结果相同（内积是标量，转置不改变）。论文统一用 $R_{n-m}$，本页沿用。

    本章问题

    1. 用三角恒等式展开 $R_m^T R_n$，证明等于 $R_{n-m}$。

      解答：$R_m^T R_n = R_{n-m}$ 的推导

      转置把 $R_m$ 的 $\sin$ 项符号翻转，因此

      $$R_m^T R_n=\begin{pmatrix}\cos m\theta & \sin m\theta\\ -\sin m\theta & \cos m\theta\end{pmatrix}\begin{pmatrix}\cos n\theta & -\sin n\theta\\ \sin n\theta & \cos n\theta\end{pmatrix}.$$

      逐元素相乘后，对角元为 $\cos m\theta\cos n\theta+\sin m\theta\sin n\theta$，用 $\cos(a-b)=\cos a\cos b+\sin a\sin b$ 得 $\cos((n-m)\theta)$；右上元为 $-\cos m\theta\sin n\theta+\sin m\theta\cos n\theta$，用 $\sin(a-b)=\sin a\cos b-\cos a\sin b$ 得 $-\sin((n-m)\theta)$。整理即

      $$R_m^T R_n=\begin{pmatrix}\cos((n-m)\theta) & -\sin((n-m)\theta)\\ \sin((n-m)\theta) & \cos((n-m)\theta)\end{pmatrix}=R_{n-m}.$$

    2. 上一章手算例子中，$m=1$、$n=2$ 与 $m=5$、$n=6$（同样 $m-n=1$）的内积是否相同？为什么。

      解答：相同，因为只依赖位置差

      相同，两者都等于 $\sqrt{2}/2\approx0.7071$。因为内积化简后只含 $R_{n-m}$，而两组位置的差都是 $n-m=1$，相对角同为 $\pi/4$。代入 F2（$q=k=(1,0)$，对称项为 1、反对称项为 0）：$1\cdot\cos(\pi/4)-0\cdot\sin(\pi/4)=\sqrt{2}/2$，与 $m=1,n=2$ 的结果一致。这正是“绝对位置在内积中抵消”的具体体现。

    3. $R_m^T R_n = R_{n-m}$ 是巧合还是必然？依赖哪个数学性质。

      解答：旋转矩阵群的性质

      是必然。二维旋转矩阵构成一个群（$SO(2)$）：乘积仍是旋转矩阵，且角度相加；转置等于逆，即 $R_m^T=R_m^{-1}=R_{-m}$。于是 $R_m^T R_n = R_{-m}R_n = R_{n-m}$，角度相减是群运算的直接结果，不依赖 $\theta$、$m$、$n$ 的具体取值。换成一般可逆矩阵则不成立——RoPE 选择旋转矩阵正是为了获得这个性质。

    本章证明了 2 维相对位置保持是旋转矩阵群的性质。但真实模型 $d$ 是 64 或 128 而非 2——下一章讲 d 维推广与 $\theta_i$ 几何级数。

    d 维推广——分块对角旋转矩阵与 $\theta_i$ 几何级数

    2 维情况只能处理一个 2 维对。真实模型的 query/key 维度 $d$ 是偶数（如 64、128），需要把机制推广到 d 维。RoPE 的做法是：把 $d$ 维向量拆成 $d/2$ 个 2 维对，每对独立旋转，频率不同。

    具体地，把 $q=(q_0, q_1, q_2, q_3, \ldots, q_{d-2}, q_{d-1})$ 看作 $d/2$ 个 2 维对：$(q_0, q_1)$、$(q_2, q_3)$、……、$(q_{d-2}, q_{d-1})$。第 $i$ 个对（$i$ 从 0 编号到 $d/2-1$）使用频率 $\theta_i$，在位置 $m$ 旋转角度 $m\theta_i$。整个 $d$ 维旋转矩阵是分块对角的：

    $$R_m^d = \mathrm{diag}(R_m^{(0)}, R_m^{(1)}, \ldots, R_m^{(d/2-1)}), \qquad R_m^{(i)} = \begin{pmatrix} \cos m\theta_i & -\sin m\theta_i \\ \sin m\theta_i & \cos m\theta_i \end{pmatrix}.$$

    每个 $2\times2$ 块上一章证明的 $R_m^T R_n = R_{n-m}$ 都成立[F4]，所以整体上

    $$\langle R_m^d q, R_n^d k \rangle = q^T (R_m^d)^T R_n^d k = q^T R_{n-m}^d k.$$

    相对位置保持性质在 d 维情况下依然成立。d 维 RoPE 的内积就是 $d/2$ 个 2 维内积之和，每个只依赖 $(n-m)\theta_i$。

    $$R_m^{d}=\begin{pmatrix} \cos m\theta_0 & -\sin m\theta_0 & 0 & 0 & \cdots & 0 & 0\\ \sin m\theta_0 & \cos m\theta_0 & 0 & 0 & \cdots & 0 & 0\\ 0 & 0 & \cos m\theta_1 & -\sin m\theta_1 & \cdots & 0 & 0\\ 0 & 0 & \sin m\theta_1 & \cos m\theta_1 & \cdots & 0 & 0\\ \vdots & \vdots & \vdots & \vdots & \ddots & \vdots & \vdots\\ 0 & 0 & 0 & 0 & \cdots & \cos m\theta_{d/2-1} & -\sin m\theta_{d/2-1}\\ 0 & 0 & 0 & 0 & \cdots & \sin m\theta_{d/2-1} & \cos m\theta_{d/2-1} \end{pmatrix}$$

    矩阵是分块对角的：第 $i$ 个 $2\times2$ 块作用在第 $i$ 个坐标对上，块内旋转角为 $m\theta_i$，块外元素全为零。以 $d=8$ 为例，坐标对 $(q_0,q_1)$ 用 $\theta_0$，$(q_2,q_3)$ 用 $\theta_1$，$(q_4,q_5)$ 用 $\theta_2$，$(q_6,q_7)$ 用 $\theta_3$；各块互不干扰，因此整体内积等于 $d/2$ 个 2 维内积之和。

    现在看 $\theta_i$ 怎么选。论文给定的频率公式是

    $$\theta_i = \mathrm{base}^{-2i/d}, \qquad i = 0, 1, \ldots, d/2-1, \qquad \mathrm{base} = 10000.$$

    这是个几何级数[C4]：$i$ 每加 1，$\theta_i$ 乘上 $\mathrm{base}^{-2/d}$[F6]。它和 Vaswani et al. 2017 的正弦位置编码频率公式同源，不是 RoPE 新发明的。但 RoPE 把它用在旋转矩阵上，每对维度独立旋转。

    几何级数让 $\theta_i$ 跨越很大范围——$i$ 小则 $\theta_i$ 大（旋转快、捕获短程依赖），$i$ 大则 $\theta_i$ 小（旋转慢、捕获长程依赖）。下面是 $d=128$、$\mathrm{base}=10000$ 的几个典型值：

    $i$$\theta_i = 10000^{-2i/128}$$m\theta_i$ 在 $m=1$ 时旋转一圈需要的位置数（$2\pi/\theta_i$）捕获尺度
    0$1$$1$ 弧度（约 57°）约 6 个位置短程
    1$\approx 0.8660$约 0.87 弧度约 7 个位置短程
    16$= 0.1$0.1 弧度约 63 个位置中程
    63$\approx 0.0001155$约 0.0001 弧度约 54410 个位置长程

    这意味着：同一个 RoPE 同时编码了从"邻近 6 个位置就转完一圈"到"5 万 4 千个位置才转完一圈"的多尺度位置信息。这是 RoPE 能同时处理短程依赖和长程依赖的关键。$i$ 大的频率在 $m$ 不大时几乎不旋转（$m\theta_i \approx 0$，$\cos(m\theta_i) \approx 1$），相当于"看长程"的尺度；$i$ 小的频率在 $m$ 增长时快速振荡，相当于"看短程"的尺度。

    展开：d=4 多频率手算例子

    取 $d=4$、教学用 $\mathrm{base}=4$（让 $\theta_1$ 可手算；真实模型 base=10000）。

    由 $\theta_i = 4^{-2i/4} = 4^{-i/2}$：

    $$\theta_0 = 4^0 = 1, \qquad \theta_1 = 4^{-1/2} = 1/2.$$

    取 $q=(1, 0, 1, 0)$、$k=(1, 0, 1, 0)$、$m=1$、$n=2$。

    第 0 对 $(q_0, q_1)=(1,0)$、$(k_0, k_1)=(1,0)$、$\theta_0=1$：

    $(n-m)\theta_0 = 1$。F2 公式：$(1\cdot1 + 0\cdot0)\cos(1) + (1\cdot0 - 0\cdot1)\sin(1) = \cos(1) \approx 0.5403$。

    第 1 对 $(q_2, q_3)=(1,0)$、$(k_2, k_3)=(1,0)$、$\theta_1=0.5$：

    $(n-m)\theta_1 = 0.5$。F2 公式：$\cos(0.5) \approx 0.8776$。

    总内积 = $0.5403 + 0.8776 = 1.4179$。

    注意：两对的 $(n-m)$ 都是 1，但因为 $\theta_i$ 不同，旋转角度不同。$\theta_0=1$ 让第 0 对在位置 $n=2$ 已旋转到 $\cos(2)$ 约为 $-0.416$（接近"转回去"），$\theta_1=0.5$ 让第 1 对在位置 $n=2$ 只旋转到 $\cos(1)$ 约为 $0.540$（还在前半圈）。这就是"多尺度同时编码"的最小例证。

    实现层面有个等价性值得注意：原论文用"相邻对"形式 $(q_0,q_1), (q_2,q_3), \ldots$；但 GPT-NeoX、LLaMA 等实现把向量拆成"前半 $q_{0..d/2-1}$ 与后半 $q_{d/2..d-1}$"，对 $(q_i, q_{i+d/2})$ 做逐元素旋转。两种形式数学等价（只是配对方式不同），实现用前后两半是因为逐元素操作更高效。本文按论文原形式讲解。

    本章问题

    1. 给定 $d=4$、$\mathrm{base}=10000$，计算 $\theta_0$、$\theta_1$。

      解答：$\theta_0=1$，$\theta_1=0.01$

      频率公式为 $\theta_i=\mathrm{base}^{-2i/d}$，$d=4$ 时 $i$ 取 0 与 1。$\theta_0=10000^{0}=1$；$\theta_1=10000^{-2/4}=10000^{-1/2}=1/\sqrt{10000}=0.01$。两者相差 100 倍，体现了几何级数的多尺度特性：$i$ 每加 1，$\theta_i$ 乘上固定比例 $\mathrm{base}^{-2/d}$。

    2. $i$ 小与 $i$ 大的频率分别对哪种依赖负责？为什么。

      解答：高频负责短程，低频负责长程

      $i$ 小对应 $\theta_i$ 大，位置每增加 1 就旋转较大角度，转一圈只需很少的位置，因此能分辨邻近 token 的细微位置差异，负责短程依赖。$i$ 大对应 $\theta_i$ 小，位置增加时角度几乎不变（$m\theta_i\approx0$、$\cos(m\theta_i)\approx1$），要跨越很多位置才转完一圈，因此在大跨度上仍保留可区分的相位差，负责长程依赖。以 $d=128$、$\mathrm{base}=10000$ 为例，$i=0$ 时约 6 个位置转一圈，$i=63$ 时约 54410 个位置才转一圈。

    3. 给定 $d=4$、$\mathrm{base}=4$、$q=k=(1,0,1,0)$、$m=1$、$n=2$，手算总内积。

      解答：总内积约 $1.4179$

      先算频率：$\theta_0=4^{0}=1$，$\theta_1=4^{-2/4}=4^{-1/2}=0.5$。位置差 $n-m=1$。两个坐标对都是 $(1,0)$，对称项 $1\cdot1+0\cdot0=1$，反对称项 $1\cdot0-0\cdot1=0$，因此每对只剩 $\cos$ 项。

      • 第 0 对：$\cos(1\cdot1)=\cos 1\approx0.5403$。
      • 第 1 对：$\cos(1\cdot0.5)=\cos 0.5\approx0.8776$。

      各块互不干扰，总内积为两项之和 $0.5403+0.8776\approx1.4179$。这里的 $\mathrm{base}=4$ 是便于手算的教学取值，真实模型用 $\mathrm{base}=10000$。

    本章把 2 维机制推广到 d 维，解释了 $\theta_i$ 几何级数的多尺度编码。但 $|m-n|$ 增大时内积怎样变化、为何只动 Q/K 不动 V——下一章讲远程衰减与 QK-only 机制。

    远程衰减——相位抵消与 QK-only 机制

    这一章回答两个问题：d 维 RoPE 的内积随 $|m-n|$ 增大怎样变化？为什么 RoPE 不旋转 V？两个问题来自同一个事实——注意力分数只来自 $QK^T$。

    先看内积的衰减。把 d 维内积按 $d/2$ 个对展开：

    $$\langle R_m^d q, R_n^d k \rangle = \sum_{i=0}^{d/2-1} \left[(q_{2i} k_{2i} + q_{2i+1} k_{2i+1})\cos((n-m)\theta_i) - (q_{2i} k_{2i+1} - q_{2i+1} k_{2i})\sin((n-m)\theta_i)\right].$$

    远程衰减是确定性求和的相位抵消性质[C5][F7]，不需要概率假设。看一个便于手算的特定情形：取 $q=k$ 且每对分量恒定（$q_{2i}=q_{2i+1}=1$，即 $q=k=(1,1,\ldots,1)$）。此时反对称项 $q_{2i} k_{2i+1} - q_{2i+1} k_{2i}=1\cdot1-1\cdot1=0$，对称项 $q_{2i} k_{2i} + q_{2i+1} k_{2i+1}=1\cdot1+1\cdot1=2$。代入得

    $$\langle R_m^d q, R_n^d k \rangle = \sum_{i=0}^{d/2-1} 2\cos((n-m)\theta_i) \propto \sum_{i=0}^{d/2-1} \cos((n-m)\theta_i).$$

    忽略常数比例，归一化后

    $$\frac{1}{d/2}\sum_{i=0}^{d/2-1} \cos((n-m)\theta_i).$$

    这是个有限和的振荡函数。当 $|m-n|$ 增大时，$\theta_i$ 跨越多个数量级使各 $\cos((n-m)\theta_i)$ 的相位相互抵消，归一化和的幅度总体趋小（但并非严格收敛到 0，而是几乎周期的振荡）。论文 §3.4.3 用 Abel 变换给出该和的上界；本文此处用特定情形的确定性计算与相位抵消直觉作教学简化，不等价于论文上界。一般 $q,k$ 下内积是 $\sum_i r_{q,i}r_{k,i}\cos((n-m)\theta_i+\phi_{q,i}-\phi_{k,i})$（极坐标表示），相位抵消的定性结论同样成立。

    补充：从内积公式到归一化和的推导

    起点：$\langle R_m^d q, R_n^d k \rangle = \sum_i \left[(q_{2i} k_{2i} + q_{2i+1} k_{2i+1})\cos((n-m)\theta_i) - (q_{2i} k_{2i+1} - q_{2i+1} k_{2i})\sin((n-m)\theta_i)\right]$。

    特定情形：取 $q=k$ 且每对分量恒定，即 $q_{2i}=q_{2i+1}=k_{2i}=k_{2i+1}=1$（对所有 $i$）。

    第一步，反对称项：$q_{2i} k_{2i+1} - q_{2i+1} k_{2i}=1\cdot1-1\cdot1=0$，$\sin$ 项贡献为零。

    第二步，对称项：$q_{2i} k_{2i} + q_{2i+1} k_{2i+1}=1\cdot1+1\cdot1=2$。

    第三步，代回内积求和：

    $$\langle R_m^d q, R_n^d k \rangle = \sum_{i=0}^{d/2-1} 2\cos((n-m)\theta_i).$$

    归一化（除以 $d/2$ 与对称项贡献 2）：

    $$\frac{1}{d/2}\sum_{i=0}^{d/2-1} \cos((n-m)\theta_i).$$

    注意：上式是 $q=k$、分量恒定这一特定情形的确定性计算，不是 i.i.d. 期望。真实模型中 $q$、$k$ 分量分布有结构，具体 token 对的内积不一定遵循这条曲线；但相位抵消的定性趋势（$|m-n|$ 大时归一化和幅度趋小）对一般 $q,k$ 仍成立，这解释了 RoPE 经验上的隐式局部性偏置。

    下面是 $d=128$、$\mathrm{base}=10000$（LLaMA 系列典型配置）下，归一化内积随 $|m-n|$ 的变化。这是教学示例，按归一化内积公式 $\frac{1}{64}\sum_{i=0}^{63}\cos((n-m)\theta_i)$ 直接计算（非实测数据）：

    教学解释。可以把 d 维 RoPE 暂时理解为 $d/2$ 只钟表指针：$i$ 小的指针转得快（$\theta_i$ 大），$i$ 大的指针转得慢（$\theta_i$ 小）；位置 $m$ 就是各指针一起走过的"时间"。两个 token 比较时，把它们的指针角度相减；如果两 token 距离 $|m-n|$ 小，慢指针基本没动、角度差接近 0，$\cos$ 接近 1；如果距离大，慢指针也转了一段、快指针转了好几圈，各指针的相位差散乱、$\cos$ 平均后抵消。这个类比只帮助理解"为什么 $|m-n|$ 大时归一化内积趋于 0"。它失效的边界：真实模型分量分布有结构，非特定情形的恒定值；指针是离散的 $d/2$ 只而非连续积分；具体 token 对不一定遵循这条曲线。

    现在回答第二个问题：为什么 RoPE 只旋转 Q 和 K，不旋转 V？[C1]这来自注意力机制本身的结构。注意力分数只来自 $QK^T$——softmax 把分数变成权重，再对 V 加权求和。Q 决定"我在找什么"，K 决定"我能被怎么找到"，两者一起决定"看哪里"；V 决定"找到之后取什么信息"。RoPE 的目的是让"看哪里"带上位置感知，所以它作用在 Q 和 K 上就够了；旋转 V 不改变注意力分数（softmax 的输入），只改变加权后的内容方向——这不是位置编码的目的。

    常见误解：把 RoPE 当成"给 Q/K/V 一起加旋转"。这是错的。原论文 §3.2.1 Eq.(13) 与 §3.2.2 Eq.(14) 给出的投影公式下标是 $\{q,k\}$、不含 $v$：$\tilde{q}_m = R_m^d W_q x_m$、$\tilde{k}_n = R_n^d W_k x_n$，而 $v_n = W_v x_n$ 不带旋转矩阵。如果旋转 V，注意力分数不变（softmax 的输入仍是 $\tilde{q}_m \cdot \tilde{k}_n$），但输出 $v$ 的方向被旋转，反而破坏了内容表示。

    本章问题

    1. 用一句话说明为什么 RoPE 不动 V。

      解答：注意力分数只来自 $QK^T$

      因为注意力分数只由 $QK^T$ 决定，旋转 Q 和 K 就已经让“看哪里”带上位置感知；V 只决定“取到之后拿什么内容”，旋转 V 不改变 softmax 的输入，只会改变加权内容的方向，这不是位置编码要达成的目标。

    2. 远程衰减的“相位抵消”直觉为什么成立？真实模型中具体 token 对一定遵循衰减曲线吗。

      解答：相位抵消成立的范围

      d 维内积是 $d/2$ 个 $\cos((n-m)\theta_i)$ 的加权和，而 $\theta_i$ 按几何级数跨越多个数量级。$|m-n|$ 增大时各项相位分散到不同象限，正负贡献相互抵消，归一化和的幅度总体趋小（并非严格收敛到 0，而是接近几乎周期的振荡）。论文 §3.4.3 用 Abel 变换给出该和的上界。

      不一定。页面给出的衰减曲线来自特定构造情形（$q=k$ 且每对分量恒定），真实模型中 $q$、$k$ 的分量分布有结构，具体 token 对的内积可能偏离该曲线；成立的是定性趋势，它解释了 RoPE 经验上的隐式局部性偏置，而非对每个 token 对的保证。

    3. 归一化内积表里 $|m-n|=5000$ 时内积变成负数，这与“衰减”矛盾吗？为什么。

      解答：衰减是趋势而非单调

      不矛盾。这里的“衰减”指幅度总体趋向 0，不是数值单调下降。归一化和是有限个余弦的叠加，本质是振荡函数：当 $|m-n|$ 增大到 5000 附近时它穿过 0 并进入小幅振荡（表中 $-0.0070$，$|m-n|=10000$ 时 $-0.0279$）。这些负值的绝对值远小于近距离时的 $0.97$ 或 $0.74$，符合“幅度趋小”的判断；若把衰减理解成严格单调递减，就会与该现象冲突。

    本章解释了远程衰减来源与"只在 QK 不在 V"的机制。但超出训练长度时 RoPE 会失效——下一章讲长度外推边界与 K3 MLA 的 NoPE 选择。

    适用边界——长度外推、K3 MLA 的 NoPE 选择

    这一章讲 RoPE 在什么条件下成立、什么条件下不成立，以及两个与边界相关的实际选择：长度外推时的扩展方法、Kimi K3 的 MLA 层为何拆出 rot 分量但不施旋转。

    先看适用条件。RoPE 成立需要：（1）softmax 注意力机制（注意力分数来自 $QK^T$）；（2）query/key 维度 $d$ 是偶数（能拆成 $d/2$ 个 2 维对）；（3）token 位置能用整数 $m$ 表示。在这些条件下，原始 RoPE 不引入可学习参数、不修改 V、不修改输入嵌入，是"乘"而非"加"的位置编码。

    RoPE 不解决的问题：它不替代 token 类型嵌入（如 segment embedding）；不解决位置编号的语义（如分段文档、相对时间）；不提供"绝对位置嵌入"那种直接的位置查询能力。在纯双向编码器中若需要显式绝对位置信号，APE 或可学习位置嵌入可能更直接。RoPE 的优势在自回归与长上下文外推。

    长度外推的边界与扩展方法

    训练长度内，位置 $m$ 在 $[0, L_{\text{train}})$（如 $L_{\text{train}}=4096$）范围取值，模型见过 $m\theta_i$ 在 $[0, L_{\text{train}}\cdot\theta_i)$ 的角度组合。超出训练长度时，$m\theta_i$ 进入训练分布外的角度区间，简单外推性能下降——尤其是 $i$ 小的高频分量（$\theta_i$ 大）很快超出已学角度范围。

    常见误解："RoPE 可以任意外推到更长序列。"这是错的。论文摘要提到"flexibility of sequence length"，指的是 RoPE 在结构上能扩展到任意长度（不像 learned APE 超出表长即失败），但不意味着简单外推效果不变。超出训练长度时性能下降是经验事实，需要扩展方法处理。

    常见的扩展方法（本文不展开推导，只列方向）[C7]：

    方法核心思路来源
    Position Interpolation（PI）把位置 $m$ 缩放到训练范围内，如 $m' = m \cdot L_{\text{train}}/L_{\text{target}}$，让 $m'\theta_i$ 落在已学区间Chen et al. 2023, arXiv:2306.13595
    YaRN按 $\theta_i$ 的频率分组，对不同频率用不同缩放因子（高频保持、低频缩放），保留局部信息Peng et al. 2023, arXiv:2309.00071
    LongRoPE非均匀地按维度搜索缩放因子，支持百万级上下文Microsoft 2024

    这些扩展方法的完整公式与机制属相邻概念，不在本页展开。RoPE 的边界——超出训练长度需要扩展——是理解"为什么主流长上下文模型都用 YaRN 或 PI 之类方法"的关键。

    K3 MLA 的 NoPE 选择——RoPE 与矩阵吸收的冲突

    RoPE 的另一个边界出现在它与其他推理优化的交互上。MLA（Multi-head Latent Attention，详见 MLA 概念页）通过压缩潜向量减少 KV cache；其推理优化依赖"矩阵吸收"——把投影矩阵 $W^{UK}$ 从 key 侧搬到 query 侧，避免显式重建 K。但矩阵吸收的前提是 $W^{UK}$ 与位置无关。

    如果对压缩潜变量施加 RoPE：注意力项变成 $\tilde{q}^T (R_n W^{UK} c^{KV})$，$R_n$ 介于 $\tilde{q}$ 和 $W^{UK}$ 之间且每个 token 的 $R_n$ 都不同，合并不出固定矩阵——位置敏感的旋转破坏了矩阵吸收的前提。这是 DeepSeek-V2 引入"解耦 RoPE"设计的原因（详见 MLA 概念页的"为什么 RoPE 要解耦"一章）：把 RoPE 单独拆出来，用额外一组共享 key 承载 RoPE，content 部分仍可矩阵吸收。

    Kimi K3 走了另一条路。K3 的 Gated MLA 层在结构上保留了 RoPE 接口（拆出 rot 分量），但 config.json 中 mla_use_nope=true，所有 MLA 层不施加位置编码——这是 NoPE 路线。K3 的位置信息由 KDA（K3 中的递归注意力变体）通过递归门控和衰减机制隐式提供，MLA 不需要额外的位置编码。这意味着扩展上下文长度时无需修改位置编码参数（如 RoPE rescaling 或 YaRN），模型直接外推到 1M token[C8]（详见 Kimi K3 概念页的"长上下文扩展"一章）。

    常见误解："K3 的 MLA 层用了 RoPE。"这是错的。DeepSeek-V2 的 MLA 用解耦 RoPE，读者可能假设 K3 也用；但 K3 通过 mla_use_nope=true 直接关闭了 MLA 层的位置编码。RoPE 与矩阵吸收的冲突在 K3 这里被 NoPE 路线绕过——这是 RoPE 边界（与某些推理优化不兼容）的实例，也是理解 K3 架构选择时 RoPE 作为前置概念的意义。

    本章问题

    1. RoPE 在长度外推时为什么失效？PI 与 YaRN 各自的解决思路是什么。

      解答：外推失效原因与两种扩展思路

      训练时位置 $m$ 只在 $[0, L_{\text{train}})$ 内取值，模型只见过 $m\theta_i$ 落在 $[0, L_{\text{train}}\cdot\theta_i)$ 的角度组合。超出训练长度后 $m\theta_i$ 进入训练分布外的角度区间，尤其 $i$ 小的高频分量很快越界，性能下降。

      PI（Position Interpolation）把位置整体缩放回训练范围，如 $m'=m\cdot L_{\text{train}}/L_{\text{target}}$，使 $m'\theta_i$ 仍落在已学区间。YaRN 按频率分组施加不同缩放：高频基本保持以保留局部分辨力，低频缩放以覆盖更长距离。此外 LongRoPE 按维度非均匀搜索缩放因子，支持百万级上下文。

    2. K3 的 MLA 层为什么用 NoPE 而不是 RoPE？这与矩阵吸收有什么关系。

      解答：RoPE 与矩阵吸收的冲突

      MLA 的推理优化依赖矩阵吸收：把 $W^{UK}$ 从 key 侧搬到 query 侧，从而免于显式重建 K，前提是 $W^{UK}$ 与位置无关。若对压缩潜变量施加 RoPE，注意力项变成 $\tilde q^T(R_n W^{UK} c^{KV})$，位置相关的 $R_n$ 夹在 $\tilde q$ 与 $W^{UK}$ 之间且每个 token 各不相同，无法合并成固定矩阵，吸收前提被破坏。DeepSeek-V2 的应对是解耦 RoPE，用额外一组共享 key 承载位置信息。

      Kimi K3 走另一条路：Gated MLA 在结构上保留 rot 分量接口，但 config.json 中 mla_use_nope=true，所有 MLA 层不施加位置编码；位置信息由 KDA 通过递归门控与衰减隐式提供。因此扩展上下文时无需调整位置编码参数，可直接外推到 1M token。

    3. RoPE 的适用条件有哪三条？举一个 RoPE 不适用的场景。

      解答：三条适用条件与一个反例

      三条条件：一是使用 softmax 注意力，注意力分数来自 $QK^T$；二是 query/key 维度 $d$ 为偶数，能拆成 $d/2$ 个二维对；三是 token 位置可用整数 $m$ 表示。

      不适用的场景：纯双向编码器中若需要显式的绝对位置信号（例如直接查询“这个 token 在第几位”），RoPE 只提供相对位置效果，APE 或可学习位置嵌入更直接。RoPE 也不替代 segment 之类的 token 类型嵌入，不表达分段文档或相对时间这类位置语义。

    本文从"Transformer 为什么需要位置编码"出发，依次回答了开篇的五个问题：RoPE 用旋转矩阵编码绝对位置，使内积只依赖相对位置 $m-n$[C2]；2 维机制通过分块对角推广到 d 维，$\theta_i$ 几何级数实现多尺度编码[C4]；远程衰减来自相位抵消[C5]；RoPE 只动 Q/K 不动 V[C1]；超出训练长度需要 YaRN/PI 扩展[C7]，与 MLA 矩阵吸收冲突时用解耦或 NoPE 绕过[C8]。这些是理解任何 transformer 位置方案的前提——不是"加 RoPE 就行"，而是"RoPE 在什么条件下成立、不成立时怎么办"。

    教学解释与类比边界

    钟表指针类比：服务"多尺度旋转的直觉"这一局部关系——$d/2$ 只钟表指针、$i$ 小转得快、$i$ 大转得慢、$|m-n|$ 大时各指针相位散乱、$\cos$ 平均后抵消。失效边界：（1）真实模型分量分布有结构，非特定情形的恒定值；（2）指针是离散 $d/2$ 只而非连续积分（论文 Eq.(18) 是积分近似）；（3）具体 token 对不一定遵循期望曲线。正式判断仍以 F7、F8 公式为准。

    "绝对构造、相对效果"措辞：服务"RoPE 不是相对位置编码但效果是相对的"这一区分。失效边界：措辞只澄清术语，不替代 $R_m^T R_n = R_{n-m}$ 的代数证明。

    简化 1：用 $\theta=\pi/4$、$\mathrm{base}=4$ 等可手算数字。可推出：便于复算验证公式正确性。不可推出：真实模型也用这些数字。
