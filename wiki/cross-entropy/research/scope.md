# 交叉熵 内容范围

## 1. 概念含义

- 概念名称：交叉熵
- 英文名称：cross-entropy
- 常见缩写：CE
- 简要定义：度量「用一个概率分布 $Q$ 去编码/预测服从分布 $P$ 的结果」的平均代价；训练中它是模型预测分布与数据真实结果之间的损失。
- 正式定义：$H(P, Q) = -\mathbb{E}_{x \sim P} \log Q(x)$（Deep Learning 教材 §3.13 式 (3.51)）；且有 $H(P,Q) = H(P) + D_{\mathrm{KL}}(P \,\|\, Q)$。
- 本文采用的语境：机器学习训练损失语境（分类与语言模型共用），从信息论定义进入训练视角。

### 概念歧义处理

状态：已裁定。「信息论中两个分布间的度量」与「机器学习中训练损失」是同一数学对象在不同语境的使用：Deep Learning §5.5 明确指出任何由负对数似然组成的损失都是经验分布与模型分布之间的交叉熵（"Any loss consisting of a negative log-likelihood is a cross-entropy between the empirical distribution defined by the training set and the probability distribution defined by model"）。正文并列呈现两种视角并说明其等价关系，不视为歧义。

### 包括什么

- 为什么训练需要把「预测概率」转换成「损失」（连续可微 vs 离散指标）
- 信息论定义：自信息 → 香农熵 → KL 散度 → 交叉熵的推导链（式 3.48–3.51）
- 训练视角：交叉熵与负对数似然、最大似然估计的等价（式 5.59–5.61）
- one-hot 标签下交叉熵化简为 $-\log q(y)$；softmax 多分类形式
- 手算示例：二分类、多分类、语言模型 token 级
- 语言模型的下一 token 交叉熵形式（token 平均；为预训练与 SFT 页服务）

每项属于该概念的理由：以上构成「交叉熵是什么、从哪来、训练中怎么算」的完整闭环。

### 不包括什么

- 困惑度（perplexity）：交叉熵的指数换算，属评估度量主题（排除理由：独立度量概念，本页只需一句话提及换算关系时不展开——实际上本页不涉及，避免依赖来源不足）
- 为什么不用均方误差训练分类器：需要额外推导与来源（Goodfellow 6.2 有讨论但超出本页学习目标；排除理由：不影响理解交叉熵本身）
- 标签平滑、Focal Loss 等交叉熵变体：变体主题（排除理由：不影响定义与手算）
- 二元交叉熵与 sigmoid 的推导细节（logistic 回归的完整推导）：按需给最小说明，不展开

### 相邻概念

- KL 散度：交叉熵的组成部分（$H(P,Q) = H(P) + D_{\mathrm{KL}}$），本页内必须讲清关系，但不展开 KL 的应用
- 负对数似然（NLL）：训练视角下与交叉熵等价，本页说明等价条件（one-hot 经验分布），不单独立页
- 最大似然估计（MLE）：交叉熵最小化的概率论解释，本页只取结论（式 5.59–5.61），不展开 MLE 理论

## 2. 学习目标

### Q1：训练为什么需要把「预测概率」转成「损失」？

- 完成答案：说明分类/预测任务的原始产出是概率（或打分），但训练需要能对参数求导、能连续变化的数值目标；准确率等离散指标不可微、无法提供梯度；损失函数把「模型认为真实结果有多可能」映射成一个数值，越自信且正确越小、越自信且错误越大。
- 为什么是核心目标：不理解这个转换需求，交叉熵只是一串符号。
- 依赖内容：梯度下降的最小值直觉（页内一句话说明，不深入）。

### Q2：交叉熵的定义是什么，它与熵、KL 散度、负对数似然分别是什么关系？

- 完成答案：给出 $H(P,Q) = -\mathbb{E}_{x\sim P}\log Q(x)$；说明它是「用 $Q$ 编码服从 $P$ 的结果」的平均自信息；$H(P,Q) = H(P) + D_{\mathrm{KL}}(P\|Q)$，其中 $H(P)$ 与 $Q$ 无关；因此对固定数据、最小化交叉熵等价于最小化 KL；训练视角下（经验分布 one-hot、MLE）最小化 NLL 就是最小化交叉熵。
- 为什么是核心目标：这是概念的数学主体。
- 依赖内容：期望与对数运算（数学常识）。

### Q3：二分类与多分类的交叉熵如何手算？

- 完成答案：二分类（真实 $y=1$、预测 $p=0.8$）算出 $-\ln 0.8$；多分类（one-hot 标签、softmax 概率向量）算出 $-\log q(y)$；说明 one-hot 化简后期望里的求和只剩真实类一项。
- 为什么是核心目标：没有手算，「交叉熵」停留在公式层面。
- 依赖内容：对数计算。

### Q4：语言模型的下一 token 交叉熵是什么形式？

- 完成答案：语言模型在每个位置输出整个词表上的分布，真实结果是要预测的下一个 token（one-hot），该位置损失即 $-\log p_\theta(\text{下一 token} \mid \text{前文})$；序列/语料的损失按 token 平均（GPT-2：语言建模结果以「每个预测单元的平均负对数概率」报告）。
- 为什么是核心目标：这是预训练与 SFT 页直接使用的形式，本页的存在意义之一。
- 依赖内容：Q2 的 one-hot 化简。

## 6. 常见误解和适用边界

### 常见误解

1. 错误理解：交叉熵是「两个独热向量的距离」。正确结论：交叉熵是分布间的度量，形式为期望 $-\mathbb{E}_{x\sim P}\log Q(x)$；one-hot 只是 $P$ 的特例。形成原因：教程中多分类交叉熵总是从 one-hot 例子引入。影响：Q2。
2. 错误理解：交叉熵与负对数似然是两个不同损失。正确结论：训练视角下两者是同一对象的不同名字（Goodfellow §5.5 原文支持）。形成原因：不同框架/库的命名差异（PyTorch 的 CrossEntropyLoss 内部是 NLL on log-softmax——此实现细节不写入页面，避免来源依赖）。影响：Q2。
3. 错误理解：交叉熵可以为负。正确结论：当 $P$ 为 one-hot 经验分布、$Q$ 为概率分布时 $-\log Q(y) \ge 0$；信息论定义下对连续分布可以出现负值（本页不涉连续情形，边界处说明离散概率分布下非负）。形成原因：混合了连续/离散场景。影响：Q2。
4. 错误理解：语言模型的损失是「整句话一个数」所以每个词的贡献不可分。正确结论：交叉熵按 token 逐个计算再平均，每个位置独立可分。影响：Q4。

### 适用边界

- 交叉熵要求 $Q$ 是概率分布（对全部可能结果求和为 1）；模型输出打分需先经 softmax/sigmoid 归一（Q3、Q4 的条件）。
- 「最小化交叉熵 = 最小化 KL」成立条件：$P$（数据分布）固定，优化只作用于 $Q$（模型）。
- 概率为 0 的真实事件使交叉熵发散（$-\log 0 = +\infty$）：这是训练中避免极端置信的数值背景，本页只在边界处一句话说明。
