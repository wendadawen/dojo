# 交叉熵 文章大纲

## 1. 页面开头

开头场景：模型对明天的天气输出「晴 80%、雨 20%」，第二天确实晴了。这个预测值 0.8 的概率本身还不是「训练用的数」——训练需要一个把概率变成代价的函数，它要在模型对的时候给小数、错的时候给大数，且能对参数求导。交叉熵就是这个函数。

随后：简要定义（一句话：度量「模型认为真实结果有多可能」的代价）、核心问题（学习目标 4 条）、首个示例预告（贯穿示例：同一个「预测天气/词表」场景从二分类走到语言模型）、过渡到第 1 章。

## 2. 章节设计

### 第 1 章：为什么预测概率需要转换成损失（回答 Q1）

- 章节问题：
  - 问题 1：模型的原始输出（概率/打分）为什么不能直接当训练目标？
  - 问题 2：损失函数需要满足什么性质，交叉熵给出的是什么映射？
- 完成答案要点：
  - 问题 1：准确率/对错是离散量，参数微小变化不改变对错，无法产生梯度；概率本身没有「错的方向」——需要与真实结果对照后的量。
  - 问题 2：连续、可微、真实结果概率越高值越小、趋于 0 时趋于无穷大；交叉熵 $-\log q(y)$ 把「模型赋予真实结果的概率」单调映射为代价。
- 对应范围：Q1。
- 正文要点：梯度下降需要可微目标（一句话说明，不展开）→ 准确率不可微的具体原因 → $-\log$ 映射的两个端点行为（$q(y)=1$ 时 0，$q(y)\to 0$ 时 $\to\infty$）。
- 表达材料及职责：$-\log q$ 的一条曲线示意（内联 SVG，标注两个端点）。
- 前置知识安排：无。

### 第 2 章：交叉熵的信息论定义（回答 Q2 前半）

- 章节问题：
  - 问题 1：自信息和熵分别度量什么？
  - 问题 2：交叉熵的定义是什么，为什么它等于熵加 KL？
- 完成答案要点：
  - 问题 1：自信息 $-\log P(x)$（式 3.48）：越罕见信息量越大；香农熵 $H(P)=-\mathbb{E}\log P(x)$（式 3.49）：分布平均的不确定性。
  - 问题 2：$H(P,Q) = -\mathbb{E}_{x\sim P}\log Q(x)$（式 3.51）；分解 $H(P,Q) = H(P) + D_{\mathrm{KL}}(P\|Q)$：用「为 $P$ 设计的最优编码」去传 $P$ 的代价是 $H(P)$，「用错了为 $Q$ 设计的编码」的额外代价是 KL；$H(P)$ 与 $Q$ 无关，故最小化交叉熵等价于最小化 KL（原文引据）。
- 对应范围：Q2 / C1 C2 C3 C4 / F1 F2。
- 正文要点：三个量的递进定义 → 分解式的直觉解释 → 等价最小化的条件。
- 表达材料及职责：无图（推导链用正文与公式表达）；完整的多步展开放折叠块（如 KL 非负性的说明不展开，只引原文）。
- 前置知识安排：期望、对数——首段最小说明（数学常识）。

### 第 3 章：训练视角——从最大似然到 one-hot 手算（回答 Q2 后半与 Q3）

- 章节问题：
  - 问题 1：为什么训练中最小化交叉熵就是最大似然？
  - 问题 2：one-hot 标签下交叉熵化简成什么？二分类和多分类怎么手算？
- 完成答案要点：
  - 问题 1：训练集定义经验分布（one-hot 于每个样本），最大似然 = 最小化 NLL = 最小化交叉熵（式 5.59–5.61 段落原文引据，C5）。
  - 问题 2：期望里只剩真实类一项，$H = -\log q(y)$（F3）；二分类例：$y=1, p=0.8 \Rightarrow -\ln 0.8 \approx 0.223$；多分类例：one-hot 标签 + softmax 概率向量，算 $-\log q(y)$；同一样本预测置信不足时的对比值。
- 对应范围：Q2 后半 / Q3 / C5 / F3 F4。
- 正文要点：经验分布与 one-hot → 化简 → 两个手算例子（关键数字在正文，完整多位计算在折叠块）→ softmax 的最小说明（打分归一为概率，一个公式一句职责）。
- 表达材料及职责：手算表格（展示代入步骤）；折叠块放完整对数计算。
- 前置知识安排：无新增。

### 第 4 章：语言模型的下一 token 交叉熵（回答 Q4）

- 章节问题：
  - 问题 1：语言模型在单个位置上的交叉熵是什么形式？
  - 问题 2：一段文本的损失怎么从 token 级损失合成？
- 完成答案要点：
  - 问题 1：每个位置模型输出词表上的分布，真实结果是下一个 token（one-hot），该位置损失 $-\log p_\theta(y_t \mid \text{前文})$（F5，构造小词表手算一个位置）。
  - 问题 2：序列损失 = token 损失求平均（GPT-2：以每个预测单元的平均负对数概率报告，C7）；每 token 独立可分（误解 4）。
- 对应范围：Q4 / C7 / F5。
- 正文要点：token 级形式 → 平均 → 与第 3 章 one-hot 化简的衔接（同一个公式换场景）→ 小词表手算。
- 表达材料及职责：小词表预测分布表 + 计算表。
- 前置知识安排：无新增。

## 4. 贯穿示例

设定：一个玩具天气模型（二分类：晴/雨）→ 同一个模型扩展为三分类（晴/雨/雪，softmax）→ 再把视角换成小词表（5 个 token）的下一个 token 预测。三个场景共用同一公式 $-\log q(\text{真实结果})$。

- 第 1 章进场：二分类概率 0.8 的场景（只谈映射需求）。
- 第 3 章推进：算出 0.223；多分类版本算 $-\log q(y)$。
- 第 4 章推进：词表版本算 token 损失与两句文本的平均损失。
