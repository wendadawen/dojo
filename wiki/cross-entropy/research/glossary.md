# 交叉熵 术语表

| 术语/符号 | 首次出现 | 含义 |
|---|---|---|
| 损失（loss） | 第 1 章 | 把模型输出与真实结果的差距映射为一个可优化的数值 |
| 梯度（gradient） | 第 1 章 | 损失对参数的导数，指示参数更新方向；页内只用直觉含义 |
| 可微（differentiable） | 第 1 章 | 数值随参数连续变化，可求导 |
| 概率分布 $P, Q$ | 第 2 章 | $P$：结果的真实/经验分布；$Q$：模型的预测分布 |
| 自信息（self-information）$I(x)=-\log P(x)$ | 第 2 章 | 单个结果的信息量，越罕见越大 |
| nats / bits | 第 2 章 | 对数底为 $e$ / $2$ 时的信息单位 |
| 香农熵（Shannon entropy）$H(P)$ | 第 2 章 | 分布平均的不确定性 $-\mathbb{E}_{x\sim P}\log P(x)$ |
| KL 散度（KL divergence）$D_{\mathrm{KL}}(P\|Q)$ | 第 2 章 | 用 $Q$ 替代 $P$ 的额外代价，非负不对称 |
| 交叉熵（cross-entropy）$H(P,Q)$ | 第 2 章 | $-\mathbb{E}_{x\sim P}\log Q(x)$；$H(P)+D_{\mathrm{KL}}(P\|Q)$ |
| 期望 $\mathbb{E}_{x\sim P}$ | 第 2 章 | 按 $P$ 加权的平均 |
| $0\log 0$ | 第 2 章 | 惯例取 0 |
| 经验分布（empirical distribution） | 第 3 章 | 训练集定义的分布：每个样本点概率为 $1/N$ |
| 负对数似然（NLL） | 第 3 章 | $-\log$ 似然；训练视角下与交叉熵同一对象 |
| 最大似然估计（MLE） | 第 3 章 | 选参数使数据出现概率最大 |
| one-hot | 第 3 章 | 只有真实结果位置为 1 的向量表示 |
| softmax | 第 3 章 | 把打分向量归一为概率分布的函数 |
| 二分类 / 多分类 | 第 3 章 | 结果有 2 类 / 多类的预测任务 |
| $q(y)$ | 第 3 章 | 模型赋予真实结果 $y$ 的概率 |
| 语言模型 / $p_\theta$ | 第 4 章 | 给前文预测下一 token 分布的模型；$\theta$ 为参数 |
| token | 第 4 章 | 文本的最小处理单元（词/子词/字符） |
| 词表（vocabulary） | 第 4 章 | 全部可用 token 的集合 |
| token 级损失 | 第 4 章 | 单个位置上的 $-\log p_\theta(\text{下一 token}\mid\text{前文})$ |
| 平均负对数概率 | 第 4 章 | 按预测单元（token 等）平均的 NLL |
| 困惑度（perplexity） | 不使用 | —（本页排除） |
