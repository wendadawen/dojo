# 块扩散（block-diffusion）术语表

| 术语/符号 | 首次出现 | 含义 |
|---|---|---|
| 自回归（AR）模型 | 第 1 章 | 按从左到右顺序逐 token 生成，每步以前文为条件 |
| 掩码扩散（masked diffusion） | 第 1 章 | 把待生成位置遮住、模型并行预测全部被遮位置、可多轮精化的生成方式；本页就地给出的最小含义 |
| 去噪（denoising） | 第 1 章 | 给定部分被遮的序列，预测被遮位置内容的过程 |
| 块（block） | 第 1 章 | 连续 $L'$ 个 token 组成的生成单元，块扩散的串行粒度 |
| 块大小 $L'$ | 第 1 章 | 每块包含的 token 数 |
| 块数 $B$ | 第 1 章 | 序列切成的块数，$B=L/L'$ |
| 序列长度 $L$ | 第 1 章 | 生成序列的 token 总数 |
| $x^{<b}$ | 第 1 章 | 第 $b$ 块之前的全部 token |
| 掩码 token（[MASK]） | 第 1 章 | 占位符，表示该位置尚未生成 |
| block-causal 注意力掩码 | 第 2 章 | 规则「块 $b$ 的 token 可见块 $1..b$」：跨块因果、块内双向 |
| KV cache | 第 3 章 | 已生成前缀的 K/V 投影缓存，避免重复计算 |
| $\mathbf{K}^b,\mathbf{V}^b$ | 第 3 章 | 模型对第 $b$ 块输出的 K/V，作为后续块的缓存输入 |
| $x_{\text{logits}}^b$ | 第 3 章 | 模型对第 $b$ 块各位置的词表预测分数 |
| 去噪轮数 $T$ | 第 4 章 | 一块内去噪的前向次数 |
| 置信度揭开 | 第 4 章 | 每轮去噪后按预测置信度选择要揭开的子集 |
| NFE（生成步数） | 第 4 章 | number of function evaluations，去噪网络被调用的次数 |
| 投机解码（speculative decoding） | 第 5 章 | 小草稿模型先猜、大目标模型并行验证的无损加速框架 |
| 草稿模型 / 目标模型 | 第 5 章 | 投机解码中分别负责猜与验证的模型 |
| bonus token | 第 5 章 | 每轮验证时目标模型顺带多产出的一个 token |
| 接受长度 $\tau$ | 第 5 章 | 每轮验证平均接受的 token 数 |
| DFlash | 第 5 章 | 把块扩散简化为单步并行起草的投机解码框架（ICML 2026） |
| BD3LM | 第 1 章 | Arriola et al. 提出的块扩散语言模型实例 |
| 单步并行预测 | 第 5 章 | 去噪轮数取 1 的极端：一次前向同时预测整块所有位置 |
