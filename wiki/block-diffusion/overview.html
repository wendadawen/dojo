Block Diffusion

块扩散语言模型把 token 序列切成块，块间按自回归从左到右建模，块内用离散掩码扩散并行去噪。

分块去噪的语言模型

token 是模型读写文本的最小单位，可以是一个词或词的一部分。自回归生成指每次只预测下一个 token，用前面所有 token 作条件。块扩散语言模型把一条 token 序列切成固定长度的块，块与块之间按自回归从左到右生成，块内部并行还原。块内用的是掩码扩散：把块里的一部分 token 换成掩码符号，模型一次给出所有被掩位置的原 token 预测，掩码符号是一个专用来占位的符号。

扩散模型缺的东西它补上

离散扩散语言模型一次为整条序列去噪，生成时每一步都要处理整条序列，已经生成的部分不能在下一步复用。模型处理序列时靠一种叫注意力的计算，让每个位置和别的位置互相比较、交换信息，这种计算为每个位置算出几个向量，其中两个叫键和值，供别的位置取用。块扩散把序列切成块后，块间是自回归的，已经生成完的块不再改动，它的键和值可以留下来复用，这就是 KV cache 省下的那部分重算。同时，块内可以并行给出多个 token，不必像自回归那样一次一个。块大小在两端之间调：块等于 1 就是逐 token 的自回归模型，块等于整条序列就退化成一次为全序列去噪的扩散模型。块扩散给出的似然（模型给整段文本的概率）不再受固定长度限制，可以连续生成任意多个块，得到比训练时的序列长度更长的序列。

切块、块间自回归、块内并行

  1. 把序列切成 $B$ 个长度为 $L'$ 的块，似然按块相乘，块 $b$ 的条件概率只依赖它之前的块。
  2. 每个块内部用离散掩码扩散去噪：按一个掩码率把块里的 token 掩掉一部分，模型预测被掩位置的原 token，逐步降低掩码率。
  3. 生成时一次出一个块，块内并行去噪，生成完这个块后把它的原 token 与它算出的键和值追加缓存，再生成下一个块。
