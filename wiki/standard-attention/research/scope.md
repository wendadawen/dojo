# 标准缩放点积注意力：内容范围

## 1.1 概念含义

- **概念名称**：标准 Transformer 注意力
- **英文名称**：Scaled Dot-Product Attention；常见同义：Standard Attention、Standard Softmax Attention、SDPA
- **一句话定义**：让序列中每个位置以"查询向量与键向量点积"衡量与其它位置的相关程度，用 softmax 归一化成权重后对"值向量"加权求和，得到该位置的输出表示。
- **正式定义**：给定查询矩阵 $Q\in\mathbb{R}^{n\times d_k}$、键矩阵 $K\in\mathbb{R}^{m\times d_k}$、值矩阵 $V\in\mathbb{R}^{m\times d_v}$，缩放点积注意力定义为

  $$\text{Attention}(Q,K,V)=\text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V.$$

  多头版本把 $Q,K,V$ 投影到 $h$ 个子空间分别做缩放点积注意力，再拼接并做一次线性投影：

  $$\text{MultiHead}(Q,K,V)=\text{Concat}(\text{head}_1,\ldots,\text{head}_h)W^O,$$

  其中 $\text{head}_i=\text{Attention}(QW_i^Q,KW_i^K,VW_i^V)$。该定义与 Vaswani et al. 2017（NeurIPS 2017, arXiv:1706.03762）§3.2.1 Eq.(1) 与 §3.2.2 Eq.(2) 一致。
- **本文采用的语境**：自注意力（self-attention）语境下的缩放点积注意力，即 $Q,K,V$ 都来自同一输入序列的线性投影。也覆盖交叉注意力（$K,V$ 来自另一序列）的形式差异，但不展开具体翻译/编码任务的应用。
- **历史定位**：本文是 Vaswani et al. 2017 提出的原始标准形式，是后续 MLA、KDA、Block AttnRes、Flash Attention、Linear Attention 等所有注意力变体的基础前置概念。

### 包括什么

| 纳入项 | 纳入理由 |
|---|---|
| 缩放点积注意力公式 $\text{softmax}(QK^\top/\sqrt{d_k})V$ | 概念的核心定义，缺则无法回答"是什么" |
| $Q,K,V$ 的来源（输入线性投影 $XW^Q,XW^K,XW^V$） | 解释"查询、键、值"如何从输入得到，回答"机制输入是什么" |
| $\sqrt{d_k}$ 缩放的方差推导 | 解释"为什么需要缩放"，是公式中唯一的非显然项 |
| softmax 把分数转成概率分布的机制 | 解释归一化步骤的目的与边界 |
| 加权求和得到输出的步骤 | 解释输出形状与"信息聚合"目的 |
| 多头注意力公式与拼接机制 | 是标准注意力的标准使用方式，不展开则概念不完整 |
| 多头的"子空间"含义与总参数量不变 | 解释为什么要多头而不是加大单头维度 |
| 因果遮罩（masked attention）的形式 | 自回归推理的标准使用方式，是后续 LLM 推理的基础 |
| 可手算的 2×2 / 3×3 注意力数字例子 | 把公式落到可复算数字，避免抽象 |
| 复杂度 $O(n^2 d_k)$ 与空间 $O(n^2)$ | 解释后续变体（Linear/Flash）要解决的瓶颈 |

### 相邻概念

| 相邻概念 | 关键区别 | 是否纳入 |
|---|---|---|
| 加性注意力（Bahdanau 2014） | 用一个前馈网络算"分数"而非点积；计算量大但小 $d_k$ 时表达力等价 | 不纳入，仅在 S5 缩放动机处一句话提及"加性注意力在 $d_k$ 大时与未缩放点积的对比" |
| Luong 点积注意力（2015） | 用点积但不除 $\sqrt{d_k}$；Vaswani 2017 的缩放因子是其创新 | 不纳入，仅作为缩放动机对照 |
| 自注意力 vs 交叉注意力 | $Q,K,V$ 是否来自同一序列；公式相同 | 形式上覆盖（一句话指出），不展开任务应用 |
| Linear Attention | 用核分解 $\exp(q\cdot k)\approx\phi(q)\phi(k)$ 把 $O(n^2)$ 降到 $O(n)$；是本文的对比对象 | 不纳入；本文是其前置 |
| Flash Attention | 公式不变，只改 GPU 上的 IO 实现 | 不纳入；本文只引复杂度瓶颈 |
| Multi-head 与 Single-head 的关系 | 多头 = 把 $d_{model}$ 拆成 $h$ 个 $d_k$ 子空间并行做注意力；不是"多次独立注意力" | 纳入；这是"标准注意力"的标准使用方式 |

## 1.2 学习目标

### Q1：注意力在解决什么问题——为什么序列建模需要"对齐"与"加权聚合"？

- **完成答案**：读者应能说明：序列建模中每个位置需要"看到"其它位置的相关信息，但相关位置随任务变化（如指代消解时"它"要看前文的"猫"，翻译时目标词要对齐源词）；注意力让模型对每个位置动态生成"查询"去匹配其它位置的"键"，按匹配程度对"值"加权求和，从而得到一个"上下文相关的表示"。读者应能指出：在 RNN 中这种对齐靠隐状态逐步传递（$O(n)$ 路径长度），在标准注意力中任意两个位置直接交互（$O(1)$ 路径长度）。
- **为什么是核心目标**：不理解"对齐 + 加权聚合"这一目的，就无法理解公式中 $Q,K,V$ 三个矩阵的角色，也无法理解后续变体（MLA 压缩 KV、Linear 替换 softmax 核）要保住什么、替换什么。
- **依赖内容**：序列位置表示的最小概念；"加权求和"的初等概念。

### Q2：缩放点积注意力公式 $\text{softmax}(QK^\top/\sqrt{d_k})V$ 的每个符号是什么、每一步在做什么、为什么除以 $\sqrt{d_k}$？

- **完成答案**：读者应能逐项解释：$Q$ 为查询矩阵（$n\times d_k$，$n$ 个查询向量，每个 $d_k$ 维）、$K$ 为键矩阵（$m\times d_k$）、$V$ 为值矩阵（$m\times d_v$）、$K^\top$ 为键矩阵转置、$QK^\top$ 为 $n\times m$ 的相似度矩阵（每个元素是 query 与 key 的点积）、$d_k$ 为查询/键向量维度、$\sqrt{d_k}$ 为缩放因子、softmax 沿每行作用把分数归一化为概率分布、最后乘 $V$ 得到 $n\times d_v$ 输出。读者应能解释为什么除 $\sqrt{d_k}$：当 $q,k$ 各分量独立同分布、均值 0、方差 1 时，点积 $q\cdot k=\sum_i q_i k_i$ 的方差为 $d_k$，标准差 $\sqrt{d_k}$；不缩放时大 $d_k$ 会让 softmax 输入过大、输出近 one-hot、梯度近零。读者应能复述 Vaswani et al. 2017 §3.2.1 的脚注 4 给出的方差推导。
- **为什么是核心目标**：公式是概念的正式定义，符号与缩放因子是后续所有变体共享的元素；不理解缩放就无法理解 MLA/Flash 等变体为何沿 $d_k$ 维度做特定优化。
- **依赖内容**：点积与矩阵乘法；softmax 的初等定义（公式中首次给出）。

### Q3：多头注意力如何把单头扩展到多头——拼接后的总维度和参数量为什么不变？

- **完成答案**：读者应能写出多头公式 $\text{MultiHead}(Q,K,V)=\text{Concat}(\text{head}_1,\ldots,\text{head}_h)W^O$，每个 $\text{head}_i=\text{Attention}(QW_i^Q,KW_i^K,VW_i^V)$，其中 $W_i^Q\in\mathbb{R}^{d_{model}\times d_k}$、$W_i^K\in\mathbb{R}^{d_{model}\times d_k}$、$W_i^V\in\mathbb{R}^{d_{model}\times d_v}$、$W^O\in\mathbb{R}^{hd_v\times d_{model}}$。读者应能解释：每个头在 $d_k=d_{model}/h$ 维子空间独立做注意力，拼接后得到 $h\cdot d_v=d_{model}$ 维向量，再用 $W^O$ 投影回 $d_{model}$；当 $d_k=d_v=d_{model}/h$ 时，所有投影矩阵总参数量与单头 $d_{model}$ 维注意力相同。读者应能算出论文参数：$d_{model}=512$、$h=8$、$d_k=d_v=64$，8 个头拼接得 $512$ 维，与单头 $d_{model}=512$ 维的总参数一致。
- **为什么是核心目标**：多头是标准注意力的标准使用方式，几乎所有现代 LLM 都用多头而非单头；不理解多头拼接就无法理解 MLA 的"$l$ 维潜在向量"压缩、KDA 的"键解耦"等变体。
- **依赖内容**：Q2 的单头公式；矩阵分块的初等概念。

### Q4：标准注意力的复杂度与边界——$O(n^2)$ 瓶颈在哪一步？注意力本身不解决什么问题？

- **完成答案**：读者应能指出 $QK^\top$ 这一步产生 $n\times m$（自注意力下 $n\times n$）矩阵，时间复杂度 $O(n^2 d_k)$，空间复杂度 $O(n^2)$；这是后续 Linear Attention、Flash Attention 要解决的瓶颈。读者应能说明标准注意力不解决的问题：(1) 不引入位置信息——注意力本身是位置无关的（permutation-invariant），需要外接 RoPE 等位置编码；(2) 不压缩 KV——推理时 KV cache 随 $n$ 与头数 $h$ 线性增长，是 MLA 要解决的问题；(3) 不改变 $O(n^2)$ 复杂度——Flash Attention 只是工程实现优化，公式不变；(4) 不保证全局最优——它只是"加权平均"操作，是否有效取决于 $W^Q,W^K,W^V$ 是否学到了有意义的子空间。
- **为什么是核心目标**：明确概念的能力边界，是后续所有变体（MLA、KDA、Flash、Linear、Sparse、Block AttnRes）动机的共同起点。
- **依赖内容**：前三个目标的结论；$O(n^2)$ 复杂度的初等概念。

## 1.6 常见误解和适用边界

### 常见误解

1. **误解**：$\sqrt{d_k}$ 是一个"经验调出来的常数"，不缩放也能学。
   **正确**：$\sqrt{d_k}$ 来自方差推导：$q\cdot k$ 在 $q,k$ 各分量方差 1 时方差为 $d_k$，标准差 $\sqrt{d_k}$。Vaswani et al. 2017 §3.2.1 脚注 4 明确给出该推导；论文 §3.2.1 同时报告未缩放点积在大 $d_k$ 下比加性注意力差。除以 $\sqrt{d_k}$ 是把 logit 方差归一到 1，使 softmax 工作在非饱和区。它不是经验常数，但确实假设了"初始化时 $q,k$ 分量方差接近 1"——训练后期该假设可能不严格成立，工程上有用 learnable scale 替代的做法，但本概念页只讲标准形式。
   **形成原因**：论文正文只用一句话"我们怀疑"引出缩放，完整推导藏在脚注里。
   **影响目标**：Q2。

2. **误解**：多头注意力 = "多个独立的注意力模型"。
   **正确**：多头是把 $d_{model}$ 维输入拆成 $h$ 个 $d_{model}/h$ 维子空间，每个子空间做一次注意力；总参数量与单头 $d_{model}$ 维等价（当 $d_k=d_v=d_{model}/h$）。不是"并行多个独立模型"。各头在训练中自然分化，关注不同子空间关系（如语法、共指、位置模式），但论文未保证每个头一定学到可解释的不同关系——有研究显示部分头高度冗余。Vaswani et al. 2017 §3.2.2 只说"允许模型在不同表示子空间中关注不同位置"。
   **形成原因**：把"并行"误读为"独立模型"。
   **影响目标**：Q3。

3. **误解**：$Q,K,V$ 是三种不同的输入数据。
   **正确**：自注意力下 $Q,K,V$ 都来自同一输入 $X$ 的不同线性投影 $XW^Q,XW^K,XW^V$；它们是同一信息在不同子空间的"视角"。交叉注意力下 $K,V$ 来自另一序列，但 $Q$ 仍来自当前序列。$W^Q,W^K,W^V$ 是可学习参数，决定"哪些维度用作查询、哪些用作键、哪些用作值"。
   **形成原因**：把"查询/键/值"的数据库类比理解成"三种不同数据"。
   **影响目标**：Q1, Q2。

4. **误解**：标准注意力"解决了"长程依赖问题。
   **正确**：标准注意力把任意两个位置之间的路径长度从 $O(n)$（RNN）降到 $O(1)$，这是机制上的优势；但它引入了 $O(n^2)$ 的计算与空间复杂度，在长上下文下成为新瓶颈。Linear Attention、Flash Attention、Sparse Attention 都是为缓解这一新瓶颈而提出的变体。标准注意力本身没"解决"长程依赖的工程问题，只是换了问题的形式。
   **形成原因**：把"路径长度 $O(1)$"扩大为"长程依赖彻底解决"。
   **影响目标**：Q4。

5. **误解**：softmax 之后的注意力权重就是"模型在关注哪里"。
   **正确**：softmax 后的 $n\times n$ 矩阵每行是一个概率分布，确实可解释为"第 $i$ 个 query 在 $m$ 个 key 上的注意力分配"。但：(a) 多头下每个头有自己的注意力矩阵，不能只看一个；(b) 训练后的注意力不一定对应人类可解释的"关注"——它可能是多个头冗余或近似均匀分布；(c) 注意力权重不等于"对输出的贡献大小"——还要乘 $V$，值向量模长大时小权重也能产生大贡献。把权重直接当"模型在关注 X"是简化解读。
   **形成原因**：可视化工具默认展示权重矩阵，让人误以为这就是"模型注意力"的全部。
   **影响目标**：Q2, Q3。

### 适用边界

- **解决的问题**：序列中任意两个位置直接交互（路径 $O(1)$）；可并行计算（不像 RNN 必须逐步）；可学习到任务相关的"查询-键"对齐。
- **不解决的问题**：位置信息（需外接 RoPE 等位置编码）；KV cache 压缩（MLA 要解决）；$O(n^2)$ 复杂度（Linear/Flash 要解决）；多头冗余（论文未保证每个头可解释）。
- **成立条件**：(1) $Q,K$ 在同一向量空间（点积有意义）；(2) $d_k$ 足够大使 softmax 不饱和（小 $d_k$ 时缩放可省，但现代模型 $d_k\ge 32$ 都需要）；(3) 训练时 $q,k$ 各分量方差接近 1（缩放推导的隐含假设，BN/LN 后基本成立）。
- **条件不满足时**：(1) $Q,K$ 不在同一空间——点积无意义，需用加性注意力或可学习的相似度函数；(2) 不除 $\sqrt{d_k}$ 且 $d_k$ 大——softmax 饱和、梯度近零、训练崩溃，Vaswani et al. 2017 §3.2.1 已实验确认；(3) 训练后期 $q,k$ 分量方差偏离 1——缩放不再是"单位方差"，但通常仍可用，因为 LN 把激活控制在单位量级。
