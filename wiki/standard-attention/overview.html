标准 Transformer 注意力

让序列每个位置用"查询-键点积 + softmax 归一化 + 对值加权求和"得到上下文相关的表示；是所有现代 Transformer 与其变体（MLA、Flash、Linear、KDA、Block AttnRes 等）共享的基础操作。

更新于 2026-08-09 · 来源：Vaswani et al. 2017

1. 一句话定位

标准 Transformer 注意力（缩放点积注意力，Scaled Dot-Product Attention）是 Vaswani et al. 2017 提出的、让序列中每个位置直接"查询"其它位置的基础操作。公式是 $\text{Attention}(Q,K,V)=\text{softmax}(QK^\top/\sqrt{d_k})V$：用查询向量与键向量的点积算相似度，除以 $\sqrt{d_k}$ 稳定数值，softmax 归一化为权重，对值向量加权求和得到输出。多头版本把 $Q,K,V$ 投影到 $h$ 个子空间分别做注意力再拼接。

2. 为什么需要它

  1. 动态对齐：序列建模中"每个位置要看到其它哪些位置"是随任务变化的（如"it"指代谁、源-目标词对齐）。传统 RNN 靠隐状态逐步传递，相关位置距离 $O(n)$ 步、信息稀释。
  2. 并行计算：RNN 必须串行处理（顺序操作 $O(n)$），无法发挥 GPU 并行算力。标准注意力任意两位置直接交互、整个序列可并行（顺序操作 $O(1)$）。
  3. 路径长度 $O(1)$：CNN 用固定窗口，远距离两位置要堆很多层才能交互（$O(\log_k n)$）；注意力一步到位。
  4. 可学习的对齐：$W^Q,W^K$ 让模型自己学"哪些维度作为查询特征、哪些作为键特征"，比手工设计的对齐函数更灵活。

3. 核心直觉

  • 查询、键、值三个角色。每个位置生成查询 $q$（"我在找什么"）、键 $k$（"我能被什么找到"）、值 $v$（"找到后返回的内容"）。匹配程度由 $q\cdot k$ 的点积衡量——方向一致时大、正交时为零、相反时为负。自注意力下 $Q,K,V$ 同源，都来自同一输入 $X$ 的不同线性投影 $XW^Q,XW^K,XW^V$。
  • softmax 把分数转成概率。每行归一化为和为 1 的非负权重，表示"这个 query 在所有 key 上的注意力分配"。权重高的位置返回的 value 在加权求和时占主导。
  • $\sqrt{d_k}$ 不是经验常数。当 $q,k$ 各分量方差 1 时，点积 $q\cdot k=\sum_i q_i k_i$ 的方差为 $d_k$（$d_k$ 个独立项求和），标准差 $\sqrt{d_k}$。不除以 $\sqrt{d_k}$ 时大 $d_k$ 让 softmax 输入过大、输出近 one-hot、梯度近零、训练崩溃。除以 $\sqrt{d_k}$ 把方差归一到 1。
  • 多头 = 拆分子空间。不是"多个独立模型"，而是把 $d_{model}$ 维输入投影到 $h$ 个 $d_{model}/h$ 维子空间分别做注意力。论文设置 $d_{model}=512$、$h=8$、$d_k=64$，使 $h\cdot d_k=d_{model}$，总参数量与单头 $d_{model}$ 维等价。
  • 因果遮罩。自回归解码时把未来位置分数设为 $-\infty$，softmax 后权重为 0，防止"偷看未来"。

4. 关键结论与边界

  • $O(n^2)$ 瓶颈在 $QK^\top$ 这步。产生 $n\times n$ 矩阵，时间和空间都随序列长度二次增长。$n=32768$ 时矩阵占数 GB 显存。这是 Linear Attention、Flash Attention、Sparse Attention 的共同动机。成立条件：标准实现（非分块 IO 优化）。
  • 注意力本身位置无关。对输入行重排不变（permutation-invariant），位置信息必须由外接位置编码注入。原论文用正弦编码，现代 LLM 多用 RoPE（旋转位置编码）。成立条件：标准注意力；带相对位置偏置的变体（如 T5 bias、ALiBi）改变这一性质。
  • 注意力不压缩 KV。推理时 KV cache 随 $n$ 与头数 $h$ 线性增长，是 MLA（Multi-head Latent Attention）要解决的问题。
  • Flash 与 Linear 的区别：Flash Attention 公式不变，只改 GPU 上的 IO 实现（结果数值等价，更快）；Linear Attention 改公式（用核分解近似 softmax，复杂度 $O(n\cdot d^2)$，$d$ 视为常数时为 $O(n)$，但表达力下降）。
  • 多头"子空间分化"是设计目标，不保证每个头可解释。论文设计是让不同头关注不同关系，但 Michel et al. 2019 报告训练后部分头高度冗余。
  • $\sqrt{d_k}$ 假设 $q,k$ 分量方差接近 1。BN/LN 后基本成立；训练后期可能偏离，但通常仍可用。本页只讲标准形式。
