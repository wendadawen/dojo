    RMSNorm：删掉均值中心化的层归一化

    主要依据：Zhang & Sennrich, Root Mean Square Layer Normalization, arXiv:1910.07467（NeurIPS 2019）；GLM 系列实现（transformers models/glm4_moe/modeling_glm4_moe.py L275-289）与 PyTorch nn.RMSNorm。

    Transformer 每层入口都要归一化一次，这个操作本身也占训练时间。2019 年的一个工作提出：LayerNorm 公式里的「减均值」这一步可以直接删掉——只除以均方根，输出照样有效，运行时间在一系列任务上下降 7% 到 64%[N1]。这个删减版就是 RMSNorm，已被 GLM 系列模型的官方实现采用[C9]。本文讲清它删了什么、为什么敢删、省了多少，以及实现里两处与论文公式不同的细节。

    结构：先拆解 LayerNorm 做的两件事，再看 RMSNorm 保留了哪件，然后是「为什么敢删」的论证与证据，最后算清计算账并核对 GLM 的实现。

    核心问题

    1. LayerNorm 对神经元输入做哪两件事？

      解答：中心化（减均值）与缩放（除标准差）

      对加权和输入 $\mathbf{a}$，LayerNorm 先减去均值 $\mu$（re-centering，使输出零均值），再除以标准差 $\sigma$（re-scaling，使输出单位尺度），最后乘可学习增益、加偏置。两件事的拆解是理解 RMSNorm 取舍的前提。完整公式见「归一化的对象」一章。

    2. RMSNorm 去掉了什么、留下什么？与 LayerNorm 的公式差别在哪？

      解答：去掉减均值，把标准差换成均方根

      RMSNorm 完全不减均值：$\bar{a}_i=a_i/\mathrm{RMS}(\mathbf{a})\cdot g_i$，其中 $\mathrm{RMS}(\mathbf{a})=\sqrt{\frac{1}{n}\sum a_i^2}$ 是对 0 而非对均值的偏差度量。输出不再零均值（正输入的输出全正）；输入恰好零均值时两者完全相等（实测差为 0）。对照见「RMSNorm」一章。

    3. 为什么去掉中心化仍然有效？

      解答：论文假设 re-scaling 才是成功原因，证据链支持

      论文的核心假设是 LayerNorm 的成功来自 re-scaling 不变性而非 re-centering。支持证据：零均值时两者精确相等；RMSNorm 完整保留各类 re-scaling 不变性（只放弃 re-centering 类性质）；实验中 RMSNorm 的激活均值比不归一化的基线更稳定；异常初始化下甚至更鲁棒。注意这是「假设+证据」而非定理。见「为什么敢去掉中心化」一章。

    4. 省了多少计算？实现上要注意什么？

      解答：每维省约 3 次标量运算；实现普遍加 $\varepsilon$ 并在 fp32 里算

      按公式清点，对 $n$ 维输入 LayerNorm 比 RMSNorm 多约 $3n$ 次标量运算（求均值 $n$ 次加法、方差 $n$ 次减法、归一化 $n$ 次减法）；论文实测各任务运行时间下降 7%~64%（Transformer 上 6.9%），幅度依框架、硬件与架构而定。实现细节：论文公式没有 $\varepsilon$，工程实现普遍在分母侧加小常数防除零[C9, C10]；GLM 实现先转到 fp32 计算再转回。见「计算与实现」一章。

    常见误解

    • 「RMSNorm 是 LayerNorm 的近似」——它是精确的不同算子：零均值输入下两者相等，一般输入下输出不同（LayerNorm 输出零均值，RMSNorm 不）。
    • 「去掉中心化会掉精度」——论文各任务质量与 LayerNorm 相当（Transformer 翻译 BLEU 26.8/27.7 对 26.6/27.7）；这是论文实验结论，引用时注明来源。
    • 「论文公式里有 $\varepsilon$」——v1 原文的式 (3)(4) 均无 $\varepsilon$；$\varepsilon$ 是工程实现加的（PyTorch 与 GLM 都加）[C9, C10]。
    • 「7%~64% 的加速可以照搬到任何硬件」——该区间来自 2019 年的 TITAN X / V100 / 2080 Ti 与 TensorFlow/Theano/PyTorch 组合，量级取决于框架与硬件。

    1. 归一化的对象：神经元的加权和

    归一化作用的对象不是网络输入，而是每个神经元自己算出的加权和。一个前向层把输入 $\mathbf{x}\in\mathbb{R}^{m}$ 变成输出 $\mathbf{y}\in\mathbb{R}^{n}$，先算加权和，再过激活[F1]：

    $$a_i = \sum_{j=1}^{m} w_{ij}x_j,\qquad y_i = f(a_i + b_i).$$

    • $a_i$：第 $i$ 个神经元的加权和输入（summed inputs），是归一化要处理的对象；
    • $w_{ij}$：权重矩阵第 $(i,j)$ 个元素；$b_i$：偏置；$f$：逐元素激活函数；
    • $n$：该层神经元数目，即向量 $\mathbf{a}$ 的维度。

    LayerNorm 的做法是在 $f$ 之前插入一步对 $\mathbf{a}$ 的改写[F2]：

    $$\bar{a}_i = \frac{a_i - \mu}{\sigma} g_i,\qquad \mu = \frac{1}{n}\sum_{i=1}^{n} a_i,\qquad \sigma = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(a_i-\mu)^2}.$$

    • $g_i$：逐维可学习增益，初始为 1；之后还常加逐维偏置（记号 $b$，初始 0）；
    • 减去 $\mu$：中心化（re-centering），把输出的均值拉到 0；
    • 除以 $\sigma$：缩放（re-scaling），把输出的尺度拉平。

    这两件事是 LayerNorm 的全部统计操作，也是 RMSNorm 做取舍的对象：保留哪件、删掉哪件。

    本章问题

    1. 「re-centering」和「re-scaling」分别对应公式里的哪一步？

      解答：减 $\mu$ 与除 $\sigma$

      re-centering 指分子里的 $a_i-\mu$：输出减去了均值，分布中心移到 0。re-scaling 指除以 $\sigma$：无论输入整体放大多少倍，输出的尺度被拉回到固定量级（这正是「缩放不变性」的来源）。两者独立：可以只做其一——RMSNorm 就是只做后者的例子。

    2. RMSNorm：只保留缩放

    RMSNorm 把分子里的 $a_i-\mu$ 换成 $a_i$，分母里的 $\sigma$ 相应换成均方根[F3]：

    $$\bar{a}_i = \frac{a_i}{\mathrm{RMS}(\mathbf{a})} g_i,\qquad \mathrm{RMS}(\mathbf{a}) = \sqrt{\frac{1}{n}\sum_{i=1}^{n} a_i^2},$$

    一般形式（把层内从加权和到输出的全过程写在一起）为 $\mathbf{y}=f\bigl(\frac{\mathbf{Wx}}{\mathrm{RMS}(\mathbf{a})}\odot\mathbf{g}+\mathbf{b}\bigr)$，其中 $\odot$ 是逐元素乘[F3]。两个关键差别：

    • 分母的参照点不同。$\sigma$ 度量元素相对均值 $\mu$ 的散布，$\mathrm{RMS}$ 度量相对 0 的散布。当 $\mu\neq0$ 时两者不等价；当 $\mu=0$ 时 $\sigma=\mathrm{RMS}$，两式完全相同[C3]。
    • 输出不再零均值。LayerNorm 的输出均值恒为 0；RMSNorm 没有减均值，输出的均值取决于输入的分布——全正的输入缩放后仍全正。

    计算示例。构造输入 $\mathbf{a}=(1,2,3,4)$（$n=4$）：

    • $\mu=2.5$，$\sigma=\sqrt{\frac{1}{4}\sum(a_i-\mu)^2}=\sqrt{1.25}\approx1.1180$；LayerNorm 输出为 $(-1.3416,-0.4472,0.4472,1.3416)$——零均值、正负对称。
    • $\mathrm{RMS}=\sqrt{\frac{1}{4}\sum a_i^2}=\sqrt{7.5}\approx2.7386$；RMSNorm 输出为 $(0.3651,0.7303,1.0954,1.4606)$——均值约为 0.913，不为 0，且保留了输入「越大输出越大」的相对结构[F5]。

    再看零均值的对照：$\mathbf{a}_0=(1,-1,3,-3)$ 恰有 $\mu=0$，此时 $\sigma=\mathrm{RMS}$，LayerNorm 与 RMSNorm 的输出完全相同（实测最大差为 0）[F5]。这个等价是第 3 章论证「敢删」的第一块基石。

    代码：LayerNorm 与 RMSNorm 的对照实现 
    import torch

def layernorm(a):
    mu = a.mean()
    sigma = ((a - mu) ** 2).mean().sqrt()
    return (a - mu) / sigma

def rmsnorm(a):
    rms = (a ** 2).mean().sqrt()
    return a / rms

a = torch.tensor([1.0, 2.0, 3.0, 4.0])
print("输入:", a.tolist())
print("LayerNorm: mu =", round(float(a.mean()), 4),
      ", sigma =", round(float(((a - a.mean()) ** 2).mean().sqrt()), 4))
print("  输出:", [round(v, 6) for v in layernorm(a).tolist()])
print("RMSNorm:   RMS =", round(float((a ** 2).mean().sqrt()), 4))
print("  输出:", [round(v, 6) for v in rmsnorm(a).tolist()])

a0 = torch.tensor([1.0, -1.0, 3.0, -3.0])
print("零均值输入:", a0.tolist())
print("  两者最大差:", float((layernorm(a0) - rmsnorm(a0)).abs().max()))

    预期输出：

    输入: [1.0, 2.0, 3.0, 4.0]
LayerNorm: mu = 2.5 , sigma = 1.118
  输出: [-1.341641, -0.447214, 0.447214, 1.341641]
RMSNorm:   RMS = 2.7386
  输出: [0.365148, 0.730297, 1.095445, 1.460593]
零均值输入: [1.0, -1.0, 3.0, -3.0]
  两者最大差: 0.0

    验证的机制：两个函数分别按论文式 (2)(3) 与式 (4) 实现，分母一个对 $\mu$ 一个对 0。

    观察重点：一般输入（$\mu\neq0$）下输出不同——LayerNorm 零均值、RMSNorm 保留输入的偏移；零均值输入下两者精确相等（差 0.0）。

    简化条件：增益 $g$ 与偏置 $b$ 都省略（等价于 $g=1$、$b=0$），不影响两式的对照关系。

    本章问题

    1. 「RMSNorm 输出零均值」对吗？什么条件下它与 LayerNorm 精确相等？

      解答：不对；输入零均值时精确相等

      RMSNorm 没有减均值操作，输出均值由输入分布决定（例中约为 0.913），不恒为零——「零均值」是 LayerNorm 特有的性质。当输入恰好零均值时，$\sigma$ 与 $\mathrm{RMS}$ 的定义重合，两个公式逐元素相同；实测 $(1,-1,3,-3)$ 上最大差为 0。这也是论文说「当加权和均值为零时 RMSNorm 与 LayerNorm 完全相等」的具体含义[C3]。

    3. 为什么敢去掉中心化

    删掉一半的统计操作，自然要回答「为什么没问题」。论文的处理是提出假设再用多路证据支持，不是给出定理[C2]。

    假设：LayerNorm 成功的原因是 re-scaling 不变性，而非 re-centering 不变性。原文的表述是「我们认为均值归一化并不降低隐藏状态或梯度的方差，因此它对 LayerNorm 的成功影响很小」[C2]。

    证据一：零均值等价。输入零均值时 RMSNorm 与 LayerNorm 完全相等（第 2 章实测）——两种归一化的差距只在输入有偏移时才存在，而偏移本身对训练的影响是可质疑的。

    证据二：不变性的完整保留。论文系统对比了两种方法的不变性集合（其 Table 1）：RMSNorm 完整保留 LayerNorm 对权重矩阵缩放、数据集缩放、单样本缩放的不变性，放弃的只有 re-centering 相关的性质。按假设，被放弃的恰好是不重要的那部分。

    证据三：均值的实际稳定性。一个自然的质疑是「不归一化均值，均值会不会失控」。论文在机器翻译模型的解码器里实测（其 Table 5）：RMSNorm 的激活均值随 token 位置从 $-0.40$ 漂移到 $-0.74$，比不归一化的基线（$-2.60$ 到 $-1.19$）稳定得多，原文的结论是「RMSNorm 的均值虽未归一化，但实践中比基线的均值更稳定」；论文同时指出，RMSNorm 与 LayerNorm 都稳定了标准差。论文的文字只把 RMSNorm 的均值与基线对比，未对 LayerNorm 的均值作相当性判断[C6, N2]。

    证据四：质量与鲁棒性。各任务上 RMSNorm 的质量与 LayerNorm 相当（论文的 Transformer 翻译实验：BLEU 26.8/27.7 对 LayerNorm 的 26.6/27.7；不归一化的 Transformer 完全训不动）[C8]。异常初始化（中心改为 0.2）下 RMSNorm 表现不差于 LayerNorm 甚至更稳[C7]。

    补充：隐式学习率自适应——梯度视角的论据

    论文的梯度分析（其式 8-10）给出两个观察：损失对增益 $g$ 的梯度正比于归一化后的（而非原始的）输入，这让 $g$ 的幅度不受输入尺度影响；损失对权重 $\mathbf{W}$ 的梯度里出现一个与权重缩放负相关的矩阵项——权重大时有效步长自动变小，论文称之为「隐式学习率自适应」，并援引 Santurkar 等人的观点：归一化的成功更多来自优化曲面变平滑，而非层输入统计本身的稳定[C5]。这些分析同样不依赖中心化项。

    本章问题

    1. 「删掉中心化有效」的论证结构是什么？它是定理吗？

      解答：假设加四路证据，不是定理

      结构是：先提出「re-scaling 才是成功原因」的假设，再用四路证据支持——零均值等价、不变性集合只减不改、激活均值实测稳定（比不归一化的基线）、质量与鲁棒性相当。论文没有证明「任何网络删掉中心化都不掉精度」，证据也都是具体任务上的实验；所以正确表述是「有假设与实验支持，未构成定理」，引用时保持这个分寸。

    4. 计算与实现

    省了多少运算。按公式清点（这是本页的推导，论文原文没有逐项计数）：对 $n$ 维输入，LayerNorm 相比 RMSNorm 多出的标量运算是约 $3n$ 次——求 $\mu$ 需要 $n$ 次加法；方差 $\sum(a_i-\mu)^2$ 里每个元素一次减法共 $n$ 次；归一化分子 $a_i-\mu$ 又是 $n$ 次减法。其余部分（$n$ 次平方、$n$ 次求和、开方、除法、增益乘）两者相同[F4]。

    实测收益。论文在多种框架与硬件上测运行时间（其 Table 2/3/4/6/8/10）[N1]：

    任务 / 模型框架 / 硬件RMSNorm 加速
    机器翻译（RNN）TensorFlow / TITAN X24.7%
    机器翻译（RNN）Theano / TITAN X34.0%
    机器翻译（RNN）PyTorch / TITAN X11.0%
    TransformerTensorFlow / V1006.9%
    阅读理解Theano / TITAN X15.1%
    图文检索Theano / TITAN X40.8%
    CIFAR-10 CNNRTX 2080 Ti20.5%

    同一个算子在不同组合下加速 6.9% 到 40.8%（摘要汇总的全部实验连同变体 pRMSNorm 计为 7%~64%）——量级取决于框架、硬件与架构，表中数字不可直接搬到当代硬件。

    实现的两处细节。其一，论文 v1 的式 (3)(4) 里没有 $\varepsilon$，直接除以 $\sigma$ 或 RMS；工程实现普遍加一个小常数防除零——PyTorch 的 nn.RMSNorm 与 GLM 都把它加在根号内（即 $\sqrt{\varepsilon+\frac{1}{n}\sum_{i=1}^{n}x_i^2}$），仅默认值不同：PyTorch 取 torch.finfo(x.dtype).eps，GLM 的 rms_norm_eps 取 $10^{-5}$[C9, C10]。其二，GLM 的实现先把输入转到 fp32 计算（归一化对精度敏感），完成后再转回原 dtype，可学习的权重乘在转回之后[C9]。

    代码：与 torch 官方实现对齐，并复现 GLM 式实现 
    import torch

ref = torch.nn.RMSNorm(4, eps=0.0)
with torch.no_grad():
    ref.weight.fill_(1.0)
a = torch.tensor([1.0, 2.0, 3.0, 4.0])
print("torch.nn.RMSNorm 输出:",
      [round(v, 6) for v in ref(a).tolist()])

def glm_rmsnorm(x, weight, eps):
    x32 = x.to(torch.float32)                    # fp32 里算
    var = x32.pow(2).mean(-1, keepdim=True)
    x32 = x32 * torch.rsqrt(var + eps)           # 分母加 eps
    return weight * x32.to(x.dtype)              # 权重乘在转回后

w = torch.ones(4)
print("GLM 式（fp32 + eps=1e-5）输出:",
      [round(v, 6) for v in glm_rmsnorm(a, w, 1e-5).tolist()])

    预期输出：

    torch.nn.RMSNorm 输出: [0.365148, 0.730297, 1.095445, 1.460593]
GLM 式（fp32 + eps=1e-5）输出: [0.365148, 0.730296, 1.095444, 1.460593]

    验证的机制：torch.nn.RMSNorm（eps 取 0、权重取 1）与手写公式输出一致（差 $1.2\times10^{-7}$，浮点舍入级别）；GLM 式实现多了 fp32 转换与 $\varepsilon=10^{-5}$，与论文公式的差为 $9.5\times10^{-7}$[F5]。

    观察重点：$\varepsilon$ 的影响在 $10^{-7}$ 量级（输入尺度为 1 时）；工程上加它不是为了精度而是为了除零安全。GLM 配置的 rms_norm_eps 为 $10^{-5}$[C9]。

    简化条件：fp32 转换在 float32 输入上是恒等操作，此处只为展示结构；真实模型输入常为 bf16，转换的作用才显现。

    本章问题

    1. 「$3n$ 次运算」和「7%~64%」这两个数字的性质有什么不同？

      解答：一个是推导一个是实测

      $3n$ 是按公式逐步清点得到的运算量差（本页推导，论文未给此计数），对确定的 $n$ 是精确的；7%~64% 是论文在 2019 年的框架与硬件组合上测的运行时间变化，依赖环境，只能作为量级参考。引用时前者标注「推导」、后者标注「实测及其条件」，不可混用。

    2. 论文公式与工程实现有哪些已知出入？

      解答：$\varepsilon$ 的有无与计算精度

      论文 v1 的式 (3)(4) 不含 $\varepsilon$；PyTorch 与 GLM 的实现都在根号内加了小常数（PyTorch 默认取 torch.finfo(x.dtype).eps，GLM 取 $10^{-5}$），目的是数值安全而非改变定义[C9, C10]。GLM 另外把统计量计算放进 fp32、完成后转回原精度、可学习权重乘在转回之后——这三点是实现选择，论文未规定。把「论文公式」与「实现行为」分开陈述可以避免把实现细节误当成定义的一部分。

    • 「删掉一半统计操作」指删掉中心化这一件事，不是字面的一半计算量——运算量差约 $3n$ 次，占比取决于 $n$ 与实现。
