# glossary.md：RMSNorm

| 术语/符号 | 首次出现 | 含义 |
|---|---|---|
| 加权和输入 $a_i$ / summed inputs | 第 1 章 | 神经元对输入的线性组合结果，归一化的作用对象 |
| $n$ | 第 1 章 | 该层神经元数目（向量 $\mathbf{a}$ 的维度） |
| $\mu$ | 第 1 章 | $\mathbf{a}$ 的均值 |
| $\sigma$ | 第 1 章 | $\mathbf{a}$ 的标准差（对 μ 的偏差） |
| 增益 $g_i$ | 第 1 章 | 逐维度可学习缩放，初始 1 |
| 偏置 $b_i$ | 第 1 章 | 逐维度可学习平移，初始 0 |
| re-centering（中心化） | 第 1 章 | 减均值使输出均值为 0 的操作 |
| re-scaling（缩放） | 第 1 章 | 除以统计量使输出尺度归一的操作 |
| RMS（均方根） | 第 2 章 | $\sqrt{\frac{1}{n}\sum a_i^2}$，对 0 而非对 μ |
| re-scaling 不变性 | 第 3 章 | 输入/权重整体放大 k 倍时（归一化后）输出不变的性质 |
| pRMSNorm | 第 3 章一句 | 用前 p% 元素估计 RMS 的变体，本页不展开 |
| ε | 第 4 章 | 实现中加在分母上的小常数，防除零；论文公式无此项 |
| Pre-Norm | 第 1 章语境 | 归一化放在残差分支入口的结构，RMSNorm 常用位置 |
