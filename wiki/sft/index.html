    SFT（Supervised Fine-Tuning）：用指令-回答数据教预训练模型按指令回答

    主要依据：Ouyang et al., "Training language models to follow instructions with human feedback"（InstructGPT, arXiv:2203.02155）§1、§3.1、§3.2、§3.5；Zhang et al., "Instruction Tuning for Large Language Models: A Survey"（arXiv:2308.10792）摘要、脚注 1、§1；Touvron et al., "Llama 2"（arXiv:2307.09288）§3.1。

    给一个预训练语言模型输入「请把这句话翻译成法语：时间就是金钱」，它没有输出译文，而是继续生成下一行类似格式的请求——因为在预训练语料里，这句文本后面跟着的通常是更多网页文本。模型学到的技能里没有「这是在对我提问」。SFT（Supervised Fine-Tuning，监督微调；综述将该术语与 instruction tuning「指令微调」互换使用[C1]）补上这一课：把大量「指令 + 人类写下的期望回答」作为训练数据，在预训练模型上继续训练，让「按指令回答」成为参数里的默认行为。本文说明 SFT 为什么必要、数据与训练目标的具体形态、一条样本的损失如何手算、它在后训练流程中的位置，以及实践中的边界与常见误解。

    核心问题

    1. 预训练模型为什么需要 SFT？

      解答：预训练目标与用户目标错位，SFT 用示范数据直接训练期望行为

      预训练在大语料上最小化下一词预测误差，用户想要的是「遵循指令、有帮助且安全」——两者错位，使预训练模型对指令的默认反应是续写而非回答。few-shot 提示能在上下文里临时改善行为但不改参数。SFT 用「指令-回答」标注数据继续训练，把期望行为写进参数。完整论证见「1. 预训练目标与用户目标的错位」。

    2. SFT 的数据和训练目标具体是什么？

      解答：(instruction, output) 对 + 因果语言模型交叉熵，损失通常只算在回答 token 上

      数据是 (instruction, output) 对（多轮对话样本把此前轮次并入条件）；训练沿用下一 token 交叉熵目标，teacher forcing 下逐 token 计算。常见实现把指令部分 token 的损失置零、只在回答 token 上反向传播（loss masking）：指令是条件，回答才是要学的内容。完整论证见「2. SFT 的数据与训练目标」。

    3. 一条 SFT 训练样本的损失如何手算？

      解答：对回答的每个 token 算 $-\log p_\theta(y_t\mid x, y_{<t})$ 再求平均

      teacher forcing 下样本拼接成一条序列，每个回答 token 的损失是该 token 条件概率的负对数；样本损失是这些值的平均。mask 与不 mask 的平均分母不同（回答 token 数 vs 全序列 token 数），数值差异显著：构造示例中 mask 版平均 $0.6547$、不 mask 版 $2.5645$。手算见「3. 手算一条 SFT 样本的损失」。

    4. SFT 在后训练流程中处于什么位置，它与偏好优化如何分工？

      解答：三步流程的第一步；SFT 教模仿示范，偏好优化处理回答间的优劣

      标准后训练流程为 SFT $\to$ 奖励模型 $\to$ 偏好优化（InstructGPT 三步法）。SFT 用示范数据训练初始策略，奖励模型用比较数据学习打分，偏好优化再对奖励优化策略。分工的根源在损失的表达能力：SFT 的监督损失只有「数据里那个回答」的似然项，没有「A 回答比 B 好」的比较项。完整论证见「4. SFT 在后训练流程中的位置」。

    5. SFT 有哪些实践边界与常见误解？

      解答：不限定参数更新方式；数据质量重于数量；验证损失过拟合不等于该停

      四个边界：①SFT 刻画数据与目标，全参数或 LoRA 等参数高效方式都可承载；②数据不是越多越好——Llama 2 用 27,540 条高质量标注达到高质量结果，放弃了数百万第三方数据；③InstructGPT 的 SFT 在 1 epoch 后验证损失即过拟合，但训满 16 epochs 反而带来更高的奖励模型分数与人类偏好评分；④完整后训练后的 1.3B 模型输出被人类偏好于 GPT-3 175B——两者架构相同，唯一区别是人类数据微调。完整论证见「5. 实践中的边界与误解」。

    1. 预训练目标与用户目标的错位

    SFT 的必要性要从预训练模型的来历讲起。语言模型预训练在大规模无标注语料上最小化下一 token 的交叉熵，机制见 语言模型预训练。这个目标塑造的能力是「续写」：模型学到的是「前文之后通常跟着什么」。指令微调综述对错位的表述是：语言模型通常被训练为在大语料上最小化上下文词预测误差，而用户想要的是模型「遵循指令、有帮助且安全」[C2]。

    错位在行为上的表现就是开头场景：指令文本进入模型后，模型按语料分布续写。训练数据与期望回答的对照是：

    预训练语料SFT 数据
    同一段指令文本后面跟着更多任意文本（网页的下一行）人类标注者写下的期望回答
    模型被训练去做的事按语料风格续写给定指令，产出回答

    不改参数的替代方案存在但不充分：few-shot prompting 在输入中给出任务的若干示例，可以引导模型在当前上下文内完成任务，但参数没有更新——InstructGPT 的对比里，给 GPT-3 加上 few-shot 提示后，小一百多倍参数的完整后训练模型，其输出仍被人类偏好于 GPT-3[C7]；示例还持续占用上下文长度。SFT 的做法更直接——用梯度更新把「指令 $\to$ 回答」变成模型的默认行为。综述列举了 SFT 的三重收益：弥合下一词预测目标与指令遵循之间的差距；让模型行为更可控、更可预测；计算高效——无需大规模重训或修改架构即可快速适配特定领域[C8]。

    本章问题

    1. 预训练模型的训练目标是什么，它与用户想要的行为差在哪里？

      解答：目标是词预测误差最小化，用户要的是指令遵循，两者错位

      预训练目标是在大语料上最小化上下文词预测误差（下一 token 交叉熵）；用户目标是「遵循指令、有帮助且安全」（综述原文表述）。错位的结果：模型面对指令的自然反应是按语料风格续写——在训练分布里，这句请求后面是更多网页文本，不是译文。能力（语言、知识）已经具备，缺的是「把这段文本当作对我的提问」的行为方式。

    2. few-shot prompting 不改参数也能让模型「像样」一些，为什么还需要 SFT？

      解答：few-shot 的行为改变只在当前上下文内生效，SFT 把行为写进参数

      few-shot prompting 在输入中给出任务的若干示例，可以引导模型在当前上下文内完成任务，但参数没有任何更新：换一个不带示例的输入，行为回到基座默认；InstructGPT 的对比中给 GPT-3 加 few-shot 提示也无法追上完整后训练的小模型；示例还持续占用上下文长度。SFT 用「指令-回答」数据做梯度更新，让按指令回答成为不依赖上下文示例的默认行为，同时让模型行为更可控、更可预测（综述对 SFT 收益的表述）。

    2. SFT 的数据与训练目标

    有了动机，现在看 SFT 到底用什么、怎么训。数据形态由综述给出：在由 (instruction, output) 对组成的数据集上以监督方式继续训练语言模型，其中 instruction 是人类的指令、output 是遵循指令的期望输出[C1]。一条翻译样本形如 $x=$「请把这句话翻译成法语：时间就是金钱」，$y=$「Le temps, c'est de l'argent」。多轮对话样本是它的扩展：把此前的轮次并入条件部分，要学的输出是其中的助手回复（哪些回复计入损失因实现而异）。一个具体做法来自 Llama 2 的多轮一致性训练（GAtt 方法）：把此前所有轮次（含此前的助手消息）的 token 损失置零，只训最后一轮的回复[C4]。

    训练目标没有发明新东西——沿用因果语言模型的下一 token 交叉熵（其定义与手算见 交叉熵）：

    $$\mathcal{L}(\theta) = -\frac{1}{|D|}\sum_{(x,y)\in D}\frac{1}{|y|}\sum_{t=1}^{|y|} \log p_\theta(y_t \mid x, y_{
  • $D$：SFT 训练集，元素为「指令-回答」对 $(x, y)$；
  • $y_t$：回答的第 $t$ 个 token，$y_{<t}$ 是它之前的前缀（含指令 $x$）；
  • $p_\theta(y_t\mid x, y_{<t})$：参数为 $\theta$ 的模型在给定指令与回答前缀下，赋予下一个回答 token 的概率。

    • 与预训练的差别在条件与前缀的构成：$x$ 是指令而非普通上文。训练采用 teacher forcing：每个位置用真实的前缀（指令 + 已写下的回答前缀）作条件，不需要模型自己生成——一条样本一次前向就能算出所有位置的损失。

    实践中样本要拼接成序列。Llama 2 的描述是：每个样本由 prompt 与 answer 组成，训练集的所有 prompt 和 answer 被拼接、用特殊 token 分隔以填充序列长度[C4]。紧接着是本页最关键的一句原文：采用自回归目标，把用户 prompt 部分 token 的损失置零，因此只在回答 token 上反向传播[C4]。这个做法称为损失掩码（loss masking）。

    为什么 mask？回到公式：要学的是 $p_\theta(y_t\mid x, y_{<t})$——「给定指令，产出回答」。指令 $x$ 在这里是条件，不是要学的内容；模型不需要被训练去预测「指令的下一个 token 是什么」。不 mask 时，模型同时在学两件事：生成类似指令的文本，与给定指令生成回答；而指令在样本里往往占多数 token，梯度的大部分被「学写指令」占据（下一章的手算会给出具体比例）。

    现在把贯穿示例定下来。构造示例：玩具词表 {翻译, :, cat, 猫, 狗, <eos>}（每个符号视为一个 token）。一条训练样本：指令 $x=$ [翻译, :, cat]，回答 $y=$ [猫, <eos>]，其中 <eos> 是标记回答结束的特殊 token。训练时拼接成序列：

    位置token所属损失是否计入
    $1$翻译指令 $x$否（mask）
    $2$:指令 $x$否（mask）
    $3$cat指令 $x$否（mask）
    $4$猫回答 $y$是
    $5$<eos>回答 $y$是

    模型对每个位置的下一 token 分布在下一章给出并手算。

    本章问题

    1. SFT 的训练数据长什么样？

      解答：(instruction, output) 对；多轮对话是它的扩展

      数据集由 (instruction, output) 对组成：instruction 是人类指令，output 是遵循指令的期望输出（综述定义）。一条翻译样本：$x=$「请把这句话翻译成法语：时间就是金钱」，$y=$ 译文。多轮对话样本把此前轮次并入条件部分，要学的输出是其中的助手回复（哪些回复计入损失因实现而异，例如 Llama 2 的多轮一致性训练只训最后一轮回复）。实践中 prompt 与 answer 拼接、以特殊 token 分隔（Llama 2）。

    2. SFT 的损失怎么算——为什么沿用下一 token 交叉熵，损失算在哪些 token 上？

      解答：沿用因果语言模型交叉熵；常见做法对指令部分置零，只在回答 token 上反向传播

      损失为 $\mathcal{L}(\theta)=-\frac{1}{|D|}\sum_{(x,y)}\frac{1}{|y|}\sum_t\log p_\theta(y_t\mid x, y_{<t})$：与预训练同一下一 token 交叉熵，条件换成指令。teacher forcing 使一条样本一次前向即可算全部位置。常见做法（Llama 2 原文："zero-out the loss on tokens from the user prompt, so as a result, we backpropagate only on answer tokens"）把指令部分损失置零：指令是条件、不是要学的内容，模型不应因「指令文本的下一词」被训练。

    3. 把指令部分也计入损失，和只算回答部分，差别是什么？

      解答：不 mask 时模型同时在学「生成指令」与「生成回答」，梯度大量流向前者

      SFT 要学的是 $p_\theta(y_t\mid x, y_{<t})$：给定指令产出回答。指令 token 的预测误差与这个目标无关；不 mask 时，序列上指令常占多数 token，总梯度被「学写指令」占据，监督信号被稀释。mask 把梯度集中在「给定指令，产出回答」上。数值对比（构造示例：指令 3 token、回答 2 token，指令部分损失占总损失的 $89.8\%$）见「3. 手算一条 SFT 样本的损失」。

    3. 手算一条 SFT 样本的损失

    沿用上一章的构造样本：序列 [翻译, :, cat, 猫, <eos>]，指令 3 个 token、回答 2 个 token。teacher forcing 下，模型对每个位置输出下一 token 分布；构造各位置「真实下一 token」的概率如下（其余概率分给词表其他 token，分布合计为 $1$）：

    位置条件（真实前缀）真实下一 token模型赋予的概率该位置损失 $-\ln p$
    $1$（句首）翻译$0.01$$4.6052$
    $2$翻译:$0.05$$2.9957$
    $3$翻译:cat$0.02$$3.9120$
    $4$翻译:cat猫$0.30$$1.2040$
    $5$翻译:cat猫<eos>$0.90$$0.1054$

    按「只在回答 token 上计算」的做法，样本损失是位置 $4$、$5$ 两个值的平均：

    $$\ell_{\text{mask}} = \frac{1.2040 + 0.1054}{2} \approx 0.6547.$$

    若不 mask、对全部 $5$ 个位置平均：

    $$\ell_{\text{no-mask}} = \frac{4.6052 + 2.9957 + 3.9120 + 1.2040 + 0.1054}{5} \approx 2.5645.$$

    两个数的对比说明两件事。第一，mask 改变的是「平均的分母」与「梯度的去向」：mask 版只由回答 token 构成，不 mask 版被指令部分主导——本例中指令 3 个 token 的损失合计 $11.5129$，占总损失 $12.8223$ 的 $89.8\%$，若不 mask，梯度的绝大部分花在「预测指令的下一 token」上。第二，「SFT 报告的损失值」取决于 mask 策略：比较两个实现或两次训练的损失数字时，先确认它们的分母一致。

    这个数值例子同时展示了 SFT 训练动态的直觉：训练会把位置 $4$ 的 $0.30$（以及位置 $5$ 的 $0.90$）往上推——因为损失只在这两个位置产生梯度。位置 $1$–$3$ 的概率无论多低，都不影响参数更新。

    展开：本例五个位置的完整对数计算

    构造示例，全部由自然对数计算：$-\ln 0.01 = 4.6052$，$-\ln 0.05 = 2.9957$，$-\ln 0.02 = 3.9120$，$-\ln 0.30 = 1.2040$，$-\ln 0.90 = 0.1054$。可复算：$e^{-4.6052}\approx 0.01$，$e^{-1.2040}\approx 0.30$。mask 版合计 $1.2040+0.1054=1.3093$，平均 $1.3093/2=0.6547$；不 mask 版合计 $12.8223$，平均 $12.8223/5=2.5645$；指令部分合计 $4.6052+2.9957+3.9120=11.5129$，占比 $11.5129/12.8223\approx 89.8\%$。

    本章问题

    1. 给定玩具词表和一条「指令-回答」样本，每个回答 token 的损失是多少，整条样本的损失是多少？

      解答：逐 token 算 $-\ln p$，回答部分平均得 $0.6547$

      构造样本 [翻译, :, cat, 猫, <eos>]：位置 $4$（真实 token「猫」，模型概率 $0.30$）损失 $-\ln 0.30=1.2040$；位置 $5$（真实 token「<eos>」，概率 $0.90$）损失 $0.1054$。mask 版样本损失为两者平均 $(1.2040+0.1054)/2\approx 0.6547$；指令部分的位置 $1$–$3$ 不进入损失。

    2. mask 前后，这条样本的平均损失数值如何变化？

      解答：$0.6547$ 对 $2.5645$；差异来自分母与梯度的去向

      mask 版平均 $0.6547$（分母为 $2$ 个回答 token）；不 mask 版平均 $2.5645$（分母为全部 $5$ 个 token）。不 mask 时指令部分损失合计 $11.5129$、占总损失 $89.8\%$——梯度主要花在预测指令的下一 token 上，偏离「给定指令产出回答」的训练意图。两个数字不可直接比较：先确认 mask 策略一致。

    4. SFT 在后训练流程中的位置

    SFT 很少单独出现——它是后训练流程的第一步。InstructGPT 把经典流程描述为三步[C3]：

    三步各自的数据类型不同：SFT 用「标注者写下的示范」，RM 用「同一指令下多个输出的排序」，偏好优化用 RM 的奖励信号。SFT 的产物是后续两步的起点——InstructGPT 的奖励模型正是「从 SFT 模型出发、去掉最后的输出层」训练的[C3]。

    为什么必须有分工？回到损失的表达能力。SFT 的监督损失只有一项：数据里那个回答 $y$ 的似然 $\log p_\theta(y\mid x)$。它教模型「像示范那样回答」，但没有任何一项在表达「回答 A 比回答 B 好」——两个都流利、都完成任务的回答，在 SFT 损失里没有高下之分，除非其中一个作为示范出现在数据里。「多个可接受回答之间的优劣排序」需要比较数据与相对目标，这正是奖励模型与偏好优化承担的部分。

    用贯穿示例说明：SFT 之后，模型对指令「翻译:cat」的两个候选——A「猫 <eos>」与 B「狗 <eos>」——各有概率。SFT 数据里只有「猫」，训练把概率质量推向「猫」，B 的概率作为副作用被压低。但这只是「像不像数据里的答案」的分辨，不是质量判断：若 A 与 B 都是合格的译文（同义词都接受），SFT 损失无法表达「A 稍好一些」；若两个候选都不在数据里，SFT 对它们之间的排序无话可说。比较与排序需要第二步往后的机制。

    本章问题

    1. 完整后训练流程有几步，SFT 在哪一步？

      解答：三步——SFT、奖励模型、偏好优化；SFT 是第一步

      InstructGPT 三步法：第一步收集示范数据、用监督学习微调预训练模型（SFT）；第二步收集比较数据、训练奖励模型；第三步以 RM 输出为奖励、用 PPO 优化策略；第二、三步可循环迭代。SFT 产物是后续步骤的初始策略（RM「从 SFT 模型出发」训练）。偏好优化也可用 DPO 等直接对齐算法替代后两步，本页不展开。

    2. 有了 SFT 为什么还要偏好优化——示范数据教不了什么？

      解答：监督损失没有「回答间优劣排序」的项

      SFT 损失只含数据中回答的似然 $\log p_\theta(y\mid x)$：它教模型模仿示范、把概率推向数据里的答案，但没有一项表达「A 回答比 B 好」。多个都可接受的回答之间的细粒度优劣、以及不在数据中的候选的质量排序，都需要比较数据与相对目标（奖励模型 + 偏好优化）。构造示例中，SFT 压低「狗」是因为它不像数据答案，而非对译文质量作出判断。

    5. 实践中的边界与误解

    最后处理四个使用 SFT 时最容易做错决策的点。前三个有论文原文支撑，第四个来自 InstructGPT 的评测结论。

    5.1 SFT 不限定参数更新方式

    SFT 刻画的是数据（标注的指令-回答对）与目标（模仿示范的监督损失），不规定参数怎么更新。全参数微调更新模型全部权重；LoRA 等参数高效方法冻结主体、只训练少量新增参数——两者承载的都是同一个 SFT 目标。把 SFT 等同于「全参数微调」会错估它的适用范围。

    5.2 数据不是越多越好

    Llama 2 的经验是：数万条量级的 SFT 标注即可达到高质量结果，团队在收集到 $27{,}540$ 条标注后停止标注；同时放弃了数百万条第三方数据集的样本，改用少量自产的高质量标注，结果显著变好[C5][N3]。这与预训练「数据越多越好」的直觉相反：SFT 教的是行为方式，示范的质量与多样性比数量更关键。

    5.3 验证损失过拟合不等于该停止训练

    InstructGPT 的 SFT 训了 $16$ epochs（epoch：训练数据完整过一遍；余弦学习率衰减：学习率随训练按余弦曲线逐步下降；residual dropout $0.2$：一种随机置零部分连接的正则化手段），并且观察到：SFT 模型在 $1$ epoch 后验证损失就过拟合，但训练更多 epoch 同时提升了奖励模型分数与人类偏好评分[C6][N2]。验证损失与下游偏好不是同一把尺子——预训练阶段「验证损失回升就早停」的直觉不能直接搬到 SFT。

    5.4 后训练改变的是行为方式

    InstructGPT 的主要发现（§1）：$1.3$B 参数的 InstructGPT（完整后训练产物，含 SFT 与后续偏好优化）输出被人类偏好于 $175$B 的 GPT-3——两个模型架构相同，唯一区别是 InstructGPT 在人类数据上做了微调，且这一结论在给 GPT-3 加上 few-shot 提示后仍然成立[C7]。参数量少一百多倍的模型在人类偏好上反超；由于两个模型唯一的人类数据微调之别，这个对比支持「后训练（SFT 为其起点）改变的是行为方式」的判断——参数内部具体发生了什么变化，不在本页范围。

    本章问题

    1. SFT 对参数更新方式有要求吗？

      解答：没有；全参数与参数高效方式都可承载 SFT

      SFT 的定义要素是数据（标注的指令-回答对）与目标（模仿示范的监督损失）。全参数微调与 LoRA 等参数高效微调的差别只在「更新哪些参数」，两者执行的都是同一个 SFT 目标。认为「SFT 就是全参数微调」是把实现选择误当成了定义。

    2. SFT 数据是不是越多越好？验证损失开始过拟合，是否应该停止训练？

      解答：都不是——质量重于数量；验证损失与下游偏好不是同一指标

      数据：Llama 2 发现数万条高质量标注即可达到高质量结果，在 $27{,}540$ 条后停止标注，并放弃数百万条第三方样本改用少量自产高质量数据，结果显著变好——SFT 教行为方式，示范质量与多样性比数量关键。停止时机：InstructGPT 的 SFT 在 $1$ epoch 后验证损失即过拟合，训满 $16$ epochs 反而带来更高的 RM 分数与人类偏好评分——验证损失不是下游偏好的替代指标，早停直觉不可直接搬用。

    辅助解释与类比边界

    • 「SFT 把行为写进参数」表述的是训练结果（参数更新使按指令回答成为默认行为），不涉及参数内部「存储」了什么知识或行为的具体机制。
    • 「梯度的大部分被学写指令占据」按本页构造示例的数值（$89.8\%$）说明方向；真实样本的指令/回答占比各不相同，具体比例随数据变化。

    简化条件及其限制

    • 损失掩码以 Llama 2 的实现为据，作为「常见做法」呈现，不表述为 SFT 定义的必然组成部分；存在不对指令置零的实现选择，本页未展开。
    • 偏好优化（PPO、DPO 及奖励模型训练）的机制全部作为黑盒引用，分工定位基于「监督损失只有数据答案的似然项」这一公式事实；关于各偏好优化算法的结论需另页论证。
    • LoRA/参数高效微调仅作边界说明，未展开其机制与适用条件。
    • 构造示例直接给定各位置概率，跳过模型内部计算；示例验证损失与 mask 的机制，不验证训练动态。
