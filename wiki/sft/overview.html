概念概览 · 训练

监督微调

监督微调（SFT）是在一个已经会做下一 token 预测、还没学过按指令作答的模型上，用人工写好的「指令—回答」标注数据继续训练，让模型从「接着续写」变成「按指令作答」。

在示范数据上继续训练

监督微调（SFT）是在一个预训练模型（在大批文本上训练过下一 token 预测、还没按指令调过的模型）上，用人工写好的「指令—回答」对继续训练。文本先被切成 token（模型读写文字的基本单位），训练目标仍是下一 token 预测：把一条样本的指令和回答拼成序列，逐位置预测下一个 token，与真实 token 比交叉熵（衡量两个概率分布差多少的量，见交叉熵），要最小化的就是这个量，叫损失。继续这个目标，就是把「看到指令该给出什么回答」写进模型的参数。

续写不是回答

预训练模型的训练目标是在网页文本上预测下一个 token，用户要的是遵循指令、有帮助且安全，两者不同。在输入里给几个例子能让模型照着模仿，但这只用当前这段输入，不改模型参数。SFT 换用示范数据继续训练，让模型收到指令时作答。

损失只算在回答上

SFT 的一条样本是指令加回答；多条拼接成固定长度的序列，指令段与回答段之间用一个特殊 token 分隔。训练时把指令段 token 上的损失置零，梯度只从回答 token 回传，模型学的是「给定指令、产出回答」。
