概念概览 · 后训练

SFT 监督微调

用「指令 + 人类写下的期望回答」标注数据在预训练模型上继续训练，把模型从续写语料变成按指令回答。

更新于 2026-08-25

它是什么

SFT（Supervised Fine-Tuning，监督微调；综述将其与 instruction tuning「指令微调」互换使用）在预训练语言模型上，用 (instruction, output)「指令-回答」对以监督方式继续训练。训练目标沿用语言模型的下一 token 交叉熵，常见做法把指令部分 token 的损失置零、只在回答 token 上反向传播（损失掩码）：指令是条件，回答才是要学的内容。

为什么需要它

预训练的目标是「在大语料上最小化词预测误差」，用户的目标是「模型遵循指令、有帮助且安全」——两者错位。预训练模型对指令的默认反应是按语料风格续写，而不是回答。few-shot 提示能在上下文里临时改善行为但不改参数。SFT 用示范数据做梯度更新，让「指令 $\to$ 回答」成为模型的默认行为。

核心机制

  • 数据：(instruction, output) 对；多轮对话样本把此前轮次并入条件部分。样本由 prompt 与 answer 拼接、以特殊 token 分隔。
  • 目标：因果语言模型交叉熵 $\mathcal{L}=-\sum\log p_\theta(y_t\mid x, y_{<t})$，teacher forcing 下逐 token 计算——与预训练同一公式，条件换成指令。
  • 损失掩码：对指令 token 置零、只在回答 token 上反向传播；不 mask 时梯度大量流向「预测指令的下一 token」。
  • 流程位置：后训练三步（SFT $\to$ 奖励模型 $\to$ 偏好优化）的第一步；SFT 产物是后续步骤的初始策略。监督损失只有「数据里那个回答」的似然项，表达不了「回答 A 比回答 B 好」——比较与排序交给偏好优化。

关键结论与边界

  • SFT 刻画数据与目标，不限定参数更新方式：全参数微调与 LoRA 等参数高效方式都可承载。
  • 数据质量重于数量：Llama 2 用 27,540 条高质量标注达到高质量结果，放弃了数百万条第三方数据。
  • 验证损失过拟合不等于该停止：InstructGPT 的 SFT 在 1 epoch 后验证损失即过拟合，训满 16 epochs 反而带来更高的偏好评分。
  • 完整后训练后的 1.3B 模型输出被人类偏好于 GPT-3 175B（架构相同、唯一区别是人类数据微调）——后训练改变的是行为方式。
