# SFT 术语表

| 术语/符号 | 首次出现 | 含义 |
|---|---|---|
| SFT（监督微调，Supervised Fine-Tuning） | 页面标题/开头 | 在预训练模型上用「指令-回答」标注数据继续做监督训练的阶段 |
| 指令微调（instruction tuning, IT） | 开头术语对照 | 与 SFT 同义（综述脚注 1），正文统一用 SFT |
| 预训练（pretraining） | 第 1 章 | 在大规模无标注语料上以下一 token 预测目标训练语言模型；见前置概念页 |
| 下一 token 预测（next-token prediction） | 第 1 章 | 自回归语言模型的训练目标：给定前文预测下一个 token 的分布 |
| 续写（continuation） | 第 1 章 | 预训练模型对输入的自然反应：接着生成语料风格的后续文本 |
| few-shot prompting（少样本提示） | 第 1 章 | 在输入上下文中放少量示例引导模型行为，不更新参数 |
| 后训练（post-training） | 第 1 章 | 预训练之后、面向行为对齐的继续训练阶段统称 |
| 指令（instruction）/ 输入 $x$ | 第 2 章 | 一条训练样本中的条件部分：用户请求及上文 |
| 回答（response/output）/ 输出 $y$ | 第 2 章 | 一条训练样本中要学的部分：期望模型产出的内容 |
| $y_t$ | 第 2 章 | 回答的第 $t$ 个 token |
| $y_{<t}$ | 第 2 章 | 回答第 $t$ 个 token 之前的前缀 |
| $p_\theta(y_t \mid x, y_{<t})$ | 第 2 章 | 参数为 $\theta$ 的模型在给定指令与回答前缀下对 $y_t$ 的预测概率 |
| $D$ | 第 2 章 | SFT 训练数据集，元素为 $(x, y)$ 对 |
| 交叉熵（cross-entropy） | 第 2 章 | 度量预测分布与真实结果的损失；SFT 的损失函数；见前置概念页 |
| teacher forcing | 第 2 章 | 训练时每个位置用真实前缀作条件（而非模型自己的生成） |
| 损失掩码 / loss masking | 第 2 章 | 把指令部分 token 的损失置零、只在回答 token 上计算的做法 |
| 特殊 token（分隔 token） | 第 2 章 | 拼接指令与回答时标记边界的专用 token |
| 多轮对话样本 | 第 2 章 | 把此前轮次并入条件 $x$ 的 (instruction, output) 对扩展形态 |
| 平均损失 | 第 3 章 | 样本损失除以参与平均的 token 数；mask 策略决定分母 |
| 奖励模型（RM, reward model） | 第 4 章 | 用比较数据训练、给回答打标量的模型；不展开 |
| 偏好优化（preference optimization） | 第 4 章 | 对「哪个回答更好」继续优化策略的阶段统称（PPO、DPO 等）；不展开 |
| 全参数微调 | 第 5 章 | 更新模型全部参数的微调方式 |
| 参数高效微调（PEFT）/ LoRA | 第 5 章 | 冻结主体、只训练少量新增或低秩参数的方式；不展开 |
| 验证损失（validation loss） | 第 5 章 | 在留出数据上计算的损失，用于监控过拟合 |
| epoch | 第 5 章 | 训练数据完整过一遍 |
| 灾难性遗忘 | 不使用 | —（不纳入本页） |
