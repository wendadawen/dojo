# SFT 文章大纲

## 1. 页面开头

开头场景：一个预训练语言模型收到「请把这句话翻译成法语：时间就是金钱」。它没有输出译文，而是继续生成下一条类似格式的请求——因为预训练语料里这句话后面跟着的往往是更多文本。这个场景引出核心错位：预训练学的是「预测下一个词」，用户要的是「按指令回答」。

随后给出简要定义（SFT 是什么，一句话）、核心问题（学习目标 5 条）、首个示例（预告贯穿示例：一条翻译指令 + 玩具词表）、过渡到第 1 章。

只使用 scope 已确认内容，开头不出现未经核对的数字。

## 2. 章节设计

### 第 1 章：预训练目标与用户目标的错位（回答 Q1）

- 章节问题：
  - 问题 1：预训练模型的训练目标是什么，它与用户想要的行为差在哪里？
  - 问题 2：few-shot prompting 不改参数也能让模型「像样」一些，为什么还需要 SFT？
- 完成答案要点：
  - 问题 1：下一 token 预测目标在大语料上最小化词预测误差（引综述 §1 原文，C2）；用户目标是「遵循指令、有帮助且安全」；两者错位使预训练模型倾向续写而非回答。
  - 问题 2：few-shot 通过上下文给出示范，但不改参数，行为改变局限在当前上下文；SFT 用梯度更新把「指令→回答」变成参数里的默认行为（此处只作定位对比，不展开 ICL 机制）。
- 对应范围：Q1 / C2 / 前置：语言模型预训练页（首次依赖处链接）。
- 正文要点：训练目标回顾（链接前置页，不重复展开）→ 错位的具体表现（开头场景的机制解释）→ 用户目标的三要素。
- 表达材料及职责：无公式；一个对比示意（HTML 结构，预训练语料中「请求后面还是文本」vs SFT 数据中「请求后面是回答」）。
- 前置知识安排：本章开头集中链接「语言模型预训练」概念页。

### 第 2 章：SFT 的数据与训练目标（回答 Q2）

- 章节问题：
  - 问题 1：SFT 的训练数据长什么样？
  - 问题 2：SFT 的损失怎么算——为什么沿用下一 token 交叉熵，损失算在哪些 token 上？
  - 问题 3：把指令部分也计入损失，和只算回答部分，差别是什么？
- 完成答案要点：
  - 问题 1：(instruction, output) 对（综述 §1，C1）；多轮对话样本是其扩展：把此前轮次并入条件部分；术语对照（SFT = instruction tuning，脚注同义）。
  - 问题 2：损失为因果 LM 交叉熵（F1，链接交叉熵概念页）；训练时用 teacher forcing（回答前缀已知）；常见做法对指令 token 的损失置零、只在回答 token 上反向传播（Llama 2 §3.1 原文，C4）；动机：指令是条件，回答才是要学的内容；模型不因「指令文本本身的下一词」被训练。
  - 问题 3：不 mask 时模型同时在学「生成类似指令」与「生成回答」两件事，梯度被指令部分的预测误差占据（序列上指令常占多数 token）；mask 把监督信号集中到「给定指令，产出回答」。此点以构造示例呈现差异，属机制解释（构造），不标注为来源结论。
- 对应范围：Q2 / C1 / C4 / F1 / 前置：交叉熵页。
- 正文要点：数据形态（单轮、多轮）→ 拼接与特殊分隔 token（Llama 2 §3.1，C4 补充）→ 损失公式 → mask 的机制解释。
- 表达材料及职责：公式 F1（表达变量关系）；teacher forcing 的最小说明（解释训练时每个位置的条件）；贯穿示例第一次进场（数据格式呈现：指令 token 序列 + 回答 token 序列 + mask 标记）。
- 前置知识安排：本章首次链接「交叉熵」概念页。

### 第 3 章：手算一条 SFT 样本的损失（回答 Q3）

- 章节问题：
  - 问题 1：给定玩具词表和一条「指令-回答」样本，每个回答 token 的损失是多少，整条样本的损失是多少？
  - 问题 2：mask 前后，这条样本的平均损失数值如何变化？
- 完成答案要点：
  - 问题 1：逐 token 计算 $-\log p_\theta(y_t \mid \cdot)$（前置页交叉熵的手算方法），求和得样本损失。
  - 问题 2：同一样本分别按「全序列平均」与「仅回答 token 平均」计算，数值不同，说明「SFT 报告的损失」取决于 mask 策略。
- 对应范围：Q3 / F1 / C4（mask 做法依据）。
- 正文要点：示例设定（玩具词表 6-8 个 token、一条翻译指令、模型对每个位置的预测概率——人为构造并标注「构造示例」）→ 逐 token 损失表 → 两种平均的对比。
- 表达材料及职责：数值表格（展示计算步骤）；完整的多位对数计算放折叠块。
- 前置知识安排：复用前置页的交叉熵手算结论，不再展开推导。

### 第 4 章：SFT 在后训练流程中的位置（回答 Q4）

- 章节问题：
  - 问题 1：完整后训练流程有几步，SFT 在哪一步？
  - 问题 2：有了 SFT 为什么还要偏好优化——示范数据教不了什么？
- 完成答案要点：
  - 问题 1：三步：SFT（示范数据训监督策略）→ RM（比较数据训奖励模型）→ PPO/偏好优化（对奖励优化策略）（InstructGPT §3.1，C3）；SFT 产物是后续步骤的初始策略。
  - 问题 2：示范只给出「可接受回答」的单点样本；偏好优化处理的是「同一指令下多个回答之间的优劣排序」，这需要比较数据与相对目标；SFT 的监督损失没有表达「A 比 B 好」的机制。
- 对应范围：Q4 / C3。
- 正文要点：三步流程结构图（HTML，dg-flow 组件）→ 每步的数据类型与产物 → SFT 与偏好优化的分工边界。
- 表达材料及职责：流程结构图（展示三步与数据流）；贯穿示例第三次进场（同一指令下模型生成两个候选回答，说明监督损失对「哪个更好」无表达——构造示例）。
- 前置知识安排：无新增前置；PPO/DPO 一律不展开（scope 排除）。

### 第 5 章：实践中的边界与误解（回答 Q5）

- 章节问题：
  - 问题 1：SFT 对参数更新方式有要求吗？
  - 问题 2：SFT 数据是不是越多越好？
  - 问题 3：验证损失开始过拟合，是否应该停止训练？
- 完成答案要点：
  - 问题 1：没有。SFT 刻画数据与目标；全参数与 LoRA 等参数高效方式都可承载（误解 1）。
  - 问题 2：不是。Llama 2：数万条即可，27,540 条停止标注，放弃数百万第三方数据改用少量高质量（C5、N3）（误解 2）。
  - 问题 3：不一定。InstructGPT：1 epoch 后验证损失过拟合，16 epochs 带来更高 RM 分数与人类偏好（C6、N2）；验证损失与下游偏好不是同一指标（误解 3）。
  - 补充（若 C7 核对成功）：SFT 后的小模型输出被偏好于大得多的预训练模型（误解 4）；核对失败则此点整体删除。
- 对应范围：Q5 / C5 / C6 / N2 / N3 / C7（待核对）。
- 正文要点：四个边界点逐条「误解 → 正确结论 → 依据」。
- 表达材料及职责：InstructGPT 与 Llama 2 的训练事实小表（数字均有来源）。
- 前置知识安排：无新增。

## 3. 讲解顺序

第 1 章（为什么）→ 第 2 章（是什么：数据与目标）→ 第 3 章（怎么算）→ 第 4 章（流程定位）→ 第 5 章（边界）。依赖关系：第 2 章依赖第 1 章的动机与前置页的预训练目标；第 3 章依赖第 2 章公式；第 4、5 章依赖前三章的概念。无循环依赖。

## 4. 贯穿示例

设定：玩具词表（约 8 个 token，含 <指令开始> <回答开始> 类特殊 token 的简化版）、一条法语翻译指令与三 token 回答。模型对每个位置的下一 token 概率分布全部给出（人为构造，标注「构造示例」）。

- 第 2 章进场：呈现样本的 token 序列与 mask 标记（数据格式）。
- 第 3 章推进：对回答的 3 个 token 逐个算交叉熵并求和；再算「不 mask」版本对比。
- 第 4 章推进：模型微调后对同一指令生成两个候选回答，展示监督损失无法表达优劣（构造）。

单一例子覆盖 Q2、Q3、Q4 的核心推进，无局部例子。
