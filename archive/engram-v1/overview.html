Engram

Engram 是插在 Transformer 少数几层前的条件记忆模块，把每个位置结尾的几个 token 按规范化文本等价折成规范 id，再对这些 id 组成的 n-gram 做哈希，取回静态嵌入表的若干行，由当前隐状态算出的标量门调制后写回残差流。

是什么

Engram 是一个条件记忆模块，插在 Transformer 少数几层的前面。它给模型补上一条查表通路：把每个位置结尾的一小段上下文当作键，用哈希在一条大嵌入表里查出若干行，再把查回的内容写回主干。表只被查，不参与每个 token 的浮点运算。

为什么需要

命名实体、固定搭配这类知识是局部的、静态的，本来查一次表就能取回；而标准 Transformer 没有原生的查找原语，只能靠若干层注意力和前馈网络把它们重新拼出来。Engram 把这类工作接过去，于是稀疏参数分成两路：一路是 MoE 的专家，稀疏地激活来做动态计算；一路是 Engram 的表，稀疏地查表来取回静态记忆。

大概怎么工作

每个位置分两段。检索段先把原始 token id 按规范化后的文本等价折叠成更少的规范 id，再对每个 n-gram 阶、每个哈希头算一个行号，从素数大小的桶里取回向量，拼成一个记忆向量。融合段用当前隐状态作查询、用这份记忆投影出的键做一次归一化点积，得到一个 $0$ 到 $1$ 的标量门，门控后的值再经过一个短的因果卷积写回主干；主干之后照常做注意力与 MoE。行号只由输入 token 决定，可以在对应的层执行之前就算出来。
