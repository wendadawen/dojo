## 修改

逐条对照资料与 guides/concept.md 核实后改。除下面列出的一条，其余报告的问题都成立。

- **RULER 八类（5 人）**：改成「单针、多键、多值、多查询四种大海捞针，加上变量追踪、常见词提取、频繁词提取与问答」，与论文 §5.1 的八类一致。
- **MMLU 与 CMMLU 那条（4 人）**：改成「低于 MMLU 的 3.0 与 CMMLU 的 4.0」，与 Table 1 的两列相减一致。
- **哈希构造（4 人）**：整句删掉，只留论文写过的「这个哈希在实现里是轻量的乘法异或」。原文里「每个阶数与头的组合各占一段自己的桶区间」还与折叠块里每头一张表的写法冲突，一并删掉。乘子、取模这些细节只出现在例子里，由例子自己走通。
- **折叠对象（1 人）**：描述改成「把每个位置结尾的几个 token 按规范化文本等价折成规范 id，再对这些 id 组成的 n-gram 做哈希」，摘要改成「把位置 $t$ 结尾的 n-gram 里的 token 折成规范 id」，与论文 §2.2 先折 id 再取后缀 n-gram 的顺序一致。
- **行号由谁决定（1 人）**：改成「行号只由以该位置结尾的那几个 token 决定」。
- **「满射」（2 人）**：删掉这个词，改成「一个把原始 id 归到规范 id 的投影」。
- **FP8、PCIe（2 人）**：多分支那句的「FP8」删掉，写成「稠密的矩阵乘」；吞吐那句改成「强制所有取回都从主机内存取」。
- **「门判错时噪声直接进入残差流」「是缓解，不是保证」（1 人）**：删掉这两句判断，只留资料里的说法，改成「门由当前隐状态算出，隐状态没聚合到足够的上下文时，判断就不准」。
- **实验条件进折叠块（3 人）**：消融那章删掉「12 层、3B 主干」「1.6B 预算」，只留结论；无限记忆那段删掉槽位数区间与参数规模，只留幂律与「不需要额外算力」；吞吐那段把设置移进新增的折叠块，正文只留「吞吐量的下降在百分之三以内」。27B 的 Engram 配置（3 元、8 头、维度 1280、Adam 五倍学习率）也移进折叠块。
- **正文数字过多（2 人）**：基准正文只留 MMLU 57.4→60.4 与 BBH 50.9→55.9，涨幅改成定性的「通用推理与阅读理解涨得比 MMLU 更多」；长上下文只留多查询大海捞针 84.2→97.0，其余在折叠表里。
- **重复（5 人，共四处）**：「Engram 不插在每一层」删掉前一章那处；Engram-40B 那句删掉「什么时候不成立」里那条（正文保留，作为结果）；「检索段要做两件事」删掉；「插得早……插得晚……」在插入层那一章保留完整说明，在「什么时候不成立」里压成一句「位置只能折中」的边界。
- **短页与长页开头（2 人）**：短页三节按「是什么、为什么需要、大概怎么工作」重写；长页开头从语言建模的两类工作讲起，两处不再共用句子。
- **元语句与口语（3 人）**：删掉「完整过程见折叠块」与复述例子设定的那句；「靠记忆补了回来」改成「性能仍与纯 MoE 基线相当」；「这条曲线给出一个行为可预测的旋钮」改成「加大表持续有收益，而且不需要额外算力」；「4B 主干掉约 1.9%」改成「吞吐量下降约 1.9%」（数字移进折叠块的表）；章标题「系统拿它做了什么」改成「确定性寻址带来的系统做法」；折叠块标题「这两组实验」改成「这几组实验」。
- **未采纳一条**：审查者 4 认为应删掉「论文的 27B 模型据此插在第 2、15 层」的整句。论文 §4.1 写明 Engram-27B 插在第 2、15 层，这句成立，只删掉没有出处的「据此」二字。
