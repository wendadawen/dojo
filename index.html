模型架构

Kimi K3：三维度扩展信息流的开源前沿模型

K3 用 KDA+AttnRes+Stable LatentMoE 在序列/深度/宽度三维度扩展信息流，2.8T 参数、104B 激活、1M 上下文，约 2.5× scaling 效率提升。完整精读覆盖架构动机、各组件机制、训练、后训练、基础设施、性能与独立评价。基于 arXiv:2607.24653v1 技术报告、官方 config.json 与源码三层核对。

 MoE 服务系统

ExpertPlex：让 prefill 和 decode 共享 MoE 专家的高吞吐服务系统

MoE 权重占参数 95%+，跨阶段共享专家消除冗余、分离 attention 保住本地算力；APK 在 tile 边界（2.2–25.3μs、与序列长度无关）有界抢占与重分配；attention 发起的一侧通信去掉 MoE 侧协调、消除跨阶段死锁。goodput 达 PD 分离 2.01×、PD 合设 1.66×。基于 arXiv:2607.18002v2 原文逐条核对。

概念学习

从为什么到机制、公式和例子的学习页面。

注意力机制

Kimi Delta Attention（KDA）

K3 的核心线性注意力：delta 规则（写前擦除）+ channel-wise 遗忘门 + lower-bounded decay（scaled sigmoid 把 log-decay 限在 (-5,0)，使对角 tile 也能用 Tensor Core）+ full-rank 输出门 + ShortConv。69 层。基于 K3 报告 §2.1.1 + config.json + 源码核对。

 注意力机制

Multi-head Latent Attention（MLA）

DeepSeek-V2 提出的 KV 低秩压缩注意力：每 token 只缓存低维潜向量，注意力时上投影重建 K/V。K3 的 Gated MLA 额外加 full-rank 输出门，且对 MLA 层用 NoPE。24 层。基于 DeepSeek-V2 论文 + K3 报告 §2.1.2 + config.json 核对。

 深度信息流

Attention Residuals / Block AttnRes

把 attention 思想用到深度：每层用可学习 pseudo-query 对前序块表征做 softmax 加权检索。Block 版把 93 层分 8 块×12 层，块内求和、块间 attention，O(Ld) 降到 O(Nd)。每层 attention 前、MLP 前、模型末尾各加权一次。基于 K3 报告 §2.2 + config.json 核对。

 MoE 架构

Stable LatentMoE

K3 的 MoE 设计：路由专家在紧凑隐空间操作（3584 维），三件稳定化——RMSNorm 聚合后归一、SiTU-GLU 有界激活、Quantile Balancing 负载均衡。896 路由专家 top-16 + 2 共享，稀疏度 56×。基于 K3 报告 §2.3 + config.json 核对。

 激活函数

SiTU-GLU：有界门控激活

用 softcap(x,β)=β·tanh(x/β) 同时限制 GLU 的门支和值支，输出上界 β1·β2=100，从根源抑制激活爆炸同时保留近原点线性响应。对比 GLU/SwiGLU 的无界性。基于 K3 报告 §2.3.2 + §B 附录推导核对。

 MoE 负载均衡

Quantile Balancing（QB）

K3 的 MoE 负载均衡：从单次前向推导下一 bias（取 margins 的 1-k/n 分位数），替代 DeepSeek-V3 固定步长 sign 更新。896 专家时 sign 失效，QB 一步到位无学习率。训练用 histogram 估计分位数，推理冻结。基于 K3 报告 §2.3.3 + §C/§D 附录核对。

 位置编码

No Position Encoding（NoPE）

不对 query/key 施加任何显式位置编码。因果掩码隐式编码位置。K3 对所有 MLA 层用 NoPE，位置感由 KDA 循环状态提供，8K→1M 外推无需 RoPE 插值。基于 NoPE 论文（Kazemnejad 2023）+ K3 报告 §2.1.2/§3.4 核对。

 视觉编码器

MoonViT-V2：从零训练的视觉编码器

K3 的视觉编码器，27 层 ViT 约 0.4B 参数。关键创新：完全从零用 next-token prediction 训练，不用 SigLIP 对比预训练初始化——因为 SigLIP init 梯度不稳定。图像/视频共享参数，pixel-shuffle 下采样。基于 K3 报告 §2.4 + config.json 核对。

 优化器

Per-Head Muon

K3 的优化器改进：不对完整 Q/K/V 投影矩阵做 Newton-Schulz 正交化，而是按头切分动量、每头块单独正交化，均衡各头更新尺度，提升大尺度训练稳定性。分布式用 P2P 通信取回本地参数分片。基于 K3 报告 §2.5 + §5.2.2 核对。

 量化

MXFP4 量化感知训练

K3 把 MoE 专家权重量化到 MXFP4（4-bit）、激活 MXFP8，从 SFT 起做 QAT 覆盖 SFT+RL，rollout 与训练共享方案消除 train-inference mismatch。非专家组件保持高精度。基于 K3 报告 §4.1.4 + config.json quantization_config 核对。

 后训练

Multi-Teacher On-Policy Distillation（MOPD）

把 9 个领域×努力程度专项专家整合进统一模型：per-token OPD 奖励 clip(sg(log(π_teacher/π_θ)))，密集信号无缝接入 RL 框架，复用 partial rollout。基于 K3 报告 §4.1.3 Eq.15 核对。

 训练基础设施

FlashKDA 与 KDA Context Parallelism

KDA 的 GPU 并行方案：FlashKDA chunkwise kernel 重叠 intra-chunk 计算与 cross-chunk 状态传播；KCP 把每段分解为累积转移 M+从零状态 S̃，all-gather 交换后 prefix scan 重组，通信量与序列长度无关；解码用投影输入缓存处理投机解码回滚。基于 K3 报告 §5.1 + §5.4.2 核对。

 训练基础设施

MoonEP：完美均衡专家并行

每 rank 恰好收到 S×K token 的 EP 方案：动态冗余专家在线规划（证明 E/R 上界基本紧）、零拷贝通信（固定 S×K buffer）、静态形状免 host 同步、workload-aware GEMM 调度。基于 K3 报告 §5.2.1 + §E 附录核对。

 注意力机制

线性注意力

用核分解 φ(q)^T φ(k) 与结合律重排把 softmax 注意力 O(N²) 降到 O(N)，因果掩码下变成固定大小递归状态，推理代价与序列长度无关。代价是失去 softmax 的指数聚焦能力。基于 Katharopoulos 2020 等论文核对。

 注意力机制

Delta 规则与 DeltaNet

递归状态更新规则：写入新 key-value 前先沿当前 key 方向擦除旧值（投影），再做加权写入。解决线性注意力在 L>d 时的 key 碰撞。DeltaNet 给出并行训练算法，Gated DeltaNet 加门控。基于 Schlag 2021 + Yang 2024/2025 论文核对。

 深度网络

残差连接

h_{l+1}=h_l+F(h_l)，让信息跨层直连，缓解深网络梯度消失。ResNet 提出。梯度结构 ∂y/∂x=1+∂F/∂x 的全 1 直通项保证梯度回传。基于 He 2016 ResNet + Veit 2016 集成视角核对。

 激活函数

Gated Linear Unit（GLU）

用 sigmoid 门控调制线性分支：GLU(x)=(xW+b)⊗σ(xV+c)。门控激活函数家族基础，后续 SwiGLU、GeGLU、SiTU-GLU 都基于它。基于 Dauphin 2017 + Shazeer 2020 论文核对。

 MoE 推理

MoE 大模型推理与服务基础

从 Transformer 层结构到 MoE 替换 FFN 的动机；router/top-k 稀疏激活、shared/routed expert、专家并行与 all-to-all dispatch/combine、TBO/SBO；prefill/decode 两阶段与 KV cache；TTFT/TPOT/SLO/goodput；PD 分离与 PD 合设的基本动机。数字以 DeepSeek-V3 系模型为准核对。

 GPU 执行模型

GPU 执行模型与 kernel 调度

SM/Tensor Core/TMA/warp/CTA/cluster/DSMEM 硬件层级；kernel 与 CUDA stream 的启动执行模型；GEMM 与 tile 的关系（长输入只是 tile 更多不是 tile 更大）；warp specialization 流水线直觉；persistent kernel 与 CUDA Graph；分一张卡的四种机制（stream 优先级/MPS/MIG/Green Context）能力边界对照。数字按 NVIDIA 官方文档核对。

 注意力机制

标准 Transformer 注意力（Scaled Dot-Product Attention）

softmax(QK^T/√d_k)V 的每个符号与每一步；√d_k 缩放来自方差推导；多头拼接与参数量等价；O(n²) 瓶颈在 QK^T。基于 Vaswani 2017 论文核对。

 位置编码

RoPE 旋转位置编码

通过旋转矩阵在 q/k 上编码相对位置：维度两两分组按位置 m 旋转 mθ_i，q_m^T k_n 只依赖 m-n。多频率几何级数 θ_i=base^{-2i/d}。基于 Su et al. 2021 论文核对。

 位置编码

位置编码基础

Transformer 自注意力不含位置信息，需位置编码。四类方案：绝对正弦、可学习绝对、相对 bias（T5）、旋转（RoPE）。K3 选 NoPE。基于 Vaswani 2017 + T5 + RoPE 论文核对。

 注意力机制

MQA 与 GQA（多查询/分组查询注意力）

MQA 所有 query 头共享一组 K/V，GQA 分组共享。MHA→GQA→MQA 是 KV cache 减少的连续谱。基于 Shazeer 2019 + Ainslie 2023 论文核对。

 线性代数

低秩分解

把大矩阵 W≈AB（r≪min(m,n)）用两个小矩阵近似。SVD 最优性。LLM 中用于 LoRA 微调、MLA KV 压缩、KDA 衰减门低秩生成。基于线性代数教材 + LoRA 论文核对。

 激活函数

SwiGLU

Swish 激活的门控 GLU：SwiGLU(x)=Swish(xW_gate)⊙(xW_up)，Swish(z)=z·σ(z)。Shazeer 2020 提出，LLaMA 等主流模型标配。K3 的 SiTU-GLU 是对其加 softcap 有界化。基于 Shazeer 2020 论文核对。

 优化器

Muon 优化器

基于 Newton-Schulz 正交化的矩阵参数优化器：对动量矩阵做正交化后再更新，使各方向更新尺度均衡。K3 的 Per-Head Muon 是其按头切分改进。

 数值方法

Newton-Schulz 正交化

迭代计算矩阵正交化近似：Q_{k+1}=Q_k(3I-Q_k^T Q_k)/2，收敛到正交矩阵。Muon 优化器用它均衡更新方向。基于数值线性代数教材核对。

 视觉模型

Vision Transformer（ViT）

把图像切成 patch 当 token 喂标准 Transformer：patch embedding + class token + 位置编码。224×224 patch 16 → 196 token。基于 Dosovitskiy 2021 论文核对。

 视觉模型

SigLIP：sigmoid 对比视觉预训练

用 sigmoid 逐 pair 对比损失替代 CLIP softmax，无需全局归一化，支持更大 batch 和更好迁移。K3 的 MoonViT-V2 选择不从 SigLIP 初始化。基于 Zhai 2023 论文核对。

 MoE 架构

DeepSeekMoE：细粒度专家分割与共享专家

把每个专家分成 m 个小专家（组合更灵活）+ 共享专家隔离（承载通用能力）。K3 的 Stable LatentMoE 继承 shared+routed 组织。基于 Dai 2024 论文核对。

 MoE 架构

LatentMoE：隐空间路由

路由专家放进紧凑隐空间：token 先 down-projection 压缩，专家在隐空间计算，再 up-projection 升回。扩大专家池时通信/显存不随专家数线性增长。基于 NVIDIA LatentMoE 论文 + K3 报告核对。

 MoE 负载均衡

辅助损失无关路由

DeepSeek-V3 的 MoE 负载均衡：router 打分加可学习 bias 影响选谁但不进权重，训练时固定步长 sign 更新 bias，无需辅助损失。K3 的 QB 是对其的改进。基于 DeepSeek-V3 报告核对。

 量化

量化基础

把高精度浮点映射到低精度（INT8/FP8/FP4）减少显存和计算。对称/非对称、per-tensor/per-channel/per-block scale、量化误差、PTQ vs QAT。基于量化综述 + OCP 规范核对。

 注意力机制

Gated DeltaNet

DeltaNet + 数据相关门控 α_t：固定衰减改为输入相关 sigmoid 门，按内容决定保留/遗忘。并行训练用 chunkwise 算法。K3 的 KDA 基于 Gated DeltaNet 但改为 channel-wise 门。基于 Yang 2024/2025 论文核对。

 推理加速

投机解码

用小 draft 模型快速生成候选 token，大 target 模型并行验证，接受匹配的拒绝不匹配的。理论等价纯 target 解码，实际加速 2-3×。基于 Leviathan 2023 + Chen 2023 论文核对。

 模型压缩

知识蒸馏

用大教师模型的软标签（温度 T 软化）训练小学生模型。损失=α·硬标签 CE + (1-α)·软标签 KL。K3 的 MOPD 是 on-policy 蒸馏变体。基于 Hinton 2015 论文核对。

 推理加速

EAGLE-3：投机解码 draft 模型

用 target 模型自身的隐藏状态生成 draft token，而非独立小模型。EAGLE-3 是 K3 用的版本，draft 模型与 target 共享 QAT 量化配置。基于 EAGLE 论文 + K3 报告 §4.1.4 核对。

 推理引擎

vLLM 并行：五种正交的切法，SP 家族只有两类方向

TP/EP/PP/DP 各切一个维度，SP 切序列 token（N→N/TP）。SP 名目虽多，实质只有一个分叉：token 切成 N/TP 后遇到权重被 TP 切开的层，是拼回再算（hunyuan TPSP）还是切着算（上游 SP-MoE）；USP 是 attention 维度互换特例，enable_sp 是编译期特例。基于 hunyuan 定制版与上游源码查证。

 GPU 通信

GPU 通信：原语、算法与传输路径

通信原语搬/算/换三类 + 8 原语前后状态详表；ring all-reduce 两阶段与通信量推导（2(N-1)/N 封顶 2 倍 vs 朴素 N-1 倍）；机内 PCIe/NVLink/NVSwitch 分工与出网必经 PCIe；跨机 socket-TCP-IP-以太网（CPU 参与、MAC vs IP）vs RDMA-IB/RoCE-GID-GPUDirect（绕过 CPU）；网卡角色三层面（NIC/HCA/mlx5/bond）；通信库 NCCL/TCCL/gloo 与传输库 UCX/NIXL 分工。
