# 计划

写 `wiki/<name>/research/dataflow.md`。生成器直接读它生成页面，页面上的文字都要先在这里写好。

## 怎么写

- 第一张图是整个模型，从输入画到输出。属于这个模型的模块各画一张图：带模型名前缀的（`HYV4Model`、`Qwen2Attention`）画；类名通用但有自己的计算的（`Indexer`、`Compressor`、`Gate`、`MoE`、`Engram`）画；只是把通用算子套在权重上的基础层（`Linear`、`RMSNorm`、`Embedding`、`PatchEmbed`、通用 SwiGLU 的 MLP、`nn.Linear`）不画，写在使用它们的节点上。用到有图的类的节点都点开过去。
- 一个节点一步。源码一行里套了几层类调用就拆成几个节点；普通函数和方法（`flatten`、`view`、`gelu`、`silu`、`mean`）跟它作用的那个值留在同一个节点里；残差相加这类算式把 `+` 单独画成一个节点。拆出来的中间量源码里没有名字，自己起一个，写在前一个张量节点的第一行。
- 结构相同的层画成一个节点，第一行写 `<层数> × <类名>`，各层的差异写在它的折叠说明里。同一个类被多处实例化、参数不同时，注明差别。
- 前提只定一条路径，写明这次前向的计算条件（输入、精度、走哪条分支）。一次前向走到几个分支就画在同一张图里，不为一支单开一张图；一张图覆盖多层、各层分支不同时，前提里写清哪几层跑哪一支。
- 节点是算子、张量或缓存，算子和张量交替。算子只有一个输出时后面接一个张量，有多个输出时下游用到的每个输出各接一个张量，没用到的写进折叠说明。缓存按读写接在对应的算子旁边。形状相同、总是一起用的一对量合成一个节点，个数写在形状后面。
- 算子里直接用到的量都画成节点，不管它是不是权重；只取某个张量的形状或 dtype、没当数据用的不画，连一条线到用它的算子，线上写明用了什么。用到的张量都要连线。
- 名字照源码写。调用的类有图的点开到那张图；只取它的权重或形状、没调用它的不点开。一个节点只留一条点开。两个类重名时图标题带模块前缀（`vision.Block`）。
- 运行时才知道的维度字母，在它第一次出现的张量第三行写明含义，前提或面板里也交代一次；同一种维度全文只用一个字母。
- 折叠挂在算子上，名字写「公式」或「说明」。公式写这个算子自己的计算，同一符号不能指两段不同的量；调用的类有图的写调用即可，不成图的（基础层）把这次调用的算式写出来。折叠里只引用同图已经画出的张量，同一个源码调用不要在两处画。
- 公式里数据变量（`x`、`h`、`input_ids` 这类）照源码写；权重和参数（`wq_a.weight`、`hc_attn_fn` 这类）改用数学符号（`W_q`、`W`、`s`），下面按式后说明每个符号是什么、**源码里叫什么**，方便对着源码看。符号在同一张图里保持一致。
- 面板的「公式」组每条只放**一个式子**，配一句它在算什么（一句话，30 字内，如「查词嵌入」）。一段流水线有好几个式子就分成几条，一条一个；一条里不写「再 …」这种接续。符号明细和推导放进折叠。
- id 用英文。同一张图里不重复；不同图里同一个 id 指同一个量，不是同一个量就换一个 id；上一个图的输出进到下一个图，沿用产它的那个 id。同一个类里局部重名的量按模块起前缀。
- 前提锁定的那条分支之外的分支不写：算子、公式、说明里都不出现。
- 源码文件名和行号写在标题和「源码」列，给审查者核对，生成器不写进页面。

## 每张图

```markdown
## <类名>.forward（<源码文件>:<起始行>-<结束行>）

### 节点

| id | 类型 | 第一行 | 第二行 | 第三行 | 源码 |
|---|---|---|---|---|---|
| <id> | 算子 | <这一步在源码里的调用> | <原来的形状 → 变完的形状> | | <文件>:<行> |
| <id> | 张量 | <源码里的变量名，没有就写产生它的表达式> | <数据类型和形状> | <运行时维度的字母含义，没有就空着> | <文件>:<行> |
| <id> | 缓存 | <源码里的变量名> | <存的是什么> | <怎么写、怎么读> | <文件>:<行> |

### 连线

- <id> → <id>
- <id> → <id>：<线上的字>
- <id> 点开 → <另一张图的标题>

### 折叠

| id | 名字 | 内容 |
|---|---|---|
| <算子 id> | 公式 | $<公式>$，<每个符号是什么> |
| <算子 id> | 说明 | <权重形状、配置，或要交代的一句话> |

### 面板

| 组 | 名字 | 值 |
|---|---|---|
| 介绍 | <名字> | <几句话，只写在第一张图：先说这是什么模型（哪一家、类型、主干参数量、每 token 激活量、上下文多长），再说这次前向在算什么> |
| 公式 | <名字> | $<一个式子>$<br><一句它在算什么，不超过 30 字。几个式子分几行 |
| 配置 | <配置名> | <用到的配置值> |
```

表格单元格里的竖线写成 `\|`，绝对值写成 `\lvert ... \rvert`，用 `<br>` 换行。
