# 计划

写 `wiki/<name>/research/dataflow.md`。这份文件先写页面信息、资料、前提和 `config.json` 面板，然后每张图各写一节。生成器直接读它生成页面，页面上的文字都要先在这里写好。

## 页面信息

```markdown
# <模型名>

- 描述：<一句话，纯文本>
- 摘要：<首页卡片上的一两句>
- 主题：<从词表里选，逗号分隔>
- 标签：数据流

## 资料

- <源码：仓库、版本或 commit、用到的文件>
- <config.json：从哪里取的>
- <权重文件头：从哪里取的>
- <论文或技术报告>

## 前提

- <推理还是训练>
- <加载精度>
- <注意力实现>
- <缓存>
- <输入，如传了哪些、有没有 padding>

## config.json

| 组 | 名字 | 值 |
|---|---|---|
| <分组> | <配置名> | <值> |
```

## 每张图

```markdown
## <类名>.forward（<源码文件>:<起始行>-<结束行>）

### 节点

| id | 类型 | 第一行 | 第二行 | 第三行 | 源码 |
|---|---|---|---|---|---|
| <id> | 算子 | <源码里的调用> | <原来的形状 → 变完的形状> | | <文件>:<行> |
| <id> | 张量 | <变量名> | <数据类型和形状> | <运行时维度的字母含义，没有就空着> | <文件>:<行> |
| <id> | 缓存 | <变量名> | <存的是什么> | <怎么写、怎么读> | <文件>:<行> |

### 连线

- <id> → <id>
- <id> → <id>：<线上的字>
- <id> 点开 → <另一张图的标题>

### 折叠

| id | 名字 | 内容 |
|---|---|---|
| <算子 id> | 公式 | $<公式>$，<每个符号是什么> |
| <算子 id> | 说明 | <权重形状、配置、一句说明> |

### 面板

| 组 | 名字 | 值 |
|---|---|---|
| 介绍 | <名字> | <几句话，只写在第一张图> |
| 公式 | <名字> | $<公式>$，<每个符号是什么> |
| 配置 | <配置名> | <值> |
```

## 怎么写

- 描述和摘要写这个模型的前向在算什么。第一张图的面板最上面写一组「介绍」，用几句话说明这个模型是什么、这次前向在算什么。
- 前提只定一条主路径，写明这条路径是什么。前提里的每一条都是这次前向的计算条件（输入、精度、走哪条分支）。同一张图画前提里的这一条路径。
- 前提由生成器显示在 `config.json` 面板顶部。配置表写用到的配置值，值照抄 `config.json`；用的是代码默认值的，注明「默认值」。
- 第一张图是整个模型，从输入画到输出。前向用到的、模型源码里自己定义的类，每个都画一张，用到它的节点都点开到这张图。PyTorch 自带的模块（如 `nn.Linear`）和普通函数画在用到它们的节点上。
- 结构相同的层画成一个节点，第一行写 `<层数> × <类名>`，各层的差异写在这个节点折叠的说明里。
- 节点是算子、张量或缓存。算子和张量交替出现；算子只有一个输出时后面接一个张量，有多个输出时下游用到的每个输出各接一个张量，没用到的写在折叠的说明里。缓存不参与这组交替，按读写接在对应的算子旁边。形状相同、总是一起用的一对量可以合成一个张量节点，个数写在形状后面，如 `bf16 [B, T, d] × 2`。
- 算子：第一行是源码里的调用或表达式。合并的层节点第一行写 `<层数> × <类名>`。第二行是形状怎么变，写成「原来的形状 → 变完的形状」，箭头两边都写上。第三行留空。折叠写「公式」和「说明」。每个算子尽量写公式，公式只含这个算子自己的计算，符号用源码里这一行已有的变量名和权重名。说明放权重形状、配置，以及原先放在第三行的那句话。
- 张量：第一行是源码里的变量名，没有变量名就写产生它的表达式；第二行是数据类型和形状，维度写 config 里的数字，运行时才知道的维度用字母。B 是批大小，T 是序列长度。另用别的字母时，在它第一次出现的节点第三行写明含义；同一种维度全文只用一个字母。
- 缓存画成圆柱，放在数据流中间：写进去的张量连到它，读出来的张量从它连出。
- 名字照源码写。源码里这个量叫什么，节点和公式里就写什么。用到的张量都要连线；算子只用到某个张量的形状或 dtype、没把它传进去时，也连一条线到这个算子，线上写明用了什么。
- 折叠只挂在算子上，名字写「公式」或「说明」。点算子右上角的标记打开这些行，点算子本身仍然进入下一张图。
- 整张图才用到、对不上单个算子的式子写在面板。面板可以分组：第一张图有「介绍」。
- id 用英文，同一张图里不重复。不同图里同一个 id 指同一个量；不是同一个量就换一个 id。
- 源码文件名和行号写在标题和「源码」列，给审查者核对，生成器不会写进页面。节点的三行、折叠和面板写计算内容。
- 表格单元格里的竖线写成 `\|`，绝对值写成 `\lvert ... \rvert`；单元格里用 `<br>` 换行。

写完运行 `python3 .dojo/scripts/dataflow/build_page.py wiki/<name>/research/dataflow.md`，它会核格式、主题标签、连线和折叠的引用，报错就改，直到没有报错，再审计划。
