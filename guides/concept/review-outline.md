# 审大纲

大纲写完、机械检查通过后审，做法见[审查](review.md)。最多 3 轮。

## 谁审什么

| 审查者 | 提示词 | 拿到什么 |
|---|---|---|
| 读者 | `outline-reader.md` | 只给 `outline.md`，不给 sources |
| 对照资料 | `outline-sources.md` | `outline.md`、`sources/` |
| 篇幅与冗余 | `outline-size.md` | `outline.md` |

## 什么算「必须改」

审查者按提示词里的类别报出的问题，都算：

- **读者**：顺序错乱、遗漏关键内容、多余、短页标题。
- **对照资料**：资料里没有、遗漏关键内容、抬高次要点。
- **篇幅与冗余**：重复、无关、预算不合理、短页不合格。

「想看更多」「可以再详细一点」不算。

3 个审查者都没有「必须改」的问题，并且作者没有未处理的问题，通过。
