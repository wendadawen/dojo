# 概念页规划

规划用于确定内容范围、证据、文章大纲和术语表，不写 HTML。

产物写入 `wiki/<name>/research/`：

```text
scope.md      内容范围
evidence.md   核心论断与证据的对应关系
outline.md    文章大纲
glossary.md   术语表
```

目标读者不具备该概念及其所属领域的背景知识。

## 1. 概念歧义处理

开始研究前先判断概念名称是否存在歧义：同名缩写、不同领域同名概念、同一术语在不同来源中的不同含义。

歧义处理状态分为：已裁定（有权威或主流含义时采用该含义并记录依据）、并列呈现（不同含义都与核心问题有关，正文中明确区分）、无法消歧（现有可靠信息不足，且不同选择会改变核心定义或主要结论）。无法消歧时停止生产，并记录缺失的证据。

## 2. scope.md：内容范围

### 2.1 概念含义

- 概念名称、英文名称和常见缩写
- 简要定义：说明概念做什么，不承担完整章节职责
- 正式定义：与权威来源一致，每项关键表述均有来源依据
- 本文采用的语境
- 包括什么：每项说明为什么属于该概念
- 不包括什么：容易被误认属于本概念的内容，每项说明排除理由
- 相邻概念：容易混淆的概念，记录关键区别及是否纳入本页范围

### 2.2 学习目标

列出 3–5 个正文必须回答的问题。每个目标包含：

```markdown
### Q1：<具体问题>

- 完成答案：读者最终应能说明的内容
- 为什么是核心目标：不理解它会缺失哪部分概念理解
- 依赖内容：回答该问题需要哪些定义、机制或前置知识
```

学习目标能用完整句子回答，直接对应概念的定义、动机、机制或边界，彼此职责不重复。不合格的示例："什么是 PPO？"（范围过大）、"PPO 有哪些公式？"（把材料形式误当成学习目标）。学习目标用于写作覆盖检查和质检。

### 2.3 内容分级

- 核心内容：缺少后会导致至少一个学习目标无法完整回答。每项记录对应的学习目标和必须说明的结论
- 辅助内容：不直接构成核心答案，但能消除关键理解障碍或澄清常见误解。每项记录它服务的核心内容或误解
- 扩展内容：与概念相关但不影响学习目标回答的内容，每项标记纳入或排除本页范围

分级只确定是否属于本页范围，不决定放正文还是折叠块。

### 2.4 前置知识映射

识别读者理解核心机制前必须掌握的概念知识。逐项检查 `wiki/` 下是否有对应概念页（concept 流程的产物）：

- 已有概念页：记录页面链接，页面中引用它，不内联重复讲解
- 没有概念页：按 `guides/concept.md` 递归生成；递归深度最多 2 层，更深层记录为待补内容

每项前置知识记录：被哪些学习目标依赖、概念页链接或生成状态、递归深度层级。前置知识映射用于正文引用。递归生成的概念页在写入本页前先完成自身质检。

### 2.5 明确不展开的内容

列出本页不展开的内容，每项说明与概念的关系和不展开的原因。合理原因包括：不影响学习目标回答、属于另一独立概念、只影响工程规模。不得仅写"篇幅有限"。

### 2.6 常见误解和适用边界

每个常见误解记录：错误理解、正确结论、形成原因、影响哪个学习目标。适用边界记录：概念解决什么问题、不解决什么问题、结论成立需要的条件、条件不满足时会发生什么。误解和边界必须具体，例如"clip 不是硬约束"应继续写明它裁剪的是代理目标中使用的概率比副本，不会直接把实际概率比限制在固定区间。

## 3. evidence.md：核心论断与证据

核心论断编号（C 论断 / F 公式 / N 数字）只覆盖核心内容。每个核心论断记录：

- 论断内容：可以被证实或证伪的完整句子
- 来源定位：论文 §X / Eq.(X) / Table X，教材章节，或固定版本官方文档与源码路径
- 适用条件：结论成立的条件
- 置信状态：已确认 / 存在冲突 / 证据不足

来源选择优先级：原始论文与标准 > 权威教材与同行评审综述 > 对应版本的官方文档 > 固定版本或 commit 的官方源码。一般教程、博客、聚合文章仅用于辅助定位，不作为核心论断的唯一依据。存在冲突或证据不足的核心论断不能写入正文。

## 4. outline.md：文章大纲

### 4.1 页面开头

规划一个具体问题或最小场景作为开头，使读者能够迅速识别概念所解决的问题；随后给出概念的简要解释、具体问题、学习目标、首个示例和与第一章的过渡。只使用 scope.md 中的内容，不加入未经证实的数字、历史或性能结论。

### 4.2 章节设计

每章只承担一个主要职责。章节数量和标题由知识依赖与学习目标决定，不使用固定章节模板。标题直接说明本章解决的问题或得到的结论，避免"背景""原理""深入理解"一类无法定位职责的抽象词。每个学习目标必须由一个正文章节负责完整回答。

每章记录：章节问题、每个章节问题的完成答案要点、对应范围（Q/K/B/M/C/F 编号）、正文要点、表达材料及职责、前置知识安排（含概念页链接）。章节问题在页面上以「本章问题」呈现，每题配一个解答折叠块，因此规划阶段必须同时确定问题与答案要点。

### 4.3 讲解顺序

章节顺序由知识依赖决定：问题和使用背景位于定义之前，前置知识位于首次依赖之前。避免在同一段集中引入多个未定义概念；存在循环依赖时，从共同场景或可观察现象切入。

### 4.4 贯穿示例

优先选择一个可以跨越主要章节的具体问题或最小例子：输入、变量和目标在第一次出现时完整说明；数字足够小能够手算或逐步追踪；后续章节每次复用时增加新的概念、计算步骤或结论。单一例子无法自然覆盖全文时，使用一条贯穿问题和多个局部例子，每个局部例子说明服务哪个解释目标。

### 4.5 表达材料职责

每种材料必须关联一个具体解释目标：公式表达变量关系，推导解释关键结论来源，数值示例展示计算步骤，图示展示结构或过程，代码展示可执行机制。无法关联具体解释目标的材料不纳入大纲。材料类型没有固定套餐，不因页面出现公式就自动安排完整推导或代码。各材料的写法参考 `guides/concept/content-examples.md`。

### 4.6 正文与折叠块分工

必须放正文：回答学习目标所需的定义、机制和结论；前置概念页链接；会改变结论的条件和限制；贯穿示例的关键推进；公式的目的与符号。可放折叠块：完整代数展开、更长手算、完整代码与输出、补充证明、扩展内容。折叠块全部收起时，正文仍须回答全部学习目标。

### 4.7 范围与证据约束

大纲只能使用 scope.md 中已纳入范围的内容。发现缺少必需定义或机制、需要新增学习目标、需要纳入已排除内容、新增事实改变概念边界时，返回重新规划。

## 5. glossary.md：术语表

登记全文所有首次出现的术语、缩写和符号：名称、首次出现位置、定义或含义。保证全文含义一致，防止同一对象出现多种记号或术语漂移。写作和审查均以此为准。

## 6. 完成条件

- 概念歧义已处理，无影响核心定义的无法消歧项
- 3–5 个互不重复的学习目标，每个有书面完成答案
- 每项核心内容对应至少一个学习目标；每项前置知识映射到概念页或生成状态
- 每条核心论断完成来源定位和置信状态；误解和边界具体可查
- 文章大纲完整：章节单一任务、讲解顺序、贯穿示例、材料职责、正文折叠块分工齐备
- 术语表齐全，符号含义全文一致
- 规划文件不包含应在写作时决定的局部措辞
