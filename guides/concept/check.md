# 概念页质检

质检用于发现并修复初稿问题，不改变已经确定的内容范围和文章大纲。

## 1. 审查轮次

执行三轮相互独立的全量审查。每轮均重新阅读最终页面，不沿用前一轮的判断。

每轮仅使用以下材料：

- `wiki/<name>/index.html`
- `wiki/<name>/overview.html`
- 页面引用的外部来源
- 本质检规范

审查期间不读取 `research/` 中的规划、修复记录和前序审查结果，以降低既有结论对判断的影响。

## 2. 审查内容

### 2.1 可读性审查

以无领域背景读者的知识起点顺序阅读页面，检查：

- 术语是否在首次使用时解释
- 前置知识是否在依赖前给出
- 公式是否说明用途、符号和运算范围
- 推导是否缺少关键步骤
- 示例是否说明输入、变化项和结果含义
- 折叠内容收起后，正文是否仍能建立完整结论
- 类比是否可能产生错误结论
- 章节之间是否存在明确的逻辑衔接
- 学习目标是否都由正文章节完整回答
- 页面级「核心问题」与每个章节的「本章问题」是否每题都有解答折叠块，答案是否独立可读

### 2.2 技术与来源审查

逐条对照外部来源，检查：

1. **定义与机制**：核心论断与来源一致，没有扩大适用范围。
2. **公式与推导**：核心公式、关键推导和数值示例可以复算；符号含义全文一致。
3. **代码**：声称可运行的代码实际执行并核对输出；无法执行时记录原因并改为静态审查。
4. **事实与推断**：来源事实具有可定位依据；构造示例和解释没有写成来源结论。
5. **不确定信息**：条件分支和未确认事项具有明确处理结果，不保留无结论的占位表述。
6. **页面链接**：前置概念链接有效；缺失页面有明确占位。
7. **简化条件**：省略和理想化条件已说明，且不改变核心结论。
8. **页面功能**：公式渲染、折叠交互、目录锚点和本地资源正常。
9. **公式书写**：数学符号全部由 KaTeX 渲染，标题、summary、正文、列表和表格中无 Unicode 数学字符直接出现；同一变量全页写法一致。
10. **图示**：结构图为 HTML 结构或内联 SVG，无等宽字符框线图；图在明暗主题与窄屏下均可读，节点与箭头含义已定义。
11. **问题块**：页面级「核心问题」与章节级「本章问题」命名正确；两级问题都有解答折叠块，答案独立可读且与正文结论一致；核心问题的答案指明了完整论证所在章节。
12. **格式一致性**：符合 `guides/concept/style-guide.md`。

具体写法可参照 `guides/concept/content-examples.md` 的对应小节。

## 3. 问题分级

每轮结果写入 `research/review-{轮次}.md`，每个问题单独记录：

```text
级别｜来源｜位置｜问题｜修复要求｜修复结果｜复验结果
```

- **阻断**：核心结论错误、页面无法使用，或缺少建立主要结论所需的信息。
- **重要**：不会直接推翻核心结论，但会形成明显误解、推理跳步或重要条件缺失。
- **轻微**：不影响正确性和主线理解，但降低表达质量或维护性。

严重度按问题对学习目标、来源一致性和阅读连续性的影响确定，不按修改工作量确定。

## 4. 修复与复验

- 每轮审查完成后逐条修复，并在对应记录中填写修复和复验结果。
- 修改范围限于问题位置及直接受影响的引用位置。
- 定义、公式和数字修改后重新核对来源。
- 代码修改后重新运行。
- 每轮修复完成后运行 `.dojo/scripts/validate.py`。
- 下一轮从修复后的完整页面重新开始审查。
- 需要改变范围或大纲的问题返回规划文件处理。

三轮完成后，阻断和重要问题必须全部关闭。仍未解决的阻断问题最多允许两次追加修复；超过限制则停止发布。

## 5. 发布条件

以下条件全部满足后方可发布：

- 三轮审查均已完成
- 所有阻断和重要问题均已关闭
- 遗留轻微问题具有明确的接受理由
- 全部学习目标由正文章节完整回答
- 页面级「核心问题」与每个章节的「本章问题」均有解答折叠块，无只列问题未作答的情况
- 数学符号全部使用 LaTeX 书写，结构图为 HTML 或内联 SVG
- `.dojo/scripts/validate.py` 返回成功
- 可运行代码的结果与页面描述一致
- 关键论断和数字已重新核对来源
- 页面 `<head>` 包含有效的纯文本 `description`、可渲染 `dojo:summary`、`dojo:type=concept`、`dojo:topics`、`dojo:tag`
- `overview.html` 与 `index.html` 相互链接
- 页面引用的概念链接有效，或具有明确占位
- 递归生成的前置概念页已完成各自质检

发布结果记录在最后一轮审查文件中。首页目录和关系图由 GitHub Pages 构建自动更新。

## 6. 审查记录模板

```markdown
# <概念名>审查记录（第 N 轮）

- 页面版本：<index.html 工作树哈希>
- 审查时间：<日期和时间>

## 问题

- [阻断·可读性] <位置>：<问题>｜修复要求：<要求>｜修复：｜复验：
- [重要·技术] <位置>：<问题>｜修复要求：<要求>｜修复：｜复验：
- [轻微·格式] <位置>：<问题>｜修复要求：<要求>｜修复：｜复验：

## 结论

- 统计：阻断 X / 重要 Y / 轻微 Z
- 处置：修复 / 返回规划 / 可发布 / 停止发布
```

问题描述和修复要求必须能够复验，不使用“表达不够清晰”“建议补充”等无法判定完成状态的表述。
