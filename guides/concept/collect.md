# 收集

只做一件事：把这个概念的官方资料收到 `wiki/<name>/research/sources/`。只收，不分析。

## 收什么

只收原作者或维护方发的资料，第三方一律不收：

- 论文：只收提出这个概念的那一篇。引用它、改进它、综述它的后续论文不收。
- 官方文档、官方仓库、原作者或维护方发的技术博客。

没有这个概念的原始资料的，停下来告诉用户，不要用第三方资料凑数。名字有多个含义、从用户的话里定不下来时，先问用户指哪一个。

## 怎么存

按类型放进 `sources/` 下的子目录：

- `paper/`：论文的 PDF 和 LaTeX 源码（有的话），记版本号（如 v1、v2）。没有 LaTeX 源码的，再存一份 PDF 转出的纯文本（`.txt`）。
- `repo/`：clone 整个仓库，记 commit 号。
- `blog/`：博客和文档，存网址，同时存一份纯文本快照（`.txt` 或 `.md`），内容改版或下线后仍能对上。

页面里的数字靠 `.tex`、`.txt`、`.md` 这类文本核对，PDF 和 `repo/` 不参与，超过 2 MB 的文本也不读。只在仓库代码里出现的数字，正文不能用，除非自己构造例子。

## index.md

`sources/index.md` 每份资料一行：

```markdown
- <文件或目录名>｜<来源链接>｜<版本或 commit>｜<取回日期>｜<一句话说明它讲什么>
```
