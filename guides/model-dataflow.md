# 模型前向数据流

适用于推导模型前向路径并生成交互页面的任务。产出 `wiki/<name>/index.html`，整个屏幕是一张可缩放、可拖动、可下钻的画布。

## 目标

读者沿图从输入走到输出，在任一节点查到模块名、张量形状与依据。

## 执行

1. 取得官方源码、`config.json` 与权重索引；三者不一致时以源码为准。
2. 依次执行规划、画图与质检规范：`guides/model-dataflow/plan.md` → `guides/model-dataflow/draw.md` → `guides/model-dataflow/check.md`。
3. 每个节点都来自源码里真实的一次调用或赋值，不凭印象补中间步骤；拿不准的一律不写。
4. 每层特有的行为（首层与其余层不同、某层走另一条分支）单独核实。
5. 常量和开关要指出它来自 `config.json` 的哪个键，或权重里的哪个张量。
6. 机器核查与独立审查两道都要过。机器只能验证名字存在、形状匹配；归属、结构、完备性必须由未参与画图的审查者从源码独立复现后比对。
7. 独立审查每轮派 3 个子代理并行，一轮零阻断零重要问题后再追加一轮，仍零问题才算通过。无法派发子代理时，向上层返回待独立审查状态，不得自审代替。

## 交付

- `wiki/<name>/index.html`（Pages 构建自动发现）
- 页面 head 中完整的首页元数据
- `research/review-{轮次}.md` 审查记录
- 交付说明仅包含生成位置、页面入口、覆盖的模块、验证结果与已知边界。
