# 模型前向数据流

适用于推导模型前向路径并生成交互页面的任务，产出 `wiki/<name>/index.html`。

## 目标

读者沿图从输入走到输出，在任一节点查到模块名、张量形状与依据。图可缩放、可拖动、可下钻，整个屏幕是一张画布。

## 材料

需要三类材料，缺哪类就说明缺哪类：

- 官方源码：执行路径、张量维度、算子顺序
- 官方 `config.json`：层数、hidden、头数、专家数、topk
- 权重索引或检查点头：每层实际有哪些张量、形状如何

三者不一致时以源码为准，并在节点 `detail` 中写明分歧。

## 执行顺序

1. 逐行读源码，确定 `forward` 的实际执行顺序与每一步的张量维度。
2. 划分视图：主干一格；注意力、MoE、循环体这类复杂模块各开一个视图，父视图只留入口。
3. 按源码整理节点、边与 config 分组。
4. 调用 `.dojo/scripts/dataflow-02-build.py` 生成页面。
5. 跑事实核查与几何自检。
6. 打开页面拖动、切换视图、点击下钻，逐项确认可读。

## 画图要求

- 数据契约为 `view` / `node` / `edge` 三层，字段见生成器文件头。
- 节点名写源码中实际出现的符号，不用部署侧实现名与自造变量。
- 检查点键名与运行时属性名不一致时，在 `detail` 中注明。
- 一个节点三层：`name` 算子名、`shape` 形状、`detail` 依据；同一视图内所有节点同宽。
- 粒度按 `forward` 的规模定：几行无分支的模块一格；十几行线性逻辑在父视图展开；几十行或带循环、分支的单独开视图。
- 单算子（`torch.where`、`torch.cat`）不必逐条罗列；`for` 循环、路由选择这类结构必须展开。
- 每个视图只表达一条完整路径，第一个视图为首屏可读的主干。
- 每条边两端都标方向：起点圆点、终点箭头。
- 跨视图的量用 `port` 标出。
- 不手写节点坐标与连线折点，布局交给 ELK。

## 事实核查

事实错误是这类页面最严重的失败：读者按图理解模型，图错了比图丑有害得多。写入前逐项回查，写完后机器复核，再交独立审查，三道都要过。

**画之前**

- 每个节点都来自源码里真实的一次调用或赋值，不凭印象补中间步骤。
- 每层特有的行为（第 0 层与其他层不同、某层走另一条分支）单独核实。
- 只出现一次的常量、开关、维数，都要指出它来自 `config.json` 的哪个键，或权重里的哪个张量。
- 源码与 config 冲突时以源码为准，把分歧写进 `detail`。
- 权重形状取自检查点头（`safetensors` 头部或 `index.json`），不靠参数名推算。
- 拿不准的一律不写；写"未核实"也比写错强。

**机器复核**

- 节点名：里面每个标识符都要能在源码中 grep 到。脚本会逐字检查，`einsum` 这类源码里不存在的词会被拦下。
- 形状：写成 `名称 [维度]`，如 `q_proj.weight [2048, 1024]`，键名要与权重表一致。脚本只比对**同时出现在页面和形状表里**的键，写错名字会静默漏过——所以键名要逐个对照检查点头。
- 来源：`--source` 可带标签（如 `mtp=/path/mtp.py`），带标签的只作用于标题含该标签的视图。同页有多个来源时必须分标签，否则会把正确的名字误判成捏造。

    python3 .dojo/scripts/dataflow-01-check.py wiki/<name>/index.html \
        --source /path/to/modeling_x.py --shapes /tmp/shapes.json
    python3 .dojo/scripts/dataflow-01-check.py wiki/<name>/index.html --geometry

**独立审查**

机器只能验证局部一致性——名字存在、形状匹配。它验证不了归属、结构、完备性：`nn.Linear` 出现几十次，grep 到了不代表是这一层的；图与源码的执行顺序是否一致、有没有漏画，都需要语义判断。

所以画完后必须交独立审查：每轮派 3 个子代理并行，各自从源码独立推导一遍数据流，再与页面比对。审查者自行取得源码与权重，不读画图记录和前序结论。一轮零阻断零重要问题后再追加一轮三方审查，仍零问题才算通过。

规范见 `guides/model-dataflow/check.md`。

**画图者自己也要看**

- 节点名拼得对但**连错了**——箭头指向错误的模块，脚本不检查。
- 遗漏步骤——源码里做了而图上没画，没有东西会提醒。
- 算子顺序对但语义说错。
- 可读性：拖动、切换视图、点击下钻、开合参数面板，逐项看过。

成稿后按源码再走一遍，确认图上每一步都能找到对应行。
