# Paper 阶段 1：规划

规划阶段决定讲什么、怎么讲，产出范围、证据、教学大纲和术语表。不写 HTML。

产物写入 `wiki/<name>/research/`：

```text
scope.md      内容范围
evidence.md   核心论断与证据的对应关系
outline.md    教学大纲
glossary.md   术语表
```

读者默认是完全小白，不具备该论文所属领域的基础知识。

## 1. 固定论文版本

开始前获取并固定论文版本：arXiv 论文优先下载 TeX 源码包并确认版本号，有正式会议版时以会议版为准；无法获取 TeX 源码时用 `pdftotext` 提取 PDF 文本。后续全部论断定位以固定版本为准。

判断是否存在会改变论文定位或主要结论的歧义：版本间实质差异、方法名与其他工作同名、预印本与会议版内容不一致。歧义无法消歧且影响论文定位或主要结论时，流程失败且不发布。

论文有官方代码仓库时，固定到具体版本或 commit 浏览核心文件，用于核对实现机制；代码只作证据，不构成页面必须覆盖的内容。

## 2. scope.md：内容范围

### 2.1 论文定位

- 论文标题、作者、单位、会议或期刊、年份、链接、代码仓库链接
- 一句话说明：论文用 X 解决了 Y 问题
- 论文宣称的贡献，与原文 abstract 或 contribution 一致，不依靠训练记忆补写
- 论文没做什么：容易被误认属于本文贡献的内容，每项说明排除依据
- 相邻工作：容易混淆的方法，记录关键区别及是否纳入本页范围

### 2.2 核心问题

列出 3–5 个读者读完后必须能够回答的核心问题。每个核心问题包含完成答案、为什么是核心问题、依赖内容。核心问题能用完整句子回答，直接对应论文的动机、机制、实验结论或边界，彼此职责不重复。

### 2.3 内容分级

- 核心内容：缺少后导致至少一个核心问题无法完整回答
- 辅助内容：不直接构成核心答案，但消除关键理解障碍或澄清常见误解
- 扩展内容：与论文相关但不影响核心问题回答，逐项标记纳入或排除

分级只确定是否属于本页范围，不决定放正文还是折叠块。

### 2.4 前置知识

识别完整解析需要读者具备的概念知识（如背景模型、方法依赖的基础机制），逐项检查 `wiki/` 下是否有对应概念页（concept 流程的产物）：

- 已有概念页：记录页面链接，完整解析中引用它，不内联重复讲解
- 没有概念页：递归调用 `guides/concept.md` 流程生成，用子代理执行完整三阶段；该概念页的前置知识缺口同样递归处理，递归深度最多 2 层，第 3 层起只登记不生成

每项前置知识记录：被哪些核心内容依赖、概念页链接或生成状态、递归深度层级。前置知识映射是生产阶段引用的依据。递归生成的概念页在写入本页前先完成它自身的质检。

### 2.5 明确不展开的内容

列出本页不展开的内容，每项说明与论文的关系和不展开的原因。合理原因包括不影响核心问题回答、属于另一独立工作、只影响工程规模。不得仅写"篇幅有限"。

### 2.6 常见误解和适用边界

每个常见误解记录：错误理解、正确结论、形成原因、影响哪个核心问题。论文解读特有的误解来源：把论文声称的改进当成无条件成立、把相对提升当成绝对数值、把特定实验设置下的结论推广到未覆盖场景、把解读者推断当成论文结论。

适用边界记录：方法解决什么问题、不解决什么问题、结论成立需要的条件、条件不满足时会发生什么、实验未覆盖哪些场景。误解和边界必须具体到数字和实验设置。

### 2.7 论断分级

scope.md 中的每条核心论断标注四类：

- 论文明确声称：原文直接陈述，附原文定位
- 文献已有结论：来自其他论文或权威来源，附来源
- 基于证据的推断：由论文内容合理推出，标注"推断"及依据
- 缺失假设的猜测：无法从现有材料确认，标注"未核实"

禁止把推断写成事实，禁止夸大论文声称。全部为"缺失假设的猜测"的论断不得作为页面核心内容。

## 3. evidence.md：核心论断与证据

核心论断编号（C 论断 / F 公式 / N 数字）只覆盖核心内容。每个核心论断记录：

- 论断内容：可以被证实或证伪的完整句子
- 来源定位：论文 §X / Eq.(X) / Table X / Figure X，或固定 commit 的源码路径与行号
- 适用条件：结论成立的条件（实验设置、数据、模型规模）
- 置信状态：已确认 / 存在冲突 / 证据不足

来源选择优先级：固定版本论文原文 > 固定 commit 的官方源码 > 权威教材与原始论文。一般教程、博客、聚合文章仅用于辅助定位，不作为核心论断的唯一依据。

版本间数字不一致、论文公式与官方实现不一致、论文数字缺少实验条件时，不得静默选择，记录冲突双方、可能原因和处理状态。核心论断处于"存在冲突"或"证据不足"状态时，不得进入生产阶段。

主实验结论性数字和关键消融数字必须编号；凡纳入页面范围的实验对比，其基线不得选择性记录。

记录可能用于教学的原文图候选：编号、原文 Figure 编号、图中内容一句话、可服务的教学点、获取途径（TeX 源码 > 官方仓库 > arXiv HTML > PDF 截图）。选择哪张、放哪里由教学大纲决定。

## 4. outline.md：教学大纲

### 4.1 页面开头

规划一句话说明、论文解决的具体问题、学习承诺（读完能够回答的核心问题）、论文元信息、首个具体场景、与第一章的过渡。

### 4.2 章节设计

每章只承担一个主要教学任务。章节数量和标题由教学依赖与核心问题决定，标题直接说明本章解决的问题或得到的结论，避免"背景""原理"一类无法定位教学任务的抽象词。每个核心问题必须由一个正文章节负责完整回答。

独立评价是必有的一章，给出解读者对方法的判断：优点、局限、适用场景、与相邻工作的位置。本章内容全部为解读者推断。

### 4.3 贯穿问题或例子

优先选择一个可以跨越主要章节的具体问题或最小例子：输入、变量和目标在第一次出现时完整说明；数字足够小能够手算；后续章节每次复用时增加新的概念或步骤。无法覆盖全文时，使用一条贯穿问题和多个局部例子。

### 4.4 讲解材料职责

每种材料必须关联一个具体教学问题：公式表达变量关系，推导解释关键结论来源，数字例子展示计算步骤，原图呈现论文原始结构与数据，图示展示结构或过程，代码展示可执行机制。无法关联具体教学问题的材料不纳入大纲。

### 4.5 正文与折叠块分工

必须放正文：回答核心问题所需的定义、机制和结论；前置概念页链接；会改变结论的条件和限制；贯穿例子的关键推进；公式的目的与符号；关键实验数字及其设置。可放折叠块：完整代数展开、更长手算、完整代码与输出、补充证明、扩展实验细节。

折叠块全部收起时，正文仍须回答全部核心问题。

### 4.6 范围与证据约束

大纲只能使用 scope.md 中已纳入范围的内容。发现缺少必需定义或机制、需要新增核心问题、需要纳入已排除内容、新增事实改变论文定位时，返回重新规划。

## 5. glossary.md：术语表

登记全文所有首次出现的术语、缩写和符号：名称、首次出现位置、定义或含义。保证全文含义一致，防止同一对象出现多种记号或术语漂移。后续阶段写作和审查都以此为准。

## 6. 完成条件

- 论文版本已固定并记录；无影响定位的无法消歧项
- 3–5 个互不重复的核心问题，每个有书面完成答案
- 每项核心内容对应至少一个核心问题；每项前置知识映射到概念页或生成状态
- 每条核心论断完成四类分级；误解和边界具体可查
- 核心论断、公式、关键数字均已编号，来源可定位到原文或源码，处于已确认状态
- 教学大纲完整：章节单一任务、贯穿例子、材料职责、正文折叠块分工、评价章节齐备
- 术语表齐全，符号含义全文一致
- 产物不包含下一阶段才该决定的写作细节
