# 论文解析页面

适用于根据论文链接、标题或 PDF 生成解析页面的任务。

## 目标

生成一篇面向无领域背景读者的完整解析页面和一篇概览页面。前置知识引用已有概念页，不在论文页重复展开。

## 执行

1. 先确认论文原文，禁止只根据二手介绍写作。
2. 依次执行规划、写作和质检规范：`guides/paper/plan.md` → `guides/paper/write.md` → `guides/paper/check.md`。
3. 页面必须区分论文明确声称、原文实验事实、解读和推断。
4. 公式、数字、实验结论必须能定位回原文；不确定的信息明确标注，不凭记忆补全。
5. 质检的三轮审查必须由未参与写作的独立审查者执行。无法派发子代理时，向上层返回待独立审查状态，由编排者派发审查者，不得自审代替。
6. 完成独立审查、修复和机械验证后，确认页面 head 中的首页元数据已替换完成；首页由 GitHub Pages 构建自动发现。

## 交付

- `wiki/<name>/index.html`（完整解析，Pages 构建自动发现）
- `wiki/<name>/overview.html`（概览）
- 页面 head 中完整的首页元数据
- 交付说明仅包含生成位置、页面入口、核心覆盖内容、验证结果、已知边界和递归生成的前置概念页。
