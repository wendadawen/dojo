# Paper：把论文变成可浏览的精读页面

当用户给出论文链接、标题或 PDF，并表达“读论文、精读、解读、生成论文页面”时，执行本场景。

## 目标

不是生成摘要，而是产出一篇能从零读懂论文的 HTML 学习页面，并可从 Dojo 首页打开。

## 执行

1. 先确认论文原文，禁止只根据二手介绍写作。
2. 阅读 `guides/paper/_flow.md`，完整执行它指向的五阶段流程。
3. 页面必须区分：论文明确声称、原文实验事实、你的解释与推断。
4. 公式、数字、实验结论必须能定位回原文；不确定的信息明确标注，不凭记忆补全。
5. 完成独立审查、修复和机械验证后，才更新 `content.json` 与首页。

## 交付

- `wiki/<name>/index.html`
- 更新后的 `content.json` 和 `index.html`
- 对用户只说明：生成位置、核心覆盖内容、验证结果、仍有的边界。

不要自动 commit、push 或部署。
