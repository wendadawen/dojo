    PPO：让策略更新不过度冒进

    PPO（Proximal Policy Optimization，近端策略优化）是一族强化学习方法。它先用旧策略收集经验，再用一个“越界后不再多给好处”的代理目标更新策略，使同一批经验可以做有限次重复训练，同时降低一次改得过猛的诱因。本文聚焦最常用的裁剪版 PPO，也就是 PPO-Clip。

    先看一个教学示例。一个智能体走到岔路口，状态记为 $s$，可选“左”或“右”。收集数据时使用的旧策略给“右”动作 $0.25$ 的概率，并恰好抽到了“右”。更新参数后，当前策略可能把“右”的概率改成 $0.30$。问题是：如果这次动作看起来不错，概率应该继续涨到多大？如果它看起来很差，又应该降到多低？

    贯穿全文的岔路场景

    智能体
    做决定的一方。
    环境
    接收动作，并返回奖励和下一个状态的一方。
    策略
    在一个状态下怎样选择动作的规则；随机策略给每个动作一个概率，并按这些概率抽样。
    旧策略
    收集当前批次数据时冻结的策略，“右”的旧概率为 $0.25$。
    当前策略
    正在被优化的策略，“右”的当前概率会随更新改变。

    同一批经验为什么不能无限反复更新

    先弄清经验从哪里来，以及“旧”数据为什么会逐渐不匹配“新”策略。

    一次交互与一批数据

    随机策略写作 $\pi_\theta(a\mid s)$：它表示在状态 $s$ 下选择动作 $a$ 的概率；若动作连续，则表示概率密度。$\theta$ 是控制这个分布的参数。策略不是永远选择概率最大的动作，而是按整个分布抽样。

    强化学习的一次交互可以写成下面的链条。下标 $t$ 表示第 $t$ 个时间步：智能体看到状态 $s_t$，从策略给出的动作分布中抽取动作 $a_t$；环境执行动作后返回即时奖励 $r_t$ 和下一个状态 $s_{t+1}$。连续多步交互组成一条轨迹。

    状态 s_t ──► 策略 π_θ(·|s_t) 抽取动作 a_t
   ▲                         │
   │                         ▼
下一状态 s_{t+1} ◄── 环境返回奖励 r_t

一批轨迹 ──► 更新参数 θ ──► 新策略用于下一轮采样

    更新后，数据生成者已经没变但策略变了

    每轮开始时，PPO 冻结一份参数 $\theta_{\mathrm{old}}$，用旧策略 $\pi_{\theta_{\mathrm{old}}}$ 收集一批轨迹。第一次参数更新后，正在优化的 $\pi_\theta$ 已经改变，但批次里的状态、动作和旧动作概率仍来自 $\pi_{\theta_{\mathrm{old}}}$。继续更新得越多，当前策略就可能离数据生成策略越远。

    关键风险不只是抽象的“距离变远”。固定批次的平均值仍由旧策略实际走到的状态、抽到的动作所决定；当前策略改变后，这批样本不再代表它现在会遇到和选择的数据分布。若目标仍反复奖励提高同几个正优势样本的概率，它本身没有“已经改得够多”的停止机制，当前策略就可能围绕固定旧样本继续放大改动。

    普通策略梯度常用下面的样本目标表达“更好的已采样动作应更可能，更差的动作应更不可能”：

    $$L^{\mathrm{PG}}(\theta)=\hat{\mathbb E}_t\left[\ln \pi_\theta(a_t\mid s_t)\,\hat A_t\right].$$

    $\hat{\mathbb E}_t$ 表示对有限批次样本取平均；$\ln$ 是以自然常数 $e$ 为底的自然对数；$\pi_\theta(a_t\mid s_t)$ 是当前策略给已采样动作的概率或密度；$\hat A_t$ 是稍后解释的优势估计。这里不推导政策梯度定理，因为理解 PPO 只需要保留它的方向职责：$\hat A_t$ 为正时提高该动作概率，为负时降低。这个公式依据原论文公式（2）。

    术语本页含义岔路例子
    批次一次外层采样得到的一组轨迹片段旧策略本轮走过的若干岔路
    轮次把整个固定批次用于训练一遍每条已采经验都看过一次
    小批量一次参数更新只使用批次中的一部分先用其中几条经验更新

    PPO 解决的不是“让历史数据永不过期”。它用新的代理目标削弱过大、有利概率变化继续获得奖励的激励，从而允许一批新鲜数据做有限轮小批量更新；更新完成后仍要用新策略重新采样。PPO 因而仍是同策略（on-policy）方法：用于更新的数据由当前外层迭代的采样策略新鲜收集，只在这次外层迭代内有限复用。

    现在还缺两个量：怎样衡量当前策略相对旧策略改了多少，以及怎样判断这个动作值得鼓励还是抑制。

    概率比告诉我们改了多少，优势告诉我们往哪改

    先评价动作相对“通常水平”的好坏，再比较新旧策略对同一动作的态度。

    从奖励到优势

    即时奖励只描述当前一步环境返回的数。回报则累计从当前开始的一串未来奖励。对同一策略 $\pi$，$V^\pi(s)$ 表示“从状态 $s$ 开始，之后一直按 $\pi$ 行动”的期望回报；$Q^\pi(s,a)$ 表示“在 $s$ 先做指定动作 $a$，之后再按 $\pi$ 行动”的期望回报。

    优势要解决的问题是：指定动作比该策略在这个状态下的通常表现好多少？它定义为

    $$A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s).$$

    $A^\pi(s,a)>0$ 表示该动作优于通常水平，$A^\pi(s,a)<0$ 表示更差，等于 $0$ 表示相当。实际 PPO 不知道真实期望值，只能从有限轨迹得到估计 $\hat A_t$，因此符号也可能受估计误差影响。优势不是即时奖励的别名：一步奖励相同，后续结果或基线不同，优势就可能不同。

    教学示例。为方便判断符号，假设岔路状态的通常回报估计为 $V=3$。若先向右后的回报估计为 $Q=5$，则 $\hat A=5-3=+2$；若估计为 $Q=1$，则 $\hat A=1-3=-2$。这些数字是人为构造的，不是实验结果。

    新旧概率之比

    现在固定同一条样本 $(s_t,a_t)$，比较当前策略和采样时旧策略给这个动作的概率：

    $$r_t(\theta)=\frac{\pi_\theta(a_t\mid s_t)}{\pi_{\theta_{\mathrm{old}}}(a_t\mid s_t)},\qquad r_t(\theta_{\mathrm{old}})=1.$$

    $r_t$ 是概率比。分子是当前策略概率，分母是产生这条样本的旧策略概率，且分母必须为正。$r_t=1$ 表示概率未变；$r_t>1$ 表示当前策略更偏好该动作；$r_t<1$ 表示更不偏好。在连续动作中分子和分母是概率密度，但比值的比较职责相同。这是原论文公式（6）。

    “右”的当前概率旧概率概率比 $r$当前策略的变化
    $0.20$$0.25$$0.8$更不偏好“右”
    $0.25$$0.25$$1.0$没有改变
    $0.30$$0.25$$1.2$更偏好“右”
    $0.35$$0.25$$1.4$偏好得更多

    两个量合起来就给出更新意图：$\hat A_t>0$ 时，希望 $r_t$ 增大，让好动作更可能；$\hat A_t<0$ 时，希望 $r_t$ 减小，让差动作更不可能。接下来要处理的问题是：这种变化是否应该一直得到更多奖励？

    min 与 clip 只封住过大的有利变化

    公式的关键不是“把所有比值夹住”，而是停止奖励越走越远的有利方向。

    先定义一个简单运算。$\operatorname{clip}(x,l,u)$ 把 $x$ 限定为用于计算的区间值：小于下界 $l$ 时取 $l$，大于上界 $u$ 时取 $u$，位于区间内则保持 $x$。令裁剪宽度 $\epsilon>0$，区间是 $[1-\epsilon,1+\epsilon]$，围绕“概率未变”的 $1$ 对称。

    教学示例。全文取 $\epsilon=0.2$，所以区间为 $[0.8,1.2]$。这个数只为手算方便，不是工程推荐值。

    公式 F3：PPO-Clip 的裁剪代理目标。算法要最大化：

    $$L^{\mathrm{CLIP}}(\theta)=\hat{\mathbb E}_t\left[\min\left(r_t(\theta)\hat A_t,\operatorname{clip}(r_t(\theta),1-\epsilon,1+\epsilon)\hat A_t\right)\right].$$

    这是原论文公式（7）。对每个样本，先算未裁剪项 $u=r_t\hat A_t$，再算裁剪项 $c=\operatorname{clip}(r_t,1-\epsilon,1+\epsilon)\hat A_t$，最后取较小的 $\min(u,c)$；$\hat{\mathbb E}_t$ 再对整个批次取平均。因为总目标要最大化，较大的值更有利；刻意取较小值是在采用更保守的样本贡献。

    优势概率比未裁剪 $u$裁剪项 $c$最终 $\min(u,c)$结论
    $+2$$1.0$$2.0$$2.0$$2.0$起点
    $+2$$1.2$$2.4$$2.4$$2.4$增加仍有收益
    $+2$$1.4$$2.8$$2.4$$2.4$超过上界后不再多得分
    $-2$$1.0$$-2.0$$-2.0$$-2.0$起点
    $-2$$0.8$$-1.6$$-1.6$$-1.6$降低仍有收益
    $-2$$0.6$$-1.2$$-1.6$$-1.6$低于下界后不再多得分
    $+2$$0.6$$1.2$$1.6$$1.2$不利变化仍被保留
    $-2$$1.4$$-2.8$$-2.4$$-2.8$不利变化仍被保留

    因此，正优势只在上侧封顶：动作已经更可能后，继续增大概率不再改善样本目标。负优势只在下侧封顶：动作已经更不可能后，继续减小概率不再改善样本目标。向错误方向走时，未裁剪项会更差，min 会保留这个坏结果，而不是用裁剪把它掩盖。

    下面的补充把优势符号带来的不对称写成分情况形式。

    补充推导：正负优势为何封住不同一侧

    已知样本项为 $\min(r\hat A,\operatorname{clip}(r,1-\epsilon,1+\epsilon)\hat A)$。当 $\hat A>0$ 时，乘正数不改变大小关系；若 $r>1+\epsilon$，裁剪项更小，所以结果固定为 $(1+\epsilon)\hat A$。当 $\hat A<0$ 时，乘负数会反转大小关系；若 $r<1-\epsilon$，裁剪后的比值更大，但乘负优势后更小，所以结果固定为 $(1-\epsilon)\hat A$。其他会让目标变差的方向仍由未裁剪项决定。

    教学示例：十组正负优势的完整计算

    取 $\epsilon=0.2$。当 $r$ 依次为 $0.6,0.8,1.0,1.2,1.4$ 时，裁剪后的比值依次为 $0.8,0.8,1.0,1.2,1.2$。乘 $\hat A=+2$ 后，未裁剪项为 $1.2,1.6,2.0,2.4,2.8$，裁剪项为 $1.6,1.6,2.0,2.4,2.4$，取较小值得 $1.2,1.6,2.0,2.4,2.4$。乘 $\hat A=-2$ 后，未裁剪项为 $-1.2,-1.6,-2.0,-2.4,-2.8$，裁剪项为 $-1.6,-1.6,-2.0,-2.4,-2.4$，取较小值得 $-1.6,-1.6,-2.0,-2.4,-2.8$。

    下面的标准库 Python 代码直接展开公式。代码中的 ratio 对应 $r_t$，advantage 对应 $\hat A_t$，epsilon 对应 $\epsilon$。

    可运行代码：验证 min 与裁剪的正负优势行为 
    def clip(value, lower, upper):
    return min(max(value, lower), upper)


epsilon = 0.2
ratios = [0.6, 0.8, 1.0, 1.2, 1.4]
advantages = [2.0, -2.0]

for advantage in advantages:
    for ratio in ratios:
        unclipped = ratio * advantage
        clipped = clip(ratio, 1.0 - epsilon, 1.0 + epsilon) * advantage
        objective = min(unclipped, clipped)
        print(
            f"r={ratio:.1f} A={advantage:+.1f} "
            f"raw={unclipped:+.1f} clipped={clipped:+.1f} "
            f"final={objective:+.1f}"
        )

    裁剪封的是得分，不是策略的可行域

    概率比可以越界；越界后发生的是某些收益封顶，而不是策略被投影回区间。

    贯穿例子里，当前概率 $0.35$ 除以旧概率 $0.25$，实际比值就是 $1.4$。当 $\hat A=+2$ 时，PPO-Clip 用上界 $1.2$ 对应的 $2.4$ 作为样本贡献，但它没有把当前概率从 $0.35$ 改回 $0.30$，也没有把实际比值改成 $1.2$。

    目标函数给优化器提供“哪个结果更值得追求”的分数；硬约束则直接规定哪些结果不允许出现。公式 F3 的 clip 位于算分表达式内部，没有定义一个禁止策略进入的区域。共享参数的一次更新还会同时改变其他状态和动作的概率，所以更不能把它理解为逐样本投影。

    作为结构对照，TRPO（Trust Region Policy Optimization，信赖域策略优化）在原论文公式（4）中显式写出平均 KL 差异不超过阈值 $\delta$：

    $$\hat{\mathbb E}_t\left[\operatorname{KL}\!\left(\pi_{\theta_{\mathrm{old}}}(\cdot\mid s_t),\pi_\theta(\cdot\mid s_t)\right)\right]\le\delta.$$

    这里的 KL 只需理解为汇总新旧动作分布差异的非负数；$\delta$ 是允许的上限，不等式定义了显式可行条件。本文不展开 KL 公式或 TRPO 的求解过程，因为它们不是理解 PPO-Clip 所必需的内容。

    比较PPO-ClipTRPO 的论文形式
    控制位置代理目标内部代理目标外的平均 KL 约束
    是否显式定义可行域否是
    能否推出每个概率比不越界不能也不是逐比值约束
    本页用途核心机制只用于说明目标与约束的区别

    PPO-Clip 不保证每个概率比停在裁剪区间内，不保证参数步长或平均 KL 有固定上限，也不保证每次更新都提高真实环境回报，更不保证找到全局最优。

    原论文把 公式 F3 称为未裁剪代理项的悲观下界，准确含义是：逐样本取较小值后，该代理贡献不会高于未裁剪的 $r_t\hat A_t$。它不是环境真实期望回报的下界。有限样本、优势估计误差和过多更新都可能让代理目标与真实表现不一致。

    PPO 原本是一族方法，原论文还给出自适应 KL 惩罚版；本文只聚焦 PPO-Clip。某些工程实现会额外使用 KL 提前停止等保护，但这些附加机制不是 公式 F3 自带的保证。

    一次 PPO 迭代如何走到下一轮采样

    把旧概率、优势、当前概率和多轮更新放回同一个数据生命周期。

    冻结旧参数 θ_old
       │
       ▼
用 π_θ_old 收集一批轨迹，并保存旧动作概率 p_old
       │
       ▼
由奖励、回报和价值估计得到优势 Â_t
       │
       ▼
固定这批数据，执行 K 轮小批量更新：
重算 p_new → ratio=p_new/p_old → 最大化裁剪代理目标
       │
       ▼
令 θ_old ← θ，使用更新后的策略重新采样
       └──────────────────────────────► 下一轮

    一次完整迭代依次完成五件事：

    1. 冻结采样策略。复制当前参数为 $\theta_{\mathrm{old}}$。它负责收集本批数据，也负责给已采样动作生成分母 $p_{\mathrm{old}}$。
    2. 收集轨迹批次。保存状态、动作、奖励、下一状态、是否结束，以及旧动作概率。结束标记只用来判断轨迹在哪里终止。
    3. 估计回报与优势。价值函数扮演 actor–critic（行动者—评价者）结构里的评价者，帮助从轨迹构造 $\hat A_t$。广义优势估计是常见选择之一，但不是 PPO-Clip 定义的一部分，本页不推导。
    4. 有限轮小批量更新。对固定批次做 $K$ 轮训练。每个小批量都用当前 $\theta$ 重算 $p_{\mathrm{new}}$，再除以冻结的 $p_{\mathrm{old}}$ 得到比值，最大化 公式 F3。价值函数通常用回报目标另外拟合。
    5. 刷新并重新采样。完成本轮后令 $\theta_{\mathrm{old}}\leftarrow\theta$，用更新后的策略开始下一批新经验。
    量来自哪里小批量更新中是否变化
    $s_t,a_t$旧策略与环境交互的固定批次不变
    $p_{\mathrm{old}}$旧策略对已采样动作的概率或密度不变
    $\hat A_t$由固定轨迹和价值估计构造本轮策略更新时固定
    $p_{\mathrm{new}}$当前参数对同一状态动作对重新计算随参数更新而变化
    $r_t$$p_{\mathrm{new}}/p_{\mathrm{old}}$随 $p_{\mathrm{new}}$ 变化
    $\epsilon$本轮设定的裁剪宽度标准目标内固定

    教学解释与类比边界

    “策略改主意”只帮助理解同一动作的新旧概率之比；策略没有主观意图。“算分封顶”只帮助区分目标激励和硬约束；正式判断以 F2、公式 F3 和 F5 为准，不能由类比推出概率比、KL 或真实回报的保证。

    教学简化及其限制

    可运行代码直接输入标量比值和优势，只验证 公式 F3 的数值分支；它省略环境、策略分布、神经网络、自动微分、价值损失、熵奖励、优势估计器、并行采样和数值稳定处理。伪代码展示数据生命周期，但不是可执行实现。真实 PPO 系统还需选择回报和优势估计、策略与价值模型、优化器及停止条件；这些选择不能从本页教学代码推出。
