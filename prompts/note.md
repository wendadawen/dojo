# Note：把一次学习对话整理成结构化 HTML 笔记

只有用户明确说“整理、留档、保存成笔记/页面”时，执行本场景。不要在每次学习后自动留档。

## 目标

把本次已经学清楚的内容整理成可独立阅读、可从 Dojo 首页打开的 HTML 页面。不是聊天记录转录，也不补写用户没有学过的大段内容。

## 内容结构

1. **问题**：这次究竟想弄懂什么。
2. **最短答案**：先给可以复述的一段话。
3. **心智模型**：用因果链、数据流或层次关系组织，不按聊天时间线组织。
4. **关键细节**：只保留会影响判断的公式、代码路径、边界条件。
5. **易错点**：记录对话中真实出现的误解，以及正确区分方式。
6. **仍未解决**：把尚未核实或尚未展开的问题列清楚。
7. **来源**：论文、文档、源码、PR 等可核验链接；推断与事实分开。

## 生成规则

- 以 `templates/note/index.html` 为外壳，写入 `content/notes/<name>/index.html`。
- 页面必须在脱离本次对话后仍能读懂。
- 涉及代码时保留文件路径、符号名和必要行号；声称可运行的代码需实际验证。
- 运行 `scripts/validate.py`；通过后在 `content.json` 的 `notes` 分区登记，并运行 `scripts/generate_index.py`。
- 对用户说明生成位置、笔记覆盖范围和未解决项。

不要自动 commit、push 或部署。
